## 전화 우선 이용 경험 추가

2026-09-09 사용자의 고령자 전화 선호 의견을 반영했습니다. 전화 안에서 조회·선택·예약 완료까지 지원하고, 문자·앱을 필수로 요구하지 않는 경험, 느린 안내·되읽기·정정, 상담원에게 맥락 인계, 동의한 전화 기반 대기 안내와 첫 통화 완료 지표를 구상서에 추가했습니다. 모든 고령자의 선호·현재 TS 구현 기능으로 일반화하지 않았습니다. 실제 음성 인식·전화 시스템·본인확인·예약·결제·상담 인계는 구현·시험하지 않은 설계입니다.

## 예약 정보·현장 가용성 불일치 의견 반영

2026-09-09 사용자 경험을 추가했습니다. 실제 예약 가능한 후보 우선 표시, 마감·정보 미확인 상태 구별, 취소 자리 재연결과 고령자 접근성, 확정 직전 재조회, 현장 대기·헛걸음 지표를 구상서에 반영했습니다. 반영 지연·배정 차이·시간대 편차는 원인 가설이며 운영 기록으로 검증하지 않았습니다. 예측 가용성과 실제 예약 가능 상태를 구별하고 잔여석 기본 정비 효과를 AI 성과로 표시하지 않도록 명시했습니다. 재생성 후 문서·브라우저 검사 58/58 통과. 실제 예약·가용성 연계 기능을 구현·시험한 결과는 아닙니다.

## 추가 발굴 — 고령자 민원 완결 AX

2026-09-09 사용자가 제시한 고령자의 사이트 탐색 부담을 신청·예약 완료 문제로 구체화했습니다. 민원 영역 전체를 제외하던 해석을 정정하고, 기존 과업의 중복 대조를 유지하면서 실제 처리·완료 확인까지 지원하는 발굴안을 작성했습니다. 보기 문서 맨 앞에 추가 발굴안과 근거 문서를 연결했습니다. 기존 5개 후보의 분류·선정 상태는 변경하지 않았습니다.

재생성 후 브라우저 검사 **58/58 통과**. 추가된 원문은 입력 해시·링크 검사에 포함됐습니다. 새 구상의 공식 업무 안내는 열람했지만 실제 예약 화면의 직접 열람은 도구 오류였으므로 실행 절차·API·본인확인·결제는 미검증입니다. 새로운 작동 프로토타입이나 예약 실행은 수행하지 않았습니다. 아래 이전 버전 검사 기록과 구별합니다.

## 최신 v0.2 — 국민체감형 AX로 방향 정정

2026-09-09 추가 사용자 피드백을 반영했습니다. 유형은 기획 초점 불일치이며 이전 첫 화면과 마인드맵에서 인프라·업무 연계가 국민 문제보다 앞서 보이는 점이 원인이었습니다. 기대 결과는 “국민의 어떤 문제를 TS의 실제 업무·법령 범위에서 AI로 줄이는가”가 첫 문장에 드러나는 것입니다.

- 선정기준을 새로 기록하고 기존 기획지침·범위 문서에 연결했습니다. 원장의 신규 범위 분류는 유지하면서 국민체감형 적합성을 별도 재검토했습니다.
- 002·005는 구체화 검토, 004는 수행 근거 선확인, 006은 문제 재발굴, 007은 AI 필요성 재검토로 표시했습니다. 사업 선정·법적 수행 가능성은 확정하지 않았습니다.
- 제목·마인드맵·흐름도·후보 카드를 국민 문제와 한 문장 WHY, 작은 적용, 국민 성과·파급력 중심으로 수정했습니다. 구현 가설·국내외 사례·기존 상세는 기본 접힘으로 보존했습니다.
- 새 기준 검사와 상세 열기·닫기를 포함한 브라우저 검사 **57/57 통과**. 최신 결과는 [화면 검사 원장](화면_검증결과.json)에 있습니다. 마인드맵과 360px 화면을 직접 확인했고 단계별 도식의 노드 내 텍스트 배치도 검사했습니다.
- 자체 QA 판정: 사용자 방향 정정의 문서·화면 반영 통과. 법적 적용성·AI 효과·사업성의 판정은 보류. 독립 검토·추가 외부 리서치는 수행하지 않았습니다.
