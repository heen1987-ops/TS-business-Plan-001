# 기획과제 관리대장

작성일: 2026-09-09. 신규 탐색 후보 8개를 등록했습니다. 사업 선정·예산 확보·계약 범위는 아직 확정하지 않았습니다.

모든 과제는 [신규 사업기획 지침](../00_기획지침/TS_신규사업기획_지침.md)의 P01~P07을 검토합니다. R&D의 국민 문제 해결, 정보화의 AX+SI 적용성, 현업 직무 영향을 함께 확인합니다.

## 과제 목록

후보는 `TS-BIZ-001` 순서로 등록합니다. 최신 탐색 후보는 문서 하단의 통합 포트폴리오 구간을 봅니다. 아래 표는 선정 후 담당·일정·기획서를 채울 관리 양식입니다.

| 과제 ID | 사업명 | 대상 사용자·고객 | 해결할 문제 | 근거 ID | 기대 가치 | 우선순위 | 상태 | 담당자 | 목표일 | 기획서 |
|---|---|---|---|---|---|---|---|---|---|---|

## 과제 선정 기준

| 기준 | 검토할 질문 | 기록할 근거 |
|---|---|---|
| 문제의 명확성 | 누가 어떤 상황에서 어떤 손실이나 불편을 겪는가? | 실제 업무, 사례, 발생 빈도 |
| 고객 가치 | 사업 전후에 무엇이 달라지는가? | 기준값, 목표값, 측정 방법 |
| 기존 사업 연계 | 현행 과업·제안 범위와 어떤 관계인가? | 원문 위치, 범위 중복·추가 여부 |
| 실행 가능성 | 필요한 데이터·인력·기술·권한을 확보할 수 있는가? | 확보 여부와 제약 |
| 비용과 효과 | 비용 부담 주체와 편익을 설명할 수 있는가? | 산정식, 단가 근거, 가정 |
| 검증 가능성 | 작은 범위에서 어떤 결과로 판단할 것인가? | 시범 범위, 기간, 수용기준 |
| 국민 가치·메가이슈 | TS 법정 역할과 국민 피해·편익이 연결되는가? | 기관·업무 ID, 공식 통계·현장 근거 |
| 조직 영향 | 직무 변화와 감원 우려를 어떻게 확인하고 대응하는가? | 현업 의견, 교육·역할·업무 재설계 |
| AI 추가 가치 | AX+SI가 비AI 대안보다 어떤 효과를 제공하는가? | 데이터 준비도, 비교 실험, 비용·위험 |
| 범정부 확장 | 어떤 기관의 어떤 업무에 재사용할 수 있는가? | 기관별 권한·법령·데이터·운영 차이 |
| 도입 정당성 | 왜 공공·TS·지금·AI이며 어떤 절차가 필요한가? | WHY, 기술가치, 재정 타당성, 심의 적용성 |

우선순위는 `상 / 중 / 하 / 미정`으로 기록하고 선정 이유를 기획서에 남깁니다. 근거가 부족하면 임의 점수나 예상 매출로 순위를 확정하지 않습니다.

## 첫 분석 순서 제안

1. SRC-001·SRC-002에서 사업 목적, 대상, 범위, 제약, 산출물을 추출합니다.
2. SRC-005·SRC-010·SRC-011과 현행 승인 요구사항·실제 원장을 대조합니다. SRC-006은 최신성 확인 후 보조자료로 사용합니다.
3. 필요한 경우 SRC-004와 보관 이력에서 문제의 배경을 확인합니다.
4. 사회문제와 기관·법정업무를 매핑하고 P01~P07 근거를 확인해 과제를 등록합니다.

## 메가이슈 → 문제정의 기록

검증 전 문제 후보의 빈 양식입니다. 이슈 등록과 사업 선정은 다른 상태입니다.

| 이슈 ID | 메가이슈와 기간 | 국민 피해·불편 및 수혜집단 | 사실 근거·통계 | 원인 가설 | TS 업무 ID | 공공 개입 필요성 | 상태 |
|---|---|---|---|---|---|---|---|

기획서에는 문제·업무 ID와 P01~P07 판정을 연결합니다. 근거가 부족하면 사업명부터 확정하지 않고 조사 항목으로 유지합니다.
