# 교통 탄소 산정과 ESG 공시근거

## 문제와 제공 결과

**문제 가설:** 활동량·계수·조직·기간·단위가 다른 데이터를 합치며 산정과 공시 문장의 일치 확인이 어려워진다는 가설.

**제공 결과:** 탄소는 독립 산식 검산, ESG는 지표별 원장·증빙·문장 대사를 수행하고 검토자의 확정을 기록.

분류는 조건부 확장 후보. TS의 발주·예산·수요 확정 또는 구현 완료를 뜻하지 않으며, 효과 수치는 현행 기준선과 비교한 뒤 제시.

## 사례 기반 AS-IS → TO-BE 상세

### 현재 확인한 내용과 남은 확인

**확인된 범위:** 공개 전략은 탄소 산정과 ESG 공시 근거를 별도 전략으로 유지함. 공통 증빙관리는 공유할 수 있으나 산식·검토 책임이 같다는 뜻은 아님.

**현장 검증 필요:** 활동량·계수·조직·기간·단위의 실제 혼용, 동일 증빙의 중복 계상, 현재 검산·공시 검토 부담을 확인.

### TS 검토 시나리오와 전환 과제

연료 사용량의 단위가 바뀌고 일부 조직 범위가 제외됐는데 이전 계수·산식을 그대로 적용한 경우의 TS 검토 시나리오.

아래 업무 사례는 설계·검증용 예시이며 TS에서 실제 발생했거나 구현·실증한 사건을 뜻하지 않음. 타기관 사례는 위에서 확인한 공개 범위에만 적용.

| TO-BE 요소 | 수행 내용과 수락 조건 |
|---|---|
| 주체 | 환경·탄소 담당, ESG 지표 소관, 계산 검토자, 공시 승인자 |
| 입력 | 활동량 원장·계수판본·단위·조직 범위·지표 정의·기간·공시 초안 |
| 행동·전환 과제 | 범위·단위를 먼저 맞춤 → 검증된 계산도구로 탄소 검산 → ESG 지표별 원천·문장 대사 → 차이와 중복을 소관자가 수정 → 승인본과 근거 동결. |
| 산출물 | 산정 재현표, ESG 지표별 증빙 대응, 수정·승인 이력 |
| 예외·인계 | 계수·원장 누락은 생성값으로 채우지 않음. 탄소 계산 결과를 외부 검증 없이 감축 실적·ESG 등급으로 표현하지 않음. |
| 완료 판단 | 탄소값은 독립 계산으로 재현되고 공시 문장은 지표·기간·원천에 맞으며 각 승인자가 미확정 항목을 수락. |

### 세 영역의 고도화·신규 구축·조건부 차세대사업

‘고도화’는 확인된 기존 경로의 개선, ‘신규 구축’은 현재 부재·추가 필요성을 확인한 기능, ‘차세대사업’은 앞 단계 성과와 추가 권한·자원이 확보된 후속·파생 경로를 뜻함. 동일 기능을 세 유형의 사업비로 반복 합산하지 않음.

| 영역 | 고도화 | 신규 구축 | 조건부 차세대사업 |
|---|---|---|---|
| 인프라·플랫폼 | 기존 환경·ESG 자료 추출의 범위·단위 대사 | 독립 계산과 문장-원천 연결 | 기관·공급망 연계는 기준 동등성·증빙권 확보 후 |
| 지식 아카이브 | 기존 지표·계수·단위·조직 사전 정비 | 산정·공시 증빙의 중복·판본 관계 | 변경 재산정은 경계·계수 영향 검증 후 |
| 업무서비스 | 기존 검산·공시 초안 검토 개선 | 차이 보완·각 소관 승인·근거 동결 | 통합 공시는 지표별 책임·외부 확인 경로 확보 후 |

### 업무별 2026~2030 단계와 검증 기준

- **2026**: 한 탄소 항목·한 ESG 지표의 원천·산식·정답과 수정 주기 확보.
- **2027**: 단위·계수판본·조직범위가 바뀐 과거 표본으로 독립 대사 검증.
- **2028**: 검증된 지표군의 운영 보고에 한정해 정정·중복과 검토시간 측정.
- **2029**: 외부 자료 연결은 산정경계·제공조건·검토 책임을 합의한 항목부터 확대.
- **2030**: 근거 재현성과 공시 정정·운영비를 평가하고 원천·계수 갱신 책임 정착.

각 단계의 수량·허용 오류·소요시간 목표는 기준선 조사 후 업무·검수 책임자가 합의. 기한 도래만으로 다음 단계에 진입하지 않으며, 중요 예외의 미해결·자료권리 미확보·기존 기능 대비 편익 미확인은 보완·축소·중단 판단 사유.

## 세 영역의 신규·고도화·연계

| 영역 | 신규 개발·구축 | 고도화 | 연계 강화 |
|---|---|---|---|
| 인프라·플랫폼 | 선정 업무의 허용 입출력·권한·기록 연결 | 예외·중복 실행·권한 회수·실패 복구의 검증 | 공식 원천·기존 시스템과 승인된 API 또는 제한된 도구 연결 |
| 지식 아카이브 | 산정경계·계수판본·단위·지표 정의·조직 범위·원천·중복 기준 | 정본·시점·소관·권리·변경·회수 상태와 오류 사례 보강 | 해당 원천·공식 기준·검토 결과를 출처와 함께 연결 |
| 업무서비스 | 원천 확보 → 범위·판본 확인 → 독립 계산·대사 → 차이 보완 → 승인 → 근거 보존 | 담당 수락·보완·사람 확정·실패 인계·완료 증거 보강 | 기존 공식 처리·검토·보고 경로로 인계하고 실제 결과 확인 |

공통 기반을 업무마다 새로 구축하지 않으며, 기존 8.3 업무지식의 절차·규칙·예외 자산을 서비스에 연결. 개별 기관의 원문·정답·개인정보와 재사용 가능한 공통 자산의 권리를 구분.

## 2026~2030 진입 조건

- **2026 준비:** 한 지표의 원장·공식 산식·계수와 현업 정답을 확보하고 기존 ESG·보고 도구와 비교. 같은 기간·대상에서 현행 처리·오류·재작업의 기준선을 확보.
- **2027:** 공통 기반·대표실증을 우선하고 이 업무는 수요·권리·정답·기존 중복의 후보검증까지만 수행 가능.
- **2028:** 현업 검증을 통과한 범위만 확산하고 기준·화면·권한 변경 시 재검증.
- **2029:** 고유업무·기관 간 연계는 각각의 소관·협약·입출력 계약과 예외 인계를 확인한 뒤 추가.
- **2030:** 사용 성과·유지 부담·권리·비용을 다시 비교해 운영 정착·재사용·축소를 결정. 전사 전면 자동화를 약속하지 않음.

2027 ON27-BASE의 M1~M9 최대 9개월은 기존 사이트의 상대 일정 제안이며 이 컨셉의 확정 착수일·납기를 뜻하지 않음.

## 책임·검증·예외

탄소 산정과 ESG 공시는 공통 근거 관리만 공유. 생성 수치·자동 ESG 등급·감축 실적 주장 제외.

업무 소관자가 정답·승인·이의처리·인수를 맡고, 정보화·데이터 담당은 권한·원천·운영을 확인. 공급자는 추가분 설계·연계·시험·복구·운영 인계의 책임과 범위를 명시. 구매·예산·계약 권한은 실제 기관 절차로 확인.

수요·자료권리·검수 책임이 없거나 기존 기능으로 충분하면 보류·축소. 중요 오류·권한 위반·복구 불가가 확인되면 해당 적용을 중단하고 수동 경로로 인계. 비용은 추가 분석·정비·개발·시험·운영의 인정 공수와 직접비로 산정하며 공통비 1회, 기존 의무·R&D·운영비의 중복 계상은 제외.
