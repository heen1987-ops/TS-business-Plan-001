# 교통문화지수 조사와 근거 검증

## 문제와 제공 결과

**문제 가설:** 조사표·표본·지역·판본과 집계 결과를 연결하기 어려워 입력 오류와 재조사의 원인을 확인하기 어렵다는 가설.

**제공 결과:** 조사 기준·필수값·집계·근거를 대사해 조사자 보완과 확정 집계의 재현을 지원.

분류는 조건부 확장 후보. TS의 발주·예산·수요 확정 또는 구현 완료를 뜻하지 않으며, 효과 수치는 현행 기준선과 비교한 뒤 제시.

## 사례 기반 AS-IS → TO-BE 상세

### 현재 확인한 내용과 남은 확인

**확인된 범위:** 기존 신규후보에는 교통문화지수 실태조사의 입력·대사·집계 지원이 포함됨. 실제 조사 자동화 수준이나 오류 규모를 확인한 자료로 취급하지 않음.

**현장 검증 필요:** 조사 표본·관찰 지점·기간·결측처리·집계식과 현행 재조사 사유를 조사 수행자 기록으로 확인.

### TS 검토 시나리오와 전환 과제

한 지역의 관찰시간이 바뀌고 일부 표본이 빠졌는데 전년과 직접 비교한 집계표가 작성되는 TS 검토 시나리오.

아래 업무 사례는 설계·검증용 예시이며 TS에서 실제 발생했거나 구현·실증한 사건을 뜻하지 않음. 타기관 사례는 위에서 확인한 공개 범위에만 적용.

| TO-BE 요소 | 수행 내용과 수락 조건 |
|---|---|
| 주체 | 조사 설계자, 현장 조사자, 집계 검토자, 결과 승인자 |
| 입력 | 조사 설계·표본틀·지점·시간·원자료·결측 사유·집계식·전년 비교 조건 |
| 행동·전환 과제 | 표본과 조사조건 대사 → 필수값·중복·결측 확인 → 독립 집계 → 비교 가능성 검토 → 보완·재조사 또는 비교 제한을 승인. |
| 산출물 | 조사조건별 품질표, 재현 집계, 보완 목록과 비교 한계 |
| 예외·인계 | 무작위 누락과 조사불가를 구분하고 무조건 평균 대체하지 않음. 비교 조건이 달라진 지표는 순위·증감 해석을 보류. |
| 완료 판단 | 승인자가 표본·집계·비교 한계를 확인하고 원자료부터 결과까지 재현 가능한 상태. |

### 세 영역의 고도화·신규 구축·조건부 차세대사업

‘고도화’는 확인된 기존 경로의 개선, ‘신규 구축’은 현재 부재·추가 필요성을 확인한 기능, ‘차세대사업’은 앞 단계 성과와 추가 권한·자원이 확보된 후속·파생 경로를 뜻함. 동일 기능을 세 유형의 사업비로 반복 합산하지 않음.

| 영역 | 고도화 | 신규 구축 | 조건부 차세대사업 |
|---|---|---|---|
| 인프라·플랫폼 | 기존 입력·집계 도구의 결측·중복 검증 | 조사조건·원자료·집계 연결 | 모바일·기관 수집 통합은 표본 일관성 검증 후 |
| 지식 아카이브 | 기존 지표·표본·기간 사전 정비 | 조사조건과 비교 가능성 규칙 | 변화 해석 자동지원은 통계·현장 정답 확보 후 |
| 업무서비스 | 기존 조사 보완·재조사 판단 개선 | 조사자 보완→집계 검산→승인 업무 | 지역 개선과제 연결은 효과 비교 설계 확보 후 |

### 업무별 2026~2030 단계와 검증 기준

- **2026**: 한 조사 항목의 표본·집계식·결측·재조사 기준선 확보.
- **2027**: 과거 허용 자료로 입력·집계 오류와 조건 불일치 탐지 비교.
- **2028**: 한 조사 주기의 현장 보완·집계 재현·승인 부담 제한 실증.
- **2029**: 지역 확대는 조사조건 차이를 보존하고 지자체별 자료·책임 확인 후.
- **2030**: 조사 품질·재작업·유지비를 평가. 지수 개선의 인과효과는 별도 검증.

각 단계의 수량·허용 오류·소요시간 목표는 기준선 조사 후 업무·검수 책임자가 합의. 기한 도래만으로 다음 단계에 진입하지 않으며, 중요 예외의 미해결·자료권리 미확보·기존 기능 대비 편익 미확인은 보완·축소·중단 판단 사유.

## 세 영역의 신규·고도화·연계

| 영역 | 신규 개발·구축 | 고도화 | 연계 강화 |
|---|---|---|---|
| 인프라·플랫폼 | 선정 업무의 허용 입출력·권한·기록 연결 | 예외·중복 실행·권한 회수·실패 복구의 검증 | 공식 원천·기존 시스템과 승인된 API 또는 제한된 도구 연결 |
| 지식 아카이브 | 지표 정의·조사대상·표본·결측·집계식·조사기간·판본 | 정본·시점·소관·권리·변경·회수 상태와 오류 사례 보강 | 해당 원천·공식 기준·검토 결과를 출처와 함께 연결 |
| 업무서비스 | 조사 설계 → 입력·자료 수집 → 규칙·집계 검산 → 표본 확인 → 담당 확정 → 개선 활용 | 담당 수락·보완·사람 확정·실패 인계·완료 증거 보강 | 기존 공식 처리·검토·보고 경로로 인계하고 실제 결과 확인 |

공통 기반을 업무마다 새로 구축하지 않으며, 기존 8.3 업무지식의 절차·규칙·예외 자산을 서비스에 연결. 개별 기관의 원문·정답·개인정보와 재사용 가능한 공통 자산의 권리를 구분.

## 2026~2030 진입 조건

- **2026 준비:** 조사 주관·수행권, 동일 조건 원자료, 독립 집계와 비교표본을 확보. 같은 기간·대상에서 현행 처리·오류·재작업의 기준선을 확보.
- **2027:** 공통 기반·대표실증을 우선하고 이 업무는 수요·권리·정답·기존 중복의 후보검증까지만 수행 가능.
- **2028:** 현업 검증을 통과한 범위만 확산하고 기준·화면·권한 변경 시 재검증.
- **2029:** 고유업무·기관 간 연계는 각각의 소관·협약·입출력 계약과 예외 인계를 확인한 뒤 추가.
- **2030:** 사용 성과·유지 부담·권리·비용을 다시 비교해 운영 정착·재사용·축소를 결정. 전사 전면 자동화를 약속하지 않음.

2027 ON27-BASE의 M1~M9 최대 9개월은 기존 사이트의 상대 일정 제안이며 이 컨셉의 확정 착수일·납기를 뜻하지 않음.

## 책임·검증·예외

입력 자동화를 지역 문화·안전 개선 성과로 바로 환산하지 않음. 조사 결과 순위·평가의 공식 확정은 소관자 책임.

업무 소관자가 정답·승인·이의처리·인수를 맡고, 정보화·데이터 담당은 권한·원천·운영을 확인. 공급자는 추가분 설계·연계·시험·복구·운영 인계의 책임과 범위를 명시. 구매·예산·계약 권한은 실제 기관 절차로 확인.

수요·자료권리·검수 책임이 없거나 기존 기능으로 충분하면 보류·축소. 중요 오류·권한 위반·복구 불가가 확인되면 해당 적용을 중단하고 수동 경로로 인계. 비용은 추가 분석·정비·개발·시험·운영의 인정 공수와 직접비로 산정하며 공통비 1회, 기존 의무·R&D·운영비의 중복 계상은 제외.
