# 반복 구매품 수요·단종 대응 지원

## 문제와 제공 결과

**문제 가설:** 입출고·재고·납기·공급종료 통지가 분리되어 보충 시점과 대체품 검토를 반복한다는 가설. 기관 현행 수요는 미확인.

**제공 결과:** 필요 수량 예측과 재고·납기·예산을 반영한 보충계획을 구분하고, 단종 증거와 대체·마지막 구매 검토를 제공.

분류는 조건부 확장 후보. TS의 발주·예산·수요 확정 또는 구현 완료를 뜻하지 않으며, 효과 수치는 현행 기준선과 비교한 뒤 제시.

## 사례 기반 AS-IS → TO-BE 상세

### 현재 확인한 내용과 남은 확인

**확인된 범위:** 기존 서비스기획은 수요예측과 보충계획, 제조사 단종을 각각 다른 판단으로 정의. 대상기관 현행 수요·데이터는 미확인 상태.

**현장 검증 필요:** 반복 품목의 사용·재고·납기·결품·과잉·단종 통지, 기존 ERP 규칙의 성능과 구매 승인 책임을 확인.

### TS 검토 시나리오와 전환 과제

연간 사용량은 줄었지만 제조사가 공급 종료를 예고한 부품의 마지막 구매·대체·유지 대안을 비교하는 TS 검토 시나리오.

아래 업무 사례는 설계·검증용 예시이며 TS에서 실제 발생했거나 구현·실증한 사건을 뜻하지 않음. 타기관 사례는 위에서 확인한 공개 범위에만 적용.

| TO-BE 요소 | 수행 내용과 수락 조건 |
|---|---|
| 주체 | 물품·구매 담당, 사용 부서, 기술 적합성 검토자, 예산·발주 승인자 |
| 입력 | 입출고·재고·납기·요청·공급 종료 증거·대체품 조건·예산·기존 계획 |
| 행동·전환 과제 | 수요와 공급 종료 사건을 분리 → 단순 평균·최소재고 기준선 비교 → 납기·재고·예산 제약의 대안 계산 → 담당 판단 → 기존 발주 인계 → 입고·사용 확인. |
| 산출물 | 보충 수량·시점 대안, 단종 근거·대체 검토, 승인·입고·사용 대사 |
| 예외·인계 | 일시 품절·내부 사용중단을 단종으로 해석하지 않음. 대체품 적합성·장기 보관 가능성이 불명확하면 기술 검토에 인계. |
| 완료 판단 | 승인된 계획이 공식 발주 경로에 인계되고 실제 입고·사용과 차이를 설명할 수 있는 상태. |

### 세 영역의 고도화·신규 구축·조건부 차세대사업

‘고도화’는 확인된 기존 경로의 개선, ‘신규 구축’은 현재 부재·추가 필요성을 확인한 기능, ‘차세대사업’은 앞 단계 성과와 추가 권한·자원이 확보된 후속·파생 경로를 뜻함. 동일 기능을 세 유형의 사업비로 반복 합산하지 않음.

| 영역 | 고도화 | 신규 구축 | 조건부 차세대사업 |
|---|---|---|---|
| 인프라·플랫폼 | 기존 ERP 재고·입출고·납기 정합 개선 | 승인된 수요·공급 통지 연결 | 공급망 연계는 계약·최신성·단종 통보 책임 확보 후 |
| 지식 아카이브 | 기존 품목·단위·납기·대체 조건 정비 | 수요·단종·대체·사용 근거 원장 | 추천 대체품은 기술 적합성·권리 검증 후 |
| 업무서비스 | 기존 보충·승인·입고 대사 개선 | 수요예측과 구매대안의 분리 검토 | 자동 계획은 결품·보유비·발주권 통제 시험 후 |

### 업무별 2026~2030 단계와 검증 기준

- **2026**: 반복 품목의 실제 수요·원천·결품/재고 비용과 ERP 규칙 확인.
- **2027**: 과거 자료의 시점 분리 비교로 예측·계획 후보 검증.
- **2028**: 한 품목군에서 담당 승인 하에 보충계획과 실제 결과 비교.
- **2029**: 공급사·대체품 연계는 통보 신뢰·기술 검토·책임 확보 후 확대.
- **2030**: 결품·과잉재고·유지공수와 기존 규칙 대비 편익을 평가해 운영 지속 판단.

각 단계의 수량·허용 오류·소요시간 목표는 기준선 조사 후 업무·검수 책임자가 합의. 기한 도래만으로 다음 단계에 진입하지 않으며, 중요 예외의 미해결·자료권리 미확보·기존 기능 대비 편익 미확인은 보완·축소·중단 판단 사유.

## 세 영역의 신규·고도화·연계

| 영역 | 신규 개발·구축 | 고도화 | 연계 강화 |
|---|---|---|---|
| 인프라·플랫폼 | 선정 업무의 허용 입출력·권한·기록 연결 | 예외·중복 실행·권한 회수·실패 복구의 검증 | 공식 원천·기존 시스템과 승인된 API 또는 제한된 도구 연결 |
| 지식 아카이브 | 품목·수요·재고·납기·공급종료·대체 적합성·예산 조건 | 정본·시점·소관·권리·변경·회수 상태와 오류 사례 보강 | 해당 원천·공식 기준·검토 결과를 출처와 함께 연결 |
| 업무서비스 | 요청·출고 확인 → 수요 기준선 → 보충·단종 대안 → 담당 승인 → 기존 발주 인계 → 입고·사용 확인 | 담당 수락·보완·사람 확정·실패 인계·완료 증거 보강 | 기존 공식 처리·검토·보고 경로로 인계하고 실제 결과 확인 |

공통 기반을 업무마다 새로 구축하지 않으며, 기존 8.3 업무지식의 절차·규칙·예외 자산을 서비스에 연결. 개별 기관의 원문·정답·개인정보와 재사용 가능한 공통 자산의 권리를 구분.

## 2026~2030 진입 조건

- **2026 준비:** 반복 구매 데이터·단종 통지·현행 ERP 규칙, 결품·재고 비용과 발주 책임을 확인. 같은 기간·대상에서 현행 처리·오류·재작업의 기준선을 확보.
- **2027:** 공통 기반·대표실증을 우선하고 이 업무는 수요·권리·정답·기존 중복의 후보검증까지만 수행 가능.
- **2028:** 현업 검증을 통과한 범위만 확산하고 기준·화면·권한 변경 시 재검증.
- **2029:** 고유업무·기관 간 연계는 각각의 소관·협약·입출력 계약과 예외 인계를 확인한 뒤 추가.
- **2030:** 사용 성과·유지 부담·권리·비용을 다시 비교해 운영 정착·재사용·축소를 결정. 전사 전면 자동화를 약속하지 않음.

2027 ON27-BASE의 M1~M9 최대 9개월은 기존 사이트의 상대 일정 제안이며 이 컨셉의 확정 착수일·납기를 뜻하지 않음.

## 책임·검증·예외

수요 감소·일시 품절을 단종으로 판단하지 않음. 자동 구매·계약 체결 제외. 기존 ERP 규칙만으로 충분하면 추가 AI 축소.

업무 소관자가 정답·승인·이의처리·인수를 맡고, 정보화·데이터 담당은 권한·원천·운영을 확인. 공급자는 추가분 설계·연계·시험·복구·운영 인계의 책임과 범위를 명시. 구매·예산·계약 권한은 실제 기관 절차로 확인.

수요·자료권리·검수 책임이 없거나 기존 기능으로 충분하면 보류·축소. 중요 오류·권한 위반·복구 불가가 확인되면 해당 적용을 중단하고 수동 경로로 인계. 비용은 추가 분석·정비·개발·시험·운영의 인정 공수와 직접비로 산정하며 공통비 1회, 기존 의무·R&D·운영비의 중복 계상은 제외.
