# 운수회사 안전점검과 미조치 추적

## 문제와 제공 결과

**문제 가설:** 점검 지적과 실제 조치·재확인·재발 관측이 사건별로 이어지지 않는다는 가설. 위험 신호가 실제 미조치인지 현업 확인 필요.

**제공 결과:** 동일 운수회사·기간·점검건의 위험 근거와 조치 요구를 연결하고, 현장 책임자가 확인한 해소·미해소 상태를 추적.

분류는 조건부 확장 후보. TS의 발주·예산·수요 확정 또는 구현 완료를 뜻하지 않으며, 효과 수치는 현행 기준선과 비교한 뒤 제시.

## 사례 기반 AS-IS → TO-BE 상세

### 현재 확인한 내용과 남은 확인

**확인된 범위:** 공개 13처 기획과 재검토는 위험 신호의 해석, 교통수단 점검 지적사항의 해소 확인·재발 관측을 구분함.

**현장 검증 필요:** 점검 지적이 실제로 미해소되는 빈도, 조치 증빙의 신뢰성, 운행량·기간을 맞춘 위험 비교 가능성은 현장 자료로 확인.

### TS 검토 시나리오와 전환 과제

운수회사에서 같은 지적이 반복되는데 서류는 매번 ‘조치 완료’로 제출되는 경우의 TS 검토 시나리오.

아래 업무 사례는 설계·검증용 예시이며 TS에서 실제 발생했거나 구현·실증한 사건을 뜻하지 않음. 타기관 사례는 위에서 확인한 공개 범위에만 적용.

| TO-BE 요소 | 수행 내용과 수락 조건 |
|---|---|
| 주체 | 점검 담당자, 운수회사 조치 책임자, 현장 재확인자 |
| 입력 | 회사·차량·기간·점검 사건 ID, 지적 기준, 운행자료 조건, 조치 증빙·재확인 기록 |
| 행동·전환 과제 | 같은 대상·기간으로 신호를 대사 → 점검 필요성을 사람이 판단 → 지적과 완료 조건을 명시 → 회사가 조치 → 현장 재확인 → 재발 여부 관측. |
| 산출물 | 근거가 있는 점검 후보, 지적·조치·재확인 묶음과 미해소 목록 |
| 예외·인계 | 자료 기간·대상이 다르면 위험 비교 보류. 조치서만 있고 현장 증거가 없으면 미확인 상태 유지, 긴급위험은 현행 대응 책임자에게 즉시 인계. |
| 완료 판단 | 확인자가 지적별 해소 또는 미해소·추가조치를 기록하고 재발 관측의 대상·기간이 정해진 상태. |

### 세 영역의 고도화·신규 구축·조건부 차세대사업

‘고도화’는 확인된 기존 경로의 개선, ‘신규 구축’은 현재 부재·추가 필요성을 확인한 기능, ‘차세대사업’은 앞 단계 성과와 추가 권한·자원이 확보된 후속·파생 경로를 뜻함. 동일 기능을 세 유형의 사업비로 반복 합산하지 않음.

| 영역 | 고도화 | 신규 구축 | 조건부 차세대사업 |
|---|---|---|---|
| 인프라·플랫폼 | 기존 점검·운행 원천의 사건 ID·기간 연결 | 지적→조치→재확인 상태 연계 | 기관 간 위험 신호 공유는 목적·권리·책임 합의 후 |
| 지식 아카이브 | 기존 지적 기준·증빙·완료 요건 정비 | 점검·조치·재발 근거 관계 | 점검 우선순위 모형은 노출량·오경보 비교시험 후 |
| 업무서비스 | 기존 점검 후보·조치 요청 흐름 개선 | 현장 재확인·미해소 재개 업무 | 예방효과 기반 확산은 비교집단·외부요인 통제 후 |

### 업무별 2026~2030 단계와 검증 기준

- **2026**: 한 점검 유형의 실제 사건과 조치·재점검 경로, 반복 지적 기준선 확보.
- **2027**: 현행 방식의 지적별 해소 여부를 독립 확인하고 공통 기반과 후보 타당성 검토.
- **2028**: 한 점검 유형에서 조치 누락·재확인 부담·종결 정확도를 제한 실증.
- **2029**: 운행·점검·현장조치를 대상·기간·소관이 맞는 범위에서 연결.
- **2030**: 재발·미해소·점검 자원 부담을 평가. 사고 감소는 별도의 비교 설계 없이는 성과로 확정하지 않음.

각 단계의 수량·허용 오류·소요시간 목표는 기준선 조사 후 업무·검수 책임자가 합의. 기한 도래만으로 다음 단계에 진입하지 않으며, 중요 예외의 미해결·자료권리 미확보·기존 기능 대비 편익 미확인은 보완·축소·중단 판단 사유.

## 세 영역의 신규·고도화·연계

| 영역 | 신규 개발·구축 | 고도화 | 연계 강화 |
|---|---|---|---|
| 인프라·플랫폼 | 선정 업무의 허용 입출력·권한·기록 연결 | 예외·중복 실행·권한 회수·실패 복구의 검증 | 공식 원천·기존 시스템과 승인된 API 또는 제한된 도구 연결 |
| 지식 아카이브 | 점검 기준·지적사항·운행자료의 조건·조치 기한·재확인 기준 | 정본·시점·소관·권리·변경·회수 상태와 오류 사례 보강 | 해당 원천·공식 기준·검토 결과를 출처와 함께 연결 |
| 업무서비스 | 위험 근거 검토 → 점검 후보 → 현장 확인 → 조치 요청 → 이행·재점검 → 종결·재발 관측 | 담당 수락·보완·사람 확정·실패 인계·완료 증거 보강 | 기존 공식 처리·검토·보고 경로로 인계하고 실제 결과 확인 |

공통 기반을 업무마다 새로 구축하지 않으며, 기존 8.3 업무지식의 절차·규칙·예외 자산을 서비스에 연결. 개별 기관의 원문·정답·개인정보와 재사용 가능한 공통 자산의 권리를 구분.

## 2026~2030 진입 조건

- **2026 준비:** 점검 관할, 운수회사 자료권리, 노출량·기간 기준, 현장 확인자와 비교 사례를 확보. 같은 기간·대상에서 현행 처리·오류·재작업의 기준선을 확보.
- **2027:** 공통 기반·대표실증을 우선하고 이 업무는 수요·권리·정답·기존 중복의 후보검증까지만 수행 가능.
- **2028:** 현업 검증을 통과한 범위만 확산하고 기준·화면·권한 변경 시 재검증.
- **2029:** 고유업무·기관 간 연계는 각각의 소관·협약·입출력 계약과 예외 인계를 확인한 뒤 추가.
- **2030:** 사용 성과·유지 부담·권리·비용을 다시 비교해 운영 정착·재사용·축소를 결정. 전사 전면 자동화를 약속하지 않음.

2027 ON27-BASE의 M1~M9 최대 9개월은 기존 사이트의 상대 일정 제안이며 이 컨셉의 확정 착수일·납기를 뜻하지 않음.

## 책임·검증·예외

LLM 독자 위험점수·운행 차단·행정처분 제외. 문서 제출만으로 안전 해소 판정 금지. 사고 감소는 별도 비교 평가.

업무 소관자가 정답·승인·이의처리·인수를 맡고, 정보화·데이터 담당은 권한·원천·운영을 확인. 공급자는 추가분 설계·연계·시험·복구·운영 인계의 책임과 범위를 명시. 구매·예산·계약 권한은 실제 기관 절차로 확인.

수요·자료권리·검수 책임이 없거나 기존 기능으로 충분하면 보류·축소. 중요 오류·권한 위반·복구 불가가 확인되면 해당 적용을 중단하고 수동 경로로 인계. 비용은 추가 분석·정비·개발·시험·운영의 인정 공수와 직접비로 산정하며 공통비 1회, 기존 의무·R&D·운영비의 중복 계상은 제외.
