# 자격시험 문제은행 품질과 법령 정합성

## 문제와 제공 결과

**문제 가설:** 문항 유사도·정답·난이도·법령 개정의 관계를 체계적으로 확인하기 어려운지 검증할 필요.

**제공 결과:** 문항별 근거판본·유사 후보·통계적 변별력 점검 결과를 출제·검토위원이 확정하는 지원.

분류는 조건부 확장 후보. TS의 발주·예산·수요 확정 또는 구현 완료를 뜻하지 않으며, 효과 수치는 현행 기준선과 비교한 뒤 제시.

## 사례 기반 AS-IS → TO-BE 상세

### 현재 확인한 내용과 남은 확인

**확인된 범위:** 기존 7신규후보에 자격시험 문제은행 분석이 포함됨. 문항·응시자료의 이용권과 현재 품질 문제는 별도 검증 대상.

**현장 검증 필요:** 실제 문항 개정 과정, 법령판본 오류, 유사 문항의 중복성과 문항 통계의 표본·난이도 차이를 확인.

### TS 검토 시나리오와 전환 과제

법령이 바뀌었지만 문제 해설은 구판을 인용하고, 비슷한 두 문항의 변별력이 다르게 나타나는 TS 검토 시나리오.

아래 업무 사례는 설계·검증용 예시이며 TS에서 실제 발생했거나 구현·실증한 사건을 뜻하지 않음. 타기관 사례는 위에서 확인한 공개 범위에만 적용.

| TO-BE 요소 | 수행 내용과 수락 조건 |
|---|---|
| 주체 | 출제위원, 검토위원, 시험 운영자, 보안 담당 |
| 입력 | 권한 있는 문항·정답·해설·근거판본·수정 이력·비식별 응시 집계 |
| 행동·전환 과제 | 법령 근거·적용일 대사 → 유사 후보 제시 → 독립 통계로 난이도·변별력 확인 → 위원 이견 조정 → 채택·수정·보류 승인. |
| 산출물 | 문항별 근거·유사 후보·통계와 위원 판단·반영 기록 |
| 예외·인계 | 작은 표본·집단 차이로 통계가 불안정하면 결론 보류. 정답이 상충하면 모델 답을 채택하지 않고 위원 재검토. |
| 완료 판단 | 위원이 문항의 근거·정답·사용 여부를 확정하고 승인된 문제은행에 해당 판본이 반영된 상태. |

### 세 영역의 고도화·신규 구축·조건부 차세대사업

‘고도화’는 확인된 기존 경로의 개선, ‘신규 구축’은 현재 부재·추가 필요성을 확인한 기능, ‘차세대사업’은 앞 단계 성과와 추가 권한·자원이 확보된 후속·파생 경로를 뜻함. 동일 기능을 세 유형의 사업비로 반복 합산하지 않음.

| 영역 | 고도화 | 신규 구축 | 조건부 차세대사업 |
|---|---|---|---|
| 인프라·플랫폼 | 기존 문제은행의 보안·판본·집계 연결 개선 | 허용 환경의 유사도·근거 대사 | 적응형 출제는 별도 평가 공정성 검증 후 |
| 지식 아카이브 | 기존 문항·해설·법령판본 정비 | 문항군·변경·위원 이견·통계 원장 | 개정 영향 추천은 중요 누락·보안 검증 후 |
| 업무서비스 | 기존 문항검토·개정 회수 개선 | 위원 검토·보류·채택 이력 업무 | 자동 생성 후보는 독립 출제 검토와 별도 품질 시험 후 |

### 업무별 2026~2030 단계와 검증 기준

- **2026**: 보안·권리·출제 절차와 비식별 통계 사용 가능성 확인.
- **2027**: 제한된 문항군에서 법령·유사도·통계 후보를 위원 정답과 비교.
- **2028**: 검증된 문항군의 개정 지원에 적용하고 오탐·누락·검토시간 측정.
- **2029**: 다른 자격 분야는 별도 근거·문항 특성·위원체계를 확보한 뒤 확장.
- **2030**: 문항 품질과 운영 보안·검토부담을 재평가. 합격·자격 판단은 공식 시험 절차 유지.

각 단계의 수량·허용 오류·소요시간 목표는 기준선 조사 후 업무·검수 책임자가 합의. 기한 도래만으로 다음 단계에 진입하지 않으며, 중요 예외의 미해결·자료권리 미확보·기존 기능 대비 편익 미확인은 보완·축소·중단 판단 사유.

## 세 영역의 신규·고도화·연계

| 영역 | 신규 개발·구축 | 고도화 | 연계 강화 |
|---|---|---|---|
| 인프라·플랫폼 | 선정 업무의 허용 입출력·권한·기록 연결 | 예외·중복 실행·권한 회수·실패 복구의 검증 | 공식 원천·기존 시스템과 승인된 API 또는 제한된 도구 연결 |
| 지식 아카이브 | 문항·정답·해설·법령판본·응시 집계·문항 수정 이력 | 정본·시점·소관·권리·변경·회수 상태와 오류 사례 보강 | 해당 원천·공식 기준·검토 결과를 출처와 함께 연결 |
| 업무서비스 | 승인된 문항 취급 → 근거·유사 후보 분석 → 집계 통계 검토 → 위원 확정 → 안전한 반영 | 담당 수락·보완·사람 확정·실패 인계·완료 증거 보강 | 기존 공식 처리·검토·보고 경로로 인계하고 실제 결과 확인 |

공통 기반을 업무마다 새로 구축하지 않으며, 기존 8.3 업무지식의 절차·규칙·예외 자산을 서비스에 연결. 개별 기관의 원문·정답·개인정보와 재사용 가능한 공통 자산의 권리를 구분.

## 2026~2030 진입 조건

- **2026 준비:** 문제은행 보안·사용권, 비식별 응시 집계, 출제위원 검증과 기존 시험시스템 범위를 확인. 같은 기간·대상에서 현행 처리·오류·재작업의 기준선을 확보.
- **2027:** 공통 기반·대표실증을 우선하고 이 업무는 수요·권리·정답·기존 중복의 후보검증까지만 수행 가능.
- **2028:** 현업 검증을 통과한 범위만 확산하고 기준·화면·권한 변경 시 재검증.
- **2029:** 고유업무·기관 간 연계는 각각의 소관·협약·입출력 계약과 예외 인계를 확인한 뒤 추가.
- **2030:** 사용 성과·유지 부담·권리·비용을 다시 비교해 운영 정착·재사용·축소를 결정. 전사 전면 자동화를 약속하지 않음.

2027 ON27-BASE의 M1~M9 최대 9개월은 기존 사이트의 상대 일정 제안이며 이 컨셉의 확정 착수일·납기를 뜻하지 않음.

## 책임·검증·예외

비공개 문항을 외부 모델에 입력하지 않음. 자동 출제 채택·합격·자격 결정 제외. 교육 추천과 보안·구매 범위를 분리.

업무 소관자가 정답·승인·이의처리·인수를 맡고, 정보화·데이터 담당은 권한·원천·운영을 확인. 공급자는 추가분 설계·연계·시험·복구·운영 인계의 책임과 범위를 명시. 구매·예산·계약 권한은 실제 기관 절차로 확인.

수요·자료권리·검수 책임이 없거나 기존 기능으로 충분하면 보류·축소. 중요 오류·권한 위반·복구 불가가 확인되면 해당 적용을 중단하고 수동 경로로 인계. 비용은 추가 분석·정비·개발·시험·운영의 인정 공수와 직접비로 산정하며 공통비 1회, 기존 의무·R&D·운영비의 중복 계상은 제외.
