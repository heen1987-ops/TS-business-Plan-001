# 공공 AI 독립평가와 운영 인수

## 문제와 제공 결과

**문제 가설:** 구축자가 만든 시연·평가만으로 중요 오류와 실제 업무 인수 가능성을 확인하기 어렵다는 가설.

**제공 결과:** 독립 정답·이견조정·동결 시험셋·권한·예외·복구·실사용 비교·잔여조치·이용권리의 평가와 인수 근거.

분류는 조건부 확장 후보. TS의 발주·예산·수요 확정 또는 구현 완료를 뜻하지 않으며, 효과 수치는 현행 기준선과 비교한 뒤 제시.

## 사례 기반 AS-IS → TO-BE 상세

### 현재 확인한 내용과 남은 확인

**확인된 범위:** 기존 상세 컨셉은 정답 이견조정·사건 단위 자료분리·업무·통제 실행시험·인수를 구분. 일반 운영 평가는 법정 감리와 동일하지 않음.

**현장 검증 필요:** 구축자와 평가자의 역할·계약상 독립성, 정답 소유, 누락·중요 오류 기준, 시험셋 유출과 현재 인수 방식 확인.

### TS 검토 시나리오와 전환 과제

시연은 통과했지만 구판 근거·권한 회수·재시도 중복 사례에서 실패한 서비스를 검수하는 TS 검토 시나리오.

아래 업무 사례는 설계·검증용 예시이며 TS에서 실제 발생했거나 구현·실증한 사건을 뜻하지 않음. 타기관 사례는 위에서 확인한 공개 범위에만 적용.

| TO-BE 요소 | 수행 내용과 수락 조건 |
|---|---|
| 주체 | 기관 지정 독립 평가자, 업무 전문가, 구축자, 운영 인수자 |
| 입력 | 동결 표본·독립 정답·중요도·수락 기준·허용 계정·장애/복구 시나리오·이용권리 |
| 행동·전환 과제 | 평가 기준 합의 → 구축 자료와 시험셋 분리 → 업무 정확도·통제·예외·복구 시험 → 이견·결함 조정 → 재시험 → 잔여 조건과 운영 인수. |
| 산출물 | 재현 가능한 시험결과, 결함·재시험 이력, 조건부 수락·인수·이용권리 대조 |
| 예외·인계 | 중요 실패를 평균점수로 숨기지 않음. 인수자가 실제 운영을 수행하지 못하면 시연 성공과 무관하게 인수 조건 보완. |
| 완료 판단 | 독립 평가자와 공식 인수자가 기준 충족·잔여조치·운영책임을 확인. 공급자 자체점검을 독립 통과로 기록하지 않음. |

### 세 영역의 고도화·신규 구축·조건부 차세대사업

‘고도화’는 확인된 기존 경로의 개선, ‘신규 구축’은 현재 부재·추가 필요성을 확인한 기능, ‘차세대사업’은 앞 단계 성과와 추가 권한·자원이 확보된 후속·파생 경로를 뜻함. 동일 기능을 세 유형의 사업비로 반복 합산하지 않음.

| 영역 | 고도화 | 신규 구축 | 조건부 차세대사업 |
|---|---|---|---|
| 인프라·플랫폼 | 기존 시험·로그·복구 환경의 재현성 개선 | 권한·예외·부하 분리 시험 환경 | 다기관 인수시험은 환경·책임·자료권리 합의 후 |
| 지식 아카이브 | 기존 정답·중요도·시험판본 정비 | 이견·결함·재시험·권리 원장 | 변경별 선택평가는 중요 결함 미탐 검증 후 |
| 업무서비스 | 기존 검수·인수 실습 보강 | 독립 판정·결함 보완·조건부 수락 업무 | 공공 AI 평가서비스 확장은 전문성·독립성·자격 확인 후 |

### 업무별 2026~2030 단계와 검증 기준

- **2026**: 평가·인수 권한과 독립성, 중요 오류·수락 기준·표본 분리 합의.
- **2027**: 대표업무와 ON-W06의 실제 업무·권한·복구·운영 실습 검수.
- **2028**: 변경·확산 시 동결셋 회귀와 실사용 비교를 연결하고 잔여 결함 추적.
- **2029**: 기관 간 인수는 각 원천·운영환경·책임의 경계시험을 추가.
- **2030**: 실제 장애·오류와 검수 누락을 대조해 평가기준·인수방식을 재검증.

각 단계의 수량·허용 오류·소요시간 목표는 기준선 조사 후 업무·검수 책임자가 합의. 기한 도래만으로 다음 단계에 진입하지 않으며, 중요 예외의 미해결·자료권리 미확보·기존 기능 대비 편익 미확인은 보완·축소·중단 판단 사유.

## 세 영역의 신규·고도화·연계

| 영역 | 신규 개발·구축 | 고도화 | 연계 강화 |
|---|---|---|---|
| 인프라·플랫폼 | 선정 업무의 허용 입출력·권한·기록 연결 | 예외·중복 실행·권한 회수·실패 복구의 검증 | 공식 원천·기존 시스템과 승인된 API 또는 제한된 도구 연결 |
| 지식 아카이브 | 평가 단위·정답·중요도·표본 분리·결함·재시험·수락 기준 | 정본·시점·소관·권리·변경·회수 상태와 오류 사례 보강 | 해당 원천·공식 기준·검토 결과를 출처와 함께 연결 |
| 업무서비스 | 독립 기준 합의 → 시험 고정 → 업무·통제 시험 → 결함·재시험 → 운영 인수 → 조건부 확산 판단 | 담당 수락·보완·사람 확정·실패 인계·완료 증거 보강 | 기존 공식 처리·검토·보고 경로로 인계하고 실제 결과 확인 |

공통 기반을 업무마다 새로 구축하지 않으며, 기존 8.3 업무지식의 절차·규칙·예외 자산을 서비스에 연결. 개별 기관의 원문·정답·개인정보와 재사용 가능한 공통 자산의 권리를 구분.

## 2026~2030 진입 조건

- **2026 준비:** 평가자 독립성·자료권한·업무 전문성·판정 책임과 계약상 검수 역할을 확인. 같은 기간·대상에서 현행 처리·오류·재작업의 기준선을 확보.
- **2027:** 공통 기반·대표실증을 우선하고 이 업무는 수요·권리·정답·기존 중복의 후보검증까지만 수행 가능.
- **2028:** 현업 검증을 통과한 범위만 확산하고 기준·화면·권한 변경 시 재검증.
- **2029:** 고유업무·기관 간 연계는 각각의 소관·협약·입출력 계약과 예외 인계를 확인한 뒤 추가.
- **2030:** 사용 성과·유지 부담·권리·비용을 다시 비교해 운영 정착·재사용·축소를 결정. 전사 전면 자동화를 약속하지 않음.

2027 ON27-BASE의 M1~M9 최대 9개월은 기존 사이트의 상대 일정 제안이며 이 컨셉의 확정 착수일·납기를 뜻하지 않음.

## 책임·검증·예외

운영팀 야간 품질점검을 법정 감리 또는 독립 검수로 동일시하지 않음. 자기점검을 독립평가로 표기하지 않음.

업무 소관자가 정답·승인·이의처리·인수를 맡고, 정보화·데이터 담당은 권한·원천·운영을 확인. 공급자는 추가분 설계·연계·시험·복구·운영 인계의 책임과 범위를 명시. 구매·예산·계약 권한은 실제 기관 절차로 확인.

수요·자료권리·검수 책임이 없거나 기존 기능으로 충분하면 보류·축소. 중요 오류·권한 위반·복구 불가가 확인되면 해당 적용을 중단하고 수동 경로로 인계. 비용은 추가 분석·정비·개발·시험·운영의 인정 공수와 직접비로 산정하며 공통비 1회, 기존 의무·R&D·운영비의 중복 계상은 제외.
