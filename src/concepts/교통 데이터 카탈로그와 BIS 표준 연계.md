# 교통 데이터 카탈로그와 BIS 표준 연계

## 문제와 제공 결과

**문제 가설:** 소재·필드·품질·권리·지역별 식별자가 달라 필요한 교통 데이터를 찾거나 결합하기 어렵다는 가설.

**제공 결과:** 자료의 소관·제공 조건을 설명하는 카탈로그와 BIS 노선·정류장·시점 등 지역 간 의미 대조를 제공.

분류는 조건부 확장 후보. TS의 발주·예산·수요 확정 또는 구현 완료를 뜻하지 않으며, 효과 수치는 현행 기준선과 비교한 뒤 제시.

## 사례 기반 AS-IS → TO-BE 상세

### 현재 확인한 내용과 남은 확인

**확인된 범위:** ST-07과 기존 BIS 후보는 자료 소재·제공 조건과 다지자체 표준화 문제를 구분해 다룸. 공공 마이데이터 제공목록은 별도의 본인정보 제도이며 일반 공개데이터 제공권과 같지 않음.

**현장 검증 필요:** 같은 정류장·노선의 지역별 식별자·시간 기준, 실제 데이터 품질, 카탈로그 사용과 승인 지연을 조사.

### TS 검토 시나리오와 전환 과제

서로 다른 지자체의 노선·정류장 코드가 같은 이름을 쓰지만 위치와 유효기간이 다른 경우의 TS 검토 시나리오.

아래 업무 사례는 설계·검증용 예시이며 TS에서 실제 발생했거나 구현·실증한 사건을 뜻하지 않음. 타기관 사례는 위에서 확인한 공개 범위에만 적용.

| TO-BE 요소 | 수행 내용과 수락 조건 |
|---|---|
| 주체 | 데이터 소관자, 지자체·BIS 운영자, 활용 담당자, 제공 승인자 |
| 입력 | 원천 사전·정류장/노선 ID·위치·유효기간·품질·목적·제공조건 |
| 행동·전환 과제 | 이용 목적 확인 → 원천·권리 탐색 → 식별자·시간 의미 대조 → 불명확 매핑을 소관자 확인 → 품질 시험 → 승인된 제공과 정정. |
| 산출물 | 제공조건이 붙은 카탈로그, 검증된 코드 매핑, 품질·누락·갱신 이력 |
| 예외·인계 | 동명 시설·노선 변경·권리 미확인은 임의 통합 금지. 개인 이동자료는 일반 공개데이터처럼 제공하지 않음. |
| 완료 판단 | 사용자가 승인된 범위에서 동일 의미·기간의 데이터를 재현하고 매핑 오류·원천 변경의 정정 책임이 확인된 상태. |

### 세 영역의 고도화·신규 구축·조건부 차세대사업

‘고도화’는 확인된 기존 경로의 개선, ‘신규 구축’은 현재 부재·추가 필요성을 확인한 기능, ‘차세대사업’은 앞 단계 성과와 추가 권한·자원이 확보된 후속·파생 경로를 뜻함. 동일 기능을 세 유형의 사업비로 반복 합산하지 않음.

| 영역 | 고도화 | 신규 구축 | 조건부 차세대사업 |
|---|---|---|---|
| 인프라·플랫폼 | 기존 수집·제공의 오류·시점·철회 처리 보강 | 빠진 원천의 승인된 표준 연계 | 다기관 연속 제공은 목적·변경통지·품질 책임 확보 후 |
| 지식 아카이브 | 기존 데이터 사전·식별자·품질 정비 | 지역 간 의미·시점·권리 매핑 원장 | 의미 자동매핑은 오결합·누락 검증 후 |
| 업무서비스 | 기존 데이터 탐색·제공 승인 절차 개선 | 불명확 매핑 검토·정정·활용 인수 | 공통 데이터 서비스는 실제 수요·운영비 비교 후 |

### 업무별 2026~2030 단계와 검증 기준

- **2026**: 두 원천의 사전·권리·코드·시점·활용 수요를 선별 확인.
- **2027**: 공개·승인 읽기 자료의 카탈로그와 제공조건 정확도를 비교 검증.
- **2028**: 한 BIS 연계에서 코드 변경·동명·결측·정정의 실제 운영 시험.
- **2029**: 지자체 추가는 표준 적합·협약·품질/갱신 책임이 확인된 경우만 확대.
- **2030**: 재사용·정정률·제공 소요와 표준 유지비를 평가해 유지할 원천과 종료할 연결 결정.

각 단계의 수량·허용 오류·소요시간 목표는 기준선 조사 후 업무·검수 책임자가 합의. 기한 도래만으로 다음 단계에 진입하지 않으며, 중요 예외의 미해결·자료권리 미확보·기존 기능 대비 편익 미확인은 보완·축소·중단 판단 사유.

## 세 영역의 신규·고도화·연계

| 영역 | 신규 개발·구축 | 고도화 | 연계 강화 |
|---|---|---|---|
| 인프라·플랫폼 | 선정 업무의 허용 입출력·권한·기록 연결 | 예외·중복 실행·권한 회수·실패 복구의 검증 | 공식 원천·기존 시스템과 승인된 API 또는 제한된 도구 연결 |
| 지식 아카이브 | 데이터 사전·식별자·시간·공간 기준·품질·제공 목적·승인 조건 | 정본·시점·소관·권리·변경·회수 상태와 오류 사례 보강 | 해당 원천·공식 기준·검토 결과를 출처와 함께 연결 |
| 업무서비스 | 수요 정의 → 카탈로그 탐색 → 권리 확인 → 표준 매핑 → 품질 검증 → 승인된 제공·철회 | 담당 수락·보완·사람 확정·실패 인계·완료 증거 보강 | 기존 공식 처리·검토·보고 경로로 인계하고 실제 결과 확인 |

공통 기반을 업무마다 새로 구축하지 않으며, 기존 8.3 업무지식의 절차·규칙·예외 자산을 서비스에 연결. 개별 기관의 원문·정답·개인정보와 재사용 가능한 공통 자산의 권리를 구분.

## 2026~2030 진입 조건

- **2026 준비:** 원천 운영자·지자체 협력, 허용 필드·이용 목적과 서로 다른 지역의 실제 데이터 표본을 확보. 같은 기간·대상에서 현행 처리·오류·재작업의 기준선을 확보.
- **2027:** 공통 기반·대표실증을 우선하고 이 업무는 수요·권리·정답·기존 중복의 후보검증까지만 수행 가능.
- **2028:** 현업 검증을 통과한 범위만 확산하고 기준·화면·권한 변경 시 재검증.
- **2029:** 고유업무·기관 간 연계는 각각의 소관·협약·입출력 계약과 예외 인계를 확인한 뒤 추가.
- **2030:** 사용 성과·유지 부담·권리·비용을 다시 비교해 운영 정착·재사용·축소를 결정. 전사 전면 자동화를 약속하지 않음.

2027 ON27-BASE의 M1~M9 최대 9개월은 기존 사이트의 상대 일정 제안이며 이 컨셉의 확정 착수일·납기를 뜻하지 않음.

## 책임·검증·예외

카탈로그 등재는 제공 허가가 아님. 개인 교통자료 공개, 근거 없는 원천 결합과 중앙관리 권한 확대 금지.

업무 소관자가 정답·승인·이의처리·인수를 맡고, 정보화·데이터 담당은 권한·원천·운영을 확인. 공급자는 추가분 설계·연계·시험·복구·운영 인계의 책임과 범위를 명시. 구매·예산·계약 권한은 실제 기관 절차로 확인.

수요·자료권리·검수 책임이 없거나 기존 기능으로 충분하면 보류·축소. 중요 오류·권한 위반·복구 불가가 확인되면 해당 적용을 중단하고 수동 경로로 인계. 비용은 추가 분석·정비·개발·시험·운영의 인정 공수와 직접비로 산정하며 공통비 1회, 기존 의무·R&D·운영비의 중복 계상은 제외.
