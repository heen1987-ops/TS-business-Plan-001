# 문서 근거 검증과 변경 재검증 연구

## 문제와 제공 결과

**문제 가설:** 출처가 붙은 답변도 대상·시점·조건이 틀릴 수 있고, 일부 변경 뒤 전체를 다시 검사하면 비용이 커진다는 연구 가설.

**제공 결과:** RD-01 중요 근거 오류 검출, RD-02 변경 영향 선택적 재검증, RD-04 검색·근거 연결의 추가 가설을 분리 시험.

분류는 순증 연구 후보. TS의 발주·예산·수요 확정 또는 구현 완료를 뜻하지 않으며, 효과 수치는 현행 기준선과 비교한 뒤 제시.

## 사례 기반 AS-IS → TO-BE 상세

### 현재 확인한 내용과 남은 확인

**확인된 범위:** v1.1은 RD-01 근거 오류 검출, RD-02 선택적 재검증을 순증 연구로 분리. RD-04 검색 가설은 후속 검토이며 납품 성능이 입증된 상태가 아님.

**현장 검증 필요:** 기존 제품·지원과제·계약의 연구 범위, 중요 오류 유형, 정답과 변경 이력의 사용권·독립성을 먼저 확인.

### TS 검토 시나리오와 전환 과제

규정 한 조항이 바뀌었을 때 관련 없는 답변까지 모두 검사하는 방식과 영향 사례만 검사하는 방식을 비교하는 TS 검토 시나리오.

아래 업무 사례는 설계·검증용 예시이며 TS에서 실제 발생했거나 구현·실증한 사건을 뜻하지 않음. 타기관 사례는 위에서 확인한 공개 범위에만 적용.

| TO-BE 요소 | 수행 내용과 수락 조건 |
|---|---|
| 주체 | 연구책임자, 업무 전문가·정답 평가자, 제품 인수 담당 |
| 입력 | 동일 사건의 원문·정답·근거관계·중요도, 변경 전후 판본, 기존 전체검사 결과·비용 |
| 행동·전환 과제 | RD-01 대상·시점·조건 오류 검출 시험 → RD-02 영향 선택과 전체검사 비교 → RD-04 검색변경의 추가 기여 분리 → 독립 재현 → 편입 여부 심사. |
| 산출물 | 가설별 기준선·중요 미탐·오탐·처리비용·한계, 재현 코드/시험설계와 납품 편입 조건 |
| 예외·인계 | 중요 누락이 허용기준을 넘으면 비용이 낮아도 채택하지 않음. 데이터 정비·일반 RAG 구현을 새 연구 성과로 산정하지 않음. |
| 완료 판단 | 가설별 비교가 재현되고 독립 평가자가 한계와 채택/보류를 판정. 제품 편입은 별도 운영·검수 통과 후. |

### 세 영역의 고도화·신규 구축·조건부 차세대사업

‘고도화’는 확인된 기존 경로의 개선, ‘신규 구축’은 현재 부재·추가 필요성을 확인한 기능, ‘차세대사업’은 앞 단계 성과와 추가 권한·자원이 확보된 후속·파생 경로를 뜻함. 동일 기능을 세 유형의 사업비로 반복 합산하지 않음.

| 영역 | 고도화 | 신규 구축 | 조건부 차세대사업 |
|---|---|---|---|
| 인프라·플랫폼 | 기존 평가 환경·계측·버전 고정 개선 | 가설별 실험·변경 재현 환경 | 운영 선택재검증은 중요 오류 통제 실증 후 |
| 지식 아카이브 | 기존 근거·변경·정답의 권리·품질 정비 | 근거 관계·영향범위·반례 연구셋 | 자동 영향추론은 독립 표본 일반화 시험 후 |
| 업무서비스 | 기존 수동 근거검토의 비교 기준선 보강 | 연구 결과 심사·실증·편입 결정 업무 | 자동 재검토 운영은 실패 인계·인수 책임 확보 후 |

### 업무별 2026~2030 단계와 검증 기준

- **2026**: 기존 연구·제품·계약과 순증 가설의 차이, 시험권·정답 확보.
- **2027**: 가설별 오프라인 기준선 비교; 실제 일정·지원사업은 별도 확인.
- **2028**: 독립 표본에서 중요 미탐·오탐·비용 재현, 실패 가설은 보완 또는 중단.
- **2029**: 통과한 가설만 대표업무의 제한 실증으로 편입하고 운영 실패 경로 검증.
- **2030**: 실서비스의 오류·운영비·일반화 한계를 재평가해 연구 후속과 제품 기능을 분리 관리.

각 단계의 수량·허용 오류·소요시간 목표는 기준선 조사 후 업무·검수 책임자가 합의. 기한 도래만으로 다음 단계에 진입하지 않으며, 중요 예외의 미해결·자료권리 미확보·기존 기능 대비 편익 미확인은 보완·축소·중단 판단 사유.

## 세 영역의 신규·고도화·연계

| 영역 | 신규 개발·구축 | 고도화 | 연계 강화 |
|---|---|---|---|
| 인프라·플랫폼 | 선정 업무의 허용 입출력·권한·기록 연결 | 예외·중복 실행·권한 회수·실패 복구의 검증 | 공식 원천·기존 시스템과 승인된 API 또는 제한된 도구 연결 |
| 지식 아카이브 | 사건별 정답·오류 유형·변경 전후 원문·근거 관계·판정 불확실성 | 정본·시점·소관·권리·변경·회수 상태와 오류 사례 보강 | 해당 원천·공식 기준·검토 결과를 출처와 함께 연결 |
| 업무서비스 | 권리 확보 → 기존 방식 기준선 → 가설별 비교실험 → 중요 미탐·비용 평가 → 재현 검토 → 납품 편입 심사 | 담당 수락·보완·사람 확정·실패 인계·완료 증거 보강 | 기존 공식 처리·검토·보고 경로로 인계하고 실제 결과 확인 |

공통 기반을 업무마다 새로 구축하지 않으며, 기존 8.3 업무지식의 절차·규칙·예외 자산을 서비스에 연결. 개별 기관의 원문·정답·개인정보와 재사용 가능한 공통 자산의 권리를 구분.

## 2026~2030 진입 조건

- **2026 준비:** 기존 지원과제·제품·납품 범위와 순증 연구 차이, 독립 시험셋·평가자·중단 기준을 확인. 같은 기간·대상에서 현행 처리·오류·재작업의 기준선을 확보.
- **2027:** 순증 연구 가설·기존 과제 차이·시험권을 확인한 경우에만 기준선 비교연구. 납품과 별도 관리.
- **2028:** 타당성·비교시험을 통과한 하위 범위만 제한 검증. 미충족이면 이월 또는 중단.
- **2029:** 고유업무·기관 간 연계는 각각의 소관·협약·입출력 계약과 예외 인계를 확인한 뒤 추가.
- **2030:** 사용 성과·유지 부담·권리·비용을 다시 비교해 운영 정착·재사용·축소를 결정. 전사 전면 자동화를 약속하지 않음.

2027 ON27-BASE의 M1~M9 최대 9개월은 기존 사이트의 상대 일정 제안이며 이 컨셉의 확정 착수일·납기를 뜻하지 않음.

## 책임·검증·예외

일반 RAG 구축·데이터 정비·오류 수정을 새 R&D 성과로 재명명하지 않음. 성공 가정 없이 연구와 납품 비용 분리.

업무 소관자가 정답·승인·이의처리·인수를 맡고, 정보화·데이터 담당은 권한·원천·운영을 확인. 공급자는 추가분 설계·연계·시험·복구·운영 인계의 책임과 범위를 명시. 구매·예산·계약 권한은 실제 기관 절차로 확인.

수요·자료권리·검수 책임이 없거나 기존 기능으로 충분하면 보류·축소. 중요 오류·권한 위반·복구 불가가 확인되면 해당 적용을 중단하고 수동 경로로 인계. 비용은 추가 분석·정비·개발·시험·운영의 인정 공수와 직접비로 산정하며 공통비 1회, 기존 의무·R&D·운영비의 중복 계상은 제외.
