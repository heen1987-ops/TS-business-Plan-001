# 규정·근거 지식의 정본과 변경 관리

## 문제와 제공 결과

**문제 가설:** 같은 문서의 구판·개정판과 적용 시점이 섞이면 답변 근거와 후속 조치를 잘못 연결할 수 있다는 가설.

**제공 결과:** 원문·권리·판본·적용일·소관·폐기 상태를 연결한 지식 아카이브와 변경 알림·재검토 목록.

분류는 공통 기반·진단. TS의 발주·예산·수요 확정 또는 구현 완료를 뜻하지 않으며, 효과 수치는 현행 기준선과 비교한 뒤 제시.

## 사례 기반 AS-IS → TO-BE 상세

### 현재 확인한 내용과 남은 확인

**확인된 범위:** 공개 기획은 적용기준 판본, 자료권리, 사건시점 기준과 변경 영향 검토를 별도 활동으로 구분함.

**현장 검증 필요:** 원문 저장소별 정본 소관, 개정 반영 지연, 동일 문서 중복률, 폐기된 자료가 답변에 남는지를 실제 검색 결과로 확인.

### TS 검토 시나리오와 전환 과제

고시가 개정된 뒤 담당자가 이전 시행일의 사건을 검토하면서 최신판만 인용하는 상황을 시험하는 TS 검토 시나리오.

아래 업무 사례는 설계·검증용 예시이며 TS에서 실제 발생했거나 구현·실증한 사건을 뜻하지 않음. 타기관 사례는 위에서 확인한 공개 범위에만 적용.

| TO-BE 요소 | 수행 내용과 수락 조건 |
|---|---|
| 주체 | 규정 소관자, 지식 운영자, 사건 담당자, 검토자 |
| 입력 | 신·구 원문, 시행일·경과조치, 사건일, 출처 위치, 제공권·접근등급 |
| 행동·전환 과제 | 두 판본을 동일 문서로 연결 → 적용일·경과조치를 소관자가 확정 → 사건일 기준으로 검색 → 변경 영향 후보만 검토자에게 전달 → 정정·회수 결과를 보존. |
| 산출물 | 판본별 정본 목록, 사건별 인용 묶음, 개정 영향·재검토 목록 |
| 예외·인계 | 시행일 불명·경과조치 상충이면 임의 최신판 적용을 중지하고 소관자 판단 대기. 권리 만료 시 원문과 허용된 파생물 처리를 구분. |
| 완료 판단 | 사건시점에 맞는 근거를 재현하고 사용 불가 판본이 차단되며 영향 사건의 검토·보류 책임이 정해진 상태. |

### 세 영역의 고도화·신규 구축·조건부 차세대사업

‘고도화’는 확인된 기존 경로의 개선, ‘신규 구축’은 현재 부재·추가 필요성을 확인한 기능, ‘차세대사업’은 앞 단계 성과와 추가 권한·자원이 확보된 후속·파생 경로를 뜻함. 동일 기능을 세 유형의 사업비로 반복 합산하지 않음.

| 영역 | 고도화 | 신규 구축 | 조건부 차세대사업 |
|---|---|---|---|
| 인프라·플랫폼 | 검색·OCR의 판본 오인과 회수 동작 개선 | 미등록 원천의 권리·버전 수집 경로 | 분산 원천의 변경 알림은 동기화·회수 증거 확보 후 |
| 지식 아카이브 | 기존 문서에 시행일·경과조치·정본 소관 부여 | 문단·표·규칙의 출처와 적용범위 연결 | 조항 변화의 의미 추론은 중요 누락 검증 후 |
| 업무서비스 | 기존 답변의 인용·적용일 확인 보강 | 개정 영향 검토·확정·이의처리 업무 | 선택적 재검토는 전체검사 대비 중요 미탐 검증 후 |

### 업무별 2026~2030 단계와 검증 기준

- **2026**: 자주 바뀌는 한 규정군의 판본·사건일·오인 사례 수집.
- **2027**: 현업 정답으로 구판/신판/경과조치 검색·인용을 시험하고 삭제·접근 회수까지 인수.
- **2028**: 개정 통지와 영향 사건 재검토의 소요시간·미처리율을 측정하며 규정군 확대.
- **2029**: 외부기관 원천은 제공조건·정본 책임·변경 통보 계약을 확보한 범위만 연결.
- **2030**: 정본 유지비와 오류 정정 결과를 평가하고 소관 이관·보존·폐기 절차를 운영 규칙으로 확정.

각 단계의 수량·허용 오류·소요시간 목표는 기준선 조사 후 업무·검수 책임자가 합의. 기한 도래만으로 다음 단계에 진입하지 않으며, 중요 예외의 미해결·자료권리 미확보·기존 기능 대비 편익 미확인은 보완·축소·중단 판단 사유.

## 세 영역의 신규·고도화·연계

| 영역 | 신규 개발·구축 | 고도화 | 연계 강화 |
|---|---|---|---|
| 인프라·플랫폼 | 선정 업무의 허용 입출력·권한·기록 연결 | 예외·중복 실행·권한 회수·실패 복구의 검증 | 공식 원천·기존 시스템과 승인된 API 또는 제한된 도구 연결 |
| 지식 아카이브 | 법령·고시·서식·내부 규정의 적용 범위와 문단별 출처 | 정본·시점·소관·권리·변경·회수 상태와 오류 사례 보강 | 해당 원천·공식 기준·검토 결과를 출처와 함께 연결 |
| 업무서비스 | 원천 등록 → 품질·권리 검토 → 공개 범위 승인 → 검색 → 변경·회수 → 영향 확인 | 담당 수락·보완·사람 확정·실패 인계·완료 증거 보강 | 기존 공식 처리·검토·보고 경로로 인계하고 실제 결과 확인 |

공통 기반을 업무마다 새로 구축하지 않으며, 기존 8.3 업무지식의 절차·규칙·예외 자산을 서비스에 연결. 개별 기관의 원문·정답·개인정보와 재사용 가능한 공통 자산의 권리를 구분.

## 2026~2030 진입 조건

- **2026 준비:** 원천 제공권과 지식 소관자, 정본 판정 규칙, 개정·삭제 시 회수 의무를 확인. 같은 기간·대상에서 현행 처리·오류·재작업의 기준선을 확보.
- **2027:** 기존 이행·권리·현업 정답을 확인한 공통 추가분과 대표업무 1~2개만 검증.
- **2028:** 현업 검증을 통과한 범위만 확산하고 기준·화면·권한 변경 시 재검증.
- **2029:** 고유업무·기관 간 연계는 각각의 소관·협약·입출력 계약과 예외 인계를 확인한 뒤 추가.
- **2030:** 사용 성과·유지 부담·권리·비용을 다시 비교해 운영 정착·재사용·축소를 결정. 전사 전면 자동화를 약속하지 않음.

2027 ON27-BASE의 M1~M9 최대 9개월은 기존 사이트의 상대 일정 제안이며 이 컨셉의 확정 착수일·납기를 뜻하지 않음.

## 책임·검증·예외

검색 성능 개선을 법적 적정성 보증으로 표현하지 않음. 고객 고유 자료와 공통 재사용 자산을 구분.

업무 소관자가 정답·승인·이의처리·인수를 맡고, 정보화·데이터 담당은 권한·원천·운영을 확인. 공급자는 추가분 설계·연계·시험·복구·운영 인계의 책임과 범위를 명시. 구매·예산·계약 권한은 실제 기관 절차로 확인.

수요·자료권리·검수 책임이 없거나 기존 기능으로 충분하면 보류·축소. 중요 오류·권한 위반·복구 불가가 확인되면 해당 적용을 중단하고 수동 경로로 인계. 비용은 추가 분석·정비·개발·시험·운영의 인정 공수와 직접비로 산정하며 공통비 1회, 기존 의무·R&D·운영비의 중복 계상은 제외.
