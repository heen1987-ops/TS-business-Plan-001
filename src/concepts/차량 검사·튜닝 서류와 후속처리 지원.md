# 차량 검사·튜닝 서류와 후속처리 지원

## 문제와 제공 결과

**문제 가설:** 차량·사건·적용기준·검사 회차가 어긋나거나 보완·재검사 경로가 분리되어 반복 확인이 생긴다는 가설.

**제공 결과:** 서류 필드·기준판본·공식 결과를 대사하고 보완, 실제 정비·재검사, 진단불능 지원의 담당 경로를 구분.

분류는 조건부 확장 후보. TS의 발주·예산·수요 확정 또는 구현 완료를 뜻하지 않으며, 효과 수치는 현행 기준선과 비교한 뒤 제시.

## 사례 기반 AS-IS → TO-BE 상세

### 현재 확인한 내용과 남은 확인

**확인된 범위:** 공개 IP·SI·AD 기획은 각각 재검사 후속처리, 측정기기 이상 검증, 진단 커버리지·실패사유 관리로 구분됨.

**현장 검증 필요:** 현재 검사·튜닝 서류검토와 공동이용, 민간검사소 점검, 장비 지원의 기능·계약·판정 책임을 각각 확인.

### TS 검토 시나리오와 전환 과제

튜닝 보완서류의 차량·기준일이 다르고 검사 결과에는 재확인이 필요한 항목이 남은 경우의 TS 검토 시나리오.

아래 업무 사례는 설계·검증용 예시이며 TS에서 실제 발생했거나 구현·실증한 사건을 뜻하지 않음. 타기관 사례는 위에서 확인한 공개 범위에만 적용.

| TO-BE 요소 | 수행 내용과 수락 조건 |
|---|---|
| 주체 | 신청인, 서류 검토자, 검사·튜닝 판정권자, 현장/장비 지원 담당 |
| 입력 | 차량·신청 사건·검사 회차·기준판본·보완서류·공식 검사결과·장비 실패사유 |
| 행동·전환 과제 | 대상·판본 대사 → 누락과 공식 부적합을 구분 → 서류 보완/정비/재검사/장비 지원 경로를 분리 → 담당자 인계 → 새 공식 결과를 원 사건과 대사. |
| 산출물 | 보완 항목·근거, 재검사 또는 기술지원 인계, 공식 결과의 연결 이력 |
| 예외·인계 | 장비 오류·진단불능을 차량 불합격으로 바꾸지 않음. 검사 종류·제공 시설을 확인하지 못하면 예약·방문 가능을 확답하지 않음. |
| 완료 판단 | 필요한 보완 또는 공식 재검사·지원 결과가 정확한 차량·회차에 연결되고 잔여 미해결이 책임자에게 인계. |

### 세 영역의 고도화·신규 구축·조건부 차세대사업

‘고도화’는 확인된 기존 경로의 개선, ‘신규 구축’은 현재 부재·추가 필요성을 확인한 기능, ‘차세대사업’은 앞 단계 성과와 추가 권한·자원이 확보된 후속·파생 경로를 뜻함. 동일 기능을 세 유형의 사업비로 반복 합산하지 않음.

| 영역 | 고도화 | 신규 구축 | 조건부 차세대사업 |
|---|---|---|---|
| 인프라·플랫폼 | 기존 검사·튜닝·장비 로그의 사건·회차 대사 | 미지원 보완·재검사 인계 연결 | 원격 다기관 지원은 시스템별 책임과 실패 복구 검증 후 |
| 지식 아카이브 | 기존 서식·기준·실패코드 정비 | 차량·회차·판본·증빙 원장 | 기준 변경 영향은 실제 사례의 재판정 대체 없이 검증 |
| 업무서비스 | 기존 누락 검토·보완 안내 개선 | 서류·정비·재검사·장비지원 분기 업무 | 통합 상태 안내는 기관별 공식 결과와 시차 확인 후 |

### 업무별 2026~2030 단계와 검증 기준

- **2026**: 검사·튜닝 한 유형에서 기존 과업·원천·판정·공동이용 범위 대조.
- **2027**: 합성·허용 표본으로 차량/회차/판본 오인과 보완 경로를 후보검증.
- **2028**: 검증된 유형에만 현업 제한 적용, 필드 오류·보완 왕복·오인계 측정.
- **2029**: IP/SI/AD의 서로 다른 결과를 의미를 보존한 상태 조회로 연결.
- **2030**: 후속처리 재문의·재검사 인계 누락과 유지비를 비교해 운영 확대·축소 판단.

각 단계의 수량·허용 오류·소요시간 목표는 기준선 조사 후 업무·검수 책임자가 합의. 기한 도래만으로 다음 단계에 진입하지 않으며, 중요 예외의 미해결·자료권리 미확보·기존 기능 대비 편익 미확인은 보완·축소·중단 판단 사유.

## 세 영역의 신규·고도화·연계

| 영역 | 신규 개발·구축 | 고도화 | 연계 강화 |
|---|---|---|---|
| 인프라·플랫폼 | 선정 업무의 허용 입출력·권한·기록 연결 | 예외·중복 실행·권한 회수·실패 복구의 검증 | 공식 원천·기존 시스템과 승인된 API 또는 제한된 도구 연결 |
| 지식 아카이브 | 차량 사건 ID·서식·적용일·검사 유형·장비 측정조건·실패 사유 | 정본·시점·소관·권리·변경·회수 상태와 오류 사례 보강 | 해당 원천·공식 기준·검토 결과를 출처와 함께 연결 |
| 업무서비스 | 신청·공식 결과 확인 → 누락·차이 검토 → 보완 또는 정비·재검사 경로 인계 → 공식 결과 대사 | 담당 수락·보완·사람 확정·실패 인계·완료 증거 보강 | 기존 공식 처리·검토·보고 경로로 인계하고 실제 결과 확인 |

공통 기반을 업무마다 새로 구축하지 않으며, 기존 8.3 업무지식의 절차·규칙·예외 자산을 서비스에 연결. 개별 기관의 원문·정답·개인정보와 재사용 가능한 공통 자산의 권리를 구분.

## 2026~2030 진입 조건

- **2026 준비:** 기존 검사 과업·공동이용과 신규 추가분, 검사소·기기·시스템별 책임과 정답 사례를 확보. 같은 기간·대상에서 현행 처리·오류·재작업의 기준선을 확보.
- **2027:** 공통 기반·대표실증을 우선하고 이 업무는 수요·권리·정답·기존 중복의 후보검증까지만 수행 가능.
- **2028:** 현업 검증을 통과한 범위만 확산하고 기준·화면·권한 변경 시 재검증.
- **2029:** 고유업무·기관 간 연계는 각각의 소관·협약·입출력 계약과 예외 인계를 확인한 뒤 추가.
- **2030:** 사용 성과·유지 부담·권리·비용을 다시 비교해 운영 정착·재사용·축소를 결정. 전사 전면 자동화를 약속하지 않음.

2027 ON27-BASE의 M1~M9 최대 9개월은 기존 사이트의 상대 일정 제안이며 이 컨셉의 확정 착수일·납기를 뜻하지 않음.

## 책임·검증·예외

합부·튜닝 승인·면제·기한 연장·장비 조작을 AI가 결정하지 않음. IP/SI/AD는 각각 다른 사건·판정 책임을 유지.

업무 소관자가 정답·승인·이의처리·인수를 맡고, 정보화·데이터 담당은 권한·원천·운영을 확인. 공급자는 추가분 설계·연계·시험·복구·운영 인계의 책임과 범위를 명시. 구매·예산·계약 권한은 실제 기관 절차로 확인.

수요·자료권리·검수 책임이 없거나 기존 기능으로 충분하면 보류·축소. 중요 오류·권한 위반·복구 불가가 확인되면 해당 적용을 중단하고 수동 경로로 인계. 비용은 추가 분석·정비·개발·시험·운영의 인정 공수와 직접비로 산정하며 공통비 1회, 기존 의무·R&D·운영비의 중복 계상은 제외.
