# 인사변경과 업무 인수인계 연속성

## 문제와 제공 결과

**문제 가설:** 인사이동 때 미결업무·다음 행동·원문·접근권이 함께 인계되지 않아 누락이 발생한다는 가설.

**제공 결과:** 공식 발령을 기준으로 업무별 인계 목록, 후임 수락, 권한 이전·회수와 잔여 조치 확인을 제공.

분류는 대표 실증 후보. TS의 발주·예산·수요 확정 또는 구현 완료를 뜻하지 않으며, 효과 수치는 현행 기준선과 비교한 뒤 제시.

## 사례 기반 AS-IS → TO-BE 상세

### 현재 확인한 내용과 남은 확인

**확인된 범위:** ST-12는 인사변경에 따른 미결·책임·권한 연속성을 다룸. 인사평정·성향 분석을 포함하는 기획은 아님.

**현장 검증 필요:** 공식 발령과 업무 인계 문서, 후임 수락·권한 회수의 실제 차이 및 긴급 미결업무의 누락을 확인.

### TS 검토 시나리오와 전환 과제

휴직자가 처리하던 기한 임박 보완요청의 문서는 넘어갔지만 다음 행동과 접근권은 빠진 경우의 TS 검토 시나리오.

아래 업무 사례는 설계·검증용 예시이며 TS에서 실제 발생했거나 구현·실증한 사건을 뜻하지 않음. 타기관 사례는 위에서 확인한 공개 범위에만 적용.

| TO-BE 요소 | 수행 내용과 수락 조건 |
|---|---|
| 주체 | 인계자, 후임자, 부서 책임자, 인사·권한 담당 |
| 입력 | 발령·업무목록·미결 사건·다음 기한·승인상태·원문권리·권한 목록 |
| 행동·전환 과제 | 발령 범위 확인 → 미결과 기한·보완자료 추출 → 인계자 검토 → 후임 수락 또는 재배정 → 이전 권한 회수 → 잔여 위험 확인. |
| 산출물 | 업무별 다음 행동·기한·근거·담당 수락, 권한 변경 결과와 잔여 조치 |
| 예외·인계 | 후임 미지정·분쟁·대리 체계는 부서 책임자에게 인계. 자료 이동 권한이 없으면 원문 복사 대신 정당한 접근 절차를 안내. |
| 완료 판단 | 후임이 실제 업무를 재개할 수 있고 이전 접근이 회수되며 미해결 건의 책임자가 확인된 상태. |

### 세 영역의 고도화·신규 구축·조건부 차세대사업

‘고도화’는 확인된 기존 경로의 개선, ‘신규 구축’은 현재 부재·추가 필요성을 확인한 기능, ‘차세대사업’은 앞 단계 성과와 추가 권한·자원이 확보된 후속·파생 경로를 뜻함. 동일 기능을 세 유형의 사업비로 반복 합산하지 않음.

| 영역 | 고도화 | 신규 구축 | 조건부 차세대사업 |
|---|---|---|---|
| 인프라·플랫폼 | 기존 인사·협업도구의 이벤트·권한 대사 개선 | 미결 업무와 수락 상태 연결 | 기관 간 인계는 자료권리·소관 변경 근거 확보 후 |
| 지식 아카이브 | 기존 인계서의 다음 행동·기한·근거 정비 | 사건·담당·발령·미결 관계 | 인계 누락 추천은 현업 정답과 개인정보 범위 검증 후 |
| 업무서비스 | 기존 인계서 작성·수락 절차 보강 | 후임 재개 확인·권한 회수·잔여조치 업무 | 장기 직무 연속성은 부서 책임·갱신 주기 합의 후 |

### 업무별 2026~2030 단계와 검증 기준

- **2026**: 이동·휴직·겸직의 인계 표본과 수락·회수 지연 기준선 확보.
- **2027**: 한 부서 인사변경 전후 미결 사건의 재개·권한 회수를 함께 시험.
- **2028**: 대리·후임 미지정·기한 임박 예외를 추가하고 인계 후 재문의 측정.
- **2029**: 부서·기관 소관 이전은 원문 권리와 공식 업무 책임이 확정된 범위만 연결.
- **2030**: 인계 누락·중단 시간·기록 유지부담을 평가하고 인사·업무 원장 운영책임 정착.

각 단계의 수량·허용 오류·소요시간 목표는 기준선 조사 후 업무·검수 책임자가 합의. 기한 도래만으로 다음 단계에 진입하지 않으며, 중요 예외의 미해결·자료권리 미확보·기존 기능 대비 편익 미확인은 보완·축소·중단 판단 사유.

## 세 영역의 신규·고도화·연계

| 영역 | 신규 개발·구축 | 고도화 | 연계 강화 |
|---|---|---|---|
| 인프라·플랫폼 | 선정 업무의 허용 입출력·권한·기록 연결 | 예외·중복 실행·권한 회수·실패 복구의 검증 | 공식 원천·기존 시스템과 승인된 API 또는 제한된 도구 연결 |
| 지식 아카이브 | 업무 소관·미결 상태·다음 기한·완료 조건·공식 발령과 후임자 | 정본·시점·소관·권리·변경·회수 상태와 오류 사례 보강 | 해당 원천·공식 기준·검토 결과를 출처와 함께 연결 |
| 업무서비스 | 발령 확인 → 미결 추출 → 인계자 검토 → 후임 수락 → 권한 회수 → 잔여 조치 확인 | 담당 수락·보완·사람 확정·실패 인계·완료 증거 보강 | 기존 공식 처리·검토·보고 경로로 인계하고 실제 결과 확인 |

공통 기반을 업무마다 새로 구축하지 않으며, 기존 8.3 업무지식의 절차·규칙·예외 자산을 서비스에 연결. 개별 기관의 원문·정답·개인정보와 재사용 가능한 공통 자산의 권리를 구분.

## 2026~2030 진입 조건

- **2026 준비:** 공식 인사 이벤트, 인계 책임, 정당한 자료 범위와 회수·수락 증거를 확인. 같은 기간·대상에서 현행 처리·오류·재작업의 기준선을 확보.
- **2027:** 공통 기반 인수 후 대표업무 1~2개 선정 시 최소 범위만 실증. 현행 방식과 같은 조건으로 비교.
- **2028:** 현업 검증을 통과한 범위만 확산하고 기준·화면·권한 변경 시 재검증.
- **2029:** 고유업무·기관 간 연계는 각각의 소관·협약·입출력 계약과 예외 인계를 확인한 뒤 추가.
- **2030:** 사용 성과·유지 부담·권리·비용을 다시 비교해 운영 정착·재사용·축소를 결정. 전사 전면 자동화를 약속하지 않음.

2027 ON27-BASE의 M1~M9 최대 9개월은 기존 사이트의 상대 일정 제안이며 이 컨셉의 확정 착수일·납기를 뜻하지 않음.

## 책임·검증·예외

인사평정·성향 분석·직원 서열화 제외. 조직 변경만으로 권한을 확대하지 않음. ON-W02·03과 중복 개발 제거.

업무 소관자가 정답·승인·이의처리·인수를 맡고, 정보화·데이터 담당은 권한·원천·운영을 확인. 공급자는 추가분 설계·연계·시험·복구·운영 인계의 책임과 범위를 명시. 구매·예산·계약 권한은 실제 기관 절차로 확인.

수요·자료권리·검수 책임이 없거나 기존 기능으로 충분하면 보류·축소. 중요 오류·권한 위반·복구 불가가 확인되면 해당 적용을 중단하고 수동 경로로 인계. 비용은 추가 분석·정비·개발·시험·운영의 인정 공수와 직접비로 산정하며 공통비 1회, 기존 의무·R&D·운영비의 중복 계상은 제외.
