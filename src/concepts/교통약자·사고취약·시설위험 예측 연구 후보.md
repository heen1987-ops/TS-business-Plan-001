# 교통약자·사고취약·시설위험 예측 연구 후보

## 문제와 제공 결과

**문제 가설:** 교통약자 이동 실패·사고 취약·시설 침수 등 사례에 예측이 기여할 가능성은 있으나 TS 대상 수요·자료·개입 효과는 미확인.

**제공 결과:** 각 위험을 별도 연구 가설로 정의하고 실제 개입 가능한 담당·경보 이후 행동과 비교평가 가능성을 먼저 진단.

분류는 선행조건 확인 전 보류. TS의 발주·예산·수요 확정 또는 구현 완료를 뜻하지 않으며, 효과 수치는 현행 기준선과 비교한 뒤 제시.

## 사례 기반 AS-IS → TO-BE 상세

### 현재 확인한 내용과 남은 확인

**확인된 범위:** 기존 후보 목록에는 교통약자·사고취약·시설 침수 등의 연구 가능성이 있으나 실제 TS 수요·자료·효과를 입증한 사례로 제시되지 않음.

**현장 검증 필요:** 서로 다른 위험별 소관·자료·발생 정의·개입 수단과 오경보/미탐 책임을 분리 확인.

### TS 검토 시나리오와 전환 과제

시설 침수 징후가 발생했을 때 실제 점검·통제 가능한 기관이 경보를 받아 대응할 수 있는지를 검토하는 TS 시나리오. 다른 위험에는 별도 설계가 필요.

아래 업무 사례는 설계·검증용 예시이며 TS에서 실제 발생했거나 구현·실증한 사건을 뜻하지 않음. 타기관 사례는 위에서 확인한 공개 범위에만 적용.

| TO-BE 요소 | 수행 내용과 수락 조건 |
|---|---|
| 주체 | 해당 위험의 현장 소관자, 데이터 담당, 연구자, 경보 수신·조치 책임자 |
| 입력 | 발생/비발생 기록·관측 시점·노출량·환경 조건·개입·오경보 비용·결측 |
| 행동·전환 과제 | 개입 가능한 위험 하나 선정 → 단순 임계값 기준선 → 시간·지역 분리 검증 → 오경보/미탐의 업무 영향 평가 → 현장 대응 가능성 심사. |
| 산출물 | 위험별 타당성, 재현 평가, 경보 후 행동·중단 조건 |
| 예외·인계 | 사건 수가 부족하거나 라벨·관측이 편향되면 모델 개발보다 자료설계 보완. 예측점수를 개인·기관의 확정 위험등급으로 사용하지 않음. |
| 완료 판단 | 소관자가 경보의 사용·미사용과 대응 책임을 수락할 만큼 근거가 확보되거나 보류 이유가 명확한 상태. |

### 세 영역의 고도화·신규 구축·조건부 차세대사업

‘고도화’는 확인된 기존 경로의 개선, ‘신규 구축’은 현재 부재·추가 필요성을 확인한 기능, ‘차세대사업’은 앞 단계 성과와 추가 권한·자원이 확보된 후속·파생 경로를 뜻함. 동일 기능을 세 유형의 사업비로 반복 합산하지 않음.

| 영역 | 고도화 | 신규 구축 | 조건부 차세대사업 |
|---|---|---|---|
| 인프라·플랫폼 | 기존 관측·알림 체계의 누락·지연 진단 | 선택한 위험의 비운영 시험환경 | 실시간 경보는 대응권·연속성·미탐 통제 후 |
| 지식 아카이브 | 기존 사건·관측·개입 정의 정비 | 위험별 라벨·편향·반례 원장 | 다른 위험 일반화는 새 표본·평가 설계 후 |
| 업무서비스 | 기존 현장 점검·대응 절차 확인 | 경보 후보→사람 검토→조치 평가 | 예방 서비스는 실제 개입효과·운영비 검증 후 |

### 업무별 2026~2030 단계와 검증 기준

- **2026**: 위험 하나의 실제 수요·소관·자료·대응권 확인.
- **2027**: 보류 후보로 표본·라벨·단순 기준선 타당성을 검토.
- **2028**: 조건 확보 시 시간/지역 분리 비교연구, 미충족이면 연구 중단·이월.
- **2029**: 독립 평가 통과 후 현장 의사결정 지원만 제한 실증.
- **2030**: 예측 정확도와 실제 대응효과·오경보 부담을 분리 평가하여 지속 여부 결정.

각 단계의 수량·허용 오류·소요시간 목표는 기준선 조사 후 업무·검수 책임자가 합의. 기한 도래만으로 다음 단계에 진입하지 않으며, 중요 예외의 미해결·자료권리 미확보·기존 기능 대비 편익 미확인은 보완·축소·중단 판단 사유.

## 세 영역의 신규·고도화·연계

| 영역 | 신규 개발·구축 | 고도화 | 연계 강화 |
|---|---|---|---|
| 인프라·플랫폼 | 선정 업무의 허용 입출력·권한·기록 연결 | 예외·중복 실행·권한 회수·실패 복구의 검증 | 공식 원천·기존 시스템과 승인된 API 또는 제한된 도구 연결 |
| 지식 아카이브 | 위험 정의·발생·노출량·관측 누락·개입·오경보 비용 | 정본·시점·소관·권리·변경·회수 상태와 오류 사례 보강 | 해당 원천·공식 기준·검토 결과를 출처와 함께 연결 |
| 업무서비스 | 수요·소관 확인 → 표본·편향 진단 → 단순 기준선 비교 → 제한 평가 → 개입 가능성 판단 | 담당 수락·보완·사람 확정·실패 인계·완료 증거 보강 | 기존 공식 처리·검토·보고 경로로 인계하고 실제 결과 확인 |

공통 기반을 업무마다 새로 구축하지 않으며, 기존 8.3 업무지식의 절차·규칙·예외 자산을 서비스에 연결. 개별 기관의 원문·정답·개인정보와 재사용 가능한 공통 자산의 권리를 구분.

## 2026~2030 진입 조건

- **2026 준비:** 충분한 발생·비발생 자료와 시간 분리 검증, 오경보·미탐 책임·윤리·현장 대응을 확보. 같은 기간·대상에서 현행 처리·오류·재작업의 기준선을 확보.
- **2027:** 소관·수요·자료·예산 경로가 확인될 때에만 사전 타당성 검토. 연도 도래만으로 구축 착수하지 않음.
- **2028:** 타당성·비교시험을 통과한 하위 범위만 제한 검증. 미충족이면 이월 또는 중단.
- **2029:** 고유업무·기관 간 연계는 각각의 소관·협약·입출력 계약과 예외 인계를 확인한 뒤 추가.
- **2030:** 사용 성과·유지 부담·권리·비용을 다시 비교해 운영 정착·재사용·축소를 결정. 전사 전면 자동화를 약속하지 않음.

2027 ON27-BASE의 M1~M9 최대 9개월은 기존 사이트의 상대 일정 제안이며 이 컨셉의 확정 착수일·납기를 뜻하지 않음.

## 책임·검증·예외

서로 다른 위험을 하나의 범용 점수로 합치지 않음. 사례 몇 건으로 사고 예방효과·구매 수요를 확정하지 않음.

업무 소관자가 정답·승인·이의처리·인수를 맡고, 정보화·데이터 담당은 권한·원천·운영을 확인. 공급자는 추가분 설계·연계·시험·복구·운영 인계의 책임과 범위를 명시. 구매·예산·계약 권한은 실제 기관 절차로 확인.

수요·자료권리·검수 책임이 없거나 기존 기능으로 충분하면 보류·축소. 중요 오류·권한 위반·복구 불가가 확인되면 해당 적용을 중단하고 수동 경로로 인계. 비용은 추가 분석·정비·개발·시험·운영의 인정 공수와 직접비로 산정하며 공통비 1회, 기존 의무·R&D·운영비의 중복 계상은 제외.
