# 철도 안전관리체계 문서와 현장 검토

## 문제와 제공 결과

**문제 가설:** 철도 기준별 필수·대체 증빙, 현장 확인, 지적·종결이 별도로 기록돼 검토 누락을 찾기 어렵다는 가설.

**제공 결과:** 사건시점 기준과 제출자료를 대사한 확인 질문·상충 후보·현장 목록 및 조치·종결 대사를 지원.

분류는 조건부 확장 후보. TS의 발주·예산·수요 확정 또는 구현 완료를 뜻하지 않으며, 효과 수치는 현행 기준선과 비교한 뒤 제시.

## 사례 기반 AS-IS → TO-BE 상세

### 현재 확인한 내용과 남은 확인

**확인된 범위:** 기존 K036~K048은 철도 기준·필수/대체증빙·현장 확인·검사관 의견·종결을 분리함. 특정 업무의 TS 위탁범위·승인권은 현행 확인 필요.

**현장 검증 필요:** 실제 사건에서 적용기준·제출자료·현장 확인·지적 종결을 연결하는 방식과 검토 누락·반복 보완을 확인.

### TS 검토 시나리오와 전환 과제

제출 문서는 요건을 설명하지만 현장 적용 증거가 없고 이전 지적도 종결 근거가 불충분한 TS 검토 시나리오.

아래 업무 사례는 설계·검증용 예시이며 TS에서 실제 발생했거나 구현·실증한 사건을 뜻하지 않음. 타기관 사례는 위에서 확인한 공개 범위에만 적용.

| TO-BE 요소 | 수행 내용과 수락 조건 |
|---|---|
| 주체 | 철도 운영기관 자료 담당, 검사관·전문 검토자, 공식 승인·종결 책임자 |
| 입력 | 사건·기준판본·필수/대체 증빙·제출 문서·현장 기록·지적·조치·종결 요건 |
| 행동·전환 과제 | 사건시점 기준 고정 → 서류 충족·상충 후보 → 검사관 확인 질문 확정 → 현장 확인 → 지적별 조치 대사 → 권한자 종결·재개 판단. |
| 산출물 | 기준-증빙 대응표, 현장 질문·지적 목록, 조치·종결 근거 묶음 |
| 예외·인계 | 서류 설명과 현장 확인을 같은 증거로 취급하지 않음. 기준 해석·대체증빙 적정성은 검사관 판단을 기다림. |
| 완료 판단 | 검사관이 서류·현장·조치의 충족 여부와 미결을 확인하고 공식 권한자가 후속 결정을 수락. |

### 세 영역의 고도화·신규 구축·조건부 차세대사업

‘고도화’는 확인된 기존 경로의 개선, ‘신규 구축’은 현재 부재·추가 필요성을 확인한 기능, ‘차세대사업’은 앞 단계 성과와 추가 권한·자원이 확보된 후속·파생 경로를 뜻함. 동일 기능을 세 유형의 사업비로 반복 합산하지 않음.

| 영역 | 고도화 | 신규 구축 | 조건부 차세대사업 |
|---|---|---|---|
| 인프라·플랫폼 | 기존 철도 사건·문서·지적 기록의 연결 개선 | 기준별 검토·보완·종결 상태 | 기관 간 제출·현장 연계는 위탁·권리·책임 확인 후 |
| 지식 아카이브 | 기존 기준·서식·필수/대체 증빙 정비 | 사건시점·현장·지적·종결 관계 | 변경 재검토는 철도 중요 누락의 독립 평가 후 |
| 업무서비스 | 기존 검사관 문서검토·현장 목록 개선 | 조치 검토·종결·재개 인계 | 다른 철도 업무 확대는 승인·검사 경계 재확인 후 |

### 업무별 2026~2030 단계와 검증 기준

- **2026**: 선정 철도 업무의 소관·위탁·기준·사건 사용권 확인.
- **2027**: 오프라인 허용 사건에서 기준·누락·현장 질문을 검사관 정답과 비교.
- **2028**: 한 업무 제한 적용과 독립 검수로 중요 누락·보완·종결 오류 검증.
- **2029**: 운영기관·업무 확대는 새 기준·권한·현장 확인 절차를 각각 확보.
- **2030**: 실사용·검사관 부담·미결 추적 성과와 운영비를 평가해 유지·확산 여부 결정.

각 단계의 수량·허용 오류·소요시간 목표는 기준선 조사 후 업무·검수 책임자가 합의. 기한 도래만으로 다음 단계에 진입하지 않으며, 중요 예외의 미해결·자료권리 미확보·기존 기능 대비 편익 미확인은 보완·축소·중단 판단 사유.

## 세 영역의 신규·고도화·연계

| 영역 | 신규 개발·구축 | 고도화 | 연계 강화 |
|---|---|---|---|
| 인프라·플랫폼 | 선정 업무의 허용 입출력·권한·기록 연결 | 예외·중복 실행·권한 회수·실패 복구의 검증 | 공식 원천·기존 시스템과 승인된 API 또는 제한된 도구 연결 |
| 지식 아카이브 | 철도 기준·적용일·필수/대체 증빙·현장 확인·검사관 의견·종결 요건 | 정본·시점·소관·권리·변경·회수 상태와 오류 사례 보강 | 해당 원천·공식 기준·검토 결과를 출처와 함께 연결 |
| 업무서비스 | 기준 고정 → 서류 대사 → 검사관 확정 → 현장 확인 → 지적·보완 → 공식 종결·재개 | 담당 수락·보완·사람 확정·실패 인계·완료 증거 보강 | 기존 공식 처리·검토·보고 경로로 인계하고 실제 결과 확인 |

공통 기반을 업무마다 새로 구축하지 않으며, 기존 8.3 업무지식의 절차·규칙·예외 자산을 서비스에 연결. 개별 기관의 원문·정답·개인정보와 재사용 가능한 공통 자산의 권리를 구분.

## 2026~2030 진입 조건

- **2026 준비:** 대상 철도 업무별 법정 권한·위탁범위, 검사관 정답과 승인된 사건자료를 확인. 같은 기간·대상에서 현행 처리·오류·재작업의 기준선을 확보.
- **2027:** 공통 기반·대표실증을 우선하고 이 업무는 수요·권리·정답·기존 중복의 후보검증까지만 수행 가능.
- **2028:** 현업 검증을 통과한 범위만 확산하고 기준·화면·권한 변경 시 재검증.
- **2029:** 고유업무·기관 간 연계는 각각의 소관·협약·입출력 계약과 예외 인계를 확인한 뒤 추가.
- **2030:** 사용 성과·유지 부담·권리·비용을 다시 비교해 운영 정착·재사용·축소를 결정. 전사 전면 자동화를 약속하지 않음.

2027 ON27-BASE의 M1~M9 최대 9개월은 기존 사이트의 상대 일정 제안이며 이 컨셉의 확정 착수일·납기를 뜻하지 않음.

## 책임·검증·예외

서류 충족을 현장 안전 확인으로 대신하지 않음. AI 승인·안전 적합 판정 금지. 별도 법정 검토 책임 유지.

업무 소관자가 정답·승인·이의처리·인수를 맡고, 정보화·데이터 담당은 권한·원천·운영을 확인. 공급자는 추가분 설계·연계·시험·복구·운영 인계의 책임과 범위를 명시. 구매·예산·계약 권한은 실제 기관 절차로 확인.

수요·자료권리·검수 책임이 없거나 기존 기능으로 충분하면 보류·축소. 중요 오류·권한 위반·복구 불가가 확인되면 해당 적용을 중단하고 수동 경로로 인계. 비용은 추가 분석·정비·개발·시험·운영의 인정 공수와 직접비로 산정하며 공통비 1회, 기존 의무·R&D·운영비의 중복 계상은 제외.
