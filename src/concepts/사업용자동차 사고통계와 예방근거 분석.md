# 사업용자동차 사고통계와 예방근거 분석

## 문제와 제공 결과

**문제 가설:** 사고건수·운행량·지역·기간 정의가 다르면 위험 비교와 예방과제 선정의 근거가 왜곡될 수 있다는 가설.

**제공 결과:** 사업용자동차 사고·운행 통계를 같은 조건으로 대사하고 불확실성 및 예방 검토 질문을 제공.

분류는 조건부 확장 후보. TS의 발주·예산·수요 확정 또는 구현 완료를 뜻하지 않으며, 효과 수치는 현행 기준선과 비교한 뒤 제시.

## 사례 기반 AS-IS → TO-BE 상세

### 현재 확인한 내용과 남은 확인

**확인된 범위:** 기존 신규후보는 사업용자동차 사고통계의 분석 지원이며, 공개 DF 기획은 노출량·기간 차이를 경고함. 국가 전체 사고정보와 동일한 범위를 가정하지 않음.

**현장 검증 필요:** TMACS 등 대상 자료의 정의·기간·업데이트·누락, 운행량 분모와 현재 통계 검산·해석 절차를 확인.

### TS 검토 시나리오와 전환 과제

사고건수는 늘었지만 운행량도 바뀐 운수유형을 단순 건수 순위로 비교한 경우의 TS 검토 시나리오.

아래 업무 사례는 설계·검증용 예시이며 TS에서 실제 발생했거나 구현·실증한 사건을 뜻하지 않음. 타기관 사례는 위에서 확인한 공개 범위에만 적용.

| TO-BE 요소 | 수행 내용과 수락 조건 |
|---|---|
| 주체 | 통계 분석 담당, 교통안전 전문가, 자료 소관자 |
| 입력 | 사고 정의·대상 차량/운수유형·기간·지역·운행량·집계 규칙·정정 이력 |
| 행동·전환 과제 | 동일 대상·기간으로 맞춤 → 결측·중복·분모 확인 → 검증된 통계도구로 계산 → 민감도·비교 한계 표시 → 전문가 해석·예방과제 인계. |
| 산출물 | 재현 통계표, 분모·정의 차이 목록, 설명 가능한 예방 검토 질문 |
| 예외·인계 | 분모 부재·표본 편향·기간 변경이면 위험 순위를 확정하지 않음. 개인 또는 회사의 원인·책임을 상관자료만으로 단정하지 않음. |
| 완료 판단 | 계산이 재현되고 비교 가능한 범위와 불확실성을 전문가가 확인하여 정책 검토에 인계. |

### 세 영역의 고도화·신규 구축·조건부 차세대사업

‘고도화’는 확인된 기존 경로의 개선, ‘신규 구축’은 현재 부재·추가 필요성을 확인한 기능, ‘차세대사업’은 앞 단계 성과와 추가 권한·자원이 확보된 후속·파생 경로를 뜻함. 동일 기능을 세 유형의 사업비로 반복 합산하지 않음.

| 영역 | 고도화 | 신규 구축 | 조건부 차세대사업 |
|---|---|---|---|
| 인프라·플랫폼 | 기존 통계 추출·정정·계산 재현성 개선 | 정의·분모 대사를 위한 승인된 연결 | 여러 원천 결합은 권리·식별·기간 정합 후 |
| 지식 아카이브 | 기존 사고·노출량·집계 정의 정비 | 대상·기간·분모·정정의 근거 원장 | 위험 해석 추천은 통계 기준선·전문가 검증 후 |
| 업무서비스 | 기존 통계 작성·검산 흐름 개선 | 비교 한계 확인·예방질문 검토 | 개입 추천은 실제 대응 가능성과 효과 평가 설계 후 |

### 업무별 2026~2030 단계와 검증 기준

- **2026**: 한 통계 항목의 대상·분모·집계식·정정 기준선 확보.
- **2027**: 과거 공개·허용 자료로 독립 계산과 정의 불일치 탐지 검증.
- **2028**: 제한 분석 업무에서 재작업·오해석·검토시간 비교.
- **2029**: 다른 자료 결합은 동일 범위·기간과 목적별 이용권을 확인 후.
- **2030**: 통계 재현성과 정책 활용을 평가하되 예방효과의 인과성은 별도 연구로 검증.

각 단계의 수량·허용 오류·소요시간 목표는 기준선 조사 후 업무·검수 책임자가 합의. 기한 도래만으로 다음 단계에 진입하지 않으며, 중요 예외의 미해결·자료권리 미확보·기존 기능 대비 편익 미확인은 보완·축소·중단 판단 사유.

## 세 영역의 신규·고도화·연계

| 영역 | 신규 개발·구축 | 고도화 | 연계 강화 |
|---|---|---|---|
| 인프라·플랫폼 | 선정 업무의 허용 입출력·권한·기록 연결 | 예외·중복 실행·권한 회수·실패 복구의 검증 | 공식 원천·기존 시스템과 승인된 API 또는 제한된 도구 연결 |
| 지식 아카이브 | TMACS 관련 사고 정의·노출량·집계식·대상·기간·자료제약 | 정본·시점·소관·권리·변경·회수 상태와 오류 사례 보강 | 해당 원천·공식 기준·검토 결과를 출처와 함께 연결 |
| 업무서비스 | 자료 범위 확인 → 결측·정의 대사 → 재현 가능한 계산 → 전문가 해석 → 예방과제 검토 | 담당 수락·보완·사람 확정·실패 인계·완료 증거 보강 | 기존 공식 처리·검토·보고 경로로 인계하고 실제 결과 확인 |

공통 기반을 업무마다 새로 구축하지 않으며, 기존 8.3 업무지식의 절차·규칙·예외 자산을 서비스에 연결. 개별 기관의 원문·정답·개인정보와 재사용 가능한 공통 자산의 권리를 구분.

## 2026~2030 진입 조건

- **2026 준비:** 자료 소관·갱신주기·허용 목적과 독립 통계 산식, 비교 집단을 확인. 같은 기간·대상에서 현행 처리·오류·재작업의 기준선을 확보.
- **2027:** 공통 기반·대표실증을 우선하고 이 업무는 수요·권리·정답·기존 중복의 후보검증까지만 수행 가능.
- **2028:** 현업 검증을 통과한 범위만 확산하고 기준·화면·권한 변경 시 재검증.
- **2029:** 고유업무·기관 간 연계는 각각의 소관·협약·입출력 계약과 예외 인계를 확인한 뒤 추가.
- **2030:** 사용 성과·유지 부담·권리·비용을 다시 비교해 운영 정착·재사용·축소를 결정. 전사 전면 자동화를 약속하지 않음.

2027 ON27-BASE의 M1~M9 최대 9개월은 기존 사이트의 상대 일정 제안이며 이 컨셉의 확정 착수일·납기를 뜻하지 않음.

## 책임·검증·예외

국가 전체 TAAS와 TS의 사업용자동차 범위를 혼동하지 않음. 상관관계를 사고 원인·예방효과로 확정하지 않음.

업무 소관자가 정답·승인·이의처리·인수를 맡고, 정보화·데이터 담당은 권한·원천·운영을 확인. 공급자는 추가분 설계·연계·시험·복구·운영 인계의 책임과 범위를 명시. 구매·예산·계약 권한은 실제 기관 절차로 확인.

수요·자료권리·검수 책임이 없거나 기존 기능으로 충분하면 보류·축소. 중요 오류·권한 위반·복구 불가가 확인되면 해당 적용을 중단하고 수동 경로로 인계. 비용은 추가 분석·정비·개발·시험·운영의 인정 공수와 직접비로 산정하며 공통비 1회, 기존 의무·R&D·운영비의 중복 계상은 제외.
