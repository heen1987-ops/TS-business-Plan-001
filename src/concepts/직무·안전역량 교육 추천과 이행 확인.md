# 직무·안전역량 교육 추천과 이행 확인

## 문제와 제공 결과

**문제 가설:** 같은 교육목록·이수 기록만으로 직무 수요나 안전 판단의 실제 보완 여부를 파악하기 어렵다는 가설.

**제공 결과:** 직무·학습이력의 과정 추천·편성 경로와 운전적성 소견의 교정교육 경로를 구분해 담당자 승인·이행·관련성 확인을 지원.

분류는 조건부 확장 후보. TS의 발주·예산·수요 확정 또는 구현 완료를 뜻하지 않으며, 효과 수치는 현행 기준선과 비교한 뒤 제시.

## 사례 기반 AS-IS → TO-BE 상세

### 현재 확인한 내용과 남은 확인

**확인된 범위:** 기존 C01 기획은 직무·이력 기반 과정 추천·편성이고 QE 재검토는 운전적성 소견의 교정교육 연결임. 목적·민감정보·판단책임을 분리해야 함.

**현장 검증 필요:** 학습자 목표·과정 적격·정원·예산과 교정교육 소견의 사용권·강사 판단, 추천 후 이행·직무 관련성 확인 방식을 조사.

### TS 검토 시나리오와 전환 과제

직원에게 필요한 교육은 추천됐지만 자격요건·일정이 맞지 않거나, 안전교육 후 보완 행동 확인이 없는 TS 검토 시나리오.

아래 업무 사례는 설계·검증용 예시이며 TS에서 실제 발생했거나 구현·실증한 사건을 뜻하지 않음. 타기관 사례는 위에서 확인한 공개 범위에만 적용.

| TO-BE 요소 | 수행 내용과 수락 조건 |
|---|---|
| 주체 | 학습자, 교육 편성 담당, 강사·전문가, 과정 운영자 |
| 입력 | 직무·목표·허용 이수이력·과정 조건·일정·정원·예산; 교정교육은 권한 있는 소견·관찰만 별도 |
| 행동·전환 과제 | 목표·자료 사용범위 확인 → 적격 과정/보완계획 비교 → 학습자·강사 확인 → 정원·예산 조정 → 수강·실습 → 이행과 현업 관련성 관측. |
| 산출물 | 추천 근거·미충족 조건·편성안·승인·이수·보완 관측 기록 |
| 예외·인계 | 원치 않는 민감 소견 노출·인사평정 전용 제외. 수강 불가·중도 포기는 불이익 판단 대신 재편성·사유 확인으로 처리. |
| 완료 판단 | 실제 편성·수강·이행이 확인되고 담당자가 관련성·미충족을 평가. 이수 여부만으로 역량 향상을 확정하지 않음. |

### 세 영역의 고도화·신규 구축·조건부 차세대사업

‘고도화’는 확인된 기존 경로의 개선, ‘신규 구축’은 현재 부재·추가 필요성을 확인한 기능, ‘차세대사업’은 앞 단계 성과와 추가 권한·자원이 확보된 후속·파생 경로를 뜻함. 동일 기능을 세 유형의 사업비로 반복 합산하지 않음.

| 영역 | 고도화 | 신규 구축 | 조건부 차세대사업 |
|---|---|---|---|
| 인프라·플랫폼 | 기존 LMS의 적격·일정·이수 연결 개선 | 허용된 추천·편성 검토 연결 | 교정교육 연계는 민감정보·소관·보존 조건 확인 후 |
| 지식 아카이브 | 기존 과정·직무·적격 조건 정비 | 목표·추천근거·이행·관찰 지식 | 개인화 확대는 공정성·권리·역량 효과 검증 후 |
| 업무서비스 | 기존 과정 탐색·편성·수강 보완 | 학습자·강사의 계획 확정·후속 관측 | 역량지원 서비스는 실제 행동 변화·부담 평가 후 |

### 업무별 2026~2030 단계와 검증 기준

- **2026**: 두 교육 경로의 목적·권리·담당과 실제 탐색·편성 부담을 분리 조사.
- **2027**: 한 직무군 또는 교육유형의 적격·추천·편성 후보를 담당자 판단과 비교.
- **2028**: 제한 추천 후 수강·이행·현업 관련성·편성 부담을 측정.
- **2029**: 교정교육·다기관 과정 연결은 민감정보와 승인·수료 책임을 별도 검증.
- **2030**: 이수와 역량 변화를 구분해 평가하고 부적절한 개인화·미사용 추천을 축소.

각 단계의 수량·허용 오류·소요시간 목표는 기준선 조사 후 업무·검수 책임자가 합의. 기한 도래만으로 다음 단계에 진입하지 않으며, 중요 예외의 미해결·자료권리 미확보·기존 기능 대비 편익 미확인은 보완·축소·중단 판단 사유.

## 세 영역의 신규·고도화·연계

| 영역 | 신규 개발·구축 | 고도화 | 연계 강화 |
|---|---|---|---|
| 인프라·플랫폼 | 선정 업무의 허용 입출력·권한·기록 연결 | 예외·중복 실행·권한 회수·실패 복구의 검증 | 공식 원천·기존 시스템과 승인된 API 또는 제한된 도구 연결 |
| 지식 아카이브 | 과정 자격·일정·정원·직무·학습목표·관찰 결과·개인정보 조건 | 정본·시점·소관·권리·변경·회수 상태와 오류 사례 보강 | 해당 원천·공식 기준·검토 결과를 출처와 함께 연결 |
| 업무서비스 | 목표 확인 → 적격 과정·보완계획 → 학습자·강사 확인 → 편성·수강 → 이행·현업 관련성 확인 | 담당 수락·보완·사람 확정·실패 인계·완료 증거 보강 | 기존 공식 처리·검토·보고 경로로 인계하고 실제 결과 확인 |

공통 기반을 업무마다 새로 구축하지 않으며, 기존 8.3 업무지식의 절차·규칙·예외 자산을 서비스에 연결. 개별 기관의 원문·정답·개인정보와 재사용 가능한 공통 자산의 권리를 구분.

## 2026~2030 진입 조건

- **2026 준비:** LMS·교육자료의 권리와 실제 수요, 강사·편성 책임, 민감정보 취급 및 이의제기 경로를 확보. 같은 기간·대상에서 현행 처리·오류·재작업의 기준선을 확보.
- **2027:** 공통 기반·대표실증을 우선하고 이 업무는 수요·권리·정답·기존 중복의 후보검증까지만 수행 가능.
- **2028:** 현업 검증을 통과한 범위만 확산하고 기준·화면·권한 변경 시 재검증.
- **2029:** 고유업무·기관 간 연계는 각각의 소관·협약·입출력 계약과 예외 인계를 확인한 뒤 추가.
- **2030:** 사용 성과·유지 부담·권리·비용을 다시 비교해 운영 정착·재사용·축소를 결정. 전사 전면 자동화를 약속하지 않음.

2027 ON27-BASE의 M1~M9 최대 9개월은 기존 사이트의 상대 일정 제안이며 이 컨셉의 확정 착수일·납기를 뜻하지 않음.

## 책임·검증·예외

이수·추천을 역량 향상으로 바로 주장하지 않음. 인사 서열화·자동 자격/수료 결정·영상/생체 판독·문제은행 학습 제외.

업무 소관자가 정답·승인·이의처리·인수를 맡고, 정보화·데이터 담당은 권한·원천·운영을 확인. 공급자는 추가분 설계·연계·시험·복구·운영 인계의 책임과 범위를 명시. 구매·예산·계약 권한은 실제 기관 절차로 확인.

수요·자료권리·검수 책임이 없거나 기존 기능으로 충분하면 보류·축소. 중요 오류·권한 위반·복구 불가가 확인되면 해당 적용을 중단하고 수동 경로로 인계. 비용은 추가 분석·정비·개발·시험·운영의 인정 공수와 직접비로 산정하며 공통비 1회, 기존 의무·R&D·운영비의 중복 계상은 제외.
