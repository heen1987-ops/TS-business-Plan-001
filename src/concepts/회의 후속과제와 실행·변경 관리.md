# 회의 후속과제와 실행·변경 관리

## 문제와 제공 결과

**문제 가설:** 회의록은 작성되지만 결정사항의 담당·기한·변경·완료 증거가 후속 업무와 분리된다는 가설.

**제공 결과:** 결정·제안·미결을 구분한 과제 목록과 담당 수락, 변경 승인, 완료 근거를 연결.

분류는 조건부 확장 후보. TS의 발주·예산·수요 확정 또는 구현 완료를 뜻하지 않으며, 효과 수치는 현행 기준선과 비교한 뒤 제시.

## 사례 기반 AS-IS → TO-BE 상세

### 현재 확인한 내용과 남은 확인

**확인된 범위:** 회의 후속업무 설계가 기존 자료에 있으며 목표·계획·협업·변경은 ON-W04·05와 공통성이 큼.

**현장 검증 필요:** 실제 회의에서 결정·제안·미결이 어떻게 구분되고 담당 수락·기한 변경·완료가 어디에 기록되는지 확인.

### TS 검토 시나리오와 전환 과제

회의에서 ‘다음 주까지 검토하자’는 발언만 있고 담당·자료·확정 기한은 없는 상태의 TS 검토 시나리오.

아래 업무 사례는 설계·검증용 예시이며 TS에서 실제 발생했거나 구현·실증한 사건을 뜻하지 않음. 타기관 사례는 위에서 확인한 공개 범위에만 적용.

| TO-BE 요소 | 수행 내용과 수락 조건 |
|---|---|
| 주체 | 회의 주관자, 과제 담당자, 승인자, 협업도구 운영자 |
| 입력 | 허용된 회의록·안건·발언의 결정 지위·담당 후보·자료·기한 |
| 행동·전환 과제 | 결정 후보 추출 → 주관자가 결정/제안/미결을 구분 → 담당자가 범위·기한을 수락 → 자료 보완 → 변경 승인 → 완료 증거 검토. |
| 산출물 | 수락된 과제 원장, 보완질문, 변경·완료 근거와 미수락 인계 목록 |
| 예외·인계 | 발언이 모호하거나 당사자 부재이면 과제 확정 금지. 기한·범위 변경은 원 결정과 사유를 보존하며 책임자를 다시 확인. |
| 완료 판단 | 담당자가 약속한 산출물을 제출하고 주관자가 완료 또는 잔여 과제를 수락한 상태. |

### 세 영역의 고도화·신규 구축·조건부 차세대사업

‘고도화’는 확인된 기존 경로의 개선, ‘신규 구축’은 현재 부재·추가 필요성을 확인한 기능, ‘차세대사업’은 앞 단계 성과와 추가 권한·자원이 확보된 후속·파생 경로를 뜻함. 동일 기능을 세 유형의 사업비로 반복 합산하지 않음.

| 영역 | 고도화 | 신규 구축 | 조건부 차세대사업 |
|---|---|---|---|
| 인프라·플랫폼 | 기존 협업도구의 과제 ID·변경·알림 보강 | 빠진 회의 결정→과제 연결 | 부서 간 과제 자동 분해는 책임·동의 검증 후 |
| 지식 아카이브 | 기존 회의 서식의 결정 지위·완료 조건 정비 | 안건·결정·과제·증빙 연결 | 반복 회의의 변경 영향은 동일 사건 식별 검증 후 |
| 업무서비스 | 기존 회의록 이후 수락·보완 흐름 개선 | 미수락·기한 변경·완료 검토 업무 | 연속 실행은 승인 기반 도구와 복구 검증 후 |

### 업무별 2026~2030 단계와 검증 기준

- **2026**: 실제 회의 표본의 미수락·기한 불명·완료 미확인 건을 조사.
- **2027**: 한 회의체에서 발언과 결정 구분, 담당 수락·변경 이력을 실증.
- **2028**: 회의→협업도구 연결 후 미처리·중복 과제·운영 부담을 비교.
- **2029**: 부서 간 과제는 분담·승인·자료 접근과 최종 인수자 합의 후 확대.
- **2030**: 회의록 작성시간과 과제 완료 연속성을 따로 평가해 형식적 기록 기능 축소.

각 단계의 수량·허용 오류·소요시간 목표는 기준선 조사 후 업무·검수 책임자가 합의. 기한 도래만으로 다음 단계에 진입하지 않으며, 중요 예외의 미해결·자료권리 미확보·기존 기능 대비 편익 미확인은 보완·축소·중단 판단 사유.

## 세 영역의 신규·고도화·연계

| 영역 | 신규 개발·구축 | 고도화 | 연계 강화 |
|---|---|---|---|
| 인프라·플랫폼 | 선정 업무의 허용 입출력·권한·기록 연결 | 예외·중복 실행·권한 회수·실패 복구의 검증 | 공식 원천·기존 시스템과 승인된 API 또는 제한된 도구 연결 |
| 지식 아카이브 | 회의 기록의 사용권·결정 지위·과제 정의·변경 사유·완료 조건 | 정본·시점·소관·권리·변경·회수 상태와 오류 사례 보강 | 해당 원천·공식 기준·검토 결과를 출처와 함께 연결 |
| 업무서비스 | 회의 기록 → 결정 확인 → 담당 수락 → 일정·자료 보완 → 승인된 실행 → 완료 검토 | 담당 수락·보완·사람 확정·실패 인계·완료 증거 보강 | 기존 공식 처리·검토·보고 경로로 인계하고 실제 결과 확인 |

공통 기반을 업무마다 새로 구축하지 않으며, 기존 8.3 업무지식의 절차·규칙·예외 자산을 서비스에 연결. 개별 기관의 원문·정답·개인정보와 재사용 가능한 공통 자산의 권리를 구분.

## 2026~2030 진입 조건

- **2026 준비:** 회의자료 접근권, 결정 확인자, 기존 협업도구 연계와 과제 수락 책임을 확인. 같은 기간·대상에서 현행 처리·오류·재작업의 기준선을 확보.
- **2027:** 공통 기반·대표실증을 우선하고 이 업무는 수요·권리·정답·기존 중복의 후보검증까지만 수행 가능.
- **2028:** 현업 검증을 통과한 범위만 확산하고 기준·화면·권한 변경 시 재검증.
- **2029:** 고유업무·기관 간 연계는 각각의 소관·협약·입출력 계약과 예외 인계를 확인한 뒤 추가.
- **2030:** 사용 성과·유지 부담·권리·비용을 다시 비교해 운영 정착·재사용·축소를 결정. 전사 전면 자동화를 약속하지 않음.

2027 ON27-BASE의 M1~M9 최대 9개월은 기존 사이트의 상대 일정 제안이며 이 컨셉의 확정 착수일·납기를 뜻하지 않음.

## 책임·검증·예외

회의 발언을 승인으로 자동 해석하지 않음. ON-W04·05의 공통 과제·변경 기능과 중복 구축 금지.

업무 소관자가 정답·승인·이의처리·인수를 맡고, 정보화·데이터 담당은 권한·원천·운영을 확인. 공급자는 추가분 설계·연계·시험·복구·운영 인계의 책임과 범위를 명시. 구매·예산·계약 권한은 실제 기관 절차로 확인.

수요·자료권리·검수 책임이 없거나 기존 기능으로 충분하면 보류·축소. 중요 오류·권한 위반·복구 불가가 확인되면 해당 적용을 중단하고 수동 경로로 인계. 비용은 추가 분석·정비·개발·시험·운영의 인정 공수와 직접비로 산정하며 공통비 1회, 기존 의무·R&D·운영비의 중복 계상은 제외.
