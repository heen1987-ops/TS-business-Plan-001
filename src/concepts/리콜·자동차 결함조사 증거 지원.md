# 리콜·자동차 결함조사 증거 지원

## 문제와 제공 결과

**문제 가설:** 신고·정비·시험 자료의 차량·증상·시점이 달라 동일 결함 가설과 근거를 추적하기 어렵다는 가설.

**제공 결과:** 사건별 자료 대사, 결함 가설과 반증, 추가 확인 질문을 정리하여 조사 담당자의 검토와 제작사 조치 확인을 지원.

분류는 조건부 확장 후보. TS의 발주·예산·수요 확정 또는 구현 완료를 뜻하지 않으며, 효과 수치는 현행 기준선과 비교한 뒤 제시.

## 사례 기반 AS-IS → TO-BE 상세

### 현재 확인한 내용과 남은 확인

**확인된 범위:** 공식 리콜대상 확인은 제작사 보고에 기반한 조치여부 제공과 조회 제한 가능성을 안내하며, 리콜알리미 SMS 경로가 이미 존재함. 실시간 수리 완료 통합을 확인한 것은 아님.

관련 공식 근거: [자동차리콜센터 리콜대상·조치여부 확인](https://www.car.go.kr/ri/recall/list.do), [자동차리콜센터 리콜알리미](https://car.go.kr/ri/ntcn/list.do).

**현장 검증 필요:** 신고·정비·시험자료의 사건 연결, 제작사 보고 지연, 중복·상반 증상과 조사 담당자의 실제 추가 확인 부담을 측정.

### TS 검토 시나리오와 전환 과제

소유자는 수리했다고 말하지만 공개 조회에는 이전 분기의 미조치 상태가 남아 있는 사건을 검토하는 TS 시나리오.

아래 업무 사례는 설계·검증용 예시이며 TS에서 실제 발생했거나 구현·실증한 사건을 뜻하지 않음. 타기관 사례는 위에서 확인한 공개 범위에만 적용.

| TO-BE 요소 | 수행 내용과 수락 조건 |
|---|---|
| 주체 | 결함조사 담당·전문가, 제작사 조치 담당, 안내 상담원 |
| 입력 | 차량·부품·증상·발생일·정비 내역·시험 조건·공개 조회의 기준시점·제작사 결과 |
| 행동·전환 과제 | 신고·차량·시점을 대사 → 조회 상태의 최신성을 표시 → 조사 가설·반증·추가 질문을 묶음 → 전문가가 판단 → 제작사 또는 공식 조사 경로에 인계. |
| 산출물 | 사건별 증거 묶음, 최신성 차이와 미확인 사항, 추가 확인·조치 결과 기록 |
| 예외·인계 | 조회 실패·분기 시차를 새 결함·미수리로 확정하지 않음. 소비자 피해·신차 중재는 별도 소관으로 안내하며 조사자료는 접근권 안에서만 활용. 환경부 리콜은 해당 공식 조회에서 조치여부가 제공되지 않으므로 제작사 등 적정 확인 경로로 인계. |
| 완료 판단 | 조사자가 가설·추가확인·공식 판단을 기록하고, 실제 수리·조치 상태는 제작사 확인 근거와 기준시점이 연결된 상태. |

### 세 영역의 고도화·신규 구축·조건부 차세대사업

‘고도화’는 확인된 기존 경로의 개선, ‘신규 구축’은 현재 부재·추가 필요성을 확인한 기능, ‘차세대사업’은 앞 단계 성과와 추가 권한·자원이 확보된 후속·파생 경로를 뜻함. 동일 기능을 세 유형의 사업비로 반복 합산하지 않음.

| 영역 | 고도화 | 신규 구축 | 조건부 차세대사업 |
|---|---|---|---|
| 인프라·플랫폼 | 기존 신고·리콜알리미·공개 조회의 시점 표시 개선 | 허용된 조사자료 사건 연결 | 제작사 상태 연계는 갱신·오류·회신 책임 협약 후 |
| 지식 아카이브 | 기존 증상·부품·정비·시험 데이터 정합 개선 | 결함 가설·반증·원천·시점 관계 | 유사결함 추천은 표본 편향·오탐·전문가 정답 검증 후 |
| 업무서비스 | 기존 문의·신고의 추가 확인 안내 개선 | 조사 검토·제작사 회신·잔여조치 추적 | 연속 상태 안내는 실시간 보장 없이 원천별 최신성 검증 후 |

### 업무별 2026~2030 단계와 검증 기준

- **2026**: 기존 신고·알리미·제작사 보고 경로와 조치여부 시차를 실제 사건에서 확인.
- **2027**: 비식별 허용 사례로 차량·부품·증상·기준시점 대사의 후보검증.
- **2028**: 조사 질문·반증·추가자료 누락을 전문가 기준과 비교하며 제한 적용.
- **2029**: 제작사 조치 결과 연계는 협약·주기·정정·상담 책임 확보 후 확대.
- **2030**: 조사 재작업·잘못된 상태안내·운영 부담을 평가하고 공개/조사/제작사 책임 분리를 유지.

각 단계의 수량·허용 오류·소요시간 목표는 기준선 조사 후 업무·검수 책임자가 합의. 기한 도래만으로 다음 단계에 진입하지 않으며, 중요 예외의 미해결·자료권리 미확보·기존 기능 대비 편익 미확인은 보완·축소·중단 판단 사유.

## 세 영역의 신규·고도화·연계

| 영역 | 신규 개발·구축 | 고도화 | 연계 강화 |
|---|---|---|---|
| 인프라·플랫폼 | 선정 업무의 허용 입출력·권한·기록 연결 | 예외·중복 실행·권한 회수·실패 복구의 검증 | 공식 원천·기존 시스템과 승인된 API 또는 제한된 도구 연결 |
| 지식 아카이브 | 차량·증상·부품·정비·시험 조건·신고 시점·시정조치 근거 | 정본·시점·소관·권리·변경·회수 상태와 오류 사례 보강 | 해당 원천·공식 기준·검토 결과를 출처와 함께 연결 |
| 업무서비스 | 신고·자료 연결 → 중복·조건 대사 → 조사 질문 → 전문가 판단 → 공식 절차·조치 결과 확인 | 담당 수락·보완·사람 확정·실패 인계·완료 증거 보강 | 기존 공식 처리·검토·보고 경로로 인계하고 실제 결과 확인 |

공통 기반을 업무마다 새로 구축하지 않으며, 기존 8.3 업무지식의 절차·규칙·예외 자산을 서비스에 연결. 개별 기관의 원문·정답·개인정보와 재사용 가능한 공통 자산의 권리를 구분.

## 2026~2030 진입 조건

- **2026 준비:** 조사 자료권리·비식별화, 전문가 정답, 공식 조사와 제작사 조치 책임을 확인. 같은 기간·대상에서 현행 처리·오류·재작업의 기준선을 확보.
- **2027:** 공통 기반·대표실증을 우선하고 이 업무는 수요·권리·정답·기존 중복의 후보검증까지만 수행 가능.
- **2028:** 현업 검증을 통과한 범위만 확산하고 기준·화면·권한 변경 시 재검증.
- **2029:** 고유업무·기관 간 연계는 각각의 소관·협약·입출력 계약과 예외 인계를 확인한 뒤 추가.
- **2030:** 사용 성과·유지 부담·권리·비용을 다시 비교해 운영 정착·재사용·축소를 결정. 전사 전면 자동화를 약속하지 않음.

2027 ON27-BASE의 M1~M9 최대 9개월은 기존 사이트의 상대 일정 제안이며 이 컨셉의 확정 착수일·납기를 뜻하지 않음.

## 책임·검증·예외

AI의 결함 확정·리콜 명령 제외. 리콜 안내, 제조사 실제 수리, 소비자 피해구제, 신차 교환·환불 중재를 구분.

업무 소관자가 정답·승인·이의처리·인수를 맡고, 정보화·데이터 담당은 권한·원천·운영을 확인. 공급자는 추가분 설계·연계·시험·복구·운영 인계의 책임과 범위를 명시. 구매·예산·계약 권한은 실제 기관 절차로 확인.

수요·자료권리·검수 책임이 없거나 기존 기능으로 충분하면 보류·축소. 중요 오류·권한 위반·복구 불가가 확인되면 해당 적용을 중단하고 수동 경로로 인계. 비용은 추가 분석·정비·개발·시험·운영의 인정 공수와 직접비로 산정하며 공통비 1회, 기존 의무·R&D·운영비의 중복 계상은 제외.

## 근거의 적용 범위

- [자동차리콜센터 제도 안내](https://www.car.go.kr/rs/system/intrcn.do): 결함조사·리콜 안내와 제작사의 실제 시정조치를 구분.
- [한국소비자원 피해구제 상담 안내](https://www.kca.go.kr/odr/pg/ma/cnsutInfo.do): 소비자 피해상담·구제의 공식 처리 경로.
- [자동차 교환·환불 중재](https://adr.katri.or.kr/online-main/main.do): 리콜 및 중고차 일반 피해상담과 다른 중재 절차.
