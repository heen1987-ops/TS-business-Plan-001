# 전세버스 안전정보 공시 대사

## 문제와 제공 결과

**문제 가설:** 운수회사·차량·운전자·기간이 다른 근거가 공시 항목에 합쳐질 때 정합성과 정정 책임을 확인하기 어렵다는 가설.

**제공 결과:** 공시 항목과 원천 증빙의 대사, 누락·불일치 후보, 검토·정정 이력과 설명 가능한 보고를 제공.

분류는 조건부 확장 후보. TS의 발주·예산·수요 확정 또는 구현 완료를 뜻하지 않으며, 효과 수치는 현행 기준선과 비교한 뒤 제시.

## 사례 기반 AS-IS → TO-BE 상세

### 현재 확인한 내용과 남은 확인

**확인된 범위:** 기존 자료는 전세버스 공시를 계속업무·기존 과업 중복 확인 대상으로 분류함. 신규 전면 구축의 수요가 확인된 것은 아님.

**현장 검증 필요:** 현재 공시 항목·원천·공개 범위·정정 절차, 회사·차량·기간 혼용 및 증빙 대사 오류를 확인.

### TS 검토 시나리오와 전환 과제

공시 대상 차량이 교체됐지만 이전 차량의 증빙이 현재 공시에 연결된 경우의 TS 검토 시나리오.

아래 업무 사례는 설계·검증용 예시이며 TS에서 실제 발생했거나 구현·실증한 사건을 뜻하지 않음. 타기관 사례는 위에서 확인한 공개 범위에만 적용.

| TO-BE 요소 | 수행 내용과 수락 조건 |
|---|---|
| 주체 | 공시 담당, 운수회사 자료 담당, 원천 운영자, 공개 승인자 |
| 입력 | 회사·차량·기간·공시 정의·원천 증빙·공개 가능 필드·정정 사유 |
| 행동·전환 과제 | 공시 대상·기간 고정 → 원천과 항목 대사 → 누락·이전 대상 연결 확인 → 회사/소관자 보완 → 승인 후 정정·재검증. |
| 산출물 | 공시 항목별 근거와 오류 후보, 정정 전후 이력·승인 기록 |
| 예외·인계 | 개인정보·공개 근거가 불명확하면 공개 대상에서 보류. 원천 정정 중에는 기존값·미확정값을 구분. |
| 완료 판단 | 공시 승인자가 대상·기간·공개범위와 정정 결과를 확인하고 원천부터 공시까지 재현 가능. |

### 세 영역의 고도화·신규 구축·조건부 차세대사업

‘고도화’는 확인된 기존 경로의 개선, ‘신규 구축’은 현재 부재·추가 필요성을 확인한 기능, ‘차세대사업’은 앞 단계 성과와 추가 권한·자원이 확보된 후속·파생 경로를 뜻함. 동일 기능을 세 유형의 사업비로 반복 합산하지 않음.

| 영역 | 고도화 | 신규 구축 | 조건부 차세대사업 |
|---|---|---|---|
| 인프라·플랫폼 | 기존 공시 수집·원천 ID·정정 연결 개선 | 미지원 항목의 검증 어댑터만 추가 | 다기관 공시 연결은 공개근거·정정 책임 확보 후 |
| 지식 아카이브 | 기존 공시 항목·기간·원천 사전 정비 | 차량 변경·증빙·공시판본 관계 | 자동 불일치 탐지는 허용 오탐·중요 누락 검증 후 |
| 업무서비스 | 기존 공시 검토·정정 흐름 개선 | 보완·승인·재검증 업무 | 활용 분석은 원자료 공개범위·오해석 통제 후 |

### 업무별 2026~2030 단계와 검증 기준

- **2026**: 계속업무·기존 계약·현행 공시기능과 잔여 오류 비교.
- **2027**: 실제 추가분이 있으면 허용 과거 표본으로 대상·기간·증빙 대사 시험.
- **2028**: 검증된 항목에 제한 적용하고 정정·재작업·검토시간 비교.
- **2029**: 추가 원천은 공개근거·갱신·정정 책임이 확보된 경우만 연결.
- **2030**: 공시 신뢰성·유지비를 재평가해 기존 운영으로 편입 또는 기능 축소.

각 단계의 수량·허용 오류·소요시간 목표는 기준선 조사 후 업무·검수 책임자가 합의. 기한 도래만으로 다음 단계에 진입하지 않으며, 중요 예외의 미해결·자료권리 미확보·기존 기능 대비 편익 미확인은 보완·축소·중단 판단 사유.

## 세 영역의 신규·고도화·연계

| 영역 | 신규 개발·구축 | 고도화 | 연계 강화 |
|---|---|---|---|
| 인프라·플랫폼 | 선정 업무의 허용 입출력·권한·기록 연결 | 예외·중복 실행·권한 회수·실패 복구의 검증 | 공식 원천·기존 시스템과 승인된 API 또는 제한된 도구 연결 |
| 지식 아카이브 | 공시 정의·대상·기간·원천·공개 범위·정정 사유 | 정본·시점·소관·권리·변경·회수 상태와 오류 사례 보강 | 해당 원천·공식 기준·검토 결과를 출처와 함께 연결 |
| 업무서비스 | 원천 확보 → 항목 대사 → 차이 검토 → 소관 승인 → 공식 공시·정정 → 재검증 | 담당 수락·보완·사람 확정·실패 인계·완료 증거 보강 | 기존 공식 처리·검토·보고 경로로 인계하고 실제 결과 확인 |

공통 기반을 업무마다 새로 구축하지 않으며, 기존 8.3 업무지식의 절차·규칙·예외 자산을 서비스에 연결. 개별 기관의 원문·정답·개인정보와 재사용 가능한 공통 자산의 권리를 구분.

## 2026~2030 진입 조건

- **2026 준비:** 현행 전세버스 공시·기존 계약 범위, 공개 기준·개인정보 제한과 검수 담당을 확인. 같은 기간·대상에서 현행 처리·오류·재작업의 기준선을 확보.
- **2027:** 공통 기반·대표실증을 우선하고 이 업무는 수요·권리·정답·기존 중복의 후보검증까지만 수행 가능.
- **2028:** 현업 검증을 통과한 범위만 확산하고 기준·화면·권한 변경 시 재검증.
- **2029:** 고유업무·기관 간 연계는 각각의 소관·협약·입출력 계약과 예외 인계를 확인한 뒤 추가.
- **2030:** 사용 성과·유지 부담·권리·비용을 다시 비교해 운영 정착·재사용·축소를 결정. 전사 전면 자동화를 약속하지 않음.

2027 ON27-BASE의 M1~M9 최대 9개월은 기존 사이트의 상대 일정 제안이며 이 컨셉의 확정 착수일·납기를 뜻하지 않음.

## 책임·검증·예외

계속업무·기존 개발 범위를 신규 매출로 중복 계산하지 않음. 자동 위험등급·사실 미확인 공시 제외.

업무 소관자가 정답·승인·이의처리·인수를 맡고, 정보화·데이터 담당은 권한·원천·운영을 확인. 공급자는 추가분 설계·연계·시험·복구·운영 인계의 책임과 범위를 명시. 구매·예산·계약 권한은 실제 기관 절차로 확인.

수요·자료권리·검수 책임이 없거나 기존 기능으로 충분하면 보류·축소. 중요 오류·권한 위반·복구 불가가 확인되면 해당 적용을 중단하고 수동 경로로 인계. 비용은 추가 분석·정비·개발·시험·운영의 인정 공수와 직접비로 산정하며 공통비 1회, 기존 의무·R&D·운영비의 중복 계상은 제외.
