# 모빌리티 실증과 연구성과 이관

## 문제와 제공 결과

**문제 가설:** 실증 요구·환경·시험 판본·결과가 흩어져 후속 검증과 연구성과의 업무 적용 범위를 설명하기 어렵다는 가설.

**제공 결과:** 시험 묶음과 미충족 요구, 추가 검증 질문, 제한·잔여 과제를 정리해 후속 연구와 검사기준 검토에 인계.

분류는 조건부 확장 후보. TS의 발주·예산·수요 확정 또는 구현 완료를 뜻하지 않으며, 효과 수치는 현행 기준선과 비교한 뒤 제시.

## 사례 기반 AS-IS → TO-BE 상세

### 현재 확인한 내용과 남은 확인

**확인된 범위:** ST-05와 RD 대표기획은 요구·시험·결과·추가 검증 및 검사기준으로의 연구성과 이관을 다룸. 새 장비 연구성과의 확인과는 구분.

**현장 검증 필요:** 실증 환경·시험판본·요구 충족의 추적 상태, 실패자료 보존, 수요부서의 인수 조건과 실제 재시험 부담을 확인.

### TS 검토 시나리오와 전환 과제

시험장에서 충족한 결과가 다른 운행 조건의 검사 기준에 그대로 사용될 위험을 검토하는 TS 시나리오.

아래 업무 사례는 설계·검증용 예시이며 TS에서 실제 발생했거나 구현·실증한 사건을 뜻하지 않음. 타기관 사례는 위에서 확인한 공개 범위에만 적용.

| TO-BE 요소 | 수행 내용과 수락 조건 |
|---|---|
| 주체 | 실증 PM, 시험·연구자, 검증 전문가, 후속 업무 인수자 |
| 입력 | 목표 요구·환경·시험방법·버전·측정 결과·실패·한계·인수 기준 |
| 행동·전환 과제 | 요구와 시험조건을 고정 → 결과별 충족·결손을 대사 → 새로운 적용조건과 차이를 확인 → 추가 검증 질문을 확정 → 잔여 한계와 함께 이관. |
| 산출물 | 시험 증거 묶음, 추가 검증계획, 적용 가능·불가 범위, 후속 인수 목록 |
| 예외·인계 | 시험 조건이 다르거나 재현 불가이면 성과 일반화 보류. 기술 실패를 문서 관리 완료로 덮지 않으며 연구 중단·재시험 결정을 분리. |
| 완료 판단 | 인수자가 연구 결과의 적용범위·검증 한계·남은 시험과 책임을 수락. 파일 전달만으로 기술 인수 완료 아님. |

### 세 영역의 고도화·신규 구축·조건부 차세대사업

‘고도화’는 확인된 기존 경로의 개선, ‘신규 구축’은 현재 부재·추가 필요성을 확인한 기능, ‘차세대사업’은 앞 단계 성과와 추가 권한·자원이 확보된 후속·파생 경로를 뜻함. 동일 기능을 세 유형의 사업비로 반복 합산하지 않음.

| 영역 | 고도화 | 신규 구축 | 조건부 차세대사업 |
|---|---|---|---|
| 인프라·플랫폼 | 기존 시험·KADAS 기록의 조건·버전 연결 | 미지원 요구-결과-이관 상태 관리 | 연구·현장 연계는 재현성과 사용권 검증 후 |
| 지식 아카이브 | 기존 시험방법·측정·실패 근거 정비 | 조건별 요구·증거·불확실성 모형 | 검증공백 추천은 전문가 판단과 독립 비교 후 |
| 업무서비스 | 기존 실증 보고·보완 흐름 개선 | 연구성과 적용성·잔여과제 인수 업무 | 타 시험·검사기준 전환은 별도 과학적 검증 후 |

### 업무별 2026~2030 단계와 검증 기준

- **2026**: 한 실증과 후속 업무의 요구·시험자료·자료권리·인수자 확인.
- **2027**: 시험 묶음의 충족·결손·조건 차이를 오프라인 전문가 검토로 확인.
- **2028**: 실제 실증 한 건에서 자료 정합·추가검증·이관 누락을 제한 검증.
- **2029**: 다른 시험환경·검사기준 연결은 새로운 조건의 검증을 마친 범위만 적용.
- **2030**: 이관 후 활용·잔여 검증 비용·재사용 권리를 재평가해 후속 실증 또는 종료 결정.

각 단계의 수량·허용 오류·소요시간 목표는 기준선 조사 후 업무·검수 책임자가 합의. 기한 도래만으로 다음 단계에 진입하지 않으며, 중요 예외의 미해결·자료권리 미확보·기존 기능 대비 편익 미확인은 보완·축소·중단 판단 사유.

## 세 영역의 신규·고도화·연계

| 영역 | 신규 개발·구축 | 고도화 | 연계 강화 |
|---|---|---|---|
| 인프라·플랫폼 | 선정 업무의 허용 입출력·권한·기록 연결 | 예외·중복 실행·권한 회수·실패 복구의 검증 | 공식 원천·기존 시스템과 승인된 API 또는 제한된 도구 연결 |
| 지식 아카이브 | 실증 조건·장비·시험판본·성공·실패·불확실성·재현 기록 | 정본·시점·소관·권리·변경·회수 상태와 오류 사례 보강 | 해당 원천·공식 기준·검토 결과를 출처와 함께 연결 |
| 업무서비스 | 실증 목표 → 요구·시험 대응 → 결과·결손 대사 → 추가 검증 → 전문가 평가 → 이관 승인 | 담당 수락·보완·사람 확정·실패 인계·완료 증거 보강 | 기존 공식 처리·검토·보고 경로로 인계하고 실제 결과 확인 |

공통 기반을 업무마다 새로 구축하지 않으며, 기존 8.3 업무지식의 절차·규칙·예외 자산을 서비스에 연결. 개별 기관의 원문·정답·개인정보와 재사용 가능한 공통 자산의 권리를 구분.

## 2026~2030 진입 조건

- **2026 준비:** 시험자료 권리·가용성, 공학적 검증 전문가와 수요부서 인수 기준을 확인. 같은 기간·대상에서 현행 처리·오류·재작업의 기준선을 확보.
- **2027:** 공통 기반·대표실증을 우선하고 이 업무는 수요·권리·정답·기존 중복의 후보검증까지만 수행 가능.
- **2028:** 현업 검증을 통과한 범위만 확산하고 기준·화면·권한 변경 시 재검증.
- **2029:** 고유업무·기관 간 연계는 각각의 소관·협약·입출력 계약과 예외 인계를 확인한 뒤 추가.
- **2030:** 사용 성과·유지 부담·권리·비용을 다시 비교해 운영 정착·재사용·축소를 결정. 전사 전면 자동화를 약속하지 않음.

2027 ON27-BASE의 M1~M9 최대 9개월은 기존 사이트의 상대 일정 제안이며 이 컨셉의 확정 착수일·납기를 뜻하지 않음.

## 책임·검증·예외

자료관리 기능을 독립 연구의 과학적 성과로 주장하지 않음. 물리 제어·새 장비·비전모델 개발은 별도 실증·예산 경로.

업무 소관자가 정답·승인·이의처리·인수를 맡고, 정보화·데이터 담당은 권한·원천·운영을 확인. 공급자는 추가분 설계·연계·시험·복구·운영 인계의 책임과 범위를 명시. 구매·예산·계약 권한은 실제 기관 절차로 확인.

수요·자료권리·검수 책임이 없거나 기존 기능으로 충분하면 보류·축소. 중요 오류·권한 위반·복구 불가가 확인되면 해당 적용을 중단하고 수동 경로로 인계. 비용은 추가 분석·정비·개발·시험·운영의 인정 공수와 직접비로 산정하며 공통비 1회, 기존 의무·R&D·운영비의 중복 계상은 제외.
