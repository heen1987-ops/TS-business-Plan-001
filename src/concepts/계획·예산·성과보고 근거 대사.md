# 계획·예산·성과보고 근거 대사

## 문제와 제공 결과

**문제 가설:** 사업·기간·지표·금액 기준이 다른 자료가 보고서에 합쳐져 재확인과 정정이 반복된다는 가설.

**제공 결과:** 한 보고 양식에서 원장·계산식·증빙과 작성 문장을 대사하고 불일치·누락·확정 의견을 제공.

분류는 대표 실증 후보. TS의 발주·예산·수요 확정 또는 구현 완료를 뜻하지 않으며, 효과 수치는 현행 기준선과 비교한 뒤 제시.

## 사례 기반 AS-IS → TO-BE 상세

### 현재 확인한 내용과 남은 확인

**확인된 범위:** ST-10은 계획·예산·성과의 근거 검토이며 S06의 대표 실증 후보. 현재 ERP·성과보고 자동화 범위는 별도 확인 사항.

**현장 검증 필요:** 보고 수치의 기간·사업·금액 단위·집계식, 원장과 보고서의 불일치 유형과 재확인 시간을 조사.

### TS 검토 시나리오와 전환 과제

한 부서의 분기 보고서에 누적 실적과 당기 실적, 예산액과 집행액이 혼재한 경우의 TS 검토 시나리오.

아래 업무 사례는 설계·검증용 예시이며 TS에서 실제 발생했거나 구현·실증한 사건을 뜻하지 않음. 타기관 사례는 위에서 확인한 공개 범위에만 적용.

| TO-BE 요소 | 수행 내용과 수락 조건 |
|---|---|
| 주체 | 사업 담당자, 재무·성과 검토자, 보고 승인자 |
| 입력 | 사업 ID·기간·예산/집행 원장·지표 정의·산식·보고 양식·원천 증빙 |
| 행동·전환 과제 | 지표와 기간을 먼저 고정 → 독립 계산으로 원장 대사 → 문장의 수치·단위·범위를 확인 → 차이 원인을 담당자가 보완 → 승인된 보고와 근거를 인계. |
| 산출물 | 차이 목록, 재현 가능한 계산표, 원문 위치가 연결된 보고 초안과 승인본 |
| 예외·인계 | 원장 마감 전·정정 중이면 잠정값으로 표시하고 승인본 혼입 차단. 정의가 다른 지표를 이름이 같다는 이유로 합산하지 않음. |
| 완료 판단 | 모든 핵심 수치가 같은 범위의 원장·산식으로 재현되고 검토자가 차이 처리와 잠정·확정 상태를 수락. |

### 세 영역의 고도화·신규 구축·조건부 차세대사업

‘고도화’는 확인된 기존 경로의 개선, ‘신규 구축’은 현재 부재·추가 필요성을 확인한 기능, ‘차세대사업’은 앞 단계 성과와 추가 권한·자원이 확보된 후속·파생 경로를 뜻함. 동일 기능을 세 유형의 사업비로 반복 합산하지 않음.

| 영역 | 고도화 | 신규 구축 | 조건부 차세대사업 |
|---|---|---|---|
| 인프라·플랫폼 | 기존 ERP·보고 추출의 ID·기간 대사 보강 | 미지원 독립 계산·증빙 연결 | 전사 보고 연결은 지표 정의·마감 책임 정합 후 |
| 지식 아카이브 | 기존 지표 사전·산식·단위 정비 | 보고 문장·원장·증빙 관계 | 지표 변경 영향 자동 검토는 과거 재작성 검증 후 |
| 업무서비스 | 기존 수치 검토·보완 회수 개선 | 차이 원인 확인·승인본 동결 업무 | 예산·계획 조정 제안은 재무·정책 판단 절차 확보 후 |

### 업무별 2026~2030 단계와 검증 기준

- **2026**: 한 부서 한 보고양식의 원장·산식·마감 일정과 현행 대사시간 확보.
- **2027**: 독립 정답이 있는 보고서로 핵심 수치 오류·근거 재현·보완 왕복을 비교.
- **2028**: 검증된 지표군에 정정·잠정값·마감 변경 시험을 추가.
- **2029**: 부서 간 집계는 지표·기간·중복 제거·승인 책임이 합의된 항목부터 연결.
- **2030**: 정정 감소·보고 준비시간·유지비를 평가하고 원장·지표 소관을 운영 인수.

각 단계의 수량·허용 오류·소요시간 목표는 기준선 조사 후 업무·검수 책임자가 합의. 기한 도래만으로 다음 단계에 진입하지 않으며, 중요 예외의 미해결·자료권리 미확보·기존 기능 대비 편익 미확인은 보완·축소·중단 판단 사유.

## 세 영역의 신규·고도화·연계

| 영역 | 신규 개발·구축 | 고도화 | 연계 강화 |
|---|---|---|---|
| 인프라·플랫폼 | 선정 업무의 허용 입출력·권한·기록 연결 | 예외·중복 실행·권한 회수·실패 복구의 검증 | 공식 원천·기존 시스템과 승인된 API 또는 제한된 도구 연결 |
| 지식 아카이브 | 지표 정의·기간·산정경계·회계·정산 규칙과 원천 증빙 | 정본·시점·소관·권리·변경·회수 상태와 오류 사례 보강 | 해당 원천·공식 기준·검토 결과를 출처와 함께 연결 |
| 업무서비스 | 자료 확보 → 독립 계산·대사 → 차이 확인 → 담당자 검토 → 보고 승인 → 근거 묶음 인계 | 담당 수락·보완·사람 확정·실패 인계·완료 증거 보강 | 기존 공식 처리·검토·보고 경로로 인계하고 실제 결과 확인 |

공통 기반을 업무마다 새로 구축하지 않으며, 기존 8.3 업무지식의 절차·규칙·예외 자산을 서비스에 연결. 개별 기관의 원문·정답·개인정보와 재사용 가능한 공통 자산의 권리를 구분.

## 2026~2030 진입 조건

- **2026 준비:** 원장과 보고서의 동일 범위·기간, 독립 검산, 담당 정답과 기존 ERP·보고 기능을 확인. 같은 기간·대상에서 현행 처리·오류·재작업의 기준선을 확보.
- **2027:** 공통 기반 인수 후 대표업무 1~2개 선정 시 최소 범위만 실증. 현행 방식과 같은 조건으로 비교.
- **2028:** 현업 검증을 통과한 범위만 확산하고 기준·화면·권한 변경 시 재검증.
- **2029:** 고유업무·기관 간 연계는 각각의 소관·협약·입출력 계약과 예외 인계를 확인한 뒤 추가.
- **2030:** 사용 성과·유지 부담·권리·비용을 다시 비교해 운영 정착·재사용·축소를 결정. 전사 전면 자동화를 약속하지 않음.

2027 ON27-BASE의 M1~M9 최대 9개월은 기존 사이트의 상대 일정 제안이며 이 컨셉의 확정 착수일·납기를 뜻하지 않음.

## 책임·검증·예외

예산 편성·계약·집행·정산의 자동 승인 제외. 회수 시간을 현금 절감으로 바로 환산하지 않음.

업무 소관자가 정답·승인·이의처리·인수를 맡고, 정보화·데이터 담당은 권한·원천·운영을 확인. 공급자는 추가분 설계·연계·시험·복구·운영 인계의 책임과 범위를 명시. 구매·예산·계약 권한은 실제 기관 절차로 확인.

수요·자료권리·검수 책임이 없거나 기존 기능으로 충분하면 보류·축소. 중요 오류·권한 위반·복구 불가가 확인되면 해당 적용을 중단하고 수동 경로로 인계. 비용은 추가 분석·정비·개발·시험·운영의 인정 공수와 직접비로 산정하며 공통비 1회, 기존 의무·R&D·운영비의 중복 계상은 제외.
