# 조직·업무 공통 AI 플랫폼

## 문제와 제공 결과

**문제 가설:** 조직·자료·업무 상태가 바뀔 때 책임자와 실제 접근권을 함께 갱신하기 어렵다는 가설. 현재 기능과 계약 범위를 먼저 대조해야 함.

**제공 결과:** 조직·업무 원장, 로그인·인사변경, 접근·승인, 목표·계획·보완질문, 협업·실행·변경, 역할 화면·독립 검수·운영 인수의 공통 기반.

분류는 공통 기반·진단. TS의 발주·예산·수요 확정 또는 구현 완료를 뜻하지 않으며, 효과 수치는 현행 기준선과 비교한 뒤 제시.

## 사례 기반 AS-IS → TO-BE 상세

### 현재 확인한 내용과 남은 확인

**확인된 범위:** TS의 2025-10-14 공식 보도자료는 AI공통플랫폼 구축 용역을 명시함. 따라서 기존 사업·납품 범위 대조가 선행하며 2026년 실제 운영·인수 완료 여부는 이 자료만으로 확인되지 않음.

관련 공식 근거: [TS AI공통플랫폼 구축 용역 관련 보도](https://main.kotsa.or.kr/portal/bbs/report_view.do?bbscCode=report&bbscSeqn=18706&cateCode=&menuCode=05010200&pageNumb=1&sechCdtn=&sechKywd=).

**현장 검증 필요:** 현재 인사변경이 각 시스템 권한에 반영되는 시간, 휴직·겸직·직무대리 예외, 기존 IAM·SSO의 미지원 범위를 현행 설정과 표본 사건으로 확인.

### TS 검토 시나리오와 전환 과제

담당자가 다른 부서로 이동했는데 이전 부서 자료 접근과 미결 민원 담당이 그대로 남아 있는 경우를 시험하는 TS 검토 시나리오.

아래 업무 사례는 설계·검증용 예시이며 TS에서 실제 발생했거나 구현·실증한 사건을 뜻하지 않음. 타기관 사례는 위에서 확인한 공개 범위에만 적용.

| TO-BE 요소 | 수행 내용과 수락 조건 |
|---|---|
| 주체 | 인사 원천 담당, 업무 소관자, 권한 승인자, 정보화 운영자, 후임 담당자 |
| 입력 | 공식 발령일·직무 범위·계정·시스템별 역할·미결업무·승인 유효기간 |
| 행동·전환 과제 | 발령을 원천과 대사 → 영향을 받는 계정·업무·지식을 식별 → 회수와 신규 접근을 별도 승인 → 후임의 업무 수락과 시스템별 반영을 확인. |
| 산출물 | 권한 변경 결과, 미결 인계 목록, 미반영·거부 사유와 운영 조치 기록 |
| 예외·인계 | 겸직·대리·외부 협업 계정은 일괄 회수 대신 해당 권한자가 유효기간을 판단. 연계 장애 시 운영자가 수동 반영하고 다시 대사. |
| 완료 판단 | 이전 역할의 접근 거부와 허용된 새 역할의 접근, 후임 수락, 잔여 예외의 소유자가 모두 확인된 상태. 단순 발령 수신은 완료가 아님. |

### 세 영역의 고도화·신규 구축·조건부 차세대사업

‘고도화’는 확인된 기존 경로의 개선, ‘신규 구축’은 현재 부재·추가 필요성을 확인한 기능, ‘차세대사업’은 앞 단계 성과와 추가 권한·자원이 확보된 후속·파생 경로를 뜻함. 동일 기능을 세 유형의 사업비로 반복 합산하지 않음.

| 영역 | 고도화 | 신규 구축 | 조건부 차세대사업 |
|---|---|---|---|
| 인프라·플랫폼 | 기존 SSO·인사 이벤트의 반영 지연·회수 시험 | 빠진 시스템에만 권한·사건 상태 어댑터 | 기관 간 협업은 목적별 승인과 회수 전파 검증 후 확대 |
| 지식 아카이브 | 조직·직무 원장의 시점·겸직 정보 정비 | 자료권리·역할·업무 관계의 공통 원장 | 변경 영향 자동 추적은 정답·관계 품질 검증 후 적용 |
| 업무서비스 | 기존 입·퇴사·이동 요청의 예외 인계 보강 | 미결업무 수락·회수 대사 화면 | 부서 간 연속 업무는 수락·책임 분쟁 처리 검증 후 확산 |

### 업무별 2026~2030 단계와 검증 기준

- **2026**: 이동·휴직·겸직의 실제 처리 표본으로 시스템별 반영시간·누락 기준선 확보.
- **2027**: ON-W01~06의 기존 납품과 신규분을 대조하고 한 부서 이동 시나리오에서 회수·인수를 함께 검수.
- **2028**: 검증된 역할·시스템만 추가하고 원천 변경·장애 때 수동 대체와 재처리 일관성 시험.
- **2029**: 기관 간 협업은 자료 목적·승인 주체·회수 통보 협약과 역방향 실패 통제를 먼저 확인.
- **2030**: 실제 사용·회수 실패·운영 부담을 재평가해 미사용 연결 폐기, 공통 원장 소유·갱신 책임 인수.

각 단계의 수량·허용 오류·소요시간 목표는 기준선 조사 후 업무·검수 책임자가 합의. 기한 도래만으로 다음 단계에 진입하지 않으며, 중요 예외의 미해결·자료권리 미확보·기존 기능 대비 편익 미확인은 보완·축소·중단 판단 사유.

## 세 영역의 신규·고도화·연계

| 영역 | 신규 개발·구축 | 고도화 | 연계 강화 |
|---|---|---|---|
| 인프라·플랫폼 | ON-W01~06의 미구현 공통 추가분 | 부하·권한회수·복구·독립검수·운영 인수 | 인사·인증·업무 원천과 책임별 연결 |
| 지식 아카이브 | 공식 조직·업무분장·권한·자료권리·사용 목적의 판본과 변경 근거 | 정본·시점·소관·권리·변경·회수 상태와 오류 사례 보강 | 해당 원천·공식 기준·검토 결과를 출처와 함께 연결 |
| 업무서비스 | 신청 → 권한 확인 → 승인 → 실행 → 결과 대사 → 회수·인수 | 담당 수락·보완·사람 확정·실패 인계·완료 증거 보강 | 기존 공식 처리·검토·보고 경로로 인계하고 실제 결과 확인 |

공통 기반을 업무마다 새로 구축하지 않으며, 기존 8.3 업무지식의 절차·규칙·예외 자산을 서비스에 연결. 개별 기관의 원문·정답·개인정보와 재사용 가능한 공통 자산의 권리를 구분.

## 2026~2030 진입 조건

- **2026 준비:** ON-W01~06의 기존 이행·검수 상태, 시스템별 계정·연계 책임, 운영 인수자를 확인. 같은 기간·대상에서 현행 처리·오류·재작업의 기준선을 확보.
- **2027:** 기존 이행·권리·현업 정답을 확인한 공통 추가분과 대표업무 1~2개만 검증.
- **2028:** 현업 검증을 통과한 범위만 확산하고 기준·화면·권한 변경 시 재검증.
- **2029:** 고유업무·기관 간 연계는 각각의 소관·협약·입출력 계약과 예외 인계를 확인한 뒤 추가.
- **2030:** 사용 성과·유지 부담·권리·비용을 다시 비교해 운영 정착·재사용·축소를 결정. 전사 전면 자동화를 약속하지 않음.

2027 ON27-BASE의 M1~M9 최대 9개월은 기존 사이트의 상대 일정 제안이며 이 컨셉의 확정 착수일·납기를 뜻하지 않음.

## 책임·검증·예외

조직도의 상하 관계를 자료 접근권으로 자동 변환하지 않음. ON27-BASE와 공통 개발비는 한 번만 산정.

업무 소관자가 정답·승인·이의처리·인수를 맡고, 정보화·데이터 담당은 권한·원천·운영을 확인. 공급자는 추가분 설계·연계·시험·복구·운영 인계의 책임과 범위를 명시. 구매·예산·계약 권한은 실제 기관 절차로 확인.

수요·자료권리·검수 책임이 없거나 기존 기능으로 충분하면 보류·축소. 중요 오류·권한 위반·복구 불가가 확인되면 해당 적용을 중단하고 수동 경로로 인계. 비용은 추가 분석·정비·개발·시험·운영의 인정 공수와 직접비로 산정하며 공통비 1회, 기존 의무·R&D·운영비의 중복 계상은 제외.
