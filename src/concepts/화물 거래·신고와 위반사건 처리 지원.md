# 화물 거래·신고와 위반사건 처리 지원

## 문제와 제공 결과

**문제 가설:** 거래·운송구간·기간·사업자·위수탁 관계가 달라 신고·정정 또는 위반사건 확인이 반복될 수 있다는 가설.

**제공 결과:** 실적 신고·정정 준비와 안전운임 위반 신고사건을 별도 경로로 관리하며 증빙 대사·보완·관할 인계를 지원.

분류는 조건부 확장 후보. TS의 발주·예산·수요 확정 또는 구현 완료를 뜻하지 않으며, 효과 수치는 현행 기준선과 비교한 뒤 제시.

## 사례 기반 AS-IS → TO-BE 상세

### 현재 확인한 내용과 남은 확인

**확인된 범위:** CL 기존 대표안은 실거래의 신고·정정, 재검토안은 안전운임 위반 신고사건 지원으로 범위가 달라짐. 두 업무를 하나의 법정 절차로 합치지 않음.

**현장 검증 필요:** 최신 고시·제도·시스템 전환일, 신고센터·관할관청 권한, 거래자료 사용권과 현재 반복 보완을 확인.

### TS 검토 시나리오와 전환 과제

실거래 정정과 운임 차액을 주장하는 신고가 같은 거래를 참조하지만 제출·조사·통보 권한이 다른 TS 검토 시나리오.

아래 업무 사례는 설계·검증용 예시이며 TS에서 실제 발생했거나 구현·실증한 사건을 뜻하지 않음. 타기관 사례는 위에서 확인한 공개 범위에만 적용.

| TO-BE 요소 | 수행 내용과 수락 조건 |
|---|---|
| 주체 | 사업자 신고 담당, 사건 확인 담당, 고시 계산 검토자, 관할관청 |
| 입력 | 거래·구간·기간·사업자·위수탁 관계·고시판본·신고/정정 자료·조사 증빙 |
| 행동·전환 과제 | 실적 신고와 위반 사건을 먼저 분기 → 거래·기간·당사자 대사 → 검증된 산식 적용 → 보완·사실 확인을 담당자가 확정 → 해당 공식 경로로 인계. |
| 산출물 | 신고·정정 준비 묶음 또는 사건 확인·통보 검토자료, 차액 계산·미확인 쟁점 |
| 예외·인계 | 고시 적용조건·관할·당사자가 불명확하면 법률 판단을 생성하지 않고 소관자 검토. 두 경로의 승인·접수번호를 혼용하지 않음. |
| 완료 판단 | 권한자가 경로별 자료·계산·미결을 확인하고 공식 신고·통보 결과가 해당 사건에 연결. |

### 세 영역의 고도화·신규 구축·조건부 차세대사업

‘고도화’는 확인된 기존 경로의 개선, ‘신규 구축’은 현재 부재·추가 필요성을 확인한 기능, ‘차세대사업’은 앞 단계 성과와 추가 권한·자원이 확보된 후속·파생 경로를 뜻함. 동일 기능을 세 유형의 사업비로 반복 합산하지 않음.

| 영역 | 고도화 | 신규 구축 | 조건부 차세대사업 |
|---|---|---|---|
| 인프라·플랫폼 | 기존 거래·신고·사건 시스템의 ID·기간 정합 개선 | 미지원 증빙 대사·인계 연결 | 통합관리 전환은 실제 법령·시스템 일정 확인 후 |
| 지식 아카이브 | 기존 고시·계산·관할·증빙 조건 정비 | 거래와 신고/조사 사건의 분리 관계 | 변경 영향 분석은 새 고시 적용 정답 검증 후 |
| 업무서비스 | 기존 신고 보완·사건 사실확인 개선 | 경로별 승인·통보·정정 업무 | 기관 간 연속처리는 제재권과 역할을 분리한 협약 후 |

### 업무별 2026~2030 단계와 검증 기준

- **2026**: 최신 제도·고시·시스템과 실제 소관·원거래 사용권 확인.
- **2027**: 두 경로를 분리한 허용 표본으로 거래·조건·산식 대사 시험.
- **2028**: 선택된 한 경로에서 보완·오인계·검토부담 제한 실증.
- **2029**: 시스템 전환·관할 연결은 실제 시행·운영 일정과 검수 기준에 맞춰 검증.
- **2030**: 신고·조사 처리의 정합성과 운영비를 재평가; 과태료 등 제재 판단은 공식 권한 유지.

각 단계의 수량·허용 오류·소요시간 목표는 기준선 조사 후 업무·검수 책임자가 합의. 기한 도래만으로 다음 단계에 진입하지 않으며, 중요 예외의 미해결·자료권리 미확보·기존 기능 대비 편익 미확인은 보완·축소·중단 판단 사유.

## 세 영역의 신규·고도화·연계

| 영역 | 신규 개발·구축 | 고도화 | 연계 강화 |
|---|---|---|---|
| 인프라·플랫폼 | 선정 업무의 허용 입출력·권한·기록 연결 | 예외·중복 실행·권한 회수·실패 복구의 검증 | 공식 원천·기존 시스템과 승인된 API 또는 제한된 도구 연결 |
| 지식 아카이브 | 거래 원장·고시판본·계산 조건·신고 항목·사건 증빙·처리기한 | 정본·시점·소관·권리·변경·회수 상태와 오류 사례 보강 | 해당 원천·공식 기준·검토 결과를 출처와 함께 연결 |
| 업무서비스 | 거래/사건 구분 → 적용기준·증빙 대사 → 독립 계산 → 담당 확인 → 승인된 신고·통보 인계 | 담당 수락·보완·사람 확정·실패 인계·완료 증거 보강 | 기존 공식 처리·검토·보고 경로로 인계하고 실제 결과 확인 |

공통 기반을 업무마다 새로 구축하지 않으며, 기존 8.3 업무지식의 절차·규칙·예외 자산을 서비스에 연결. 개별 기관의 원문·정답·개인정보와 재사용 가능한 공통 자산의 권리를 구분.

## 2026~2030 진입 조건

- **2026 준비:** 현행 제도·시스템 변경일과 소관 권한, 원거래 사용권·검산·신고센터 및 관할관청 역할을 재확인. 같은 기간·대상에서 현행 처리·오류·재작업의 기준선을 확보.
- **2027:** 공통 기반·대표실증을 우선하고 이 업무는 수요·권리·정답·기존 중복의 후보검증까지만 수행 가능.
- **2028:** 현업 검증을 통과한 범위만 확산하고 기준·화면·권한 변경 시 재검증.
- **2029:** 고유업무·기관 간 연계는 각각의 소관·협약·입출력 계약과 예외 인계를 확인한 뒤 추가.
- **2030:** 사용 성과·유지 부담·권리·비용을 다시 비교해 운영 정착·재사용·축소를 결정. 전사 전면 자동화를 약속하지 않음.

2027 ON27-BASE의 M1~M9 최대 9개월은 기존 사이트의 상대 일정 제안이며 이 컨셉의 확정 착수일·납기를 뜻하지 않음.

## 책임·검증·예외

실적 신고와 위반 조사·제재를 합치지 않음. 무승인 제출·법적 적정성 확정·과태료 부과 제외. 과거 통계를 현재 성과로 사용하지 않음.

업무 소관자가 정답·승인·이의처리·인수를 맡고, 정보화·데이터 담당은 권한·원천·운영을 확인. 공급자는 추가분 설계·연계·시험·복구·운영 인계의 책임과 범위를 명시. 구매·예산·계약 권한은 실제 기관 절차로 확인.

수요·자료권리·검수 책임이 없거나 기존 기능으로 충분하면 보류·축소. 중요 오류·권한 위반·복구 불가가 확인되면 해당 적용을 중단하고 수동 경로로 인계. 비용은 추가 분석·정비·개발·시험·운영의 인정 공수와 직접비로 산정하며 공통비 1회, 기존 의무·R&D·운영비의 중복 계상은 제외.
