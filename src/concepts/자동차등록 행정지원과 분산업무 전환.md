# 자동차등록 행정지원과 분산업무 전환

## 문제와 제공 결과

**문제 가설:** 지자체 등록업무의 반복 증빙·사전 확인·인계 부담을 공동 지원할 수 있다는 가설. 기술보다 법정 권한·재원·책임의 검토가 선행.

**제공 결과:** 현행 권한을 유지한 사전 안내·증빙 대사와 공동지원 대안을 비교하고, 이관이 필요한 부분은 제도 검토로 분리.

분류는 선행조건 확인 전 보류. TS의 발주·예산·수요 확정 또는 구현 완료를 뜻하지 않으며, 효과 수치는 현행 기준선과 비교한 뒤 제시.

## 사례 기반 AS-IS → TO-BE 상세

### 현재 확인한 내용과 남은 확인

**확인된 범위:** 기존 기획에는 등록행정 공동지원·중앙처리·전면 이관 대안이 있으나, 정책 제안의 존재가 권한 이관을 뜻하지 않음. 마이데이터 목록상 자동차등록 관련 정보와 TS의 보유정보도 구분됨.

**현장 검증 필요:** 등록 유형별 현재 관청·권한·전결·기존 온라인 처리, 실제 방문·증빙 부담과 이관 가능 근거를 현행 제도·실무로 확인.

### TS 검토 시나리오와 전환 과제

자동차 이전등록 신청 전에 필요한 증빙을 정리하고 보완을 줄이되 법정 등록 결정을 현행 권한자가 수행하는 TS 검토 시나리오.

아래 업무 사례는 설계·검증용 예시이며 TS에서 실제 발생했거나 구현·실증한 사건을 뜻하지 않음. 타기관 사례는 위에서 확인한 공개 범위에만 적용.

| TO-BE 요소 | 수행 내용과 수락 조건 |
|---|---|
| 주체 | 신청인, 현행 등록관청 담당, 정책·제도 담당, 공동지원 수행 후보 |
| 입력 | 등록 유형·법정 소관·필요증빙·공동이용·보완·처리기한·수수료 귀속·이의절차 |
| 행동·전환 과제 | 현행 온라인/창구 흐름 조사 → 안내·증빙 대사 지원과 권한 이관 대안을 분리 → 실제 대체비용·추가 조정비 비교 → 법령·협약 검토 → 허용된 범위만 실증. |
| 산출물 | 권한 유지형 지원안, 제도 변경 필요 목록, 순편익·재원 가정과 제한 실증 범위 |
| 예외·인계 | 위탁·수신권·수수료 근거 미확보이면 기관 간 실행 중지. 보완 지원이 등록 승인·소유권 판단을 대신하지 않음. |
| 완료 판단 | 관계기관이 업무·권한·재원·민원 책임과 실증 범위를 확인하고 실제 등록은 공식 관청 결과로 대사. |

### 세 영역의 고도화·신규 구축·조건부 차세대사업

‘고도화’는 확인된 기존 경로의 개선, ‘신규 구축’은 현재 부재·추가 필요성을 확인한 기능, ‘차세대사업’은 앞 단계 성과와 추가 권한·자원이 확보된 후속·파생 경로를 뜻함. 동일 기능을 세 유형의 사업비로 반복 합산하지 않음.

| 영역 | 고도화 | 신규 구축 | 조건부 차세대사업 |
|---|---|---|---|
| 인프라·플랫폼 | 기존 온라인 등록·공동이용의 장애·보완경로 개선 | 허용된 사전검토·인계 연결 | 중앙처리는 법적 근거·운영 책임·복구 검증 이후 |
| 지식 아카이브 | 기존 유형별 증빙·권한·수수료 규칙 정비 | 관청·사건·증빙·보완 요구 관계 | 전국 공통 규칙은 지역 예외·제도 변경 검증 후 |
| 업무서비스 | 기존 신청 안내·사전 대사 개선 | 공동지원의 검토·인계·결과 확인 업무 | 전담 이관은 별도 제도·재원 의사결정 후 |

### 업무별 2026~2030 단계와 검증 기준

- **2026**: 등록 유형별 현행 권한·온라인 기능·수신권·실제 비용 조사.
- **2027**: 보류 후보로 지원/공동화/이관 대안을 비교하고 제도적 가능성 확인.
- **2028**: 권한을 유지한 사전지원부터 제한 실증; 미확보 제도는 구축하지 않고 이월.
- **2029**: 공동처리 또는 이관은 법령·협약·재원·인수 책임이 확정된 범위만 검토.
- **2030**: 실제 민원 부담·총비용·책임 공백을 재평가. 전면 이관·새 수입을 기본 결론으로 두지 않음.

각 단계의 수량·허용 오류·소요시간 목표는 기준선 조사 후 업무·검수 책임자가 합의. 기한 도래만으로 다음 단계에 진입하지 않으며, 중요 예외의 미해결·자료권리 미확보·기존 기능 대비 편익 미확인은 보완·축소·중단 판단 사유.

## 세 영역의 신규·고도화·연계

| 영역 | 신규 개발·구축 | 고도화 | 연계 강화 |
|---|---|---|---|
| 인프라·플랫폼 | 선정 업무의 허용 입출력·권한·기록 연결 | 예외·중복 실행·권한 회수·실패 복구의 검증 | 공식 원천·기존 시스템과 승인된 API 또는 제한된 도구 연결 |
| 지식 아카이브 | 등록업무 유형·지자체 권한·증빙·수수료·보완·이의제기와 처리책임 | 정본·시점·소관·권리·변경·회수 상태와 오류 사례 보강 | 해당 원천·공식 기준·검토 결과를 출처와 함께 연결 |
| 업무서비스 | 현행 업무·권한 조사 → 개선/공동지원/이관 대안 비교 → 순편익 검토 → 제도·협약 판단 → 제한 검증 | 담당 수락·보완·사람 확정·실패 인계·완료 증거 보강 | 기존 공식 처리·검토·보고 경로로 인계하고 실제 결과 확인 |

공통 기반을 업무마다 새로 구축하지 않으며, 기존 8.3 업무지식의 절차·규칙·예외 자산을 서비스에 연결. 개별 기관의 원문·정답·개인정보와 재사용 가능한 공통 자산의 권리를 구분.

## 2026~2030 진입 조건

- **2026 준비:** 등록관청·국토교통부·TS의 역할, 법령·위탁 가능성, 재원·수수료 귀속과 실제 대체비용을 확인. 같은 기간·대상에서 현행 처리·오류·재작업의 기준선을 확보.
- **2027:** 소관·수요·자료·예산 경로가 확인될 때에만 사전 타당성 검토. 연도 도래만으로 구축 착수하지 않음.
- **2028:** 타당성·비교시험을 통과한 하위 범위만 제한 검증. 미충족이면 이월 또는 중단.
- **2029:** 고유업무·기관 간 연계는 각각의 소관·협약·입출력 계약과 예외 인계를 확인한 뒤 추가.
- **2030:** 사용 성과·유지 부담·권리·비용을 다시 비교해 운영 정착·재사용·축소를 결정. 전사 전면 자동화를 약속하지 않음.

2027 ON27-BASE의 M1~M9 최대 9개월은 기존 사이트의 상대 일정 제안이며 이 컨셉의 확정 착수일·납기를 뜻하지 않음.

## 책임·검증·예외

TS가 이미 자동차등록을 전담한다거나 AI가 등록공무원 권한을 대체한다고 표현하지 않음. 전면 이관·새 수입은 정책 제안이며 확정 사업 아님.

업무 소관자가 정답·승인·이의처리·인수를 맡고, 정보화·데이터 담당은 권한·원천·운영을 확인. 공급자는 추가분 설계·연계·시험·복구·운영 인계의 책임과 범위를 명시. 구매·예산·계약 권한은 실제 기관 절차로 확인.

수요·자료권리·검수 책임이 없거나 기존 기능으로 충분하면 보류·축소. 중요 오류·권한 위반·복구 불가가 확인되면 해당 적용을 중단하고 수동 경로로 인계. 비용은 추가 분석·정비·개발·시험·운영의 인정 공수와 직접비로 산정하며 공통비 1회, 기존 의무·R&D·운영비의 중복 계상은 제외.
