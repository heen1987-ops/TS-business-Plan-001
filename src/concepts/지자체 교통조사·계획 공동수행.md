# 지자체 교통조사·계획 공동수행

## 문제와 제공 결과

**문제 가설:** 택시 운임 원가연구·주차 실태조사·도시교통계획 등 반복 용역에서 공통 자료·방법을 재사용할 순편익이 있다는 가설.

**제공 결과:** 세 업무의 법정 소관과 지역 특성을 보존한 공동 자료관리·분석·검증·성과 인계 대안을 비교.

분류는 선행조건 확인 전 보류. TS의 발주·예산·수요 확정 또는 구현 완료를 뜻하지 않으며, 효과 수치는 현행 기준선과 비교한 뒤 제시.

## 사례 기반 AS-IS → TO-BE 상세

### 현재 확인한 내용과 남은 확인

**확인된 범위:** 기존 주요색인에는 택시 원가연구·주차 실태조사·도시교통계획 공동수행의 기획 계열이 존재. 상세 법령·경제성 본문을 전수 재검증한 상태는 아님.

**현장 검증 필요:** 각 지자체의 발주 주기·실제 외주비·지역 표본·법정 책임·TS 수행 가능 근거와 공동화 조정비를 확인.

### TS 검토 시나리오와 전환 과제

인접 지자체가 비슷한 자료를 조사하지만 택시원가 기준·주차 표본·교통계획의 결정권은 각각 다른 상황의 TS 검토 시나리오.

아래 업무 사례는 설계·검증용 예시이며 TS에서 실제 발생했거나 구현·실증한 사건을 뜻하지 않음. 타기관 사례는 위에서 확인한 공개 범위에만 적용.

| TO-BE 요소 | 수행 내용과 수락 조건 |
|---|---|
| 주체 | 지자체 발주·정책 담당, 조사·계획 수행자, TS 수행 검토자, 지역 검수자 |
| 입력 | 기존 과업·원자료·방법론·지역조건·발주/검수 기준·권리·실제 비용 |
| 행동·전환 과제 | 세 업무를 분리해 현재 용역 파악 → 공통 수집·분석 자산과 지역 고유 판단 분리 → 대체 가능한 비용과 추가 조정비 비교 → 협약·제한 수행 → 지역별 인수. |
| 산출물 | 업무별 공동수행 가능 범위, 지역 예외·검수 조건, 순편익 산정식·보류 근거 |
| 예외·인계 | 법정 결정권·발주 책임·원자료 권리가 불명확하면 공동화 보류. 동일 양식을 쓴다고 표본·결론을 일괄 적용하지 않음. |
| 완료 판단 | 각 지자체가 지역 결과·권리·검수·운영 책임을 수락하고 공동 수행의 순편익이 비교 가능해진 상태. |

### 세 영역의 고도화·신규 구축·조건부 차세대사업

‘고도화’는 확인된 기존 경로의 개선, ‘신규 구축’은 현재 부재·추가 필요성을 확인한 기능, ‘차세대사업’은 앞 단계 성과와 추가 권한·자원이 확보된 후속·파생 경로를 뜻함. 동일 기능을 세 유형의 사업비로 반복 합산하지 않음.

| 영역 | 고도화 | 신규 구축 | 조건부 차세대사업 |
|---|---|---|---|
| 인프라·플랫폼 | 기존 용역 자료·분석도구의 재사용성 개선 | 협약된 공통 수집·검증 환경 | 중앙 운영은 법적 역할·재원·조정비 검증 후 |
| 지식 아카이브 | 기존 원가·주차·계획 방법의 조건 정비 | 공통 항목과 지역 예외·권리 원장 | 지역 간 추론은 표본·정책 조건 동등성 확인 후 |
| 업무서비스 | 기존 반복 조사·검산·인수 개선 | 공동 수행·지역 검수·정정 업무 | 반복 서비스화는 실제 구매·순편익·책임 합의 후 |

### 업무별 2026~2030 단계와 검증 기준

- **2026**: 세 업무의 자료·권한·외주비·구매 수요를 분리 확인.
- **2027**: 보류 후보로 공통화 가능한 항목과 법적·경제적 타당성 조사.
- **2028**: 협력 지자체·권리가 확보된 한 업무의 제한 공동수행 비교.
- **2029**: 다른 지역·업무는 표본·제도·지역 검수·재원을 다시 합의 후 확장.
- **2030**: 실제 대체비용·조정비·지역 품질을 비교해 공동 운영·분산 유지·중단 결정.

각 단계의 수량·허용 오류·소요시간 목표는 기준선 조사 후 업무·검수 책임자가 합의. 기한 도래만으로 다음 단계에 진입하지 않으며, 중요 예외의 미해결·자료권리 미확보·기존 기능 대비 편익 미확인은 보완·축소·중단 판단 사유.

## 세 영역의 신규·고도화·연계

| 영역 | 신규 개발·구축 | 고도화 | 연계 강화 |
|---|---|---|---|
| 인프라·플랫폼 | 선정 업무의 허용 입출력·권한·기록 연결 | 예외·중복 실행·권한 회수·실패 복구의 검증 | 공식 원천·기존 시스템과 승인된 API 또는 제한된 도구 연결 |
| 지식 아카이브 | 택시 원가 항목, 주차 수급·안전 조사, 도시교통계획의 표본·지역·기간·산정 조건 | 정본·시점·소관·권리·변경·회수 상태와 오류 사례 보강 | 해당 원천·공식 기준·검토 결과를 출처와 함께 연결 |
| 업무서비스 | 지역 수요·기존 용역 조사 → 공동화 가능부분 분리 → 비용·품질 대안 비교 → 협약·제한 수행 → 인수·편익 평가 | 담당 수락·보완·사람 확정·실패 인계·완료 증거 보강 | 기존 공식 처리·검토·보고 경로로 인계하고 실제 결과 확인 |

공통 기반을 업무마다 새로 구축하지 않으며, 기존 8.3 업무지식의 절차·규칙·예외 자산을 서비스에 연결. 개별 기관의 원문·정답·개인정보와 재사용 가능한 공통 자산의 권리를 구분.

## 2026~2030 진입 조건

- **2026 준비:** 지자체 구매·계획 권한, TS 수행 근거, 실제 대체 외주비·조정비·지역 자료권리와 협력 수요를 확인. 같은 기간·대상에서 현행 처리·오류·재작업의 기준선을 확보.
- **2027:** 소관·수요·자료·예산 경로가 확인될 때에만 사전 타당성 검토. 연도 도래만으로 구축 착수하지 않음.
- **2028:** 타당성·비교시험을 통과한 하위 범위만 제한 검증. 미충족이면 이월 또는 중단.
- **2029:** 고유업무·기관 간 연계는 각각의 소관·협약·입출력 계약과 예외 인계를 확인한 뒤 추가.
- **2030:** 사용 성과·유지 부담·권리·비용을 다시 비교해 운영 정착·재사용·축소를 결정. 전사 전면 자동화를 약속하지 않음.

2027 ON27-BASE의 M1~M9 최대 9개월은 기존 사이트의 상대 일정 제안이며 이 컨셉의 확정 착수일·납기를 뜻하지 않음.

## 책임·검증·예외

중앙화가 자동 절감이나 법정 권한 이관을 뜻하지 않음. 택시·주차·도시교통계획은 별도 사업·검수 경계를 유지.

업무 소관자가 정답·승인·이의처리·인수를 맡고, 정보화·데이터 담당은 권한·원천·운영을 확인. 공급자는 추가분 설계·연계·시험·복구·운영 인계의 책임과 범위를 명시. 구매·예산·계약 권한은 실제 기관 절차로 확인.

수요·자료권리·검수 책임이 없거나 기존 기능으로 충분하면 보류·축소. 중요 오류·권한 위반·복구 불가가 확인되면 해당 적용을 중단하고 수동 경로로 인계. 비용은 추가 분석·정비·개발·시험·운영의 인정 공수와 직접비로 산정하며 공통비 1회, 기존 의무·R&D·운영비의 중복 계상은 제외.
