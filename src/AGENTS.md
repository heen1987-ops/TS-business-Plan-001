# src/AGENTS.md — 데이터 원장·화면 규칙

루트 `AGENTS.md`를 먼저 적용한다. 이 폴더는 React 화면(`*.jsx`)과 구조화된 기획 데이터(`*.json`, `slide-data.cjs`)를 담는다. 화면은 데이터를 표시만 하고, 수치·문장을 JSX에 하드코딩하지 않는다.

## 원장 파일과 역할

| 파일 | 내용 | 검사 |
|---|---|---|
| `data.json` | 13개 처(`departments`, 34필드)와 법정업무(`legal`, 27행·출처 21건) | `check.cjs`: 처 13개 |
| `impact.json` | 처별 기대효과·출처 21건·평가 조건(`evaluation`) | 상태 문구 유지 |
| `architecture-v2.json` | 상세 아키텍처 16개(`units`), 공통 모듈·저장소·인터페이스 | `check.cjs`: 16개, 모듈 4개 |
| `katri.json`, `ars.json`, `discovery.json`, `updates.json` | 주제별 검토 원장 | 출처·기준일 필드 |
| `solutions-47.json`(추가 예정) | 47번 근거 재검증 공개본. `docs/solutions-47/solutions-47.public.json` 복사본 | 근거 ID 존재·공개 경계 |
| `slide-data.cjs` | 슬라이드 분할·상세 개조식 생성 | `check-slides.cjs`: 108 경로·104 요구사항 |

## 값을 넣을 때

- 필드가 없으면 비워 두거나 `null`로 둔다. `0`, `"0원"`, `"-"`로 채우지 않는다. 화면은 `null`을 "미산정"으로 표시해야 한다.
- 처 5개(IP·SI·PK·AD·RD)에 `annual`·`mm_total`·`labor`·`wbs`·`scenarios`가 없다. 채울 때는 산정 근거(단가·MM 산식·기준일)를 `source_registers`에 함께 적는다.
- 금액은 원 단위 정수로 저장하고 표시 단위(만원·억원)는 화면에서 변환한다. 상대 감소율·비율 차이·점수 변화는 원래 단위를 유지한다.
- 출처(`sources`)는 `id`·`title`·`url`·게시일 또는 확인일·비고를 갖춘다. "게시일 미표시"도 그대로 적는다.
- 상태 문구(`status`, `evaluation.status`)는 "설계 가정·실측 전·협의용 목표"를 지우지 않는다.

## 조직·예산 표기

- 처 이름을 바꾸거나 추가할 때 `docs-2026-plan` 42번·25번 §7.3과 대조하고, 불일치는 데이터에 `"org_note": "확인 필요: …"`처럼 남긴다. 사이트 쪽에서만 통일하지 않는다.
- 예산은 라벨과 함께 병기한다. 예: `{"label":"1차 계약(확정, 25번)","value":420000000}`, `{"label":"목표 상한 검토안(미확정)","value":700000000}`. 두 값을 평균·합산하지 않는다.
- 총액을 낼 때 포함된 처 수를 라벨에 적는다(`"8개 처 기준"`).

## 화면(JSX)

- 새 화면은 `pages.jsx`·`App.jsx` 라우팅과 `site-routes.json`을 함께 갱신한다. 경로는 저장소 하위 경로(`window.__TS_BASE__`) 기준 상대경로만 쓴다.
- 접근성·키보드 규칙은 `docs/SLIDE_READER.md`를 따른다. 2026-09-23 사용자 정정: 설명을 페이지로 분할하지 않고 상세 본문을 연속 스크롤로 표시한다. 본문 목차는 해당 절의 앵커 이동에 사용하고 고정 높이·본문 내부 스크롤을 두지 않는다.
- `<title>`은 "화면명 | TS AX" 한 번만. 홈은 "TS AX 사업기획 | TS AX"처럼 중복을 피한다.
- 외부 API·서버·LLM 호출을 넣지 않는다. 정적 산출물로만 동작한다.

## 근거 재검증(47번) 표시

- 13개 처 화면은 `solutions-47.json`의 판정·새 제목·입증 사실·기준선을 기존 원장보다 먼저 표시한다. 기존 원장 필드는 덮어쓰지 않는다.
- 사실 문장 옆에는 근거 ID와 등급 배지를 둔다. `source_level`이 "2차"인 근거는 "보도 인용"으로 표시한다.
- UNKNOWN·INFERRED 근거만으로 된 주장은 공개 파일에 없다. 새 주장을 만들 때 공개 근거 ID 없이 쓰지 않는다.
- 재설계 처의 이전 컨셉은 "이전 가설(2026-09-24)"로 접어서 보존한다.
- 기준선은 실측값(기준일·분모 포함) 또는 확보 경로 문장만 표시한다. 예시 기준선·가정 목표치는 표시하지 않는다.
