## 데이터 적용의 필수 정정

- 안전등급정보는 도로 링크 속성이다. 운수회사 평가로 사용하지 않는다.
- 사고 메시지 행 수는 고유 사고 건수가 아니다. 사상자수나 노출량도 없다.
- 인구밀도는 교통량·고령인구 비율을 대체하지 않는다.
- 지식자료 CSV는 본문이 아닌 목록이다. 원문을 읽지 않고 RAG 근거로 확정하지 않는다.
- 교육 수료/계획은 학습 성과·사고 예방효과와 다르다. KoROAD와 TS 실적을 합산하지 않는다.
- 필기시험204행의 자격구분은 철도운전면허164·철도교통관제40행이다.
- 궤도 검사일자 자료는 희망기간이며 확정/완료일이 아니다. 1900-01-01 포함 행은2개다.
- CCTV 목록은 영상·실시간 가동·사고·사각지대 정보가 아니다.
- 홈페이지 의견은 2019년44행이고 국민신문고가 아니다. 7행을 전체 국민의 발생률로 해석하지 않는다.
- Trip 샘플은2018년7월10일100행이며 시각3개 열 모두100행이 지수 표기다. 상세 시간은 추정 복구하지 않는다.

## 원본 재계산 확인

도로등급 A508,610/B15,439/C7,485/D14,053/문자NULL14행, 제한속도999 km/h135행을 직접 계산했다. 등급의 높고 낮음은 코드 정의 확인 전 단정하지 않는다. 도로명 공란28,056행·사고 진행방향 공란40행이 있다. 결측을 임의 0으로 바꾸지 않았다.

기기자료는 결과 합격598행에 재검일이 있고, 불합격148행에는 재검일이 없다. 따라서 전체746행을 초검 모집단으로 놓아 부적합률·재검 개선율을 산출하지 않았다. 상태 정의가 먼저다.
