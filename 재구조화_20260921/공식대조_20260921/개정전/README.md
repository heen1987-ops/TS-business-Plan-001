## 이번에 달라진 판단

- 안전등급을 회사등급이 아닌 도로 구간 데이터로 연결했다.
- 지식자료157행은 문서 본문 확보가 아닌 파일 목록으로 표시했다.
- 홈페이지44행 중 구체적인 불편·개선요청7행을 분리했다. 현재 민원이나 대표 표본으로 취급하지 않았다.
- TS-04의 중심인 시설·교육 운영을 유지하고 개인별 학습은 추가 가설로 구분했다.
- 장애·결제·모바일 기능 문제는 시스템 개선을 우선 검토하도록 했다.
- 정책기획 AI는 자료 요약에서 끝나지 않고 원인 가설·반대근거·TS 권한·기존 사업·대안·검증을 연결하도록 설계했다.
- 고령자·음주운전·혁신제품·PM 의제는 관련 데이터 부족을 밝히고 조사 의제로 보존했다.

## 근거와 현재 한계

로컬 CSV/ZIP 직접 점검, 참조 대화 최근20개 턴 확인 내용, 현재 작업 폴더의2026-09-15 기획 지침을 사용했다. 과거 파생 검토 JSON은 참고했으며 중요한 수치는 원본에서 재계산했다. 전체 법령조사나 포털27개 상세 대조를 완료한 문서가 아니다. 공식 페이지 확인은 만족도·교육영상2개이며 방식과 한계는 출처 문서에 기재했다.

TS-01 번호와 TS-P01 번호는 자동 대응하지 않는다. 기존 P23 원문은 이번 경로에서 재확보하지 못해 번호 통합을 보류했다. 기존 기획 문서·원본 데이터는 덮어쓰거나 이동하지 않았다.

방법론: 중규모 문서 재구조화(M), 원본 영향 낮음·정책 판단 위험 중간. 근거 수집→개념 정의→자료 매핑→원본 대조→자체 검토 적용. 코드/UI/배포 산출물은 요청 범위 밖이므로 만들지 않았다.
