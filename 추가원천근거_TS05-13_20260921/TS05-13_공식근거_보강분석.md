# TS-05~13 공식 근거 보강 및 사업기획 반영 검토

조사일: 2026-09-21 | 대상: CCK 사업기획·TS 협의 담당자 | 연결 보고서: TS 사업기획 리포트 v1.1

## 1. 결론

추가 대화의 사업컨셉 중 일부를 공식 원문으로 대조했다. 이번 조사에서 14개 HTML 원문을 저장했으며, 이 중 10개는 관련 본문을 검토했다. 3개는 탐색·위치 안내 자료이고 1개는 상세 검토 대기다. 별도 사무편람 PDF 1건은 HTTP 400으로 확보하지 못했다. **9개 주제의 근거조사를 모두 완료했다는 의미는 아니다.**

가장 중요한 반영점은 기존 협업·검증·안내 체계를 사업의 적용 기반으로 삼는 것이다. 기존 체계의 부재나 효과 부족을 공개 안내만으로 주장할 수 없다. 조명등 설치조건, 철도용품 기준, 부산 부적격 운수종사자 관리, 수소차검사센터 행정절차는 기관이 직접 제기한 문제·개선방향을 확인했지만 현재도 동일한 문제가 남는지, 추가 예산을 지출할 수요가 있는지는 별도 확인해야 한다.

## 2. 가정과 범위

- 기존 v1.1의 기획 방향을 유지하고 이번 검증을 보충자료로 연결한다. Word 본문 자체를 새 판본으로 바꾼 것은 아니다.
- CCK 주관, 로컬 LLM·기존 서버 사용, 신규 인프라 0원, 비전 제외, 독립 R&D 제외 조건 유지. 서버 용량·동시접속·보안 적합성은 실제 환경 검증 전제다.
- 기존 AI에도 추가 기능을 적용할 수 있다. 동일 계약 납품분을 중복 견적에 포함하지 않고 공통 기능 재사용과 업무별 추가 작업을 구분한다.
- 공식 웹페이지는 조사 시점의 안내 증거다. 해당 페이지의 법령 인용을 현행 법령·시행일 독립 검증 결과로 승격하지 않는다.
- 기대효과는 검증 가설이며 달성 실적이 아니다. 국민생각함 의견은 통계적으로 대표성 있는 전체 국민 조사로 해석하지 않는다.

## 4. 정책 문제정의 AI에 반영할 논리

입력자료를 수집하는 것만으로 정책 문제의 원인이 입증되지는 않는다. 다음 단계별 판단과 담당자 확인을 설계한다.

1. **현상 추출:** 공식 통계, 공개 정책의견, 뉴스, 연구자료를 출처·시점·지역·대상과 함께 기록한다. 공개 정책의견과 비공개 민원 원문을 구분한다.
2. **기존 대응 대조:** 담당기관·법정업무·기존 시스템·개선계획·계약 범위를 대조한다. 이미 조치한 사안을 미해결로 누적하지 않는다.
3. **원인 가설 분리:** 규정의 불명확성, 정보 접근, 물리적 시설 부족, 협의·예산 제약을 별개 가설로 작성한다. 반복 기사와 재전재는 독립 증거로 세지 않는다.
4. **추가 사업 후보:** AI가 해결 가능한 문서 대조·근거 연결·조건 안내와 제도 개정·시설 확충 등 별도 정책수단을 구분한다. 비AI 검색·서식 개선 대안과 비교한다.
5. **반증과 결정:** 문제의 현재성, 실제 사용자 불편, 담당부서 수요, 활용 가능한 데이터, 신규 납품 범위를 확인한 뒤 기획 우선순위를 정한다.

권장 문제카드 필드: 주제ID, 문제 진술, 영향 대상, 출처ID와 위치, 자료 발생일, 조사일, 관측 사실, 원인 가설, 기존 대응, 반대 근거, 현재 해결 상태, 추가 작업, 담당기관·근거, 데이터 권한, 검증지표, 의사결정자.

**정책 의견의 요약 → 원인 확정 → 사업 필요성 확정**을 자동으로 연결하지 않는 것이 핵심이다. 이번 S31의 화면 참여수와 본문 의견수 집계 차이는 숫자의 정의와 집계 단위를 먼저 확인해야 하는 실제 예다. 해당 비율은 사업 타당성 수치로 사용하지 않는다.

## 5. 예상 개선효과와 측정 설계

아래는 제안 지표이며 수치 목표·달성 효과는 미확정이다. 업무 담당자와 기준선·표본·허용 오차를 합의한 뒤 목표를 정한다.

| 적용군 | 효과 가설 | 측정 방법 | 같이 확인할 부작용 |
|---|---|---|---|
| 정책 문제카드·TS05 | 근거 확인과 비교조건 이해 개선 | 동일 사례의 기존 방식 대비 출처 확인 정확도·누락률·검토시간 비교 | 허위 인용, 기간이 다른 지표의 잘못된 비교 |
| TS06·10·11 | 제출·준비 부족에 따른 재문의·재작업 감소 | 도입 전후 또는 대조군의 보완 요청 비율·재문의율·과업 성공률 측정 | 잘못된 확정 안내, 필요한 전문가 검토 생략 |
| TS07·12·13 | 책임·확인사항·조치 상태의 가시성 향상 | 미확인 상태 정리율·증빙 연결률·오래된 상태 오인 비율 측정 | 기관 책임 오배정, 적격 오판, 정당한 협의를 지연으로 오인 |
| TS09 | 기준 버전과 증빙 대조 정확도 개선 | 전문가가 판정한 기준 변경 사례의 누락·오탐 및 검토 근거 추적 가능성 평가 | 폐지 기준 적용, 안전 판단의 자동화 |

업무시간 개선을 인원 감축으로 환산하지 않는다. 사고 감소·사업기간 단축·기업 비용 절감은 다른 요인의 영향을 받으므로 단순 전후 변화로 AI 인과효과를 주장하지 않는다.

## 7. 다음 검증 대기열

우선순위는 수주 가능성의 점수가 아니라 **기획 의사결정에 필요한 미확인 사항의 순서**다.

1. TS-10·09: 의견수렴 이후 실제 기준 개정과 이행 여부, 현행 기준 원문·시행일, 미해결 사례 확보.
2. TS-11: 공식 시험장비·시험조건·상담·예약 안내 확보 후 물리적 수용능력 문제와 안내 문제 분리.
3. TS-13·07·12: 기관별 협업 계획의 이행 결과, 업무상 누락 사례, 조치 이력 확인.
4. TS-05·06: 최신 편람·면제요건 및 정정·보완 사례 확보. S40 재확보 필요.
5. 공통: 담당부서 수요, 데이터 이용권한, 기존 계약 범위, 기존 서버 가용성 확인. 실제 수요 없이 제안금액·도입 일정을 확정하지 않음.

## 8. 검증 범위와 판정

Stage-Gate의 근거 확인→적용 판단→검토 방식으로 수행했다. 원문 저장, 해시 대조, 연결 경로, 주제별 한계 표시를 확인한다. 본문 내용 검토는 전 문서의 전체 조항을 검증했다는 뜻이 아니다. S35는 상세 검토 대기, S40은 확보 실패다. S30·S32의 별도 첨부파일은 아직 확보하지 않았으며 공개 HTML 본문만 사용했다.

자체 QA 판정: **기획 검토용 조건부 사용 가능**. 조건은 미확인 항목을 확정 사실·현재 규정·달성 성과로 사용하지 않는 것이다. 독립 평가위원 승인이나 현장 검증 완료를 의미하지 않는다. 본 자료는 사업 확정·발주·운영 배포 승인 자료가 아니다.
