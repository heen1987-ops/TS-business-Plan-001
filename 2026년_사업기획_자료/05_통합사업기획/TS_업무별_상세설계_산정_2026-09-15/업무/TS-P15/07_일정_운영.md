# TS-P15 추진 일정·운영

전기차 배터리 식별정보 확인 절차 지원

> **기획 검토안**: CCK 주관 AX+SI / NOA·로컬 LLM / 기존 서버 / 신규 인프라 0원. 실제 API·물량·견적·효과는 확인 전.

## 추진 전제·책임

기존 상담 AI 운영자와 제작사 공식 안내의 갱신 책임·확인 주기를 정한다. 별도 플랫폼 사업으로 중복 발주하지 않는다.

CCK가 분석·NOA/LLM 구성·화면/연계·검증·운영 인계를 주관한다. TS는 자료·권한·규칙·정답·검수·공식 업무 결정을 맡는다. 원 시스템 공급사 변경 작업은 별도 책임과 범위를 확정한다.

## 단계·종료 조건


| 단계 | 수행 | 종료·책임 |
| --- | --- | --- |
| G0 범위 | 제작사 1곳의 공식 절차 안내, 공개 문서 1종, 개인 데이터 연계 0개 | 자료·API·계약·검토자 확인 / TS+CCK |
| G1 설계 | 공식 경로·질문 범위 확인 | 요구·화면·데이터·권한·평가셋 승인 / TS |
| G2 구현 | 제작사 1곳 안내팩과 질문·오안내 평가 추가 | 정상·예외 흐름 시연 / CCK |
| G3 검증 | 조회수·실패 질문을 검토해 공식 안내 갱신 체계 보강 | 기능·권한·근거·성능·복귀 시험 / CCK+TS |
| G4 시범·인계 | 승인 사용자·물량으로 제한 적용 | 현업 인수·운영 교육·복귀 확인 |
| 후속 | 추가 제작사는 공식 안내 확보량에 따라 지식팩 단위 확대 | 효과·자원·추가 물량 검토 후 결정 |


## 일정·인력 환산 가정

증분 중간 공수 14인일을 평균 2명·주 5일로 단순 환산하면 약 2주다. 자료·권한·현업 검토 대기 4주를 별도 가정한 참고 기간은 **약 6주**다. 공통 기능·선행 업무·조달·보안 심의 기간은 포함하지 않았다. 22개를 이 기간에 모두 수행한다는 계획이 아니다.

분석→구성→연계→시험의 의존성을 지킨다. 독립 자료 정리·화면 설계만 병행하고 실제 팀은 직무 겸임·병행을 조정한다.

## 운영·성과 환류

- 월별 지식 갱신·오류·권한 변경·실패 호출·응답 시간·수정량 검토
- 규칙·지식·프롬프트 변경 시 회귀 사례 재실행과 이전 승인 버전 보관
- 업무 지표: 잘못된 확인 경로·완료까지 탐색시간·불필요한 문의
- 인수인계: 설치 구성·권한표·지식 목록·연계 계약·장애·복귀 절차·제약 전달



## 준비 상태
