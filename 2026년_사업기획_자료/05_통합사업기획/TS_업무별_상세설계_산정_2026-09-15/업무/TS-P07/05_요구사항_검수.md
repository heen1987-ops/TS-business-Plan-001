# TS-P07 요구사항·검수

항공 자격 응시 준비자료 점검 지원

> **기획 검토안**: CCK 주관 AX+SI / NOA·로컬 LLM / 기존 서버 / 신규 인프라 0원. 실제 API·물량·견적·효과는 확인 전.

## 기능·비기능 요구사항


| ID | 요구·행동 | 수용기준·시험 |
| --- | --- | --- |
| TS-P07-HF01 | 자격별 규칙 분리 / 항공 자격 종류와 기준일을 고정하고 타 자격 자료를 구분한다. | 화물 자격 규칙이나 다른 항공 자격 요건이 섞여 나오지 않는다. / TS-P07-HT01 |
| TS-P07-HF02 | 경력·증빙 대조 / 서술의 기간·단위·발급 주체를 증빙과 대응시킨다. | 중첩 기간이나 단위가 다른 수치를 자동 합산해 응시 요건 충족으로 표시하지 않는다. / TS-P07-HT02 |
| TS-P07-HF03 | 증빙 부족 질문 / 없는 자료와 내용 불일치를 구분해 보완을 안내한다. | 증빙이 없으면 경력 사실을 확인된 것으로 적지 않는다. / TS-P07-HT03 |
| TS-P07-HF04 | 확인 후 인계 / 준비 상태와 공식 접수를 구분하고 이용자 확인 내용을 고정한다. | 동의 후 내용이 변경되면 재확인하며 인계 실패는 접수 완료가 아니다. / TS-P07-HT04 |
| TS-P07-HN01 | 접근권한·로컬 처리 / 원문·인덱스·로그·호출의 권한과 외부 경로를 점검한다. | 승인된 권한 거부 사례에서 원문·검색·직접 요청을 모두 거부하고, 기존 서버 실행 시험 중 승인되지 않은 외부 모델·데이터 전송이 관측되면 배포를 보류한다. / TS-P07-HT05 |
| TS-P07-HN02 | 근거·실패 상태·복귀 / 원문 위치·버전·조회 시점을 표시하고 자료 실패와 실제 결과를 분리한다. | 삭제·접근 철회·변경된 자료가 탐지되면 해당 결과를 최신·확정으로 표시하지 않으며 오류 시 입력을 보존하고 기존 처리 경로를 제공한다. / TS-P07-HT06 |

## RFP 수행·검수 조항 초안

- 계약 대상: 항공 자격 1종의 신청 준비, 문서 유형 2종, 상태 조회·인계 각 1개
- 기존 납품분·추가 설정·추가 개발·업무 연계의 구분과 작업분해·견적 근거 제시
- 화면·데이터·인터페이스·권한 명세, 지식·규칙·프롬프트 버전, 시험 증거, 운영·복귀 문서 제출
- 정답·판정 책임·수정 이력을 가진 승인 평가셋 사용
- 자동 확정·권한 우회·상태 오표시를 해소한 뒤 인수 검토
- 기존 서버 사용. 신규 장비·클라우드 인프라 구매 제외

요구사항과 RFP 문안의 발주 검토 초안이다. 계약 심사·제품 인수 시험·현업 승인은 미완료다.
