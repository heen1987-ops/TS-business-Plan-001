# P23 HTML 도입제안서 v1.4 — 검토·검증 기록

## 결론

제안용 HTML과 일치하는 Markdown을 작성하고 지정한 G드라이브 폴더에 정리했다. 기존 문서·이미지는 보존하며 시작 안내 3개만 최신 제안서 우선으로 수정했다.

## 범위와 방법

- 작업 유형: 기존 자료의 제안 논리·도식·HTML 재구성. 규모 M, 위험도 Low. 문서 제작 Standard Loop 적용.
- 순서: 기존 문서·원장 확인 → 본문과 도식 설계 → 독립 읽기 검토 → 제작 → 브라우저·시각·산정 검증 → 안내 갱신.
- 별도 발표자료·제품 구현·기관 연계·배포·외부 제출은 이번 범위에 없음.
- 가정: 로컬 LLM·NOA 활용, 기존 서버, 신규 인프라 구매 0원. 실제 환경·사용권·자료·양식 확보 상태는 확인 전.

## 독립 검토와 수정

- 논거 검토: '음성시험'을 '비허용 접근·공개 요청 시험'으로 수정. 반올림 중간항목 합계와 최종 총액의 1원 차이를 설명.
- 도식 검토: 감액·보완 후 재설계·재검토와 발주 준비의 진행 조건을 명시. P23 업무 SI와 사업·비용 저장소의 직접 조회·저장을 추가.
- 판정: 본문·도식의 내부 검토 필수 지적 반영. 기관의 실제 수용·정책 승인 판정은 아님.

## 실행 검증

- HTML 14개 본문 절, 핵심 SVG 도식 4개, 비교표 18개, 생성 이미지 2개 재사용.
- 55개 링크의 로컬 경로·앵커 확인: 누락 0. 외부 URL의 최신 내용은 이번 개정에서 재검증하지 않음.
- 1440 / 1024 / 768 / 390px 화면: 본문 가로 넘침 0. 표·도식은 좁은 화면에서 영역 내 가로 탐색.
- PC·모바일 목차 이동 확인, 이미지 로딩 정상, 중복 ID 0, JavaScript 오류 0, 외부 런타임 요청 0.
- 추가 확장분 하한·중간·상한 3개 산식 재계산: 기존 원장 총액과 일치. 기반 공수 원장 전체의 재감사나 외부 원가 검증은 아님.
- 데스크톱·모바일 화면 및 네 도식 스크린샷 육안 확인. 글자·선 겹침 발견 항목을 수정.
- 접근성: 한국어 lang·제목 계층·대체텍스트·건너뛰기 링크·포커스 가능 표/도식 영역·동작 감소 설정 확인. 스크린리더와 WCAG 전체 적합성 인증은 미수행.

## 시각 검토

내부 자체평가: 목적 적합성 5 / 정보계층 4 / 브랜드 일관성 5 / 구도·여백 4 / 반응형 적합성 4 / 접근성 4 / 참조 이미지 보존 5 / 왜곡·오류 4 = 35/40. 두 이미지는 기존 생성 원본을 그대로 재사용했고 도식의 정확한 텍스트는 SVG로 작성했다. 제안 문서의 시각 점검이며 제품 사용성 실험이 아니다.

## 미검증·후속 확인

실제 NOA API·권한 연계·서버 성능, HWPX 2종 출력, TS 자료·실제 예산 경로·부서 수요, 이용권·운영비, 사업 효과는 본 HTML 제작으로 검증되지 않는다. 이 내용은 제안서에 착수·수용 조건으로 표시했다.

## 복구

기존 안내 3개의 변경 전 사본을 이 폴더의 변경전 하위에 보관했다. 새 제안서 경로는 제안서_v1.4이며 기존 v1.1~v1.3 본문과 파일은 수정하지 않았다. 복구가 필요하면 변경기록의 해시와 현재 수정 내용을 비교한 뒤 해당 안내를 복원한다.
