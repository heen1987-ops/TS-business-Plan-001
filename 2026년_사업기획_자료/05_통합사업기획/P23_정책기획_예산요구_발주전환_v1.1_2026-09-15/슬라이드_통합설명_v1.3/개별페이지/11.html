데이터 흐름과 근거 추적

연결키 예시: source_id, evidence_id, issue_id, project_id, project_version, budget_version, template_id, template_version, document_version, review_id. ID 예시는 설계안이다.

데이터 처리: 승인된 자료 반입 → 텍스트·표 구조화 → 출처 메타데이터와 접근정책 등록 → 근거 단위 연결 → 가설·문제 검토 → 사업·비용 원장 → 양식별 초안. 스캔·음성·영상 인식은 제안 범위에 포함하지 않는다.

검색은 권한 필터를 적용하고, 요약·생성문서도 사용한 보호 근거에 맞는 접근 수준을 유지한다. 내부 열람 권한이 외부 공개 권한을 의미하지 않는다.

원문 정정·철회가 발생하면 파생 주장과 영향을 받은 문서를 재검토 대상으로 표시한다. 이전 버전은 승인된 보존정책에 따라 유지하며 삭제·보존기간은 TS가 정한다.
