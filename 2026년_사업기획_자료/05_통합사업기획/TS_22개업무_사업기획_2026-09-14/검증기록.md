# TS 22개 업무 사업기획 검증 기록

기준일 2026-09-14. 작성자 자체 문서·화면 검토이며 실제 제품 시험·독립 평가위원 승인·현업 사용자 조사는 수행하지 않았다.

## 산출물과 근거

- 기존 TS-L01~22를 TS-P01~22에 일대일 연결했다. 공식 주요사업 7개 대분류를 유지했다.
- 개별 HTML 22개·Markdown 22개, 통합 HTML/MD, 공통 수행설계 HTML/MD, 업무/사업기획/요구사항 원장, 후속 확인 대기열을 생성했다.
- 근거 34개에는 공식 기관 자료, 공급사 설명, 내부 기획·기술·RTM 자료가 포함된다. 34개 모두가 새 공식 원문이라는 뜻은 아니다.
- 공식 안내의 핵심 범위를 재확인하고, 공급사 제품 소개와 설치·성능 증거를 구분했다. 실제 문제 규모·현행 법령·위탁 전체·최종 계약·API·설치 버전·가용인력·견적은 미검증 또는 협의 전이다.
- 자동차검사 예약 불편은 사용자 경험이며 현행 화면에서 재현하지 않았다. 2026년 이륜차 공고의 일부 신청연도 표기 혼재와 공급사 Grantee 당일 열람 실패를 근거원장에 남겼다.

## 자동 검증

- 문서·데이터·HTML 검사 **137개 통과 / 실패 0개**. 결과: [자동검증 원본](검증/자동검증_결과.json).
- HTML 24개를 Edge에서 실제 열었다. 내부 파일 링크 330개 출현과 앵커 528개 출현을 검사했다. 고유 링크 수와 다르다.
- 통합표 22행과 44개 개별 파일 링크, 분류·검색·판단 결합 필터, 빈 결과와 초기화, 키보드 본문 이동을 확인했다.
- 통합표·개별 목차를 클릭한 뒤 해당 절의 실제 화면 도착 위치를 검사했다.
- 1440px·768px·390px에서 문서 전체의 가로 넘침을 검사했다. 넓은 표는 내부 좌우 스크롤로 제공하고 모바일 키보드 스크롤을 확인했다.
- 요구사항 88개의 ID·기획·시험 설계 연결을 확인했다. 기획서에 설계된 제품 시험 110개(22×5)는 모두 미수행이다.
- 파일명 공백으로 Markdown 링크가 해석되지 않을 가능성을 발견해 각괄호 링크 형식으로 보완하고 위 검증을 수행했다.

## 화면 직접 확인

다음 4개 화면 이미지를 직접 열어 읽었다. 이미지 파일 생성 자체를 시각 확인으로 간주하지 않았다.

- [통합 데스크톱](검증/01_통합_데스크톱.png): 제목·설명·비교표·필터의 정보 순서와 여백 확인.
- [P13 요구사항](검증/03_P13_요구사항.png): 요구사항·입력·데이터·책임 표의 본문 표시 확인.
- [모바일 분류 필터](검증/05_통합_모바일_필터.png): 입력 레이블·초기화·결과 수·표 스크롤 안내 확인.
- [P13 모바일](검증/06_P13_모바일.png): 제목 줄바꿈·목차·본문·표 스크롤 안내 확인.

문서 탐색에 중대한 겹침·누락은 발견하지 않았다. 표는 모바일에서 좌우 이동이 필요하다. 스크린리더·브라우저 인쇄 출력·전체 WCAG 2.2 AA 적합성은 별도로 검증하지 않았다. 제안된 서비스 화면은 기획 개요이며 제품 프로토타입 구현물이 아니다.

## 기획 QA/QC 판정

**기획 문서 전달: 자체 검토 통과. 실제 사업 착수: 조건부 검토.** 외부 또는 독립 평가위원의 승인으로 표시하지 않는다.

| 점검 항목 | 확인 결과 |
|---|---|
| 기관 | TS 업무 목록에 연결. KoROAD·운전면허 갱신·신호 운영을 TS 신규 업무로 전용하지 않음 |
| 기술 | NOA·로컬 LLM·전자문서/정형 결과 중심. 비전·OCR·STT·TTS·센서·차량제어 제외 |
| 중복 | 기존 SFR-001~009 정리자료와 비교할 범위를 명시. 최종 계약 판정은 미완료 |
| 수행 현실성 | 단일 업무·문서·규칙·인터페이스 물량을 가정으로 제시. CCK 인력·사용권·API 확보는 확정하지 않음 |
| 비용 | 신규 인프라 0원. 1차 7억·2차 추가 5억은 전체 프로그램 상한 검토안 유지. 22개 구축 견적 아님 |
| 사업 통합 | P17은 P01, P22는 P21 부속 과업 검토. 독립 예산 합산하지 않음 |
| 운영·안전 | 사람의 최종 판단·권한·상태 확인·실패 복구·버전 복귀를 설계. 사고 감소나 적합 자동 판정 보장 없음 |
| 기존 자료 보존 | 루트·이전 조사 README와 기관 원장에 새 자료 링크 추가. 후보 수·타 기관·법정 관계·모집단 상태 보존. 파일 삭제 없음 |

## 후속 검증

[업무별 후속 확인 대기열](05_후속확인_대기열.md)에 최종 계약, 실제 데이터·문제, 제품·사용권·서버 여력, 연계 계약, 가용인력, 비AI 비교, 견적 산정 조건을 남겼다. P13의 실제 보완 사례를 먼저 확보할 근거가 있으나 수요·사업 선정·발주 승인은 아직 확정하지 않았다.
