# 예산 제약을 반영한 수정 계획

2026-09-10. 사용자 최신 제안은 1차 약 7억 원, 2차 약 5억 원이다. 부가세 포함 목표 상한으로 가정한다. 예산 확보·발주 승인·CCK 견적이 아니다.

작업 유형은 기존 기획·산정 문서 수정, 규모 M, 위험도 Medium이다. Stage Gate와 요구사항 추적을 적용해 예산 → 납품 범위 → 요구사항 → WBS → 계산을 맞춘다. 서비스 소프트웨어 구현·운영 배포와 독립적인 사업 승인 심사는 이번 문서 작업에 포함하지 않는다.

1. v0.1 전체 확장안과 원본은 보존한다.
2. 1차 X02·X04 제한 적용, 2차 X01 예약 일정 탐색 및 앞선 서비스의 읽기 연계로 축소한다. X03·X05와 외부 예약 확정은 이연한다.
3. 공수·품목을 다시 쌓아 계산하고 목표 상한과 차액을 별도로 표시한다. 남는 예산을 임의 비용으로 채우지 않는다.
4. 정의서 2종·명세서·RFP·비용 설명·Excel·HTML을 같은 범위로 갱신한다.
5. 산식·입력 변경·Excel 재계산·Word 페이지·HTML 반응형 및 링크를 검사한다.

핵심 가정은 기존 로컬 GPU·망·인증 기반 제공, CCK 재사용 권리와 로컬 적합성, 공식 텍스트 제공, 2차 읽기 API 협조다. 미충족 시 재견적하거나 서비스 범위를 추가 축소한다. 새로운 GPU 서버 구매를 무료로 간주하지 않는다.

검토용 산출물의 자체 QA와 CCK 수행능력·TS 인수·독립 평가위원 승인은 구별한다. 이전 파일로 되돌아가면 문서 수정 롤백이 가능하다.
