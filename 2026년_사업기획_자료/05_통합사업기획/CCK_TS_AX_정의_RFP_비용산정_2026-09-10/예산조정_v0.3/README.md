## 확인과 한계

Word 4종의 전체 페이지 배치를 Microsoft Word PDF 변환과 Poppler 이미지로 확인하고, Excel은 독립 계산·입력 변경·상한 초과·누락·실제 Excel 재계산을 검사한다. 최종 실행 결과는 검증/QA_결과.md에 기록한다. 사용자 시험·제품 성능·사업 투자 판정·독립 평가위원 승인은 수행하지 않는다.

## 이전 버전과의 관계

상위 폴더의 v0.1과 형제 폴더의 v0.2는 이력으로 보존한다. v0.2 대비 저장·백업 보완비 3천만 원(VAT 제외), 연간 장비 보증·백업 자원 증분 4,000,004원(VAT 제외)을 제거했다. 이번 RFP에는 v0.3 요구를 사용하며 v0.1 확장 과업을 합산하지 않는다. 현재 브라우저 진입점에는 새 버전 안내를 추가한다.

## 다음 확정 입력

기존 서버 실측 용량·로그인 권한, CCK 재사용 모듈·사용권·인력, 기존 계약 비중복, 원천 읽기 API, 품목 견적, 감리·영향평가 적용과 전체 예산 포함 여부를 확인한다.

## 방법과 재현

Stage Gate와 요구사항 추적으로 기존 조사·범위·검수·가격을 연결했다. 제작_문서.py → 제작_비용.mjs → Word/Excel/HTML 검증 → 제작_안내.py로 갱신한다. 계산의 원 자료는 사업정의_데이터.json이며 Word·HTML은 작성 시점 값이다.
