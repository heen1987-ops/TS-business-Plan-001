0. 기구축 기반의 CCK AI 적용·중복 재판정

2026-09-15 사용자 정정에 따라 기존 시스템·업무·안내·AI 사업의 후속 적용도 기획 대상에 포함했다. 이전의 추가 가치 선확인를 기구축 업무 AI 적용로 재판정했다. 이번 기획 판정이며 제품 동작·계약 중복을 확정한 결과는 아니다.[49]

구분 이번 적용안
기존 기반 ETAS 위험운전 분석·진단표·교육 전후 결과
CCK AI 추가 적용 공식 수치·기간의 맥락 설명, 질의응답·맞춤 실천 문답

비용 처리 기존 자산 구매비·이미 계약된 동일 납품분은 추가 개발비에서 제외. 실제 설치·설정·지식 정비·연계·검증·운영 추가 작업은 산정 가능

판정 이유: 기존 분석은 재사용하고 해석·후속 교육에 CCK AI를 추가하는 사업으로 검토.

1. 실제 업무와 기획 대상

확인된 업무: ETAS 위험운전 분석, TAGO·TIMS·자동차 정보 등. [9][3]

수행 근거와 경계: ETAS 공식 서비스와 교통안전법 제55조 안내 확인. 개인 운행정보의 목적·권한 검토 필요. 업무의 존재와 새 AI 과업의 발주 필요성은 별도 판단이다. 페이지의 법령 인용은 조사 출발점이며 현행 법령·위탁·사무분장을 모두 대조한 법률 검토 결과가 아니다.

공식 업무 중 이번 초기 범위: ETAS 결과 유형 1개·승인된 안전지침 1개, 조회 1개, 다른 정보시스템은 후속. 나머지 세부 업무는 이번 최소 구축 범위에 넣지 않고 동일 묶음의 후속 검토로 둔다.

2. 국민·현업 문제와 WHY

  • 문제의 근거 수준: 기존 운행분석 결과를 실제 교육·조치로 이해하고 활용하기 어렵다는 가설.
  • 설명용 상황: 운전자가 위험행동 횟수는 보지만 어떤 상황·지침과 연결해 개선해야 할지 묻는 상황. 실제 관찰·면담 결과로 일반화하지 않는다.
  • 국민 가치: 잘못된 안내·보완 누락·처리 실패를 줄이고 근거를 확인할 수 있게 한다. 안전 업무에서는 검토의 질을 높이는 경로를 검증하며 사고 감소를 직접 보장하지 않는다.
  • 공공 개입 이유: 법정 절차·공공 안전서비스에서 이용자의 정보 격차와 업무 실패를 줄일 필요가 있다.
  • 왜 AI인가: 기존 ETAS 진단표·교육 전후 비교·정형 해설만으로 해결되지 않는 자유 서술의 조건 해석·근거 연결이 있는지 비교한다. 같은 효과가 나면 AI 개발 범위를 줄이거나 제외한다.
  • 수요 확인: 공식 분석 결과 샘플·기존 설명 수준·교육 사용 사례.

3. 현재 흐름과 변경할 행동

현재 업무는 공식 안내에서 확인했지만 실제 화면 조작·처리시간·오류 발생률은 현장 확인 전이다. 아래 변경 흐름은 제안이다.

  1. 확정된 ETAS 지표와 산출 조건을 조회.
  2. 해당 결과와 승인된 교육 지침을 연결.
  3. 설명·실천 질문·교육 후 확인 항목을 제시.
  4. 교육 담당자가 상황을 검토해 사용하고 결과를 피드백.

최종 산출물은 근거 있는 결과 해설과 교육 담당자용 질문 목록이다. LLM의 자연스러운 답변이나 문서 생성 자체를 업무 완료로 표시하지 않는다.

4. 서비스 범위와 요구사항

요구사항 ID 수행할 기능 수용기준 초안

TS-P16-F4 교육 담당자가 상황을 검토해 사용하고 결과를 피드백 입력·근거·사용자 또는 담당자 확인·결과 상태가 추적되고 미확인 값은 미확인으로 유지
  • 핵심 입력: 확정 ETAS 결과·산출 기간/단위·교육 지침·검토 기록.
  • 결과: 근거 있는 결과 해설과 교육 담당자용 질문 목록.
  • 초기 물량: 2개 문서 유형, 1개 규칙·지침 묶음, 1개 조회 인터페이스, 0개 처리·인계 인터페이스를 상한 가정으로 견적 확인한다. 실제 API 개수나 제공 사실이 아니다.
  • 제외: 비전·OCR·STT·TTS·센서·차량제어·검사설비, 자동 법적·안전 판정, 기관 간 원본 데이터의 포괄 통합.
  • 입력 제한: 텍스트 전자문서·승인된 정형 결과만 사용한다. 스캔·사진 필수자료는 기존 공식 제출경로에서 사람이 확인하며 전체 제출절차를 AI가 완결했다고 표시하지 않는다.

5. 데이터·NOA·SI 및 책임

계층 역할·범위 확보 상태
데이터 확정 ETAS 결과·산출 기간/단위·교육 지침·검토 기록 담당부서 허용·표본·품질·용도 확인 전
NOA·로컬 LLM 입력 서술의 구조화·검색·근거 설명·근거 있는 결과 해설과 교육 담당자용 질문 목록 초안 공급사 설명과 내부 대장 참고; TS 버전·실행·사용권 검증 전
업무 규칙·SI 결과 조회·단위/기간 검증·운전자 권한·설명 버전 인터페이스·권한·변경 협조 미확정
사람 사실 정정, 보완·적격·안전·공개·발송의 최종 확인 데이터융복합처·안전교육 담당자와 실제 분장 협의 필요
CCK 주관 범위 요구사항·NOA 구성·업무 모듈·연계·검수·운영 인수 총괄 담당 인력·가용률·납품계약 확인 전

NOA 공개 소개는 폐쇄망·업무 연결·감사·사람 검토를 설명한다. 특정 기능이 현재 TS 설치물에서 동작한다는 증거와는 다르다. 내부 대장의 기재와 현재 정정도 원 코드·사용권·실행 시험을 대신하지 않으므로, NL2SQL·승인 중단/재개·자동 재실행을 기본 보유 기능으로 확정하지 않는다.[33][44][45][46]

기존 운영사에는 결과 조회·단위/기간 검증·운전자 권한·설명 버전의 계약·인터페이스 협조를 요청하는 역할안을 둔다. 협력사 확보나 기관 협조가 완료됐다는 뜻은 아니다. 초기에는 조회·검토 결과 생성까지 제한하며 기존 시스템의 결정·상태 변경은 담당자가 수행한다.

6. 대안·중복과 현재 판정

대안 범위·효과 가설 비용·기간 영향 판단
현행 유지·운영 개선 기존 ETAS 진단표·교육 전후 비교·정형 해설 신규 구축 최소; 반복 문제 잔존 여부 확인 유효한 비교 기준
SI·규칙 개선 입력·식별자·상태·원문 검색 정비 연계·데이터 정비 필요, LLM 운영 부담 없음 같은 목표를 달성하면 우선 적용
NOA+SI 근거 있는 결과 해설과 교육 담당자용 질문 목록와 검토 흐름 문서 정비·AI 평가·연계·운영 비용 추가 기구축 업무 AI 적용

중복 대조: TS-BIZ-002, ETAS, SFR-003005, L21과 교육 연계; 기구축 업무의 존재는 제외 사유가 아니며 기존 기능 재사용과 추가 AI 적용분을 구별. 비교 단위는 업무·대상자·입력 데이터·기능·산출물·성과다. SFR-001009 정리자료에는 공통 기반·직무 특화·민원·전세버스 AI 요구가 기재되어 있다. 동일 납품 기능은 기존 계약 이행·재사용으로 묶고, 새 적용 업무·변경 기능·연계·지식 정비·평가 등 추가 수행분을 사업 범위로 산정한다. 기구축 또는 같은 업무라는 이유로 적용 대상을 제외하지 않는다.[43][31]

현재 판단: 기구축 업무 AI 적용 — 기존 분석은 재사용하고 해석·후속 교육에 CCK AI를 추가하는 사업으로 검토. 이번 판정은 CCK AI 적용 검토 방향이다. 최종 계약의 추가 범위·제품·수요·견적을 확인한 뒤 실제 발주·수행 범위를 확정한다.

8. 성공지표와 시험 설계

핵심 지표는 수치·기간 설명 오류·교육 내용 이해·담당자 수정량다. 기준값은 미측정이며 임의의 달성률을 쓰지 않는다. 같은 업무 사례에서 현행/비AI와 NOA+SI를 비교하고 입력·모델·규칙·동시성·문서 버전을 기록한다. 표본과 목표 개선폭은 실제 자료와 피해 수준을 보고 실증 전에 정한다.
