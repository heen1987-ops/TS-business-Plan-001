## 기획 기준과 남은 근거

| 기준 | 현재 적용 방향 | 다음에 필요한 근거 |
|---|---|---|
| P01 국민 편익 | 공공서비스 연속성과 이행 품질 | 실제 서비스와 수혜 집단, 운영 공백·불편 자료 |
| P02 현업과 직무 | 검토·인수인계 부담 완화 및 사람의 판단 유지 | 현업 시간·수용성·직무 변화와 절감시간 활용 |
| P03 AI 추가 가치 | 기존 PMS·규칙 SI·NOA 결합 비교 | 같은 사례에서 순시간·품질·예외 비용 비교 |
| P04 문제와 업무 | 인력 교체·자료 분산·보완 지연 가설 | 기관 실제 사례와 최신 업무 현황 |
| P05 확산 | 공통 검사 절차와 기관별 규칙·권한 분리 | 기관별 법정 역할·도입 조건·증분 비용 |
| P06 권한과 조직 | 기관 계약·승인·관리 책임을 원장에 연결 | 실제 발주기관·수행부서·위탁 관계의 적용 근거 |
| P07 재정과 책임 | 비용·근거·소명·사람 승인 연결 | 확정 물량·사용권·예산·심의 및 검수 조건 |

공공 PMS 기획은 TS 22개 업무별 기획과 별도 관리한다. 독립 R&D로 전환하거나 기관 간 자료 공유 권한이 확보된 것으로 취급하지 않는다.

## 변경 관리

새 설계 문서에는 요구사항 ID → 유스케이스 → 화면 → 업무규칙 → 논리 인터페이스 → 데이터 → 권한 → 수용 시나리오를 연결한다. 실제 API가 확인되지 않은 항목은 제안 연계 계약으로 표시한다. 구조화 원장의 현재 52개 ID와 기존 보류 상태는 검토 없이 변경하지 않는다.
