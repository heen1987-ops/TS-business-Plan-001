## 2. 현행 기반과 고도화 목표

ETAS 위험운전 분석·진단표·교육 전후 결과을 이용하는 업무에 ETAS 결과 연계·단위 검증·지침 연결·해설 평가 항목을 추가한다. 현행 내부 화면·소요시간·API를 직접 시험한 것은 아니다. 아래 흐름과 오류 처리는 **제안 설계**이며 현업 워크숍에서 실제 절차와 대조한다.

대표 상황: 운전자가 위험행동 횟수는 보지만 어떤 상황·지침과 연결해 개선해야 할지 묻는 상황

| 현행 기반 활용 | 고도화할 처리 | 유지할 공식 책임 |
| --- | --- | --- |
| ETAS 위험운전 분석·진단표·교육 전후 결과 | 확정된 ETAS 운행분석 지표를 운전자가 이해할 수 있는 설명과 실천 질문으로 바꾸는 교육 지원 | 기존 업무의 자격·검사·예약·지급·공개·안전 판단 권한 |
| 기존 ETAS 진단표·교육 전후 비교·정형 해설 | 공식 수치·기간의 맥락 설명, 질의응답·맞춤 실천 문답 | 원천 데이터·적용 기준의 승인과 검토자 확인 |


국민에게 기대하는 가치는 정확한 다음 행동과 보완 필요를 더 빨리 이해하거나, 담당자의 검토 누락을 줄이는 것이다. 다음 지표를 측정해 확인한다: 수치·기간 설명 오류·교육 내용 이해·담당자 수정량. 업무시간 절감을 감축 인원으로 환산하지 않는다. 사고 감소·무사고를 이 기능만으로 입증했다고 주장하지 않는다.

## 4. 처리 흐름과 화면

공식 결과 읽기 → 단위·비교조건 검증 → 근거 지침 연결 → 설명·질문 초안 → 교육 담당자 검토 → 사용·피드백. LLM은 위험도 재계산을 하지 않는다.

| 순서 | 사용자·시스템 동작 | 처리 책임 |
| --- | --- | --- |
| 1 | 설명에 쓰는 수치는 ETAS 확정 결과에서 가져온다. | LLM은 제안·설명, 규칙·권한·원천 상태는 응용 계층에서 검증 |
| 2 | 기간·거리·지표 정의가 다른 결과는 직접 증감으로 비교하지 않는다. | LLM은 제안·설명, 규칙·권한·원천 상태는 응용 계층에서 검증 |
| 3 | 공식 지표와 승인 교육지침을 연결해 실천 질문을 만든다. | LLM은 제안·설명, 규칙·권한·원천 상태는 응용 계층에서 검증 |
| 4 | 교육 담당자가 문구·적용 상황을 검토한 버전만 사용한다. | 사용자/현업 확인 후 공식 시스템의 권한 유지 |


화면 TS-P16-S01은 **입력·조건 → 근거를 포함한 결과 → 사용자/담당자 확인 → 다음 처리** 순서로 구성한다. 원문 위치와 적용본은 결과 옆에서 확인하고, 확인 전 초안과 확정된 원천 상태를 구분한다. 모바일은 입력·결과·확인을 세로로 배치하며 조건을 잃지 않는다.

| 화면 상태 | 필수 동작 |
| --- | --- |
| 대기·조회 중 | 입력을 보존하고 진행 단계 표시; 확정 버튼 중복 실행 방지 |
| 자료 없음·일부만 확인 | 없는 항목과 미확인 사유, 가능한 다음 행동 표시 |
| 권한 거부 | 자료 내용을 노출하지 않고 권한 요청 또는 기존 창구 안내 |
| 오류·시간 초과 | 현재 처리 결과를 확정하지 않음; 원 상태 재조회 후 재시도 |
| 정상 결과·확인 대기 | 근거·적용본·한계를 읽고 사용자가 선택 또는 담당자가 수정 |
| 이관·확정·반려 | 공식 응답이나 담당자 결정 이력으로 상태 구분 |


화면 상세 디자인과 API 실주소는 별도 구현 단계에서 확정한다. 키보드 입력·오류 초점·상태 읽기와 모바일 조건 유지가 제품 인수 시험 대상이다.

## 5. 데이터·출력 계약

아래 필드명은 **논리 설계 예시**다. 실제 원 시스템 필드·API가 존재한다는 뜻이 아니다. 필드별 필수 여부·보존기간·마스킹·추출 가능성을 원천 담당자와 매핑표로 확정한다.

| 입력 논리 항목 | 연결·검증 규칙 |
| --- | --- |
| analysis_ref / vehicle_group | 허용된 ETAS 결과 참조·대상 범위 |
| period / distance / unit | 산출 기간·주행거리·지표 단위 |
| indicator_code / value | 공식 분석 코드·확정 수치 |
| comparison_basis | 비교 가능 조건과 불일치 항목 |
| guideline_ref / revision | 승인 안전지침·교육 자료 |
| educator_approval / feedback | 교육 담당자 승인·수정·후속 확인 |


출력은 다음 항목을 묶고 각 항목에 원문 참조·버전·확인 상태를 붙인다.

- 수치·단위를 보존한 결과 설명
- 산출 조건과 비교 제한
- 지표에 연결된 승인된 안전행동
- 교육용 질문·실천 확인표
- 교육 담당자 수정 이력

공통 메타데이터: case_id, source_refs, source_version, retrieved_at, rule_version, model_config_version, review_status, reviewer_action. 여기의 review_status는 제안 기능의 상태이며 법정·업무 처분 상태를 대신하지 않는다.

ETAS 확정 분석 결과 읽기 1개를 우선한다. 원시 운행데이터의 신규 분석·예측은 별도 구축하지 않는다. P21/P22의 교육 출력·검토 기능과 연결 가능하나 이륜차 ETAS 데이터 존재를 가정하지 않는다.

자료가 없으면 승인된 파일 반입·공개 지식만으로 가능한 1단계까지 수행한다. 개인 데이터 조회·쓰기 연계가 필요한 후속 단계는 실제 인터페이스와 권한이 확인돼야 개발 범위를 확정한다.

## 8. 데이터 주권·안전·운영

지표 해설이 새로운 안전 진단처럼 읽힐 위험. 출처 수치와 해석 문장을 분리하고 제한조건을 함께 표시한다.

- 자료 원본·검색 인덱스·모델 호출·로그·백업·라이선스 경로를 기존 서버 환경에서 점검한다. 로컬 배치라는 이유만으로 외부 전송이 없거나 보안이 충족됐다고 단정하지 않는다.
- 문서 안의 명령·외부 링크는 근거 데이터로 취급하고 실행 지시로 사용하지 않는다. 인용 권한은 검색과 원문 열람 모두에서 검증한다.
- 기준·문서 변경과 접근 철회 시 결과를 재확인 대상으로 전환하고 인덱스 갱신·삭제 전파 방법을 검증한다. 보존기간과 삭제 권한은 TS 정책 확인 후 설정한다.
- 기존 업무 화면을 복귀 경로로 보존하고 AI 기능만 비활성화할 수 있게 한다. 쓰기 도입 시 요청 식별자·상태 재조회·승인·중복 방지·복구 담당을 계약에 명시한다.

법정업무 확인 범위: ETAS 공식 서비스와 교통안전법 제55조 안내 확인. 개인 운행정보의 목적·권한 검토 필요. 실제 현행 조문·위탁 관계·개인정보 처리 근거의 최종 적용 검토는 착수 전 확인 항목이다.

## 10. 작업분해·증분 공수·비용

**업무별 증분 23–38인일(1인일=8시간 계획 기준).** 실측 견적이 아닌 기획자 가정 범위이며 공통비·사용료·운영비는 포함하지 않는다. 최초 적용 단위와 공통 기능 재사용을 전제로 한 1회 개발·검수 추정이다. 9절의 업무 내 1·2단계에서 WBS에 명시한 기본 설정·연계까지를 포함하며, 3단계의 추가 유형·기관 확대는 포함하지 않는다. 업무 내 단계 번호는 프로그램의 1차 7억·2차 5억 예산 연도와 직접 대응하지 않는다.

산정 근거: ETAS 결과 유형 1개·승인된 안전지침 1개, 조회 1개, 다른 정보시스템은 후속. 개발 물량은 전자문서·규칙팩·읽기/인계 단위와 위 추가 작업이다. API별 실주소·문서량·문맥 길이·동시성·품질 난도는 미확정이므로 하한/상한의 확률 의미는 없다. API 신설·문서 전수 정비·추가 자격·추가 기관·확장 단계는 재산정한다.

비용 산식: **업무 증분 인건비 = 역할별 확정 인일 × 확인한 역할별 일단가의 합. 해당 사업비 = 공통 기능 비용 1회 + 선택 업무 증분 + 확인된 증분 사용료·필요 경비 + 계약 방식에 따른 제경비·이윤·세금.** 단가에 포함된 항목을 다시 더하지 않는다.

P21·22와 교육 자료 생성 부분 공유; ETAS 결과 조회·해석은 P16이 담당 기존 계약의 동일 납품분과 공통 모듈은 신규 작업으로 중복 청구하지 않는다.

신규 서버·GPU·저장/백업/망 구매·증설·임차·클라우드 비용은 **0원**이다. 기존 환경의 설정·연계·부하 시험은 수행 공수에 포함 가능하다. 모델 사용권·제품 라이선스가 기존 계약에 포함되는지는 확인 전이며 무상으로 단정하지 않는다. 추가 사용료가 필요하면 비용·대안을 확정하고 상한 안에서 범위를 조정한다.

1차 7억·2차 추가 5억 원은 **전체 프로그램 목표 상한(VAT 포함 해석)**이다. 이 보고서 단독 금액도, 22개 전부를 포함하는 확정 견적도 아니다. 실제 금액·분배·일정은 선택 물량과 확인 단가로 확정한다.
