# CCK 솔루션·로컬 LLM 기반 TS 신규사업 적용 기준

2026-09-15 · v2.0 · 사용자 추가 정정 U-CCK-01·02·03 및 U-INFRA-01 반영. TS의 공식 승인이나 제품 성능 검증 결과가 아니다.

2026-09-15 추가 기준: [기구축 사업의 CCK AI 적용과 중복판정](기구축사업_CCK_AI_적용과_중복판정.md)을 적용한다. 이전의 기구축 업무·후속 확장 일괄 제외 해석을 사용하지 않는다.

## 1. 기획 질문

**CCK가 주관·총괄 수행사로서 자사 솔루션과 로컬 LLM을 바탕으로 수주·구축·검수·운영까지 책임질 수 있으며, 국민의 편의·안전을 개선하는 사업은 무엇인가?**

사용자 추가 정정 U-CCK-02의 “주마더사”는 문맥상 주관·총괄 수행사를 뜻하는 것으로 해석했다. 실제 수행 가능성을 필수 선정 조건으로 둔다. LLM 적용 가능성과 CCK의 주관 수행 가능성을 따로 판정한다. 세부 사업별 자격·인력·일정·원가·협력·납품 증거를 확인하지 않은 상태를 “CCK 수행 가능”으로 표시하지 않는다.

국민 문제 → TS 실제 수행업무 → 필요한 언어·지식·절차 처리 → CCK 자산과 로컬 LLM 적합성 → 데이터·규칙·API의 부족분 → 기존 과업 중복 → 작은 검증 순서로 본다. 메가이슈는 문제를 찾는 배경이며 기술 범위를 넓히는 근거가 아니다. 설명의 첫 문장은 국민이 얻는 변화로 쓴다.

사용자가 확정한 기술 방향은 **CCK 솔루션 기반, 로컬 LLM 사용, 비전 기반 과제 제외**다. 특정 모델·GPU·제품 버전·모든 모듈의 로컬 동작 가능성까지 확정된 것은 아니다.

**U-INFRA-01 — 사용자 확정 인프라 제약(2026-09-10): 기존 로컬 서버를 사용하며 신규 인프라 투자비는 0원이다.** 신규 GPU·서버·저장·백업·망 장비의 구매·증설·임차와 클라우드 자원비를 신규 사업비에 넣지 않는다. 응용 SW 개발·기존 환경 배포 설정·연계·검수·데이터 복원 시험 공수는 구별해 산정한다. 기존 장비 유지보수와 자원 증분도 이번 용역비에 계상하지 않는다. 기존 자원 용량은 실측 전이며 부족할 때 대기열·모델 설정·동시성·자료량·업무 범위를 조정하고 품질을 재검수한다. 인프라 0원은 TS 자산의 소유권·사용권 또는 성능 검증 완료를 뜻하지 않는다.

## 6. 검증 기준

- 동일 과업에서 현행·규칙 기반 개선·CCK+로컬 LLM 구성을 비교한다. 클라우드 모델이나 비전 성능을 로컬 LLM 성능으로 대체하지 않는다.
- 근거 일치, 필수 조건 보존, 확인 질문의 적절성, 조치 누락·사실 왜곡, 실제 업무 완료와 실패 복구를 측정한다.
- 해당 로컬 모델·양자화·문맥 길이·GPU·동시 요청 조건에서 품질·응답시간을 측정한다. 아직 모델 선정·실측·개선율 목표 확정은 하지 않았다.
- 가용정보를 받지 못하면 조회 불가를 표시하고, 실행 응답 없이 완료를 생성하지 않는다. 승인·확정 흐름과 감사 기록은 실제 구현으로 검증한다.

현재 판정: **기획 범위 반영 완료 / 제품 기능·로컬 호환성·사업 적합성 검증 전**.

## 7. CCK 주관 수행 가능성 — 필수 선정 조건

주관 수행은 모든 구성요소를 CCK가 직접 개발한다는 뜻이 아니다. 협력사와 구축할 수 있으나 핵심 솔루션, 전체 설계·통합, 품질·검수와 납품·운영 책임을 CCK가 통제할 수 있어야 한다. 이 역할은 기획상의 책임 배분안이며 실제 조직·인력·협력사 확보를 확인한 것은 아니다.

| 검토 항목 | 후보가 제시해야 할 근거 |
|---|---|
| CCK가 주관할 이유 | 국민 문제 해결의 핵심에 CCK 지식검색·로컬 LLM·검토·업무 실행 자산이 들어가며, 단순한 챗봇 납품이나 일부 모듈 공급에 그치지 않는지 |
| 핵심 기능의 실재 | 버전·실행 데모·코드·사용권, 재사용/설정/연계 개발 범위. 타 도메인·클라우드 실적을 TS 로컬 수행 실적으로 옮기지 않음 |

### 판정과 후보 처리

- **주관 수행 검증 전:** 핵심 자산·자원·연계·원가·검수 근거가 아직 부족. 지금의 A/B/C는 이 상태다.
- **CCK 주관 후보:** 핵심 기능·자원·의존성·납품·검수·운영 근거가 확보돼 실제 제안 범위를 설명할 수 있음. 수주·기관 승인 확정은 아님.
- **협력 조건부 주관 후보:** 핵심은 CCK가 통제하되 명시한 협력 범위와 확보 조건이 남음. 협력 가능성을 확보 사실로 표시하지 않음.
- **범위 축소·보류·제외:** 핵심이 비전·센서·차량 제어·물리적 안전진단이거나 타사 핵심 기술에 종속돼 CCK가 품질·납품을 통제하기 어려운 경우. 업무 접근권한·경제성 부족도 보류 사유로 남김.

협력사에게 제외 기술을 맡긴다는 이유로 비전·센서 중심 사업을 다시 포함하지 않는다. CCK가 소프트웨어 구축을 총괄하더라도 법정 안전판정과 기관 의사결정을 대신하는 것은 아니다.
