# 기구축 사업의 CCK AI 적용과 중복판정

2026-09-15 · 사용자 정정 U-CCK-03. 이 기준은 과거의 “기존 사업 후속 확장 제외”보다 우선한다. 기관 승인·계약 검토·제품 성능 증거는 아니다.

## 현재 기획 범위

**기존에 구축된 사업·시스템·안내·상담·업무에도 CCK AI를 적용하는 사업을 기획한다.** 기존 AI의 후속 적용·기능 개선도 포함한다. 완전히 새로운 업무여야 한다는 조건은 두지 않는다. 현재 표현한 CCK AI는 이전에 합의한 NOA·로컬 LLM 기반으로 해석한다.

CCK 주관 수행, 기존 로컬 서버, 신규 인프라 투자 0원, 비전·신규 센서·장비·제어 제외는 유지한다. 독립 R&D는 대상이 아니며 필요한 PoC는 AX+SI 적용 과업 안에서 수행한다.

## 중복의 구분

| 구분 | 판단 | 처리 |
|---|---|---|
| 기존 업무·시스템·데이터가 있음 | AI를 적용할 기반 | 기존 기능·DB·규칙·화면·분석 결과 활용 |
| 기획안끼리 기능·대상·산출물이 겹침 | 통합·모듈 재사용 검토 | 공통 기능 1회 + 업무별 지식·연계·검수 증분 |
| 이미 계약된 동일 AI 납품 기능 | 계약 이행·재사용 범위 | 같은 납품물을 다시 추가 개발비로 산정하지 않음 |
| 기존 AI의 새 업무 적용·기능 개선 | 적용/고도화 사업 가능 | 적용 대상·변경 기능·산출물·버전·품질 목표·추가 작업량을 명시 |

중복은 업무·이용자·입력 데이터·기능·산출물·성과·납품 버전을 함께 비교한다. 업무명이 같거나 RAG·챗봇·로컬 LLM을 함께 쓴다는 이유만으로 동일 사업으로 판정하지 않는다. 같은 공통 엔진을 쓸 수 있어도 업무 규칙·자료 권한·검수 책임이 다르면 업무 모듈은 별도 유지한다.

## 사업·원가 구성

기존 기반 → CCK AI가 추가로 수행할 일 → 재사용할 기능 → 새 지식·설정·화면·연계·검증 작업 → 실제 납품물·효과로 정리한다.

공통 구성 1회분 + 업무별 추가 수행 공수 + 확인된 증분 사용료·운영비로 견적을 구성한다. 기존 제품을 사용해도 새 환경 적용을 위한 설정·튜닝·데이터 정비·통합·시험·교육은 수행비로 산정할 수 있다. 이미 계약된 동일 기능·기존 시스템 원가를 다시 새 개발비로 계상하지 않는다. 계약 변경·별도 발주 여부는 발주자와 최종 범위를 보고 판단한다.

1차 7억·2차 추가 5억은 VAT 포함 해석의 기존 목표 상한이며 22개 전체의 구축 견적이 아니다. 신규 인프라 0원은 유지한다. 실제 품질·현업 효과·서버 여력에 따라 적용 크기를 정한다. 안내·상담도 적용 대상이며 작은 기능은 공통 모듈로 제안할 수 있다.

## 이전 판정의 취급

2026-09-14의 22개 초안과 TS-BIZ의 5검토·2유보·1제외는 이력이다. 기존 안내·민원·구축 사업이라는 이유의 유보·제외를 자동 승계하지 않는다. 현재 22개 적용 판단은 [v0.2 재판정 원장](../05_통합사업기획/TS_22개업무_사업기획_2026-09-15_v0.2/07_AI추가적용_재판정.json)을 따른다. 그 원장은 발주·수주·제품 실증을 승인한 목록이 아니다.

전세버스 등 현재 수행 중인 동일 AI 과업은 기존 계약 이행으로 구분한다. 기구축 시스템의 별도 추가 적용·개선까지 일괄 제외하는 규칙은 사용하지 않는다. 22개 밖의 과거 후보 전체가 자동으로 선정됐다는 뜻은 아니다.
