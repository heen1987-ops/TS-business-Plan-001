## 0. 이 문서의 위치와 한계

사용자가 이 세션과 별도로 오늘 오전 진행한 분석(TS 공식 "AX 주요과제 12선" 인포그래픽 판독 → CCK 신규후보 발굴 → CCK 자체 제안서 2건 기반 제품철학 재정렬)을 이 프로젝트(`[TS] 사업기획`)에 편입하고, 기존 N-코드·컨셉카드·N-08B·22개업무 자산과의 정합성을 검토한 문서다.

## 2. 신규후보 발굴 — 두 라운드

### 2.1 1라운드: 12선 자체를 CCK가 보완하는 서비스 6종 (기존 12과제의 "그다음 단계" 제안)

12선을 대체하는 게 아니라, ⑪·⑫가 이미 확보한 근거검색·데이터기반 위에 "분석결과 → 검토 → 조치"까지 잇는 계층을 CCK가 담당한다는 구도.

| 서비스 | 하는 일 | 연결되는 기존 과제 |
|---|---|---|
| ① 안전점검·사고자료 데이터화 에이전트 | 점검보고서·사고조사서에서 발생일·장소·위험요인·조치사항 추출, 통합대장 생성 | ⑪의 확장 |
| ② 근거 기반 점검·검토 에이전트 | 점검자료를 지침·기준·과거사례와 대조해 검토항목·누락·점검계획서 초안 작성 | ⑪·③의 확장 |
| ③ 교통분석 결과 질의·보고 에이전트 | 승인된 사고통계·위험도·점검이력 조회, 비교표·검토보고서 작성(위험점수 임의생성 금지) | ②·④와 연결 |
| ④ 기준 기반 국민안내 에이전트 | 이용자 질문을 조건으로 정리해 공식기준과 대조, 근거 붙은 안내 | ⑤의 기준검색·안내 부분과 연결 |
| ⑤ 위험지점 개선·조치관리 에이전트 | 위험분석 결과로 현장점검표·개선검토서·조치요청서 생성, 상태관리 | ②③④ 및 현장안전관리 후속 |
| ⑥ 데이터 자산 탐색·품질관리 에이전트 | 데이터 목록·정의·출처·누락중복 검토(저장소 대체 아님) | ⑫와 연결 |

**초기 서비스 결합안**: ①(데이터화)→②(근거검토)→⑤(조치문서)를 하나의 업무로 묶는 것을 권고. 예시 요청: "도로안전 점검보고서들을 지점별로 정리하고, 이전 지적사항 중 이번 보고서에서 조치 여부가 확인 안 되는 항목을 찾아 확인요청서 초안을 작성."

**텔레컨스(외부 파트너 후보) — [보류 확정, 2026-09-22 사용자 결정]**: 지도기반 위치관제·LiDAR 객체검출·교통량/정체 판별 등 공간·현장 데이터 처리 역량 보유(공식 소개 기준, 검증된 위험예측엔진 보유는 미확인). 고령보행자 위험분석·K-Safer 후속 서비스에서 **CCK=업무흐름/근거관리, 텔레컨스=공간정합/현장데이터, TS·기존사업자=위험도정의·현장확인·개선판단**으로 역할분담 가능(확정 아닌 설계안). ⚠️ 이 프로젝트 다른 문서 어디에도 "텔레컨스" 언급이 없음(grep 전수 확인) — 이번에 처음 등장한 파트너 후보. **사용자가 이 축 자체를 추진하지 않기로 결정했다("없었던 일로") — 25번 §8.5-15 참조. 가벼운 사실확인(WebSearch, 2026-09-22) 결과 텔레컨스는 실재 회사(내비게이션·GIS·관제시스템·TPEG 개발, LG전자 AVN 협력사)이나 LiDAR 역량은 이번 검색으로 재확인되지 않았다.**

**추진 순서 권고**: A(CCK 단독 문서·데이터 서비스, 저비용·단기) → B(CCK+텔레컨스 분석결과 연계, 본안) → C(신규 센서·예측모델 R&D, 기존 자료로 안 풀리는 공백 확인 시에만 분리). **A를 먼저 검증하며 B를 구체화**가 권고안.
