## 이번 구상의 핵심

현안 발견 → 현황·증거 대조 → 문제정의 → 원인 가설·반대 근거 검토 → TS 역할·기존 사업 연결 → 대안 및 추가 사업 비교 → 담당자 검토·후속 확인.

자료가 부족하면 추가 조사로 돌아가며, 현행 유지·운영 개선·기존 AI 고도화·타 기관 협업도 대안에 포함한다. 기사량이나 민원량을 위험 규모·원인의 확정 근거로 사용하지 않는다.

CCK 주관 AX+SI, NOA·로컬 LLM, 기존 서버, 신규 인프라 투자 0원 조건을 적용한다. 비전·신규 센서·장비·제어와 독립 R&D는 범위에서 제외한다. 기존 계약의 동일 납품분과 새 지식·설정·기능·연계·검증의 추가 수행분을 구분한다.

## 기존 P23과의 관계

저장 폴더에서 확인한 P23 서비스 컨셉은 이미 ‘민원·뉴스·정책보고·공식 현황 → 문제정의·원인 가설 → TS 역할·기존사업 → 추가 사업 대안’을 다룬다. 이번 대화의 구상은 이 정책기획 범위에 연결한다. 별도 후보를 추가로 번호 부여하거나 기존 22개 업무를 늘리지 않았다.

이 폴더는 초기 아이디어와 직접 열람한 출처의 보관·안내 위치다. 상세 서비스·예산요구·발주 전환 자료는 위 P23 문서를 참조한다. P23의 비용·시험·제품 설명은 해당 문서의 가정과 검증 범위를 따르며, 이번 파일 정리에서 실증한 성과로 승격하지 않는다.

## 읽을 때 구분할 상태

- 사업구상 v0.1은 앞선 대화의 초안으로 보존한다. 10절의 로컬 파일 열람 실패는 초안 작성 당시의 이력이다. 현재는 지정 폴더·초안·지침·P23 관련 문서를 읽어 존재와 연결을 확인했다.
- 정책 담당자의 실제 수요, 계약 범위, 자료 이용권한, 현행 법령·위탁 및 수행조직, CCK 제품·서버 가용성은 추가 확인 대상이다.
- TS와 한국도로교통공단(KoROAD)은 다른 기관이다. 이전 고령운전자·음주운전·안전기술 구상의 기관·권한·예산을 TS에 자동 적용하지 않는다.
- 파일 정리 완료는 시스템 구축·정책 승인·예산 확보·실증 완료를 뜻하지 않는다.
