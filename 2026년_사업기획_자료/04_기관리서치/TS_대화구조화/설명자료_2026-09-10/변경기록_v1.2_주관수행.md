# v1.2 변경·검증 기록

2026-09-10 · 사용자 정정 U-CCK-02

## 변경 목적

CCK 솔루션과 로컬 LLM을 기반으로 CCK가 주관·총괄 수행사로 수주·구축·검수·운영할 수 있는 사업을 찾는다. 사용자 표현 ‘주마더사’는 문맥상 주관·총괄 수행사로 해석했다. 모든 구성요소의 자체 개발을 요구하는 뜻으로 확대하지 않았다.

## 반영 내용

- 기획 기준에 CCK 핵심 책임, 직접·협력 분담, 기관 협조, 인력·납기·원가·입찰·운영 근거를 추가했다.
- HTML·Markdown에 책임 분담표와 A/B/C별 최소 납품물 초안을 넣었다. 실제 확보된 인력·협력사·견적·제품 구현과 구분했다.
- 연구 단계 복사문 8개와 후속 대기열 Q11에 같은 기준을 적용했다.
- 비전·센서·차량 제어·물리적 진단이 핵심인 사업은 협력사 활용을 이유로 다시 포함하지 않는다.
- 조회 연계만 가능한 경우 예약 확정을, 서식 출력만 가능한 경우 접수 완료를 납품 범위로 약속하지 않는다.

## 확인 결과

로컬 Edge·Playwright 검사 **51/51 통과**. HTML·Markdown·다운로드 일치, 새 기준과 연구 복사문, 기존 상호작용·키보드·반응형·인쇄·JavaScript 미사용 동작을 확인했다. HTTP 요청과 JavaScript 오류는 각각 0건이다. 기술 범위와 모바일 첫 화면 스크린샷을 직접 열어 문장·표·제목 배치를 확인했다.

문서 반영에 대한 자체 QA는 합격이다. 독립 평가위원 심사와 실제 사용자 검증은 수행하지 않았다. axe-core가 없어 해당 자동 접근성 검사는 실행하지 않았다.

**A/B/C의 CCK 주관 수행 가능성은 아직 검증 전이다.** 이번 검사는 설명자료에 관한 것이며 CCK 제품·로컬 LLM·실제 API 실행, 인력·협력사 확보, 비용·기간 타당성, 사업 선정 검증이 아니다.

## 보존·후속 입력

직전 버전은 `이력/v1.1_주관수행조건_반영전`에 보존했다. 후보별 제품 버전·데모, 책임 분담과 인력, 연계 권한, 납품·검수 기준, 비용·기간·운영 조건이 확보되면 Q10·Q11을 근거로 판단을 갱신한다. 정식 후보 선정 상태와 자동화는 변경하지 않았다.
