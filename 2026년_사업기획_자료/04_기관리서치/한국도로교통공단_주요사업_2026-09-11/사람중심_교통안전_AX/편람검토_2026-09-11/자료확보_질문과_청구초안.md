# 세 후보의 자료 확보 질문과 정보공개청구 초안

2026-09-11 · 검토용 초안. 외부 제출·연락·수수료 결제는 하지 않았다.

가정: 요청 기간은 완료 연도 기준 2023-01-01~2025-12-31로 잡았다. 최근 3개 완료 연도의 기존 문서부터 확인하기 위한 범위이며, 실제 해당 문서의 존재·수량을 확인한 것은 아니다. 2026년 자료와 진행 연구는 별도 목록으로 확인한다. 이미 공개된 자료는 공개 위치를 먼저 찾는다.

## 1. H01 — 고령운전자 정책 근거 자료

**제목: 고령운전자 운전 관련 기능·평가·정책 연구의 완료 보고서 및 기존 목록**

> 귀 기관이 보유·관리하는 2023~2025년 완료 연구 중 고령운전자의 시각·인지·신체 기능, 운전능력 평가, 면허·교육 기준 또는 안전·이동지원 정책과 관련된 최종 연구보고서와 기존 연구과제 목록의 공개를 청구합니다.
>
> 기존 목록에 수록된 과제명·완료연도·보고서명·공개 위치를 확인하고자 합니다. 이미 공개된 경우 해당 자료의 열람 위치를 안내해 주시기 바랍니다. 연구대상자 개인별 검사결과·건강정보·식별정보는 요청 대상에서 제외합니다. 비공개 정보가 혼재한 경우 공개 취지를 해치지 않고 분리 가능한 부분의 공개를 검토해 주시기 바랍니다.
>
> 새로운 연구·비교표 작성은 요청하지 않습니다. 가능한 경우 보유 중인 전자파일 형태로 제공해 주시고, 자료에 이미 표시된 저작권·공공누리·이용조건 안내도 함께 확인할 수 있도록 해 주시기 바랍니다.

사업 확인 질문: 정책 담당자가 반복 작성하는 비교표·검토서가 무엇인지, 어떤 조건 누락 때문에 재검토가 발생하는지, 기존 연구검색·AI 시스템이 어디까지 지원하는지 확인한다. 이 질문은 현업 인터뷰용이며 보고서 청구와 구별한다.

## 2. H02 — 음주운전 재범 예방 제도·운영 검토 자료

**제목: 음주운전 교육·재범 예방의 완료 평가보고서와 공개 가능한 업무절차·서식**

> 귀 기관이 보유·관리하는 2023~2025년 완료 음주운전 교육·재범 예방 관련 연구 및 사업평가의 최종 보고서 중 제도·교육 효과·기존 집계 결과를 확인할 수 있는 자료의 공개를 청구합니다.
>
> 또한 귀 기관 소관으로 보유 중인 음주운전 방지장치 부착 조건부 면허 관련 교육·지원 업무의 공개 가능한 절차 안내와 개인정보가 기입되지 않은 공통 서식을 요청합니다. 해당 업무·문서를 귀 기관이 보유한다는 전제는 두지 않으며, 보유 여부와 기존 공개 위치를 확인하고자 합니다.
>
> 개인별 범죄·처분·면허·교육·상담기록, 운행기록 원본, 개인을 식별할 수 있는 사례는 요청 대상에서 제외합니다. 새로운 재범률 계산이나 기관 간 자료 연계는 요청하지 않습니다. 비공개 부분이 있는 경우 분리 가능한 공개 부분을 검토해 주시기 바랍니다.

내부 사업협의에서 별도로 확인할 사항:

- 각 조치의 담당 기관·부서·업무 근거와 현재 시스템이 수행하는 기한·이행 관리.
- 실제로 남아 있는 서술형 증빙 검토 문제와 규칙 기반 방식으로 해결 가능한 범위.
- 실제 기록을 쓰려는 경우 데이터 항목별 수집·이용·제공·위탁 관계, 보유기간, 수행사 접근 범위와 처리 근거.

정보공개 여부와 실제 업무시스템 접근 허가는 별개의 판단이다. 공개청구 결과를 개인기록 연계의 허가로 사용하지 않는다.

## 3. H03 — 교통안전 기술·제품의 공개 검토 근거

**제목: 교통안전 장비·시설 관련 공개 시험·기술 기준과 완료 실증평가 자료**

> 귀 기관이 보유·관리하는 교통안전 장비·시설 관련 공개 가능한 현행 시험·기술 기준의 문서 및 기존 목록과, 2023~2025년 완료된 제품·기술 실증 또는 시범적용 평가 중 공개 가능한 최종 보고서·요약자료를 청구합니다.
>
> 기존 공개 목록에 포함된 경우 문서명·기준 버전·적용일·공개 위치를 확인하고자 합니다. 특정 업체의 비공개 설계·원가·특허 출원 관련 비밀, 비공개 입찰평가, 검사신청자의 개인정보 및 비공개 검사성적서 원문 전체는 요청 대상에서 제외합니다. 공개 내용과 비공개 내용이 혼재하면 공개 취지를 해치지 않고 분리 가능한 부분을 검토해 주시기 바랍니다.
>
> 모든 중소기업 신제품을 새로 조사하거나 목록을 신규 작성해 달라는 요청은 아닙니다. 보유 중인 자료 또는 기존 공개 위치를 요청하며, 가능한 경우 자료에 표시된 이용조건도 확인할 수 있도록 해 주시기 바랍니다.

사업 확인 질문: 실제 도입을 검토한 현장문제 1건, 당시 검색한 등록부, 찾지 못했거나 비교하기 어려웠던 조건, 공개 자료로 확인 가능한 성능과 추가 시험이 필요한 성능을 구분한다. 제품 성능·인증·가격은 자료 확보 전에는 채우지 않는다.

## 4. 회신·자료 확보 후 기록할 항목

부분공개·비공개·부존재를 서로 구별한다. 비공개를 기능 개발 불가능으로, 공개를 AI 학습·재배포 허가로 자동 변환하지 않는다. 현재는 회신이나 기관 확인이 없는 상태다.
