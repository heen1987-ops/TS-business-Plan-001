# 기관·법정업무 매핑 설계와 조사 대기열

작성일: 2026-09-09. 전체 기관을 누적 조사하기 위한 구조이며 전수조사 완료본이 아니다.

기계 판독이 가능한 초기 데이터는 [기관업무 원장](기관업무_원장.json)에 저장한다. 공식 출처는 [공식근거 및 심의경로](공식근거_및_심의경로.md)에서 PUB ID로 관리한다.

2026-09-09 추가 조사 결과는 [기관법령 관계도](관계도/기관법령_관계도.html), [조사 결과·검증 범위](관계도/조사결과_및_검증범위.md), [관계원장](관계도/기관법령_관계원장.json)에 저장했다. 이번 원장의 출처 ID는 `S…`이며 원장 내부와 [출처 목록](관계도/출처목록.json)에 정의한다. 초기 `ORG-0001`은 이번 `A_C0019`에 대응한다. 다음 조사에서는 [후속 대기열](관계도/후속조사_대기열.md)과 [기관별 미확인 대장](관계도/기관별_미확인대장.json)을 우선 읽는다.

## 연결 구조

`기관(ORG) → 설립 근거 → 법정 사업·위탁업무(MAN) → 수행조직 → 사회문제(ISS) → 국민 수혜집단 → 사업기회(OPP) → 기술·SI 구성 → 적용 심의 → 확장기관`

설립 근거와 개별 업무의 위탁 근거를 혼합하지 않는다. 기관 하나에 여러 업무가 있고 업무 하나에 여러 기관이 참여할 수 있으므로 관계를 별도 관리한다.

| 객체 | 필수 기록 |
|---|---|
| 기관 | ID, 정식 명칭, 별칭, 기관 계층, 지정 유형·연도, 주무부처·소관기관, 설립 근거, 홈페이지, 확인 상태 |
| 업무 | ID, 업무명, 국민 수혜집단, 법률·시행령·고시, 조·항·호, 시행일, 확인 상태 |
| 기관-업무 관계 | 기관 ID, 업무 ID, 역할(직접·위임·위탁·지정·대행·지원), 위탁·지정 주체, 근거, 수행조직, 유효기간 |
| 문제 | ID, 메가이슈, 구체적 피해·불편, 대상·지역·기간, 통계·현장 근거, 원인 가설, 연결 업무 ID |
| 사업기회 | ID, 문제·업무 ID, R&D·AX+SI 유형, 국민 가치, AI 필요성, 조직 영향, 후보 확장기관, 검증 계획 |
| 출처 | PUB/SRC ID, 발행기관, URL·경로, 원문 위치, 발행·시행·확인일, 열람 상태, 지원하는 주장, 한계 |
| 변경 이력 | 대상 ID, 이전 값, 변경 값, 근거, 변경·확인일, 영향받는 기획서 |

현재 수집하지 못한 값은 JSON에서 `null`과 확인 상태로 표시한다. `null`은 업무·기관·권한이 없다는 뜻이 아니다.

## 조사 상태와 품질

- 기관 상태: `목록 등록 / 분류 확인 / 설립 근거 확인 / 핵심 업무 확인 / 조직·권한 확인 / 기획 연결 / 재검토 필요`.
- 법적 관계 상태: `설명자료 확인 / 원문 부분 확인 / 원문·시행일 확인 / 적용성 확인 / 미확인 / 폐지·변경`.
- 최초 조사 범위: 기관별 TS와 연관된 핵심 업무부터 기록한다. 핵심 업무 확인을 해당 기관의 모든 위탁업무 검증 완료로 표현하지 않는다.
- 전체 목록 수집과 개별 법정업무의 깊이 있는 검증은 다른 진척률로 보고한다.
- 모든 수치에는 분모와 분자의 기준을 표시한다. 분모가 없으면 전수조사 완료율을 계산하지 않는다.
- 초기 기획 원장은 기관 1개·업무 1개·관계 1개의 최초 상태를 보존한다. 최신 관계도 원장은 법령 412개·조례 498개 본문과 TS 핵심 관계 15개를 포함한다. 전체 기관의 전 업무 법률검토 완료 수 또는 전국 단일 모집단은 확정하지 않았다.

## 초기 순차 조사 대기열 이력

아래는 최초 대기열이다. 추가 조사의 완료·잔여 범위와 다음 실행 순서는 [최신 후속 대기열](관계도/후속조사_대기열.md)을 따른다.

| 순서 | 조사 항목 | 필요한 결과 | 상태 |
|---|---|---|---|
| Q01 | 2026 공공기관 지정고시·ALIO 목록 | 기관명·유형·주무부처·기준일의 공식 목록과 중복 제거 기준 | 고시 첨부 열람 재시도 필요 |
| Q02 | TS 설립법과 개별 업무 위탁·지정 근거 | TS 업무별 MAN ID와 현행 법령 관계 | 교통수단안전점검 1건 설명 확인 |
| Q03 | 기존 TS 원문·승인 요구사항·실제 자산 | 기존 사업 범위, 권한, 재사용 가능성 | 파생 문서 1차 검토 / 원문 미검증 |
| Q04 | 국토교통 분야 및 유사 안전·검사·인증·공시 기관 | 법적 업무 패턴과 TS 공통점·차이 | 기관 목록 기반 선정 대기 |
| Q05 | 재난·환경·산업안전·복지 등 타 부처 기관 | 범정부 공통 문제와 확장 제한 | Q01 목록 확보 후 순환 조사 |
| Q06 | 지방공기업·출자출연기관 등 별도 모집단 | 중복 없는 기관 목록과 설립·업무 근거 | 미착수 |
| Q07 | 최신 R&D·정보화·투자 심사 절차 | 사업별 적용성 질문과 심의 경로 | 상위 근거 1차 확인 / 하위 기준 대기 |

정기 실행에서는 중요한 법령 변경과 전일 미결을 먼저 처리하고, 남은 범위에서 미조사 기관을 순차 조사한다. TS와 인접 분야만 반복해 전체 범위 확장을 멈추지 않도록 이미 검토한 기관·다음 시작점을 운영 기록에 남긴다.

## 범정부 재사용 판단표

| 공통 업무 패턴 | 재사용 가능한 기능 가설 | 기관별 재검증 |
|---|---|---|
| 신청·제출·검사·평가·공시 | 문서 추출, 근거 제시, 규칙 버전, 예외 검토, 감사 이력 | 법적 판단 권한, 평가규칙, 개인정보, 공시 범위, 이의제기 |
| 국민 정보·절차 안내 | 출처 검색, 시점별 답변, 접근성, 오류 안내와 상담 연결 | 담당 업무, 최신 법령, 설명 의무, 지원 대상, 실제 승인 채널 |
| 위험 예방과 대응 지원 | 데이터 품질·위험 신호·판단 근거·사람 검토 | 데이터 대표성, 오탐·미탐 피해, 현장 대응권한, 모델 검증 |

이 표는 재사용 가설이다. 확정된 공통 솔루션이나 사업 선정 결과가 아니며 기관별 검증 결과로 수정한다.
