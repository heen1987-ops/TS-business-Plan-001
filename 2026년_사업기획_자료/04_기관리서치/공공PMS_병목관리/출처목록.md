## 열람 과정과 보완

- 국세청 규정은 웹 열람 도구가 동적 본문을 반환하지 않아, 같은 공식 사이트의 본문 요청 주소를 페이지 스크립트에서 확인하고 PowerShell HTTP 조회로 제20~31조를 읽었다. 2024판을 확인했으며 현행성은 후속 과제로 남긴다.
- 전자정부법 제57조의 첫 변경조문 주소와 법령 별칭 주소는 오류·빈 응답이었다. 공식 조문정보 주소에서 2026-08-28 시행 본문을 확인하여 보완했다.
- 한국교통안전공단법의 첫 링크는 제6조 제6호만 반환했다. 제6조 전체 조문 링크로 다시 열람한 내용을 사용했다.
- 나라장터 R26BK01348164 첨부 검색에서 IT PMS·요구사항 추적표 항목을 발견했으나 발주기관·사업명·공고 본문을 확인하지 못해 실명 도입사례로 채택하지 않았다.
- 국내 적격심사·신인도·다수공급자 관련 규정도 검색되었으나 정보화사업의 지속 평가 및 기관 간 공유와 같은 제도라고 확인하지 못했다. 국내 제도가 없다는 결론을 내리지 않았다.

공개 HTML 13개를 [근거자료](근거자료/)에 보존했다. 취득 URL·시각·바이트·SHA-256은 [취득결과](취득결과.json)에 기록했다. HTTP 응답의 보존은 본문 전체의 검증이나 해당 판본의 현행성을 뜻하지 않는다. 감리원 자격 별표는 검색 발췌만 확인하여 다운로드 보존 대상에서 제외했다. 재현 스크립트는 [수집_근거.py](수집_근거.py)이며 기존 보존본이 있으면 다시 내려받지 않는다.
