# 공공 PMS 조사 검증 결과

검토일: 2026-09-09 / 버전: v0.2. 이번 검증은 조사·구조화 문서와 근거 연결의 자체 검토다. 독립 평가위원·기관·법률전문가의 승인이나 제품·AI의 실증 성적을 뜻하지 않는다.

## 수행한 검증

- `python -X utf8 검증_조사.py`의 문서·대화·요구추적·출처·보존 무결성 검사 **27개를 통과**했다. 자세한 결과는 [검증결과.json](검증결과.json)에 기록했다.
- 출처 16개 ID·필수 필드와 보고서 인용 참조, P01~P07, 후속 대기열 15개를 확인했다.
- UTF-8 문서, 로컬 링크 대상, 공개 HTML 13개와 취득 SHA-256을 확인했다.
- 핵심 법령 보존본에서 인용 조문·시행일 표식, 국세청 PMS·만족도와 제품 기능 표식을 확인했다. 표식 존재는 문서 전체의 현행성·진실성을 자동 판정한 결과가 아니다.
- 기존 포트폴리오·기관관계 원장의 해시는 연결문서 편집 직전과 같다. 해당 원장에는 신규 후보를 추가하지 않았다.
- 보고서의 사실/가설, 공급사 설명/실증 성과, 국내/미국 제도, 기관 도입/기업정보 공유, TS 내부 수요/범정부 운영 권한을 구별하는지 자체 내용 검토했다.
- 대화 10건의 원문·원본 turn ID가 요구원장과 일치하고 모든 사용자 발언이 요구 20건에 연결되는지 확인했다. 설계 18건의 참조, 요구→기능→설계 연결, 미검증 주장 6건과 수용 시나리오 14건의 상태 표기를 검사했다.
- 기본 만족도·기본 수행이력·레퍼런스의 1차 배치, 이전 문서 7개 보존 해시, PMS-S01의 추가 확인 이력과 다른 15개 출처의 검증 수준 보존을 확인했다.
- 검사 도중 원장 필드명을 잘못 참조한 `design_proposals` 오류가 발생했다. 실제 필드 `designs`로 수정한 뒤 재실행해 종료 코드 0과 27개 통과를 확인했다. 제품 결함이나 제품 시험 결과가 아니다.

## 판정

- **문서·출처의 참조 무결성: 통과.** 자동 검사 범위에 한한다.
- **대화 구조화: 자체 검토 기준 충족.** 사용자 요구 20건과 설계 제안 18건, 미검증 주장 6건을 연결했으며 상세 설계의 최종 승인을 뜻하지 않는다.
- **조사자 기획 검토: 조건부 합격.** 실제 문제와 자료를 확인하는 다음 조사에 활용할 수 있다.
- **TS 신규사업 선정·본구축·공식 기업평가·기관 간 공유: 보류.** 수요·권한·기존 과업 중복·AI 추가 가치·국민 효과가 미검증이다.
- **독립 평가·법률검토·제품 데모·실제 사용자 조사·AI 실증: 미실시.** 사용자 관점 내용은 내부 시나리오 검토이며 실제 사용자 검증을 대체하지 않는다.

문서에 Mermaid 관계 구조를 포함했으나 UI나 이미지 자산을 제작한 것이 아니다. Mermaid 렌더링·웹 접근성·반응형 시각 QA는 이번 검사 범위가 아니다.

## 방법론·완료 범위

1차에는 근거 기반 비교 조사와 업무흐름 분석으로 문제 정의→자료 확인→대안·실증 설계→자체 검토→기록을 수행했다. 이번 v0.2는 M / Low 문서 보완으로 대화 확인→요구 추적→전체 구조·업무·아키텍처 문서→자체 검토를 수행했다. 구현·배포 단계는 요청 범위가 아니므로 수행하지 않았다.

추가 산출물은 [전체 구조화](공공PMS_전체구조화_2026-09-09.md), [추적표](대화확인_변경점과_요구사항추적표.md), [요구원장](대화_요구사항원장.json), [대화 보존본](대화원문_2차.json)이다. 기존 조사보고서·출처원장·목록·대기열·검증 기록과 프로젝트 연결문서를 갱신했다. 기존 원본 프로젝트·포트폴리오·기관관계 원장은 수정하지 않았다.

다음 반복주기 입력은 PMS-Q01~04의 수요·계약·기존 기능·실제 병목과 PMS-Q14~15의 공동 처리 기준·문서 표본이다. PMS-Q13의 시제품 실물 확인은 별도이며 문서 구조화의 선행조건이 아니다. 재사용할 교훈은 기존 기능과의 중복 비교, 대화상 요구·설계·완료 주장의 구분이다. 전역 지침은 변경하지 않았다.
