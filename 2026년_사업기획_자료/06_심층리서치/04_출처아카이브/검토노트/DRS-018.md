## 확인 내용과 적용 한계

TS 공식 홈페이지의 관련 시스템 링크에서 존재를 확인했으나 해당 서비스 본문 열람은 실패했다.[^18]

서비스 상세·현행 가동·이용자 권한은 미확인. 실패를 운영 중단으로 판단하지 않는다.

`claim_verified`는 위의 제한된 확인 내용에 대한 열람 판단이다. 법적 적용성·실제 서비스 동작·독립 성과 검증을 뜻하지 않는다. 본문 검토를 완료하지 못했으므로 탐색 단서로만 관리한다.

## 보존·추적

- 원문: 원문 파일 없음 — 검토 노트를 원문으로 사용하지 않음
- SHA-256: `없음`
- 취득시각 UTC: 미취득
- 바이트 수: 미취득
- 수집 응답 제목: 미취득
- 재사용 조건: 내부 근거 확인용. 원문 저작권·재배포 조건은 별도 확인하며 외부 공개하지 않음.
- 연관 사례: [CASE-015 위험물질운송안전관리 체계](<../../03_도입사례/CASE-015.md>)

HTML 응답은 실행을 막기 위해 `.html.txt`로 보존한다. 관련 이미지·스크립트·첨부파일까지 내려받은 완전한 웹사이트 사본은 아니다. 링크 변경·내용 변경 시 같은 출처 ID에 새 취득 버전을 연결하고 종전 응답과 판단 이력을 남긴다.
