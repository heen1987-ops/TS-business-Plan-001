# TS-BIZ-008 · 드론 절차·안전정보 근거형 안내

> 현재 범위: **유보** / 디지털전환+AI+정보화. 현 구상은 민원 안내 중심이다. 독립된 업무·데이터 전환과 기존 과업 비중복 입증 전 유보한다. 비중복은 미확정이다. 연구·PoC는 전환사업 세부 과업이며 독립 R&D는 현재 대상이 아니다.


[전체 조사 인덱스](<../../README.md>) · [전체 포트폴리오](<../../../05_통합사업기획/사업기획_통합보기.html>)

- 문제 ID: PRB-008
- 기획 유형: 디지털전환+AI+정보화
- 조사 상태: 유보 · 신규 검토목록 제외 / v0.2 / 2026-09-09
- 사업 선정·재원·예산·추진 일정: 미정

드론 이용자가 기체신고·조종자 증명·비행 승인 등을 하나의 절차로 오해하거나 자신의 기체·용도·장소에 맞는 담당기관을 찾지 못할 수 있다. 기존 민원 채널에서 실제 혼선과 중복 입력을 확인한다.

## 다음 판단을 바꾸는 증거

현행 공식 채널별 담당·연계 가능성, 실제 문의·오안내·재입력 규모, 현재 민원 사업과 중복

비중복 근거, 업무·데이터 전환, AI 추가 가치, 시스템 구축·연계, 운영·국민 성과를 모두 확인. 조건형 SI 기준안을 만든 뒤 AI의 추가 편익을 검증하며 미국 자동화 사례를 국내 자동승인 근거로 쓰지 않는다.

공통 사례와 출처는 후보 폴더에 복제하지 않고 ID로 연결한다. 사실·가설·적용 판단을 구별하고 현장 검증 후 후보분석 원장을 개정한다.
