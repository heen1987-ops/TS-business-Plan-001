# TS-BIZ-003 · 자동차 튜닝·검사 절차 근거형 안내

> 현재 범위: **유보** / 디지털전환+AI+정보화. 민원·직무 특화 안내와 중복 가능성이 있다. 독립 업무 전환과 비중복 근거를 확보하기 전 신규 목록에서 유보한다. 비중복은 미확정이다. 연구·PoC는 전환사업 세부 과업이며 독립 R&D는 현재 대상이 아니다.

실제 문의·반려/보완 분류와 기존 민원 사업의 포함 범위, 지자체 위탁과 TS 판단 책임

비중복 근거, 업무·데이터 전환, AI 추가 가치, 시스템 구축·연계, 운영·국민 성과를 모두 확인. 중대한 오안내가 검출된 기능은 공개하지 않고 규칙 또는 담당자 연결로 돌아간다. 성능 기준은 업무 전문가가 정한다.

공통 사례와 출처는 후보 폴더에 복제하지 않고 ID로 연결한다. 사실·가설·적용 판단을 구별하고 현장 검증 후 후보분석 원장을 개정한다.
