# 공공 PMS와 감사엔진 기획설계 안내

2026년 9월 15일 · v0.2 · 사용자 단계 정정 반영

**현재 서비스 전략은 1차 PMS, 2차 감사엔진이다.** 1차에서 사업관리와 이행기록을 완결하고 2차에서 감사계획·기준·증거·발견사항·소명·시정·재검증·보고를 연결한다. NOA와 대시보드는 단계별 구성 수단으로 검토한다.

1. [단일 HTML 설명서](공공PMS_1차PMS_2차감사엔진_서비스설계_v0.2.html): 컨셉·아키텍처·서비스 흐름·데이터 흐름·감사엔진 로직, 기존 52개 재배치와 감사엔진 10개 요구 초안.
2. [Word 설계 문서](공공PMS_1차PMS_2차감사엔진_서비스설계_v0.2.docx) / [Markdown](공공PMS_1차PMS_2차감사엔진_서비스설계_v0.2.md): 단계별 서비스모델을 정리한 7쪽 Word와 편집용 원문.
3. [요구사항 단계 재배치 제안](요구사항_단계재배치_제안_v0.2.json): 기존 RFP ID 유지, 새 단계별 검토 분류.
4. [후속 설계 작업목록](02_후속설계_작업목록.md): 단계별 상세 요구와 RFP 개정 순서.
5. [변경 이력](07_단계구분_변경이력_v0.2.md) / [문서 검증](08_단계개정_검증_v0.2.md).

## 기존 자료의 적용

- [원본 자료목록](01_자료목록.md)은 요구사항·공공 RFP·테일러링·NOA 적합성의 변경 전 근거다.
- 기존 52개 원장은 수정 전 초안이다. 새 1차 PMS 전체의 확정 납품·검수 범위로 사용하지 않는다.
- 이번 재배치는 설계 제안이며 상세 RFP의 문구·물량·검수·가격 개정은 다음 단계다.
- v0.1 문서와 HTML은 원래 파일명으로 보존한다. 서비스 단계가 충돌하면 사용자 정정과 v0.2를 우선한다.
- NOA 설치본·API·권리·용량, 감사 업무별 적용 기준, 편익·예산·기간은 미확정이다. 구현·배포는 수행하지 않았다.

CCK 주관, 기존 로컬 LLM·서버와 신규 인프라 투자 0원 조건을 유지한다. 총사업비는 별도이며 같은 공통 기능 비용을 두 단계에 중복 계상하지 않는다.
