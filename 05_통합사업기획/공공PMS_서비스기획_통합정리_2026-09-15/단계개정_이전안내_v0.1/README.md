# 공공 PMS 기획설계 통합 안내

정리일 2026년 9월 15일. 설계와 서비스모델을 검토하기 위한 문서 묶음이다.

1. [통합 Word 문서](공공PMS_서비스모델과_설계현황_통합정리_v0.1.docx) 또는 [통합 Markdown](공공PMS_서비스모델과_설계현황_통합정리_v0.1.md)에서 현재 서비스 방향을 읽는다.
2. [자료목록](01_자료목록.md)에서 NOA 적합성·요구사항·공공 RFP·테일러링의 원본을 연다.
3. [후속 설계 작업목록](02_후속설계_작업목록.md)에서 미결 사항과 다음 설계 결과를 관리한다.

현재 권고는 NOA의 개인 문서·검사 지원과 공식 공동 사업 원장을 논리적으로 분리하고 실제 제품 확장·API 조건에 따라 NOA 내부 앱, 별도 업무화면 또는 기존 PMS 연계를 선택하는 것이다. 52개 RFP 요구의 기준선은 유지한다.

9월 15일 추가 적용 기준에 따라 기구축 시스템·기존 AI도 활용 기반으로 인정한다. 동일 계약 납품분과 추가 작업을 구분하며 기존 로컬 LLM·서버·신규 인프라 투자 0원을 유지한다. 예산·기간·물량과 NOA 실물 적합성은 미확정이다.

기존 파일은 이동·삭제·덮어쓰지 않고 실제 위치로 연결했다. 과거 검토서와 설명 HTML의 날짜·내용은 이력으로 유지한다. 이 묶음은 원본을 대신하는 복제본 저장소가 아니며, 원본이 개정되면 자료목록과 해시도 갱신한다.
