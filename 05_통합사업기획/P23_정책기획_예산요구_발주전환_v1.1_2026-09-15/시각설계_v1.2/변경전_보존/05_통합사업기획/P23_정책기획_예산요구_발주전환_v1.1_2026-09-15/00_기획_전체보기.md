# 근거에서 예산·발주까지

P23 v1.1 · TS 정책·예산·발주 기획지원 플랫폼


> 여러 부서가 같은 자료를 다시 읽고 같은 설명을 다시 쓰는 부담을 줄인다. 검토된 문제·근거·사업범위·예산을 하나의 원장으로 관리하고, 제출 목적에 맞는 문서 초안과 수정할 부분을 연결한다.

## 서비스 정의

**이용자:** 혁신·기획·예산·업무·정보화·계약을 담당하는 TS 직원. 사용자께서 말씀하신 ‘혁신처·기획처’는 기능상 역할로 반영했으며 공식 조직명·전결권자는 착수 시 확인한다.

**해결할 문제:** 정책보고서·통계·민원·뉴스·내부 사업자료를 각 부서가 별도로 검토하여 문제정의, 예산 설명, 요구사항 작성 사이에서 근거와 범위가 끊기는 상황. 발생 빈도·작업시간은 아직 실측하지 않은 업무 가설이다.

**핵심 제품:** 부서 공동의 근거 검토 작업대 + 사업·예산 원장 + 검토 흐름 + 양식별 문서 초안. 예산 확보 결과는 심의·정책 판단에 달려 있으며, 이 제품은 필요성·실행가능성을 설명하는 자료의 품질과 일관성을 지원한다.

## 8단계 업무 로직

| 단계 | 담당자에게 제공할 것 | 다음 단계 진입 조건 |
| --- | --- | --- |
| 1. 자료 파악 | 중복을 묶은 근거 카드, 기간·대상별 현황 | 반입 권리·개인정보·접근 범위 확인 |
| 2. 문제정의 | 현상·불이익·규모·원인가설·반대근거 | 업무 담당자가 문제와 조사 공백 확인 |
| 3. 정책·사업 대안 | 운영 개선·기존 기능 활용·AI 고도화·신규 도입 비교 | TS 소관 및 기존 계약과 차이 확인 |
| 4. 사업 구체화 | 목표·대상·범위·요구사항·일정·비용 근거 | 실행 주체와 기술·데이터 전제 확인 |
| 5. 예산 요구 준비 | 제출 경로별 사업설명자료·연차비용·예상 질의 | 예산 담당 검토, 해당 경로의 서식 확정 |
| 6. 심의 보완 | 질의 근거와 답변 초안, 감액 시 범위 조정안 | 실제 심의·승인 증빙 등록 |
| 7. 발주 전환 | 승인 범위와 검수기준을 담은 RFP·공고 준비자료 | 업무·정보화·계약 담당자의 검토 |
| 8. 사후 학습 | 계약·수행 결과·성과를 원래 문제와 연결 | 확인된 결과만 차기 기획에 반영 |

## 앞선 22개 업무와 관계

P01–P22는 개별 업무의 AI 적용 후보이고, **P23은 여러 업무에서 필요한 사업을 찾아 구체화하는 공통 기획지원 후보**다. TS의 공식 23번째 업무분류로 주장하지 않는다. P23이 다른 업무의 필요성을 입증하거나 신규 도입이 최선이라고 미리 결정하지 않는다.

v1.0의 문제·근거·원인 가설·대안 검토를 재사용하고, v1.1에서 **예산 경로·공통 사업원장·서식 변환·변경 영향·발주 전환**을 추가한다. 기존 계약과 동일한 기능은 재개발 비용에서 제외한다.

## 전제와 완료 기준

- 기존 TS 로컬 서버·로컬 LLM·NOA 활용, 신규 인프라 투자 0원. 용량 부족 시 동시 작업·자료량·처리시간 범위를 조정한다.
- 텍스트 전자문서와 승인된 구조화 자료 중심. 영상·음성·OCR·센서·사고 예측 및 직접 안전 판단은 범위에 포함하지 않는다.
- 첫 적용은 정책 의제 1개, 시범부서 2개, 자료 종류 4개, 문서 프로필 6개, 실제 출력 검수할 HWPX 양식 2개를 가정한다.
- 이 산출물은 **기획 설계·HTML/MD 양식·규칙 시연**이다. 로컬 LLM 연동, TS 데이터 연결, 실제 HWPX 변환 및 운영 승인 기능은 구현·실증 전이다.

## 자료 읽는 순서

01에서 문제 검토 → 02에서 예산 경로 → 03에서 양식 연결 → 04에서 기술 구성 → 05에서 발주 전환 → 06에서 검수 → 07에서 비용 → 08에서 시연을 확인한다. 서식 6종은 필요한 항목을 바로 채울 수 있는 빈 초안으로 제공한다.

## 공공기관으로 재사용할 범위

근거 카드·사업원장·예산 산식·검토 이력·양식 매핑은 공통 기능으로 구성하고, 기관 소관·예산 경로·문서 양식·전결권한·기존 시스템 연결은 기관별 설정으로 분리한다. TS에서 의제1개를 검증한 뒤 다른 부서·기관으로 확장할 수 있는 제품 구조를 제안한다. 타기관 연동·다기관 통합 운영까지 이번 비용에 포함한 것은 아니다.
