## 예산 경로를 선택한다

| 경로 | 설계상 업무 흐름 | 자동으로 확정하지 않을 것 |
| --- | --- | --- |
| TS 자체예산 | 업무부서 검토 → 기획·예산 협의 → 기관의 예산·의사결정 절차 → 발주 준비 | 모든 자체예산이 중앙 예산기관에 직접 제출된다는 가정 |
| 정부예산 연계 | TS 작성지원 자료 → 해당 소관부처 취합·검토 → 정부 예산 절차 → 결과 확인 | TS의 직접 제출 권한·경로·서식·기한 |
| 위탁·보조·특정 사업재원 | 협약·재원 기준 확인 → 해당 제출기관 양식 → 비용 인정·승인 절차 | 일반 정보화사업과 동일한 비용·제출 규칙 |

사용자께서 말씀하신 ‘기획재정부 전달용’은 **중앙 예산 심의에 필요한 자료를 준비한다는 요구**로 반영한다. 확인한 2027년도 지침 발간 기관은 기획예산처다. 시스템에서는 기관명을 고정하지 않고 연도·수신처·재원에 맞는 승인 양식을 선택한다. [공식 2027 세부지침](https://www.mpb.go.kr/web/main/bbs/b_0005/2225)

## 예산을 설명하는 연결

**근거 → 해결할 문제 → 공공 개입 필요성 → 정책 대안 → 선택 사업 → 수행범위 → 비용 항목 → 성과·검수 → 집행계획**을 동일한 ID로 연결한다. 필요성을 설명할 근거가 부족하면 예산 설명 문장을 늘리는 대신 필요한 조사를 표시한다.

| 예산 설명 항목 | 필요한 입력 | 출력 |
| --- | --- | --- |
| 왜 지금인가 | 발생 규모·지속성·정책목표·미대응 영향 | 사업 필요성과 시급성 초안 |
| 왜 TS인가 | 소관 근거·현행 수행주체·협업 관계 | 수행 주체와 협업 범위 |
| 왜 이 방법인가 | 비SW 대안·기존 시스템 활용·추가 도입 비교 | 선택 사유·포기한 대안·전제조건 |
| 얼마가 필요한가 | 항목별 수량·단가·기간·요율·VAT·출처 | 연차별 비용·총비용·산식 |
| 기존 예산과 다른가 | 기구축·계약·추가 범위·관련 기관 의견 | 유사중복 검토 및 실제 의견조회 결과 |
| 집행 가능한가 | 자료 접근·서식·자원·조달 일정·담당자 | 선행조건·집행계획·유보조건 |
| 무엇이 달라지는가 | 실측 기준선·검증 대상·측정 방법 | 산출물 지표와 사업 성과지표 |

## 총비용과 연차

2027 세부지침의 정보화사업 항목은 연차별·항목별 투자소요를 요구하며, 신규사업에 구축 경비 외 구축 후 5년간 운영유지관리비·추가구축비·이용료 등을 포함하도록 설명한다. 사업별 총소요비용 작성양식은 필요시 별도 공지될 수 있다. **단일 고정 양식이 모든 제출에 통용된다고 가정하지 않는다.** [공식 지침, 인쇄45쪽](https://www.mpb.go.kr/web/main/bbs/b_0005/2225)

입력 모델은 구축연도 Y0, 운영 Y1–Y5, 기타 승인 연차를 관리한다. 기존 서버 사용으로 신규 인프라 투자액은 0원이지만 추가 운영인력·SW 이용권·유지보수까지 자동으로 0원 처리하지 않는다. 미견적 항목은 ‘미확정’으로 남겨 알려진 소계와 구분한다.

## 실제 예산 심의의 피드백

- 질의: 질문 원문·발신처·기한·담당자를 등록하고 근거를 연결한 답변 초안을 작성한다.
- 감액: 감액된 금액을 승인·제안·가정 중 어느 상태인지 구분한다. 우선 기능 유지·범위 축소·단계 분리안을 다시 산정한다.
- 증액: 증가 항목·사유·단가·수량을 기록하고 원래 문제와 연결되는지 재검토한다.
- 부결·유보: 사유·보완 근거·재검토 조건을 남긴다. 자동 공고 준비 상태로 넘어가지 않는다.

ISP·ISMP·사전협의·각종 심사·예비타당성조사 등의 적용 여부는 재원·유형·규모·연도·소관 기준으로 담당자가 확인한다. 여기서는 해당 여부와 근거를 보관할 필드를 설계하며 개별 사업의 법적 의무 판정을 완료한 것으로 보지 않는다.
