## 사용 방법

HTML 상단에서 슬라이드를 고르고 발표 보기를 사용할 수 있다. 방향키로 이동하고 Esc로 발표 보기를 종료한다. 상세 설명에는 각 장의 전제·근거·예외·연결 문서를 담았다. 개별페이지 폴더에는 01~20의 각 장 전용 HTML을 제공한다. 모바일에서는 하단 텍스트 설명을 함께 읽을 수 있다.

## 범위

P23는 TS의 추가 기획지원 후보이며 공식 23번째 업무분류가 아니다. CCK NOA와 로컬 LLM·기존 서버를 바탕으로 하는 제안 설계다. 생성 이미지 2종은 설명용이다. 실제 TS·NOA·HWPX·기관 승인 시스템에 연결한 제품 구현물은 아니다. 도식·한글·표는 PowerPoint에서 편집할 수 있으며 생성 이미지 내부의 화살표는 래스터 개념 표현이다.

비용은 실제 구축 상태에 따라 달라지는 기존 v1.1의 기획 추정이다. 신규 인프라 투자 0원을 전제로 하며 이용권과 운영비는 별도 확인한다. 정책·예산·발주 및 공식 제출은 담당자가 판단한다.
