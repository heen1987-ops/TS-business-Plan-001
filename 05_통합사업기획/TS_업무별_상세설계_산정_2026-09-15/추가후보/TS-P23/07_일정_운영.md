# TS-P23 추진 일정·운영

교통안전 문제정의·정책사업 기획 AI 에이전트

> **기획 검토안**: P23은 추가 후보이며 조사에서 정리한 22개 업무 묶음에 포함하지 않음. CCK 주관 AX+SI / NOA·로컬 LLM / 기존 서버 / 신규 인프라 0원. 실제 API·물량·견적·효과는 확인 전.

## 추진 전제·책임

기획 책임자·대상 주제·자료 이용권한·기간·기존사업 목록·현업 반대 근거 검토자를 확정한다. 공개 분석자료로 먼저 시작하고 국민신문고 개별 원문 전체 접근을 가정하지 않는다.

CCK가 분석·NOA/LLM 구성·화면/연계·검증·운영 인계를 주관한다. TS는 자료·권한·규칙·정답·검수·공식 업무 결정을 맡는다. 원 시스템 공급사 변경 작업은 별도 책임과 범위를 확정한다.

| 단계 | 수행 | 종료·책임 |

| G4 시범·인계 | 승인 사용자·물량으로 제한 적용 | 현업 인수·운영 교육·복귀 확인 |

## 일정·인력 환산 가정

증분 중간 공수 45인일을 평균 2명·주 5일로 단순 환산하면 약 5주다. 자료·권한·현업 검토 대기 4주를 별도 가정한 참고 기간은 **약 9주**다. 공통 기능·선행 업무·조달·보안 심의 기간은 포함하지 않았다. 22개를 이 기간에 모두 수행한다는 계획이 아니다.

분석→구성→연계→시험의 의존성을 지킨다. 독립 자료 정리·화면 설계만 병행하고 실제 팀은 직무 겸임·병행을 조정한다.

## 운영·성과 환류

- 월별 지식 갱신·오류·권한 변경·실패 호출·응답 시간·수정량 검토
- 규칙·지식·프롬프트 변경 시 회귀 사례 재실행과 이전 승인 버전 보관
- 업무 지표: 근거 없는 주장·허위 인용·원인 단정·중복 사업 제안·현업 수정량·문제정의 완료시간·기획 채택 사유의 추적 가능성
- 인수인계: 설치 구성·권한표·지식 목록·연계 계약·장애·복귀 절차·제약 전달

채택·시행 후 공식 성과자료로 예상 효과와 실제 현황을 비교해 문제정의·원인 가설·대안 선택 이력을 갱신한다. 근거 없는 신사업 제안 수·채택률을 성과 목표로 삼지 않는다.
