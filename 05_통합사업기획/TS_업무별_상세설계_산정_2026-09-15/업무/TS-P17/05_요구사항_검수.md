# TS-P17 요구사항·검수

COSAS 협업 문서 검토 기능 연계

> **기획 검토안**: CCK 주관 AX+SI / NOA·로컬 LLM / 기존 서버 / 신규 인프라 0원. 실제 API·물량·견적·효과는 확인 전.

## 기능·비기능 요구사항


| ID | 요구·행동 | 수용기준·시험 |
| --- | --- | --- |
| TS-P17-HF01 | 건별 매핑 / COSAS 점검키와 P01 점검키의 유일한 대응을 관리한다. | 중복·미매핑이면 근접한 다른 건을 대신 표시하지 않는다. / TS-P17-HT01 |
| TS-P17-HF02 | 권한 전달 / 기관·역할·문서 접근권한을 서버에서 확인한다. | 화면에서 숨기는 것뿐 아니라 직접 문서 요청도 차단한다. / TS-P17-HT02 |
| TS-P17-HF03 | 상태 호환 / P01 검토 결과와 COSAS 업무 상태를 별도 필드로 유지한다. | P01 충족 후보가 COSAS 종결 상태로 자동 저장되지 않는다. / TS-P17-HT03 |
| TS-P17-HF04 | 버전 충돌 복구 / 분석 후 증빙이 바뀌면 오래된 결과임을 표시한다. | 재조회·재분석이 완료될 때까지 최신 검토 결과로 표시하지 않는다. / TS-P17-HT04 |
| TS-P17-HN01 | 접근권한·로컬 처리 / 원문·인덱스·로그·호출의 권한과 외부 경로를 점검한다. | 승인된 권한 거부 사례에서 원문·검색·직접 요청을 모두 거부하고, 기존 서버 실행 시험 중 승인되지 않은 외부 모델·데이터 전송이 관측되면 배포를 보류한다. / TS-P17-HT05 |
| TS-P17-HN02 | 근거·실패 상태·복귀 / 원문 위치·버전·조회 시점을 표시하고 자료 실패와 실제 결과를 분리한다. | 삭제·접근 철회·변경된 자료가 탐지되면 해당 결과를 최신·확정으로 표시하지 않으며 오류 시 입력을 보존하고 기존 처리 경로를 제공한다. / TS-P17-HT06 |

## RFP 수행·검수 조항 초안

- 계약 대상: L01의 문서 대조 결과를 COSAS 한 업무 화면에 연계하는 부속 과업
- 기존 납품분·추가 설정·추가 개발·업무 연계의 구분과 작업분해·견적 근거 제시
- 화면·데이터·인터페이스·권한 명세, 지식·규칙·프롬프트 버전, 시험 증거, 운영·복귀 문서 제출
- 정답·판정 책임·수정 이력을 가진 승인 평가셋 사용
- 자동 확정·권한 우회·상태 오표시를 해소한 뒤 인수 검토
- 기존 서버 사용. 신규 장비·클라우드 인프라 구매 제외

요구사항과 RFP 문안의 발주 검토 초안이다. 계약 심사·제품 인수 시험·현업 승인은 미완료다.
