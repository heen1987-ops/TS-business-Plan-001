# TS-P17 추진 일정·운영

COSAS 협업 문서 검토 기능 연계

> **기획 검토안**: CCK 주관 AX+SI / NOA·로컬 LLM / 기존 서버 / 신규 인프라 0원. 실제 API·물량·견적·효과는 확인 전.

## 추진 전제·책임

P01 결과 스키마와 COSAS 운영자의 연계 허용·키 매핑·기관 권한표가 있어야 한다.

CCK가 분석·NOA/LLM 구성·화면/연계·검증·운영 인계를 주관한다. TS는 자료·권한·규칙·정답·검수·공식 업무 결정을 맡는다. 원 시스템 공급사 변경 작업은 별도 책임과 범위를 확정한다.

## 단계·종료 조건


| 단계 | 수행 | 종료·책임 |
| --- | --- | --- |
| G0 범위 | L01의 문서 대조 결과를 COSAS 한 업무 화면에 연계하는 부속 과업 | 자료·API·계약·검토자 확인 / TS+CCK |
| G1 설계 | COSAS 키·역할·상태 계약 정의 | 요구·화면·데이터·권한·평가셋 승인 / TS |

| G3 검증 | 승인된 검토 이력 반영; 업무 상태 쓰기는 별도 범위 확정 | 기능·권한·근거·성능·복귀 시험 / CCK+TS |
| G4 시범·인계 | 승인 사용자·물량으로 제한 적용 | 현업 인수·운영 교육·복귀 확인 |
| 후속 | 추가 협업기관은 권한·매핑·회귀 시험을 수행 | 효과·자원·추가 물량 검토 후 결정 |


## 일정·인력 환산 가정

증분 중간 공수 21.5인일을 평균 2명·주 5일로 단순 환산하면 약 3주다. 자료·권한·현업 검토 대기 4주를 별도 가정한 참고 기간은 **약 7주**다. 공통 기능·선행 업무·조달·보안 심의 기간은 포함하지 않았다. 22개를 이 기간에 모두 수행한다는 계획이 아니다.

분석→구성→연계→시험의 의존성을 지킨다. 독립 자료 정리·화면 설계만 병행하고 실제 팀은 직무 겸임·병행을 조정한다.

- 규칙·지식·프롬프트 변경 시 회귀 사례 재실행과 이전 승인 버전 보관
- 업무 지표: 권한 오류·점검건 오연결·상태 불일치·중복 입력
