# TS-P07 추진 일정·운영

항공 자격 응시 준비자료 점검 지원

> **기획 검토안**: CCK 주관 AX+SI / NOA·로컬 LLM / 기존 서버 / 신규 인프라 0원. 실제 API·물량·견적·효과는 확인 전.

## 추진 전제·책임

항공 자격 1종의 경력 인정 기준·공식 증빙 유형·인계 가능 범위를 자격 담당자가 확인한다.

CCK가 분석·NOA/LLM 구성·화면/연계·검증·운영 인계를 주관한다. TS는 자료·권한·규칙·정답·검수·공식 업무 결정을 맡는다. 원 시스템 공급사 변경 작업은 별도 책임과 범위를 확정한다.

## 단계·종료 조건


| 단계 | 수행 | 종료·책임 |
| --- | --- | --- |
| G0 범위 | 항공 자격 1종의 신청 준비, 문서 유형 2종, 상태 조회·인계 각 1개 | 자료·API·계약·검토자 확인 / TS+CCK |
| G1 설계 | 경력·증빙·단위 규칙 정의 | 요구·화면·데이터·권한·평가셋 승인 / TS |
| G2 구현 | 항공 자격 1종의 경력 문진·증빙 대응표 | 정상·예외 흐름 시연 / CCK |
| G3 검증 | 공식 상태 조회와 확인된 신청 인계 연결 | 기능·권한·근거·성능·복귀 시험 / CCK+TS |
| G4 시범·인계 | 승인 사용자·물량으로 제한 적용 | 현업 인수·운영 교육·복귀 확인 |
| 후속 | 다른 자격은 경력 산입 규칙·증빙 종류를 별도 검증 | 효과·자원·추가 물량 검토 후 결정 |


## 일정·인력 환산 가정

증분 중간 공수 36인일을 평균 2명·주 5일로 단순 환산하면 약 4주다. 자료·권한·현업 검토 대기 4주를 별도 가정한 참고 기간은 **약 8주**다. 공통 기능·선행 업무·조달·보안 심의 기간은 포함하지 않았다. 22개를 이 기간에 모두 수행한다는 계획이 아니다.

분석→구성→연계→시험의 의존성을 지킨다. 독립 자료 정리·화면 설계만 병행하고 실제 팀은 직무 겸임·병행을 조정한다.

| 자료·기준 변경 | 관련 결과를 재확인 상태로 전환하고 승인 후 갱신 | 자료 소유자 |

## 운영·성과 환류

- 월별 지식 갱신·오류·권한 변경·실패 호출·응답 시간·수정량 검토
- 규칙·지식·프롬프트 변경 시 회귀 사례 재실행과 이전 승인 버전 보관
- 업무 지표: 잘못된 준비자료 안내·보완 요구 재발·신청 준비시간
- 인수인계: 설치 구성·권한표·지식 목록·연계 계약·장애·복귀 절차·제약 전달



## 준비 상태
