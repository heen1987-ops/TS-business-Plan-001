# TS-P05 요구사항·검수

철도 시험운행·시설평가 보고서 검토 준비

> **기획 검토안**: CCK 주관 AX+SI / NOA·로컬 LLM / 기존 서버 / 신규 인프라 0원. 실제 API·물량·견적·효과는 확인 전.

## 기능·비기능 요구사항


| ID | 요구·행동 | 수용기준·시험 |
| --- | --- | --- |
| TS-P05-HF01 | 평가 유형 제한 / 시험운행 유형의 승인된 필수 항목만 적용한다. | 시설평가 기준을 이름 유사성만으로 시험운행에 적용하지 않는다. / TS-P05-HT01 |
| TS-P05-HF02 | 조건을 보존한 요약 / 결과값을 시험 구간·조건·한계와 함께 제시한다. | 제약 문장이 있는 결과를 무조건 적합으로 축약하지 않는다. / TS-P05-HT02 |
| TS-P05-HF03 | 근거 위치·버전 대조 / 항목별 근거의 보고서·구간·버전을 표시한다. | 타 구간·구판 인용은 동일 근거로 처리하지 않는다. / TS-P05-HT03 |

## RFP 수행·검수 조항 초안

- 계약 대상: 여러 평가 중 시험운행 결과검토 1종 우선, 보고서 유형 3종, 조회 연계 0–1개
- 기존 납품분·추가 설정·추가 개발·업무 연계의 구분과 작업분해·견적 근거 제시
- 화면·데이터·인터페이스·권한 명세, 지식·규칙·프롬프트 버전, 시험 증거, 운영·복귀 문서 제출
- 정답·판정 책임·수정 이력을 가진 승인 평가셋 사용
- 자동 확정·권한 우회·상태 오표시를 해소한 뒤 인수 검토
- 기존 서버 사용. 신규 장비·클라우드 인프라 구매 제외

요구사항과 RFP 문안의 발주 검토 초안이다. 계약 심사·제품 인수 시험·현업 승인은 미완료다.
