# TS-P08 요구사항·검수

항공안전 자율보고 분석·전파 초안 지원

> **기획 검토안**: CCK 주관 AX+SI / NOA·로컬 LLM / 기존 서버 / 신규 인프라 0원. 실제 API·물량·견적·효과는 확인 전.

## 기능·비기능 요구사항


| ID | 요구·행동 | 수용기준·시험 |
| --- | --- | --- |
| TS-P08-HF01 | 보고 유형 확인 / 공식 규칙으로 의무·자율 보고의 확인 사항을 제시한다. | 입력만으로 법적 보고 의무 해소를 단정하지 않는다. / TS-P08-HT01 |
| TS-P08-HF02 | 조건 보존 / 비행 단계·기상 등 텍스트 조건을 원문 범위에서 정리한다. | 원문에 없는 원인·상황을 생성하지 않고 불명 조건은 미확인으로 둔다. / TS-P08-HT02 |
| TS-P08-HF03 | 유사사례 차이 표시 / 검색된 승인 사례마다 공통 위해요인과 다른 조건을 함께 제시한다. | 비슷한 제목만으로 동일 원인이나 동일 대응을 권고하지 않는다. / TS-P08-HT03 |
| TS-P08-HF04 | 전파 승인 / 검토용 원본과 공개 후보를 분리하고 승인 버전을 기록한다. | 항공 보고 원본이 철도 사례 검색에 섞이지 않고 승인 전 외부 전파되지 않는다. / TS-P08-HT04 |
| TS-P08-HN01 | 접근권한·로컬 처리 / 원문·인덱스·로그·호출의 권한과 외부 경로를 점검한다. | 승인된 권한 거부 사례에서 원문·검색·직접 요청을 모두 거부하고, 기존 서버 실행 시험 중 승인되지 않은 외부 모델·데이터 전송이 관측되면 배포를 보류한다. / TS-P08-HT05 |
| TS-P08-HN02 | 근거·실패 상태·복귀 / 원문 위치·버전·조회 시점을 표시하고 자료 실패와 실제 결과를 분리한다. | 삭제·접근 철회·변경된 자료가 탐지되면 해당 결과를 최신·확정으로 표시하지 않으며 오류 시 입력을 보존하고 기존 처리 경로를 제공한다. / TS-P08-HT06 |

## RFP 수행·검수 조항 초안

- 계약 대상: 항공 위해요인 보고 유형 1개, 원본·사례 문서 2종, 전문가 검토만 제공
- 기존 납품분·추가 설정·추가 개발·업무 연계의 구분과 작업분해·견적 근거 제시
- 화면·데이터·인터페이스·권한 명세, 지식·규칙·프롬프트 버전, 시험 증거, 운영·복귀 문서 제출
- 정답·판정 책임·수정 이력을 가진 승인 평가셋 사용
- 자동 확정·권한 우회·상태 오표시를 해소한 뒤 인수 검토
- 기존 서버 사용. 신규 장비·클라우드 인프라 구매 제외

요구사항과 RFP 문안의 발주 검토 초안이다. 계약 심사·제품 인수 시험·현업 승인은 미완료다.
