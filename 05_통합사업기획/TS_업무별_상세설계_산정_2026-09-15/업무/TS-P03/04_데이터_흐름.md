# TS-P03 데이터 흐름

위험물질 운송계획·점검 인계 문서 일치 확인

> **기획 검토안**: CCK 주관 AX+SI / NOA·로컬 LLM / 기존 서버 / 신규 인프라 0원. 실제 API·물량·견적·효과는 확인 전.

![데이터 흐름](data.svg)

## 자료의 입력·결과

운송계획·점검결과·차량 식별자·조치·인계 및 수신 기록 → 문서 일치 확인표와 인계 누락 검토 목록. 실제 DB명·API·보존기간은 자료 소유자와 확정한다.


| 논리 저장소 | 내용 | 권한·수명주기 |
| --- | --- | --- |
| D1 승인 근거 | 운송건·문서 대응표 / 원문 위치·버전·적용일 | 권한 계승 / 변경·삭제 시 색인 갱신 |
| D2 검토 결과 | 문서 상충·수신 누락 / 초안·수정·근거 | 업무 대상키·역할별 접근 / 승인본 분리 |
| D3 결정·처리 이력 | 담당자 인계·수신 확인 / 검토자·이유·참조 | 공식 상태는 원 시스템 기준 |
| D4 최소 감사 | 권한·자료 버전·행동·성공/실패 | 원문 전체 중복 저장 금지 / 보존기간 협의 |


## 데이터 정의·검증


| 논리 필드 | 의미·검증 |
| --- | --- |
| transport_plan_id / revision | 승인된 운송계획과 버전 |
| vehicle_id / material_code | 차량·물질의 공식 식별값 |
| planned_period / inspection_at | 계획 기간과 점검 시각; 시간대 고정 |
| finding_id / action_text | 점검 지적 및 조치 설명 |
| recipient_org / handoff_id | 권한 있는 수신기관과 인계번호 |
| receipt_status / confirmed_at | 발송·수신 확인 상태와 시점 |


## 품질·예외·변경 처리


| 조건 | 처리 |
| --- | --- |
| 대상·기간·단위 불일치 | 식별값 불일치는 같은 물질·차량으로 자동 합치지 않는다. |
| 문서 변경·근거 철회 | 재색인·캐시 만료·생성물 근거 상태를 함께 갱신. 최신 확정 표시 중지 |
| 권한 변경·삭제 | 원문·색인·캐시·결과 참조에 전파. 보존 의무·삭제 권한 담당자 확인 |
| 자료 내 명령 | 입력은 분석 대상이며 시스템 권한·도구 설정을 덮어쓰지 못함 |
| 자료 없음·모호함 | 전송 완료만으로 수신 완료를 표시하지 않으며 마지막 확인 시각을 표시한다. |


## 데이터 주권의 구현 조건

- 기관이 원문·색인·임베딩·질문·생성물·감사의 저장 위치와 접근을 통제
- 외부 공개자료 반입 권한과 내부 모델 처리 경계 분리
- 운영자·원격 유지보수·백업·반출·정정·삭제 경로까지 검증
- 납품 시 지식·규칙·구성·근거·검토 이력을 이관할 형식 명시


## 도식의 연결


| 연결 | 전달 내용 |
| --- | --- |
| E1 승인된 원천 → P1 반입·구조 검증 | 허용 자료 |
| P1 반입·구조 검증 → D1 근거 자료 | 검증·분리 결과 |
| D1 근거 자료 → P2 근거·규칙 검색 | 원문·메타정보 |
| P2 근거·규칙 검색 → P3 로컬 LLM 구성 | 근거·규칙 |
| P3 로컬 LLM 구성 → P4 검토·수정 | 초안·불확실성 |
| P4 검토·수정 → D2 검토 결과 | 검토된 결과 |
| D2 검토 결과 → D3 결정·처리 이력 | 승인·선택 |
| D3 결정·처리 이력 → D4 최소 감사기록 | 참조·행동 |
| P2 근거·규칙 검색 → D4 최소 감사기록 | 검색·권한 기록 |
