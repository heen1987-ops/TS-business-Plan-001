# TS-P01 개발·용역·운영 산정

운수회사 안전점검 개선조치 증빙 검토 지원

> **기획 검토안**: CCK 주관 AX+SI / NOA·로컬 LLM / 기존 서버 / 신규 인프라 0원. 실제 API·물량·견적·효과는 확인 전.

## 초기 범위·공수 가정

**운수회사 한 업종, 점검 유형 1개, 전자문서 3종, 기존 기록 조회 1개**

기존 보고서 작업별 하한·상한 공수를 유지했다. P23만 별도 제안 가정이다. 중간 공수는 산술평균이며 최빈 견적이나 확정 금액을 뜻하지 않는다.


| 작업 | 인일 하한–상한 | 직무 비중 가정 | 혼합 일 단가 |
| --- | --- | --- | --- |
| 지적·증빙 키와 정답 사례 정의 | 4–7 | 업무분석가 80% + IT PM 20% | 478,531원 |
| 요구조건·대조·보완 질문 설정 | 8–13 | 응용SW개발자 70% + 데이터분석가 30% | 389,155원 |
| 검토 화면과 P17 결과 계약 구현 | 6–10 | 응용SW개발자 70% + UI/UX기획·개발자 30% | 365,775원 |
| 대상/기간 불일치·누락 평가 및 인수인계 | 6–10 | IT테스터 60% + IT품질관리자 40% | 334,084원 |


업무 증분 합계 **24–40인일**. PM·QA는 위 배분에 포함하므로 별도로 중복 가산하지 않는다. 인일은 노동량이며 사업기간이 아니다.

도입 소계는 필요한 공통 모듈·선행 업무가 아직 없을 때다. 이미 준비된 기능은 증분만 산정한다. 운영은 공통 3인일/월 + 각 포함 업무의 가정 작업량(P23 2인일, P15/P20 0.5인일, 나머지 1인일/월)이다. 여러 업무의 도입·운영 소계를 단순 합산하지 않는다.


| 항목 | 처리 |
| --- | --- |
| 자동 포함 선행 업무 | 없음 |
| 공통 모듈 | C00, C01 / 통합 선택 시 1회 |

| 추가 라이선스·직접경비 | 미확인. 입력 0원은 비교값이며 무상 확정 아님 |
| 운영 서비스료 | 미확인. 연간 사용권·추가 유지 지원료는 별도 가산 |


## 계산식

직접인건비 = Σ(작업 인일 × 직무 비중 × 공식 일 임금). 제경비 = 직접인건비 × 144%. 기술료 = (직접인건비 + 제경비) × 20%. 공급가 = 직접인건비 + 제경비 + 기술료 + 별도 라이선스 + 직접경비. VAT = 공급가 × 10% 가정. 신규 인프라 = 0원.

공식 가이드의 투입공수 방식으로 기획 비교한다. 기능점수 방식 이윤을 여기에 다시 더하지 않는다. 최종 산정 방식·공수·요율·과세·견적은 계약 범위에 맞춰 확인한다.

## 견적 전 확인 자료

- 실제 문서·규칙·연계 물량·복잡도와 정답셋·현업 검토 책임
- NOA 설치 버전·추가 모듈 사용권·개발/배포 라이선스의 서면 견적
- 기존 계약 동일 납품분과 공통 재사용분 공제
- 보안 점검·자료 정제·교육·출장 등 실제 직접경비 확인
- 운영 범위: 지식 갱신·오류 분석·규칙 수정·권한 점검. 24시간 상주·장비 유지·대규모 자료 구축 제외
