# TS-P06 추진 일정·운영

철도안전 자율보고의 보호된 사례화

> **기획 검토안**: CCK 주관 AX+SI / NOA·로컬 LLM / 기존 서버 / 신규 인프라 0원. 실제 API·물량·견적·효과는 확인 전.

## 추진 전제·책임

보고 보호 책임자가 원본 사용 목적·접근자·보존·전파 정책을 확정한다. 확정 전 실제 원본 반입은 하지 않는다.

CCK가 분석·NOA/LLM 구성·화면/연계·검증·운영 인계를 주관한다. TS는 자료·권한·규칙·정답·검수·공식 업무 결정을 맡는다. 원 시스템 공급사 변경 작업은 별도 책임과 범위를 확정한다.

## 단계·종료 조건


| 단계 | 수행 | 종료·책임 |
| --- | --- | --- |
| G0 범위 | 철도 자율보고 유형 1개, 승인된 보고서·사례 문서 2종, 외부 쓰기 0개 | 자료·API·계약·검토자 확인 / TS+CCK |
| G1 설계 | 보고 보호정책·접근 구획·위해 분류 정의 | 요구·화면·데이터·권한·평가셋 승인 / TS |

| 후속 | 다른 보고 유형별 재식별·의미 보존 평가 후 전파 체계 연계 | 효과·자원·추가 물량 검토 후 결정 |


## 일정·인력 환산 가정

증분 중간 공수 42인일을 평균 2명·주 5일로 단순 환산하면 약 5주다. 자료·권한·현업 검토 대기 4주를 별도 가정한 참고 기간은 **약 9주**다. 공통 기능·선행 업무·조달·보안 심의 기간은 포함하지 않았다. 22개를 이 기간에 모두 수행한다는 계획이 아니다.

분석→구성→연계→시험의 의존성을 지킨다. 독립 자료 정리·화면 설계만 병행하고 실제 팀은 직무 겸임·병행을 조정한다.

## 운영·성과 환류

- 월별 지식 갱신·오류·권한 변경·실패 호출·응답 시간·수정량 검토
- 규칙·지식·프롬프트 변경 시 회귀 사례 재실행과 이전 승인 버전 보관
- 업무 지표: 안전 핵심 사실의 의미 손실·식별 위험 누락·전문가 수정 부담
- 인수인계: 설치 구성·권한표·지식 목록·연계 계약·장애·복귀 절차·제약 전달



## 준비 상태

문서 설계·기획 산정 초안 단계다. 자료권한·연계·견적·제품 시험·현업 승인·운영 반영은 미완료다. 이 문서는 배포 승인이나 확정 사업계획을 의미하지 않는다.
