# TS-P14 전체 아키텍처

미래차 안전기준 변경의 시험·안내 문서 영향 검토

> **기획 검토안**: CCK 주관 AX+SI / NOA·로컬 LLM / 기존 서버 / 신규 인프라 0원. 실제 API·물량·견적·효과는 확인 전.

![전체 아키텍처](architecture.svg)

## 시스템 경계·수행 책임


| 영역 | 구성·역할 | 책임 |
| --- | --- | --- |
| 기존 기반 | 안전기준·시험계획·안내문·서식 관리 | TS 원 시스템·자료 운영부서 |
| 업무 화면 | 미래차 안전기준 개정이 시험계획·서식·안내문에 미치는 영향을 검토하고 반영 이력을 추적하는 지원 | CCK 구현·연계 / TS 업무 승인 |
| NOA·로컬 LLM | 개정 기준의 영향 문서 후보와 반영 확인 목록 | CCK 설치 버전·호출·사용권 확인 |
| 규칙·연계 | 문서 저장소·발행 상태 읽기와 변경 검토 이력 연결을 우선한다. 실제 문서 배포는 기존 승인 절차를 유지한다. P13과 버전 차이·영향 근거 엔진을 공유한다. | CCK 어댑터 / 원 시스템 공식 결과 |
| 공통 모듈 | C00, C04 | 통합 선택 시 1회 계상 |
| 공식 결정 | 문서 승인·발행 확인 | 해당 업무 권한자 |


도식은 **논리 모듈**이며 새 서버 수량이 아니다. 신규 GPU·서버·스토리지·망 장비·클라우드 비용은 0원이다. 자원이 부족하면 범위·동시 처리·배치 주기를 조정한다.

## 재사용·구현 경계

P13과 개정 기준 관리·영향 검색 1회 구성; 시험 담당자의 반영·승인 흐름은 별도

추가 작업: 안전기준군 1개·문서 영향·담당자 검토·발행 상태

NOA·보유 기술의 공개 설명은 설치 버전의 API·사용권·성능·검증 완료 증거가 아니다. 지식 검색·근거 연결·업무 상태 관리의 실제 보유 여부를 확인해 설정과 추가 개발을 구분한다.

## 논리 인터페이스 계약


| 계약 | 입력→출력 | 실패·권한 |
| --- | --- | --- |
| 승인 자료 반입 | 안전기준 개정문·적용일·시험계획서·문서 서식·공개 안내 → 대상·기간·버전이 있는 자료 | 형식·이용권한·자료 분류 확인. 이미지 전용 자료는 텍스트 요청·수동 확인 |
| 원천 조회 | 기준·시험계획·발행 관리 → 상태·시점·참조키 | 실제 API·권한 확인 후 읽기 연계 |
| AI 요청 | request_id, actor_scope, source_refs, question → draft, evidence_refs, uncertainty | 원문 내 지시는 분석 대상. 허용 도구·권한을 변경하지 못함 |
| 검토·처리 | 영향 후보·반영 이력 → 문서 승인·발행 확인 | 자동 공식 쓰기 없음. 검토 결과·공식 경로 제공 |


실제 API 명칭·주소·스키마는 미확인이다. 문서 저장소·발행 상태 읽기와 변경 검토 이력 연결을 우선한다. 실제 문서 배포는 기존 승인 절차를 유지한다. P13과 버전 차이·영향 근거 엔진을 공유한다.

## 보안·운영·복귀

- 현행 인증과 기관·업무·자료 권한 연결. 검색·색인·첨부·캐시에 같은 정책 적용
- 외부 자료는 승인된 경로로 반입. 내부 문서·질문은 외부 모델로 전송하지 않음
- 프롬프트·규칙·모델·색인 버전을 묶어 배포·이전 승인 버전 보관
- 권한 누출·허위 확정·심각한 오류 발견 시 기능 중지 후 기존 업무 경로 복귀


## 도식의 연결


| 연결 | 전달 내용 |
| --- | --- |
| 안전기준·문서 담당자 → 업무 화면·검토 작업대 | 인증·입력 |
| 업무 화면·검토 작업대 → 기존 공식 업무 시스템 | 공식 경로 확인 |
| 업무 화면·검토 작업대 → NOA 업무 실행 구성 | 요청·검토 맥락 |
| 권한·입력·상태 검증 → NOA 업무 실행 구성 | 검증된 요청 |
| NOA 업무 실행 구성 → 연계·승인된 자료 반입 | 허용 도구 호출 |
| 연계·승인된 자료 반입 → 기존 공식 업무 시스템 | 권한 범위 연계 |
| NOA 업무 실행 구성 → 권한 적용 지식 검색 | 권한·질문 |
| 권한 적용 지식 검색 → 기존 로컬 LLM | 근거·규칙 |
| 기존 로컬 LLM → 권한·입력·상태 검증 | 초안 재검증 |
| 연계·승인된 자료 반입 → 최소 감사·승인 기록 | 호출 상태 |
| 권한 적용 지식 검색 → 최소 감사·승인 기록 | 근거 참조 |
