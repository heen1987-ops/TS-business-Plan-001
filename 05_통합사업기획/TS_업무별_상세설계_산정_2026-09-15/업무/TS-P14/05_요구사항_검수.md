# TS-P14 요구사항·검수

미래차 안전기준 변경의 시험·안내 문서 영향 검토

> **기획 검토안**: CCK 주관 AX+SI / NOA·로컬 LLM / 기존 서버 / 신규 인프라 0원. 실제 API·물량·견적·효과는 확인 전.

## 기능·비기능 요구사항


| ID | 요구·행동 | 수용기준·시험 |
| --- | --- | --- |
| TS-P14-HF01 | 관할·적용일 관리 / 국내외 기준과 시행일·경과 적용을 별도 필드로 둔다. | 해외 개정을 국내 즉시 적용 의무로 바꾸지 않는다. / TS-P14-HT01 |
| TS-P14-HF02 | 영향 근거 연결 / 변경 조항과 영향을 받는 문서 부분을 함께 제시한다. | 키워드 일치만으로 필수 개정이라고 단정하지 않고 영향 사유를 검토 가능하게 한다. / TS-P14-HT02 |
| TS-P14-HF03 | 채택·기각 이력 / 담당자가 영향 후보를 채택·기각하고 사유를 기록한다. | 기각된 후보를 다음 검색에서 확정 영향으로 되살리지 않고 새 근거일 때 재검토로 표시한다. / TS-P14-HT03 |
| TS-P14-HF04 | 반영·발행 확인 / 문서의 승인본과 실제 발행 버전을 비교한다. | 초안 저장만으로 반영 완료를 표시하지 않는다. / TS-P14-HT04 |
| TS-P14-HN01 | 접근권한·로컬 처리 / 원문·인덱스·로그·호출의 권한과 외부 경로를 점검한다. | 승인된 권한 거부 사례에서 원문·검색·직접 요청을 모두 거부하고, 기존 서버 실행 시험 중 승인되지 않은 외부 모델·데이터 전송이 관측되면 배포를 보류한다. / TS-P14-HT05 |
| TS-P14-HN02 | 근거·실패 상태·복귀 / 원문 위치·버전·조회 시점을 표시하고 자료 실패와 실제 결과를 분리한다. | 삭제·접근 철회·변경된 자료가 탐지되면 해당 결과를 최신·확정으로 표시하지 않으며 오류 시 입력을 보존하고 기존 처리 경로를 제공한다. / TS-P14-HT06 |

## RFP 수행·검수 조항 초안

- 계약 대상: 안전기준군 1개, 시험계획/서식/안내 3종, 실제 개정 사례 1개
- 기존 납품분·추가 설정·추가 개발·업무 연계의 구분과 작업분해·견적 근거 제시
- 화면·데이터·인터페이스·권한 명세, 지식·규칙·프롬프트 버전, 시험 증거, 운영·복귀 문서 제출
- 정답·판정 책임·수정 이력을 가진 승인 평가셋 사용
- 자동 확정·권한 우회·상태 오표시를 해소한 뒤 인수 검토
- 기존 서버 사용. 신규 장비·클라우드 인프라 구매 제외

요구사항과 RFP 문안의 발주 검토 초안이다. 계약 심사·제품 인수 시험·현업 승인은 미완료다.
