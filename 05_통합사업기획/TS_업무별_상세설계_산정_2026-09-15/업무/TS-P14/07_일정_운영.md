# TS-P14 추진 일정·운영

미래차 안전기준 변경의 시험·안내 문서 영향 검토

> **기획 검토안**: CCK 주관 AX+SI / NOA·로컬 LLM / 기존 서버 / 신규 인프라 0원. 실제 API·물량·견적·효과는 확인 전.

## 추진 전제·책임

기준 담당자가 국내 적용·시행일을 확정하고 문서 관리자가 문서 목록·소유자·발행 상태를 제공한다.

CCK가 분석·NOA/LLM 구성·화면/연계·검증·운영 인계를 주관한다. TS는 자료·권한·규칙·정답·검수·공식 업무 결정을 맡는다. 원 시스템 공급사 변경 작업은 별도 책임과 범위를 확정한다.

## 단계·종료 조건


| 단계 | 수행 | 종료·책임 |
| --- | --- | --- |
| G0 범위 | 안전기준군 1개, 시험계획/서식/안내 3종, 실제 개정 사례 1개 | 자료·API·계약·검토자 확인 / TS+CCK |
| G1 설계 | 기준·문서·담당자·발행 관계 정의 | 요구·화면·데이터·권한·평가셋 승인 / TS |
| G2 구현 | 안전기준군 1개·3종 문서·개정 사례 1개의 영향 검토 | 정상·예외 흐름 시연 / CCK |
| G3 검증 | 문서 소유자·승인·실제 발행 확인 연결 | 기능·권한·근거·성능·복귀 시험 / CCK+TS |
| G4 시범·인계 | 승인 사용자·물량으로 제한 적용 | 현업 인수·운영 교육·복귀 확인 |
| 후속 | 새 기준군은 관할·적용일 규칙과 영향 평가 사례를 추가 | 효과·자원·추가 물량 검토 후 결정 |


## 일정·인력 환산 가정

증분 중간 공수 35.5인일을 평균 2명·주 5일로 단순 환산하면 약 4주다. 자료·권한·현업 검토 대기 4주를 별도 가정한 참고 기간은 **약 8주**다. 공통 기능·선행 업무·조달·보안 심의 기간은 포함하지 않았다. 22개를 이 기간에 모두 수행한다는 계획이 아니다.

분석→구성→연계→시험의 의존성을 지킨다. 독립 자료 정리·화면 설계만 병행하고 실제 팀은 직무 겸임·병행을 조정한다.

| 위험 | 대응 | 책임 |

| 자료·기준 변경 | 관련 결과를 재확인 상태로 전환하고 승인 후 갱신 | 자료 소유자 |
| 권한 위반·허위 확정 | 기능 중지→영향 조사→기존 경로 복귀→재검증 | 보안·업무 책임자 |

## 운영·성과 환류

- 월별 지식 갱신·오류·권한 변경·실패 호출·응답 시간·수정량 검토
- 규칙·지식·프롬프트 변경 시 회귀 사례 재실행과 이전 승인 버전 보관
- 업무 지표: 필수 반영 대상 누락·잘못된 영향 제시·오래된 안내 잔존
- 인수인계: 설치 구성·권한표·지식 목록·연계 계약·장애·복귀 절차·제약 전달



## 준비 상태

문서 설계·기획 산정 초안 단계다. 자료권한·연계·견적·제품 시험·현업 승인·운영 반영은 미완료다. 이 문서는 배포 승인이나 확정 사업계획을 의미하지 않는다.
