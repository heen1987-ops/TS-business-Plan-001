# TS-P21 추진 일정·운영

교통안전 체험교육 전후 실천 지원

> **기획 검토안**: CCK 주관 AX+SI / NOA·로컬 LLM / 기존 서버 / 신규 인프라 0원. 실제 API·물량·견적·효과는 확인 전.

## 추진 전제·책임

교육 책임자가 학습목표·교재·사용 시점과 강사 검토 역할을 확정한다. 교육 효과 평가는 실제 교육생 동의·운영 조건 확보 후 수행한다.

CCK가 분석·NOA/LLM 구성·화면/연계·검증·운영 인계를 주관한다. TS는 자료·권한·규칙·정답·검수·공식 업무 결정을 맡는다. 원 시스템 공급사 변경 작업은 별도 책임과 범위를 확정한다.

## 단계·종료 조건


| 단계 | 수행 | 종료·책임 |
| --- | --- | --- |
| G0 범위 | 교육과정 1개·승인된 교재/사례 2종, 교육상태 조회 1개, 강사 검토 후 사용 | 자료·API·계약·검토자 확인 / TS+CCK |
| G1 설계 | 학습목표·교재·교육 평가 정의 | 요구·화면·데이터·권한·평가셋 승인 / TS |
| G2 구현 | 과정 1개의 강사 검토형 상황 문답·실천 확인 | 정상·예외 흐름 시연 / CCK |
| G3 검증 | 동의한 후속 응답과 교안 개선 이력 연결 | 기능·권한·근거·성능·복귀 시험 / CCK+TS |
| G4 시범·인계 | 승인 사용자·물량으로 제한 적용 | 현업 인수·운영 교육·복귀 확인 |
| 후속 | 다른 과정·P22 이륜차 콘텐츠팩을 같은 엔진에 추가 | 효과·자원·추가 물량 검토 후 결정 |


## 일정·인력 환산 가정

증분 중간 공수 30.5인일을 평균 2명·주 5일로 단순 환산하면 약 4주다. 자료·권한·현업 검토 대기 4주를 별도 가정한 참고 기간은 **약 8주**다. 공통 기능·선행 업무·조달·보안 심의 기간은 포함하지 않았다. 22개를 이 기간에 모두 수행한다는 계획이 아니다.

분석→구성→연계→시험의 의존성을 지킨다. 독립 자료 정리·화면 설계만 병행하고 실제 팀은 직무 겸임·병행을 조정한다.

## 운영·위험·복귀


| 위험 | 대응 | 책임 |
| --- | --- | --- |
| 교육 문답 개선을 무사고 효과로 과장할 위험. 우선 근거 정확성·학습 확인·강사 수정량을 측정하고 사고성과는 장기 별도 검증한다. | 현행 비교안·제한 시범으로 효용 측정 | TS 현업·CCK PM |
| 기존 서버 과부하 | 동시 요청·문서 분할·배치·범위 조정. 신규 장비비 편입 없음 | CCK·TS 운영 |
| 자료·기준 변경 | 관련 결과를 재확인 상태로 전환하고 승인 후 갱신 | 자료 소유자 |
| 권한 위반·허위 확정 | 기능 중지→영향 조사→기존 경로 복귀→재검증 | 보안·업무 책임자 |
| 연계 오류 | 교안 수정 → 재승인 | 원 시스템 운영부서 |
| 효과 미달 | 원인·피드백·범위 수정 후 재평가 또는 중단 | 사업 책임자 |


## 운영·성과 환류

- 월별 지식 갱신·오류·권한 변경·실패 호출·응답 시간·수정량 검토
- 규칙·지식·프롬프트 변경 시 회귀 사례 재실행과 이전 승인 버전 보관
- 업무 지표: 안전수칙 오설명·핵심 내용 이해·강사 수정량·후속 실천 확인
- 인수인계: 설치 구성·권한표·지식 목록·연계 계약·장애·복귀 절차·제약 전달



## 준비 상태

문서 설계·기획 산정 초안 단계다. 자료권한·연계·견적·제품 시험·현업 승인·운영 반영은 미완료다. 이 문서는 배포 승인이나 확정 사업계획을 의미하지 않는다.
