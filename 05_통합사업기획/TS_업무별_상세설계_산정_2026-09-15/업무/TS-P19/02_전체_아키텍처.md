# TS-P19 전체 아키텍처

DRT 이용 조건·예약 완료 지원

> **기획 검토안**: CCK 주관 AX+SI / NOA·로컬 LLM / 기존 서버 / 신규 인프라 0원. 실제 API·물량·견적·효과는 확인 전.

![전체 아키텍처](architecture.svg)

## 시스템 경계·수행 책임


| 영역 | 구성·역할 | 책임 |
| --- | --- | --- |
| 기존 기반 | 지자체 DRT 예약·배차·취소와 TS 지원플랫폼 | TS 원 시스템·자료 운영부서 |
| 업무 화면 | DRT 이용 조건을 텍스트로 확인하고 지역별 공식 접수·배차 상태를 알려주는 이용 지원 | CCK 구현·연계 / TS 업무 승인 |
| NOA·로컬 LLM | 자유로운 이동 요구를 필수 조건으로 정리, 대안 설명·예약 준비 | CCK 설치 버전·호출·사용권 확인 |
| 규칙·연계 | 지자체 운영자의 가용성 조회와 예약 요청 각 1개를 협의한다. TS 지원플랫폼의 역할과 실제 운영기관의 권한을 구분한다. P10의 예약 확인·오류복구 패턴만 재사용하며 배차 엔진은 신규 구축하지 않는다. | CCK 어댑터 / 원 시스템 공식 결과 |
| 공통 모듈 | C00, C02 | 통합 선택 시 1회 계상 |
| 공식 결정 | 운영사의 예약·배차 | 해당 업무 권한자 |


도식은 **논리 모듈**이며 새 서버 수량이 아니다. 신규 GPU·서버·스토리지·망 장비·클라우드 비용은 0원이다. 자원이 부족하면 범위·동시 처리·배치 주기를 조정한다.

## 재사용·구현 경계

P10과 자연어 조건·확인·실패 복구 구조 공유; 배차/운행 규칙은 별도

추가 작업: 지역 규칙팩·예약 연계·접수/배차 구분·취소 예외

NOA·보유 기술의 공개 설명은 설치 버전의 API·사용권·성능·검증 완료 증거가 아니다. 지식 검색·근거 연결·업무 상태 관리의 실제 보유 여부를 확인해 설정과 추가 개발을 구분한다.

## 논리 인터페이스 계약


| 계약 | 입력→출력 | 실패·권한 |
| --- | --- | --- |
| 승인 자료 반입 | 지역 이용 규칙·출발/도착 조건·공식 가용/예약 상태·동의 → 대상·기간·버전이 있는 자료 | 형식·이용권한·자료 분류 확인. 이미지 전용 자료는 텍스트 요청·수동 확인 |
| 원천 조회 | 지자체 DRT 예약·배차 → 상태·시점·참조키 | 실제 API·권한 확인 후 읽기 연계 |
| AI 요청 | request_id, actor_scope, source_refs, question → draft, evidence_refs, uncertainty | 원문 내 지시는 분석 대상. 허용 도구·권한을 변경하지 못함 |
| 검토·처리 | 가능 대안·접수/배차 상태 → 운영사의 예약·배차 | 최종 명시 확인·멱등키·모호한 결과 재조회 |


실제 API 명칭·주소·스키마는 미확인이다. 지자체 운영자의 가용성 조회와 예약 요청 각 1개를 협의한다. TS 지원플랫폼의 역할과 실제 운영기관의 권한을 구분한다. P10의 예약 확인·오류복구 패턴만 재사용하며 배차 엔진은 신규 구축하지 않는다.

## 보안·운영·복귀

- 현행 인증과 기관·업무·자료 권한 연결. 검색·색인·첨부·캐시에 같은 정책 적용
- 외부 자료는 승인된 경로로 반입. 내부 문서·질문은 외부 모델로 전송하지 않음
- 프롬프트·규칙·모델·색인 버전을 묶어 배포·이전 승인 버전 보관
- 권한 누출·허위 확정·심각한 오류 발견 시 기능 중지 후 기존 업무 경로 복귀


## 도식의 연결


| 연결 | 전달 내용 |
| --- | --- |
| DRT 이용자·안내 직원 → 업무 화면·검토 작업대 | 인증·입력 |
| 업무 화면·검토 작업대 → 기존 공식 업무 시스템 | 공식 경로 확인 |
| 업무 화면·검토 작업대 → NOA 업무 실행 구성 | 요청·검토 맥락 |
| 권한·입력·상태 검증 → NOA 업무 실행 구성 | 검증된 요청 |
| NOA 업무 실행 구성 → 연계·승인된 자료 반입 | 허용 도구 호출 |
| 연계·승인된 자료 반입 → 기존 공식 업무 시스템 | 권한 범위 연계 |
| NOA 업무 실행 구성 → 권한 적용 지식 검색 | 권한·질문 |
| 권한 적용 지식 검색 → 기존 로컬 LLM | 근거·규칙 |
| 기존 로컬 LLM → 권한·입력·상태 검증 | 초안 재검증 |
| 연계·승인된 자료 반입 → 최소 감사·승인 기록 | 호출 상태 |
| 권한 적용 지식 검색 → 최소 감사·승인 기록 | 근거 참조 |
