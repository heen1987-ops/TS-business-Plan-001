# TS-P11 요구사항·검수

기계식주차장 검사 후 보완 증빙 연결

> **기획 검토안**: CCK 주관 AX+SI / NOA·로컬 LLM / 기존 서버 / 신규 인프라 0원. 실제 API·물량·견적·효과는 확인 전.

## 기능·비기능 요구사항


| ID | 요구·행동 | 수용기준·시험 |
| --- | --- | --- |
| TS-P11-HF01 | 시설·부위 연결 / 시설키와 지적 부위로 보수 자료를 연결한다. | 같은 업체가 제출해도 타 시설 보수 기록은 충족 근거로 쓰지 않는다. / TS-P11-HT01 |
| TS-P11-HF02 | 보수 내용 대조 / 지적 항목의 요구 조치와 실제 텍스트 작업 범위를 비교한다. | 점검만 했다는 문장을 교체·수리 완료로 바꾸지 않는다. / TS-P11-HT02 |
| TS-P11-HF03 | 비텍스트 증빙 인계 / 사진만 있는 증빙을 수동 검토 목록으로 분리한다. | 사진을 보지 않고 안전상태·보수 완료를 생성하지 않는다. / TS-P11-HT03 |
| TS-P11-HF04 | 재확인 상태 유지 / 공식 재확인 결과를 읽어 검토 이력에 연결한다. | 서류가 갖춰져도 필수 현장 확인 전 종결로 바뀌지 않는다. / TS-P11-HT04 |
| TS-P11-HN01 | 접근권한·로컬 처리 / 원문·인덱스·로그·호출의 권한과 외부 경로를 점검한다. | 승인된 권한 거부 사례에서 원문·검색·직접 요청을 모두 거부하고, 기존 서버 실행 시험 중 승인되지 않은 외부 모델·데이터 전송이 관측되면 배포를 보류한다. / TS-P11-HT05 |
| TS-P11-HN02 | 근거·실패 상태·복귀 / 원문 위치·버전·조회 시점을 표시하고 자료 실패와 실제 결과를 분리한다. | 삭제·접근 철회·변경된 자료가 탐지되면 해당 결과를 최신·확정으로 표시하지 않으며 오류 시 입력을 보존하고 기존 처리 경로를 제공한다. / TS-P11-HT06 |

## RFP 수행·검수 조항 초안

- 계약 대상: 검사 종류 1개·시설 1개 시범, 지적/보수/재확인 문서 3종, 조회 1개
- 기존 납품분·추가 설정·추가 개발·업무 연계의 구분과 작업분해·견적 근거 제시
- 화면·데이터·인터페이스·권한 명세, 지식·규칙·프롬프트 버전, 시험 증거, 운영·복귀 문서 제출
- 정답·판정 책임·수정 이력을 가진 승인 평가셋 사용
- 자동 확정·권한 우회·상태 오표시를 해소한 뒤 인수 검토
- 기존 서버 사용. 신규 장비·클라우드 인프라 구매 제외

요구사항과 RFP 문안의 발주 검토 초안이다. 계약 심사·제품 인수 시험·현업 승인은 미완료다.
