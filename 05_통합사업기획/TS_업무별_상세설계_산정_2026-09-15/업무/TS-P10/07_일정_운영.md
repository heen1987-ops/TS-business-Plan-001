# TS-P10 추진 일정·운영

자동차검사 예약 탐색·재검사 후속행동 지원

> **기획 검토안**: CCK 주관 AX+SI / NOA·로컬 LLM / 기존 서버 / 신규 인프라 0원. 실제 API·물량·견적·효과는 확인 전.

## 추진 전제·책임

예약 운영부서가 가용상태·마감·확정 응답·중복 요청 처리 방식을 제공하고 현행 탐색 동선을 재현한다.

CCK가 분석·NOA/LLM 구성·화면/연계·검증·운영 인계를 주관한다. TS는 자료·권한·규칙·정답·검수·공식 업무 결정을 맡는다. 원 시스템 공급사 변경 작업은 별도 책임과 범위를 확정한다.

## 단계·종료 조건


| 단계 | 수행 | 종료·책임 |
| --- | --- | --- |
| G0 범위 | 예약 탐색 1개 흐름을 우선, 차량 유형 1개, 가용성 조회 1개; 재검사 지원은 후속 범위 | 자료·API·계약·검토자 확인 / TS+CCK |
| G1 설계 | 현재 동선·가용성 계약·차량 조건 확인 | 요구·화면·데이터·권한·평가셋 승인 / TS |
| G2 구현 | 읽기 가용성·달력·조건 유지 화면과 자연어 조건 확인을 통합 검증 | 정상·예외 흐름 시연 / CCK |
| G3 검증 | 최종 확인·예약 결과 재조회·중복 방지까지 연계 | 기능·권한·근거·성능·복귀 시험 / CCK+TS |
| G4 시범·인계 | 승인 사용자·물량으로 제한 적용 | 현업 인수·운영 교육·복귀 확인 |
| 후속 | 공식 검사 결과와 조치 문구가 확보되면 재검사 후속 안내를 별도 추가 | 효과·자원·추가 물량 검토 후 결정 |


## 일정·인력 환산 가정

증분 중간 공수 41인일을 평균 2명·주 5일로 단순 환산하면 약 5주다. 자료·권한·현업 검토 대기 4주를 별도 가정한 참고 기간은 **약 9주**다. 공통 기능·선행 업무·조달·보안 심의 기간은 포함하지 않았다. 22개를 이 기간에 모두 수행한다는 계획이 아니다.

분석→구성→연계→시험의 의존성을 지킨다. 독립 자료 정리·화면 설계만 병행하고 실제 팀은 직무 겸임·병행을 조정한다.

## 운영·성과 환류

- 월별 지식 갱신·오류·권한 변경·실패 호출·응답 시간·수정량 검토
- 규칙·지식·프롬프트 변경 시 회귀 사례 재실행과 이전 승인 버전 보관
- 업무 지표: 빈자리 탐색시간·화면 왕복·상태 불일치·중복 예약
- 인수인계: 설치 구성·권한표·지식 목록·연계 계약·장애·복귀 절차·제약 전달



## 준비 상태

문서 설계·기획 산정 초안 단계다. 자료권한·연계·견적·제품 시험·현업 승인·운영 반영은 미완료다. 이 문서는 배포 승인이나 확정 사업계획을 의미하지 않는다.
