# TS-P10 요구사항·검수

자동차검사 예약 탐색·재검사 후속행동 지원

> **기획 검토안**: CCK 주관 AX+SI / NOA·로컬 LLM / 기존 서버 / 신규 인프라 0원. 실제 API·물량·견적·효과는 확인 전.

## 기능·비기능 요구사항


| ID | 요구·행동 | 수용기준·시험 |
| --- | --- | --- |
| TS-P10-HF01 | 조건 해석·확인 / 자연어 날짜·지역을 필수/선호 조건으로 바꾸고 이용자에게 보여준다. | 상대 날짜의 기준일과 시간 범위를 표시하며 임의로 이동 한도를 넓히지 않는다. / TS-P10-HT01 |
| TS-P10-HF02 | 가용성 선표시 / 검사소 목록과 달력에 공식 가능·마감·휴무·미확인 상태를 표시한다. | 마감 확인만을 위해 별도 화면 진입을 요구하지 않고 조회 불가를 마감으로 바꾸지 않는다. / TS-P10-HT02 |
| TS-P10-HF03 | 대안 비교 / 동일 날짜 다른 검사소와 같은 검사소 다른 날짜를 분리해 제시한다. | 필수 조건 밖 대안은 변경 조건을 표시하고 이용자 승인 없이 예약하지 않는다. / TS-P10-HT03 |
| TS-P10-HF04 | 예약 경합 복구 / 최종 요청 전 유효 상태를 확인하고 요청 결과가 모호하면 원 시스템을 재조회한다. | 타임아웃 후 같은 예약을 바로 중복 전송하지 않으며 공식 예약번호가 있을 때만 완료 표시한다. / TS-P10-HT04 |
| TS-P10-HN01 | 접근권한·로컬 처리 / 원문·인덱스·로그·호출의 권한과 외부 경로를 점검한다. | 승인된 권한 거부 사례에서 원문·검색·직접 요청을 모두 거부하고, 기존 서버 실행 시험 중 승인되지 않은 외부 모델·데이터 전송이 관측되면 배포를 보류한다. / TS-P10-HT05 |
| TS-P10-HN02 | 근거·실패 상태·복귀 / 원문 위치·버전·조회 시점을 표시하고 자료 실패와 실제 결과를 분리한다. | 삭제·접근 철회·변경된 자료가 탐지되면 해당 결과를 최신·확정으로 표시하지 않으며 오류 시 입력을 보존하고 기존 처리 경로를 제공한다. / TS-P10-HT06 |

## RFP 수행·검수 조항 초안

- 계약 대상: 예약 탐색 1개 흐름을 우선, 차량 유형 1개, 가용성 조회 1개; 재검사 지원은 후속 범위
- 기존 납품분·추가 설정·추가 개발·업무 연계의 구분과 작업분해·견적 근거 제시
- 화면·데이터·인터페이스·권한 명세, 지식·규칙·프롬프트 버전, 시험 증거, 운영·복귀 문서 제출
- 정답·판정 책임·수정 이력을 가진 승인 평가셋 사용
- 자동 확정·권한 우회·상태 오표시를 해소한 뒤 인수 검토
- 기존 서버 사용. 신규 장비·클라우드 인프라 구매 제외

요구사항과 RFP 문안의 발주 검토 초안이다. 계약 심사·제품 인수 시험·현업 승인은 미완료다.
