# TS-P16 추진 일정·운영

공식 운행분석 결과의 안전행동 설명 지원

> **기획 검토안**: CCK 주관 AX+SI / NOA·로컬 LLM / 기존 서버 / 신규 인프라 0원. 실제 API·물량·견적·효과는 확인 전.

## 추진 전제·책임

ETAS 운영자가 지표 정의·확정 결과·조회 권한을 제공하고 교육 담당자가 실천 지침을 승인한다.

CCK가 분석·NOA/LLM 구성·화면/연계·검증·운영 인계를 주관한다. TS는 자료·권한·규칙·정답·검수·공식 업무 결정을 맡는다. 원 시스템 공급사 변경 작업은 별도 책임과 범위를 확정한다.

## 단계·종료 조건


| 단계 | 수행 | 종료·책임 |
| --- | --- | --- |
| G0 범위 | ETAS 결과 유형 1개·승인된 안전지침 1개, 조회 1개, 다른 정보시스템은 후속 | 자료·API·계약·검토자 확인 / TS+CCK |
| G1 설계 | ETAS 코드·단위·비교조건 정의 | 요구·화면·데이터·권한·평가셋 승인 / TS |
| G2 구현 | ETAS 지표 유형 1개와 승인 지침으로 설명·질문 초안 | 정상·예외 흐름 시연 / CCK |
| G3 검증 | 교육 담당자 승인·사용 후 확인을 교육 흐름에 연결 | 기능·권한·근거·성능·복귀 시험 / CCK+TS |
| G4 시범·인계 | 승인 사용자·물량으로 제한 적용 | 현업 인수·운영 교육·복귀 확인 |
| 후속 | 추가 지표는 단위·조건·설명 평가팩을 먼저 확정 | 효과·자원·추가 물량 검토 후 결정 |


## 일정·인력 환산 가정

증분 중간 공수 30.5인일을 평균 2명·주 5일로 단순 환산하면 약 4주다. 자료·권한·현업 검토 대기 4주를 별도 가정한 참고 기간은 **약 8주**다. 공통 기능·선행 업무·조달·보안 심의 기간은 포함하지 않았다. 22개를 이 기간에 모두 수행한다는 계획이 아니다.

분석→구성→연계→시험의 의존성을 지킨다. 독립 자료 정리·화면 설계만 병행하고 실제 팀은 직무 겸임·병행을 조정한다.

## 운영·성과 환류

- 월별 지식 갱신·오류·권한 변경·실패 호출·응답 시간·수정량 검토
- 규칙·지식·프롬프트 변경 시 회귀 사례 재실행과 이전 승인 버전 보관
- 업무 지표: 수치·기간 설명 오류·교육 내용 이해·담당자 수정량
- 인수인계: 설치 구성·권한표·지식 목록·연계 계약·장애·복귀 절차·제약 전달



## 준비 상태

문서 설계·기획 산정 초안 단계다. 자료권한·연계·견적·제품 시험·현업 승인·운영 반영은 미완료다. 이 문서는 배포 승인이나 확정 사업계획을 의미하지 않는다.
