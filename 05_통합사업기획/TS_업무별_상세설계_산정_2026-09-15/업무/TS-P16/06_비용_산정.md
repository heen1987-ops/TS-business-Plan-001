# TS-P16 개발·용역·운영 산정

공식 운행분석 결과의 안전행동 설명 지원

> **기획 검토안**: CCK 주관 AX+SI / NOA·로컬 LLM / 기존 서버 / 신규 인프라 0원. 실제 API·물량·견적·효과는 확인 전.

## 초기 범위·공수 가정

**ETAS 결과 유형 1개·승인된 안전지침 1개, 조회 1개, 다른 정보시스템은 후속**

기존 보고서 작업별 하한·상한 공수를 유지했다. P23만 별도 제안 가정이다. 중간 공수는 산술평균이며 최빈 견적이나 확정 금액을 뜻하지 않는다.


| 작업 | 인일 하한–상한 | 직무 비중 가정 | 혼합 일 단가 |
| --- | --- | --- | --- |
| ETAS 코드·단위·비교조건 정의 | 4–7 | 업무분석가 80% + IT PM 20% | 478,531원 |
| 결과 설명·지침 연결 설정 | 6–10 | 응용SW개발자 70% + 데이터분석가 30% | 389,155원 |
| 결과 조회·교육 검토 UI 구현 | 6–10 | 응용SW개발자 70% + UI/UX기획·개발자 30% | 365,775원 |
| 수치 보존·비교 오류·과잉 판단 시험 | 7–11 | IT테스터 60% + IT품질관리자 40% | 334,084원 |


업무 증분 합계 **23–38인일**. PM·QA는 위 배분에 포함하므로 별도로 중복 가산하지 않는다. 인일은 노동량이며 사업기간이 아니다.

## 계산식

직접인건비 = Σ(작업 인일 × 직무 비중 × 공식 일 임금). 제경비 = 직접인건비 × 144%. 기술료 = (직접인건비 + 제경비) × 20%. 공급가 = 직접인건비 + 제경비 + 기술료 + 별도 라이선스 + 직접경비. VAT = 공급가 × 10% 가정. 신규 인프라 = 0원.

공식 가이드의 투입공수 방식으로 기획 비교한다. 기능점수 방식 이윤을 여기에 다시 더하지 않는다. 최종 산정 방식·공수·요율·과세·견적은 계약 범위에 맞춰 확인한다.
