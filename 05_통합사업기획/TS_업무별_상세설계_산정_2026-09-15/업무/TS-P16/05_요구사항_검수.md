# TS-P16 요구사항·검수

공식 운행분석 결과의 안전행동 설명 지원

> **기획 검토안**: CCK 주관 AX+SI / NOA·로컬 LLM / 기존 서버 / 신규 인프라 0원. 실제 API·물량·견적·효과는 확인 전.

## 기능·비기능 요구사항


| ID | 요구·행동 | 수용기준·시험 |
| --- | --- | --- |
| TS-P16-HF01 | 원 수치 보존 / 설명에 쓰는 수치는 ETAS 확정 결과에서 가져온다. | 값·단위·기간이 누락되면 값을 채우지 않고 설명을 보류한다. / TS-P16-HT01 |
| TS-P16-HF02 | 비교 조건 확인 / 기간·거리·지표 정의가 다른 결과는 직접 증감으로 비교하지 않는다. | 조건 불일치를 보여주고 운전자 위험이 증가했다고 단정하지 않는다. / TS-P16-HT02 |
| TS-P16-HF03 | 지침 근거 설명 / 공식 지표와 승인 교육지침을 연결해 실천 질문을 만든다. | 지침에 없는 차량 조작 요령이나 새로운 위험도 점수를 만들지 않는다. / TS-P16-HT03 |
| TS-P16-HF04 | 교육용 검토 / 교육 담당자가 문구·적용 상황을 검토한 버전만 사용한다. | AI 설명이 징계·채용·운전적격 판정으로 자동 전환되지 않는다. / TS-P16-HT04 |
| TS-P16-HN01 | 접근권한·로컬 처리 / 원문·인덱스·로그·호출의 권한과 외부 경로를 점검한다. | 승인된 권한 거부 사례에서 원문·검색·직접 요청을 모두 거부하고, 기존 서버 실행 시험 중 승인되지 않은 외부 모델·데이터 전송이 관측되면 배포를 보류한다. / TS-P16-HT05 |
| TS-P16-HN02 | 근거·실패 상태·복귀 / 원문 위치·버전·조회 시점을 표시하고 자료 실패와 실제 결과를 분리한다. | 삭제·접근 철회·변경된 자료가 탐지되면 해당 결과를 최신·확정으로 표시하지 않으며 오류 시 입력을 보존하고 기존 처리 경로를 제공한다. / TS-P16-HT06 |

## RFP 수행·검수 조항 초안

- 계약 대상: ETAS 결과 유형 1개·승인된 안전지침 1개, 조회 1개, 다른 정보시스템은 후속
- 기존 납품분·추가 설정·추가 개발·업무 연계의 구분과 작업분해·견적 근거 제시
- 화면·데이터·인터페이스·권한 명세, 지식·규칙·프롬프트 버전, 시험 증거, 운영·복귀 문서 제출
- 정답·판정 책임·수정 이력을 가진 승인 평가셋 사용
- 자동 확정·권한 우회·상태 오표시를 해소한 뒤 인수 검토
- 기존 서버 사용. 신규 장비·클라우드 인프라 구매 제외

요구사항과 RFP 문안의 발주 검토 초안이다. 계약 심사·제품 인수 시험·현업 승인은 미완료다.
