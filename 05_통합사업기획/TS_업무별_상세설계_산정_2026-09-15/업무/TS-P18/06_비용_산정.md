# TS-P18 개발·용역·운영 산정

K-패스 이용 등록·처리결과 이해 지원

> **기획 검토안**: CCK 주관 AX+SI / NOA·로컬 LLM / 기존 서버 / 신규 인프라 0원. 실제 API·물량·견적·효과는 확인 전.

## 초기 범위·공수 가정

**등록 완료 확인 또는 미지급 상태 설명 중 1개 흐름, 조회 1개·인계 1개**

기존 보고서 작업별 하한·상한 공수를 유지했다. P23만 별도 제안 가정이다. 중간 공수는 산술평균이며 최빈 견적이나 확정 금액을 뜻하지 않는다.


| 작업 | 인일 하한–상한 | 직무 비중 가정 | 혼합 일 단가 |
| --- | --- | --- | --- |
| 등록 상태·사유·본인확인 범위 정의 | 4–7 | 업무분석가 80% + IT PM 20% | 478,531원 |
| 상태 설명·다음 행동 설정 | 6–10 | 응용SW개발자 70% + 데이터분석가 30% | 389,155원 |
| 조회·정정 인계·입력 유지 구현 | 8–13 | 응용SW개발자 70% + UI/UX기획·개발자 30% | 365,775원 |
| 타인 조회·사유 불명·미접수 시험 | 6–10 | IT테스터 60% + IT품질관리자 40% | 334,084원 |


업무 증분 합계 **24–40인일**. PM·QA는 위 배분에 포함하므로 별도로 중복 가산하지 않는다. 인일은 노동량이며 사업기간이 아니다.

| 추가 라이선스·직접경비 | 미확인. 입력 0원은 비교값이며 무상 확정 아님 |
| 운영 서비스료 | 미확인. 연간 사용권·추가 유지 지원료는 별도 가산 |


## 계산식

직접인건비 = Σ(작업 인일 × 직무 비중 × 공식 일 임금). 제경비 = 직접인건비 × 144%. 기술료 = (직접인건비 + 제경비) × 20%. 공급가 = 직접인건비 + 제경비 + 기술료 + 별도 라이선스 + 직접경비. VAT = 공급가 × 10% 가정. 신규 인프라 = 0원.

공식 가이드의 투입공수 방식으로 기획 비교한다. 기능점수 방식 이윤을 여기에 다시 더하지 않는다. 최종 산정 방식·공수·요율·과세·견적은 계약 범위에 맞춰 확인한다.
