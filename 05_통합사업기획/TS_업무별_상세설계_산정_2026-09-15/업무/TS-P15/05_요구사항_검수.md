# TS-P15 요구사항·검수

전기차 배터리 식별정보 확인 절차 지원

> **기획 검토안**: CCK 주관 AX+SI / NOA·로컬 LLM / 기존 서버 / 신규 인프라 0원. 실제 API·물량·견적·효과는 확인 전.

## 기능·비기능 요구사항


| ID | 요구·행동 | 수용기준·시험 |
| --- | --- | --- |
| TS-P15-HF01 | 제작사별 안내 / 제작사와 질문 목적에 맞는 승인 안내만 사용한다. | 다른 제작사의 앱 경로를 적용하지 않는다. / TS-P15-HT01 |

| TS-P15-HF03 | 식별과 상태 구분 / 식별번호의 목적만 공식 자료 범위에서 설명한다. | 번호만으로 수명·화재 위험·건강상태를 추정하지 않는다. / TS-P15-HT03 |

| TS-P15-HN02 | 근거·실패 상태·복귀 / 원문 위치·버전·조회 시점을 표시하고 자료 실패와 실제 결과를 분리한다. | 삭제·접근 철회·변경된 자료가 탐지되면 해당 결과를 최신·확정으로 표시하지 않으며 오류 시 입력을 보존하고 기존 처리 경로를 제공한다. / TS-P15-HT06 |

## RFP 수행·검수 조항 초안

- 계약 대상: 제작사 1곳의 공식 절차 안내, 공개 문서 1종, 개인 데이터 연계 0개
- 기존 납품분·추가 설정·추가 개발·업무 연계의 구분과 작업분해·견적 근거 제시
- 화면·데이터·인터페이스·권한 명세, 지식·규칙·프롬프트 버전, 시험 증거, 운영·복귀 문서 제출
- 정답·판정 책임·수정 이력을 가진 승인 평가셋 사용
- 자동 확정·권한 우회·상태 오표시를 해소한 뒤 인수 검토
- 기존 서버 사용. 신규 장비·클라우드 인프라 구매 제외

요구사항과 RFP 문안의 발주 검토 초안이다. 계약 심사·제품 인수 시험·현업 승인은 미완료다.
