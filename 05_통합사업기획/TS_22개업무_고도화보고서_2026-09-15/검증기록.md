## 2. 직접 화면 검토·수정 이력

직접 확인한 대표 화면은 통합 데스크톱·모바일 검색·P10 요구사항·모바일 표·공통 예산 산식·모바일 목차 도착이다.

2. 직접 시각 검토에서 연속된 물결표 범위가 Markdown 취소선으로 해석되는 오류를 발견했다. 범위 표기를 en dash로 바꾸고 모든 HTML의 del/s 요소가 0개임을 구조 검증에 포함했다.
3. 모바일 표의 좌우 이동 안내와 업무 내부 단계/프로그램 예산 차수의 구분을 보완했다. 전체 문서를 재생성하고 162개 검증을 다시 통과했다.
4. 실제 이전 요구사항 ID가 F1–F4임을 확인해 초기 F01 형태 연결을 생성 단계에서 수정했다. 최종 88개 계보는 존재하는 ID와 일치한다.
