기구축 사업 CCK AI 적용 공통 수행설계

2026-09-15 v0.2. 기존 구축 업무와 AI 기능의 후속 적용·개선을 포함한다.[49]

1. 적용 방식

기존 문서·DB·서비스 화면 → 허용된 조회/자료 연결 → CCK NOA·로컬 LLM의 설명·검토·초안 → 사용자/담당자 확인 → 공식 시스템 인계·결과 확인으로 구성한다. 기존 자료를 쓰는 독립 보조 화면, 기존 화면 내 AI 기능, 허용 API를 통한 처리 지원 중 현재 연계 조건에 맞춰 선택한다. API가 없으면 승인 자료 업로드·내보내기와 공식 화면 인계로 범위를 정할 수 있다.

2. 공통 기능과 업무별 추가 작업

공통화할 부분 각 업무에서 추가할 부분
사용 가능한 NOA 실행·접근권한·근거 UI·감사 설치 환경·업무 권한·모델 설정 차이 검증
증빙 대조 P01·03·04·05·11·12·17 문서 구조·식별자·법정 기준·검토 사례·커넥터
안내/처리 P02·07·09·10·15·18·19·20 질문·지식·규칙·조회·접수/배차/지급 상태·본인확인
보호된 사례 P06·08 제도별 분류·보호 규칙·저장/접근 영역·전파 승인
기준 변경 P13·14 기준군·영향 문서·제작자/시험기관의 승인 절차

공통 기능군은 발주 사업 수가 아니다. P01/P17과 P21/P22의 통합은 중복 개발을 피하는 구성 제안이며 사업 영역을 제외하는 판정이 아니다.

3. CCK의 수행·검수

CCK는 사용권이 확인된 솔루션의 구성, 업무 지식·규칙, 화면·연계, 실제 자료 평가, 배포 설정·교육·운영 인수를 총괄하는 역할안이다. 기존 운영사는 조회·변경 인터페이스와 권한·상태 호환을 협의한다. 담당기관이 자격·접수·공개·안전·지급의 최종 권한을 갖는다. 제품 소개가 실제 해당 버전의 구현·품질 증거를 대신하지 않는다.[33][48]

4. 비용 산식과 계약 대조

기존 구축비 전체를 재산정하지 않고 공통 구성 1회 + 업무별 설정·지식·화면·연계·시험 추가 공수 + 확인된 증분 사용료·운영비로 산정한다. 새 적용을 위한 데이터 정비·설치·설정·튜닝·시험은 수행비 대상이다. 이미 계약된 같은 납품물은 기존 이행 또는 재사용으로 표시한다. 기존 AI의 기능 개선은 전후 기능·수용기준·작업량으로 증분을 설명한다.[43]

1차 7억·2차 추가 5억은 VAT 포함 해석의 프로그램 목표 상한이며 22개 전체 견적이 아니다. 신규 GPU·서버·저장/백업/망 구매·증설·임차·클라우드 자원비는 0원이다. 기존 환경의 응용 SW 구성·통합·검증 공수는 별도다. 공식 단가·가용인력·물량 확인 전 금액을 확정하지 않는다.[48]

5. 운영·품질

원본·검색 인덱스·로그·백업·라이선스 호출을 포함해 로컬 처리와 접근권한을 확인한다. 변경된 원문·권한을 검색·초안에 반영하고 근거가 없으면 미확인으로 표시한다. 실제 접수 응답 전에 완료라고 하지 않는다. 문서 제안 기능을 중단해도 기존 업무로 복귀할 수 있도록 버전·설정과 원 시스템을 보존한다.

6. 적용 규모 결정

기존 기능표 → CCK 적용 단위 → 추가 작업 물량 → 현업 사례·품질/효과 비교 → 공수·견적 → 단계 확대 순서로 본다. 비AI 비교는 적용 규모·효과를 확인하는 방법이며 기구축 업무를 일괄 제외하는 조건이 아니다. P15처럼 작은 안내는 공통 상담 모듈로, P01/P17처럼 같은 업무는 통합 적용으로 구성한다.
