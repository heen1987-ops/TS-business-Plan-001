# 사업기획 검토 체크리스트

현재 기준은 [신규사업 범위와 중복배제](../00_기획지침/신규사업_범위와_중복배제.md)다. 현재 추진사업 외 신규 **AX 전환 또는 디지털전환+AI+정보화사업**을 기획한다. 독립 R&D·기존 공통플랫폼·민원·전세버스 공시 AI 연장은 제외하고, 필요한 연구·PoC는 전환사업의 세부 과업으로만 검토한다.

- [ ] 현재 추진사업의 업무·기능·산출물과 비중복을 대조했다.
- [ ] AS-IS/TO-BE·디지털전환·AI·정보화 구축/연계·운영 책임이 모두 있다.
- [ ] 유보·제외와 독립 R&D를 신규사업 집계에서 분리했다.

이 문서는 향후 사업기획서를 검토하기 위한 양식입니다. 체크되지 않은 항목은 검토 완료를 뜻하지 않습니다.

## TS 신규 사업기획 필수 기준

- [ ] P01: R&D의 국민 수혜집단·문제·실증 가설을 설명하고 단순 내부 자동화와 연구 필요성을 구별했다.
- [ ] P02: 감원 우려·직무 변화·현업 수용성을 실제 의견과 연결했다. 인력 영향을 숨기거나 시간 절감을 감축 인원으로 바로 환산하지 않았다.
- [ ] P03: AX 미반영 정보화의 AX+SI 결합을 검토했고 비AI 대안·SI·AI·통합 운영을 비교했다.
- [ ] P04: 메가이슈의 기간·통계·피해집단·원인과 TS 법정업무의 연결 근거가 있다.
- [ ] P05: TS 실증에서 유사 기관·범정부로 확장할 공통 기능과 기관별 법령·권한·데이터 차이를 기록했다.
- [ ] P06: 기관 유형·주무부처·설립 근거·개별 위탁/지정·수행조직을 현행 원문과 대조했다. 기관명으로 권한을 추정하지 않았다.
- [ ] P07: 공공·TS·지금·AI의 WHY, 기술가치별 검증 지표, 생애주기 비용, 사업 유형별 심의 경로를 제시했다.

해당 없으면 사유를 기록합니다. 필수 근거의 미검증은 보류 사유이며 모든 과제에 동일한 심의가 적용된다고 가정하지 않습니다.

## 근거와 사업 적합성

- [ ] 문제, 대상 사용자, 해결 가치가 구체적이다.
- [ ] 주요 주장과 수치에 원문 출처와 위치가 있다.
- [ ] 사실·해석·가정·미검증 사항을 구분했다.
- [ ] 현행본과 보관본을 구분하고 상충 내용은 해결하거나 미결로 표시했다.
- [ ] 기존 TS 과업과의 중복, 추가 범위, 제약을 검토했다.
- [ ] 변동 정보는 적용 시점의 원문과 대조했다.

## 실행과 사용자 관점

- [ ] 목표, 범위, 제외범위, 수용기준이 명확하다.
- [ ] 필요한 데이터·권한·인력·예산의 확보 여부가 표시됐다.
- [ ] 비용과 효과의 산정 근거를 재확인할 수 있다.
- [ ] 일정, 담당자, 의존관계, 산출물이 연결된다.
- [ ] 주요 성공·실패 시나리오와 운영 책임을 검토했다.
- [ ] 개인정보·보안·접근성 영향을 검토했다. 해당 없으면 이유를 남겼다.
- [ ] 사용자의 업무 부담과 도입·학습 비용을 검토했다.
- [ ] 실사용자에게 확인한 내용과 내부 가정을 구별했다.
- [ ] 중단·전환 조건과 복귀 방안이 있다.
