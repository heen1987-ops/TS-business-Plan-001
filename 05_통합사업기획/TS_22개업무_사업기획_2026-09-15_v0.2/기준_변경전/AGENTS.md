# TS 신규 사업기획 작업 지침

2026-09-09 사용자가 제시한 7개 기획 기준을 이 프로젝트에 적용한다. 새 사업의 조사·제안·검토를 시작할 때 `00_기획지침/TS_신규사업기획_지침.md`를 읽는다.

현재 신규사업 범위는 아카이브에 추진 중인 사업을 제외한 **AX 전환 또는 디지털전환+AI+정보화사업**이다. `00_기획지침/신규사업_범위와_중복배제.md`를 함께 읽는다. 기존 공통플랫폼·민원·전세버스 공시 AI의 후속 확장을 신규사업으로 재포장하지 않는다. 독립 R&D는 현재 기획 대상이 아니며 필요한 연구·PoC는 전환사업의 세부 과업으로 둔다. 유보·제외 항목은 기록을 보존하되 신규 검토대상 집계에서 분리한다.

1. R&D는 국민의 안전·편익·접근성 문제를 해결하는 대외 솔루션을 우선한다.
2. 내부 효율화는 감원 우려와 현업 수용성을 검토한다. 업무시간 절감을 감축 인원으로 환산하거나 인력 영향을 숨기지 않는다. 안전·품질·전문성·서비스 개선을 우선 평가한다.
3. AX가 반영되지 않은 정보화사업은 AX+SI 결합을 기본 검토안으로 둔다. 기존 SI·비AI 대안과 비교해 AI의 추가 가치를 입증한다.
4. 사회적 메가이슈를 TS의 실제 법정업무·수탁업무와 연결한 뒤 국민 문제와 해결 가설을 정의한다.
5. TS에서 검증하고 타 공공기관·범정부로 확장할 수 있도록 공통 기능과 기관별 법령·규칙·데이터·권한을 구분한다.
6. 정부기관, 공공기관의 지정 유형, 지방공기업 등을 구별한다. 기관명만으로 유형·위탁업무를 추정하지 않는다. 설립 근거, 개별 업무 근거, 위임·위탁 관계, 실제 수행조직을 출처와 시행일로 매핑한다.
7. WHY와 기술가치철학을 국민의 권익, 공공성, AI 필요성, 책임성, 재정 타당성, 검증 지표로 구체화한다. 사업 유형·재원·규모·시점에 맞는 심의·협의 경로를 확인하며 모든 신규 사업에 동일한 사전 심의를 단정하지 않는다.

## 근거와 산출물

- 현재 작업 폴더에 기획 산출물을 작성하고 기존 TS 원본은 읽기 전용으로 참조한다.
- `00_자료목록/기존_TS_프로젝트_맥락.md`에서 기존 사업과 신규 기획의 경계를 확인한다. 파생 문서의 원문 검증 표기를 자신의 검증 결과로 승격하지 않는다.
- 계약 이행, 신규 사업기회, 수행사 내부 도구를 구별한다. 원본 WBS·예시·과거 일정은 실제 현재 상태의 근거가 아니다.
- 사용자 현장 의견은 출처가 사용자임을 기록한다. TS의 공식 의사결정이나 전 직원 의견으로 일반화하지 않는다.
- 법령·제도는 공식 원문, 시행일, 조사일, 적용 판단을 함께 기록한다. 열람 실패·부분 열람·미확인은 그대로 남긴다.
- 지속 조사 결과는 `04_기관리서치`의 원장·대기열·이력에 누적한다. 전체 기관 조사 완료는 공식 모집단과 검토 완료 건수를 대조한 뒤에만 표시한다.
- 범정부 확장은 공통 구조의 재사용 가능성이다. 기관 간 개인정보·업무 데이터 통합 권한이 확보됐다는 뜻이 아니다.
- 신규 사업은 기획서와 검토 체크리스트에 P01~P07 충족 근거를 작성한다.
