TS-P20 데이터 개방센터 이용·분석 준비 지원

승인된 연구자·기업 이용자와 데이터 개방 담당자이 겪는 문제를 데이터 개방센터 이용·분석 준비 지원로 줄이는 AX+SI 기획 초안이다. 내부·연구자 편의에서 국민 성과로 이어지는 경로와 AI 필요성을 추가 확인.

구분 내용
업무 연결 TS-L20 · 교통정보 서비스 · 데이터 개방센터
검토 상태 문제 재검증. 핵심 업무의 공식 안내 확인; 수요·현행 법령 전체·최종 계약·제품 성능 미검증
대상 독자·발주 검토 CCK 사업·기술·수행 책임자, TS 해당 업무부서. 실제 발주부서·재원 미확정
기술·자원 전제 NOA·로컬 LLM, 기존 서버, 신규 인프라 구매·임차·클라우드 비용 0원
판정의 범위 별도 신규 사업 등록·사업 선정·CCK 주관 수행 확정 아님
기준일 업무 재확인 2026-09-14. 개별 출처의 최초 조사일·재열람 여부는 각주 참조

1. 실제 업무와 기획 대상

확인된 업무: 자동차 생애주기 등 데이터의 통제된 분석 이용 지원. [25]

수행 근거와 경계: TS 데이터 개방센터 열람·분석 지원과 반출 제한 안내 확인. AI 학습·재배포 허용으로 확대하지 않음. 업무의 존재와 새 AI 과업의 발주 필요성은 별도 판단이다. 페이지의 법령 인용은 조사 출발점이며 현행 법령·위탁·사무분장을 모두 대조한 법률 검토 결과가 아니다.

공식 업무 중 이번 초기 범위: 공개 카탈로그 1개 분야·이용 절차 문서 2종, 원시 데이터 연계 0개. 나머지 세부 업무는 이번 최소 구축 범위에 넣지 않고 동일 묶음의 후속 검토로 둔다.

2. 국민·현업 문제와 WHY

  • 문제의 근거 수준: 데이터의 정의·이용조건·제공절차를 이해하지 못해 분석 준비를 반복하는 가설.
  • 설명용 상황: 이용자가 필요한 변수는 찾았지만 반출 가능 범위와 신청 목적을 혼동하는 상황. 실제 관찰·면담 결과로 일반화하지 않는다.
  • 국민 가치: 잘못된 안내·보완 누락·처리 실패를 줄이고 근거를 확인할 수 있게 한다. 안전 업무에서는 검토의 질을 높이는 경로를 검증하며 사고 감소를 직접 보장하지 않는다.
  • 공공 개입 이유: 법정 절차·공공 안전서비스에서 이용자의 정보 격차와 업무 실패를 줄일 필요가 있다.
  • 왜 AI인가: 검색 가능한 데이터 사전·이용 안내·정형 신청 양식만으로 해결되지 않는 자유 서술의 조건 해석·근거 연결이 있는지 비교한다. 같은 효과가 나면 AI 개발 범위를 줄이거나 제외한다.
  • 수요 확인: 반복 이용 불편·실제 신청 사례·카탈로그 품질·국민 성과 연결.

3. 현재 흐름과 변경할 행동

현재 업무는 공식 안내에서 확인했지만 실제 화면 조작·처리시간·오류 발생률은 현장 확인 전이다. 아래 변경 흐름은 제안이다.

  1. 이용 목적을 확인하고 카탈로그에서 관련 자료 후보 제시.
  2. 정의·항목·이용 제한을 근거와 함께 설명.
  3. 신청서의 목적·필요항목 누락을 점검.
  4. 담당자가 이용·제공·반출 여부를 심사.

최종 산출물은 데이터 탐색 근거와 신청 준비 목록이다. LLM의 자연스러운 답변이나 문서 생성 자체를 업무 완료로 표시하지 않는다.

4. 서비스 범위와 요구사항

요구사항 ID 수행할 기능 수용기준 초안
TS-P20-F1 이용 목적을 확인하고 카탈로그에서 관련 자료 후보 제시 입력·근거·사용자 또는 담당자 확인·결과 상태가 추적되고 미확인 값은 미확인으로 유지
TS-P20-F2 정의·항목·이용 제한을 근거와 함께 설명 입력·근거·사용자 또는 담당자 확인·결과 상태가 추적되고 미확인 값은 미확인으로 유지
TS-P20-F3 신청서의 목적·필요항목 누락을 점검 입력·근거·사용자 또는 담당자 확인·결과 상태가 추적되고 미확인 값은 미확인으로 유지
TS-P20-F4 담당자가 이용·제공·반출 여부를 심사 입력·근거·사용자 또는 담당자 확인·결과 상태가 추적되고 미확인 값은 미확인으로 유지
  • 핵심 입력: 승인된 카탈로그·자료 사전·이용 지침·신청 목적 텍스트.
  • 결과: 데이터 탐색 근거와 신청 준비 목록.
  • 초기 물량: 2개 문서 유형, 1개 규칙·지침 묶음, 0개 조회 인터페이스, 0개 처리·인계 인터페이스를 상한 가정으로 견적 확인한다. 실제 API 개수나 제공 사실이 아니다.
  • 제외: 비전·OCR·STT·TTS·센서·차량제어·검사설비, 자동 법적·안전 판정, 기관 간 원본 데이터의 포괄 통합.
  • 입력 제한: 텍스트 전자문서·승인된 정형 결과만 사용한다. 스캔·사진 필수자료는 기존 공식 제출경로에서 사람이 확인하며 전체 제출절차를 AI가 완결했다고 표시하지 않는다.

5. 데이터·NOA·SI 및 책임

계층 역할·범위 확보 상태
데이터 승인된 카탈로그·자료 사전·이용 지침·신청 목적 텍스트 담당부서 허용·표본·품질·용도 확인 전
NOA·로컬 LLM 입력 서술의 구조화·검색·근거 설명·데이터 탐색 근거와 신청 준비 목록 초안 공급사 설명과 내부 대장 참고; TS 버전·실행·사용권 검증 전
업무 규칙·SI 카탈로그 버전·공개/비공개 분리·신청서 초안 저장·담당자 인계 인터페이스·권한·변경 협조 미확정
사람 사실 정정, 보완·적격·안전·공개·발송의 최종 확인 데이터 개방 담당부서·안심구역 운영기관와 실제 분장 협의 필요
CCK 주관 범위 요구사항·NOA 구성·업무 모듈·연계·검수·운영 인수 총괄 담당 인력·가용률·납품계약 확인 전

NOA 공개 소개는 폐쇄망·업무 연결·감사·사람 검토를 설명한다. 특정 기능이 현재 TS 설치물에서 동작한다는 증거와는 다르다. 내부 대장의 기재와 현재 정정도 원 코드·사용권·실행 시험을 대신하지 않으므로, NL2SQL·승인 중단/재개·자동 재실행을 기본 보유 기능으로 확정하지 않는다.[33][44][45][46]

기존 운영사에는 카탈로그 버전·공개/비공개 분리·신청서 초안 저장·담당자 인계의 계약·인터페이스 협조를 요청하는 역할안을 둔다. 협력사 확보나 기관 협조가 완료됐다는 뜻은 아니다. 초기에는 조회·검토 결과 생성까지 제한하며 기존 시스템의 결정·상태 변경은 담당자가 수행한다.

6. 대안·중복과 현재 판정

대안 범위·효과 가설 비용·기간 영향 판단
현행 유지·운영 개선 검색 가능한 데이터 사전·이용 안내·정형 신청 양식 신규 구축 최소; 반복 문제 잔존 여부 확인 유효한 비교 기준
SI·규칙 개선 입력·식별자·상태·원문 검색 정비 연계·데이터 정비 필요, LLM 운영 부담 없음 같은 목표를 달성하면 우선 적용
NOA+SI 데이터 탐색 근거와 신청 준비 목록와 검토 흐름 문서 정비·AI 평가·연계·운영 비용 추가 문제 재검증

중복 대조: 기존 카탈로그·신청 시스템·공통플랫폼 검색, 자연어 SQL 신기능 보유 단정 금지. 비교 단위는 업무·대상자·입력 데이터·기능·산출물·성과다. SFR-001~009 정리자료는 기존 플랫폼·자동차검사/자격시험/안전단속 특화·민원·전세버스 공시 기능을 명시한다. 계약 원문·승인된 직무 시나리오와 같은 범위이면 신규로 제안하지 않는다.[43][31]

현재 판단: 문제 재검증 — 내부·연구자 편의에서 국민 성과로 이어지는 경로와 AI 필요성을 추가 확인. 비중복·제품·수요 검증 전에는 확정 후보나 발주 가능 사업으로 승격하지 않는다.

7. 화면·예외·사용자 경험

화면 ID 목표·주요 행동 권한·표시
TS-P20-UI1 입력·자료·현재 상태 확인 본인 또는 담당 권한, 필수 입력·자료 미확보 표시
TS-P20-UI2 데이터 탐색 근거와 신청 준비 목록 검토 원문·버전·확인/미확인·상충을 함께 표시
TS-P20-UI3 수정·확인·인계 결과 확인 사용자·담당자 승인 기록, 원천 접수·판정과 AI 초안을 구분
  • 업무 예외: 반출 심사를 통과하지 않은 분석 결과를 외부 파일로 내보내지 않음.
  • 로딩: 문서·시스템 조회 중임을 표시하고 중복 실행을 막는다.
  • 빈 상태: 자료·결과가 없다는 사실과 다음 확인 항목을 표시한다.
  • 권한 없음: 자료 제목·요약도 노출하지 않고 허용된 문의 경로를 제시한다.
  • 일부 성공·타임아웃: 완료된 단계와 실패 단계를 나누고 마지막 확인시점·재시도 가능 여부를 표시한다.
  • 접근성 목표: WCAG 2.2 AA를 목표로 키보드·초점·레이블·확대·스크린리더를 설계 단계에서 검증한다. 이번 기획 문서 검사는 제품 접근성 인증이 아니다.
  • 개인정보·운영: 로그는 최소 식별자·상태 중심, 원문 접근은 별도 권한, 원본 변경·삭제를 검색 인덱스·캐시까지 반영한다. 보존기간은 업무 규정으로 확정한다.

8. 성공지표와 시험 설계

핵심 지표는 변수 정의 오안내·권한 위반·신청 보완·분석 준비시간다. 기준값은 미측정이며 임의의 달성률을 쓰지 않는다. 같은 업무 사례에서 현행/비AI와 NOA+SI를 비교하고 입력·모델·규칙·동시성·문서 버전을 기록한다. 표본과 목표 개선폭은 실제 자료와 피해 수준을 보고 실증 전에 정한다.

시험 Given / When / Then 요약 합격 기준 초안 상태
TS-P20-T1 정상 승인된 자료가 있을 때 해당 입력을 처리하면 데이터 탐색 근거와 신청 준비 목록와 원문 근거가 연결됨 필수 근거와 상태 연결 누락 없음 미수행
TS-P20-T2 업무 예외 반출 심사를 통과하지 않은 분석 결과를 외부 파일로 내보내지 않음 해당 예외에서 완료·적합·공개를 임의 확정하지 않음 미수행
TS-P20-T3 권한·개정 권한 회수 또는 원문 개정 후 조회하면 제한·개정 상태가 반영됨 사전 정의한 시험 사례에서 무권한 노출 0건 미수행
TS-P20-T4 인계·복구 승인·접수 실패 또는 중복 요청 시 결과를 확인하고 재처리 무승인 상태변경·허위 완료 표시·중복 처리 0건 미수행
TS-P20-T5 가치 비교 동일 입력을 검색 가능한 데이터 사전·이용 안내·정형 신청 양식과 비교 중대한 품질 저하 없이 사전 합의한 국민·현업 지표 개선 미수행

시험집의 실패 0건은 실제 운영 위험 0의 보증이 아니다. 안전·개인정보 결함은 빈도와 피해를 함께 검토하며 미해결 중대 결함이 남으면 확대하지 않는다. 개선시간을 감축 인원으로 환산하지 않는다. 현업 의견은 아직 수집하지 않았고, 검토 품질·교육·국민 지원에 확보 시간을 활용하는 방안을 협의한다.

9. 비용·일정·납품 범위

  • 축소/중단 조건: 비중복 미입증, 허용 자료 부재, 비AI와 차별적 성과 없음, 기존 서버 품질 미달, 중대 결함 발생.

  • 확장: 공공 데이터 이용신청 준비 패턴; 원시 데이터·승인 권한은 기관별. 기관 간 개인정보·업무자료 통합 권한을 확보했다는 뜻은 아니다.

  • 자체 기획 판정: 문제 재검증. 실제 실행 승인·외부 평가위원 판정은 미실시.
