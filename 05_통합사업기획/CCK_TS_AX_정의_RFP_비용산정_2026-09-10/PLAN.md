# CCK TS AX 정의와 발주 검토 패키지

2026-09-10. L 규모, Medium 위험의 사업 구체화 문서 작업. Stage Gate와 요구사항 추적을 적용한다. 실제 제품 개발·공고·계약·배포는 수행하지 않는다.

- 범위: X01~X05 전체 정의. X02·X04의 제한된 업무 유형을 1단계, X01·X03·X05를 조건부 2단계로 산정한다.
- 산출물: 서비스 정의서, 요구사항 정의서, 요구사항 명세서, RFP 초안 각 DOCX/MD, 수식 포함 비용 XLSX, 비용 설명 MD, 추적표, HTML 목록.
- 가정: 현재 업무량·API·제품 견적·GPU 부하·실제 투입인력이 미확정이다. 모든 신규 범위·공수·납기·품질 목표는 검토안이다.
- 수용 기준: 다섯 서비스의 사용자·절차·제외·소유자가 구분되고 요구사항 ID가 명세·검수·비용에 연결되어야 한다. 공통 개발·운영·직접경비 중복을 배제하고 입력 변경 시 계산이 갱신되어야 한다.
- 품질 게이트: 내용 범위 → 추적성 → 수식·독립 계산 → Word/Excel 시각 점검. 실제 제품과 사업 추진 가능성의 승인과 구별한다.
- 쓰기 범위: 이 폴더와 조사 이력만. 기존 기술 확장 문서와 G 드라이브 원본은 변경하지 않는다.
- 롤백: 생성 산출물은 독립 폴더에 보관하므로 기존 산출물에 영향이 없다.
- 생략: 실제 제품 UI 구현, 현장 실증, 운영 배포 문서, 정식 FP 측정. 이번 작업은 발주 전 설계·예산 검토용이다.
