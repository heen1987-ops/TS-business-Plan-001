# TS 국민 편의와 안전 AX 요구사항 정의서

버전 0.1 · 2026-09-10 · 발주 전 검토안

이 문서는 무엇을 왜 제공해야 하는지를 정의한다. 구현 동작·예외·검수의 상세 기준은 03 요구사항 명세서, 계약 요구와 제출 지시는 04 RFP에서 관리한다. 동일한 요구 ID를 문서 간 유지한다.

## 사업 요구와 범위

| 사업 요구 | 대상과 연결 요구 | 검토 지표와 비용 |
| --- | --- | --- |
| BR01 가능한 예약을 적은 왕복으로 찾는다 | X01 / SFR-101~104 | 희망조건 보존·후보 탐색시간·왕복 횟수 / W07 |
| BR02 공식 검사 결과에서 다음 행동을 이해한다 | X02 / SFR-201~204 | 필수 행동 누락·근거 없는 안내·이해도 / W04 |
| BR03 관찰 사실을 정확하게 보고한다 | X03 / SFR-301~304 | 사실 변경·필수정보 누락·수신 확인 / W08 |
| BR04 지적사항과 조치 증빙을 빠짐없이 연결한다 | X04 / SFR-401~404 | 증빙 미연결·미해결 지적·담당자 재검토 / W05 |
| BR05 신청 요건을 확인하고 보완한다 | X05 / SFR-501~504 | 준비물 누락·보완 횟수·신청 단계 전환 / W09 |
| BR06 근거와 현행 기준을 추적한다 | 공통 / SFR-002~003,006; DAR-001 | 출처·버전 보존과 승인 후 반영 / W02 |
| BR07 동의와 권한에 맞게 처리한다 | 공통 / SFR-004~005,007; SER-001~003 | 무권한 접근·허위 완료·중복 실행 / W03 |
| BR08 로컬 환경에서 안정적으로 제공한다 | 공통 / SFR-001; PER-001~002; COR-001 | 외부 전송 차단·응답시간·복구 / W02,W06,W10 |
| BR09 누구나 사용하고 오류를 고친다 | 공통 / UIR-001; QUR-001~002 | 키보드 완결·빈 상태·정정과 비교평가 / W06,W10 |
| BR10 서비스 개선과 책임 있는 인수를 수행한다 | 공통 / SFR-008; PMR-001~004; TER-001 | 시험·변경·라이선스·운영 인수 / W01,W06,W10 |

## 가정과 규모 기준

| ID | 기준 | 가정 |
| --- | --- | --- |
| A01 | 범위 | 5개 업무군의 제한된 1개 대표 업무씩. 전국 전업무 구축 아님. |
| A02 | 일정 | 1단계 8개월, 이후 2단계 6개월의 순차 도입 가정. 계약 전 적정사업기간 재산정. |
| A03 | 운영 부하 | 전체 일 2,000 업무 세션, 동시 생성 10건, 요청당 입력 8,000·출력 1,000 토큰 이내를 초기 검증 조건으로 가정. 실제 피크 미확정. |
| A04 | 데이터 | 전체 전자 텍스트 10,000건 이하, 5개 시스템 연계. 신규 OCR·도면·영상·센서 처리 없음. |
| A05 | 기술 자산 | 기존 자산 사용권과 로컬 호환성을 계약 전 입증. 자유 NL2SQL, 신규 기반모델 학습, 대규모 파인튜닝 미포함. |
| A06 | 가격 시점 | 2026년 불변 가격. 향후 발주 임금·견적·환율 변동 반영 필요. |
| A07 | 견적 방식 | 본 WBS 공수 모델은 초기 ROM. 확정된 FP, 원가계산서, 공급사 견적이 아님. |
| A08 | 가산 계수 | 개발 제경비 144%, 기술료 20%는 초기 가격화 가정. 운영 가이드의 범위를 참고한 임시 계수이며 개발에 자동 적용되는 법정요율로 주장하지 않음. |
| A09 | 유상 운영 | 전체 도입·검수 후 12개월 정상 운영의 연간 증분비. 24시간 전담 인력·콜센터 없음. 하자보수는 계약 책임으로 구분하여 중복 청구 배제. |
| A10 | 예비 충당 | 구축 공급가액의 15%를 사업주 예산 여유로 별도 표시. 계약대가·자동 지급액 아님. |

### 채택과 변경 기준

필수는 해당 서비스가 계약 범위에 채택될 때의 필수다. 2단계 항목을 1단계 검수 조건으로 자동 적용하지 않는다. 요구 제거·변경은 관련 화면·API·시험·WBS·비용을 함께 갱신하고 변경 사유·승인자·적용 버전을 남긴다.

착수 전 확정 항목: 대표 업무와 데이터 제공, API 계약, CCK 제품 데모·사용권·인력, 기존 과업 비중복, 품질 목표와 시험 환경, 발주 및 심의 경로. API 미제공 시 준비/조회 모드로의 축소를 별도 합의하며 전체 실행 모드 비용을 그대로 지급하지 않는다.
