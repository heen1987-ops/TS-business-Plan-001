# 기존 로컬 서버 사용과 신규 인프라 투자 0원 반영

2026-09-10 · v0.3

- 문제: v0.2에 남은 저장·백업 보완비와 인프라 구매 조건이 사용자 확정 제약과 충돌한다.
- 작업 유형: 문서·원가 모델 수정. 규모 M, 위험 Medium. Stage Gate와 요구사항 추적을 간소 적용한다.
- 변경: v0.2 서비스와 36.6 MM 유지, 신규 인프라 투자 0원 고정, 장비 유지보수·자원 증분 제거. 7억+5억 상한 유지.
- 포함: 응용 SW 이용권·개발·배포 설정·연계·검수·교육, 응용서비스의 백업 설정·복원 시험 공수.
- 가정: VAT 포함 상한·가산율·공수는 기존 산정 가정. 기존 서버 사용은 사용자 확정이나 용량은 실측 전.
- 수용기준: 현재 문서 4종·MD·HTML·Excel에 인프라 0원이 일치하고, 구매 대안이 남지 않으며, 계산·링크·화면과 Word 페이지가 유효하다.
- 검증: 직접 비용·VAT 독립 계산, Excel 재계산/입력 변경/인프라 제약, Word 전체 렌더, HTML 링크/검색/모바일.
- 보존: v0.1·v0.2 원본은 이력으로 보존하고 진입 안내만 추가한다. 운영 배포는 하지 않는다.
- 미수행: 제품 성능 시험, 실제 사용자 조사, TS 인수, 외부 독립 평가위원 승인. 새로운 대규모 설계서와 별도 제품 구현은 불필요하므로 생략한다.
