# TS AX 예산 조정 요구사항 명세서

버전 0.2 · 2026-09-10 · 발주 전 검토안

현재 납품 후보는 36개 요구다. v0.1 명세의 숫자만 바꾼 것이 아니라 서비스·연계·운영 규모를 줄였다. 1차와 2차의 한도를 넘는 기능은 붙임으로 자동 포함되지 않는다. 각 목표값은 합의 전 초안이며 측정된 제품 성능이 아니다.

## 시스템 경계와 공통 계약

입력 → 원문·권한 저장 → 공식 규칙 확인 → 로컬 검색·LLM → 근거와 제안 → 담당자 검토 → 내부 상태·내보내기가 기본 흐름이다. 2차에는 공식 읽기 원천을 입력 앞에 연결한다. 공개 일정 탐색과 내부 사례의 인증·데이터 접근 경계를 분리한다.

API-C는 신규 보조 기능의 내부 설계 계약이다. API-X01/X02/X04도 내부 식별자다. 외부 계약은 EXT-SLOT 예약 가용성, EXT-RESULT 검사결과, EXT-ACTION 조치 정보의 읽기 3개다. URL·규격·사용권은 미확인이다. 공통 응답 필드는 request_id, status, source_id, source_version, fetched_at, data, error_code로 제안한다. 파일 입력과 조회 응답에 같은 원천 식별·권한 검증을 적용한다.

### SFR-001 로컬 모델 호출

1단계 및 2단계 범위 내 확대 / BR08 / W02 / T-SFR-001

처리 요구: 입력 텍스트를 승인된 로컬 LLM·임베딩·재순위화 엔드포인트에만 전달한다. 모델·프롬프트 버전과 요청 ID를 저장하고 출력 JSON 스키마를 검증한다. 스키마 재시도는 최대 1회이며 실패 시 수동 경로를 제시한다.

검수 기준: 외부 네트워크를 차단하고 정상·스키마 오류·모델 중단을 주입했을 때 외부 호출 0건, 실패 표시, 원문 보존을 확인한다.

검수 기준: 원천 응답과 날짜별 상태가 일치한다. 마감 확인만을 위해 상세 페이지 왕복을 강제하지 않는다. 응답 부재를 마감으로 간주하지 않는다.

화면 UI-X01 · 계약 API-X01 내부 계약 · 데이터 Slot · 권한 제한 공개 시험 이용자

### SFR-401 지적사항 단위 구조화

1단계 및 2단계 범위 내 확대 / BR04 / W05,W08,W09 / T-SFR-401

처리 요구: 설계·소스·설정·규칙·프롬프트·평가세트·API 계약·SBOM·운영 매뉴얼을 계약상 권리 범위와 함께 인계한다. 기존 자산과 신규 산출물의 소유·수정·재사용·유지보수 권리를 구분한다.

검수 기준: 깨끗한 검수환경에서 전달 패키지로 재설치·복구가 가능하고, 라이선스 만료·계약 종료 시 데이터·근거·상태를 표준 형식으로 반출한다.

화면 UI-C 또는 UI-A · 계약 API-C 내부 계약 · 데이터 업무 및 감사 데이터 · 권한 업무·운영·보안 담당자

### PMR-004 교육과 운영 책임

1단계 및 2단계 범위 내 확대 / BR10 / W06,W10 / T-PMR-004

처리 요구: 사용자·검토자·기준 관리자·운영자를 대상으로 단계별 교육 4회와 4주 시범운영을 수행한다. 근무시간 지원·장애 등급·연락망·권한·규칙 갱신 책임과 유상 운영/하자 책임 경계를 정한다.

검수 기준: 운영 담당자가 근거 갱신·사용자 정정·실패 재개·백업 복구를 시연한다. 인력 감축 환산을 성과지표로 사용하지 않는다.

화면 UI-C 또는 UI-A · 계약 API-C 내부 계약 · 데이터 업무 및 감사 데이터 · 권한 업무·운영·보안 담당자

### SIR-001 공식 결과와 조치 읽기 연계

2단계 / BR11 / W08 / T-SIR-001

처리 요구: X02 결과·X04 조치 정보의 읽기 전용 계약을 각각 1개까지 연계한다. ID·버전·갱신시각·접근권한을 확인한다. 실패·중복·결측은 파일 입력 대체 경로로 처리하고 원천 기록을 수정하지 않는다.

검수 기준: 정상·권한 거부·타임아웃·중복 응답에서 원문과 상태가 일치한다. 쓰기 요청은 발생하지 않는다. 실제 명세와 접근권한 확보 전에는 해당 계약을 제공된 API로 표시하지 않는다.

화면 UI-X02, UI-X04 · 계약 EXT-RESULT, EXT-ACTION · 데이터 SourceRecord · 권한 연계 서비스 계정
