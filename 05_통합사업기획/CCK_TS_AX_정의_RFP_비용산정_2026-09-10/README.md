- 2단계 X01·X03·X05 추가, 39 MM, 6개월: VAT 포함 1,153,141,990원.
- 전체 구축: 2,799,163,451원. 구축 공급가액의 15% 예산 여유까지 별도 반영하면 3,219,037,969원.
- 전체 도입 후 정상 운영 12개월: VAT 포함 469,027,614원. 중간 단계 운영과 기관 측 별도 비용 제외.

금액은 설계 기반 공수와 2026 평균임금, 임시 가격화 계수, 견적 전 충당액으로 계산했다. 예정가격·CCK 견적·확정 예산이 아니다. 개발용 제경비·기술료 가정과 공식 운영 가이드 적용을 구별하며, 실제 과업에 맞는 FP/공수/견적 방식은 최종 범위 후 결정한다.

## 검증과 상태

- Stage Gate와 요구사항 추적 방식으로 정의·명세·발주·산정을 연결했다.
- 43개 요구 ID 중복 없음, WBS 연결 완료. Word 4종은 7·5·19·6페이지.
- Excel 107개 수식의 저장 오류 0건. 독립 계산, 공수 변경, 0원, 누락, 보정계수와 원복을 확인했다.
- 실제 Microsoft Excel 전체 재계산 및 변경 입력으로 헤드라인 금액 일치를 확인했다. 원본은 재저장하지 않았다.
- 기본 Word 렌더 도구는 Windows에 묶음 LibreOffice가 없어 실패했다. Microsoft Word의 PDF 변환과 묶음 Poppler로 대체 검증했다. 사용자 설치 LibreOffice는 사용하지 않았다.
- 자체 QA 판정: 문서·계산 검토용 산출물 통과. 외부 평가위원·TS 인수 승인·CCK 수행능력·현장 효과·사업 투자 판정은 미수행이다.
- 국민 이용 흐름의 정상·빈 결과·오류·권한·미확인·정정 경로는 명세에 포함했다. 실제 사용성 시험 결과는 아니다.

## 다음 확인 입력

TS 범위·권한·API·비중복, CCK 로컬 데모와 가용 인력·사용권, HW·라이선스·외부 연계 견적, 기관 측 감리·평가·발주 규정의 적용을 확인하여 다음 버전을 작성한다.
