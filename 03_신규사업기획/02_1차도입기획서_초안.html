A

상황별 교통안전 이해·실천 지원서비스

대국민 직접 서비스 — 사용자가 공단 직원이 아니라 일반 국민으로 바뀌는 첫 사업

대상

1차 대상자와 상황

우회전·횡단보도 등 사례 후보 중 TS가 실제 접점(찾아가는 교육·안전관리 과정)을 가진 대상부터 시작 — 고령자·어린이·사업용 운전자 등 그룹별로 역할·교육내용을 구분한다. 보행자에게 사고 책임을 전가하는 설계는 배제.

어느 대상군·상황을 1호 과제로 할지는 9~11월 실접점 확인(강사·담당자 인터뷰) 이후 확정
문제

문제 가설 (검증 전)

안전수칙·교육·경보가 이미 제공되는데도 실제 상황에서 조건을 혼동하거나 교육 효과가 유지되지 않는 대상이 있는지 확인한다. 시설·감지·근무조건이 원인인 위험을 "이해 부족"으로 잘못 진단하지 않는다.

제공기능

이용 흐름 및 CCK 구축범위

상황 제시 → 행동 선택·이유 확인 → 혼동 조건 식별 → 검수된 설명·연습 → 새 상황 재평가 → 지연 재평가(기간 후 재확인). 운전 중 문답이나 실시간 주행 명령은 1차 범위에서 제외.

  • 검수된 상황·기준·설명 자료의 지식화 (Noa RAG·지식화 SKILL 재사용)
  • 조건 확인·추가질문·오해 분류·맞춤 연습 SKILL (신규 개발)
  • 선택형·음성 등 접근성 고려 입력방식 (신규 개발)
  • 강사·전문가 검수 및 피드백 연결 (신규 개발)
  • 지연 재평가·행동측정 연결용 기록 체계 (신규 개발)

검수 기준(안)

"왜 틀렸는지 설명하는가"와 "새로운 상황에서도 같은 판단을 하는가"를 핵심 합격기준으로 삼는다. 정오 판정 정확도가 아니라 재평가 시 유지율을 1차 검수 지표로 제안.

운영

운영 주체

기대효과

측정 지표(안)

위험 행동선택 감소, 새 상황 판단 개선률, 지연 재평가 유지율. 교육 실시 인원수·이용횟수는 성과지표로 쓰지 않는다(9/17 문서 원칙9). 실제 사고감소는 노출량·비교군·관측기간이 갖춰진 뒤 별도 분석.

비용

산정 방식(안) — 금액 미기재

신규 SKILL·워크플로우·UI는 기능점수 방식(간이법, 제안단계), Noa 코어 재사용분은 별도 개발비 미계상. 학습환경·재평가 기록체계처럼 AI API 호출이 수반되는 부분은 AI 도입 방식(이용료+커스터마이징)과 병기 검토.

기능점수 산정은 SKILL 단위 요구사항이 구체화된 뒤 가능 — 현재는 산정 불가
B1

AI 자동시험·한계검증 엔진

①CP를 포함한 TS 내 AI 시스템이 "실제로 요구사항대로 동작하는지" 검증하는 독립 제품

대상

1차 대상자와 검증 범위

TS 내부에서 AI·SKILL·모델·연계가 바뀔 때마다 재시험이 필요한 담당 부서(품질·성과분석 담당)가 1차 사용자. 1차 검증 대상 시스템은 ①CP의 등록 AI서비스(현재 20건)부터 시작 — 경계표 §3 참조.

문제

문제 가설

AI 서비스 성과분석·검수지원은 이미 계획돼 있다. "시험을 안 한다"가 아니라, 변경이 있을 때마다 요구사항을 누락 없이 재시험하고 결과를 재현하는 반복 부담·검증공백이 실제로 있는지 확인한다.

제공기능

파이프라인

  • 요구사항·지침·변경분 등록 → 검사조건·합격기준 구성
  • 검증된 합성자료·시나리오 생성 (실사용자 데이터 재사용 아님)
  • 승인된 시험도구로 기능·의미·완료·권한·부하·회복 계측
  • 관측증거 + 충족판정 → 실패 재현 패키지 → 수정 후 회귀시험

설계 경계: 부하생성·자원계측은 전용 도구, AI는 계획·변형·분석만 담당. 생성 AI가 자신이 만든 정답으로 자신을 채점하지 않는다 — 계산·필드검증/독립 의미평가/전문가 확인을 분리.

요구사항별 시험상태·미시험 목록, 환경·버전·데이터가 붙은 재현 패키지, 변경 전후 비교, 시정·재검증 기록. 합성질문 수만 증가시키는 것은 실패로 판정(9/17 문서 확대판단 조건표).

운영 주체

발주기관 AI 서비스 성과분석·검수지원 담당 부서가 합격기준을 승인, CCK가 시험 파이프라인을 운영. 과부하시험은 허가된 시험환경·한도·중단조건 내에서만 수행.

기대효과

측정 지표(안)

동일 검증범위의 총작업시간, 증거 확보된 요구사항 범위, 중요 결함 발견·오탐률, 재현율, 회귀문제 수, 성공업무당 비용. 사람의 재조사 시간을 비용에 포함.

개인정보 처리 실증검증 엔진

대상

①CP 비식별화의 실제 구현·검수 완료 시점 확인 필요 — 현재 [제안] 등급, 이행 증빙 없음
문제

문제 가설
