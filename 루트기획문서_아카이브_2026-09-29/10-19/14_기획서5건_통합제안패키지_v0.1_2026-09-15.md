# 0. 이 문서의 목적과 한 줄 결론

착수사다리(03번 §5.2) 1군 3건(N-03·N-06·N-05)과 2군 2건(N-07·N-04) — 총 5건의 정식 기획서가 2026-09-15 모두 완성됐다. 이 문서는 5건을 하나의 의사결정용 패키지로 묶은 것이다.

**한 줄 결론: 5건 모두 이번에 요청하는 것은 Phase 0(문서·확인 작업, 예산 불요)뿐이다.** 어느 항목도 전면 착수(Phase B) 승인을 구하지 않으며, Phase B는 각 항목의 선행조건(Delivery 준공, 기반사업 계약체결 등)이 해소된 뒤 별도 보고로 재요청한다. 따라서 이 패키지의 실질적 의사결정 부담은 "예산 승인"이 아니라 "30여 개 확인 작업을 지금 진행해도 되는가"이다.

# 3. 항목별 요약

## 3.1 N-03 — 사업용차량 안전공시 국민공개 (1군 1-2, SHAPE)

Delivery 사업(448,316,087원, 준공 2026-12-18)의 SFR-008(AI 판별 15종)·SFR-009(분석보고서) 산출물 위에, 계약범위 밖인 "국민 공개 조회 포털"을 얹는 후속 확장. 법적근거는 여객자동차운수사업법 §20의2(구 "제21조" 인용은 오기, 정정됨)→시행규칙§43의2→국토부훈령 제1137호§4로 4단계 CONFIRMED.

- **Phase 0 요청(6개, 예산 불요)**: data.go.kr 사고통계 확정 / 시행령§38·위탁조항 원문대조 / "제21조"→"제20조의2" 내부문서 정정 / 최근 3반기 공시 이의·정정 건수 확보(KPI 기준선) / 화물·시외버스 공시여부 확인 / 행안부 정보화사업 사전협의 대상여부 판단.
- **최대 리스크**: Delivery가 RED(확정률 5.6%) 상태라 SFR-008/009 지연 시 전체가 지연 — 임의 축소·독립착수 금지. 부수적으로 통학버스(경찰청 신고제) 통계를 전세버스 근거로 혼용하지 않을 것.
- **Phase B 조건**: Delivery 준공·SFR-008/009 검수 완료 시점에 별도 재승인 요청.

## 3.2 N-04 — 전기차·배터리 안전이력 AI (2군 2-2, SHAPE)

TS 기존 KADIS(전자장치진단기) 데이터 위에 AI 위험도 예측·이상탐지를 신설하는 신규 독립사업. 5건 중 **법적근거·Sponsor 모두 가장 강함** — 자동차관리법 §30조의7·§30조의8·시행령§8조의4·§31·§73조의2 전조항 CONFIRMED, Sponsor(첨단자동차검사연구센터)도 2026-09-14 조직도 직접열람으로 CONFIRMED.

- **Phase 0 요청(6개, 예산 불요)**: 성능시험대행자 지정고시 원문 확보(G6, 유일한 남은 공백) / 소방청 자동통보 시범사업 이행상황 확인 / 사용후배터리 이력관리시스템(2027) TS 참여여부 확인 / 화재율 통계 두 종(11.89건 vs 4.78건) 산정기준 재확인 / '성능시험대행자'-'사업Sponsor' 관계 확인 / Sponsor 부서 현업 협의 착수.
- **최대 리스크**: '성능시험대행자'(제작단계 인증)와 '사업 Sponsor'(운행중 이력관리)를 같은 조직으로 서술하지 않을 것 — 두 트랙 혼동 리스크.
- **참고**: 2군 실적이 축적되면 3군 "3-2"(T3 R&D 1순위 테마)로 재사용되는 순차관계이나, 이번 요청 범위에는 3군이 포함되지 않는다.

## 3.3 N-05 — 대국민 교통민원 통합 AI 창구, 범위 한정판 (1군 1-3, SHAPE)

TS 콜센터·국민신문고 답변체계(Delivery SFR-006/007)에 근거기반 답변보조를 결합하는 사업. **범위를 "TS 자체 채널 AI 고도화"로 한정**하고 "범정부 통합 창구 주체화"는 명시적으로 배제한다 — 국민권익위가 이미 110/AI신문고 범정부 사업을 주도 중이며 TS는 참여기관 명단에 없음(CONFIRMED).

- **5건 중 법적 근거가 유일하게 미확정** — 공단법§6의 12개 호 중 어느 조항이 TS 고유 상담 근거인지 확정되지 않았고, 문서 자신이 "1군 중 가장 방어하기 어렵다"고 명시한다.
- **Phase 0 선결과제(3개, 이것이 해소되지 않으면 Phase B는 상정하지 않음)**: 공단법§6 근거 호 원문 재대조 / TS-권익위 협의·MOU 여부 확인 / 콜센터 정량 기준선(오접수율 등) 확보.
- **대안 경로**: 근거 호가 끝내 확인되지 않으면 자체 구축 대신 "권익위 공통기반 편입"으로 전환한다.

## 3.4 N-06 — 국가자격시험 AI 출제·검정 공통기반, 확장후속 (1군 1-1, INCUBATE)

착수사다리 최우선(1-1)이었으나, **기반사업(공고 제2026-128호, 249,892,403원, 도로자격 4종 한정, 입찰 09-16~18, 개찰 09-23)이 이미 별도 입찰 트랙(PRESALES)으로 진행 중**이고 RFP가 "타 기관과 공동활용 계획 없음"을 명시해 확장 근거가 아직 성립하지 않는다. 본 문서는 예산·착수 승인이 아니라 **기반사업 수행 중 확장기획용 실적지표를 사전에 합의해 두는 것**만 요청한다(G5 ◎→△ 하향).

- **Phase 0 요청 중 최우선**: §3.2 실적지표(출제 소요시간·검토위원 수정률·난이도 판정 일치율·유사문항 중복탐지율·이의신청 건수)를 **기반사업 착수 시점부터** 수집하도록 자격교육처와 사전 합의.
- **기관 혼동 주의**: 메가이슈 통계는 전부 한국산업인력공단 사례(TS 사례 아님) — 대외 문서에서 소관기관을 매번 명시할 것.
- **Phase 1 재상정 조건**: 기반사업 완료(2026-12-20) + 실적지표 확보 + 항공·철도 위탁근거 원문 확인.

## 3.5 N-07 — 인허가·심사 서류 AI 공통기반, 확장후속 (2군 2-1, INCUBATE)

검사본부 AI 8억 기반사업(튜닝승인·검사기기 정밀도·삭도궤도·기계식주차, 제안 2026-09-02 제출, 계약 대기)이 개발 중인 자산 중 텍스트·구조화 데이터로 남는 부분만 "인허가·심사 서류 AI 공통기반"으로 일반화하는 확장 후속기획. **당초 시급성 근거였던 NIA 범정부 심사·심의 Agent와의 관련성이 재검증으로 철회**되어 SHAPE→INCUBATE 하향이 유지된다.

- **Phase 0 요청(8개, 예산 불요)**: 8억 기반사업 계약체결 여부·일정 확인 / 삭도궤도 2025 국정감사(노후시설 66.5%·부실업체 46.8%) 1차출처 확보 / 궤도운송법 시행령§16 위탁조문 확보 / 튜닝·기계식주차장 처리량·반려율 통계 확보 / C-1 Domain Pack 설계초안 / NIA·N-08 구분을 대외문서에 일관 반영 / 고영향AI 판단서 착수.
- **3단계 파이프라인**: [검사본부 AI 8억] → [N-07, 자산 재사용, 근거 강함] → [NIA, 장기·개념적 전망일 뿐 즉각결합 아님]. 지금 단계에서 NIA를 확장·시급성 근거로 쓰지 않는다.
- **N-08과의 구분**: N-07(물건·시설 물리검사) vs N-08(산출물·증빙서류 심사) — 대상이 다르므로 NIA 관련성 판단이 서로 모순되지 않는다.

# 4. 공통 패턴과 종합 리스크

1. **5건 전부 동일한 겸손 프레이밍** — "이번에 전면착수 승인을 구하지 않는다." Phase 0(문서·확인, 예산불요)만 요청하고 Phase B는 선행조건 해소 후 별도 재승인.
2. **선행사업 의존이 5건 중 4건의 최상위 리스크** — N-03(Delivery 준공)·N-06(기반사업 개찰 09-23)·N-07(8억 계약체결)·N-04는 상대적으로 독립적이나 Sponsor 부서 협의가 남음. **N-06·N-07은 지금 이 순간 외부 이벤트(개찰/계약) 대기 중**이라 Phase 0 확인작업 외에는 실질적으로 할 수 있는 게 없다.
3. **법적근거 강도 순위**: N-04(최강, 5단계 전조항+Sponsor CONFIRMED) > N-03·N-06(위탁조항 CONFIRMED, 세부만 PENDING) > N-07(4개 업무 중 3개 CONFIRMED) > N-05(최약, 근거 호 자체 미확정).
4. **기관·통계 혼동 경계가 3건에서 공통 발견** — N-03(통학버스↔전세버스), N-04(성능시험대행자↔사업Sponsor), N-06(산업인력공단 사례↔TS 사례). 대외 문서 작성 시 매번 소관·주체를 명시할 것.
5. **G2(인력감축·감시 우려) 방어는 5건 모두 무난** — HITL·중단기준이 표준 템플릿에 내장돼 있어 별도 쟁점 없음. N-05만 "국민신문고 게시물 수정 권한 미확인"이라는 별도 권한 리스크를 안고 있다.

# 7. Phase 0 데스크리서치 1차 실행 결과 (2026-09-15, §5-A 항목 착수)

사용자 "다음" 지시로 §5-A(지금 일괄 승인 가능한 것)에 해당하는 Phase 0 항목 중 외부 웹조사(law.go.kr·data.go.kr·관보·WebSearch)로 해소 가능한 것들을 4개 에이전트(N-03/N-04/N-05·직접/N-06+N-07)가 병렬 실행했다. 5개 기획서 원문에 개별 반영 완료, 여기서는 패키지 관점의 요약만 남긴다.

**완전 해소(공식 1차 출처 확보)**:
- **N-04 G6(이 패키지 전체의 유일한 "완전 해소" 사례)** — 성능시험대행자 지정고시 원문을 관보(gwanbo.go.kr)에서 직접 확보: **건설교통부고시 제2003-10호(2003-01-21, 관보 제15304호)**, "교통안전공단(부설 자동차성능시험연구소)을 성능시험대행자로 지정". §30조의8(배터리 핵심장치 인증)은 별도 고시 없이 이 기존 지위를 원용함도 확인.
- **N-03 위탁조항** — 추정했던 "시행령§94 부근"이 틀렸고 실제로는 **시행령 제38조③1호**(law.go.kr DRF API로 원문 확보). 화물차·시외버스는 **둘 다 전세버스와 같은 공시제도 대상이 아님**을 확정(화물차는 §47조의7의 별도 "화물운송서비스평가" 제도).
- **N-06 위탁근거** — 추정했던 "§34"가 틀렸고 실제로는 항공(**§38+§135⑤1호→시행령§26⑥**)·철도(**§77②→시행령§63①2호·6의2호**) 전부 원문 CONFIRMED.
- **N-07 위탁조문** — 궤도운송법 **시행령 제16조**가 TS를 안전검사전문기관으로 명문 지정함을 원문 확보. 삭도·궤도 2025 국정감사 수치도 1차 보도(철도경제신문 2025-10-16, 엄태영 의원 질의)로 출처 확보.

**부분 해소·신규 후보 발견**:
- **N-05 최대 공백(TS 고유 상담 근거 호)** — 원안의 4호·14호보다 **10호("교통 및 자동차 정보시스템 운영과 정보 제공에 관한 사업")**가 문언상 더 직접적임을 발견(law.go.kr §6 전문 재확인). "후보 없음"에서 "유력 후보는 있으나 TS 공식 적용 확인 전"으로 좁혀짐 — 5건 중 유일하게 INVEST/SHAPE 논의 자체가 막혀 있던 항목의 첫 진전.
- **N-07 확장근거** — 식약처(의료기기법§44②, NIDS 위탁)는 TS형 패턴으로 CONFIRMED 추가됐으나, **조달청은 위탁이 아니라 자체수행**임이 확인돼 확장근거에서 제외해야 함(과잉 확장 주장 방지).

**정직하게 남은 공백(찾아봤으나 미해소)**:
- N-03: 전세버스 2021~2025년 사고건수(2018-19년치만 확보, 이후는 data.go.kr CAPTCHA로 다운로드 차단 — 우회 시도하지 않고 중단).
- N-04: 사용후배터리 이력관리시스템 TS 참여여부(UNKNOWN 유지, 나라장터 1차 확인 필요).
