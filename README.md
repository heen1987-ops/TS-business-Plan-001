## 규칙

- 원자료는 `원자료/` 하위에만 둔다. 루트에 파일을 바로 내려받지 않는다.
- 동영상·설치파일·`(1)` 중복본은 `.gitignore`로 제외된다. 규칙을 바꿀 때는 줄 단위로만 고친다.
- 문서 안의 절대경로 링크(`C:/Users/…/[TS] 사업기획/…`)는 2026-09-23 정리 때 `원자료/` 경로로 일괄 갱신했다.
- 이 폴더는 원자료·검토 산출물 보관용이다. 사이트 소스는 `main`, 기획문서 본체는 `docs-2026-plan`에서 관리한다.
