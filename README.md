## 기존 작업 문서 안내

한국교통안전공단(TS) AI 플랫폼 관련 CCK 내부 검토·사전기획 문서. **전부 내부용이며, 고객(TS) 대상 자료로 그대로 재사용하지 말 것** — 대체·윈백 표현, 기 구축시스템 비판 등은 사내 규정상 금지.

## 01. 플랫폼구조정리

기 구축 TS AI 공통플랫폼(오케스트로, tsai.kotsa.or.kr)의 구조·목적 정리. 사진 22장 + 화면 녹화 영상(5분36초) 직접 관찰 기반. 법령 관리 메뉴는 두 차례 시도 모두 미확보.

## 02. NOA_차별성검토

CCK 엔진(TA-01~23)을 위 플랫폼 기준선과 비교한 내부 전략 검토. 결정성·추적성·통제성·운용성 4축, 근거등급(확정/제안/미확인)과 한계를 명시.

## 03. 신규사업기획

2026-09-17 CCK-TS 신규 AX 사업기획(2027~2030) 후속 사전기획 초안 4종:
1. **CP사업_vs_신규포트폴리오_경계표** — 기 수주 ①사업과 신규 포트폴리오(대국민 서비스 A, AI자동시험 B-1, 개인정보실증검증 B-2)의 경계
2. **1차도입기획서_초안** — A/B-1/B-2 각각의 대상·문제·기능·연계·검수·운영·기대효과·비용(방식만, 금액 미기재)
3. **코어_RD_기획서_초안** — 도입기준선·실제한계·기존대안·연구질문 3종·평가환류. TIPS 딥테크 과제(RS-2026-25607962)와의 중복지원 리스크 확인 포함
4. **근거_요구사항_연결표** — 출처→문제→기능→증거→평가→조치승인→성과 추적 매트릭스
