# 09. Slack 공유문안

[NoA Public AI-PMS / Continuous Assurance 문서 초안 공유]

기존 논의를 문서 세트로 정리했습니다.

핵심 방향은 NoA에 범용 PMS를 하나 더 만드는 게 아니라, **기관·수행업체가 정보화사업의 공식 상태를 공동관리하는 `Project Layer`를 추가하고 그 과정에서 검사 가능한 Evidence를 계속 축적하는 구조**입니다.

- **1차년도: NoA Project / AI-PMS**
  - RFP·계약·지침 기반 Baseline
  - 공동 일정/WBS·Task·산출물·검토/승인
  - 수행업체 AI Pre-Check
  - Continuous Evidence
  - 담당자 인수인계/업무지원

- **2차년도: NoA Assurance / 감리엔진**
  - Baseline과 Evidence 기반 AI 상시·전수검사
  - AI Finding + 감리사 전문·현장검증 투트랙
  - 양측 판단 차이도 별도 Evidence로 관리
  - 보완·소명·재검증

- **3차년도: NoA Intelligence**
  - 담당자/검토자/관리자/결재자/관련부서/사용자 다면평가
  - 실제 역할·품질·대응 기반 업체 Reference
  - Risk·만족도·Finding을 차기 RFP로 환류

중요한 포인트는 **AI가 감리사를 대체한다는 개념이 아니라, 모든 정보화사업에 AI 기반 최소 검증선을 제공하고 법정·고위험 사업에는 사람 감리를 추가한다는 구조**입니다.

또 신규기업은 Reference가 없다는 이유로 감점하지 않고 NoA의 사업관리/Pre-Check 지원을 받아 첫 사업부터 실제 수행성과로 Reference를 만들 수 있도록 했습니다.

작성 문서:
1) 사업기획·컨셉 정의서
2) RFP 초안
3) 요구사항분석서
4) 요구사항정의서 초안
5) 서비스 기능정의서
6) 아키텍처·데이터모델
7) 3개년 R&D 로드맵
8) 실증·성과·편익 검증계획
9) 요구사항 추적매트릭스

검토 포인트는 특히 **① 1차년도 Project 범위가 과하지 않은지 ② 2차년도 감리엔진의 검사영역 ③ 3차년도 Reference의 활용범위** 세 가지입니다.
