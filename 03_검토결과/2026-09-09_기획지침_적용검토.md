# 신규 사업기획 지침 적용 검토

검토일: 2026-09-09. 작성자의 자체 검토이며 별도 평가위원, TS 담당자, 법무·예산 담당자의 승인 결과가 아니다.

## 결론

사용자의 7개 기준을 프로젝트 규칙·상세 지침·기획 양식·검토표에 연결했다. 기관·법정업무 매핑 원장과 지속 조사 절차를 만들고 사용자가 선택한 월~금 오전 9시(Asia/Seoul) 자동화를 등록했다.

문서 체계 적용은 자체 점검 합격이다. 개별 사업 선정, 전수조사 완료, 법적 적용성 판정, 최종 계약 범위 확인, 실제 예약 실행 검증은 아직 완료되지 않았다.

## 방법과 범위

- 유형·규모·위험: 신규 사업기획 기준 정비 / M / Medium.
- 방법: 기존 맥락 조사와 근거 중심 요구사항 정리, 지침→양식→검토 항목의 추적.
- 완료 단계: 사용자 기준 접수 → 기존 자료·공식 출처 1차 조사 → 기준 설계 → 문서 반영 → 구조 검사·자체 검토 → 정기 리서치 등록.
- 제외: 개별 사업 예산·일정·솔루션 확정, 시스템 구현, 외부 제출, GitHub 반영, 운영 배포.
- 원본 관리: 기존 TS 자료는 읽기 전용으로 참조했고 현재 사업기획 폴더에 산출물을 작성했다.

## 실행한 구조 검사

- 보고서 추가 전 문서·JSON 12개: UTF-8 읽기, 빈 파일 및 깨진 문자 확인, 이상 없음.
- 내부 링크 17개: 로컬 대상 존재 확인, 누락 없음.
- 기관 원장: JSON 파싱 통과, 기관·업무·관계 각 1개, ID 중복·잘못된 참조 없음.
- 원장의 PUB 참조: 공식 출처 목록 PUB-001~PUB-008 내 존재 확인.
- 상세 지침·기획서 양식·검토표: P01~P07 총 21개 식별자 존재 확인. 이 검사는 근거 내용의 정확성을 자동으로 판정한 것이 아님.
- 자동화: 도구 생성 결과와 저장된 설정에서 ID `ts-ai`, ACTIVE, 현재 작업 연결, 월~금 09:00 설정 확인. 실제 첫 예약 실행은 미검증.

## 사용자 관점과 잔여 사항

- 기획자가 양식에서 국민 문제·WHY·법적 역할·AX+SI·확장·조직 영향·심의 항목을 함께 작성할 수 있다.
- 내부 효율화 우려를 단순 표현 변경으로 처리하지 않도록 했다.
- 기존 프로젝트의 과거 WBS·예시·제안 개념을 현재 승인·실적으로 사용하지 않도록 했다.
- 기관 원장은 설명자료 확인과 현행 법령 적용성 확인을 구별한다. 법령 적용성까지 확인한 관계는 현재 0개이다.
- 2026 지정고시 첨부 열람 오류로 전체 기관 목록을 확보하지 못했다. TS 공개 보고서의 분류와 현행 고시 행의 대조가 남아 있다.
- 최종 계약·승인 요구사항, 개별 위탁 근거, 실제 현업 의견·권한, 심의 하위 기준을 후속 검증해야 한다.
- 별도 검토자·평가위원·TS 담당자에 의한 승인과 실제 사용자 검증은 수행하지 않았다.
