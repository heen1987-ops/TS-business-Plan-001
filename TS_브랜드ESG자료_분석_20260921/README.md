## 이번 분석에서 확인한 특이사항 요약

1. **ESG보고서와 브로슈어의 미션·비전·핵심가치·경영목표 문구가 완전히 동일** — 같은 시기(2026년) 동일 경영전략체계를 두 매체에 일관 반영한 것으로 확인(교차대조로 CONFIRMED).
2. **브랜드자산 zip 파일명이 실제 내용과 다르다**: `symbol_kor.zip`은 워드마크, `logo_kor.zip`은 시그니처를 담고 있음 — 향후 이 파일들을 인용/전달할 때 파일명만 보고 오인하지 않도록 주의.
3. **ESG보고서 자체에 13가지 내부 불일치(수치·표기)가 있음**을 원문 대조로 확인 — 01번 문서 하단 "확인 필요" 절에 전부 정리. 이는 이 세션이 만든 요약의 오류가 아니라, 원문 보고서 자체(또는 그 표를 선형텍스트로 뽑을 때 생기는 한계)에서 비롯된 것이므로, 대외 인용 전 원본 PDF 해당 페이지를 직접 확인할 것을 권장.
4. **브로슈어는 전체가 텍스트 없는 디자인 PDF**였다 — 향후 유사한 마케팅/브로슈어류 PDF를 분석할 때는 먼저 `fitz`로 텍스트 존재 여부를 확인하고, 0글자면 Windows 내장 OCR(`Windows.Media.Ocr.OcrEngine`, 한국어 팩 지원 확인됨)으로 페이지 이미지를 렌더링해 처리하는 방법이 이 환경에서 별도 설치 없이 재사용 가능함을 확인했다.
