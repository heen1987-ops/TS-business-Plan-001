## 1. Word Mark(워드마크) — `symbol_kor.zip` 내 `BS-01`
- **구성**: "TS" 두 글자만으로 이루어진 로고타입. **T는 오렌지 그라데이션, S는 블루 그라데이션**
- **의미**(매뉴얼 원문): 커뮤니케이션 명칭 'TS'를 강조해 교통(Transportation)과 안전(Safety)이라는 핵심가치를 전달. 직선적 서체로 "교통사고 없는 밝은 미래로 향하는 안전한 길"을 표현. 글자 높이·폭을 동일하게 해 안정감·신뢰성 전달
- **색상 의미**: Blue gradation = 교통안전을 책임지는 기관의 신뢰성·전문성 / Orange gradation = 국민의 행복한 생활을 추구하는 서비스기관의 특성
- **최소사용규정**: 원문에 최소크기 예시가 "5mm" 기준으로 명시되어 있음(정확한 측정 기준·여백 규정은 원본 `.ai` 파일의 그리드를 직접 참조할 것 — 이 캡처 이미지만으로는 도면 치수를 전부 판독하지 못함, UNKNOWN 세부수치)

## 2. Signature(시그니처) — `logo_kor.zip` 내 `BS-14`
- **구성**: 워드마크(TS) + "한국교통안전공단" 국문 사명을 결합한 조합형. **국문 단독형 / 국문+영문(Korea Transportation Safety Authority) 병기형**, 각각 가로 배치·세로(스택) 배치 버전이 매뉴얼에 함께 제시됨
- **용도**(매뉴얼 원문): "워드마크와 사명을 조직적이고 효과적으로 조합시켜 보다 적극적으로 이미지 통일을 기하기 위한 것" — 상황에 따라 매뉴얼에 규정된 비율(그리드 단위 "a")을 지켜 사용해야 함
- **주의**: 이미지 안에 표시된 정밀한 그리드 치수(3a, 5.5a, 7a 등)는 실제 리사이즈·인쇄용으로 쓰려면 원본 `.ai` 벡터 파일을 열어 직접 확인해야 한다 — 이 문서는 캡처 이미지를 육안으로 읽은 수준의 정보만 제공한다(UNKNOWN, 벡터 파일 직접 열람 필요).

## 3. Character(캐릭터) — Tangel(탠젤) — `tangel_kor.zip`
- **이름**: **Tangel(탠젤)** = **Transportation + Angel**의 합성어
- **컨셉**(매뉴얼 원문 그대로): "부지런하고 명민한 행동으로 항상 국민 가까이에서 수호천사 역할을 하는 한국교통안전공단의 친근한 이미지를 부각시킨 캐릭터"
- **디자인 의미**:
  - 순백색 몸체 = 투명하고 맑은 마음·자세로 국민에게 다가가는 TS를 상징
  - **날개 3색**: 노랑=**도로안전**, 파랑=**항공안전**, 녹색=**철도안전** — TS의 3대 안전관리 영역을 상징
- **외형**: 토끼形 백색 캐릭터, 빨간 코, 3색(주황/노랑, 파랑, 초록) 리본형 날개 4장

## 4. Character — Tanjel Junior(탠젤 주니어) — `tangel_junior_kor.zip`
- **정의**(매뉴얼 원문): "탠젤의 어린이(주니어) 모습" — 순백색 몸체는 탠젤과 동일한 상징을 유지하되, **몸의 비율과 곡선을 바꿔 더 간결한 이미지로 다방면 활용 가능**하도록 설계
- **날개 → 천사링(halo)으로 변경**: 탠젤의 날개 대신 머리 위 **천사링(3색 — 노랑/파랑/녹색, 도로·항공·철도 안전 의미는 탠젤과 동일)** 을 채택 — "천사(Angel)" 모티브를 날개가 아닌 링으로 표현해 **감정 표현을 더 효과적으로** 하려는 의도라고 명시됨
- **문서 출처 표기 차이**: 이 페이지만 상단 헤더가 "Basic / Character Identity Menual System / BS_01"로, 다른 세 페이지("TS Basic System" 상단 헤더 + "Korea Transportation Safety Authority Corporate Identity")와 형식이 다르고, 우측 하단에 "Copyright ⓒEC21. All rights reserved" 표기가 있다 — **별도 매뉴얼 문서(혹은 별도 제작사 산출물)에서 가져온 페이지로 추정**(PARTIALLY_CONFIRMED, 동일 매뉴얼의 다른 판일 가능성도 배제 못함)

## 실무 활용 메모
- 위 4개 자산은 전부 TS 자체 CI/BI 매뉴얼("TS Basic System")에서 발췌한 개별 페이지 export(JPG 미리보기 + AI 벡터, 또는 PNG)로 보인다 — 즉 **완전한 매뉴얼 전체가 아니라 필요한 4개 페이지만 골라 압축한 것**이다. 매뉴얼 전체(색상규정, 전용서체, 응용시스템, 명함·서식류 규정 등)는 이 4개 zip에 포함되어 있지 않으므로, 로고를 실제 인쇄물·간행물에 적용하려면 원본 BI 매뉴얼 PDF 전체를 별도로 확보해야 한다(UNKNOWN — 전체 매뉴얼 소재는 이번 조사 범위 밖).
- 벡터(.ai) 파일은 이번 분석에서 텍스트/이미지 내용을 직접 열람하지 않았다(Illustrator 파일 포맷이라 PyMuPDF·이미지 뷰어로 직접 열리지 않음) — 인쇄용으로 실제 사용할 때는 Illustrator 등에서 원본을 열어 최신 규정(그리드 치수, 색상 코드 CMYK/RGB/Pantone 등)을 재확인할 것을 권장.
