# 주차안전처 근거기반 솔루션

> 조사 기간 2026-09-24~25. 근거ID는 §12·`PK_근거원장.json`과 동일. "내부자료"는 CCK 내부 문서(계약 사실 확인용)

## 0. 한 장 요약

- **판정: 재설계.** 현 컨셉의 방향("미흡 해소와 이용회복 검증")은 증거와 일치하나, 문제 단위가 틀림. 증거상 가장 큰 병목은 개별 보수 증빙의 연결 누락이 아니라 **부적합 판정 이후 운행중지·보수·재검사·재운행 확인이 TS·지자체·관리자 사이에서 추적되지 않는 공백**(PK-22·PK-66·PK-25). 현 컨셉의 "확인 없는 종결" 가설은 자체점검 긴급수리의 자체 종결 경로로 제도상 존재가 확인되나 빈도는 미확인(PK-I5·PK-U1) → 사슬의 한 구간으로 축소 수용
- **입증된 문제 3개**
  1. 정밀안전검사 부적합 후 재검사·신규검사 미실시 **656기**(2026-07 말), 지자체 운행중지명령 확인 **152기(23.2%)**, 나머지 **504기(76.8%)**는 운행·보수·폐쇄 여부를 TS가 미파악. TS는 부적합 명단을 매월 지자체에 통보하나 이후는 지자체 개별 관리, 국토부·TS에 전국 취합 자료 없음(PK-22·PK-66·PK-I1, 국감 제출자료 인용 보도, PLAUSIBLE)
  2. TS 스스로 2026 추진계획에 "지자체 실태점검, 과태료 부과 등의 행정조치 미흡"을 명시하고 국민 신고센터로 보완 추진(PK-25, CONFIRMED). 같은 문제는 2018 국감에서도 지적(서울 불합격 241기 중 120기 운영, PK-48)
  3. 노후화 누적: 3만6,234기 중 20년 이상 43.7%, 2022~2026.7 부적합 5,115기의 84.6%가 20년 이상(PK-23). 법정 주기상 연 약 1.8만 회 검사가 기대되나 공개 통계상 2025년 정기 9,193기+정밀 5,064기=1만4,257기(78%)(PK-45·PK-I4, 차이 원인 미확인)
- **솔루션 한 줄**: 정보망(mpis)의 검사결과·운행중지명령 입력·자체점검 판정·재검사 신청을 장치 단위로 대사해 **"부적합 이후 상태 미확인·기한 도과·기록 모순"** 장치를 매월 찾아내고, 조문 근거와 함께 지자체 통보 초안·현장확인 우선순위를 담당자에게 제시하는 **부적합 후속조치 추적 점검**(규칙 대사 우선, LLM은 주소·건물명 매칭·자유서술 정규화·서류 대조·통보문 초안에 한정)
- **사람이 결정하는 지점**: 상태 분류 확정·통보 발송(TS 주차안전처), 운행중지명령·재운행 해소 확인(시장·군수·구청장, 법 제19조의24), 재검사 합격(검사원), 보수(관리자·보수업자)
- **기준선 확보 경로**: 후속상태 미확인 비율 76.8%·명령 확인 23.2%는 2026-07 실측값 존재(보도 인용). 재검사 경과일·3개월 도과율·자체점검 긴급수리 자체종결 건수·정보망 운행중지 입력률은 mpis 원자료(2024-08-17 이후)로 산출
- **사용자 결정 필요사항**: ①재설계 방향 승인 ②주차안전처 인터뷰에 mpis 원자료(검사결과·운행중지 입력·자체점검 판정) 열람 범위·권한 질의 포함 여부 ③한국승강기안전공단 검사분 포함 범위 ④공공데이터 설치현황 원자료(32,114건) 다운로드·집계 승인 ⑤국민 신고센터·mpis 유지관리 사업과의 경계 협의 주체

### 1.1 조직상 위치
- 자동차검사본부 소속 처. 2026 추진계획의 주차안전처 과제 4건: ①위해·위법 주차장 안전관리 강화(정보망 내 국민 신고센터) ②AI 활용 안전성 검증(설계서 안전도심사 AI) ③민원서류 디지털화 ④주차로봇 제도개선(PK-25·26·27)
- 공식 업무안내: 설계서 안전도 심사, 사용·정기·정밀안전검사, 관리인 교육, 자체점검 안내, 사고조사, 정보망 운영(PK-37·36·63)
- 2025 성과로 중형 기계식 수용률 56.9%→97.7% 설치기준 상향 보고(PK-27)

- 통보 의무 비교: 승강기법은 미검사·불합격 전건의 지자체 통보를 법률에 명시(제50조①), 주차장법령은 전문검사기관 발급 시 통보만 규정(규칙 제16조의8⑤) → TS 월별 통보는 운영 관행으로 추정(PK-I6)
- 반대방향 신호: 2025-12 개정은 "안전관리 체계가 강화된 점"을 들어 기계식 설치비율 조례 제한을 폐지(PK-10) → 신규 설치 증가 가능

### 1.3 업무 흐름(부적합 이후)

```
[검사기관: TS·타 기관] 검사 → 20일 내 결과 통보 + 사용금지 표지 → (TS) 부적합 명단 월별 지자체 통보(관행)
  → [관리자] 보수(보수업자) → 3개월 내 재검사 신청 → 재검사(10일) 또는 사진·시험성적서 서류 확인(5일)
  → 미재검사·미중지 시 [지자체] 운행중지명령(의무, 제19조의24①1·2) → 정보망 입력(규칙 제16조의28③)
  → [지자체] 사유 해소 확인 → 재운행
병행: [관리자] 월1회 자체점검(양호/주의 관찰/긴급 수리) → 익월 10일까지 정보망 입력
      긴급 수리 → 운행중지·수리 → 관리자 자체점검 '양호' 판정 후 운행(외부 확인 규정 없음, PK-I5)
```

- 2022 TS 대책은 사례집·구조교육·관리인교육·지자체 합동점검 중심(PK-41). 사후조치 추적 체계는 언급 없음

### 2.3 반대 증거·한계
- 현 컨셉의 "확인 없는 종결" 사례·빈도는 공개자료에서 미발견(PK-U1). 제도상 경로(서류 확인 재검사 PK-12, 자체점검 긴급수리 자체 종결 PK-I5)만 확인
- 입법부는 안전관리 체계가 강화되었다고 판단(PK-10)
- 사고사례집 표 간 불일치(인적 29 vs 27, 대물+대인 64≠55)로 요인 비율 정밀도 제한(PK-19)
- 656기는 의원실 원문 미열람(PK-U6), 지자체 입력 누락과 실제 미조치 구분 불가
- 2018 서울 40%는 1~8월 부분기간 값으로 연간 미수검률 아님(PK-48)
- 감사원·TS 자체감사의 기계식주차장 사후관리 지적은 미발견(PK-U5) — 감사 부재가 문제 부재를 뜻하지 않음
