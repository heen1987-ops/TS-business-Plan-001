# 기후탄소물류처 근거기반 솔루션

> 재설계안 제목: **"안전운임 위반 신고, 증빙에서 사실확인·관할관청 통보까지"**
> 기존 FPIS 신고·정정 컨셉은 보류, 위험물 운송안전은 확장 후보 유지.

## 0. 한 장 요약

**판정: 재설계**

- 대표 컨셉을 "FPIS 신고·정정 완결"에서 "안전운임 위반 신고사건 처리 지원"으로 교체. 같은 처(기후탄소물류처)의 법정 위탁업무이며 사이트 연차계획 CL27-04(확장 후보)를 증거 기준으로 승격한 안.
- 교체 이유 3가지
  - FPIS 컨셉 전제(거래 해석 혼선→반복 정정) 미입증: 국민신문고 TS 민원 374건 중 FPIS·실적신고 민원 0건(CL-E26), 정정 건수 공개자료 없음(CL-E67), TS가 2026-03 "마감 전 수정·정정 기회" 기능개선 이미 시행(CL-E43)
  - FPIS 자체의 수명·중복: 법률 제21483호로 2028-01-01부터 FPIS 근거가 "화물운송행정 통합관리시스템"으로 대체(CL-E42). 1월 계획 "FPIS 데이터 검증 알고리즘·지자체 229개 수집"과 인접(CL-E16, CL-E41)
  - 같은 처 안전운임 신고 처리에서 병목 수치와 TS 자체 개선과제가 함께 확인(CL-E17, CL-E32, CL-E33)

**입증된 문제 3개**

- **솔루션 한 줄**: 신고서와 증빙(거래명세서·세금계산서·입금내역·배차·출입기록)을 사건 단위로 구조화하고, 고시·운영지침 규칙도구로 기준운임과 차액을 계산해, 조사 담당자가 승인하는 보완요청·사실확인 초안·관할관청 통보 묶음과 처리상황 안내를 만드는 AX
- **사람이 결정하는 지점**: 위반사실 확인 결론과 통보(TS 조사 담당), 과태료 부과(국토부장관·시·도지사, 법 제70조), 고시 미규정 쟁점 해석(국토부·안전운임위원회), 신고인 정보 노출 범위
- **기준선 확보 경로**: STFS(safetruck.go.kr) 2026-02-01 이후 사건 전수 로그(접수·보완요청·소명·통보·지자체 회신·취하일), 조사 담당 3명 4주 작업시간 기록. 2020~2022 보도 수치는 참고치로만 사용
- **사용자 결정 필요사항**
  1. 대표 컨셉 교체 승인 여부. FPIS 유지를 원하면 범위를 "2028 통합관리시스템 전환 대비 대상자 정합성 예외 검토"로 축소하는 대안(§5.6)
  2. 안전운임제 일몰(2028-12-31, CL-E09) 위험 수용 여부. 대통령 영구화 검토 지시(CL-E51)는 반대 방향 신호
  3. TS 확인 질문 발송 여부(외부 접촉이라 사용자 승인 필요): STFS 고도화 범위·계약 위치, 운영지침상 처리기한, 2026 사건 통계

### 2.2 정성 사례

- 안전운임 신고인은 거래명세서·세금계산서·운송료 입금내역 등 여러 증빙을 갖춰야 해 준비 단계부터 부담, 조사 장기화로 중도 포기(화물연대 인천 TF 발언 보도)(CL-E33)
- 과거 신고 다수가 "사실관계 입증, 자료 확보, 당사자 진술 과정"에서 종결(CL-E32)
- 2026-04 운영지침 확정: 할증은 상위 3개 요인만, 2·3순위는 50%만 가산, 대기료는 영수증·출입기록 등 객관 증빙 요구(CL-E52). 계산 규칙이 복잡하고 증빙 의존도가 큼
- 국민신문고 답변은 "고시 미규정 구간은 당사자 협의", "위원회에 전달 예정"으로 종결되는 사례 반복(no.286·288·289·298·316)(CL-E26)
- FPIS: 국토부 관계자 "화물계약 구조 입력 시스템은 구축됐지만 불법 다단계 행위자는 지키지 않는 경우가 많다"(CL-E31). 문제는 선의 신고자의 해석 혼선보다 의도적 미준수 쪽
- FPIS: TS 스스로 "지자체 운영 운수사 인허가 DB의 낮은 신뢰성"을 원인으로 진단하고 대상자 선별 검증을 과제로 설정(CL-E16)
- 다단계 적발은 민원·신고 후 위탁대장·세금계산서 합계표 대조로 이뤄진 사례(2012 행정심판)(CL-E61)
- 위험물: 사고 시 유해물질 파악 후 유선 전파 → 시스템 연계 자동 전파로 전환 중, 노후·통신오류 단말 개선 과제(CL-E19)

### 2.3 반대 증거·해석 한계

- 안전운임 처분 0건의 원인이 TS가 아닌 처분권자(시·도) 단계에 있다는 주장 존재(전북 도청 소극행정 비판)(CL-E45). TS 처리 개선이 처분률 개선으로 이어진다는 보장 없음
- 2022 미부과 587건·취하 1,418건은 당사자 합의·신고인 선택 결과(CL-E44). AI로 줄일 대상 아님
- 조사 인력은 이미 1→3명 확충(CL-E46, CL-E50). 인력 부족이 해소 중일 가능성
- 보도 수치는 정보공개청구·단체 주장 인용이며 TS 공식 통계 미확인(CL-E68 UNKNOWN)
- 국민신문고 374건은 공개 게시판 표본. FPIS 콜센터·헬프데스크 문의는 포함 안 됨(CL-E26). "FPIS 민원 0건"은 FPIS 문제 0을 뜻하지 않음
- FPIS 자유게시판의 2016년 입력 부담 불만(CL-E34)은 이후 게시가 없어 현재 상태 판단 불가
- 위험물 감지율 정의(분모) 미확인. 미감지 5건 추정은 단순 곱셈(CL-E73)
- 2025 국토교통위원회 국정감사 요구자료(국회도서관) 존재만 확인, 본문 미열람(CL-E70). TS 대상 FPIS·안전운임 국감 지적 유무 미확인

### 5.3 정상 흐름과 예외

- 정상: 접수 → F1 분해 → F2 추출·확인 → F3 계산 → F4 보완요청(필요 시) → 소명 수령 → F5 통보 초안 → 조사 담당 결재 → 기존 경로 통보 → F6 회신 대사·안내
- 예외
  - 스캔 판독 불가: 값 추측 금지, "판독 불가" 표시 후 원본 요청
  - 운임표 미규정 구간·할증 조합: 계산 중단, F7 쟁점 대장 등록
  - 동일 피신고인 반복 신고: 합동조사 후보 목록 제시(국토부 방침, CL-E46). 선정은 사람
  - 신고인 식별 우려: 통보 묶음의 신고인 정보 최소화 옵션(CL-E44)
  - 취하·합의: 사건 종결 사유를 "취하"로 분리 기록, 성과 분모에서 별도 관리
  - 지자체 회신 없음: 처분 상태를 추정하지 않고 "미회신"으로 유지

- aRDa: 증빙 필드 스키마·판본, 사건 자료의 AI-Ready 변환
- NOA: 사건별 처리 계획, 결손 시 재계획, 초안 검증
- 로컬 LLM·기존 서버 전제, 신규 인프라 투자 0원. 1차사업 공통플랫폼·문서 추출 모듈 재사용(CL-E62)

### 5.5 AI기본법·권한

- 행정처분(과태료)으로 이어지는 사실확인을 보조하므로 고영향 AI 해당 여부 검토 필요(판단 전). 최종 판단은 사람, 계산 근거·원문 위치 제시로 설명 가능성 확보
- TS 권한은 사실확인·통보까지. 처분 판단 문구를 초안에 넣지 않음

### 5.6 FPIS 처리안(보류)과 조건부 대안

- 보류 사유: 문제 증거 부재(CL-E26, CL-E67), TS 기능개선 기시행(CL-E43), 1월 계획 검증 알고리즘과 인접(CL-E16), 2028 통합관리시스템 이관(CL-E42, CL-E74)
- 조건부 대안: TS가 FPIS 헬프데스크 문의 중 정정·해석 문의 비중 자료를 제시하고, 1월 계획 검증 알고리즘 범위 밖이 확인되면 "통합관리시스템 전환 대비 대상자 정합성 예외 사건 검토"(휴·폐업·양도양수·상속·허가대수 불일치 사건의 근거 문서 정리, 처분은 시·도)로 축소 재검토

### 5.7 위험물(확장 후보 유지)

- 실시간 관제·사고 감지·전파는 AX 대상에서 제외(기존 계획 중복, 안전 필수 실시간 판단)(CL-E19, CL-E20, CL-E55)
- 텍스트 기반 후보만 유지: 운송계획정보·점검·인계 문서 상충 확인(CL-E64). 누락 빈도 실측 전 착수 보류
