# 국내외 사례의 병목·미해소·미도입 분석

- [상세 보고서](국내외_사례와_병목_분석.md): 국내 5·국외 4개 비교 항목, 세 유형과 예외 분류, TS 적용 판단.
- [구간별 비교표](병목_비교표.md): 15개 구간을 분류·근거·상태·후속 확인으로 비교.
- [병목 구간원장](병목_구간원장.json): CASE·DRS 식별자와 기존 X·N 개념 연결.
- [출처 검토 기록](출처_검토기록.json): 공식 출처 12건, 원문 응답 취득·해시·검토 위치.
- [검증 결과](검증_결과.md): 각주·파일·원장 연결 점검과 제한.
- [PDF 근거 페이지 대조](PDF_근거페이지_대조.png): PDF 40·57·99·206쪽의 2×2 확인 이미지. 출처는 NIA 사례집이며 새로 만든 도식이 아니다.

기준 원장은 기존 `03_도입사례/사례원장.json`과 `04_출처아카이브/출처원장.json`이다. 같은 사례·URL은 ID를 유지한다. 이 폴더의 GAP ID는 업무 구간 분석이며 사업 선정·법적 위탁 간선이 아니다. 변경전 파일은 이력 보존용이다.

국세청 생성형 챗봇 자료는 검색 단서를 찾았으나 직접 본문 확인이 충분하지 않아 본 비교 사례에 포함하지 않았다. AISAY FAQ도 최종 재열람이 403으로 실패하여 근거로 사용하지 않았다. 로그인이나 접근 제한을 우회하지 않았다.
