# 심층리서치 변경이력

## 2026-09-09 · v0.2 범위 정정

사용자가 현재 아카이브의 추진사업 외 AX 전환 또는 디지털전환+AI+정보화사업으로 정정했다. 기존 공시 설명 확장 001은 제외, 민원 안내와 중복 가능한 003·008은 유보했다. 002·004·005·006·007은 업무·데이터 전환, AI, 구축·연계, 운영의 독립 범위를 검토한다. 최종 계약의 비중복 확정은 미완료다.

독립 R&D를 신규 후보 유형에서 제거하고 필요한 기술 검증은 전환사업 세부 과업으로 관리한다. 사용자 피드백을 프로젝트 지침·기획서/검토 양식·예약 리서치 운영에 반영했다. 원장·화면·상세 문서에 상태를 연결하고, 기본 목록 5건·유보/제외 직접 링크·모바일 가독성 검증을 추가했다. 원문 20건과 기존 사례 19건·출처 33건은 그대로 보존했다. 새 외부 조사는 하지 않았으며 아카이브 RTM의 SFR-001~009 업무 설명을 추가 대조했다.

## 2026-09-09 · v0.1

- 기존 후보 8개와 TS 기획 기준 P01~P07을 유지하며 문제정의·연관솔루션·국내외 사례·사업화/실증·근거/미확인을 상세화했다.
- 공통 솔루션 7개, 국내외 사례 후보 19개, 출처 33개를 네 기준 원장과 후보별 문서로 연결했다.
- 실제 원문 응답 20개에 파일 해시·바이트·취득시각을 기록했다. 나머지 13개를 미보존으로 표시했고 DRS-018·019의 직접 본문 미확인을 유지했다.
- eTAS 검색 결과의 점검 공지를 직접 취득한 응답과 대조했다. 수집 응답에는 메뉴·공지·FAQ가 있고 해당 점검 문구가 없어 현행 가동 판단을 미확인으로 정정했다. 두 관찰을 출처 원장에 남겼다.
- LTA 발표일을 수집 본문으로 2025-08-23까지 구체화했다. 국외 주차설비 공급사 자료는 실명 현장 도입으로 집계하지 않았다. FAA 페이지의 공급자 수 불일치는 수치 인용에서 제외했다.
- 종합보고서, 폴더·보존 규칙, 조사 대기열, 템플릿, 문서 생성·참조/해시 검증·스냅샷 도구를 작성했다.
- 루트 안내와 통합기획 폴더의 진입 문서, 기존 예약 리서치가 참조하는 운영 문서에 새 조사 경로를 연결했다. 기존 포트폴리오 데이터·기관법령 원장·원본 TS 아카이브·예약 주기는 바꾸지 않았다.

이번 작업은 대화 중 조사이며 예약 자동화의 실행 증거가 아니다. 실제 업무·법적 적용·독립 성과 검증과 사업 승인은 수행하지 않았다. 검사 결과와 보존 스냅샷은 [검증 결과](검증_결과.md)에 기록한다.
