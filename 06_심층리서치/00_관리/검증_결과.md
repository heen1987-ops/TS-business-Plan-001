# 심층리서치 검증 결과

## v0.2 범위 정정 — 최신

현재 추진사업 외 신규 AX·디지털전환+AI+정보화만 기획하도록 정정했다. 기존 8개 ID·사례·출처를 보존하고 검토대상 5건·유보 2건·제외 1건으로 분리했다. 신규 검토대상도 비중복 미확정이다. 단순 이름 변경을 방지하기 위해 업무·데이터 전환, AI, 구축·연계, 운영, 진행사업과의 제외 경계를 필수 필드로 두었다.

문서·근거 검사 261개, 재생성 보호 3개가 통과했다. 화면 검사는 범위 필터·집계·직접 링크 상태·AS-IS/TO-BE·기관법령 연결·키보드·모바일을 확인했다. 실행별 최종 수치는 화면_검증결과.json과 심층리서치 검증결과.json을 따른다. 데스크톱과 모바일 캡처를 직접 확인해 모바일 선택값 잘림을 수정했다. 실제 사용자 인터뷰·독립 평가위원·계약상 비중복 확정은 미실시다.

변경 전 원장은 2026-09-09_범위정정_변경전, 새 조사 버전은 2026-09-09_v0.2에 보존한다. 아래의 원장 미변경·R&D 분류·검사 수치는 v0.1 당시 이력이며 현재 상태로 사용하지 않는다.

## v0.1 검증 이력

2026-09-09 / v0.1. 파일·참조·보존 무결성을 검증한다. 법률 적용성·실제 현장 사용·독립 효과평가와 구분한다.

기계 검증 **229개 통과, 오류 0건**. [검증결과.json](검증결과.json)에 실행 결과를 보존했다. 격리 복사본에서 수행한 [재생성 보호 검사](재생성_검증결과.json) 3개도 통과했다.

로컬 링크 검사는 모든 실제 경로를 대조했다. 위 검사 JSON은 마지막 실행의 링크 수를 담는다. 문서 연결이 추가되면 해당 수만 증가할 수 있다. 기존 사업 포트폴리오와 TS 법정업무 검토 원장은 이번 연결 작업 전후 해시를 대조하며, 상세 조사 때문에 선정·예산·사업 성격을 바꾸지 않았다.

## QA/QC 검토 범위

- 기존 포트폴리오의 8개 후보·유형·선정·예산 상태와 상세 조사 ID를 대조한다.
- 국내외 사례의 운영주체·지역·발표와 도입 시점·AI 역할·효과 한계가 구분됐는지 확인한다.
- 출처 주소·서지·관련 절과 파일 보존 상태를 연결하고 원문 파일의 크기·SHA-256을 재계산한다.
- 국외 공급사 2건과 직접 본문 열람 미완료 2건의 상태를 확정으로 승격하지 않는다.
- 각주·문서 링크·추적원장과 생성 문서의 해시를 검사한다.

## 판단과 한계

요청을 ‘기존 8개 후보의 문제·대안·사례를 근거와 함께 상세화하고 지속 보존할 수 있는 폴더 체계 구축’으로 정의하고 Stage-Gate와 근거 추적을 적용했다. 공식 출처 조사, 구조 설계, 원장·문서 생성, 참조 및 보존 검증을 완료했다. 예산·일정·실제 국민 수요는 가정으로 채우지 않았다.

사용자 관점의 문서 흐름은 전체 인덱스 → 후보 → 사례 → 출처 노트 → 보존 원문 또는 미취득 사유 순서로 검토했다. 문제·대안·실증·법적 경계가 없는 후보는 없고, 기관 이름 없이 확장기관 ID만 보이던 부분은 기관명과 기존 관계도 조회 링크로 보완했다. 실제 국민 대상 사용성 평가는 아니다.

QA/QC 판정: 문서·참조·보존 무결성 합격. 사업기획 판단: 현장·법적 적용·비용 검증 전의 상세 조사 초안. 독립 평가위원 판정: 미실시로 보류. 기존 화면은 수정하지 않아 UI 회귀시험을 반복하지 않았고, 문서 링크와 생성 보호를 필요한 범위에서 확인했다.

초기 검사의 오류 1종은 결과 JSON을 처음 쓰기 전에 자기 링크를 검사하던 순서 문제였다. 검사 시작 시 진행 중 상태를 먼저 기록하도록 수정한 후 재검증해 해소했다. 재생성 보호 검사는 실제 사용자 폴더를 변경하지 않은 격리 입력으로 수행했다.

기존 연결 문서의 변경 전 사본은 `99_버전보관/2026-09-09_연결문서_변경전`, 조사 버전 보존 결과는 `99_버전보관/2026-09-09_v0.1/스냅샷목록.json`으로 관리한다. 스냅샷 도구는 ZIP CRC·개별 파일 SHA-256 검증을 통과해야 목록을 작성한다. 원문은 ZIP에 중복 포함하지 않고 원문 폴더의 경로·해시로 참조한다.

독립 Reviewer·평가위원·법률 전문가·실제 국민 대상 사용성 평가는 수행하지 않았다. 내부 자료의 구성과 기계 검증만으로 사업 타당성·법적 권한·AI 효과·공공기관 참여를 승인하지 않는다. 모델 학습·민원 제출·운영 배포·외부 공개·메시지 전송은 수행하지 않았다.

잔여 과제는 [조사 대기열](조사_대기열.md)에 있으며, 검증 결과가 바뀌면 원장과 보고서도 다시 검토한다.

재사용할 교훈은 검색 결과와 직접 응답의 불일치 기록, 공급사 소개와 실명 도입 구분, 미취득 원문의 해시 금지, 수동 변경 시 생성 중단이다. 운영규칙·출처 관찰·검증 스크립트에 반영했다.
