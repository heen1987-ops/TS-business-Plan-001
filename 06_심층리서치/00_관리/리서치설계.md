# TS 문제·솔루션·도입사례 심층리서치 설계

현재 적용 v0.2: [신규사업 범위 기준](../../00_기획지침/신규사업_범위와_중복배제.md)을 우선한다. 조사 이력 8건은 보존하되 검토대상 5건·유보 2건·제외 1건을 분리한다. TS-BIZ-001은 제외, 003·008은 중복 경계 확인까지 유보한다. AX·디지털전환+AI+정보화의 AS-IS/TO-BE·AI·구축/연계·운영을 상세화하며, 독립 R&D 조사·공고를 신규사업으로 우선 추진하지 않는다.

## 범위와 가정

기존 TS-BIZ-001~008을 균형 있게 조사한다. 독자는 사업기획 담당자·내부 검토자다. 신규 사업 선정이나 공고 신청이 아닌, 근거를 추적할 수 있는 상세 기획 자료와 지속 관리 구조를 만든다. 공식 운영기관·정부·공급사 자료를 우선하며 국내외 사례는 동일 업무와 유사 기능을 구분한다. 산출물은 편집 가능한 Markdown·JSON 및 실제 취득한 원문 응답이다.

조사 기준일은 2026-09-09다. 발표일·서비스 도입일·조사일을 구별한다. 과거 시범사업을 현재 전국 운영으로 표시하지 않는다. 기존 계약·현업 데이터·사업별 예산·선정 결과는 제공·확인되지 않았다.

## 조사 질문

1. 누구의 어떤 상황에서 실패·불편·위험이 발생하는가? 규모·원인·현행 대응 중 무엇이 확인됐는가?
2. 이미 제공하는 서비스는 무엇이며, 어떤 공백이 신규 정보화 또는 R&D를 정당화하는가?
3. 국내외 누가 어디서 무엇을 도입·실증했는가? AI 역할과 운영·효과 증거는 각각 무엇인가?
4. 기관별 법적 역할·데이터 권한·재정 경로가 달라질 때 어떤 기능을 재사용할 수 있는가?
5. 원문이 변경되거나 오류가 확인되면 어떤 주장·후보·기획 판단을 재검토해야 하는가?

## 관리 구조

- 기존 `00~05` 폴더: 원래 역할과 경로 유지. `04`는 기관·법령의 기준 원장, `05`는 사업 포트폴리오의 기준 원장.
- `06_심층리서치/00_관리`: 폴더 규칙, 조사 계획, 검증, 변경 이력, 다음 조사.
- `01_후보별/TS-BIZ-번호_주제`: 문제정의, 연관솔루션, 국내외사례 비교, 사업화·실증, 근거·미확인.
- `02_공통솔루션`: 재사용 가능한 기능 묶음과 솔루션 원장.
- `03_도입사례`: 한 사례당 하나의 기준 문서. 후보에는 사례 ID와 적용 판단만 연결.
- `04_출처아카이브`: 출처 원장·검토 노트·취득 시점별 원문 응답. 원문과 요약을 구분.
- `05_종합분석`: 전체 비교·종합보고서·추적 관계.
- `90_템플릿`: 새 후보·사례·출처를 같은 형식으로 추가하는 양식.
- `99_버전보관`: 확정된 조사 스냅샷과 파일 해시. 사업 승인 의미 없음.

## 실행 및 수용기준

L 규모, Medium 위험도, Stage-Gate와 근거 추적을 적용한다. 읽기 전용 맥락 확인 → 출처 탐색·본문 검토 → 분류 설계 → 하나의 작성 주체로 문서·원장 생성 → 기계적 참조 검사 → 사실·추론 및 사용자 탐색 검토 → 스냅샷 보존 순으로 진행한다. 독립 평가위원 또는 실제 법률 검토를 수행한 것으로 보고하지 않는다.

| ID | 수용기준 | 검증 |
|---|---|---|
| DR-01 | 8개 후보 모두 문제·대안·국내외 비교·법적 경계·미확인 항목을 보유 | 원장 및 파일 검사 |
| DR-02 | 모든 사례에 운영주체·지역·시점·도입단계·AI 여부·효과 한계 기록 | 사례 필수 필드 검사 |
| DR-03 | 공식 원문 주소·제목·발행주체·날짜·본문 위치·열람 상태 관리 | 출처 원장 및 검토 노트 검사 |
| DR-04 | 취득한 파일은 실제 크기·SHA-256·취득시각을 기록 | 파일 재해시 대조 |
| DR-05 | 후보→문제→솔루션→사례→출처 및 기존 법정업무 ID 추적 가능 | 참조 무결성 검사 |
| DR-06 | 미확인 사례·가능규정·공급사 주장을 운영·효과 확정으로 승격하지 않음 | 문서 검토 및 상태 검사 |
| DR-07 | 기존 원본·포트폴리오 선정 상태 보존, 조사 인덱스에서 탐색 가능 | 변경 범위 및 링크 검사 |
| DR-08 | 새 자료 추가·개정·폐기·복구 절차와 재검토 대기열 제공 | 운영 문서·양식·스냅샷 확인 |

## 사전 검토

내부 기획 자료 작성 범위로 진행 가능하다. 국가별 권한·운영환경을 같게 가정하거나 수집 건수를 연구 완성도로 해석하지 않는다. 자료 부족은 공백으로 남긴다. 예산 산정·모델 선정·운영 배포·외부 전송은 이번 조사 산출물에 필요하지 않아 생략한다.
