## 실행 절차

3. 대기열의 미결사항을 처리하고, 공식 명단에서 미조사 기관을 순차 선정한다. 기본 작업량은 핵심 업무 검토 기준 기관 3~5개이며 자료 난이도에 따라 줄인다. 수량을 채우려고 근거를 추정하지 않는다.
4. 기관 유형·주무부처·설립 근거·법정/위탁업무·수행조직을 원문과 시행일로 매핑한다. 각 관계의 확인 수준을 구별한다.
5. `../05_통합사업기획/사업포트폴리오.json`과 해당 폴더의 `사업유형_판단기준.md`를 읽고 TS 관련 사회문제·기관·법령의 새 근거를 후보 ID에 연결한다. 국민 가치·R&D의 기술적 불확실성·비AI 대안·SI와 AI 범위·직무 영향·실증·운영·확산·심의 경로를 구별한다. 적합한 후보가 없으면 억지로 만들지 않는다. 탐색 후보를 공고 사업·선정 사업·예산 확보로 자동 승격하지 않는다.
6. 원장, 출처 목록, 대기열과 `실행기록/YYYY-MM-DD_리서치.md`를 갱신한다. 포트폴리오를 바꾼 경우 단일 원장 `05_통합사업기획/사업포트폴리오.json`의 확인일·출처·미확인 상태를 갱신하고 같은 폴더의 `생성_통합보기.py`로 화면·요약·과제 관리대장을 함께 생성한다. 변경된 동작과 데이터 참조를 검증한다. 같은 날 재실행하면 새 중복 기관을 만들지 않고 기존 기록에 이어 쓴다.
7. JSON 파싱, ID 중복, 관계의 참조 대상, PUB/SRC 출처 존재, 시행일·미검증 상태를 확인한다. 기존 기록을 근거 없이 삭제·확정으로 승격하지 않는다.
8. 이번 확인 범위, 발견·변경·미확인 사항, 관련 기획 영향, 다음 조사 시작점을 기록한다.

- 중요 법령 변경, 유효한 신규 사업기회, 조사 단계 완료, 오류 또는 사용자 판단이 필요할 때 알린다.
