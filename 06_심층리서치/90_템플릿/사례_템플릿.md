# CASE-번호 · 사례명

- 국가·실제 도입지역:
- 운영기관·공급사·역할:
- 공식 문서 제목·발행주체·DRS ID:
- 발표일·도입일·후속 갱신일·조사일:
- 단계: 소개 / 구매 계획 / 시범 / 운영 확인 / 확대 / 중단 / 미확인
- 대상 사용자·시설·도입 범위:
- 해결한 문제와 기존 대응:
- 실제 AI 역할과 비AI 기능:
- 결과지표·분모·관측기간·비교군:
- 자체 발표인지 독립 평가인지:
- 비용·운영비·라이선스·실명 고객 확인:
- 실패·반대 근거·현행성·접근 한계:
- TS 후보·SOL ID와 적용 판단:
- 법적 역할·데이터·운영환경의 차이:
- 추가 확인·버전·대체 기록:

‘미확인’은 ‘없음’과 다르다. 예측 정확도·검출 건수·이용 만족·사고 감소를 같은 지표로 취급하지 않는다. 각 사실 문장 뒤에 공식 출처 각주를 붙이고 끝에 전체 서지 정보를 적는다.
