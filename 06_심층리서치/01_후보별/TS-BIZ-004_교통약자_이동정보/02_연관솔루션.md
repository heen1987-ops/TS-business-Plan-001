## 현행 → 개선 가설

| 전환 항목 | 범위 |
| --- | --- |
| AS-IS | 시설·운행 정보와 실제 사용 상태·갱신 책임이 분리돼 있는지 확인 |
| TO-BE | 시설 상태·시각·책임자→불일치 확인→갱신→이동 지원·오류 회수 |
| 디지털전환 | 시설·출입구 ID, 접근 조건·관측시각·갱신 책임과 품질 기준 |
| AI 핵심 기능 | 정보 불일치·변경 신호 탐지와 이용 조건에 맞는 설명 |
| 정보화 구축·연계 | 시설·서비스 정보 표준화, 갱신 책임, 교통정보 연계, 접근성 화면·상담 대체 경로 |
| 운영·책임 | 정보 갱신·현장 확인·지원 상담의 역할과 부담을 명확히 하고 현업·이용자 검증을 선행 |
| 추진사업과 제외 경계 | 새 전국 길찾기 앱·일반 민원 챗봇·기존 플랫폼 고도화 |

시설·서비스 정보 표준화, 갱신 책임, 교통정보 연계, 접근성 화면·상담 대체 경로

| 대안 | 구현 범위 | 선택 조건 |
| --- | --- | --- |
| A. 비AI 비교 기준 | 검증된 시설 목록·조건 검색·전화 확인·갱신 알림 | AI 추가 가치가 없으면 이번 신규 후보를 유보·제외 |
| B. AX·디지털전환+AI+정보화 | 정보 불일치·변경 신호 탐지와 이용 조건에 맞는 설명 | 현재 추진사업과의 비중복 대조 및 최신성·현장 확인 책임과 대체 경로를 먼저 확보 |
| C. 필요한 기술 검증·PoC | 불완전한 접근성 정보의 신뢰도·갱신 필요성을 추정하면 단순 정보 목록보다 이동 실패를 줄이는가? | 전환사업의 세부 과업으로 검토·독립 R&D 기획 제외 |

비용·기간은 모두 미산정이다. 비교에는 콘텐츠 정비, 데이터 연계·정답 작성, 전문가 검토, 모델 이용료, 모니터링·정정, 장애 대체 절차까지 포함한다. AI 사용량이나 모델 정확도 한 가지로 대안을 선택하지 않는다.

## 데이터·업무 흐름 — 제안

공식 원천·업무 규칙 등록 → 출처·시점·접근권한 확인 → 기존 검색·규칙 기준안 → 허용된 AI 보조 → 담당자 판단 또는 국민의 공식 절차 진행 → 오류·정정·조치 결과 기록.

- 필요한 입력: 시설·출입구·승강기 ID와 상태, 관측시각, 갱신 책임, 접근성 조건, 허가된 실제 이용 평가
- 책임 경계: 기존 서비스의 데이터 신뢰·갱신·설명·대체 확인. 새 전국 길찾기 앱을 전제로 하지 않으며 안전한 경로를 보장하지 않는다.
- 공개 전 조건: 비중복 근거, 업무·데이터 전환, AI 추가 가치, 시스템 구축·연계, 운영·국민 성과를 모두 확인. 실제 수탁 근거·지자체/운영사 갱신 책임과 현장 평가 확보가 선행 조건이다.

업무 규칙과 원자료의 버전을 답변·검토 결과에 연결한다. 원문 부족, 규칙 충돌, 접근권한 부족은 각각 이유를 표시하고 공식 담당 채널로 넘긴다. 생성한 문장이 원자료에 없는 사실·허가·검사 결과를 만들지 않도록 검토한다.

## 기존 사업과 중복 판단

시설·출입구 상태, 갱신 책임, 오류 회수와 실제 이동 지원을 연결하는 전환사업으로 검토한다. 최종 계약·승인 범위의 대조는 미완료다.

기존 계약 원문, 승인된 요구사항, 실제 구축 화면·데이터 연계·운영 기능을 대조하기 전에는 재사용 가능 자산이나 신규 과업으로 확정하지 않는다. 계약 이행·신규 사업·수행사 내부 도구는 각기 다른 범위로 기록한다.
