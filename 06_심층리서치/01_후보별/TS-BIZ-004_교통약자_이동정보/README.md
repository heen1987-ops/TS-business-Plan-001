# TS-BIZ-004 · 교통약자 이동정보 신뢰·연계 정보화

> 현재 범위: **검토대상** / 디지털전환+AI+정보화. 시설·출입구 상태, 갱신 책임, 오류 회수와 실제 이동 지원을 연결하는 전환사업으로 검토한다. 비중복은 미확정이다. 연구·PoC는 전환사업 세부 과업이며 독립 R&D는 현재 대상이 아니다.

- 문제 ID: PRB-004
- 기획 유형: 디지털전환+AI+정보화
- 조사 상태: 신규범위 검토 · 비중복 미확정 / v0.2 / 2026-09-09
- 사업 선정·재원·예산·추진 일정: 미정

교통약자는 경로에 편의시설이 표시돼도 실제 사용 가능 상태·접근 조건·연결 구간이 다르면 이동에 실패할 수 있다. 전국 인구 규모와 도 지역 시설 실태는 맥락이며, 구체적 서비스 과제는 정보와 현장 상태의 불일치를 줄이는 것으로 정의한다.

## 다음 판단을 바꾸는 증거

교통약자법 시행령상 실제 위탁 고시, TS 역할과 서울동행맵 등 기존 서비스 협업 가능성

비중복 근거, 업무·데이터 전환, AI 추가 가치, 시스템 구축·연계, 운영·국민 성과를 모두 확인. 실제 수탁 근거·지자체/운영사 갱신 책임과 현장 평가 확보가 선행 조건이다.

공통 사례와 출처는 후보 폴더에 복제하지 않고 ID로 연결한다. 사실·가설·적용 판단을 구별하고 현장 검증 후 후보분석 원장을 개정한다.
