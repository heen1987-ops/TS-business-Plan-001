# TS-BIZ-006 · 철도 안전증빙·시정조치 AX 전환

> 현재 범위: **검토대상** / AX 전환. 일반 문서 질의응답과 구분해 요건·증빙·현장 조치·보완 종결을 연결하는 업무 AX로 검토한다. 비중복은 미확정이다. 연구·PoC는 전환사업 세부 과업이며 독립 R&D는 현재 대상이 아니다.


[전체 조사 인덱스](<../../README.md>) · [전체 포트폴리오](<../../../05_통합사업기획/사업기획_통합보기.html>)

- 문제 ID: PRB-006
- 기획 유형: AX 전환
- 조사 상태: 신규범위 검토 · 비중복 미확정 / v0.2 / 2026-09-09
- 사업 선정·재원·예산·추진 일정: 미정

철도 안전체계 검토에서 규정·운영절차·점검기록·변경조치의 버전과 관계가 어긋나면 안전상 중요한 누락이나 모순을 확인하기 어려울 수 있다. TS 검토 업무와 운영기관의 예측정비를 구분한 뒤 증빙 추적을 기획한다.

## 다음 판단을 바꾸는 증거

문서와 운영 데이터의 열람권, 최신 기술기준, 전문가 판독 기준, 조직별 승인·정비 책임

비중복 근거, 업무·데이터 전환, AI 추가 가치, 시스템 구축·연계, 운영·국민 성과를 모두 확인. 별도 조직의 유지보수 성과를 TS 증빙검토 효과로 전용하지 않고 업무별 실증 근거를 확보한다.

공통 사례와 출처는 후보 폴더에 복제하지 않고 ID로 연결한다. 사실·가설·적용 판단을 구별하고 현장 검증 후 후보분석 원장을 개정한다.
