# TS-BIZ-007 · 위험물 사고정보·공동대응 연계 정보화

> 현재 범위: **검토대상** / 디지털전환+AI+정보화. 기존 관제 기능과 구분한 사건 정보·권한·수신 확인·기관 간 인계 전환을 검토한다. 비중복은 미확정이다. 연구·PoC는 전환사업 세부 과업이며 독립 R&D는 현재 대상이 아니다.


[전체 조사 인덱스](<../../README.md>) · [전체 포트폴리오](<../../../05_통합사업기획/사업기획_통합보기.html>)

- 문제 ID: PRB-007
- 기획 유형: 디지털전환+AI+정보화
- 조사 상태: 신규범위 검토 · 비중복 미확정 / v0.2 / 2026-09-09
- 사업 선정·재원·예산·추진 일정: 미정

위험물 운송 사고에서 필요한 물질·위치·운송정보가 권한 있는 대응자에게 제때 전달되지 않으면 판단과 인계가 지연될 수 있다. 기존 관제·전파체계의 실제 공백을 확인한 뒤 경보와 공동대응을 검토한다.

## 다음 판단을 바꾸는 증거

국내 시스템 직접 열람과 실제 운영 세부, 대행 지정·데이터 공유 범위·현행 대응 매뉴얼

비중복 근거, 업무·데이터 전환, AI 추가 가치, 시스템 구축·연계, 운영·국민 성과를 모두 확인. 실제 대행·목적 제한·공동활용·지휘 책임을 확인하기 전 운영 통합을 확정하지 않는다.

공통 사례와 출처는 후보 폴더에 복제하지 않고 ID로 연결한다. 사실·가설·적용 판단을 구별하고 현장 검증 후 후보분석 원장을 개정한다.
