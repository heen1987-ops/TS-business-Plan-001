# TS-BIZ-002 · 사업용차 안전개입 AX 전환

> 현재 범위: **검토대상** / AX 전환. 전세버스 공시 산출물과 구분한 운행위험→교육·안전조치→이행 확인 업무를 검토한다. 비중복은 미확정이다. 연구·PoC는 전환사업 세부 과업이며 독립 R&D는 현재 대상이 아니다.

- 기획 유형: AX 전환
- 조사 상태: 신규범위 검토 · 비중복 미확정 / v0.2 / 2026-09-09
- 사업 선정·재원·예산·추진 일정: 미정

사업용차 안전관리에서 위험행동을 많이 검출해도 운전자·운수사업자가 실행할 수 있는 예방 조치로 연결되지 않으면 국민 안전 편익이 생기지 않는다. 기존 eTAS 분석과 중복되는 탐지 기능보다 조건에 맞는 개입의 질을 확인한다.

## 다음 판단을 바꾸는 증거

eTAS 공개 점검 공지의 현행성, 실제 인터페이스·로그·데이터 재사용권, 사업용차 분리 통계

비중복 근거, 업무·데이터 전환, AI 추가 가치, 시스템 구축·연계, 운영·국민 성과를 모두 확인. 데이터 사용권·현재 시스템 가동과 개입 주체를 먼저 확인하고 안전 신호를 정확도만으로 평가하지 않는다.

공통 사례와 출처는 후보 폴더에 복제하지 않고 ID로 연결한다. 사실·가설·적용 판단을 구별하고 현장 검증 후 후보분석 원장을 개정한다.
