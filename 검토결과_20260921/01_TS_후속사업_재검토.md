# CCK TS 후속사업 재검토

작성일: 2026-09-21 · 상태: 공고 미매핑 내부 기획 초안

## 1. 결론

**TS-03의 ‘운행상황에 맞는 안전정보 해석·대응지원’을 가장 먼저 검증한다.** 제공된 도로안전등급·사고정보·운행기록의 구조를 이용해 설명의 적용조건과 한계를 구체화할 수 있다. 다만 이번 자료만으로 특정 운전자나 노선의 현재 위험을 예측하거나, 신규 구매수요가 확인됐다고 판단할 수는 없다.

검사장비 부적합·재검사 지원은 데이터가 구체적이지만 기존 검사본부 AI와 겹치는 범위가 확인돼 **후속 확장 후보**로 둔다. 철도 자격교육은 별도 업무영역의 탐색 후보로 남긴다. TS-04 교육시설 운영 및 TS-16 검사예약 지원은 기존 문제 가설을 유지하되, 이번 다운로드 자료로 데이터 확보 조건이 충족된 것으로 보지 않는다.

이번 우선순위는 **데이터로 검토 가능한 범위와 기존사업 중복 위험에 대한 기획 판단**이다. 수익성 순위, 수주확률, 신규사업 승인 결과가 아니다. 제공 파일은 문제를 검증할 출발점이며 구매의사·업무상 손실을 직접 증명하는 자료는 아니다.

## 2. 검토 범위와 가정

- 지정 폴더의 직접 파일 30개: CSV 25개, ZIP 2개, MP4 3개.
- ZIP 내부 CSV 1개를 추가하여 총 26개 CSV의 전 행을 읽고 구조·결측·중복·기간을 점검.
- ZIP 2개 내부 목록과 공공누리 표시 이미지 확인. 두 이미지는 해시가 동일하며 출처표시·상업적 이용금지·변경금지 표시를 담고 있음.
- MP4는 직접 파일 3개와 ZIP 내부 1개의 존재·구성만 확인. 영상 시청, 자막 추출, 교육내용의 현행성 검증은 미실시.
- 참조 대화 「CCK TS 사업 조사」의 최근 20개 턴 조회. 최근 10개 턴은 응답당 조회 상한을 높여 재확인. 전체 과거 대화 및 과거 첨부파일을 전수 검토했다는 의미는 아님.
- CCK 공통플랫폼 정성제안서 PDF 70쪽 직접 텍스트 판독. 자동차검사 Q&A의 검사원·고객용 시나리오, 법령 출처, 다중 대화, 데이터·화면 연계 기재 확인. 제안 기재를 구현·검수 실적으로 해석하지 않음.
- 검사본부 정성제안서의 해당 로컬 파일은 133바이트 Git LFS 포인터로 본문 미확보. 특수검사 범위는 회사 아카이브 관리문서 §5.2로 확인했으며, 최신 원 제안서·계약과의 최종 대조는 남아 있음.
- 현 단계는 사업 방향 검토. 신규 개발, 예산 확정, 대외 제안·제출은 수행하지 않음.

가정: 실제 구매 주체와 기존 시스템에 남아 있는 이용 문제를 중심으로 후보를 비교한다. 사용자의 사업 우선목표가 달라지면 순위를 조정한다.

## 3. 기존 대화에서 이어받을 판단 맥락

1. TS-01, TS-02처럼 큰 사업컨셉 단위로 판단하고 개별 API·화면을 독립사업으로 부풀리지 않는다.
2. 기존 대화에서 이미 수행 중으로 확인된 민원 AI, 전세버스 평가·공시 AI, 자동차검사 Q&A는 중복 제외의 기준선으로 둔다. 최신 계약상 경계는 별도로 확인한다.
3. 안전 관련 사업은 교육·검사·조치의 질과 이용자의 이해·행동까지 연결한다. 문서 작성시간 단축만으로 공공가치나 신규성을 확정하지 않는다.
4. 기능의 존재, 현장의 문제, 기존 시스템의 미해결 범위, 추가 구매수요는 서로 다른 확인사항이다.
5. TS-01~16의 기존 번호를 유지한다. 이번에 발견한 추가 후보는 번호를 새로 부여하지 않고 기존 편제와의 관계부터 정리한다.

## 5. 데이터 연결과 품질의 현실 조건

### 5.1 현재 파일만으로 가능한 연결

- 장비 부적합 자료의 `(기기명, 형식)` 746행 모두 형식등록 자료의 동일 문자열 조합에 존재한다. 이는 형식 범주의 대응이며 동일한 개별 장비를 연결했다는 뜻은 아니다. 형식명 263종은 등록표에서 복수행이므로 일대일 결합을 가정하지 않는다.
- 도로안전등급은 링크id별 단일행이지만 좌표·도로 형상이 없다. 사고 좌표와 결합하려면 동일 버전의 표준노드링크/공간자료와 방향·시점 대응이 필요하다.
- Trip 파일은 경로 전체·운전자 식별키·교육생 연결키가 없다. 도로 구간, 개별 운전자, 교육 전후를 파일끼리 직접 연결할 수 없다.
- 사고 메시지·CCTV는 모두 좌표가 있어 지리적 근접성 검토가 가능하지만 동일 사건의 영상이나 실제 사고 관측을 연결했다는 뜻은 아니다.
- 한국교통안전공단과 한국도로교통공단(옛 표기 도로교통공단)은 다른 기관이다. 교육계획·수료 통계는 기관·대상·과정이 일치하는지 먼저 확인한다.

### 5.2 재기획에서 놓치면 안 되는 값

- 도로안전등급: 실제 등급값 A~D와 문자열 `NULL` 14행. 제한속도 `999 km/h` 135행, `0 km/h` 4행. 결측·미정 코드인지 공식 정의 확인 전 실제 속도로 해석하지 않는다. 도로명 빈칸 28,056행.
- 사고연계: 전체열이 같은 중복 13행. 중복을 제거하더라도 메시지 갱신과 고유 사고를 구분할 ID가 없어 고유 사고 건수는 확정할 수 없다. 도로정보는 고속도로 13,813행·국도 693행이어서 생활도로 전체의 위험 표본으로 일반화하지 않는다.
- Trip: 자료제출·시동ON·시동OFF 값 100행 모두 지수표기. 해당 파일만으로 원래의 정밀한 시각을 복원할 수 있다고 보지 않는다.
- 궤도시설: 희망 종료일에 `1900-01-01`이 존재. 예약 슬롯이나 실제 검사 완료일로 처리하지 않는다.
- 인구밀도: 행정구역코드 중복에 해당하는 행이 92행. 지역코드 조인으로 행이 늘어나는지 점검해야 한다.
- 부적합·재검사: 완전 중복 1행. 재검일 공란 148행은 자료 작성시점의 의미를 추가 확인할 대상이며 현재 미이행 148건의 증거가 아니다.

이 값들은 이번 제공본에서 확인한 현상이다. 원천 업무시스템 전체의 결함이나 현재 운영 장애로 확대하지 않는다. 분석 원본은 수정하지 않았다.

## 8. 함께 남길 후보와 제외할 과장

### 8.1 기존 검사본부 AI의 후속 확장 후보

검토할 가치는 ‘현장에서 발견한 장비 부적합을 어떤 조치·증빙·재검사 준비로 연결할 것인가’에 있다. 검사장비의 정확도와 성능을 확인하는 업무의 의미 및 담당부서는 TS 공식 기기정도검사 안내에서 확인된다. [기기정도검사 안내](https://main.kotsa.or.kr/portal/contents.do?menuCode=01030201)

그러나 회사 아카이브 §5.2에는 이미 기기 도면·제원표 라이브러리, 구조 기준·계산식 검증, 부적정 부분 표시, 알림톡, 성적서 이력, 궤도시설 안전관리계획 검토가 기재돼 있다. **장비검사 AI 신규 도입으로 추천하지 않는다.** 최신 요구사항에 없는 현장 조치·재발 여부·재검사 증빙 연결이 존재하는지부터 확인한다.

필요 자료는 최신 특수검사 요구사항·업무 화면, 실제 부적합 통지서, 조치·수리 기록, 재검사 결과, 담당자 확인 기록이다. 공개 CSV는 구체적인 부적합 사례의 존재를 보여줄 뿐, 조치 지연·재발·검사 신뢰성 저하의 규모를 증명하지 않는다. 안전도측정기기와 환경측정기기의 검사체계도 섞지 않는다.

### 8.2 철도 자격교육의 탐색 후보

철도 운전면허·관제 자격 평균점수를 출발점으로, 교수자에게 과목별 추가 점검이 필요한 영역과 관련 교재·훈련자료를 연결하는 방향을 검토할 수 있다. 개인 맞춤교육이나 자동 출제 사업으로 즉시 확대하지 않는다.

응시인원·문항 구성·난이도·교육 참여자·과목별 분산과 학습결과가 없으므로 낮은 평균의 원인을 ‘교육 부족’이라고 단정하지 않는다. 기존 AI 출제·검증 사업 및 교육시스템 범위와의 차이도 확인한다. TS-06 교통안전관리자 자격시험과 구분해 관리한다. [철도종사자 자격시험 안내](https://main.kotsa.or.kr/portal/contents.do?menuCode=02030200)

### 8.3 현재 자료만으로 추진 근거가 부족한 방향

- CCTV 실시간 사고탐지: 위치 목록만 확보. 영상 접근·이용조건·실시간 운영체계 추가 필요.
- 개인 운전자 위험예측·교육효과 입증: 최신 개인·운행·교육 결과의 연결과 적절한 비교자료 필요.
- 전국 위험도/사고율 순위: 사고 메시지의 모집단·중복·노출분모와 도로·지역 기준의 정합성 필요.
- 교육시설 가동 최적화: 실제 시설·차량·강사 가용상태와 과정별 필수조건 필요.
- 자동차검사 실시간 예약추천: 승인된 차량·검사조건 및 예약 가용시간 조회가 필요. 희망일이나 사업소 코드로 대체 불가.
