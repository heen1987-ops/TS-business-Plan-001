# TS 후속사업 전면 재검증 결과

2026-09-21 · v1.2 · 대화 확인 기준 14:07 KST / 공개자료 확인일 2026-09-21

## 1. 결론

**앞선 컨셉 중 여러 개가 2026년 실제 발주 과업과 직접 겹친다. 신규사업을 늘리는 방향의 기획을 수정한다.** TS-03의 우선 추천은 철회하고, TS-05·07·10·13·15도 기존 사업 이후의 잔여 문제를 입증하기 전 독립 신규사업 추천을 보류한다. TS-08은 계속 신규사업에서 제외한다.

**다음 사업 검증의 우선 후보는 TS-09와 TS-11이다.** 공개적으로 제기된 문제가 있고 확인할 업무 창구도 있지만 현재의 미해결 규모·추가 구매의사·자료 사용권은 확정되지 않았다. 따라서 '수주 가능한 신규사업 2개'가 아니라, 사업으로 성립하는지 먼저 확인할 두 컨셉이다.

공공데이터를 내려받았다는 사실은 운영 데이터·개인별 결과·실시간 예약정보·학습권한을 확보했다는 뜻이 아니다. 이번 자료의 주된 용도는 구조·범위·품질과 기존 업무를 파악하는 데 있다.

## 2. 무엇을 어디까지 확인했는가

문제는 '아이디어가 더 필요한가'보다 **기존 대화의 컨셉이 현재 사업과 겹치는지, 실제 문제와 이용 가능한 자료로 뒷받침되는지**였다. 내부 기획을 위한 Discovery·Stage-Gate 검토로 수행했고, 실제 시스템 구현·기관 연락·운영 변경은 범위에 포함하지 않았다.

### 예산·일정의 해석

공식 과업서에서 검사본부 AI는 800,499,634원, 출제 AI는 249,892,403원, 모빌리티 조사·연구는 331,500,000원, 운수종사자 관리시스템은 152,697,959원(VAT 포함)을 확인했다. 이는 **해당 발주 과업의 예산·용역금액 표기**이며 체결계약·CCK 매출·신규사업 견적이 아니다. 연초 발주계획 금액과 다를 수 있고, 공통플랫폼·민원·전세버스 구성이나 재공고를 따로 합산하지 않는다.

## 5. 신규 검증 후보를 어떻게 좁힐 것인가

### TS-09: 철도용품 기준·시험·입증자료 연결

[2025-12-30 개선 결과](https://www.epeople.go.kr/idea/kotsa/1AE-2512-0002729/detail.npaid)는 철도용품 7종의 전문가 검토 방향을 제시한다. 기존 제도개선이 있으므로 '기준을 AI로 검색해 준다'는 기능만으로는 사업 차별성이 부족하다.

- **확인할 사용자·문제 가설:** 제작·수입사와 철도승인처 검토자에게 동일 용품의 적용판본·요구조건·시험 및 입증자료를 연결하는 반복 보완이 현재도 남아 있는지 확인.
- **초기 검증 단위:** 용품 1종의 실제 정상·보완 사례를 기준으로, 적용 조항→요구 시험→제출 증빙→보완 이유를 한 묶음으로 대조. 표준 이용권과 자료 제공 승인이 필요.
- **CCK 공급 가설:** 문서 구조화와 근거·판본 연결, 확인 누락 표시, 전문가 검토 이력. 기존 승인 절차에 붙는 검토지원이며 자동 승인 아님.
- **사업 성립 조건:** 기존 전문가 검토·규정 개정 이후에도 동일한 입증 단절이 남고, 새 도구가 기존 검색·체크리스트보다 필요한 이유를 현업 사례로 입증.
- **중단 기준:** 문제 원인이 기준 자체의 정책 결정을 기다리는 것이거나, 현행 개선으로 해결됐거나, 필요한 표준·실제 자료를 사용할 수 없는 경우.

### TS-11: 시험목적에서 공식 시험의뢰 준비까지 연결

[2026 장비 수요조사](https://www.epeople.go.kr/idea/kotsa/1AE-2607-0001975/detail.npaid)는 원거리 시험 이용과 장비 수요를 다룬다. [기존 TS 시험서비스 안내](https://main.kotsa.or.kr/portal/bbs/report_view.do?bbscCode=report&bbscSeqn=18558&menuCode=05010200)는 이미 시험·상담·예약 창구를 제공한다.

- **확인할 사용자·문제 가설:** 기업의 개발·품질 담당이 시험목적과 시료조건을 기관의 수행범위에 맞추는 과정에서 잘못된 시험 선택·반복 문의·재준비가 실제로 발생하는지 확인.
- **초기 검증 단위:** 시험인증처가 현재 제공하는 한 시험분야의 의뢰·상담 사례. 외부 시험기관 전체를 연결하는 포털로 시작하지 않음.

- **사업 성립 조건:** 장비 부족을 제외해도 반복되는 정보·준비 문제가 있고 기존 상담·서식 개선보다 의미 있는 추가 편익이 확인됨.
- **중단 기준:** 원인이 실제 장비·인력·처리용량 부족이거나 기존 상담 개선만으로 해결됨. 이 경우 시설 확충·공동활용·운영조정 과제로 전환.

두 후보 모두 실제 수요자·담당자 확인 전 개발 예산이나 매출을 가정하지 않는다. 현재 가능한 산출물은 이번 근거 묶음과 사례 검증 틀이며, 실제 검증 데이터를 확보한 것처럼 시연하지 않는다.

**판정: 기획 재검토 문서는 조건부 합격. 신규 사업의 구매·구현 확정은 보류.** 내부 품질 점검과 원문 재검증을 마쳤지만 실제 잔여 사례·사용권·현업 편익·구매 책임의 확인을 대체하지 않는다.
