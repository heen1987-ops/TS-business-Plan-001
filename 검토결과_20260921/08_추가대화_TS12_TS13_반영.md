# 추가 대화 반영: TS-12·TS-13

2026-09-21 · v1.3 · 최종 대화 확인 14:35 KST · 79턴

**새로 완료된 TS-12·13의 구체화 내용을 기존 사업기획에 반영했다.** TS-12는 건립 선행조건과 주민편익 조치의 이행, TS-13은 운행요건 확인 건의 상태·후속조치·정정 반영을 중심으로 보완했다. 두 안건 모두 실제 잔여 문제와 구매수요가 확정된 것으로 승격하지 않았다.

## 1. 이번 확인 범위

- 작업 유형·규모: 기존 기획의 변경분 반영, M / Medium.
- 방법론: 변경 내용·영향 대조 → 새 외부 주장 공식 확인 → 컨셉과 요약 동기화 → 요구사항·링크 점검.
- 대상 독자·성공기준: CCK·TS 기획 검토자가 원 대화의 추가 내용과 공식 중복 근거를 함께 읽을 수 있도록 같은 번호·상태·근거 유지.
- 가정: 이미 확인한 과업·원자료의 판단은 새 반증이 없는 한 유지. 새 대화의 설명은 외부 사실의 증거를 대신하지 않음.
- 생략: 신규 WBS·예산·개발·화면·배포 산출물. 사용자가 요청한 사업컨셉 변경에 집중.
- 기존 v1.2의 77번 턴에는 사용자 '다음'만 있었으나 이번에 TS-12 응답이 완료됐다. 78번 TS-13도 완료됐고 79번은 사용자 '다음'만 있다. 이번 최종 재조회에 TS-14 신규 응답은 없었다.
- 새 TS-12·13 응답 본문을 전부 읽었다. 과거 76턴까지 이미 읽은 내용을 다시 처음부터 재검토했다고 보고하지 않는다.

### TS-12에 추가한 핵심

1. **법적 절차를 미리 단정하지 않음:** 공개 발제의 '용도변경'은 재산 상태·처분/취득·도시계획/시설·건축/공사·기존 서비스 전환 중 무엇을 뜻하는지 개별 부지에서 확인.
2. **이행 상태 구분:** 검토안, 합의조건, 승인계획, 실제 이행결과, 잔여쟁점을 분리. 의견을 요약하거나 대체공간을 검토한 상태를 이행 완료로 취급하지 않음.
3. **주민편익을 실제 조건으로 연결:** 대체주차의 대상·이용가능일·접근성·운영조건·예산을 기존 주차기능 중단 시점과 대조.
4. **추진 순서:** A 기존 절차·대응표 정비 → 반복적인 내용 대조 부담이 남으면 B 기존 시스템 연계 모듈 → 복수 사업의 재사용성과 참여책임이 확인되면 C 확장.
5. **평가·수익 경계:** 필요한 심의시간이나 정상 계획변경을 실패로 세지 않으며 주민 찬성률·인허가 성사를 성과·수익 기준으로 두지 않음. 건축·법무·사업관리 전문책임은 해당 수행자가 유지.

### TS-13에 추가한 핵심

1. **사람 전체가 아닌 확인 건을 관리:** 특정 종사자의 해당 업종·요건·사유·기간을 관리단위로 설정. TS-06 교통안전관리자 자격과 혼동하지 않음.
2. **설계상 5개 상태:** 미충족 확인 / 자료 부족 / 정보 불일치 / 조치 후 결과확인 대기 / 해당 요건 충족 확인. 법정 분류를 새로 만든 것이 아님.
3. **다른 시점을 분리:** 사실 발생, 원천 반영, 회사 확인, 알림, 조치, 정정 반영. 예약·검사 실시·요건 충족·정보 반영도 별도 상태.
4. **조회실패와 부적격 구분:** 조회되지 않았다는 이유로 부적격 판정, 경고가 없다는 이유로 모든 요건 충족 또는 운행 허용을 하지 않음.
5. **기존 범위 우선:** 단순 값·기간 비교와 갱신·기술적 오류는 기존 연계·규칙 개선으로 처리. 비정형 사유·회신 대조의 실제 잔여 부담이 있어야 추가 AI 검토.
6. **평가·권익:** 실제 미충족 해소와 잘못된 분류의 정정을 함께 평가. 같은 건의 반복 알림을 신규 발생으로 세지 않고, 분모·분류가 달라진 부적격률 하락을 효과로 주장하지 않음.
7. **초기 범위:** 시내버스·택시·화물 중 한 업종·한 사유. 전세버스 신규발굴 제외와 위험등급·개인명단 판매·적발 건수 연동 수익모델 제외를 유지.
