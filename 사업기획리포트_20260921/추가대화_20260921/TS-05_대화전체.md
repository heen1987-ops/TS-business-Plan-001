# TS-05. 교통문화지수 실태조사·작성·공표

## 사업컨셉: 교통문화 조사결과를 검증하고, 지역의 안전문제를 이해하도록 돕는 지원서비스

## 3. 해결하려는 문제는 세 가지

아래는 기존 문제원장과 공개된 업무구조를 바탕으로 작성한 **검증 전 가설**입니다. 조사품질에 실제 문제가 있다고 확정한 내용은 아닙니다.

### ① 실제 행태 변화와 조사조건 변화를 구분하기 어려울 수 있음

전년과 올해 수치가 달라도, 비교하는 조사지점·시간·대상·조사항목 정의가 달라졌다면 해석에 추가 확인이 필요합니다.

**확인할 문제**

> 조사결과의 변화를 설명할 때, 실제 교통행태 변화와 조사조건 변경을 구분하기 위해 과거 자료와 현장기록을 반복적으로 대조해야 하는가?

원래 TS-05 문서도 **조사지점·시간·기준 변경과 실제 행태변화를 구분하는 어려움**을 핵심 가설로 설정했습니다. :chatgpt-content-reference{index="8"}

문제가 확인되더라도 결과를 임의로 보정해서 비교 가능한 것처럼 만들지는 않습니다. 비교조건이 다르면 **비교의 한계를 명시하거나 전문가가 승인한 분석을 별도로 수행**하는 방향입니다.

### ② 서로 다른 성격의 지표를 같은 의미로 해석할 수 있음

공식 조사에는 직접 관측한 행태, 설문으로 확인한 응답, 지자체 제출자료, 사고통계가 함께 사용됩니다. 예를 들어 방향지시등 점등은 관측조사이고, 일부 운전행태는 설문조사이며, 행정노력도는 지자체 제출자료를 사용합니다. :chatgpt-content-reference{index="9"}

**확인할 문제**

> 결과 이용자가 직접 관측한 행동, 응답자의 자기보고, 행정활동 기록, 사고결과를 구분해서 이해할 수 있는가?

이를 구분하지 못하면 ‘행정자료가 충실하다’는 것과 ‘현장에서 안전행동이 개선됐다’는 것을 혼동할 수 있다는 가설입니다.

| 자료 유형 | 확인한 내용을 설명할 때의 기준 |
|---|---|
| **관측자료** | 어느 장소·시간·대상에서 무엇을 관측했는지 설명 |
| **설문자료** | 누구에게 어떤 질문을 했으며, 응답이 무엇을 뜻하는지 설명 |
| **행정자료** | 어떤 활동·계획·집행을 어떤 근거로 확인했는지 설명 |
| **사고통계** | 대상·기간·노출조건을 확인하고 다른 지표와의 관계를 신중하게 해석 |

이 표는 공식 지표를 재설계하는 것이 아니라, **각 자료가 뒷받침할 수 있는 설명의 범위를 구분하기 위한 기획 기준**입니다.

### ③ 조사결과를 지역의 실제 확인사항으로 연결하기 어려울 수 있음

수치를 이해하는 것과 실제로 무엇을 추가 확인해야 하는지 아는 것은 다릅니다.

**확인할 문제**

> 지자체 담당자가 기존 결과자료와 컨설팅을 활용한 뒤에도, 특정 지표 변화가 지역의 어느 상황과 관련되는지 확인하기 위해 자료를 다시 수집하거나 질문을 반복하는가?

여기서는 지자체 단위 결과만으로 특정 교차로나 주민집단의 상태를 단정하지 않습니다. **지역 단위 지표를 특정 지점의 실시간 위험정보처럼 사용하는 것은 별도의 근거가 필요한 다른 과업**입니다.

### TS-05 통합 문제정의

> **교통문화 실태조사 결과를 검증·설명·활용하는 과정에서 원자료, 조사조건, 지표 정의, 수정이력의 연결이 충분하지 않아 비교 가능성과 변화의 의미를 반복 확인해야 하는 부담이 있는지 검증한다. 기존 품질개선 연구와 컨설팅으로 해결되지 않은 부분이 확인되면, 근거 있는 결과 설명과 추가 현장확인으로 연결하는 지원기능을 검토한다.**

## 4. 서비스는 어떻게 작동하는가

큰 흐름은 다음과 같습니다.

**조사자료·기준 확인 → 결과와 원자료 연결 → 비교조건 검토 → 전문가 확인 → 설명자료 제공 → 필요한 현장확인 연결**

이를 세 개의 독립사업으로 나누지 않고, **TS-05 하나의 사업 안에서 세 가지 구성요소**로 묶습니다.

| 구성요소 | 서비스가 지원할 내용 | 사용자가 확보하는 결과 |
|---|---|---|
| **① 조사결과의 근거 연결** | 지표를 해당 조사기록·항목 정의·집계조건·수정이력과 연결 | “이 수치가 어떻게 만들어졌는가”를 확인 |
| **② 변화와 비교조건 검토** | 연도·지역·항목 비교에서 조사조건 차이와 미확인 사항 제시 | “비교해도 되는 부분과 주의해야 할 부분”을 구분 |
| **③ 역할별 설명·활용지원** | TS 검토용, 지자체 협의용, 국민 공개용 자료를 구분해 작성 | 필요한 근거와 한계를 이해하고 다음 확인행동으로 연결 |

CCK의 활용 지점은 **자료를 찾고 연결하며 차이를 설명하는 반복작업**입니다. 표본설계·가중치·공식 산식·통계적 판단을 생성형 AI가 임의로 바꾸는 것은 제외합니다.

## 5. 대표 적용 예시: 횡단보도 신호 준수 관측결과가 달라진 경우

다음은 실제 지역의 결과가 아닌 **설명용 상황**입니다.

한 지자체에서 전년과 올해의 횡단보도 신호 준수 관측결과가 달라졌다고 가정합니다. 서비스가 곧바로 ‘교통문화가 악화됐다’고 결론내리는 것이 아니라 다음을 확인하도록 지원합니다.

| 단계 | 서비스 지원 | 담당자가 판단할 내용 |
|---|---|---|
| **같은 내용을 조사했는가** | 항목 정의·관측방법·집계조건의 변경 여부 대조 | 같은 개념을 측정한 결과인지 확인 |
| **비교조건이 같은가** | 조사지점·시간대·관측대상·표본규모 등 확보된 조건 비교 | 어느 범위에서 비교가 가능한지 판단 |
| **원자료와 공표결과가 일치하는가** | 원자료·집계표·확정본·설명자료의 수치와 버전 연결 | 오류인지, 정상 정정인지, 추가 확인인지 구분 |
| **현장에서 무엇을 더 봐야 하는가** | 결과만으로 설명되지 않는 질문 정리 | 현장조사·이용상황 확인 필요성 결정 |
| **국민에게 어떻게 설명할 것인가** | 확정된 사실과 해석 한계를 분리한 초안 작성 | 공개범위와 설명내용 최종 확인 |

경우에 따라 결론은 다를 수 있습니다.

**조사지점이나 시간대가 달라졌다면** 단순 전년 비교의 한계를 설명합니다.

**집계 과정의 오류라면** 공식 정정절차와 영향범위를 확인합니다.

**비교조건이 적절하고 변화가 확인됐다면** 그 원인을 알아내기 위한 추가 현장정보가 무엇인지 정리합니다.

이 과정에서 중요한 문장은 다음입니다.

> **“관측결과가 달라졌다”는 사실과 “왜 달라졌는가”라는 원인 판단은 구분한다.**

관측자료만으로 특정 시설개선이나 홍보활동의 효과를 확정하지 않습니다. 반대로 원인을 아직 모른다는 이유로 확인된 결과까지 숨기지도 않습니다.

### 초기 사업형태

**이미 수행한 통계품질 개선연구와 컨설팅 결과를 실제 조사·검토·설명 업무에 적용하는 지원모듈**로 시작하는 방향을 권고합니다.

| 추진안 | 제공범위 | 비용·기간의 성격 | 필요한 선행조건 |
|---|---|---|---|
| **A. 기존 기준·서식·설명자료 개선** | 항목 정의, 변경표, 표준 설명자료와 검토절차 보완 | 상대적으로 작음. 실제 수정범위 확인 후 기간 산정 | 현행 편람·연구결과·실제 질의사례 |
| **B. 조사근거 검증·해석지원 모듈** | 자료대사, 조건 비교, 근거 연결, 보완·정정 검토, 공개 설명지원 | 중간 수준의 연계·검증 필요. 제한 시범범위 확정 후 산정 | 원자료 접근, 승인된 규칙, 전문가 기준답안, 기존 시스템 연계 |

**B가 이번 CCK 사업컨셉의 중심이지만, A로 충분히 해결된다면 별도 AI 사업으로 만들지 않습니다.** C는 장기 연구개발로 검토할 수 있으나 이번 문서·데이터 검증 컨셉에 묶어 이미 가능한 기능처럼 제안하지 않습니다.

### 구매·확산 구조

초기 수요부서는 **TS 모빌리티연구처를 중심으로 확인**합니다. 기존 조사·시스템 운영계약 안에서 개선할지, 추가 모듈로 발주할지는 계약범위와 업무수요에 따라 판단합니다.

추가사업이 성립하면 CCK의 공급범위는 다음처럼 구성할 수 있습니다.

> **조사자료 구조화 → 지표·원자료·조건 연결 → 검증·정정 지원 → 역할별 설명자료 → 기존 시스템 연계·운영 검증**

다른 조사·평가업무로 확대할 때는 **문서대사·근거추적·변경관리 같은 공통기능을 재사용하고, 조사별 정의·산식·권한·전문검증을 별도로 구성**합니다. 기관 원자료나 비공개 통계자료가 CCK의 재판매 자산이 된다고 전제하지 않습니다.

현재 CCK 제안서에는 이미 보고서 생성, 메타데이터 관리, 권한·로그 등의 고도화가 포함되어 있습니다. 따라서 공통기능을 모두 신규개발로 다시 산정하지 않고, **교통문화 조사에 특화된 규칙·자료·연계·검증의 추가분**을 구분해야 합니다. :chatgpt-content-reference{index="18"}

### 첫 현업 확인질문

> **“최근 조사결과나 지자체 컨설팅에서 ‘지난해와 왜 달라졌는가’라는 질문에 답하기 위해 원자료·조사조건·수정이력을 다시 확인했던 사례가 있습니까? 기존 통계품질 개선연구를 반영한 뒤에도 어떤 부분이 남아 있습니까?”**

이 질문과 함께 처음 확보할 자료는 **현재 적용 중인 조사편람, 기존 품질개선 연구의 반영목록, 실제 정정·재조사·추가질의 사례, 컨설팅에서 반복되는 질문**입니다.

현재 공개자료로 확인한 것은 조사체계, 담당부서, 자료제출 기능, 관련 연구실적과 컨설팅 안내입니다. **실제 미해결 사례, 연구의 상세 성과, 시스템 내부 검증기능, 추가 구매수요는 아직 확인되지 않았으므로 신규사업성을 확정하지 않습니다.**

### TS-05 사업컨셉 핵심 문장

> **본 사업은 교통문화지수 실태조사의 원자료·항목 정의·조사조건·집계결과·수정이력을 연결하여, 조사결과의 검증과 비교·공개설명을 지원하는 것을 목적으로 한다. 실제 행태 변화와 조사조건 차이를 구분하고, 자료 유형별로 설명할 수 있는 범위와 추가 확인사항을 명확히 하여 TS·지자체·국민의 정보 활용을 돕는다. 기존 통계품질 개선연구와 자료제출·컨설팅 체계를 활용하되, 해당 체계로 해결되지 않는 근거 연결·검토·설명 부담이 확인된 범위만 추가 구축한다.**

**TS-05의 차별점은 ‘교통문화지수를 더 보기 좋게 발표하는 AI’가 아니라, ‘그 수치가 무엇을 말하고 무엇까지 말할 수 없는지 근거로 설명하는 AI’입니다.** 다음은 **TS-06 ‘교통안전관리자 자격시험·증명서 발급’**의 상위 사업컨셉입니다.
