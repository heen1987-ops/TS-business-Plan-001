# 처별 탐색·상세 본문 재구성 · 2026-10-07

## 사용자 문제와 변경 목적

- 처별 탐색이 드롭다운에 묻힌 문제. 좌측 조직 계통·처 클릭 목록 복원.
- 선택 처보다 기관·공통 설명이 먼저 보이는 문제. 선택 처 본문 우선 배치.
- 업무·자료·CCK 역할·완료조건이 연결되지 않는 문제. 기존 상세 자료의 개조식·필드별 전개.
- 공통플랫폼·ISP 전체 설명의 반복으로 긴 페이지 발생. 기본 접힘과 명시적 펼침 적용.

## 범위·가정

- 조사 대상 51개 조직, 계획서 연결 39개 처·42개 과제, 개별 계획 미작성 12개 조직.
- 현재 기획·조사 자료의 재구성. 실제 현업 피드백·제품 실행·사업 선정·구현효과 검증과 구분.
- 현행 source 원장·설문 질문·한글 원본·도식 자산 보존. 새 기관 업무·예산·개선율 임의 생성 제외.
- 기존 배포 승인에 따른 main·GitHub Pages 반영. GitHub main 이전 커밋으로 롤백 가능.

## 정보구조

- 좌측: 처·업무 검색 → 조직 계통 → 처 클릭 → 현재 처의 복수 과제 → 해당 처 상세 목차.
- 본문: 선택 처·현재 과제 → 목적·목표·수단 → 업무 범위 → 현재 확인·문제·근거 → 데이터 → 세부 실행 → 완료·개인정보 → 효과 측정 → 환경·추가 작업 → 현업 확인 질문 → 도식·한글 문서.
- 보존 상세: 법령·공식 처리·국내외 사례 / 이전 상세 설계·요구사항·RFP. 펼침형 보존과 기존 해시 직접 진입 지원.
- 공통 설명: 현업 의견, 플랫폼, ISP·대가, 현재 적용 범위, 기관 소개의 5개 접힌 장. 메뉴·직접 주소 이동 시 해당 장 자동 펼침.
- 본문 내부 고정 높이·페이지 분할 제외. 처 탐색 목록의 독립 스크롤만 사용.
