# GROWTH AI 통합 설계 공개 반영

2026-10-15 · 통합 설계 제안 v0.2

`src/growth-ai.cjs`를 구조화된 공개 원장으로 사용한다. 화면과 다운로드는 같은 원장에서 생성한다. 이 문서는 구현·검수 범위 기록이며 공개 설계 본문을 복제하지 않는다.

## 범위

- GROWTH AI 공통 제품 계층, 조직·직무·권한 온톨로지, TS/병원 업무 비교, H01~H05, 신규 GAI-R01~R12와 GAI-T01~T12를 연결한다.
- TS W27-A~D의 주관·범위·스킬·추가개발·제외·검수·발주조건·일정·C27-COM은 기존 `annual-work-2027.cjs`에서 참조한다. 별도 최신판을 수작업으로 만들지 않는다.
- 정적 공개 조직자료와 개인 공식 ID·권한 원장을 구분한다. 실제 조직형 엔진·ETL·API·기관 데이터 접근·권한·성능·검수 완료를 주장하지 않는다.
- 병원 초기 범위는 H01~H04 운영·행정 지원 제안이다. 대상 기관과 데이터는 미확정이며 H05 임상 연계는 별도 검토다.
- 내부 대화·Slack 내용과 링크, 개인 식별정보, 내부 단가·총액은 공개 모델에 포함하지 않는다. 공개 저장소의 자료와 신규 설계 제안을 구분한다.
- 1차 사업은 조직·직무 기반 사용자 인식과 업무 맥락 자동 분류다. 사용자 4대 요구→부처/기관 관계→TS 공식 부서·직무·업무 후보→GAI 개발·검수를 연결한다. 부처·기관 관계가 접근권한을 상속하지 않는다.
- 공통 스킬 정본은 CCK-Public-basic의 CCK-GROWTH-Skills 0.1.0이다. 고정 커밋 b6dc23772d3847bcb9ef2ebe7927fb3a3e2dd5c0에서 5개 스킬과 공통 파일을 설치하고 해시와 적용 메타데이터를 검증했다.

## 데이터 계약

`module.exports`는 `layers`, `boundaries`, `common`, `ontology`, `domains`, `hospital`, `requirements`, `tests`, `scenario`, `tsBundles`, `timeline`, `cost`, `legacyTests`, `deliveryStages`, `responsibilities`, `deliverables`, `sections`, `sources`, `toMarkdown()`를 제공한다. 요구/시험 ID는 각 12개이며 1:1 대응한다. 모든 임계치는 협의용 기준으로 유지한다.

## 검증과 완료 조건

원장 ID·참조 무결성, 기존 W27 원장과의 동일성, 공개본문/JSON의 일치, 비밀·개인경로·내부자료 미포함을 검사한다. 전체 npm test(빌드와 기존 회귀·신규 무결성 검사)를 통과했다. 로컬 브라우저에서 13개 절·내부 앵커·공식 부서 근거 펼침·5개 공통 스킬·직무 선택을 확인했고, 데스크톱 1280 및 모바일 390 너비에서 가로 넘침과 콘솔 오류가 없었다. 기관 시스템·실제 AI·권한 엔진 실증은 수행하지 않았다. 공개 배포 결과는 이 기능의 GitHub Actions와 version.json에서 커밋을 대조한다.

롤백은 이 기능의 변경 커밋을 역변경하고 기존 검증·배포 경로를 따른다. 원천 기관 데이터나 운영 시스템을 변경하는 기능은 없다.


신규 growth-ai.html 경로 1개로 React 경로 수는 73→74, 탐색 상세 레코드는 325→326이다. 기존 검사 수를 이에 맞춰 갱신했고 기존 기준을 삭제하거나 완화하지 않았다. 내려받기는 통합 MD/JSON, 요구·시험 CSV, 기존 스킬 MD/JSON, 공통 스킬 적용 JSON 6종이다.
