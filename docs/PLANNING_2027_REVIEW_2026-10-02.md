## 입력과 해석

사용자의 기획기간 정정을 적용하여 2027년 후속사업으로 범위 고정. 2026–2030년 TS 공식 전략은 배경 근거로 연결. NPU·5개년 하드웨어 계획을 이번 사업의 비용·개발범위·착수조건으로 사용하지 않음.

「사이트 분석」 최신 5개 대화 흐름을 조회하여 외부 문제, TS 책임, 현재 대응 이후 잔여문제, 비AI 대안, NOA 추가가치의 선별 순서 확인. 완료된 심층리서치 보고서·첨부 원문은 이번 조회에 없음. 조사 착수 안내를 새로운 문제의 증거로 사용하지 않음.

현재 후보의 공식 업무 접점과 실제 문제의 입증 상태를 구분. 6개 후보는 필요한 사례·기록을 확보하기 전 보류이며 검증된 신규사업으로 승격하지 않음. 13처와 DRT의 기존 검토·조건부 판단 보존. 3개 모듈은 공통 기능 재사용 구분이며 신규 문제의 탐색영역을 제한하지 않음.

## 변경과 수용기준

- `planning-2027.cjs`: 대상연도·범위·선별 관문·판단·문서 추적·후보별 필요 근거의 정본.
- `AnalysisReview.jsx`: 기존 6장 연속 읽기와 링크 유지, 2027년 범위 및 판단 추가.
- 자료실·왼쪽 메뉴·브라우저 탭의 2027년 기획 표시.
- 기존 검토서 및 신규 MD/JSON에 같은 범위·판단 출력.
- 공식 근거 확인일 2026-10-01과 이번 편집일 2026-10-02 구분.
- 총사업비·인월·기준선·목표값 미산정 상태 보존.
- 기존 한글 보존본 117개 유지, 새 HWPX 판본 작성으로 표시하지 않음.

## 배포와 복구

기존 사용자 승인에 따라 main 푸시 후 GitHub Actions/Pages 경로 사용. 공개 `version.json`의 커밋과 신규 JSON/MD·본문을 배포 후 대조. 소스 변경의 되돌리기로 복구 가능하며, 이전 문서·조사 원장·이미지·HWPX의 삭제·이력 재작성 없음.
