# 한글파일 공개 연결 보강 · 2026-10-02

## 문제와 확인 결과

- 사용자 요구: PC 파일 경로 대신 GitHub에 실제 한글파일을 포함하고 사이트의 개별 다운로드로 연결
- 기존 상태: 39개 처·117개 HWPX가 로컬 Git과 GitHub main에 등록되어 있고 Pages에도 게시된 상태
- 발견한 탐색 문제: `research-library.html?view=planning`의 내려받기에는 MD·JSON만 연결되어 있어 해당 검토 내용과 처별 한글파일 사이의 진입점 부족
- 적용 범위: 검토서·한글 자료실·저장소 README·GitHub 개별 파일 목록 및 다운로드 검증
- 문서 범위: 기존 HWPX 본문·판본·해시 보존. 최신 2027년 웹 검토를 한글 신규 판본으로 작성한 것으로 표시하지 않음

## 검증

- `npm ci`, `npm test`: 빌드·전체 기존 검사 통과. 한글파일 검사 18,889개, 파일 117개, 총 432,693,587바이트
- 다운로드 연결 브라우저 검사: 216개 통과. 실제 사용자 클릭 다운로드 3종·파일명·SHA-256 일치, GitHub 원본 링크 117개 대조
- 기존 한글 자료실 브라우저 회귀검사: 297개 통과. 39개 처·검색·초기화·개별 제안·앵커·키보드·모바일 확인
- 기존 사업기획 검토 브라우저 회귀검사: 200개 통과. 6개 장·13처·문제정의·범위·내려받기 보존
- 공개 HTTP 확인: Pages 117개 파일 전수 수신·SHA-256 일치. GitHub 원본 대표 3개도 SHA-256 일치
- 첫 HTTP 전수검사에서 1개 응답의 60초 시간 초과 발생. 실패 기록 후 최대 2회 네트워크 재시도와 시도 이력 기록 추가. 재검사는 117개 모두 첫 시도 통과. HTTP 오류·해시 불일치를 통과로 바꾸지 않음
- HTTP 압축 전송의 `Content-Length`와 실제 HWPX 크기는 다를 수 있어, 수신·해제한 본문의 길이와 SHA-256으로 검증
- 데스크톱 1600px·모바일 390px 화면 캡처 확인. 표는 좁은 화면에서 영역 내부 가로 스크롤, 본문은 세로 연속 열람
- 공개 URL에서 동일 브라우저 검사와 `version.json`을 배포 후 다시 확인

## 보안·운영·잔여사항

- 새로운 개인정보·자격증명·금액·외부 API 연계 추가 없음. GitHub 외부 링크는 새 창의 `noopener noreferrer` 적용
- 기존 한글파일 내 936개 텍스트 부분의 개인 PC 경로·비밀키 패턴 검사 유지
- 기능·접근성·문서 연결 자체 검토: 통과. 실제 사용자의 다운로드 환경 전체 또는 한컴오피스 본문 렌더링 시험을 대신하지 않음
- 롤백: 이번 링크/UI 커밋 되돌리기 후 기존 Actions 재배포. HWPX 파일 자체는 변경하지 않았으므로 이전 파일 유지
- 이후 한글 본문을 개정할 때 새 판본으로 누적하고 정본 목록·다운로드 인덱스·해시 동시 갱신
