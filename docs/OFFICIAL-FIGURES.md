## 원문 시각 확인

웹 도표는 원본 DOM과 CSS를 변경하지 않고 실제 TS 사이트를 1520×1200, DPR2로 표시하여 해당 요소만 캡처. PDF는 Poppler 300dpi 렌더링으로 도표 영역만 발췌. 글자·연도·색상·관계 재작성 없음. 17·18쪽 전체 렌더와 발췌본을 대조하여 도표 누락 없음 확인. 행사사진·금액표 제외. Poppler의 불가리아어·그리스어·태국어 nameToUnicode 경로 경고가 있었으나 한글 임베디드 글꼴의 시각 출력 정상 확인.

## 판본 해석

보고서명은 2025이나 인쇄16쪽 도표 표제는 2026년. 해당 그림 안 경영목표는 2029로 표기되어 있으므로 홈페이지 2026–2030 체계와 임의 통일하지 않음. ESG 추진체계는 해당 영역의 책임 구조이며 공단 전체 조직도·최신 전결표로 확대하지 않음. 기관 전체 AI 로드맵 원본 도표는 이번 확인에서 미확보. 임의 생성 도표로 대체하지 않음.
