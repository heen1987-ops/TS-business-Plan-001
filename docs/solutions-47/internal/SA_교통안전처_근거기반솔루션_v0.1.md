# 교통안전처 근거기반 솔루션

> 작성 기준: 2026-09-24~25 조사. 법령은 국가법령정보센터 현행본(법 2024-08-17, 시행령·시행규칙 2026-09-15, 지침 2026-07-08) 직접 대조. 로컬 CSV 2종 직접 집계. 외부 기관 접촉·로그인·파일 내려받기 없음.

## 0. 한 장 요약

**판정: 수정.** 목표(조치 뒤 실제 해소·재발방지)는 유지. 범위를 교통수단안전점검(법 제33조⑥, TS 위탁) 지적사항으로 한정하고, 기능 축을 "AI의 원인·조치 재계획"에서 "지적-조치-종결-후속결과의 연결과 재발 관측"으로 전환. 기준선 확보 단계(Phase 0)를 선행하고 그 결과로 계속·보류 결정.

- 판정 이유
  - 문서 종결 구조는 법령·지침 원문으로 입증(SA-E01·E03·E06·E32·E53). 반면 실제 미해소율·재지적률은 공개자료 어디에도 없어 문제 규모는 미입증(SA-E51).
  - 교통안전관리규정 이행 확인 평가는 TS가 2025-12 AI 특화 서비스를 이미 도입(SA-E37), 운수안전지도 검토 15→2분도 기운영(SA-E38) → 문서 검토 효율화는 증분 없음.
  - COSAS 2026 고도화(4.18억)의 요구사항 5건은 운전자 AI 모델·보고서·위험도 예측이며 지적-조치-해소 관리는 없음(SA-E23) → 이 공백이 유일한 증분 후보.

- 반대 증거: TS 발표 "점검업체 사망 173→38건(-78%)"(SA-E35), "컨설팅 사고율 54.7% 감소"(SA-E18). 단 사고 발생으로 선정된 집단의 전후 비교라 평균회귀와 구분 불가(SA-E52).
- 솔루션 한 줄: **TMACS 점검·조치 기록을 지적 단위 원장으로 묶고, 조치 증거가 지적 유형에 맞는지 점검을 보조하며, 종결 후 12개월 사고·운행기록 신호로 재발을 관측해 담당자의 종결·재확인 결정을 돕는 기능.** 규칙 기반(SI)이 기본, AI는 비정형 조치결과서 해석과 과거 기록 소급 코드화에 한정.
- 사람이 결정하는 지점: 종결·보완요청·현장 재확인(TS 점검책임자), 개선권고·시정지시·처분(지방국토관리청·시도·시군구), 지적 유형별 허용 증거 규칙표 승인(교통안전처).
- 기준선 확보 경로: TMACS 2021~2025 점검결과·조치결과 전수(대략 2천 개사, 지적 2~3천 건 규모 추정) → M1~M6 산출. data.go.kr 「교통수단 안전점검 정보」(로그인 필요) 보조.
- 사용자 결정 필요
  1. 대표 범위를 교통수단안전점검 지적사항으로 한정하고 SA27-01(관리규정 작동성)을 보류할지
  2. TS 교통안전처·데이터융복합처에 TMACS 점검 기록 구조와 기존 AI 특화 서비스 기능 폭 확인(외부 접촉, 승인 필요)
  3. 로그인 필요 공공데이터(15072419)와 10MB 초과 연차보고서 PDF 내려받기 승인
  4. Phase 0 결과에 따른 보류 조건(§5.3)을 사전 합의할지

### 2.2 정성·구조
- 종결 구조: 조치 확인 수단이 조치결과서와 TMACS 입력이며 결과 확인은 재량(SA-E06·E32). 실제 해소를 별도로 관측하는 절차는 법령·지침에 없음(SA-E53, 추론).
- 제재 공백: 교통수단안전점검의 개선권고 불이행은 과태료 대상 아님. 과태료는 규정 미준수·점검 거부·거짓보고에 한정(SA-E03).
- 관측 창: 재점검은 사고 재발 조건부, 규정평가 5년, 규정평가 받은 해 점검 간주, 우수사업자 점검 면제(SA-E05·E10·E12·E33).
- TS 자기진단: "고위험군 집중관리 대상 외 운수社 사망자 증가", "DRT 및 중·소형 사고다발 회사 관리제외"(SA-E19·E21).
- 인접 영역(전세버스 공시) 인터뷰: 허위 사진 제출 사례, 제재는 0점 처리뿐, 현장점검 장기간 미시행 발언(내부자료·STT 요약, SA-E28).
- 업체명 변경(양도·폐업 후 재등록) 시 이력 단절(내부자료, SA-E29) → 재발 추적의 식별 문제.

### 2.3 반대 증거와 한계
- 기관 발표 사고 감소 수치는 점검·컨설팅의 효과를 지지하는 방향. 단 선정 편향으로 효과 크기 판단 불가(SA-E35·E18·E52).
- 국정감사·감사원의 "점검 형식화" 지적은 이번 조사에서 미발견. 2024 국감 이슈분석은 DRM으로 본문 미열람(SA-E49).
- 국민신문고 374건 중 관련 민원 0건(SA-E43). B2G 업무라 국민 체감 신호가 약한 영역.
- 결론: 문제의 **구조**는 입증, **규모**(미해소·재발 비율)는 미입증. 규모 입증이 Phase 0의 목적.

## 5. 솔루션 설계

### 5.1 구성과 단계
- 명칭: **점검 지적사항 폐루프 관리 — 조치 증거 적합성 점검과 재발 관측**
- Phase 0(선행, 기준선·권한): TMACS 과거 기록으로 M1~M6 산출, 데이터 권한 경로(DF) 확정, 기존 AI 기능 폭 확인. 결과로 계속·보류 결정.
- Phase 1(파일럿): 1개 지역본부·1개 업종(버스 또는 일반화물), 1년 점검분. B(SI·규칙)와 C(B+AI) 비교.
- CCK 구성요소: aRDa(점검·조치 기록 판본·업체 식별 정합), 폴리스(법·영·지침 조문 근거 연결), NOA(증거 불일치 질의·재발 신호 설명 초안). 로컬 LLM·기존 서버, 신규 인프라 0원 전제.

### 5.3 계속·보류 조건(Phase 0 후)
- 보류: TMACS·COSAS가 지적 단위 확인방식·종결 후 관측 기능을 이미 보유한 경우
- 보류: 현장·데이터 확인 종결 비율이 높고 재지적이 드문 경우. 판단 기준치는 Phase 0 전에 교통안전처와 합의(임의 수치 금지)
- 보류: DF 데이터 권한 경로 불가 또는 개인정보 목적 외 결합 판단
- 축소: B(SI·규칙)만으로 F2 정합 검토가 충분하면 AI 범위 제거

## 9. 리스크·반증·한계
- AI기본법: 고영향 AI 영역에 "교통수단·시설·체계의 주요 작동·운영"(아목)과 "국가기관등의 국민 영향 의사결정"(자목) 포함(SA-E54). 재확인 대상 선정·종결 판단 보조가 자목 해당 가능성 → 법률 검토 전까지 고영향 준용(설명 제공, 사람 최종결정, 판단 근거 기록, 이의·정정 경로).
- 법적 권한: TS는 위탁 점검 수행 기관, 권고·처분 권한 없음(SA-E08·E09). 현장 재확인 확대는 지침 "확인할 수 있다" 범위의 운영 선택이며 강제 근거 아님(SA-E32). 운송안전감독관 입법은 공개자료로 미확인(SA-E50).
- 개인정보·목적 외 이용: DTG·종사자 정보 결합은 업체 단위 집계·가명처리 원칙, ETAS 위탁 목적 범위 검토 필요.
- 조직: 3주체 분산, 데이터는 DF, 현장 인력은 지역본부. 재확인 증가가 현장 부담으로 전가될 위험(M6로 관측).
- 중복: 관리규정 평가 AI(SA-E37), 운수안전지도 검토(SA-E38), 운수지도지원 AI(SA-E24), COSAS 2026 운전자 AI 보고서(SA-E23). 공개자료로 기능 폭이 불명확한 SA-E37이 수단점검 조치결과 검토까지 포함하면 F2는 **증분 없음**으로 보류.
- 반증 가능성: M3 높고 M4 낮으면 문제 규모 미미 → 보류. H6이 우세하면 컨셉의 사망자 감소 기여는 제한적.
- 측정 한계: 재점검 표본의 선택 편향, 사고의 다요인성, 도로등급 판본 변동.
- 증거 한계: 국감·감사원 지적 미발견, 지적·조치 통계 부재, 내부 회의록(SA-E28·E29)은 STT 요약.
