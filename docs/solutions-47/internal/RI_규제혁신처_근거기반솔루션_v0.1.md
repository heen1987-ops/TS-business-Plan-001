# 규제혁신처 근거기반 솔루션

## 0. 한 장 요약

- **판정: 재설계(기존 AI 기능 대조 전제).** '조건 이행' 축은 유지. 대표 병목은 '운영 변경의 조건 영향'에서 **'승인→사업개시 전환 지연'과 '조건 원문·판본의 비정형·불일치'**로 교체 필요
  - 이유 1: 공개 게시판 전수 집계상 승인→개시 중앙값 169일, 1~7차 승인 79건 중 180일 내 개시 31.6%, 공지 기준 미개시 43/95(RIS-15·16·65)
  - 이유 2: 공고상 실증기간이 '사업개시일부터 24개월'로 기산 → 개시 기한이 공고에 없음(RIS-66). 범정부 샌드박스는 이미 '사업개시 6개월 이상 지연 시 부가조건 재검토'를 도입(RIS-37)
  - 이유 3: 현 컨셉의 대표 시나리오(운영구역 확대 → 변경 확인)는 공개 자료에서 사례 0건 관찰, 법·영에 변경 절차 조문 없음(RIS-22·40)
  - 이유 4: 법적 관리·감독 권한은 국토부·관계기관 공무원(영 §10①). TS 위탁은 접수·통보·발급(영 §21) → 도구 출력은 '확인 필요 목록·기한 경보'까지(RIS-07·08·39)
- **입증된 문제 3개**

| 1 | 승인 후 개시까지 장기 소요 | n=51 중앙값 169일·Q3 259일, 1~7차 코호트 180일 내 개시 31.6%(25/79) | RIS-15·65 |
| 2 | 장기 미개시 승인과제 누적 | 공개 개시 공지 없는 승인 43/95, 그중 승인 후 1년 초과 23건 | RIS-16 |

- **솔루션 한 줄**: 확인서·위원회 의결 조건·이용자 고지를 판본별 '조건 카드'로 구조화하고, 보험·개시·결과보고·연장 **법정 기한**과 **개시 지연 신호(90/180일)**를 사건별로 추적해 규제혁신처 담당자에게 확인 과업을 제안하는 내부 업무 보조
- **사람이 결정하는 지점**: 조건 충족·위반 판단과 시정명령·취소·과태료(국토부장관), 조건 재검토·변경 심의(모빌리티혁신위원회), 기업 안내·보완요청 발송과 게시물 정정(규제혁신처 담당자)
- **기준선 확보 경로**: ① 공개 기준선 실측 완료(RIS-15·16·17·65) ② 내부 대장(신청·관리 시스템)의 의결일·확인서 발급일·보험증명 접수일·개시확인서 접수일·결과 접수일 추출로 공지 누락 보정 ③ 확인서 원본 조건 전수 목록화 후 '증빙 접수 여부' 표본 점검
- **사용자 결정 필요사항**
  1. 기존 '생성형 AI 활용 규제샌드박스'('25 시범구축→'26 고도화)의 계약·기능 목록 확인 전까지 본 컨셉을 '조건부 재설계'로 둘지(RIS-27·41·58·62)
  2. 대표 시나리오를 '승인 후 180일 미개시 → 사유 확인 과업'으로 교체하고 '변경영향'을 확장 후보로 내릴지
  3. 공개 게시판 집계(기준일 2026-09-24)를 사이트 '공개 기준선'으로 게시할지(공지 누락 가능성 단서 필수)

### 2.2 정성 사례
- 조건 유형 이질성: 기술기준(휘도·광도, RIS-21), 운영 제약(대수 한정·배회영업 금지), 기한부 의무(개시 후 1년 내 성과 보고, 종료 전 허가 취득)(RIS-19). 기한부 의무는 개시일 기준으로 기한 변동
- TS 다른 시스템이 증빙원: 택시 임시운전 특례 조건에 'TS 운수종사자 관리시스템 등록·임시자격 증명 게시'(RIS-20)
- 이용자 고지 서식이 '사후관리 지침 [별지 제2호서식]' → 내부 지침 존재, 본문 비공개(RIS-20·61)
- 보험 가입은 개시 전 의무, 보험료 지원은 개시 후 신청 → 영세 사업자의 개시 전 자금 부담 구조(RIS-10·43, 추론)

### 2.3 반대 증거·해석 제한
- TS 성과는 개선 추세(개시건수 133.3%↑, 개시기간 2.9%↓, 승인~개시 약 109일 단축 주장)(RIS-25·46) → 악화 증거 없음
- 공지 미게시 ≠ 미개시. 2025-11-20·25 일괄 게시 흔적, 8차는 관찰 4.5개월(RIS-16)
- 개시 지연 원인(조건·자금·차량 확보·보험 인수·지자체 협의) 공개 자료로 분해 불가
- '변경' 사례 0건 관찰은 공개 경로 부재 탓일 수 있음(발생 0 아님)
- 조건 불이행에 따른 시정명령·취소·과태료 사례 미발견(RIS-59). 0건 관찰 ≠ 위반 0
- 국정감사·감사원 지적 미발견(RIS-60). 감사 지적이 없다는 것이 문제 부재를 뜻하지 않음

## 9. 리스크·반증·한계
- 법적 권한: 조건 준수 판단·시정·취소는 국토부 권한(RIS-07). 출력 문구에 '위반·부적합' 판정 금지, '확인 필요'로 한정
- AI기본법: 행정처분에 직접 쓰이지 않는 내부 보조로 설계 시 고영향 AI 가능성 낮음(추론). 처분 근거로 쓰면 재검토
- 개인정보·영업비밀: 고지에 관리책임자 개인 연락처, 사업실시계획서 영업정보 → 내부망·로컬 LLM, 게시물 재가공 시 개인정보 제거
- 중복: 기존 생성형 AI의 '26 고도화 범위가 사후관리까지면 축소·보류(RIS-58·62)
- 데이터 대표성: 공개 게시판 공지 누락·일괄 게시 → 내부 대장 대조 전 '기준선 후보'
- 수요 불확실: 지연의 주원인이 자금·차량 등 조건 외 요인이면 F3 효과 제한 → 사유 분류를 먼저 표본 조사
- 조직: 관리·감독 주체(국토부)와 도구 사용자(TS)가 달라 경보의 후속 조치 경로 합의 필요
