# 데이터융복합처 근거기반 솔루션

## 0. 한 장 요약

- **판정: 수정.** "분석 결과를 예방조치로 잇는다"는 방향은 증거로 지지됨. 다만 현 컨셉의 중심인 "해석·경쟁가설·노출량 보정"은 이미 운영 중인 eTAS(100km당 비교)와 2026 계약(ETAS 3.95억·COSAS 4.18억)이 대부분 덮고 있어 증분이 약함. 증분을 "법이 허용한 조치유형별 인계·이행 확인·후속 관측의 사건 관리"와 "미제출·장치불량 자료공백의 신호화"로 좁혀야 함 [DF-C02][DF-C06][DF-W05][DF-I06]
- **입증된 문제 3개**
  - **신호 모집단의 절반 이상이 비어 있음.** 운행기록 제출률 2019 38%·2020 43%·2021 44%, 택시 35.5%·화물 32.3% [DF-W01]. 화물 주기제출 의무는 25톤 이상·견인형 10톤 이상만 [DF-L02]. 2026년에도 USB 수동제출·장치 전원불량·기초정보 미입력 대응이 진행 중 [DF-D04][DF-W03]
  - **분석 결과가 조치권자에게 가는 길이 오프라인·분산.** 지자체·유관기관 제공이 "현재 오프라인"이라 2026 과업으로 온라인 연계 구축 중 [DF-C03]. 분석결과로 할 수 있는 조치는 법 제55조④의 4개 유형뿐이고, 조치권자는 DF 밖(교통안전처·지자체·경찰) [DF-L01][DF-L05][DF-X01]. TS 스스로 "현장 활용 관점 보완 과제 발굴 필요"를 이유로 활용 실태 진단 연구를 발주 [DF-C11]
  - **결과 지표 악화.** 2025년 사업용 사망자 390명(10월말), 전년比 25명 증가·목표대비 68.2% [DF-P01]. 고속도로 화물차 사망 71→89→93명(2023→2025) [DF-W02]. 고위험군 집중관리 밖 운수사 사망 증가 [DF-P04]
- **반대 증거**: TS는 고·중위험 컨설팅으로 사고율 54.7% 감소를 주장(분모·대조군 미기재) [DF-P03]. COSAS는 이미 "지자체 협업 업무의 진행상황 모니터링" 채널을 제공 [DF-W07]
- **솔루션 한 줄**: ETAS 고위험 목록·COSAS AI 안전보고서·미제출 목록을 입력으로, 조치유형(법 제55조④·규칙 제30조⑤)별 인계 사건을 만들고 조치권자의 수신·시행·4주/12주 후속 관측을 하나의 원장으로 닫는 "신호-조치 연결 원장". 새 위험모델·새 보고서 생성은 만들지 않음
- **사람이 결정하는 지점**: 인계 여부와 조치유형(DF 분석담당), 조치 채택·시행(교통안전처·지역본부·지자체·운수회사), 종결·재개(DF), 효과 판정(독립 검토자)
- **기준선 확보 경로**: ①19021 "운행기록 활용방안 연구"(2026년 말 종료 예정)의 활용 실태 진단 결과 재사용 [DF-C11] ②공공데이터 "운행기록 제출집계 및 통계자료" CSV로 2022년 이후 제출률 복원(내려받기 사용자 승인 필요) [DF-W09] ③2025년 고위험 운수사 표본의 조치 기록 역추적
- **사용자 결정 필요**: ①착수 시점을 19021 결과 이후로 둘지 ②COSAS 진행상황 모니터링 기능의 실제 범위를 TS에 확인하는 질문 발송 여부(외부 발송은 별도 승인) ③제출집계 CSV 내려받기 승인 ④K-패스(DF 업무의 약 3분의 1 추정)를 별도 컨셉으로 분리할지 [DF-X05]

### 2.2 로컬 데이터 직접 집계

- **Trip 샘플(2018-07-10, 100 trip, 3개사·80대)**: 11종 이벤트 3,249건 중 급진로변경 38.1%·급좌회전 24.6%·급우회전 10.9%·급가속 9.0%·과속 2.7%·장기과속 0 [DF-D05]
  - 계산: 각 이벤트 컬럼 합 ÷ 11종 합계. 거리 단위는 파일에 미표기
  - 고속버스 연구의 지배 유형(급가속 61.3%)과 다름 → 업종·임계값별 해석 필요 [DF-N02][DF-D01]
- **노출량 보정 효과(직접 계산)**: 차량 80대의 원건수 순위와 100거리단위당 순위의 스피어만 ρ=0.95, 상위 5대 중 4대 일치. 반면 거리 17단위 차량 1대가 100단위당 847건으로 비율 1위 [DF-D06]
  - 함의: 이 표본에서는 "노출량 미보정이 순위를 크게 뒤집는다"는 현 컨셉 가설의 증거 약함. 오히려 **짧은 노출에서 비율이 폭증**하는 문제가 확인 → 최소 노출 기준(TS 이벤트의 500km 기준 등)이 필요 [DF-D04]
  - 한계: 1일·100건·단일 업종 편중 샘플. 모집단 추론 불가
- **TS 자동차 교통사고 통계(사망사고 42,602건, 2012~2022)**: 사망자 5,392명(2012)→2,735명(2022). 법규위반 "안전운전 의무 불이행" 69.5%. 사업용·차종 컬럼 없음 [DF-D07]

## 5. 솔루션 설계 — 신호-조치 연결 원장

- **비AI 대안(B안)**: 조치유형 규칙표 + 상태관리 테이블 + 기한 알림으로 F1·F2·F4·F5 상당 부분 구현 가능
- **AI 증분(C안)**: 조문 근거 대조(F3), 인계문·재개 사유 초안(F4·F5), 교육기록·점검결과서 등 비정형 증거 문서의 항목 대조(F5), 미연결 사유 텍스트 분류(F7)
- **판단**: 가치의 대부분은 절차·SI에서 나옴. AI는 보조 증분이며 B 대비 C 추가효과는 별도 측정 대상
