# 조직 네이티브 업무 시나리오·전략 모듈·DRT 설계

기준일: 2026-10-20. 홈페이지의 설계·시나리오 확장 기록. TS 운영 시스템 구현·기관 검수·AI 실측 결과와 별도.

## 변경 범위

- 제공 직제시행세칙(2026-06-30) 57개 업무분장 유형에 대표 업무 시나리오 각 1건 연결. 132개 조직별 적용 경로, 8개 처리단계, 5개 자료 상태, 3개 검수 설계 연결.
- 227개 조직 색인 중 나머지 95개는 상위 조직 또는 별도 세칙·설치 근거 대상. 자동차안전연구원 등의 사무를 임의 추가하지 않음. 전체 4,484개 원문 업무 항목은 기존 조직·직무 원장 연결 유지.
- 기관·부서·업무건의 목적·역할·규범 → 목표·계획·질문 → 협업·승인 → 원천 실행·완료 증거의 6개 실행 모듈 설계. 기존 A01~A07, ON-W01~06, GAI 요구·시험에 연결. 별도 공통 사업비로 중복 계상하지 않음.
- 12대 전략별 입력·판단·사용 도구·산출물·완료조건·CCK 재사용 후보·추가 검수 연결. 기존 우선순위 및 AX27 요구·시험 ID 유지.
- DRT는 한 지역·한 서비스의 신규 예약 상담 지원으로 1차 실증 범위 설정. 지역 정책·정정 발화·누락 질문·상담원 확인·기존 예약·결과 대사의 5개 적용 모듈과 6개 검수 설계.
- 지역소멸·초고령화 필요성과 주민 접근성·현장 업무·지역 운영·생활권 효과를 구분. 실측 절감률·확정 사업예산·인구 증가 효과로 표현하지 않음.
- 조직·직무 → 부서 시나리오, 전략 모듈 → 관련 시나리오, ST-04 → ST-08 DRT 설계의 동일 본문 탐색. 검색·조직범위·전략 필터, URL workOrg, 새로고침·뒤로가기 연결.

## 구현·검증 방법

원장 CJS → React 본문/Markdown/JSON/CSV 동시 생성 → 정적 참조·직제 원문 대조 → Edge 화면·상태·내려받기 검사 → 기존 CI/Pages 배포 경로.

- `npm ci`, `npm test`: 전체 빌드와 기존 검사 유지; 3건 검사에서 57건·132조직 전수 검사로 확대.
- `check-ts-org-scenarios-browser.cjs`: 57개 시나리오·456개 단계·132개 조직 선택, URL·새로고침·검색·좌측 메뉴·조직 화면 왕복·다운로드·모바일 대표 유형.
- `check-ts-org-modules-browser.cjs`: 6개 실행 모듈·12개 전략·DRT 단일 노출·공식 근거·내려받기·모바일·좌측 메뉴 유지.
- `check-org-native-literature-browser.cjs`, `check-ts-ax-portfolio-browser.cjs`: 기존 문헌·전략·사례 탐색 회귀.
- MR-02 설계 다운로드 2종은 기존 원장의 요청 유형·시간 정밀도·불명 상태 측정 정의를 빌드 과정에서 동기화. 새로운 실측값 추가 없음.

검증 로그·화면 캡처·공개 배포 버전은 실행 완료 폴더의 기록으로 보존. 기관 연계/API/실제 직원자료/AI 추론/업무 수락 시험은 수행 범위 밖.

- `ts-org-scenario-profiles.cjs`: 실제 업무별 자료·협의·판단·완료 설계 입력. 0 기반 원문 문장 좌표 보존.
