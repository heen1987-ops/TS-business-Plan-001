## 내용 연결 범위와 가정

- 39처·42기획항목·117개 현재 HWPX 연결 보존
- 대표 13처 상세안·추가 28기획 프로필·DRT 1개 전용 설계에서 업무 설명 연결
- DRT는 수동 접수·배차·운영계획 문제를 중심으로 연결. 앱미터 검정 업무 설명과 분리.
- 업무별 128개 기존 측정 산식과 공통 5개 효과 측정방법 표시. 기준선·목표·가격·효과 달성은 미확정 유지.
- 개별 출처는 기존 조사 원장의 연결. 전체 원문 신규 열람·현행 법령 재검증 결과로 승격하지 않음.
- 공식 조직 대조 51처와 작성 39처·추가 자료 필요 KATRI 12처 구분. 전국 지역 조직 모집단 확정과 구분.
- 기관 전략은 배경 자료로 유지. 2027년 계획에 NPU 도입·5개년 인프라 구매 범위를 추가하지 않음.
- 기존 플랫폼·로컬 LLM·기존 서버·신규 인프라 0원·비전 제외·CCK 주관 조건 보존
- HWPX 본문·판본·파일 경로 수정 없음. 현재 계획 v0.5_r01, 대가·도식 v0.3_r01 및 계획 이력 v0.4_r01 유지.

## 검증 방법

1. `npm test`: 빌드·32개 정적 검사, 73경로·내부 링크·156 HWPX 무결성·미확정 상태 검사
2. `npm run check:feedback-browser`: 최신 검색·정확한 목적지·ID 연결·URL 이력·필터 충돌·빈 상태·업무별 설명/산식·출처 주의사항·반응형 검사
3. `npm run check:planning-hub-browser`, `check:ux-browser`, `check:isp-browser`: 기존 핵심 탐색·한글 다운로드·ISP 본문 회귀검사
4. 읽기 전용 독립 검토: 내용/근거·업무 흐름·탐색의 세 관점. 내부 검토 결과를 현업 수락으로 사용하지 않음.
5. 배포 후 동일 피드백 검사와 `version.json` 커밋 일치 확인
