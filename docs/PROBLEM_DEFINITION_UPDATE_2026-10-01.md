## 기술·데이터·책임

원문 확인 → 로컬 LLM의 사실·주장·미확인 추출 → 기존 문서·지식 기반의 사건·조건 관계 대조 → TS 책임·현행 기능·A/B/C 대안 비교 → 근거 검수·보류·재계획 → 검토된 처별 요구사항·측정명세 연결의 추가 적용안.

NOA·aRDa의 실제 TS 배포본과 권한·성능은 미검증. LLM이 계산·공간 분석·배차 최적화·법정 판단을 독자 수행하는 범위로 확장하지 않음. 기존 도구의 결과와 담당자 판단을 연결하고, 미확보 근거를 생성하여 채우지 않음.

외부 자료는 공개 원문만 조사하며 개별 민원·개인 식별정보는 게시하지 않음. 내부 기록은 목적·자료 권한·최소 항목·보존·정정·삭제 조건을 확인한 뒤 로컬 처리. 빈 양식은 예시 사건이 아닌 미작성 서식이며 기준선·목표·판단은 null.

## 검증 기록

- npm ci: 잠금파일 기준 설치 완료·취약점 0건. esbuild 설치 스크립트 경고가 있었으나 실제 빌드 성공 확인
- npm test: 빌드와 전체 26개 검사 묶음 통과. 사이트 분석·신규 문제정의 정합성 390항목 통과
- 기존 회귀: 73개 React 경로, 깨진 내부 링크 0건, 13처 원 정본 불변, 39처 한글 117개 무결성 확인
- 새 검사: 10항목의 질문·필요 근거, 6후보의 7개 검증 필드·직접 공식 근거, 기술·개인정보 제약, 빈 서식의 20개 작성칸 존재와 null 상태, MD·JSON 일치
- 최초 검사 실패: 최신 방향에 숫자 문구 ‘10개’가 있어야 한다는 검사와 실제 방향 문장이 불일치. 방향의 의미 항목을 직접 검사하도록 보정하고 10개 고유 ID·질문·근거 검사는 별도 유지. 이후 전체 검사 재실행 통과
- 실제 브라우저: 최신 로컬 Edge에서 1600px·390px, 목차·링크·13처 현재 판단·기존 보강안·새 질문/검증·기술 제약·3개 내려받기·스크립트 오류 131항목 통과. 캡처 시각 검토 완료
- 독립 검토: 근거·기술·검증/UX 3역할 읽기 전용 검토 모두 CONFIRMED·합격. 실제 피해나 제품 효과의 확인 판정과 구분
- 필수보완 해소: 빈 양식에 AI 필요성·필요 데이터·KPI 정의가 빠진 점을 추가하고 필드 존재 회귀검사. 담당 처·출처 게시일도 함께 추가
- 권고보완 반영: 검토서 자체의 공통 기술 제약 표시, P02의 직접 공식 사실을 S02 e만족 FAQ에 연결
- 과거 6종 내부 초안은 독립 검토자가 원문 전체의 HTTP/HTTPS 검색을 재확인. 지정 파일의 외부 원문 링크 미확인에 한정하며 초안 내용의 허위 판정으로 확대하지 않음

검토서 작성 자체를 사례 조사·실증·배포 완료로 처리하지 않음. 실제 현업 사용자 조사·스크린리더·전체 WCAG 인증, NOA/aRDa 배포본·LLM 실행·실제 피해/편익 측정은 미수행. 117개 한글 보존본의 신규 판본 작성은 이번 범위에 포함하지 않음.
