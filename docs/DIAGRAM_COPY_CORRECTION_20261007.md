# MR-01 도식 한글 교정

- 사용자 제보: 아키텍처 부제의 `플랫폼` 글자 손상.
- 원인: 이미지 모델 PNG 내부 한글 획 오류. JSX·설계 원장의 해당 단어는 정상.
- 교정 범위: MR-01 전체 아키텍처·서비스 흐름·데이터 흐름·요구환경 4종, 플랫폼 관련 9개 글자 영역.
- 방법: 내장 image_gen 수정도 시도했으나 동일 글자 잔존. 기존 이미지 모델 원본을 보존하고 정확한 한글 SVG 텍스트 레이어로 교정본 PNG 생성. 재생성 모델의 결과를 최종 교정본으로 사용하지 않음.
- 자산: `MR-01_*_v1.png` 보존, 사이트 연결은 `MR-01_*_v2.png`. 기존 168개 자산 중 4개 활성 경로만 변경.
- 정확한 문구·배치 정본: `src/diagram-copy-corrections.json`.
- 재생성: `PLAYWRIGHT_MODULE`에 개발환경 Playwright 경로 지정 후 `node scripts/render-diagram-copy-corrections.cjs`. Windows Edge·Malgun Gothic 사용. 정상 CI 빌드에서 재생성하지 않음.
- 검증: 9개 라벨 모두 지정 영역 내부. 원본 대비 교정 영역 밖 변화 픽셀 0. 원문 판본·제품명·업무책임·화살표·개인정보 경계 보존. `qa-output/copy-review/corrections.json`에 실행 결과 기록.
- 회귀: 활성 v2 경로·원본 SHA·교정 시점·문구·배치영역·PNG SHA·배포 바이트 검사. 이미지 오류·재시도 브라우저 검사는 활성 원장의 실제 파일 경로를 사용.
- 실제 실행: `npm ci`·`npm test` 성공(41개 정적 검사 스크립트). 교정 도식 HTTP·표시·확대·모바일 27개 조건 통과. 전체 도식 브라우저 회귀 626개 조건 통과. 실행 오류 없음. `git diff --check` 통과.
- 독립 검토: MR-01 교정 4종의 9개 문구 정상 판독, 잘림·오타 잔재·연결선 훼손 없음. 해당 표기 교정 범위 합격. 배경의 약한 색차는 비차단 권고.
- 공개 반영 완료조건: 커밋·푸시 → Actions 성공 → 공개 `version.json`의 커밋 일치 → 4종 교정본 HTTP SHA 및 실제 페이지 표시 재검증. 공개 검증은 `SITE_BASE`와 `RELEASE_SHA` 지정 후 `node scripts/check-diagram-copy-browser.cjs`로 실행.
- 한계: 자동 문자 인식으로 전체 168개 이미지의 오탈자를 검증한 결과가 아님. 이미지 밖 픽셀 보존과 정확한 문자 원장 검증을 구별. 이번 MR-01 4종은 원본 크기·사이트 표시 크기 육안 검토 대상.
- 롤백: 필요 시 수정 커밋의 표시 경로·교정본 변경만 되돌림. 기존 원본·근거·한글 문서 삭제 없음. 오류본을 재노출할 수 있으므로 롤백 사유 기록 필요.
