## 요청과 결과

TS 기본정보·관계부처·법령·기관 의의·조직은 보존하고, AI 서비스 비교와 사례에서 기존 사업 이후의 추가 적용 범위를 도출하도록 첫 화면과 전역 탐색을 재구성했다. 기존 GitHub Pages 배포 경로·75개 HTML 주소·이전 기획 및 다운로드를 유지한다. 새로운 8개 보기는 `index.html?view=...`로 등록한다.

기획 자료는 사용자 지정 TS 폴더의 최신 비교분석·현행 고도화 v0.2·사례 143건 검토·사업기회/사업기획/2030 로드맵 v1.1·AS-IS/TO-BE v1.2를 우선했다. 과거 저장소 정본을 조용히 덮어쓰거나 다른 브랜치를 병합하지 않고, 현재 재구성 원장을 추가했다. 공개 화면에는 기능·기획 요약과 공식 출처만 포함하며 원본 업무파일·보안 구성·개인 경로·계약 금액은 새로 반출하지 않았다.

## 근거와 판단의 경계

- TS 매뉴얼의 한글·양식·문서·드라이브·스킬 및 민원 전용 분석을 현행 기반으로 유지한다. 미확인을 미지원으로 표시하지 않는다.
- 요구·반영 보고·제공 계획·실제 검수와 운영 성과를 구분한다. 현재 자료에서 실제 인수·성능·가격·후속사업 승인을 확정하지 않는다.
- 현행 의무 이행과 운영·절차 개선 이후 남는 순증을 검토한다. API·RAG·권한·판본·LLMOps 기능이 없다는 주장을 만들지 않는다.
- TS RIMS는 기존 자산 사례이며 신규 후속 구축 후보로 집계하지 않는다. 법제처 사례의 당시 문맥 검색 개통과 생성형 확대 계획을 구분한다.
- 공식 기능은 기준일의 제공 조건이며 동등 과제로 실측한 정확도·속도 순위가 아니다.
- Claude 컴퓨터 사용은 Pro/Max/Ultra 베타·Team/Enterprise 미제공 조건, Gemini Skills와 유료 Tasks의 이용 범위, ChatGPT 예약의 환경별 자료 접근 차이를 반영했다.
