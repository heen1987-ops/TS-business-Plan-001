# 처별 인터뷰지 준비 설계 · 2026-10-06

> 후속 정정: 사용자 요청에 따라 설명을 서두에 두는 설문 v0.2 작성. [설문 v0.2 설계](SURVEY_DESIGN_20261006.md) 참조. 아래는 당시 v0.1 인터뷰 준비안과 검증 이력이며 새 설문을 덮어쓴 기준이 아님.

## 요청·완료 범위

- 요청: 처별 현재 사항을 확인하고 인터뷰지 작성을 위한 세분화 계획 작성.
- 산출물: 기존 조직/기획과 연결한 조사 준비안, 공통 문항, 처별 검증 문항, 전문 담당 보충, 실제 사건카드·후속 확인의 빈 양식.
- 시간축: 2027년 ISP·후속사업 편성 준비. 장기 NPU 투자계획 제외.
- 실제 면담·발송·회신·자료 이용승인·참여확약·제품 실행·의료 성능·최종 대가 확인은 미실시.
- 추가 발화 ‘리스토베이’의 의미는 확인 요청 중. 도구·실시방식은 지정하지 않고 질문/증거/편성 판단 매핑부터 작성. 면담·서면 구성은 준비 가정이며 현업과 미합의.

## 모집단·질문 구성

- 기존 공개 조직도 대조 원장: 본사 38처 + KATRI 13처 = 51처.
- 기존 계획서 연결: 39처, 42항목. 전체 TS 분장·현업 수요·전국 설치수 확정 아님.
- 별도 추가 후보: 자격교육처 QE-H01 1항목. 기존42항목에 편입하거나 완료사업으로 계수하지 않음.
- KATRI 미매핑12처: 업무 발견·분장 확인 문항. 솔루션 배정 전제 없음.
- 질문 주제55 = 기존42 + 추가후보1 + 발견12. 사업55건이라는 뜻 아님.
- 고유질문197 = 공통12 + 주제별3×55 + 전문보충4×5. 공통 핵심6과 실제 제공 가능한 한 건을 우선, 후속 서면/전문담당 확인으로 분리.
- 지역2처 유형과 직속실·내부팀·센터·사무국·외부기관은 보충 응답자로 구분. 실제 지역 설치수 미확인.

## 수용기준·설계

1. 원장의 조직ID51과 기존 기획ID42를 빠짐없이 대조. MR/QE/철도안전/철도승인 복수주제 분리.
2. 각 주제에 고유한 실제 범위·사건 질문, 기존 대응·반증 질문, 검증·개발조건 질문과 필요한 증거·편성 경계 연결.
3. 제품·서버·연계·계약·보안은 공통 전문 보충으로 분리. NOA 기능부터 보여주어 수요를 유도하지 않음.
4. 요청·근거·자료 가용·기획 판단을 별도 축으로 관리. 회신/역할/날짜/판단은 null, 상태는 미요청·미확인.
5. 공개는 질문·준비계획·빈 양식만 포함. 실제 회신·식별정보·건강정보·원문 사건은 별도 접근제한 관리 및 공개 판단 필요.
6. 근거의 기존 확인일·검증범위 보존. 작성일을 전체 출처의 재검증일로 승격하지 않음.
7. 51처 직접링크·자동 펼침/포커스·본문 검색과 108개 다운로드 연결. 연속 스크롤, 페이지 분할·고정높이 없음.
8. 현행 A/정형 개선 B/B+NOA C의 비교 입력과 품질·검수·재작업·과잉처리 측정을 확인. FP/MM/목표/금액 임의 승계 금지.
