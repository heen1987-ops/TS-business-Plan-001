## 이미지 교정 범위

- 활성 모집단: 42개 과제 × 전체 아키텍처·서비스·데이터·요구환경 4종 = 168장.
- 로컬 Windows 한국어 OCR로 168장 모두 후보 탐지. OCR 문장을 업무 사실이나 정확한 글자로 채택하지 않음.
- 이전 MR-01 4장·9영역의 정확한 교정본 유지.
- 추가 157장·303영역의 플랫폼 관련 표기를 정확한 `플랫폼` 글자 레이어로 적용. 정상 인식 후보도 같은 글자 레이어로 통일.
- 플랫폼 관련 표기가 없는 데이터 도식 7장 유지: QE-01, EX04-01, EX08-01, EX10-01, EX11-01, EX12-01, EX14-01.
- v1 원본 보존, 현재 사이트 이미지·확대 링크는 v2 교정본 참조. 생성 이미지의 업무 내용·제품 역할·화살표·연결선 변경 없음.
- 정본: `src/diagram-platform-corrections.json`. 렌더러: `scripts/render-platform-copy-corrections.cjs`. CI에서 재생성하지 않음.
- 실행 검증: 추가 303영역의 글자 범위 적합. 157장 모두 교정 영역 밖 변화 픽셀 0. QA는 `qa-output/platform-copy/results.json`.
- 육안 확인: DF 데이터, DRT 서비스, AD 전체, PK 서비스, EX06 데이터 등의 확대·표기·연결선 검토. 나머지 문장 전체의 오탈자 전수 육안검증과 구분.
- 새 회귀 검사 1,401조건. 기존 전체 도식 브라우저 626조건 통과: 168장 로딩, 확대 경로, 42과제, 직접 앵커, 모바일, 실패·재시도.
- 추가 배포 바이트·실제 표시 검사: `scripts/check-platform-copy-browser.cjs` 로컬 184조건 통과. 157장 HTTP·SHA 일치, 8개 대표 도식, 모바일·새 탭 확대 검사. `SITE_BASE`·`RELEASE_SHA` 지정 시 공개 배포 검사로 재사용.
