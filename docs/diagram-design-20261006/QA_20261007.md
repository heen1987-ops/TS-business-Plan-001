## 제품·권한·데이터 검수

- NOA가 aRDa·Grantee·전문도구·Nexus·Argus/Keeper·사건 이력에 요청하고 결과를 받는 관계를 각 과제의 논리 원장에 명시.
- aRDa는 허용된 근거·원문·판본·ACL 관리 후보. Grantee는 기준·증거·공식 기록의 대사 후보. 산술·최적화·공식 결정·분쟁 중재 역할을 임의 배정하지 않음.
- 담당자 확정 기록과 독립 공식 원천을 결과 대사의 별도 입력으로 유지. AI 초안을 사람 승인본 또는 공식 기록으로 표시하지 않음.
- MR-02는 전화 접수·수동 배차·운영계획 고도화가 목적. 부정수급 판정·환수·전국 예산배분을 포함하지 않음.
- EX11-01은 조회·승인 초안 인계가 기본. 연계·쓰기권한·멱등·결과 조회를 확인한 경우 제한된 ERP 초안 등록만 검토. 지급·마감·취소 자동실행 제외.
- QE-01의 공식 확정자는 지정 검사요원·기관 권한자. 수검자를 공식 판정자로 표시하지 않음.
- EX21-01·EX22-01은 국내 요건·수요·협의주체 또는 자료 이용권·보호 검수가 확보되기 전 운영 적용 HOLD 유지.
- 원식별정보·기업 설계/시험자료·건강 상세 정보와 최소화된 검토 문맥을 구분. 보존·정정·삭제·파생본 권한 전파는 확인·구현 조건으로 명시.

## 공개·배포·복구

- 공개 설계 MD/JSON에 PC 파일 경로 없이 42개 후보의 정확한 노드·흐름·권한·요구환경 수록. 기존 HWPX 자료 156개는 기존 구조/텍스트 무결성 검증 대상 유지.

- GitHub `main`의 기존 Pages 워크플로우 사용. 이 문서는 로컬 검증 기록이며 실제 배포 성공은 해당 커밋의 Actions와 공개 `version.json`으로 확인.
