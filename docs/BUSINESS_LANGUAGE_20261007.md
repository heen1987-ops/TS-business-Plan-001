# 업무 설명·도식 개정 — 2026-10-07

- 요청: 서비스 설명과 도식의 내부 상태 용어를 실제 업무의 상황·행동·담당자·결과로 표현.
- 적용: 현재 42개 기획 후보의 설명, 168개 도식 중 133개 이미지의 372개 글자 영역.
- 성격: 기존 제안의 설명 개정. 실제 TS 구축·현장 운영·효과 검증의 완료를 의미하지 않음.

## 업무 언어의 적용

| 기존 표현 | 공개 설명의 기준 | DRT 예시 |
|---|---|---|
| 보완·재계획 | 무엇이 달라졌으며 무엇을 다시 검토·조정하는지 명시 | 차량 부족·기사 거절·지연 시 다른 차량·시간의 제안 및 주민 조율 |
| 확인불가·권한 미확보 | 필요한 자료·답변과 확인할 담당자를 명시 | 출발지·목적지·도움 필요조건의 재확인, 등록주소·지원 대상의 주민·담당기관 문의 |
| 공식 완료 증거 | 제안·접수·실제 처리의 차이와 확인할 자료를 설명 | 운영자 확정·기사 수락으로 배차 확인, 기사 응답·운행기록·상담원 확인으로 실제 탑승 확인 |

권한·자료 이용 제한을 없애거나 AI에 새 권한을 부여하는 변경이 아님. 본문에서는 업무 행동을 설명하고, 개발·운영의 상태·권한·연계 조건은 기본으로 접힌 상세 명세에 유지.

## 구현 범위

- `src/proposal-business-language.cjs`: 42개 과제의 문제 상황·대응·추가 문의·결과 표현, 업무 연결 9단계, 제품 역할, 새 이미지 입력.
- `src/ProposalDiagramSuite.jsx`: 업무 설명의 기본 표시, 상황별 안내, 기술 조건의 접힌 표시, 개정 이미지의 연결.
- `src/diagram-business-copy.json`: 이전본·편집 기반의 해시, 교정 글자·좌표, 새 이미지 경로.
- `scripts/render-business-copy.cjs`: 정확한 한글 레이어, 글자 영역·최소 크기 검사, 편집 영역 밖의 변경 검사. 일부 도식만 다시 렌더링 가능.
- `public/downloads/proposal-diagrams/design.json`, `design.md`: 업무 설명과 기술 설계의 동시 제공.
- `docs/diagram-design-20261007/image-prompts-business.json`: 내부 상태 표기를 다시 생성하지 않도록 수정한 168개 이미지 입력.

## 이미지 변경과 보존

전화 DRT 서비스 흐름 1장은 이미지 모델로 재제작. 생성한 원본의 플랫폼 표기는 정확한 한글 레이어로 마무리. 다른 도식은 해당 글자 영역만 수정하여 기존 구성요소·연결선을 보존. 이전 v1·v2와 이번 v3의 경로·해시를 각각 유지.

이미지 개정 v3는 사이트 자산의 개정번호이며, 처별 한글 계획서의 누적 문서 버전을 갱신했다는 뜻이 아님.

## 검증 및 재발 방지

- 전체 `npm ci` 및 `npm test`: 빌드와 45개 검사 스크립트 통과.
- 도식 렌더링: 133장·372영역의 글자 범위·크기 확인, 편집 영역 밖 변경 0픽셀. 재제작 DRT는 이미지 모델 원본을 편집 기반으로 비교.
- OCR: 168장 판독 후 잔여 표현을 추가 교정하고 해당 도식 재판독. OCR만으로 모든 한글의 정확성을 보증하지 않으며 대표 이미지·실제 화면의 육안 검토 병행.
- 실제 화면: 업무 설명 352개 검사, 기존 도식의 탐색·확대·직접주소·모바일·이미지 실패/재시도 626개 검사 통과.
- 회귀 검사: 42개 과제 업무 문구, 133개 개정 이미지 연결·해시·이전본 보존, 내려받기 일치 확인. 미래 이미지 입력에도 업무 행동 중심 표현 적용.

## 남아 있는 적용 조건

배차·전화·지도·문자·ERP 등 실제 연계권한, 제품 설치본·사용권, 현장 자료, 성능·효과는 기존 확인 대상 유지. 정산감사·부정수급 판정·환수·전국 예산배분을 DRT의 이번 서비스 흐름에 추가하지 않음.

## 배포 확인과 복구

GitHub Actions 빌드·검사·Pages 배포 뒤 공개 `version.json`의 커밋과 개정 PNG의 SHA-256, 42개 과제의 실제 설명을 재확인. 배포 후 치명적 회귀가 발견되면 이번 변경 커밋을 되돌려 직전 배포본 `be18f78`의 구성으로 복구하고 동일 검사 재실행.

최초 배포의 1GB 초과 경고를 보완하기 위해 현재 도식 168장만 배포. 미사용 초기본 168장·이전 교정본 126장·모델 원본 1장은 Git에 보존하고 배포에서 제외. 현재 이미지의 바이트 일치, 이전본 원본 해시, 한글 계획서 156개 파일, 내부 링크, 1GB 미만의 배포 총량을 검사. 공개 경로가 필요한 파일을 같은 방식으로 제외하지 않도록 현재 도식 원장의 경로를 우선 사용.
