# 목적·목표·수단 구분 보완 · 2026-10-06

## 사용자 문제와 변경 범위

‘목표·목적·수단이 구별되지 않아 솔루션을 이해할 수 없다’는 피드백 반영. 기존 모델은 공공 편익과 내부 작업의 결과를 `purpose`에 함께 표시하고, 지표 이름을 ‘측정할 변화’로 나열했음. NOA·기존 도구·사람의 판단도 `how` 문자열 안에서 혼합.

원문 근거·지표·법정 책임·기존 상세설계·한글 파일은 유지. 새로운 기획 해석층을 통해 아래 세 의미 구분. 실제 발생률·성능·개선효과·확정 예산을 추가로 입증한 조사로 간주하지 않는 범위.

| 구분 | 의미 | 앱미터 예시 |
|---|---|---|
| 목적 | 누구를 위한 공공 편익·사업 이유 | 이용자 요금 신뢰와 제작사 검정 절차 예측가능성 |
| 목표 | 달성할 업무 결과·지표·원하는 변화 | 적정 경로 확정, 같은 사유 보완 감소, 유효 검토기간 단축 |
| 수단 | 결과를 만드는 기술·처리·책임 | NOA의 변경·증거 해석, 기존 시험·규칙, 담당자의 공식 경로 결정 |
| 산출물 | 수행사가 제공할 개발 결과 | 관계모델·스킬·연계·양식·평가사례 |

## 설계와 수용기준

- 42개 후보 모두 편익 목적·수혜자·결과 상태·3~5개 목표·측정식·역할별 수단·업무 변화·추가 개발 검토안 연결.
- 현재 `solutions.html`의 42개 과제 카드와 37개 상세 profile에 같은 표시 적용. 이 중 9개는 기존 보조 제안이며 42개 ISP 후보에 새로 편입한 것으로 표시하지 않음.
- 미작성 12개 조사 대상은 현재 미작성·수요 탐색 상태 유지. 목적·효과·공식 분장을 생성해 채우지 않음.
- 기준선·수치 목표는 `null` 유지. 목표 상태·개선 방향과 미확정 목표값을 구별. 기존 측정지표의 순서·산식 보존.
- NOA의 의미·조건 해석, 규칙·계산·기존 도구, 원문·판본·권한 기반, 사람의 공식 확정 책임 분리.
- MR-01 앱미터와 MR-02 전화 DRT 분리. DRT의 정산감사·부정수급 판단·환수·전국 예산배분은 현재 납품·대가·핵심 성과에서 제외.
- 목적·목표·수단·업무 변화 설명을 상세 근거·도식보다 앞에 표시. 기존 6개 장의 상세는 연속 스크롤 유지.
- 모바일 단일 열·명시적 라벨·정상 키보드 탐색 유지. 페이지 분할·고정 본문 높이·내부 세로 스크롤 추가 없음.

## 파일과 추적

- `src/proposal-intent.cjs`: 편익 목적·결과 상태·개선 방향의 수동 작성 및 기존 근거·지표의 연결. 추가 개발은 검토안.
- `src/ProposalIntent.jsx`, `src/proposal-intent.css`: 같은 순서의 공통 설명 패널과 용어 정의.
- `IntegratedReader`, `Revision47`, `ProposalLinks`, `DrtAssurance`, `UserHome`, `DepartmentDirectory`: 통합 본문·독립 제안·보존 개요에 적용.
- `check-proposal-intent.cjs`: 42개 ID·담당·128개 목표/원 산식·미확정 상태·권한 경계·보조 제안 검사.
- `check-proposal-intent-browser.cjs`: 실제 42개 선택, 12개 미작성, 독립 제안, 순서·모바일·기존 근거 보존 검사.

## 검증·운영·롤백

`npm ci` 후 `npm test`, 목적·목표·수단 브라우저 검사와 기존 통합 본문 회귀 검사 수행. 독립 리뷰는 원장과 의미 대응을 확인하되 실제 현업·국민 이해도 조사를 대체하지 않음. 시험 결과는 `qa-output/purpose-intent`와 `qa-output/integrated`에 저장. GitHub Actions 결과와 공개 `version.json`, 실제 브라우저 내용으로 배포 확인.

한글 계획서·대가산정·도식 파일은 이번 변경에서 재작성하지 않음. 웹 기획 해석의 구분 보완과 기존 다운로드 판본의 내용 개정은 별도 작업. 한글 파일 무결성·호환성 검증값 유지.

롤백: 이전 정상 커밋으로 이번 소스 변경만 되돌린 뒤 전체 검사·Actions 재배포. HWPX를 포함한 공개 원본 파일이나 이전 기획 이력 삭제 없음.
