# 전사 업무 효율화 AX 확대 — v0.8

- 요청: AI PMS 중심 업무 효율화 축을 공단 전체 업무로 확대하고 처별 적용·우선순위·NOA 재사용·업무 스킬·개발 차분·2027~2029를 홈페이지에 반영.
- 범위: 2026-10-08 공식 직원검색 등록 처 74개(본사 38, 연구원 13, 지역 21, 교육 2). 실·센터·검사소·팀은 별도 적용 유형. 전국 실제 직제·권한 전수검증이나 현업 수요 확정으로 표현하지 않음.
- 데이터: `src/enterprise-work-ax.cjs`가 제안 정본. 원문 업무는 `official-duty-research.cjs`에서 ID·코드·위치를 유지해 결합. Markdown·CSV·JSON은 빌드에서 생성.
- 화면: 기존 두 축 구조에 전체 업무 요약, 네 단계 적용 순서, 재사용/스킬/차분, 접을 수 있는 처별 목록과 검색·필터 추가. AI PMS와 국민서비스 10개군 경계 유지.
- 연차: 2027 선정 업무 운영 인수 완료 및 국민서비스 설계, 2028 조건부 연계 구축, 2029 연결/예외/품질 고도화. 연도별 독립 발주, 후속 계약 보장 없음.
- 원가: 구체 물량·권한·설치본 대조 전 미산정. 동일 플랫폼·허브·스킬·연계·평가 비용은 중복 계상하지 않음. 개발 FP와 비개발 작업량은 해당 시점 기준에 따라 구분.

## 수용기준과 검증

1. 74개 처 코드·명칭·소속이 보관 원장과 일치하고 업무관측 ID·원문·쪽/행이 추적된다.
2. 모든 처에 업무흐름·담당·우선순위 사유/진입조건·3개년·재사용/스킬/개발·산정물량·분야 검수가 있다.
3. 국민서비스 10개군이 유지되고 감리 AI·PMS를 국민서비스군으로 분류하지 않는다.
4. 서울 안전사업2처의 주차장 정밀검사를 운전적성정밀로 오분류하지 않는다.
5. 데스크톱·태블릿·모바일에서 검색/교차 필터·빈 결과/초기화·키보드 상세 열기·가로넘침·다운로드를 확인한다.
6. 정적 사이트이며 새 API·인증·개인정보 수집·의존성은 추가하지 않는다. 운영 시스템의 실제 업무 등록 기능은 구현하지 않는다.

## BDD와 화면 상태

- Given 전사 계획 진입 / When 처별 상세 펼치기 / Then 74개 처와 선택 조건·검색 수가 표시된다.
- Given 예산처 검색 / When 상세 키보드 열기 / Then 재사용·스킬·차분과 3개년·근거가 나타난다.
- Given 일치하지 않는 검색 / When 결과 없음 / Then 빈 상태와 초기화로 복구 가능하다.
- 읽기 전용 정적 자료이므로 로그인·저장·거래 실패/로딩 상태는 추가 대상이 아니다. 내려받기 파일 생성/HTTP 검증을 수행한다.

## 운영·롤백

원장·컴포넌트·빌드 생성 파일 검사를 `npm test`에 포함. 공개 배포는 해당 커밋의 Actions와 `version.json`·공개 데이터 내용/해시 확인. 문제 시 해당 변경 커밋만 일반 revert하고 재검증·배포하며 기존 사용자 UI 변경은 건드리지 않는다. 미확인 설치본·현업 기준선은 후속 조사 대기열로 유지.
