## 반영 범위

- 홈페이지 최신 조사 링크 → 자료실의 `associations.html` 연결.
- 기존 후보 10개의 신규성 미확정 판정, 상담·민원 기존 요구범위, 공식 절차에서 확인할 세 가지 조사 출발점 선배치.
- 단체·지역조직·공제·교육기관 378개 기록 검색, 선택 조직의 정의·의의·직접 문제 근거와 업종 공통 근거 구분.
- 공개 쟁점 32개, 후보 10개의 근거·확인 한계·설계 이력·향후 시험안 열람.
- 기존 연구 JSON에서 공개용 열람본 생성. 개인 파일 경로 제외, 공식 URL·근거 제목·쪽수·확인 상태 보존.
- 전체 MD·JSON 내려받기. 독립 협회 수·민원 접수 건수·전국 전수조사 완료로 확대하지 않음.

## 원본과 배포 데이터

- 입력: `협회_정의_민원_사업기획.json`.
- 입력 SHA-256: `6d3e6dbfb09ae844b14ea38688df4b193e7767e3ef2f8eec6f0f3fc643a6550b`.
- 변환: `node scripts/import-association-research.cjs <조사자료 폴더>`.
- 공개 데이터: `src/association-research.json`.
- 빌드 내려받기: `dist/downloads/association-research.md`, `dist/downloads/association-research.json`.
- 변환 시 URL 불변 검증. 원래 연구 폴더 없이 저장소 자체 빌드 가능.

## 검사와 배포

1. `npm ci` 및 `npm test`: 기존 경로·링크·기획 데이터 회귀 검사와 신규 자료 참조·판정·URL·공개 범위 검사.
2. `scripts/check-associations-browser.cjs`: 검색·선택·공유주소·빈 결과·초기화·후보 이동·설계 펼침·내려받기·모바일 목차·키보드·가로 넘침 검사. `PLAYWRIGHT_MODULE`과 `SITE_URL`로 런타임·검토 주소 지정.
3. 변경 파일만 커밋·main 푸시. GitHub Actions의 해당 커밋 빌드·배포 성공 확인.
4. 공개 화면·내려받기·`version.json` 커밋 일치 확인 후 완료 보고.

경로 67→68, 메뉴 기록 319→320. 협회 조사 경로 한 개 추가에 따른 변경이며 기존 경로 삭제 없음.

오류 시 이전 정상 버전으로 되돌리는 별도 커밋 후 같은 workflow 재배포. 배포 실패 시 로컬 작성과 공개 완료를 구분.
