## 실제 수행한 사이트 검증

- `npm ci`: 잠금 의존성 설치, 의존성 감사 0 취약점. 전체 애플리케이션의 보안 인증으로 해석하지 않음
- `npm test`: 73개 React 경로 빌드와 47개 검사 스크립트 통과. 새 PMS 설계 검사 225항목
- 새 PMS 브라우저: 41항목 통과. 13개 절·8개 요구·4개 연구·5개 지표·5종 다운로드 HTTP/해시·모델 이미지 2개 디코딩
- 통합 화면 1440/768/390px: 본문·숨김 부모 열림·가로 넘침 방지·키보드 다운로드·처 선택 유지 확인
- 기존 PMS 브라우저: 33항목 통과. 39처·42기획·117개 최신 한글 파일·319개 설계 연결, 검색·앵커·목차·모바일·문서 이동 유지
- 전체 처 탐색 브라우저: 292항목 통과. 51개 조직·복수 과제·상세 본문·기존 해시·처 검색·모바일 메뉴·한글파일 응답 유지
- 화면 캡처와 최종 생성 PNG 직접 확인. 시각 자산 검수는 `VISUAL-QA.md` 참조
- `git diff --check`: 공백 오류 없음

초기 실패 처리: 새 검사의 중복 라벨 선택자는 `first()`로 명확화. 전체 처 검사는 기존 `SITE_BASE` 환경 변수로 서버를 지정. 이전 PMS 검사의 폐기된 `.ts-location`은 현재 공통 메뉴 제목과 `.ts-header`로 대체하여 동일 메뉴/고정헤더 검증 의도 보존. 실패 숨김·검사 삭제 없음.

## 미수행·검증 범위

- 실제 PMS 백엔드·DB·큐·SSO·TS API·RealPMS 계정 사용 구현 없음
- 제품 설치·Grantee 감리 성능·연구 정답셋·전문가 현장 시험 미수행
- 현업 피드백·법률 자문·공식 감리·접근성 인증 미수행. 키보드·폭·화면 검토만으로 WCAG 전체 준수 확정하지 않음
- FP·인월·단가·총액·기준선·목표·공고 지원 조건 미확정. 미산정 수치를 0으로 치환하지 않음
- NTIS API 실조회 시도는 허용 IP 거부로 실패. 직접 유사 과제 미확보를 유사 과제 부재나 독창성 확보로 해석하지 않음

## 릴리즈·복구

기존 사용자 배포 승인에 따라 테스트 통과 커밋을 main에 푸시하고 Actions→Pages→공개 버전·다운로드를 확인. 배포 결과는 커밋 후 조사 폴더의 배포 확인 기록에 보존. 롤백은 PLAN.md의 정상 커밋 기준으로 새 복구 커밋·재배포, 기록 삭제·강제 푸시 제외.
