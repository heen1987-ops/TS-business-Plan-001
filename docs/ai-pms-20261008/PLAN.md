# TS 자체 AI PMS·감리 지원엔진 · 변경·검증 계획

2026-10-08 · 신규 정보화사업/연구 기획 · L / Medium

## 문제와 범위

국토부 PMS의 보고 구조를 참고한 TS 자체 업무추적 PMS 설계와, 기구축 TS AI 플랫폼에서 사용할 감리 지원엔진의 별도 R&D·이식 계획 작성.

- 현재 국토부 PMS 사용은 사용자 현장 확인. 참조 시스템은 RealPMS로 잠정 설정하며 정확한 시스템·TS 이용범위·연계권한 추가 확인
- 기존 스킬형 PMS v0.3의 공동 코어·스킬·권한·문서 연결 재사용. 새로운 계획은 별도 TS-AIPMS-2027 v0.1로 보존
- 2027 정보화사업 일정, 공고·협약 미확정 R&D 시간축, 독립 감리 역할·대가의 구분
- 운영 서버·TS API·실제 감리 성능 구현은 이번 정적 기획 사이트 반영 범위 밖
- 최근 사용자의 독립 R&D 요청은 이번 감리엔진에 적용. 과거 일반 기획의 독립 R&D 제외를 모든 사업에 전역 변경하지 않음

## 변경·위험·롤백

- canonical: src/ts-ai-pms.cjs · render: TsAiPmsPlan.jsx/CSS
- 기존 IntegratedReader 공통 플랫폼 본문에 삽입, 사이드 목차에 같은 페이지 앵커. SkillPms 공통 화면 첫 상세안에 삽입. 별도 페이지 신설 없음
- Markdown·JSON·CSV는 canonical에서 빌드 생성, 사이트 상대경로·공식 원문 링크만 제공
- 기존 업무/산출물·재사용 제품 구현으로 오인할 위험: 상태·판본·권한·설치본 확인을 별도 명시
- 공개 사이트는 자료 열람용. 외부 API·인증·PMS 상태 변경 기능 추가 없음
- 롤백: 이번 변경 이전 72cd218 커밋의 사이트 소스로 되돌려 새 정상 커밋·Actions 배포. 기존 문서/브랜치 삭제·이력 재작성 없음
