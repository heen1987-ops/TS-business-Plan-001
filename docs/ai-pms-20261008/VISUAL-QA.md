## Visual Brief

- 목적: 기관·수행사·검토자가 기구축 AI 플랫폼 안의 자체 PMS 위치와 감리 지원엔진 연구·이식 경계 이해
- 배치: 연속 본문의 전체 아키텍처 절, 감리엔진 연구·이식 절
- 비율·실제 크기: 두 PNG 모두 1672×941, 16:9 근사
- 스타일: 흰색 배경·남색/청록·PPT 기술 아키텍처 도형, 명확한 화살표·큰 한글 제목, 장식 최소화
- 메시지: NOA 진입점, aRDa 근거·판본, TS PMS Core 공식 업무기록, Grantee 재사용 후보, Argus/Keeper 확인 후 선정, 기존 시스템·RealPMS의 허용 연결
- 연구도 메시지: 격리 연구→전문가·강한 규칙/그래프/RAG 비교·권한/복구 시험→읽기 스냅샷·사람 검토→개선 확인 및 연구 환류
- 금지: 실제 설치·성능 확정처럼 표시, 자동 법정 감리 판정, 무승인 외부 쓰기, 공고/기간/재원 확정처럼 표시
- 안전영역: 모든 제목·도형·범례의 이미지 내부 여백, 웹의 전체 폭 자동 축소와 원본 확대 링크
- 웹 접근성: 설명 alt·설계 상태 캡션·동일 내용의 상세 표/본문 제공. 작은 화면에서 이미지 글자만으로 정보 이해를 요구하지 않음
