# 법령·업무·담당 처·AX 컨셉 매핑

기준일: 2026-09-23

## 목적·범위

법령 이름만으로 처를 배정하지 않고 `법령·원 권한자 → 실제 수행업무 → 담당 처·역할 → AX 컨셉·배정 이유`를 연결하는 탐색 화면.

- 대상: 기존 13개 처의 대표 제안, 27개 법정업무 묶음, 36개 하위 업무 관계.
- 기존 법정업무를 조사·검사·기술지원 등으로 나눈 관계 수이며 신규사업 36건을 의미하지 않음.
- 부처: 이번 화면에서는 TS 내부 처. 국토교통부·지자체 등은 원 권한·의뢰 주체로 별도 표시.
- 전체 TS 직무분장·위탁사무 모집단의 완전성 또는 내부 전결 확인을 의미하지 않음.
- 기획상 주관 검토 처의 제안이며 실제 발주·예산·과업 확정과 구분.

## 근거와 적용 판단

- 법령 조문·시행일: 기존 `data.json` 법령 원장 판본·원문 링크 인용. 이번에 전체 현행 법령을 새로 확정한 것은 아님.
- 담당 관계: TS 공식 업무안내 본문·담당부서 표시 재열람. URL·제목·담당 부서·열람일·게시일 미표시를 `law-mapping.json.sources`에 기록.
- 담당 표시의 의미: 해당 안내업무 담당. 내부 독점 소관·결재·예산권·최종 행정권한의 확정과 구분.
- 직접 근거 없는 기존 연결: `기존 원장·재확인` 상태 유지. L19 기반시설 업무의 상세 담당은 미확정.
- L02 정정: 종전 연결 URL `01060305`는 시설관리규정 심사 안내. 진단평가·특별실태조사 직접 근거로 부적합하여 기존 원장의 해당 안내 링크 제거 및 재확인 표기. 법령 원문 링크는 유지.
- TMACS 안내의 과거 시행령 조문 표기와 기존 법령 원장의 조문 차이는 원장 비고에 보존. 홈페이지 안내를 법령 효력의 대체 근거로 사용하지 않음.

## 핵심 구분

| L06 | IP 검사 운영, AD 진단기술 지원, RD 검사방법 연구 역할 분리 |
| SI | 기기정도검사를 대표 연결로 사용. 내압용기·삭도는 별도 업무 |
| KATRI·튜닝·철도·항공 | 기존 법정업무에서 담당 관계 유지. 현재 13개 대표 컨셉에 강제 연결하지 않음 |

## 화면·사용 흐름

- `legal.html`: 첫 슬라이드에서 법령→처→컨셉 사례와 매핑 진입 제공.
- `legal/mapping.html?dept=MR`: 처 선택 → 명시적 이동 버튼 → 대표 업무·법령·처 역할·제안 이유 → 컨셉 상세 또는 근거 확인.
- 처 선택만으로 이동하지 않고 키보드 연속 선택·초점 유지.
- `legal/mapping.html?mode=law`: 법령·업무·처 검색 및 분야 필터 → 하위 업무별 담당 관계 → 관련 컨셉.
- `?mode=law&law=L06`: 동일 법령 내 검사·기술·연구 역할 비교.
- 검색 0건: 빈 상태와 초기화 제공. 잘못된 처 값: 첫 대표 처 사용.
- 법령 판본과 공식 업무안내: 접힘 영역에서 필요 시 확인.
- 조직 지도: 처별 자료에 ‘담당 처·법령·컨셉’ 링크 추가.
- 처별 제안: 담당 처와 업무 근거 슬라이드 추가. 기존 `ax` 배열을 소관 확정표로 사용하지 않음.
- 출력: 동일 원장에서 MD·JSON 생성. 등록 원장·검색·사이트맵과 연결.

정적 화면으로 외부 API·LLM·DB·계정·개인정보 저장 변경 없음. URL에 처·법정업무 선택값만 기록.

## 배포·운영·남은 확인

기존 main→GitHub Actions→Pages 경로 사용. 배포 후 version.json 커밋 및 매핑 페이지·다운로드 확인. 장애 시 이번 변경 커밋 revert 후 동일 검증·배포 경로로 복원.

현행 직제·업무분장·위임전결, 개별 위탁·지정 문서, 전국 DRT 총괄 및 예산·위치정보 이용권한은 추가 확인 대상. 미연결 업무의 추가 컨셉 편성은 별도 기획으로 수행.
