## 독립 반증 검토

공공사업 근거 감사 스킬의 절차에 따라 독립 검토자 3인이 동일한 강한 주장 6개를 읽기 전용 검토. 모두 REFUTED 판정. 반증 대상은 다음 해석이며 기존 사업의 전체 가치나 모든 현장 문제를 부정한 판정이 아님.

| 주장 | 정정 결과 |
|---|---|
| 169일 = 행정 처리 지연 | 공개 유효기간 날짜와 실제 개시·처리기간 구분. 원 게시판 이번 재집계 미수행 |
| 재검일 공란 = 미재검 / 80.2% = 기관 성과 | 공개 CSV 기재율. 원 기기 상태·종결·추적기간 없이는 해석 확장 불가 |
| 택시 양수교육 입교 수 = 정밀검사 소견 AI 직접 수요 | 교육 실적과 소견 이해·교정교육 수요의 관측변수 차이 |
| TS에는 분석 이후 조치·이행 확인이 없음 | 공식 점검·역사 평가 절차에 존재. 잔여 부담 별도 확인 |

| 수동 DRT = 즉시 전국 신규 플랫폼 필요 | 기존 서비스와 지역 원인을 확인한 조건부 운영 실증 |

공개 CSV는 주 실행자와 독립 검토자 2인의 재집계가 일치. 746행 중 재검일 기재 598행·공란 148행. 80.1608579%는 날짜 기재 비율. CSV 판본 해시와 집계 방법은 공개 검토서에 포함. 개별 기기·담당자·원자료 행은 게시하지 않음.

적용 결과 독립 검토에서 SI-E01·SI-E02의 공개 JSON에 과거 해석이 남은 점을 필수보완으로 확인. 현재 투영값·등급·검증범위와 공개 evidence/처별 sources를 정정한 후 재검토 합격. 검토자는 새 정합성 검사 244항목을 직접 실행해 통과 확인. 판정 범위는 정정 반영과 공개 산출물의 일치이며, 실제 사업 수요·효과·계약 확정과 구분.
