복수 사업 링크의 대표 사업 오연결 수정. 조직 지도의 옛 기관 안내 주소 호환 복구. 이전 UI를 전제한 검사(중복 목차 검색, PMS 전체목록 혼재, 원장 수량319 고정값)를 새 수용기준과 현재 정본에 맞춰 갱신. 한글 파일 무결성 안내 접힘과 실제 제안 본문 숨김의 검사 구분.

## 증거·재현

로컬 브라우저 기록·스크린샷: qa-output/ux/ 및 qa-output/*.json. QA 출력은 Git 제외. npm test 및 package.json의 check:*browser 명령으로 재현. 실행 환경은 Node.js24, Microsoft Edge headless, Playwright.

## 배포·운영

main push → 기존 pages.yml의 build/check → Pages 배포 → 공개 version.json의 commit 확인 및 공개 사용자 여정 재검사. 문제가 생기면 이번 UX 커밋 revert 후 같은 Actions로 재배포.
