# 연속 문서 읽기 UI

2026-09-23 사용자 피드백 반영. 기존 문서 링크의 호환을 위해 파일명 유지.

## 문제와 변경

적은 설명을 한 화면씩 나누고 이전·다음으로 넘기는 방식에서 내용의 흐름이 단절됨. 전체 세부 본문을 한 번에 표시하고 브라우저 스크롤로 읽는 방식으로 변경.

- 설명 길이에 따른 자연 높이. 슬라이드 비율·고정 높이·큰 빈 공간 제거.
- 페이지 번호·이전·다음·한 장씩 보기·전역 방향키 가로채기 제거.
- 한 문서 안에서 제목·개조식·도식·상태·근거가 순서대로 이어지는 구조.
- 같은 제목과 조건으로 나뉜 연속 조각은 내용 손실 없이 통합.
- 왼쪽 폴더 메뉴 유지. 본문 목차는 절의 위치로 바로 이동.
- 2026-09-24: 우측 고정 목차 제거. 본문 상단에는 큰 장의 이동 링크를 두고, 왼쪽에는 기관 이해 순서와 현재 부서의 큰 장만 표시. 작은 화면은 목차 열기·닫기로 이용.
- 실제 상세 도구(검색·비교·도식 탐색·측정 계산)는 문서 하단의 별도 펼침 영역으로 보존.

## 내용과 근거

`slide-data.cjs`의 원래 내용 모델을 `document-data.cjs`가 연속 문서 모델로 변환. 기존 분할 모델은 주소 별칭과 내용 보존 검사에 사용하며 화면에서는 렌더링하지 않음.

- 원문 카드·모든 글머리표·메시지·상태·가정·미산정·근거 링크·이미지 보존.
- 13개 처·104개 요구사항·16개 아키텍처·39개 지표 원장 내용의 변경 없음.
- 같은 법령·부서·정량지표의 사실 판정이나 예산 재산정 수행 없음.
- 기존 상세 기능의 데이터 소유·상태·운영·인터페이스 계약·과업 추적 기능 유지.

## 직접 링크·접근성

- 기존 `slide`, `-part-N`, `contract`, `store`, `metric`, 법령 해시를 연속 문서의 해당 절로 해석.
- `unit`, `arch`, `case`, `view`의 문서 범위 선택 유지.
- 유효하지 않은 과거 slide 값이 유효 contract·store·metric을 가리지 않도록 순차 확인.
- 본문 목차 이동 시 제목에 초점 이동 및 고정 헤더 아래 표시. 주소 해시·뒤로/앞으로·새로고침 지원.
- 모바일 목차를 접은 후 새 레이아웃에서 이동 위치 계산.
- PageDown·PageUp·Home·End·방향키는 브라우저 기본 스크롤 유지.
- 도식 확대 dialog: Esc·바깥 클릭·닫기, 원본 연결, 열기 버튼으로 초점 복귀.
- 이미지 실패: 안내·원본 링크·재시도 제공. 이미지 공간을 확보해 후속 절 이동 위치 안정화.
- 본문은 숨김·가상화 없이 전체 표시하여 브라우저 찾기·텍스트 선택·인쇄 지원.
- `reading=full` 기존 주소는 연속 본문과 함께 상세 검토 도구를 펼치는 호환 경로로 유지.

## 변경 파일·검증

- `DocumentReader.jsx`, `document-reader.css`: 연속 본문·목차·도식·상세 도구.
- `document-data.cjs`: 조각 통합·기존 주소 별칭.
- `App.jsx`, `ts-navigation.css`: 공통 렌더러 교체·고정 높이 규칙 제거.
- `check-document.cjs`: 전체 111개 경로 조합의 원문 무손실·기존 링크·고유 ID 검증.
- `check-document-browser.cjs`: 전체 본문·기존 직접 링크·목차·뒤로/앞으로·키보드·모바일·도식·상세 도구·인쇄 검증.
- 기존 메뉴·법령 매핑·조직 지도·공식 홈페이지 검사는 동일 사용자 기능을 연속 문서 기준으로 갱신.

배포: 기존 main→GitHub Actions→Pages 경로. 페이지 URL·공개 범위·업무 원장·API·서버 변경 없음. 롤백은 이번 UI 변경 커밋 revert 후 동일 검증·배포 수행.
