# 슬라이드형 읽기 UI

## 목적·구성

- 기존 웹 자료를 한 주제씩 읽는 슬라이드형 본문으로 전환
- 왼쪽 폴더 목차와 제목·폴더 검색 유지
- 상단: 문서명·전체 문서 전환·집중 보기
- 본문: 제목·핵심 메시지·도식 또는 상세 개조식 설명
- 하단: 적용 상태·근거 링크·페이지 번호·이전/다음·페이지 목차
- 4개 이상 설명 블록은 후속 페이지로 분할
- 긴 세부 설명은 이름이 있는 본문 스크롤 영역으로 제공, 키보드 접근 지원
- 모바일은 글자 축소 대신 세로 배치·페이지 전환 시 제목 복구

## 내용 보존

- data.json·impact.json·architecture-v2.json 등 기존 원장은 변경하지 않음
- 13개 처·104개 원 요구사항·16개 아키텍처의 기존 자료 활용
- 기존 JSON 누락 필드는 이미 작성된 아키텍처 원장으로 보완, 미확정 항목은 확인 필요 표시
- 미산정 공수·직접인건비를 0원으로 표시하지 않음
- 상대 감소율·비율 차이·점수 변화의 원래 단위 유지
- 실측 전 협의용 목표안·기준선 미확보·구현 미검증 조건 유지

## 탐색·접근성

- 이전/다음, 방향키, PageUp/PageDown, Home/End 지원
- 입력·목차·버튼·본문 스크롤 영역에서는 고유 키보드 동작 보존
- 페이지 목차의 현재 위치·Escape 닫기·포커스 복구
- 도식 확대 dialog의 Escape 닫기·열기 버튼 포커스 복구
- slide·contract·store·metric·법령 해시의 상세 진입 해석
- 전체 문서의 아키텍처 관점 변경 시 이전 slide 선택값 해제
- 저장소 하위 경로·새로고침·정적 진입점 유지

## 수용기준·검증

| 요구 | 확인 |
|---|---|
| 한 장씩 읽기 | 기본 본문의 슬라이드 1개 표시 |
| 설명·근거 유지 | 상세 텍스트·단위·요구사항 데이터 검사 및 별도 검토 |
| 찾기·이동 | 목차 검색·페이지 목차·키보드·직접 주소 |
| 도식 판독 | 확대 보기·원본 연결·컨셉/흐름/아키텍처 구별 |
| 화면 적합 | 1600×1000, 1280×768, 768·390px 폭 확인 |
| 기존 자료 | 전체 문서 전환과 기존 상세 기능 유지 |
| 회귀 방지 | scripts/check-slides.cjs를 npm test 및 Actions에 포함 |

## 변경·복구

React 표시계층과 정적 데이터 조합만 변경. API·업무 원장·권한·서버 인프라 변경 없음.
문제 발생 시 전체 문서 모드로 전환 가능. 코드 복구는 해당 UI commit을 되돌린 뒤 동일 Actions로 빌드·배포.
