# GROWTH AI 스킬 적용 — TS에서 다른 기관으로 확장

공통 정본은 `CCK-Public-basic/CCK-GROWTH-Skills`다. 이 저장소는 공통 패키지의 고정 판본을 적용하고 TS 사업기획과의 연결을 관리한다. 특정 기관의 공고·양식·계약·협약은 공통 스킬에 섞지 않는다.

1차 사업의 우선 목표는 공식 조직·직무정보 기반 사용자 인식과 업무 맥락 자동 분류다. 부처·기관·부서·직무·업무 매핑과 권한 확인 뒤 필요한 업무 스킬을 선택한다. 아래 수동 호출은 설계·기획 작업에 적용하는 현재 사용 방식이며 플랫폼의 자동 인식을 구현했다는 뜻이 아니다.

## 사용 순서

1. `cck-public-business`로 업무를 선택한다. 기관명과 함께 실제 역할, 사업유형, 공고와 정정 차수, 현재 단계를 식별한다.
2. `cck-public-evidence`로 정보화 가이드와 해당 사업 원문을 대조한다. 원문 판본 확인과 사업 적용 판단은 별도다.
3. 제안 단계에는 `cck-proposal`, 수행 단계에는 `cck-project-management`를 사용한다.
4. 새로운 기관·교육청·학교는 `cck-agency-onboarding`으로 등록한다. 기관 일반 안내만 확보했다면 공고별 양식·배점·기한은 미확인으로 둔다.
5. 제안에서 수행으로 넘어갈 때 제안 주장, 협상·선정 결과, 계약·협약 조항, 승인 계획과 증거를 연결한다. 제안 초안을 승인 기준선으로 바꾸지 않는다.

## TS 적용

| 사업 | 제안서 작성 | 사업관리 | 기존 기획 연결 |
| --- | --- | --- | --- |
| W27-A | 감독·AI PMS 범위와 평가 대응, 기존 기능과 추가분 | 승인 기준선, 산출물, 일정, 이슈, 검수 증거 | `src/annual-work-2027.cjs`의 A와 W27-A-T |
| W27-B | 계획·예산·성과 연결, 수치 근거와 검증 방법 | 기준판본, 수치 대사, 성과 증빙, 보고 | B와 W27-B-T |
| W27-C | 계약·검수 지원, 승인 경계와 시험 조건 | 계약 의무, 납품, 검사, 지출 증빙 | C와 W27-C-T |
| W27-D | 현장점검, 역할·데이터·완료 기준 | 지적, 담당, 기한, 보완, 재확인 증거 | D와 W27-D-T |

기관별 공통 엔진이나 방법론을 사업마다 다시 구매하는 것으로 산정하지 않는다. C27-COM의 유일한 귀속과 기존 납품 차분은 기존 원장을 따른다. 새 기관·병원의 전용 조사·설정·검수 비용은 TS 사업과 구분한다.

## 호출 예시

다음은 업무 지시 예시다. 실제 공고나 계약의 확보·읽기·제출을 의미하지 않는다. 자료가 없으면 초안과 필요한 자료 목록까지만 작성한다.

```text
$cck-public-business
TS 2027 W27-A의 제안서 초안을 준비해줘.
이 저장소의 기존 기획은 제안 근거로 사용하고, 실제 공고·평가표·제출양식은 아직 미확보로 표시해줘.
NOA 재사용, 추가 개발, 검수와 산출물을 요구 대응표로 연결해줘.
```

```text
$cck-project-management
TS 정보화사업의 주간보고와 미완료 산출물 목록을 준비해줘.
첨부한 계약·승인계획·보고자료에서 기관·사업·판본을 확인하고,
기준선과 변경 제안, 실제 증적을 구분해줘. 승인 근거가 없는 변경은 확인 큐에 남겨줘.
```

```text
$cck-proposal
IITP의 지정 공고에 맞는 연구개발계획서를 준비해줘.
먼저 해당 공고가 R&D 협약 사업인지 정보화 조달인지 확인하고,
공고·RFP·평가표·지정 양식·정정 차수에 맞춰 대응표와 초안을 작성해줘.
우리 회사의 과거 실적은 원래 기관·사업을 보존하고 현재 제안에서의 사용 근거를 따로 연결해줘.
```

```text
$cck-agency-onboarding
새 교육청 사업을 추가하려고 해.
교육청·교육지원청·학교 중 실제 계약 주체, 공고, 사업유형, 규정과 양식을 식별해줘.
교육청 이름이나 공고가 미정이면 EDU를 확정 기관으로 쓰지 말고 필요한 정보와 등록 초안을 만들어줘.
```

## 적용·검증의 의미

저장소에 스킬 파일을 배치한 것, 입력 검사 프로그램을 실행한 것, 앱이 스킬을 발견한 것, 실제 업무 산출물 품질을 검증한 것은 다른 상태다. 설치 기록과 파일 해시는 판본을 증명하며 법령 적합성·승인 진위·기관 데이터 접근권한을 증명하지 않는다.

기존 TS 전용 7개 업무 스킬은 별도 어댑터 자산으로 연결한다. 해당 사업 카탈로그·내부 원장·양식·도구를 동봉하거나 병원·KEIT·교육청 규칙으로 전용하지 않는다.
