- 작성일: 2026-10-06
- 시간축: 2027년 공고 미매핑 검토 후보 `QE-H01`
- 요청: 연령·질병·인지·신체 능력을 고려한 고령자의 자격요건 검사 변별력 개선 가능성 검토
- 전제: 고령 버스·택시·화물 운수종사자 우선. 일반 운전면허 관리는 별도 기관 경로. 외부 현업 피드백 미확보.
- 방법: 공식 법령·권고·의료검사 원문 대조 → 추가 범위 설계 → 웹 구현 → 회귀·브라우저 검사 → 읽기 전용 재검토

## 근거와 판단

현재 자격유지검사와 인지·운동기능 의료검사, 2025년 12월 기준 강화는 기존 제도로 구분. 2025년 권익위의 개선 권고를 모든 항목의 현행 시행 또는 현재 검사 오류율로 승격하지 않음. 화물 의료검사 기준에서 현 병력·신체계측은 적부판정 대상이 아님.

추가 후보는 현재 검사·적법한 의료결과의 기능 프로파일, 불일치·누락 검토, 전문가 확인과 교육·재검 연결, 추가 정보가치 검증. 건강보험공단 직접 연계의 TS 제공권한·실제 경로는 미확인. 1차 개발은 해당 연계에 의존하지 않는 범위.

근거 8건은 `src/senior-assessment.cjs`의 제목·URL·시행 판본·위치·확인 사실·한계가 정본. 공개 검토서 MD·JSON은 빌드에서 동일 데이터로 생성. 파생 문서를 별도 사실 정본으로 만들지 않음.

## 개발 범위와 보호

- 기존 플랫폼·로컬 LLM·기존 서버 활용, 신규 인프라 구매 0원 조건 유지. 가용량과 추가 SW·연계 비용은 미확정.
- aRDa 활용안: 허용 원문·판본·검사일·대상 연결. 실제 설치본의 처리·권한 상속은 확인 필요.
- NOA 활용안: 확인된 사실과 미확인 사항 구분, 추가 질문·보완 과업·검토안 구성. 수치 계산은 기존 규칙·분석도구.
- 연령·건강특성별 검증과 개인 자격제한 구분. 임의 질병 가중치·자동 합불·새 검사주기 생성 제외.
- 별도 제공근거·민감정보 처리·제3자 제공조건 확인, 최소 입력·사건별 권한·로그/캐시/파기 검토.
- 가명 연구자료 결합과 개인의 자격 판정 자료 분리. 추가 정보가 실제로 검토 품질을 개선하는지 비교 후 범위 확정.
- M01·M02는 추가 확인 필요 대상의 누락·과잉의뢰 지표. 기능 저하 확정·법정 적부·사고위험 정확도로 해석하지 않음.
- 5개 평가 지표의 기준선·목표와 예산·인원·기간 미확정. 실제 독립 전문평가·임계값 합의 전 성과 보장 제외.

## DRT 연속 요청 반영

`src/drt-scope.cjs`의 동일 경계를 DRT 본문·분석·비용·실행 검토에 연결. 현재 범위는 접수조건 이해·배차 예외·운영계획 고도화. 정산감사·부정수급 판단·환수·전국 예산배분은 현재 납품·대가·핵심 성과 제외.

기존 정산·감사 아이디어와 원래 그림은 미선정 후속안으로 보존. 관련 표 행·그림 설명에 제외 문구를 붙이고 상세 블록을 기본 접힘으로 표시. 기존 원본과 업무 원장·HWPX의 재작성은 수행하지 않음.

## 배포·롤백

현재 사용자의 사이트 작성·배포 지시와 저장소 재공개 승인에 따라 main → Actions → Pages 경로 사용. 공개 QE 본문 앵커와 내려받기 URL을 배포 후 확인. 배포 결과는 Actions와 공개 `version.json`으로 검증하며 로컬 검사 통과만으로 완료 처리하지 않음.

롤백은 이번 커밋을 revert 후 동일 Actions로 재배포. 기관 운영 시스템·공식 검사 기준 변경 없음. 잔여 현업 확인 질문은 공개 후보의 5개 질문으로 연결.
