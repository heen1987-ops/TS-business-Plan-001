# 47번 근거 기반 제안의 요구사항·검수 명세화

작성일: 2026-09-25
상태: 로컬 제안·설계 검토 완료. 공고 매핑·실제 제품/API 확인·현업 수용·효과검증 전.

## 목적·범위

- 대상: 기존 13개 처의 47번 근거 기반 대표 제안.
- 문제: 근거와 업무흐름만으로는 개발범위·검수방법·측정 원천의 연결을 확인하기 어려운 상태.
- 목적: 업무 4단계별 기능요구, 입력·산출물, 모듈·화면·데이터, 정상/결손 시험, 운영 지표의 추적성 확보.
- 방법론: 공공사업의 요구사항 추적과 단계별 검토를 적용한 점진 구현. 근거 정본·기존 조직 축·기존 요구사항 원장 보존.
- UI: 기존 여섯 장 연속 스크롤 안의 ‘정량효과·도입·검수’ 절 확장. 페이지 분할·새 대분류 추가 없음.
- 외부 변경: 배포·push·Pages·워크플로 변경 없음.

## 독립 검토와 보완

1. 지표 ID만 연결된 상태를 지표별 수집계약으로 확장.
   - QE-R02: 표준질문·허용 응답·채점기준·독립 채점자·참여/불참 분모.
   - PS-R03: 운영요청·완료 여정·포기 이동 표본조사의 원천과 분모 구분.
   - IP/RD-R03: 사람별 활동 시작/종료·일시정지·동시작업 배분. 단일 이벤트 시각으로 시간 추정 금지.
2. AD의 로그 부재를 미시도로 확정하던 반례 수정.
   - 수집 범위·완전성·시각 확인 전 요청기록/시도 여부 미확인 유지.
   - 적격 분모 보존, 지연 로그 도착 시 판본·상태·집계 정정 이력 보존.
3. 근거 일괄 배치 수정.
   - 단계별 연결과 배경/직접 연결/확인보류 역할 구분.
   - RD-E28은 확인보류 표시로만 연결하고 기능 정당화 evidenceRefs에서 제외.
   - IP-E18의 2차 보도 인용 및 검토 비고 유지.

독립 읽기 전용 재검토 판정: 합격. 필수 보완 3건 해소, 추가 필수사항 없음. 판정 범위는 명세·표시·내보내기 일관성이며 실제 서비스 성능·법적 적합성 인증이 아님.
