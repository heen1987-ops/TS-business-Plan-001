# 업무 효율화 AX와 국민서비스 AX 분류 정정

사용자 정정에 따라 감리 AI·AI PMS·회의·조치·일정 관리를 업무 효율화 AX로 분리했다. 검사소 Agent·DRT 및 기존 10개 서비스군은 국민서비스 AX에 유지했다. NOA와 공통 엔진은 두 축이 공유하는 기반이며 세 번째 사업축이 아니다.

2026 구축 기반을 재사용하며, 2027 업무 운영정착과 국민서비스 설계, 2028 구축, 2029 고도화를 연간 범위로 제안한다. 기관 확정계획·실제 AI 제품 구현·실측 성과를 표시하는 변경이 아니다.

## 변경과 검수

- 홈과 기획 작업공간: 두 축의 직접 사용자, 적용업무, 검수관점, 연차를 공통 데이터에서 표시.
- AI PMS 상세: 감리 AI의 원문·판본·효력·증거·주차·공학 규칙·시정·독립 확인을 9개 추가 개발과 10개 제안 검수로 연결.
- 3개 컨셉 비교표: 사업축 추가, PMS 개발·원가·연차를 AUD 식별자로 통일. 공식 감리·검사·인수·지급 상태를 AI 점검과 구별.
- 기존 NOA와 동일 계약 납품분은 제외하고 설치본·계약·사용권 대조가 필요한 상태를 보존. 공통 작업은 한 번 계상.
- 금액 워크북·내부 원문·개인 경로는 공개 배포에 포함하지 않음.

## 검증 기록

- `npm ci --no-audit --no-fund`: 통과.
- 최종 `npm test`: 종료값 0으로 통과. 최초 검사에서 빠진 기존 공식 감리·지급 경계를 복구하고, 과거 기능 ID를 AUD 식별자 검증으로 갱신한 뒤 전체 재실행 통과.
- 두 축 브라우저 검사: 1440/768/390px, 분류·키보드·10군·연결·가로 넘침·오류 29개 항목 통과. 최초 한 번의 로딩 시간초과는 독립 재현에서 발생하지 않았고 전체 재실행 통과.
- 기존 AI PMS 브라우저 회귀: 74개 항목 통과. 다운로드 내용 대조·목차·인수/지급 경계 포함.
- 독립 내용·설계·공개 경계 검토: 합격. 원가 귀속·검수기간·이전 버전 미완료 문구 수정 확인.
- 실제 현업 검증, 운영 성능시험, 법정 감리 대체 가능성 검증은 수행하지 않음.

## 배포와 복구

사용자의 테스트 후 git push 승인에 따라 해당 변경만 선택 커밋하고 정상 push한다. 기존 작업 저장소에 준비된 다른 UI 변경은 포함하지 않는다. Actions 성공과 공개 `version.json`의 커밋을 대조한다. 복구가 필요한 경우 이 선택 커밋을 되돌리는 새 커밋과 정상 Pages 배포를 사용한다. 임의 병합·강제 push는 수행하지 않는다.
