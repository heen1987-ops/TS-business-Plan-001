# 처별 상세 설명·설문 v0.3 재구성

- 작성일: 2026-10-06
- 대상: `research-library.html?view=survey`
- 문제: 다섯 줄 요약·공통 질문만으로 처별 업무 맥락과 기술적 해결방법 파악이 어려운 상태. 구버전 자료·도구용 파일이 현행 읽기 흐름에 혼재.
- 산출물: 51개 조사 대상 조직, 55개 주제의 상세 설명과 현업 확인 질문. 43개 검증 가설·12개 수요 탐색 주제이며 신규사업 수 또는 공식 전체 업무분장 수가 아님.
- 적용 방법: 업무 경계 분석·BDD·회귀검증·읽기 전용 독립 검토. 주 실행자 한 명의 파일 수정.

## 사용자 흐름과 수용기준

`조사 목적·NOA 설명 → 내 처 선택 → 업무별 상세 설명 → 현업 의견 확인 → 최신 설문지·빈 회신 양식`

| 절 | 반드시 읽을 수 있는 내용 | 구현·검증 연결 |
|---|---|---|
| 1. 업무·목적·근거 | 처리단위·대상자·시작조건·식별정보, 필요성, 확인된 내용, 출처·원문 위치·날짜·적용 한계 | survey-briefing / SurveyDesign / 상세 설명 정적·브라우저 검사 |
| 2. 현행·병목 | 확인 내용과 검증 가설, 입력·공식 결과, 현장에서 확인할 누락·반복 사례 | 업무별 briefing과 원자료 대조 |
| 3. CCK 기술·처리 | 단계별 입력·처리·출력, NOA·aRDa·정형 도구·전문가 역할, 인수 시나리오·공식 완료조건 | 주제별 흐름·경계·단계 필드 검사 |
| 4. 실행·개인정보 | 최초 실증·연계 조건, 수집·이용·승인·실행·보관·폐기, 중단·예외·사람 전환 | 분야별 제한·조건 검사 |
| 5. 효과·측정 | 산식·필요 기록·비교방법·결측 및 오류 처리. 기준선·목표값은 미확정 유지 | 기존 지표 필드 보존·null 검사 |
| 6. 현업 의견 | 병목 정합성·별도 의견·실제 사례·필요 증거. 조사대상에 맞는 질문 | 15개 검증 질문 또는 3개 탐색 질문, 공통 역할 질문은 첫 주제 한 번만 표시 |

- 한 처의 주제 전체를 연속 스크롤로 열람. 주제별 작은 페이지 전환 제거.
- 업무 설명을 역할 질문보다 먼저 배치. 선택 처 한 개만 표시.
- 주제 이름·가설 상태를 제목과 각 절에 유지. 심사·정책·개인정보의 공식 권한은 사람·기존 원장에 유지.
- 현재 자료실에는 선택 처의 최신 상세 설문 MD와 빈 회신 CSV만 표시. 정의 JSON·CSV와 구버전 링크는 현재 화면에서 제외.
- v0.2의 158개 빈 산출물은 public 경로에 보존하여 과거 공유 URL 유지. 새 산출물은 v0.3 경로 사용.
- 모든 회신값은 null 또는 빈값. 홈페이지에서 회신을 저장·제출하거나 TS 시스템에 실행하지 않음.

## 분야별 보완

- EX 28개: 최신 부서별 제안의 처리단위·공식 완료·기술역할·실증 조건을 연결. 최신 검토의 보류·권한 확인 조건 보존.
- 모빌리티 DRT: 전화/대리 접수·조건 확인·제약 계산·기사 수락·단일 확정·변경/운행·일/주간 운영계획의 7단계. 전화번호의 본인인증·GPS 대체 금지. STT/TTS·CTI는 별도 역량 검증 대상. 감사·부정 확정·환수·전국 예산배분 제외.
- 고령자 검사: 허용된 기존 결과와 기능평가의 연계 검토. 건강보험 원자료 직접 연계·AI 진단·합격 판정 제외. 기관 권한·실제 의료/평가 책임 확인 필요.
- 12개 수요 탐색: 업무·자료·예외를 확인할 질문과 증거를 먼저 제시. 미확인 병목에 솔루션·정량 목표를 선배정하지 않음.
- 독립 검토에서 발견한 ESG 고객경험, 디지털기획 ITSM, 운영지원 정보공개, 보안 시정, 자산 변경·인수, UAM 직무·역량의 맥락 불일치 수정.

## 제한·운영·롤백

- 이 결과는 홈페이지 설명과 조사 준비물 검증. TS 현업 회신·전체 직무분장·설치 기능·연계 권한·모델 성능·실제 효과 검증이 아님.
- 출처의 기존 확인 날짜·원문 위치·한계를 함께 표시. 파생 자료의 과거 검증을 이번 재검증으로 승격하지 않음.
- 기준선·목표·최종 가격은 확정하지 않음. 비교는 현행 A / 비AI 또는 기존 기능 B / 추가 NOA 적용 C를 구분.
- ResearchBay 실제 제품·등록 양식·개인정보 설정 미확정. 등록·외부 전송·회신 수집 미실시.
- 이번 상세 산출물은 MD·빈 CSV. 기존 HWPX는 보존하며 새 한글파일을 생성했다고 표시하지 않음.
- 배포 권한: 사용자의 기존 commit/push/Pages 즉시 배포 요청 적용. main 전용, 다른 자료 브랜치 병합 없음.
- 공개 검증: 해당 commit의 Actions 성공 → version.json 일치 → 공개 브라우저·다운로드 검사. 실제 결과는 루트 작성 기록에 누적.
- 롤백: 이번 commit을 되돌리는 별도 commit으로 main에 push하여 Pages 재배포. 과거 v0.2 파일 보존. 이력 강제 변경·파일 삭제 없음.
