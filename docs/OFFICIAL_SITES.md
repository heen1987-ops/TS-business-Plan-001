## 운영·보안·접근성

- 정적 공개 데이터만 사용. 별도 인증·API·DB 변경 없음.
- TS 외부 사이트는 새 창, noopener noreferrer 적용. 새 창 안내 텍스트 제공.
- 사용자 입력은 React 문자열 렌더링. HTML 삽입·원격 코드 실행 없음.
- 원문 URL 확인과 사이트 전체 운영·로그인·업무처리 검증 구분.
- 공식 통합회원 로그인 경로는 공개 GET 200 확인. 로그인 수행 없음.
- WCAG 전항목 적합성 인증을 주장하지 않음. 키보드, 포커스, 모바일 넘침을 작업 범위에서 점검.
- 31개 공식 목록 항목을 독립 검토자가 원HTML 본문으로 재집계하여 누락 0 확인.
