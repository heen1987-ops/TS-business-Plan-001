2026-10-07 / 기존 main 기준 2180996 / 내부 기획 초안 검토

## 1. 문제·범위·방법

- 문제: 업무의 필요성과 제품 적용방법·인수기준·산정 근거의 연결 부족, DRT 처리 순서 및 ERP 초기/후속 범위의 설명·그림 불일치
- 산출물: 처별 연속 본문의 개발 설계, 실제 MD·JSON 다운로드, 이미지 교정, 요구·연계·시험·대가 추적 및 검토 기록
- 대상: TS 업무·정보화 검토자와 CCK 기획·개발 담당자
- 규모·위험: M / Medium / 근거 대조 + Stage-Gate + 요구 추적 + 회귀 검증
- 시간축: 2027 단년도 후속 AX+SI 편성 검토. 5개년 NPU 계획·독립 R&D 편성 제외
- 가정: TS 현업 회신 없음. 설치본·API·자료 이용권·실측 효과·최종 수행가격 미확정
- 성공기준: 처 선택 유지, 한 본문에서 업무→HOW→시험→산정 입력 연결, 본문·이미지·다운로드 범위 일치, 미산정·미검증을 확정값으로 표시하지 않는 상태
- 기존 native 한글 문서 156개 및 이전 도식 버전 보존. 이번 작업은 기존 HWP/HWPX의 본문 재작성·Hancom 실행 검증이 아닌 현재 기술 설계의 MD·JSON 추가

## 5. 개발 설계 구성과 대가 경계

- 현재 39개 기획 연결 조직의 42개 과제에 개발 후보 8개씩, 총 336개 처별 요구 작성
- 공통 요구 5개 및 코어 개발 3개는 공통 1회 관리. 42개 독립 사업 또는 336 FP의 의미 아님
- 처별 2개 읽기·인계 인터페이스, 7개 증분 WBS, 3~5개 지표, 고유 업무 키·자료·전문도구·판정자·반례를 기존 원장으로 연결
- QE-01·DV-01·EX21-01·EX22-01 독립 편성 보류 유지. 전체 사업 선정·발주 범위 미확정
- 실제 입력서식·필드·규칙·접점·예외·시험량·사용권·견적 확보 후 기능량/활동량 산정. 요구·프롬프트 수를 FP/MM으로 환산하거나 미산정 금액을 0원으로 기재하지 않는 기준
- 기존 서버·로컬 LLM 활용, 신규 하드웨어 구매 제외, 비전·센서·차량 제어 제외. 사용권·검증·운영·통신 비용의 무상 주장 제외
- 이미 납품·계약된 동일 기능 공제. 계약에 포함되지 않은 Agentic OS 공통 확장 후보는 별도 확인하며 모든 처에 중복 계상하지 않는 구조
