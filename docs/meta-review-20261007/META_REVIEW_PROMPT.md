# TS 2027 사업기획 사이트 메타리뷰 프롬프트

- 검토 대상: main 기준 2180996, 현행 처별 제안·42개 과제·도식·근거·탐색 구조
- 검토 목적: 읽는 사람이 사업 목적, 적용 업무, 구현 수단, 담당자 역할, 효과 검증을 연결할 수 있는지 평가하고 실제 수정으로 연결
- 작업 규모: M / 위험도 Medium / 근거 대조·Stage-Gate·회귀 검증 적용
- 가정: TS 현업 회신과 제품 운영 실증은 아직 없음. 공개 사이트는 기획 제안이며 운영 시스템이 아님.

## 공통 검토 지시

**아래 주장을 반박하라.** 새 기능을 제안하거나 문구를 미화하는 데 앞서, 원자료·코드·화면에서 주장과 어긋나는 사례를 찾는다. 세 검토자는 같은 여섯 주장을 독립적으로 평가하고, 담당 관점에서 구체적인 결함을 추가한다. 파일은 수정하지 않는다.

1. 목적·목표·수단이 구분되며, 현재 업무의 근거가 AI 추가 필요성까지 입증한 것처럼 서술하지 않음.
2. NOA·aRDa·Grantee의 역할이 제품 근거 수준에 맞으며, 설계 후보를 실제 배포 기능으로 표시하지 않음.
3. 기구축 AI 플랫폼 재사용과 추가 개발 범위가 구분되며, 수동 업무에 존재하지 않는 연계 도구를 기구축 기능으로 가정하지 않음.
4. 서비스·데이터·전체 아키텍처와 설명의 처리 순서 및 사람의 결정 역할이 일치함. 특히 DRT는 기사 수락 전 배차 확정을 표시하지 않음.
5. 기대효과는 측정 대상·자료·계산·비교 조건과 연결되며, 미측정 효과를 검증된 성과로 서술하지 않음.
6. 처·과제 선택을 유지하며 연속 본문으로 읽을 수 있고, 시스템 용어와 반복 안내가 핵심 업무 설명을 가리지 않음.

## 증거 수집

- 읽기 범위: src/proposal-business-language.cjs, proposal-e2e-diagrams.cjs, proposal-intent.cjs, ProposalDiagramSuite.jsx, IntegratedReader.jsx 및 연결 원자료. 저장소 AGENTS.md와 src/AGENTS.md 적용.
- 내용은 정본/공식 원자료/기획 가설/미검증 구현으로 구분. 출처 제목만으로 원문 검증 완료로 처리하지 않음.
- 업무 존재와 병목 존재, 법적 수행 권한과 데이터 접근 권한, 제품 설명과 TS 구현 완료를 구분.
- 공통 모듈 재사용이 적절한 곳과 과제별 차이가 사라진 곳을 구분. 정형문구의 반복 개수만으로 사업 가치 판단 금지.
- 필요한 브라우저 관찰: MR-02, MR-01, QE-01 및 추가 대표 과제. 데스크톱과 모바일, 처 선택과 뒤로 가기, 본문과 이미지의 일치 확인.
- 원문이 확인되지 않은 경우 '입증 부족'으로 기록. 반증 근거가 없는 것을 사실상 거짓 또는 업무 부재로 확대하지 않음.

## 출력 형식

각 주장에 CONFIRMED / PARTIALLY_CONFIRMED / REFUTED 판정과 범위·증거를 기록. 결함은 다음 형식 사용.

`ID | 심각도(P1/P2/P3) | 발생 위치(파일:줄/화면) | 현재 내용 | 사용자·사업 영향 | 원문/재현 증거 | 최소 수정안 | 검증 방법 | 불확실성`

- P1: 업무 순서·권한·근거의 오해로 사업 범위나 타당성 판단을 바꾸는 결함.
- P2: 과제 이해·구현 경계·탐색·가독성을 방해하는 결함.
- P3: 의미를 바꾸지 않는 일관성·표현 개선.
- 검토자가 실제 읽은 파일/확인한 화면만 범위로 보고. 전체 42개 원문·이미지 검증을 하지 않았다면 전체 완료 주장 금지.

## 메타리뷰 종합 규칙

- 다수 의견은 보완 우선순위의 참고로 사용. 모델 합의는 사실·실증·기관 승인 증거가 아님.
- 의견 불일치는 삭제하지 않고 원문과 재현으로 해결. 수정 채택은 책임자가 독립 대조한 증거에 따름.
- 실제 결함 → 수용기준 → 구현 → 회귀 검증의 연결 유지. 검토자의 추상적 권고만으로 사이트 전면 재작성 금지.
- 리뷰 프롬프트·투표·평가 기록은 docs/에 보관. 사이트 본문에는 업무에 도움이 되는 내용만 반영.
- 서류 원본과 기존 버전 보존. 메타리뷰만으로 한글 계획서 수정·제품 실증·법률 검증 완료를 주장하지 않음.
