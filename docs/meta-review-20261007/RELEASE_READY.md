# TS 2027 개발 설계 릴리즈 준비

2026-10-07 / 기존 기준 2180996 / 공개 반영 후보

- 사용자 권한: 작성 후 홈페이지 배포·저장소 공개·Git push·Actions 사용의 기존 명시 승인 유지
- 변경 범위: 42개 기획 과제의 현재 개발·검증·대가 설계, 처별 연속 본문 및 MD/JSON 84개, DRT 서비스·ERP 서비스/데이터 v4, 메타리뷰 및 회귀 검사
- 상태: 로컬 검증 통과, GitHub Actions의 최종 실행결과·공개 버전/파일 확인은 배포 후 확인 대상으로 분리
- 보존: 156개 기존 한글 문서·이전 도식·73개 경로·51개 처별 탐색. 다른 브랜치 병합·이력 재작성 없음
- 보류: 기존 독립 편성 보류 4건 유지. 공식 RFP 수령·기관 선정·현장 구현·효과·가격 확정 아님
- 회귀: npm ci와 npm test(46개 검사 경로) 통과. 업무 설명 브라우저 352항목, 도식 브라우저 626항목 통과. 신규 개발 설계 브라우저 521항목(배포 후 커밋 확인 추가) 검증
- 자동 배포: 기존 `.github/workflows/pages.yml`의 push(main) → npm ci → build → check → upload → Pages 경로 유지. 인증·보안·워크플로 권한 변경 없음
- 확인: 배포 후 version.json의 커밋 일치, 84개 새 MD/JSON의 실제 HTTP·로컬 바이트 일치, 3개 교정 PNG의 SHA256, 처별 화면·모바일 탐색 확인
- 관측: React 실행 오류·깨진 링크·파일 수·활성 도식·배포 크기 검사. 외부 원출처 사이트의 가용성은 TS 사이트 배포와 별도
- 복귀: 이번 릴리즈에 회귀가 확인되면 보존된 이전 버전의 해당 파일/변경을 `git revert` 방식으로 되돌리고 같은 빌드·배포·HTTP 검증 수행. 공개 Git 이력 삭제·강제 push 없이 복귀
- 운영 인계: 기획 사이트 변경과 실제 TS AI 플랫폼 개발·실행 권한은 별개. 실제 후속 사업의 기관 운영/인수·지원 책임은 본문의 단계·조건에 따라 별도 확정

릴리즈 성공은 GitHub Actions 실행결과 및 공개 HTTP 검증으로 확인하며, 이 준비 문서 자체를 실제 배포 완료 증거로 사용하지 않음.
