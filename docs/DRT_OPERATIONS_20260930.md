# DRT 전화 접수·배차·운영계획 전환 반영
작성: 2026-09-30 · 대상: B08-G / drt-assurance.html

## 문제와 적용 범위
- 사용자 정정: 지역 택시조합 담당자가 연락을 직접 받고 기사를 직접 배정하는 수동 운영의 전환과 운영계획 최적화가 핵심.
- 현장 의견의 조합·지역·수동 비중·실제 시스템은 미확인. 전국 조합이나 TS 공식 조사결과로 일반화하지 않는 기준.
- 제안 제목: 택시조합 전화 접수·배차·운영계획 AX.
- 정산 검증은 운행 뒤의 후속 모듈로 유지. 기존 감사 수치·보호 통제의 근거는 보존.
- 다른 13개 처 대표안과 기후탄소물류처 상세 이미지 3개 유지.
- 사이트는 설명·검토 자료. 실제 자동 배차 시스템의 개발·연계·운영 완료를 뜻하지 않음.

## 방법론·수용기준
- 유형: 기존 제안·시각 자산·탐색 경로 개선 / 규모 M / 웹 변경 위험 Medium.
- 방법: 영향분석 + 요구사항 추적 + 실제 브라우저 검증 + 독립 읽기 전용 리뷰.
- 순서: 사용자 정정 → 현행 공식 기능 대조 → 운영 설계 → 모델 이미지 생성·오류 수정 → 화면/다운로드 반영 → 정적/브라우저 QA → 배포.
- API·DB 변경 없음. 실행되는 UI는 기존 React, 시각 자산은 이미지 모델 PNG. 확대·alt·HTML 동등 설명 동반.
- 수용: 전화 운영 중심의 첫 화면, 일반건 자동 처리와 예외 인계, 기사 수락·잠금·확정의 구분, 미충족 수요를 포함한 운영계획, 후속 정산 분리.
- 불필요한 별도 제품 목업·새 라이브 배차 API·전면 UI 재구축 생략. 기존 연속 문서 구조 유지.

## 주요 정량효과·측정
1. 이용요청당 담당자 수동 처리시간: 접수·확인·기사 연락·재배정 활동시간 / 고유 요청.
2. 당일 요청 대기시간: 연결/접수·배차 확정·실제 승차의 구간별 중앙값·P90. 미완료 비중 병기.
3. 약속 시간 내 이동 제공률: 승인 범위 요청 중 합의 시간창 내 실제 승차 비율.
4. 서비스 공차 이동 비율: 서비스 근무시간 공차 거리 / 총 이동거리. 제공률·접근성 악화 시 단독 합격 금지.
5. 수요·공급 불일치: 구역·시간대별 필요 차량시간과 계획 배치시간의 부족·과잉. 모형의 추정 한계 공개.

기준선·목표 null 유지. 현행 수동 A, 정형 SI·최적화 B, B+NOA C를 비교하고 개인정보·자료권한·공급·계절 변동을 통제. 잠재수요·미배차 누락으로 개선폭을 부풀리지 않는 기준.

## P01~P07 연결
- P01 국민 편익: 전화 접근성·약속 내 이동·이용조건 유지.
- P02 현업 수용성: 일반 반복 처리 감소, 예외·이동지원에 시간 재배치. 감원 환산 없음.
- P03 AX+SI: NOA와 음성·규칙·최적화·원장 연계, 비AI 대안 비교.
- P04 TS 업무 접점: 공식 DRT·TIMS와 모빌리티연구처 공개 안내. 개별 위탁·운영권은 확인 대상.
- P05 확장성: 공통 과업·연계 재사용, 지역 정책·권한·조건은 분리.
- P06 기관·권한: TS·지자체·조합·기사·CCK의 책임 구분.
- P07 필요성·책임·재정: 근거와 가정 구분, 제약·성과 측정, 기존 계약·추가 기능·비용 확인.
