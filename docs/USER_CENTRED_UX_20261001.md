# 사용자 중심 탐색 재구성 · 2026-10-01

## 문제와 결정

상단 메뉴·왼쪽 읽기 순서·본문 목차의 서로 다른 분류, 홈의 장문 설명, PMS에 집중된 조직 검토·39처 문서·공통 기술 설계로 인한 목적 혼재 개선. 사실·근거·문서의 변경 없이 화면 책임과 진입점 재구성.

- 처음 방문: 홈의 기관 정의 → 기관 이해·2030 목표 → 조직·업무.
- 제안 검토: 처별 제안 목록 → 처 검색·소속/작성 상태 선택 → 필요성·해결방법·설계·효과·근거 연속 열람.
- 자료 확보: 문서 자료실 → 처 검색 → 정보화사업계획서·대가산정서·도식집 직접 다운로드.
- 기술 검토: 공통 플랫폼 → 스킬형 PMS의 방향·아키텍처·실행·평가. 전체 처 매핑과 공식 조직 대조는 목적별 별도 보기.

## 수용기준

1. 같은 6개 큰 메뉴와 같은 이름을 상단·전체메뉴·왼쪽 메뉴·현재 위치에 적용.
2. 홈에서 기관 설명, 처별 제안, 한글 자료, 공통 플랫폼으로 각 1회 이동.
3. 51개 공식 본사·연구원 처와 39개 문서 연결 처, 미작성 12처의 상태 구별. 전국 설치 처 총수로 해석 금지.
4. 39처·42기획·117HWPX·319설계 링크의 손실 없음. 기존 해시·query 직접 주소와 뒤로/앞으로 보존.
5. 기본 PMS 화면에서 조직 대조표·전체 문서 목록 혼재 제거. 해당 목록의 독립된 보기와 기존 직접 주소 호환.
6. 검색·빈 결과·초기화·필터 상태와 키보드 초점 표시, 모바일 메뉴 닫힘·Escape·초점 복귀 확인.
7. 390·768·1280·1600px에서 가로 넘침·본문 잘림 없음. 본문 내부 고정 높이/페이지 분할 금지.
8. 실제 API·로그인·운영 PMS를 구현한 것처럼 표시하지 않음. 초안·미산정·미검증·판본 상태 유지.

## 범위와 가정

React 표현층·탐색 데이터·홈·처별 목록·문서 자료실·PMS 보기와 검증만 변경. 업무 원장, 법령 판단, 가격, 문서 판본, 실제 기관 시스템·개인정보·외부 호출 변경 없음. 기존 승인에 따라 검증 후 main → GitHub Actions → Pages 배포.

## 검증과 롤백

기존 전체 정적·내용 보존 검사, 새 사용자 여정 브라우저 검사, 대표 상세·조직 지도·PMS·문서 매핑 회귀, 화면 캡처 비교 수행. 기존 주소와 자료 원본의 해시·수량은 변경하지 않음. 문제 발생 시 이번 커밋 revert 후 동일 Actions로 재배포. 실제 사용자 인터뷰 및 WCAG 인증은 이번 검증으로 대체하지 않음.

## 사용자 인터랙션과 접근성

- 처별 목록: q·scope를 URL에 보존, 뒤로가기·새로고침 시 결과 복원. 빈 결과와 초기화 제공.
- 상세 읽기: 내부 고정 높이와 페이지 분할 없음. 기존 해시·query를 해당 본문의 최신 설명으로 연결.
- 메뉴: 현재 영역과 현재 문서 목차 분리, 모바일 열림 상태에서 Escape 닫힘·초점 복귀.
- 검색: 네이티브 dialog의 모달 초점 관리, 제목·조직·문서 유형 선택, 결과 한 개일 때 Enter 이동.
- 파일: download 이름 유지, 자료실·처별 상단·검색의 동일 원본 연결.
- 반응형: 390·768·1280·1600px, 키보드 초점·메뉴 닫힘·앵커 위치 확인. 실제 스크린리더·사용자 인터뷰·WCAG 인증은 별도 검증 대상.
