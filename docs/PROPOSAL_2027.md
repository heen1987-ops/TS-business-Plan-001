# TS 2027 조직 네이티브 AI 제안서 초안 공개본

작성일: 2026-10-15 · 제안서 v0.1

## 목적과 내용

TS 2027의 1차 AI 플랫폼 고도화를 조직 네이티브 AI 구축으로 제안한다. 홈페이지의 사업 범위·일정·검수 요약에서 기존 조직형 설계와 제안서 전문으로 이동한다.

- 공식 부서·직무·업무 매핑 → 기존 기능 대조 → 추가 개발 → 검수 증빙.
- 공통 기반 12개 개발·검수 연결과 W27-A·B 우선 검토, C·D 조건부 선택.
- 최대 9개월, M2 설계·평가 합의 / M5 시범 / M7 인수 준비 / M9 인수.
- 기존 NOA·설치판·사용권의 확인된 기능 재사용, C27-COM 차분 단일 귀속.
- 미확정 공고·사업비·실제 착수일·평가 목표, 실제 구현·기관 자료 접근 미검증 표기 유지.

이는 공고 대응 전 제안 초안이며 사업 승인·계약·실제 운영 검수 완료를 뜻하지 않는다.

## 정본과 파생 문서

- src/ts-2027-proposal.json: 작성한 제안서의 148개 Markdown 블록, 13개 절. 공개 내용만 저장.
- src/proposal-2027.cjs: 원문 표에서 범위·일정·개발·시험을 추출하고 기존 원장의 ID와 연결한다.
- src/Proposal2027.jsx / src/proposal-2027.css: 요약 화면.
- scripts/export-proposal-2027.cjs: 같은 정본으로 Markdown·인쇄용 HTML·UTF-8 BOM CSV 생성.
- scripts/check-proposal-2027.cjs: 전문 보존, 원장 연결, 다운로드 일치와 공개 경계 확인.

작성한 제안서 전문의 기술 범위와 검수 기준을 보존했다. 공개 문구 중 “수주 또는 선정 이후”는 “계약 체결 이후”로, 근거 원장의 “사용자 요구와 제공된 TS 협의 요약”은 “조직 중심 사용자 인식 요구와 연계 검토 요약”으로 정리했다. 개인 Page 계정·블록 ID·공유 메타데이터는 복사하지 않았다.

공통 스킬 근거: CCK-Public-basic b6dc237의 CCK-GROWTH-Skills. 기존 TS 기획 근거: 16bbcd8의 annual-work-2027 / growth-ai / growth-org-rollout. 제안서 13절에 원문 링크와 판본을 보존한다.

## 검증 범위

npm ci 및 npm test, 로컬과 공개 브라우저의 데스크톱·모바일 표시, 목차·다운로드 응답, Actions와 version.json의 배포 판본을 확인한다. 사이트와 문서의 검증이며 TS 원천 연계·권한·AI 성능의 실제 검수와 구분한다. 실제 결과는 공개 배포 완료 후 작업 보고에서 확인한다.

로컬 브라우저 확인: 데스크톱 1280px·모바일 390px에서 가로 넘침 없음, 홈→제안서 이동, 목차의 동일 절 반복 선택, 품질 기준 펼치기, 전문 13절·23표·구성도 12노드 확인. 브라우저 오류 로그 0건. 내려받기는 IAB의 완료 이벤트 수신 제한으로 버튼 저장 완료를 확인하지 못했으며, 3개 파일의 HTTP 200과 배포 산출물 바이트 일치로 별도 검증했다. 인쇄용 HTML은 문서 열람·구성도·목차·인쇄 스타일을 확인했으며 실제 프린터 출력은 수행하지 않았다.

## 2026-10-16 조직 기반 우선 개정

1차 사업을 TS 조직 네이티브 AI 플랫폼 구축·인수로 재편했다. W27-A~D는 후속 적용 후보, C27-COM은 ON27-BASE 단일 귀속이며 조직 기반 인수 후 업무효율화·국민서비스를 별도 확장한다. 상세 변경과 검증 계약은 [조직 기반 사업 구조](ORG_PLATFORM_2027.md)를 따른다.
