# 법령·현행 업무·담당 처 연결 보완

작성일: 2026-10-08. 대상: 2027년 TS 후속사업기획 검토 사이트. 법적 권한·추가 발주·현업 효과의 확정과 구분.

## 문제·수용기준

- 기존 법령 화면의 39처·42과제 선택 목록과 최신 통합 본문의 51처·54제안 간 불일치
- 실제 담당 처의 링크 부재, 담당 역할과 제안 주관의 혼합 가능성
- 무선택 법령 화면·잘못된 주소의 기본 MR 과제 표시
- 기존 27개 대표 법정업무·36개 수행관계 보존, 추가 4개 KATRI 업무안내 분리
- 51처 선택·54제안 정방향/역방향·과제 단독 주소의 본문/헤더 불일치 0건 목표
- 법령 업무의 담당처 클릭 시 무관한 첫 제안의 자동 선택 금지
- 담당업무 관찰과 법적 위탁·내부 전결·기획 적용관계의 구분

## 구현·근거

- `law-department-connections.cjs`: 통합 읽기 정본·문제별 기획 정본·공식 직원검색·기존 법령 원장의 명시적 관계 연결. 처 이름만으로 위탁관계 추정 금지
- `LawDepartmentContext.jsx`: 처별 공식 업무 → 관련 법령·기관 역할 → 목적·CCK 방법 → 상세설계의 연속 읽기. 담당 처·상위조직·제안 ID 링크 표시
- B09 세부업무: 결함정책·결함조사1·결함조사2·안전도평가(KNCAP) 분리. 결함조사1·2 사건 배정·독점 분장 미확정 유지
- B14 플랫폼·B19 기반시설: 담당 처 미확정 유지. 제안 주관처로 수행처 대체 금지
- 추가 업무: 자동차 기술검토·실차 안전검사·건설기계 형식승인/신고·확인검사. 공식 KATRI 업무안내 4건 및 현행 건설기계관리법 시행령 제18조의3 직접 대조
- 건설기계 안내의 과거 시행령 제18조의2와 현행 제18조의3 구분. 타워크레인 예외·검사 결과 통지와 최종 등록의 구분
- 법령업무 링크 `dept + binding`: 특정 제안 미선택. `dept + project`: 명시 제안 선택. `project` 단독: 정확한 처 추적. 잘못된 처·과제: 재선택 안내
- 공식 업무 정본의 소속 불일치·파견 경고를 원문 위치와 연결하여 화면·MD·JSON에 보존. 확정유보 관찰의 담당 증거 승격 금지
- 기존 HWPX·이미지·RFP·대가·업무/사례 자료 보존. 최신 처 연결 MD·JSON은 빌드에서 단일 생성

## 배포·복구·제한

- 기존 사용자 승인에 따른 main 커밋·푸시·GitHub Actions/Pages 적용. 실제 배포 커밋과 `version.json`, 공개 URL 검증은 릴리즈 결과로 확인
- 롤백: 해당 UI·연결 모델 커밋 revert 후 기존 Pages 워크플로로 재배포. 기존 법령/제안 정본·원문 파일·Git 이력의 삭제 없음
- 51처·54제안은 탐색 대상이며 모든 처별 위탁·전결의 확정 건수 아님. 현재 대표/추가 업무와 개별 적용관계가 없는 28제안은 별도 근거 추가 확인 대상
- 공개 직원검색 관찰은 업무 기재 근거. 현행 전체 법령·직제·위임전결·운영계 데이터 권한의 확정 또는 현업 인터뷰 완료와 구분
- KATRI 추가 12처의 후보 등록과 한글 계획서·대가산정·첨부문서 3종 실제 작성 상태 분리
- 보안: 직원명·전화번호 제외된 기존 정본만 이용. 신규 인증정보·개인정보 수집 및 외부 시스템 변경 없음
