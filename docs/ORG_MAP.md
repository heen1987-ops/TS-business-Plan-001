# 조직 기반 메인 연결지도

- 목적: TS 조직 계통에서 처별 업무·AX 제안·근거·정량평가·요구사항으로 이동하는 탐색 중심 메인
- 범위: 기존 조직도·업무 원장 기반 69개 탐색 노드, 상세 제안 13개 처, KATRI 3개 적용안
- 숫자의 의미: 69개는 이 자료의 탐색 항목 수. TS 전체 공식 조직 수 또는 신규사업 수와 구분
- 가정: 제공 조직도와 기존 기획 원장 활용. 현행 직제·전결·전체 분장 확정표가 아닌 탐색용 구성
- 기존 상세 페이지·법령 원문·39개 측정명세 유지

## 탐색 설계

1. 메인에서 TS → 본부 → 실·센터 → 처 순서로 단계별 이동
2. 현재 위치의 상위 조직·하위 조직을 연결선으로 표시
3. 처의 말단 노드는 컨셉·서비스 흐름·아키텍처·근거·효과·요구사항의 실제 링크로 전환
4. 검색 대상: 조직명·제안 제목·목표·기존 시스템·상위 조직
5. URL의 node 값으로 경로 공유·새로고침·뒤로 가기 지원
6. 모바일에서 연결선이 있는 세로 계층으로 전환. 동일 링크·순서 유지
7. 목록 보기와 폴더 목차·슬라이드 안내를 대체 탐색 경로로 유지

## 조직·관계 표현

- 실선: 기존 자료의 조직 계통
- 점선: 탐색 묶음·업무 적용안·자료 연결
- 이사장 직속과 감사(비상임) 계통 구분
- 자동차안전연구원과 첨단자동차검사연구센터 구분
- 지역·현장은 탐색 묶음이며 독립 본부로 표시하지 않음
- KATRI의 기술검토·부품·국제기준 항목은 조직명이 아닌 적용안
- 미연결 처에는 상세 제안 미연결 상태 표시. 업무 부재로 해석하지 않음
- 협업 링크는 기존 제안의 partner 필드에 상대 처가 기재된 경우만 연결. 공식 업무분장과 구분

## 실행·배포

- 기본 검사: npm run check
- 브라우저 검사: npm run check:map-browser
- 브라우저 사전조건: Playwright와 Edge 사용 가능 환경. PLAYWRIGHT_MODULE로 설치된 Playwright 모듈 지정 가능
- SITE_BASE 환경변수: 로컬 또는 배포 URL. 기본값 http://127.0.0.1:8768/
- API·개인정보·데이터 저장·거래 기능 변경 없음
- 롤백: 이번 변경 커밋 revert 후 기존 GitHub Pages 워크플로 재배포
- 확인 범위: UI 탐색 및 기존 자료 연결 검증. 현행 공식 직제 확인이나 실제 업무 편익 실측과 구분

## 검증 기록

- 기능 검증: 13개 처의 6종 자료, 39개 지표 링크, 검색·빈 결과·키보드·뒤로 가기·미등록 URL·목록 전환 확인
- 시각 검증: 1600·1280·390px 화면 확인, 긴 명칭 30개 조합(1280·1024·981·768·640px) 경계 검사
- 수정 이력: 문서용 CSS의 메인 폭 충돌, 탐색 관계 표시, 긴 명칭의 카드 밖 넘침 수정
- 환경 이슈: OneDrive의 디렉터리 엔트리 타입 오인으로 검증 실패 발생. lstat 기반 확인으로 수정하며 실제 심볼릭 링크 차단 유지
- 데이터 검증: 69개 탐색 노드·191개 연결 자료 주소·13개 처, 순환·고아 노드 없음
- 효과 검증의 한계: 위 검증은 탐색 UI 검증이며, TS 업무성과 또는 사용자 조사 결과가 아님

- 최종 판정: 독립 읽기 전용 리뷰 합격. 필수 보완 0건, 브라우저 시나리오 검사 175건 통과. 현행 직제 전체·WCAG 전체 인증 판정과 구분.
