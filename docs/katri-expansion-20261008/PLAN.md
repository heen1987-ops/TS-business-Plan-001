# 자동차안전연구원 미연결 12처 솔루션 확장

- 작업 유형: 기존 기획·처별 탐색 기능 확장
- 규모·위험: L / Medium. 정적 기획 사이트 변경이며 실제 업무·ERP·시험장 제어 없음
- 방법론: Stage-Gate, 요구사항 추적, DDD 업무경계, BDD 탐색·다운로드 검증
- 문제: 공개업무 조사 12처가 통합 화면의 과제 선택·솔루션 본문과 연결되지 않은 상태
- 산출물: 12처별 구체적 솔루션 후보, 업무별 하위 기능, 기술·데이터·인터페이스·개인정보·측정·검증·편성 명세, 추가 공식 출처, 개별 MD/JSON
- 대상: TS 현업·기획·정보화 담당자, CCK 설계·개발 담당자
- 성공기준: 51처 탐색 보존, 기존 42과제 및 39처 한글 문서 보존, 신규 12처 후보 직접 선택·주소·목차·내려받기 가능, 공개업무 전 항목에 기능·산출물 연결
- 가정: 기존 로컬 LLM·서버 활용, 신규 장비·비전·차량 제어 제외, 실제 API·제품 버전·성능·현업 수요 확인 전
- 신규 후보 수와 사업 계약 수의 구분: 12개 처별 적용안이며 공통 기능 재사용. 12건 독립 발주 제안 아님
- 법령·조직: 공개 담당업무와 법정 권한·위임전결 구분. 원문 효력·담당 처 전결 미확인은 유지
- 요구/판정: 효과 기준선·목표값·FP·MM·가격은 null 유지. 미확인을 0 또는 효과 없음으로 대체 금지
- 재사용: 연구기획·연구지원은 기존 TS AI PMS 스킬 확장. 결함조사1·2 공통 사건검토 엔진, 처별 가설·증거 스키마 분리
- 변경: 보충 정본 추가 및 integrated-reading/IntegratedReader 연결. 기존 39처·42과제·117종 한글 문서 원문 변경 없음
- 사전 검토: 공식 업무가 있다는 이유만으로 병목·구매수요를 확정하지 않음. 기존 자동화·예약·리콜 시스템의 중복 신설 제외
- 테스트: 신규 데이터/출처/전 업무 대응/미산정/개별 다운로드 검증, 12처 실제 브라우저 선택·앵커·반응형·오류, 기존 전체 npm test
- 릴리즈: 기존 사용자 자동 배포 승인 적용. root만 쓰기·커밋·배포. 이전 정상 커밋을 기준으로 변경 취소·재배포 가능
- 독립 검토: 조사 담당의 1차 출처 재확인 및 별도 산출물 리뷰. 실제 TS 인터뷰·제품 기능시험 미수행을 명시
