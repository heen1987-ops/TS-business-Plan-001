# TS 공식 조직·담당업무 기반 매핑

2026-10-16 · 기획 제안 · 내부 업무분장·전결·실제 연계 미확인

TS 2027의 1차 구축은 조직 기반을 인수하는 사업이다. 공식 공개 조직·담당업무를 먼저 연결하고 조직별 직무·맥락, 수행·검토·승인·협업 역할, 별도 권한정책과 변경 이력을 검증한다. 업무효율화·국민서비스는 그 이후 별도 범위·예산·검수로 연결한다.

## 정본과 공개 화면

- `src/ts-org-evidence-20261016.json`: 공식 직원안내 227개 조직 노드, 76개 조직 조회에서 선별한 294개 업무 문장, 원문 페이지·확인일·행 위치. 이름·직위·연락처는 저장하지 않는다.
- `src/ts-department-mapping.cjs`: 76개 상세 매핑, 역할 원칙, 12개 대표 협업 계약, ON-W01~06 구축 묶음, GAI-R01~12↔GAI-T01~12 연결.
- `src/DepartmentMapping.jsx`: 검색·유형 선택, 공식 근거와 제안의 구분, 구축·검수·CSV 연결. `proposal-2027.html#department-mapping`에서 열고 홈·GROWTH AI 공통 구조에서 바로 연결한다.
- `src/proposal-2027.cjs`: 정본을 제안서 3.5~3.6에 삽입한다. 상세 표는 원문 JSON에 중복 저장하지 않는다.
- `scripts/export-department-mapping.cjs`: Markdown, 매핑·협업·검수 CSV, 전체 구조·근거 JSON을 빌드 시 `dist/downloads/`에 생성한다.
- `scripts/check-department-mapping.cjs`: 원천 참조·코드·협업 끝점·요구/검수·범위·제안서·내려받기 일치와 개인 연락처 제외를 검증한다.

## 이번 관측의 차이

공식 직원안내에 AI혁신처 하위 AI서비스개발팀(1019700)이 있고 TS AI GPT 운영·고도화 업무가 이 팀으로 표시된다. AI혁신처는 AI·데이터 기획, 공공데이터 및 데이터기반행정 업무가 관측된다. 2026-10-08의 226개 노드 보존본과 다른 관측이며 신설일·이관 시행일을 확정하지 않는다. 오래된 공식 업무 연구 화면은 해당 관측일의 이력으로 보존한다.

예산처의 조직담당·조직관리, 인재개발처의 인사, 디지털기획처의 통합 운영·계정관리, 정보보안처의 보안 업무를 원천/운영 책임 협의의 근거로 삼는다. 사업 총괄·개인별 역할·전결권은 기관이 별도로 지정한다. 개인정보보호 업무는 디지털기획처와 정보보안처 양쪽에서 관측되어 사례별 책임 경계를 확인한다.

## 범위와 한계

기존 74개 처 기획에 AI미래전략실과 AI서비스개발팀을 추가한 76개 상세 설계다. 전체 227개 노드의 전수 업무분장 확정이나 전 조직 동시 구축을 뜻하지 않는다. 76개 설계 행의 대표 업무 문장을 선별했으며 각 부서의 모든 업무를 전사한 것이 아니다.

공개 검색 조직코드는 내부 인사·SSO 키와 동일하다고 가정하지 않는다. 검사소의 직원안내 parentCode와 분사무소 조직도 표시선은 별도 정보다. 상하관계·협업·직책을 접근권한으로 사용하지 않는다. 개별 승인자는 내부 전결·위임 확인 전까지 미확정으로 남긴다.

M2에 실제 대상·물량·원천·평가셋·목표를 합의한다. 6개 구축 묶음은 기존 12개 요구사항을 한 번씩 배정하며 비용은 C27-COM/ON27-BASE에 한 번만 귀속한다. 12개 검수 시나리오는 제안이고 실행 결과가 아니다. 사이트 검사 통과를 기관의 AI 플랫폼 검수 통과로 표현하지 않는다.
