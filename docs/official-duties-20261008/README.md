- 총괄: 원문에 명시된 총괄을 유지, 하위 처리행위·전결을 임의 생성하지 않는 기준
- 지원: 실제 지원 문구와 지원센터·연구지원처 등의 조직명 분리. 분석문자열에서만 조직명을 제외
- 파견: 실제 기재 업무 보존 및 수행주체·담당기간 별도 표시. 4개 단위의 직접 제안 연결 유보
- 소속 대조: 주차안전처의 경기남부본부 총괄, 첨단검사전략처의 경남본부 총괄, 항공자격처의 자동차검사업무 총괄3건 원문 보존·대조 표시. 과거 담당·겸직·갱신 여부 미확인
- AI미래전략실: 등록조직 데이터에는 존재하나 공식 하위선택에서 제외. 직접 업무행 미표시 및 강제 조회 제외
- T.F팀: 하위 등록항목32개에 위원회·추진단·TF 포함. 현재 활동·구성·기간·예산·발주 확인과 별도
