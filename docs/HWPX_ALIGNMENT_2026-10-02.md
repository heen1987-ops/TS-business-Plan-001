# 처별 시행계획서 v0.5 개정·게시

- 작성일: 2026-10-02
- 목적: 2027년 웹 편성 검토와 39개 처의 한글 시행계획서 본문 정합성 개선
- 상태: 기관 협의용 초안. TS 확정 사업계획·계약·예산·제품 구현·실측 성과와 구분

## 개정 범위

39개 처·42개 기획항목의 시행계획서 39개를 v0.5_r01로 작성. 현재 열람 문서 117개는 계획서 v0.5 39개, 대가산정서 v0.3 39개, 도식집 v0.3 39개로 구성. 이전 계획서 v0.4 39개를 별도 보존하여 전체 게시 파일은 156개.

1. 목적·사용자·처리단위·필요 자료·해결방식의 육하원칙 명세
2. 유지·통합·축소·보류 등 13개 처의 최신 편성 판단 반영
3. 추가 26개 처의 기존 업무·가설·기술 HOW·요구사항 연결
4. DRT의 수동 전화접수·기사 배정·운영계획 개선 우선, 정산 검증 후속 기능 구분
5. 사업별 3~5개 지표의 산식·분모·결측·기준선·A/B/C 대조·검수 포함 시간·평가 책임 명시
6. 실측 없는 개선율·표본수·기간·공수·대가를 확정값으로 승계하지 않는 기준
7. 기존 로컬 서버·LLM 활용, 신규 인프라 구매 0원 조건, 공통 기능 1회 산정 및 처별 차분 검토

기존 기술계약·요구사항·출처를 재구성했으며, 출처의 기존 확인일을 이번 원문 재열람일로 바꾸지 않음. 신규 문제 가설 6개를 독립 구축사업으로 추가 확정한 작업도 아님.

## 그림·이전판

계획서에 기존 2.5D 컨셉, 전체·실행 아키텍처, 서비스·데이터·개인정보 흐름, 기술 HOW 도식 총 294개 내장. 이미지 모델 신규 생성 없이 v0.2~v0.4 도판을 재사용하고 캡션에 판본·조건부 설계 상태 명시.

기존 v0.4 파일의 경로·바이트·SHA-256 유지. 최신 다운로드 3종은 기본 표시, 이전 계획서는 접힌 목록에서 제공. 파일별 GitHub 보기·원본 다운로드 유지.

## 검증·한계

- 39개 한글 재저장 후 본문 문단 보존, HWPX ZIP/XML, 그림 해시, 이전 원본 불변 대조
- 13개 처 최신 목적·편성 상태와 한글 본문의 일치, DRT 별도 목적의 회귀 검사 추가
- 대표 PDF 5개 전쪽의 빈 페이지·본문 경계 이탈 자동검사 및 선택 페이지 시각검토
- 39개 문서의 모든 페이지를 사람이 수동 검수한 것은 아님
- 현업 자료·제품 설치판본·원장 API 실행·기관 전결·실측 효과·최종 대가 검증은 별도
- 대가산정서·도식집 v0.3은 이번 범위의 확정 산정·운영 구성으로 사용하지 않음

조판 검수에서 발견한 DRT 사업코드 오연결과 빈 페이지를 수정하고, 제목과 다음 본문이 분리되지 않도록 문단 속성 보정. 게시 전 최신 상태·다운로드·무결성 검사 대상으로 전환.

실행 결과: `npm ci`와 `npm test` 통과. 한글 문서 검사 25,272개 항목 통과, 현재 117개·이전 39개 총 156개 파일의 저장소 등록·빌드 바이트·SHA-256 확인. 브라우저 검사 3종 각각 221·297·463개 항목 통과. 최신 계획서·대가산정서·도식집과 이전 계획서의 클릭 다운로드 4건, 검색·키보드 이전판 열기·모바일 가로 넘침·실행 오류 검증. 데스크톱 및 모바일 화면 캡처 시각 확인 완료.

위 결과는 문서와 사이트 배포 후보에 대한 검증이며, 제안한 업무 솔루션의 현업 실증 결과가 아님. 공개 사이트의 파일 응답은 배포 완료 후 별도 검사 대상.

## 검증 명령과 복구

`npm ci && npm test` 이후 `check-department-documents-browser.cjs`, `check-document-publication-browser.cjs`, `check-pms-document-mapping-browser.cjs` 실행. 배포 후 `check-document-publication-http.cjs`로 현재 117개·이전 39개 전체 HTTP 수신 바이트와 SHA-256 대조.

검사 항목의 파일 수를 117개에서 156개로 확대한 이유는 이전 v0.4의 링크와 원본을 보존하기 위함. 현재판 117개 검사는 유지하고 보존본 39개에 동일 구조·해시·경로 검사를 적용.

복구는 해당 개정 커밋을 되돌린 뒤 재배포하는 방식. 이전 v0.4 원문은 이번 커밋에서 변경하지 않으며 기존 다운로드 주소 유지. 재발 방지를 위해 웹 목적·DRT 별도 매핑·현재판/이전판 상태를 정적·브라우저 검사에 포함.
