## 문제·설계

사업별 주키는 project.id. ISP·대가·구현·PMS·한글 정본을 연결해 39처/42후보/117현재파일을 계산. 공식 조직 대조 51처/미작성12와 분모 구분. 모든 선정 값 false, 금액·기준선·목표 미확정 유지. 한 처의 여러 사업은 통합 서류를 공유하며 고유 파일 수를 중복 합산하지 않음.

홈: 목적/상태 → 기관 배경 → 4단계 진입 → B00 및 B01~B04 → 42후보 조회 → 확인할 사항 → 자료실. 조회용 검색·필터·펼침이며 사업을 선정하거나 실행하는 입력 기능 아님. 검색 입력의 실시간 후보 필터와 제출 버튼의 처별 목록 이동을 명시.

기획 본문: 동일 문서 안에서 ISP/묶음·대가/실현성/이전 검토의 4영역으로 구분. native details와 전체 펼침 제공. 기존 해시·뒤로/앞으로·새로고침은 상위 details를 먼저 열고 해당 절로 초점·스크롤 이동. 고정 본문 높이·내부 스크롤·자료 삭제·추가 소페이지 없음. 인쇄 시 전부 펼침 후 상태 복구.
