현재 읽기 화면: `research-library.html?view=survey`. 구성 변경과 검증 이력은 [SURVEY_UX_20261006.md](SURVEY_UX_20261006.md) 참조. 아래는 기존 문항·내보내기 작성 기준이며 내용 유지.

- 요청: 현재 프로젝트·NOA 등 CCK 솔루션과 AX 확대 방향을 서두에 설명한 후, 조사된 병목의 정합성·타당성·별도 의견·현업 불편·대국민서비스 개선 의견을 작성하는 양식.
- 시간축: 2027년 처별 후속사업 편성. 기존 인터뷰 준비 v0.1과 제품·계약 범위 원장은 보존.
- 설계 방법: 근거 대조 → 설명과 가설 분리 → 응답 필드·분기 설계 → 정본 기반 내보내기 → 독립 검토 → 내용/화면/다운로드 검사 → Pages 배포.

## 서두 근거와 적용 한계

- 기존 TS 맥락 문서: 2026-09-09 파생 문서 분석. AI 공통플랫폼 고도화·민원·전세버스 공시 AI 구축의 설명. 최종 계약·검수·설치·처별 실사용 완료 직접 확인으로 사용하지 않음.
- [CCK 공식 NOA 소개](https://www.ccksolution.com/noa): 2026-10-06 열람. 폐쇄망 자체 LLM·문서 이해·근거 연결·작업 지원·사람 검토 방향에 대한 공급사 설명. TS 실행·품질·규범준수 인증·효과 실측의 근거로 승격하지 않음.
- Agentic OS 추가제안: 2026-09-22 사용자 회신상 계약/기술협상 미포함. 계약 원문 직접 대조 미완료 표기 유지.
- aRDa·Argus·Keeper: 기존 제품 설명·분석자료의 재사용 후보 역할. 실제 build·사용권·API·권한·복구는 전문 보충지 S01~S04로 확인.
- DRT는 기존 발주의 자동배차·관제·정산 등을 재개발하는 제안과 구분. 전화 조건 이해·예외·운영계획 차분 검토. 감사·부정수급 판단·환수·전국 배분은 현재 범위 제외.
- QE-H01은 기존 기능검사·허용 의료 기능 결과부터 검토. NHIS 원자료 연계 초기 전제와 AI 의료/자격 합불 제외.

## 파일 책임·도구 전환

- `src/survey-design.cjs`: 서두·제품 역할·26필드·선택지·분기·51처/55주제 매핑의 정본.
- `src/SurveyDesign.jsx`, CSS: 연속 스크롤 문항 미리보기·처별 찾기·빈 양식 다운로드. 실제 회신 제출 폼 없음.
- `scripts/export-survey-design.cjs`: 공통 5 + 처별 51×3 = 158개 MD/CSV/JSON 생성.
- CSV 정의: 문항ID·처·주제·질문·단일/복수/서술형·선택지·표시조건·조건참조 범위·배타 선택코드·작성 안내·출처·확인 수준.
- CSV 회신: 답변 상태·답변값·근거·제약·회신일·검토 상태·기획판단의 빈 필드.
- 조건 참조는 동일 처·동일 주제 안에서 해석. NONE/NO_NEED/UNKNOWN 배타 선택코드를 전달.
- 사용자가 언급한 리서치베이/ResearchBay를 고려한 도구 중립 정의서. 정확한 서비스·공식 가져오기 규격·개인정보/보관 설정·실제 등록·발송 미확인. 자동 가져오기 성공을 주장하지 않음.

## 독립 검토와 보완

- 근거·사업 경계 리뷰: 필수보완 없음. 서두 상태와 한계 주석을 UI/MD에서 함께 제공하는 인수조건 유지.
- 응답 설계 리뷰: 처별 MD에 공통 응답 문항이 선행·반복되는 문제 1건 발견. 설명만 반환하는 함수를 분리하고 서두→응답배경→병목/의견→추가의견 순서로 수정.
- 다중 주제 조건 참조 혼선과 배타 선택 누락 가능성에 대한 권고를 반영. 분기 범위/코드 CSV 추가.
- 회신은 의견·경험·기록·추정으로 구분하여 대조. 동의율·평균·합계만으로 병목 규모·효과·수요·발주 확정 금지.
