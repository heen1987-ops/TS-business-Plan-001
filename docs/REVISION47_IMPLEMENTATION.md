## 사실·측정의 보정

- 공개 원장 529건은 제공 자료의 항목 수. 이번 사이트 작업에서 529개 원문 전체를 재검증한 수가 아님.
- 법령상 절차 존재와 실제 기록 공백, 날짜 공란과 위법 행위, 선별 점검 적발률과 전체 위반율을 구분.
- IP-E18: 언론의 정부 발표 인용을 2차 출처로 표시.
- RD-E28: 연결된 2025년 시행판과 2027년 시행 주장의 불일치. `UNKNOWN` 및 사용 보류 설명. 표시용 사실 등급·목록·JSON에 동일 반영.
- MR 보급 수치의 당시 기준일, QE·SI·RI 수치의 제공 원장 집계 성격과 재집계 미수행, SI 사유 표준화 수치의 추가 확인 상태 명시.
- 기존 39개 E 지표의 예시 기준선·목표 수치 표시 철회. 새 39개 R 지표와 구분. 기준선 확보 전 목표 미설정.
- AD-R01: 사전 적격 차량×필수항목을 분모로 적용, 미시도·미지원 포함.
- IP-R02: 전체 정상 집단의 오탐률로 부르지 않고 ‘점검 후보 중 정상 확인 비율’로 정의.
- PS-R03: 여정 도달시간과 미충족 요청 비율 분리. 이동 포기 조사와 운영요청·추정 수요 구분.
- 현행 A, 규칙/SI B, B+NOA C의 비교 설계. 실측 전 개선율·금액·인원 감축 수치 산출 없음.

- 의존성 재현: `npm ci`.
