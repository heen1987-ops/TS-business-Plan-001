## 검토·검증 기준

1. 모든 이미지에 원문·발행기관·게시일·이용조건·대체텍스트 연결.
2. 파일 해시 대조로 다운로드 원본과 저장본 일치 검증.
3. 데스크톱·태블릿·모바일에서 비율 유지와 가로 넘침 검사.
4. 키보드 원본 열기, 로드 실패 시 기사 대체경로, 재시도 복구 확인.
5. 전체 빌드·정적검사와 기존 연속 읽기 브라우저 회귀검사.

GTV 버스교육 기사는 대표사진과 본문 실습장면의 동일성을 확인할 수 없어 미사용. 인천 사진은 원본 크기 316px를 넘겨 확대하지 않음. TS 홈페이지의 일반 저작권 안내를 전체 사진의 자유이용 허락으로 해석하지 않음.

배포 중지 상태 유지. 로컬 검토본만 갱신.

- `npm ci` 및 최종 `npm test`: 통과. 새 사진 원본·출처·본문 연결 검사 29건 통과, 내부 깨진 링크 0건.
- 실제 Edge 브라우저 사진 검사: 91건 통과. 1600·1280·768·390px에서 이미지 로드·비율·출처·가로 넘침 확인, 키보드 원본 열기와 실패→재시도→포커스 복구 확인.
- 기존 연속 읽기 브라우저 회귀검사: 126건 통과, 실행 오류 0건.
- 시각 검토: 1600px·390px 실제 화면 확인. 데스크톱 사진/설명 병치, 모바일 순차 표시, 잘림 없음.
- 읽기 전용 독립 검토: 출처·역할·본문 회귀 관점 합격. 재시도 후 키보드 포커스 소실 권고를 반영하고 브라우저로 복구 확인.
- 발견·수정: 로컬 preview가 JPEG를 application/octet-stream으로 반환하여 원본 링크가 다운로드로 처리됨. image/jpeg 응답 추가 후 새 창 열기 검증 통과.
- 범위 한계: 전체 스크린리더·전 사이트 접근성 인증을 수행한 결과가 아님. 사진은 현재 업무를 설명하는 자료이며 AX 성과 실증 자료가 아님.
