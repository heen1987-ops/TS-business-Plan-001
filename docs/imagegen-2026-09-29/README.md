## 운영·제약·롤백

- 이미지마다 원본 확대가 필요할 수 있는 작은 보조 문구 존재. 모바일에서 모든 글자를 축소 이미지 안에서 읽도록 강제하지 않고 동등 HTML 설명 제공
- 원문 사실·법령·업무분장은 이번 이미지 제작만으로 재검증한 것으로 승격하지 않음
- API·쓰기 권한·CCK 배포본 구현범위·서버 가용량은 상세설계의 확인 대상 유지
- 기존 서버·로컬 LLM 전제 유지. 새로운 인프라·비전·자동 행정처분·자동 안전판정 도입 주장 없음
- 이번 변경은 정적 설명 사이트. 실제 TS 업무시스템·개인정보 저장·외부 AI 호출에 영향 없음
- 롤백: 이 변경 커밋만 되돌려 기존 SVG 표시 복원. 앞선 상세설계·근거·메뉴 구성 커밋은 유지
- 재발방지: 실제 PNG 형식·해시·해상도·39종 고유성·제안 예시 표기·페이지 로딩 검사를 자동화
