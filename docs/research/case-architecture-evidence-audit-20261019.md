`src/case-architecture-evidence.cjs`의 네 분류는 **그림의 출처 방식**일 뿐 근거 신뢰도나 운영 단계의 등급이 아님. 현행 `case-source-figures.json`은 원문 이미지 23개를 10개 원천 사례 ID에 연결. 상세 화면의 `PF-A12`는 `AX06`의 그림을 별칭으로 상속하므로 그림을 보여주는 화면 엔트리는 11개. 원본 그림이 11개 사례에서 독립 확보된 것은 아님. 3개 이미지 모델 재구성은 RFP 설명의 시각화이며 원문 도면 아님. `PF06`의 공식 API 문서로 확인되는 것은 공개 API 계약이지 서버 내부 구조 아님.

전체 조사원장 `src/case-catalog.json`의 2,637행(국내 110, 해외 2,527)은 2개 책자·인벤토리의 **후보 색인**. 같은 사업의 중복 가능성, 키워드 기반 전략 후보, 원 사업별 RFP·원문 배치도·현재 운영 검증 부재. 따라서 이번 **상세 근거 전수**의 분모는 심층 57개 엔트리. 2,637행을 분석·검증 완료한 사례 수로 합산 금지.

## 원문 도식의 단계·성격 교정

1. `PF-R03-01`과 `PF-R06-01`: RFP에 수록된 **기존 시스템 현황**. 후속 AI 플랫폼 목표 배치도라는 인상 차단 필요.
2. `PF-R04-01/02`: 과업내용서의 H/W·S/W **예시**. 계약 발표와 실제 설치 형상 동일성 미확인.
3. `PF-R08-01/02`: **사전규격** RFP의 대민·내부 서비스 구상. 공급사 계약 발표와 최종 RFP·준공 설계 동일성 미확인.
4. `PF-R02-01~04`: 본공고 RFP 목표 도식. 2026년 서비스 개시 발표는 존재하나 RFP 도식의 실제 구축 재현 증거 아님.
5. `PF07-01~04`: Bürokratt Common-Knowledge 저장소의 문서화된 설계·시퀀스. 특정 참여 기관의 운영망 배치도 아님.
6. `AX05-01~04`: DeepMind가 설명한 운영 제어 단계. 개발사 공개 내용이지 독립 현장감사·TS 물리 제어 효과 아님.
7. `AX06-01`: 2025년 공개 베타 C4 기술기록. `AX06-02`: 별도 2023년 파일럿 ADR. 두 시점의 모델·저장소·서비스 계층을 한 배치도로 합성 금지.
8. `PF-R07/PF-R09/PF-A03`: RFP를 바탕으로 생성한 이미지와 CCK 논리 설계를 명시적으로 분리. RFP 부속 그림 전수 점검의 부정 판정은 **그 패키지에 한정**. 외부 전체에 도면이 없다는 주장 금지.

현재 `src/case-architecture-evidence.cjs`는 그림 존재만으로 `원문 도식`을 반환하므로 목표·현황·예시·공식 운영 도식이 같은 배지로 묶임. `figureRole`(`existing`/`target`/`example`/`official-architecture`/`sequence`)과 `phase`(`RFP`/`pilot`/`beta`/`published-operations`)를 별도 표시할 필요. `PF-A12`의 별칭 그림 재사용 또한 `forCase`와 상세 화면의 집계 차이 교정 필요.

## 구조 도출의 허용 범위

57개를 하나의 공통 구현으로 합치지 않고 다음 **분석 유형**으로 묶을 수 있음: ① 문서·민원 RAG와 사람 확정, ② 조직·권한·업무 앱 연결, ③ 공개 안내와 공식 처리의 분리, ④ 센서·영상 위험 분석과 현장 조치, ⑤ 자동 산정·보고의 감사·재심, ⑥ 공통 모델/API와 현업 업무팩. 이는 위 R/T/O/A/S/V 근거에서 도출한 **CCK 비교 설계**이며 제3자 내부 서버 구조의 관찰 결과가 아님. 각 유형은 원천→정규화·판본→정책·검색/분석→사람 판단→공식 업무 상태→평가/환류의 공통 질문으로 비교하되, 원문이 없는 단계는 `추론` 표시 필요.

남은 미확인: 57개 제3자 시스템의 설치 형상·실시간 트래픽·숨긴 품질 평가셋·실제 병목 계측값·보안 권한 집행·운영 비용·성과의 인과관계. TS/CCK에 적용할 때의 병목은 원천/설계에 기초한 **검증 후보**이며, MyCity 감사·NHTSA 보고 누락 등 공개 조사 결과와 같은 관찰 사실로 섞지 않아야 함.
