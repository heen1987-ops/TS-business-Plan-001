## 목적·범위

- 사용자 요구: 정량 기대효과의 측정방법 및 근거 명확화
- 범위: 기존 13개 처의 39개 지표, 지표별 4개 설명 구역
- 기존 목표·원 산식·증감 유형 유지
- 상태: 공고 미매핑 기획 초안, 기관 확정·실측 성과와 구분
- 방법: 업무별 관측 정의 → 비교설계 → 증빙·판정 → 통계 해석 → 웹 검증
- 가정: 기존 시스템의 원장·타임스탬프 제공 가능성은 현업 확인 전
