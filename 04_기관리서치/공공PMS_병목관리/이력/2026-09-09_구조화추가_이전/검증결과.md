# 공공 PMS 조사 검증 결과

검토일: 2026-09-09. 이번 검증은 조사 문서와 근거 연결의 자체 검토다. 독립 평가위원·기관·법률전문가의 승인이나 제품·AI의 실증 성적을 뜻하지 않는다.

## 수행한 검증

- `python -X utf8 검증_조사.py`의 문서·출처·보존 무결성 검사 13개를 통과했다. 자세한 결과는 [검증결과.json](검증결과.json)에 기록했다.
- 출처 16개 ID·필수 필드와 보고서 인용 참조, P01~P07, 후속 대기열 12개를 확인했다.
- UTF-8 문서, 로컬 링크 대상, 공개 HTML 13개와 취득 SHA-256을 확인했다.
- 핵심 법령 보존본에서 인용 조문·시행일 표식, 국세청 PMS·만족도와 제품 기능 표식을 확인했다. 표식 존재는 문서 전체의 현행성·진실성을 자동 판정한 결과가 아니다.
- 기존 포트폴리오·기관관계 원장의 해시는 연결문서 편집 직전과 같다. 해당 원장에는 신규 후보를 추가하지 않았다.
- 보고서의 사실/가설, 공급사 설명/실증 성과, 국내/미국 제도, 기관 도입/기업정보 공유, TS 내부 수요/범정부 운영 권한을 구별하는지 자체 내용 검토했다.

## 발견·보완한 사항

| 항목 | 보완 내용 | 남은 한계 |
|---|---|---|
| 기존 기능과의 중복 | 국세청 SLA·사용자 만족도와 국내 PMS 승인·변경관리 기능을 비교표에 반영 | 실제 TS 기능·계약과의 대조 미완료 |
| 동적 법령 열람 누락 | 국세청 공식 HTML 본문을 직접 조회·보존 | 2024판 이후 연혁 대조 미완료 |
| 검색 발췌의 일부 조문 | TS 제6조 제6호 링크 대신 전체 제6조를 재열람 | 정관·전결·실제 수행조직 미확인 |
| 감리 전문성 일반화 | 사용자 우려와 공식 자격 경로, 실제 전문성 검증을 분리 | 자격 별표 현행 연계·교육요건 전체 및 감리품질 실태 미검증 |
| 평가·일정 수치 오용 | 효과·가격·기간·배점 확정값 없이 실증 설계와 미정 조건 표기 | 현장 자료·비용 견적·평가 기준선 미확보 |
| 후속 항목 추적 | 보고서 실행 순서에 PMS-Q11~12의 현행성·국민 효과 보완도 연결 | 실제 후속 조사 미수행 |

## 판정

- **문서·출처의 참조 무결성: 통과.** 자동 검사 범위에 한한다.
- **조사자 기획 검토: 조건부 합격.** 실제 문제와 자료를 확인하는 다음 조사에 활용할 수 있다.
- **TS 신규사업 선정·본구축·공식 기업평가·기관 간 공유: 보류.** 수요·권한·기존 과업 중복·AI 추가 가치·국민 효과가 미검증이다.
- **독립 평가·법률검토·제품 데모·실제 사용자 조사·AI 실증: 미실시.** 사용자 관점 내용은 내부 시나리오 검토이며 실제 사용자 검증을 대체하지 않는다.

문서에 Mermaid 관계 구조를 포함했으나 UI나 이미지 자산을 제작한 것이 아니다. Mermaid 렌더링·웹 접근성·반응형 시각 QA는 이번 검사 범위가 아니다.

## 방법론·완료 범위

근거 기반 비교 조사와 업무흐름 분석으로 문제 정의→자료 확인→대안·실증 설계→자체 검토→기록을 수행했다. 생성 산출물은 조사보고서, 출처원장·목록, 후속 대기열, 공개 근거 보존본과 취득·검증 기록이다. 기존 원본 프로젝트는 수정하지 않았고 외부 연락·데이터 업로드·유료 API 실증·배포는 수행하지 않았다.

다음 반복주기 입력은 PMS-Q01~04의 수요·계약·기존 기능·실제 병목 자료다. 재사용할 교훈은 ‘일정·만족도·AI 추가 자체를 신규성으로 주장하기 전에 기관 규정과 기존 제품의 구체적 기능을 확인한다’이다. 전역 지침은 변경하지 않았다.
