# 설계 계속 결과 v1.1

2026-09-10. [공공 PMS 병목 관리](https://chatgpt.com/c/6aa098d5-82b0-83e9-81af-668c665dc3b4) 최신 추가내용 반영.

## 결론·변경

- 사용자 발언 21건을 페이지 3개에서 확인했다. 이전 15건의 ID·문구 일치를 검사하고 새 6건을 포함한 보존본을 작성했다.
- **Y1 AI-PMS → Y2 감리 검사엔진 → Y3 레퍼런스·성과환류**를 최신 방향으로 채택했다. 실제 달력연도·예산·기관 승인으로 확정하지 않았다.
- B1 기준설정, B2 수행·Evidence, B3 검사·사람 검토를 개발 연차와 구분하고 상태·예외·버전·권한·화면·API 계약 초안으로 구체화했다.
- 주기적 다면평가의 기초 수집은 Y1, 종합 활용은 Y3에 둔다. 직접 담당·검토·중간관리·최종 결재·업무부서·사용자·전문가의 관찰 범위를 분리했다.
- 우수·미흡 수행은 근거·실제 책임·소명·정정과 연결한다. 무이력·관찰 불가를 저성과·0점으로 취급하지 않고 공식 입찰 가감점과 내부 참고를 구별했다.
- 기존 17개 기능의 연차를 재배치했다. 요구사항은 기존 원장 R01~20을 보존하고 설명자료의 확장 원장 R21~33으로 연결했다.
- 대화 AI가 제시한 독립 R&D 분류, 확인하지 않은 조달제도 세부·임금·효과 계수, 고정 평가 가중치를 확정 사항으로 채택하지 않았다.

## 검증·판정·한계

요구 추적·BDD·단계별 검토를 적용해 내용 대조 → 설계 → 설명 HTML/MD 구현 → 브라우저 검사 → 시각검토 → 모바일 보완 → 재검증을 완료했다. 제품 기능은 구현하지 않았으므로 상세설계의 PMS-AT 시험은 향후 실행할 초안이다.

Microsoft Edge / Playwright 70개 검사 통과. 원문·원장 보존, 3개년 선택·키보드·인쇄·JS 비활성, 7단계·계산·음수·오류 입력, 문서 링크, 반응형과 외부 요청 부재를 확인했다. 9종 현재 화면과 이전 아키텍처 화면을 직접 검토했다. 시각 자체평가 37/40.

자체 QA 판정은 설명자료 범위 **합격**이다. 독립 평가위원은 참여하지 않았다. 실제 사용자·스크린리더·기관 환경 검증, 운영 PMS·AI·감리 성능·경제성·법적 적용의 판정은 미실시다.
