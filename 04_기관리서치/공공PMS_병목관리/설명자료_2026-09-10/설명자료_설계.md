# 설명자료 설계·수용기준

작성일: 2026-09-10 / 대상: CCK Public AI-PMS 설명용 HTML·Markdown·SVG  
작업: M / Low / 근거 기반 문서 구성 + 사용자 흐름 중심 구현 + 브라우저 자체 QA

## 문제와 산출물

사업 검토자가 긴 대화를 다시 읽지 않아도 도입 이유, 공동 처리, CCK 검사엔진, 감리의 두 경로, 편익 가정과 후속 검증을 설명할 수 있도록 한다. 실제 업무를 처리하는 PMS는 이번 구현 대상이 아니다.

산출물: 독립 HTML 1개, 대응 Markdown 1개, 편집·인용 가능한 SVG 1개. CSS·JavaScript·데이터·생성 스크립트는 편집용 원본으로 보존한다. 이미지 생성은 정확한 한글과 구조 연결이 필요한 목적에 맞지 않아 사용하지 않고 SVG로 직접 작성한다. 공개 배포·업무자료 업로드·인증·서버는 불필요하므로 만들지 않는다.

## 화면 구조와 이용 흐름

- EX-01 설명자료 본문: 목차 → 도입 이유 → 기능 → 공동 처리 → 감리 → 아키텍처 → 편익 → 도입 단계 → 근거.
- EX-02 단계 설명: 7개 단계 선택 → 담당자·AI 역할·기록·시험결과서 예시.
- EX-03 편익: 업무량·감소율·추가 부담·단가·비용 입력 → 순시간·가치·연환산 차이 → 가정 확인.
- EX-04 공유·인쇄: Markdown·SVG 다운로드 또는 인쇄. HTML 자체는 단독 열람하며 연결 파일은 같은 폴더에서 제공.

와이어프레임: 데스크톱은 왼쪽 목차 230px + 오른쪽 본문. 첫 화면은 서비스 정의와 검사 흐름, 다음 절은 전후 비교·7개 서비스 영역·상세 17개 기능. 모바일은 상단 줄바꿈 목차와 단일 열, 아키텍처는 세로 정보구조로 대체. 인쇄는 목차·조작 버튼을 제거하고 단계·접힌 상세 내용을 모두 표시한다.

## 상태와 접근성

- 기본: 원문 콘텐츠는 정적으로 표시, 단계 1과 기본 가정 계산.
- 빈 입력·범위 오류: 결과를 숨기고 필드별 오류 안내. NaN·과거 유효값을 최신 결과처럼 표시하지 않음.
- 음수: 추가업무·비용이 편익을 넘으면 음수 그대로 설명.
- 초기화: 예시 초기값 복원. 실제 자료·저장값이라고 표시하지 않음.
- JavaScript 비활성: 설명 본문·7단계·기본 계산 예시 열람. 동적 계산 불가 안내.
- 오프라인: 외부 폰트·스크립트·API 없이 열람·계산. 연결 원문 사이트는 별도 네트워크 필요.
- 권한: 공개 업무자료·로그인 기능 없음. 원문 대화는 사용자의 기존 접근권한 필요.
- 접근성: 한국어 문서 언어, heading 구조, 본문 바로가기, 네이티브 컨트롤·표, 입력 이름·오류, aria-live, 키보드 포커스, reduced-motion, 색과 텍스트 병기.
- 목표: WCAG 2.2 AA를 고려한 설계. 자동·브라우저 자체 검사로 공식 접근성 인증을 주장하지 않음.

## 제약과 후속

실제 접근성 보조기기·다양한 브라우저·기관 배포환경 검증은 별도다. 실제 PMS의 권한·버전·제출·LLM 오류 복구는 설명 대상이며 동작을 구현한 것으로 보고하지 않는다. 외부 법령·시장·임금·AI 생산성의 신규 조사는 이번 문서 제작에서 수행하지 않았다.

독립 평가위원은 참여하지 않았다. 자체 QA의 조건과 한계를 검증 기록에 남긴다. 수정은 설명자료 폴더로 제한하며 기존 원본·원장은 보존하고 프로젝트 목록·실행이력에 링크를 추가한다.

## v1.1 설계 계속 — 추가 범위

- 최신 대화 21건, 확장 요구 R21~33을 반영한다. 기존 15건의 발언·ID와 기존 원장·포트폴리오는 보존한다.
- 정보구조: 서비스 → 도입 이유 → 기능 → 공동 처리·B1~B3 → AI·감리 → 다면평가 → 아키텍처 → 편익 → 3개년 개발 → 근거.
- EX-Y 연차 선택: Y1·Y2·Y3 버튼은 목표·범위·산출물·연차 전환조건을 표시한다. 실제 계획 저장·승인 기능은 없다.
- EX-B 업무 설명: B1 기준설정, B2 증거축적, B3 검사·사람 검토를 펼쳐 읽는다.
- EX-E 평가 설명: 역할 7종과 관찰 범위, 평가 시점, 신규기업·소명·정정·공식 활용 경계를 설명한다.
- 로컬 정적 자료를 사용하므로 API·인증·입력 저장은 없다. 제품 화면 BL-01·EX-01·IN-01·EV-01·RF-01 및 API는 상세설계상의 제안이다.
- 반응형: 연차 패널은 모바일에서 한 열로 배치한다. 넓은 평가표는 별도 가로 스크롤 영역·안내·키보드 포커스를 제공한다.
- 인쇄·JavaScript 비활성: 3개년 설명을 모두 읽을 수 있다. 기존 7단계와 인쇄 상세 펼침 규칙을 유지한다.
