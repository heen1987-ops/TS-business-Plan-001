1. 시작하기 
1.1 로그인과 비밀번호 설정 
Noa 계정은 관리자가 생성해 전달합니다. 최초 접속 시에는 다음 순서로 비밀번호를 설정합니다. 
1. 관리자에게 받은 아이디와 임시 비밀번호로 로그인합니다. 
2. 로그인하면 비밀번호 설정 창이 표시됩니다. 
3. 앞으로 사용할 새 비밀번호를 입력하고 저장하면 Noa 를 사용할 수 있습니다. 
1.2 Noa 는 어떤 도구인가요 
Noa 는 AI 와 함께 업무를 처리하는 작업 도구입니다. 파일 정리 도구와 문서 작성 도구가 따로 있는 것이 
아니라, 필요한 자료를 한곳에 모아 두면 AI 가 그 자료를 근거로 업무를 처리합니다. 
중요한 개념은 다음과 같습니다. 
개념 한 줄 설명 
워크스페이스 AI 와 함께 업무를 수행하는 개인 작업 공간. 자료를 모아 두고 채팅으로 작업을 
지시합니다(2 장). 
드라이브 파일을 업로드해 두는 보관함. 여러 워크스페이스에서 불러와 사용합니다(3 장). 
스킬 AI 가 따르는 업무 지침. 자주 수행하는 업무를 매번 처음부터 설명하지 않고 바로 
시작하기 위해 사용합니다(4 장). 
 
1.3 가장 빠른 시작 
수행할 업무를 문장으로 작성하면 됩니다. 
1. 새 워크스페이스를 만듭니다. 
2. “document · 문서 처리” 분야의 스킬을 AI 컨텍스트에 넣습니다. 
3. 입력이 될 파일이 있다면 함께 넣습니다. 
4. 무엇을 어떤 형태로 원하는지 채팅으로 요청합니다. (예: “이 양식에 맞춰 회의록 작성해줘”) 
※ 어디서부터 시작할지 정하기 어렵다면 채팅으로 문의할 수 있습니다. (예: “회의록 만들고 싶은데 어떻게 해?”)

2. 워크스페이스 — 일하는 공간 
2.1 워크스페이스란 
워크스페이스는 AI 와 함께 실제 업무를 수행하는 개인 작업 공간입니다. 문서 작성, 파일 분석 등 구체적인 
작업은 모두 이곳에서 수행합니다. 
• 워크스페이스는 개인 소유입니다. 다른 사람과 공유되지 않으므로, 결과물을 다른 사람에게 전달할 
때는 드라이브로 보내거나 내 컴퓨터로 내려받습니다(5.5). 
• 업무 하나에 워크스페이스 하나씩 만들어 사용하는 것을 권장합니다. 한 곳에 여러 일을 넣으면 자료가 
섞여 AI 가 어떤 자료를 근거로 삼을지 판단하는 데 시간이 걸립니다. 
• 왼쪽 메뉴의 워크스페이스 아이콘에서 목록을 확인하고, 새로 생성합니다. 
2.2 화면 구성 
영역 내용 
맨 왼쪽 — 메뉴 바 홈 · 검색 · 알림과 각 기능 아이콘, 맨 아래 내 프로필이 있습니다. 이하 “왼쪽 
메뉴”라고 부릅니다. 
 
좌측 — 앱 영역 문서 · 표 · 뷰어 등 작업 화면. 여러 개를 탭으로 열 수 있습니다.

2.3 자료 넣기 
AI 컨텍스트에 넣어 둔 자료를 AI 가 작업의 근거로 사용합니다. 넣는 방법은 다음과 같습니다. 
방법 설명 
끌어다 놓기 내 컴퓨터에 있는 파일을 탐색기에서 바로 끌어다 놓을 수 있습니다. 
드라이브 화면의 파일이나 스킬 화면의 스킬을 AI 컨텍스트로 끌어다 놓습니다. 
올리기 버튼 AI 컨텍스트의 [파일] 옆 + 버튼으로 내 컴퓨터의 파일을 업로드합니다. 
@ 로 부르기 채팅 입력창에 @ 를 입력하면 이미 담아 둔 자료와 내 드라이브 파일 목록이 
표시됩니다. 이어서 글자를 입력하면 목록이 좁혀집니다.

2.4 AI 에게 요청하기 
요청은 자연어로 작성합니다. 다음 사항을 지키면 결과의 정확도가 높아집니다. 
1. 무엇을 어떤 형태로 원하는지 작성합니다. (예: “이 계약서에서 위험 조항 찾아서 표로 정리해줘”) 
2. 근거가 될 자료를 먼저 워크스페이스에 넣습니다. 자료가 없으면 일반적인 내용만 답변합니다.

입력창에서 사용하는 기호는 다음과 같습니다. 기호를 입력하면 목록이 표시되고, 이어서 글자를 입력하면

# 스킬 묶음(그룹) 
 
작업 시간이 긴 경우 진행 상황이 단계별로 표시되어, AI 가 어떤 자료를 읽고 어떤 도구를 사용하는지 
확인할 수 있습니다. 답변이 중간에 중단되면 이어서 진행해 달라고 요청합니다. 
2.5 워크스페이스 관리하기 
목록 화면의 항목 메뉴에서 이름 변경 · 분야 변경 · 보관 · 삭제를 할 수 있습니다. 
• 당장 쓰지 않는 것은 보관해 두면 기본 목록에서 빠집니다. 이후 보관 해제가 가능합니다. 
• 즐겨찾기는 카드 제목 옆의 별 아이콘으로 따로 설정합니다. 
• 워크스페이스에서 삭제한 파일은 AI 컨텍스트 아래쪽의 전용 휴지통으로 이동합니다. 
 
[주의] 워크스페이스를 삭제하면 복구할 수 없습니다. 워크스페이스와 그 안의 대화, 담겨 있던 파일이 
모두 삭제됩니다. 보관이 필요한 결과물은 삭제 전에 드라이브로 보내거나 내 컴퓨터로 내려받으시기 
바랍니다.

3. 드라이브 — 파일 보관함 
드라이브는 파일을 보관하는 공간입니다. 파일을 업로드해 두고 필요할 때 불러와 사용합니다. 왼쪽 
메뉴의 드라이브 아이콘에서 엽니다. 
3.1 드라이브를 사용하는 이유 
• AI 는 드라이브에 있는 파일을 자동으로 읽지 않습니다. 워크스페이스의 AI 컨텍스트에 넣어야 작업 
대상 파일로 사용합니다. 
• 같은 파일을 여러 작업에서 사용할 예정이라면 드라이브에 한 번 업로드해 두고 필요할 때 가져와 
사용하는 것을 권장합니다. 워크스페이스에 직접 올린 파일은 해당 워크스페이스에만 남습니다. 
• 워크스페이스에서 작업한 최종 결과물을 드라이브로 보내 두면, 워크스페이스를 삭제해도 파일은 
남습니다. 
3.2 파일 올리고 정리하기 
수행할 작업 방법 
파일 올리기 [컴퓨터에서 올리기] 버튼을 누르거나, 파일·폴더를 드라이브 화면에 
끌어다 놓습니다. 
폴더 만들기 [새 폴더]로 생성합니다. 같은 종류의 문서를 폴더로 묶어 두면 Smart 
Excel 작업에 활용할 수 있습니다(5.2). 
찾기 화면 위쪽의 검색과 정렬 · 유형 · 수정날짜 필터를 사용합니다. 
이름 변경 · 이동 · 삭제 · 
다운로드 
파일을 우클릭해 표시되는 메뉴에서 수행합니다. 
워크스페이스로 보내기 파일을 워크스페이스의 AI 컨텍스트로 끌어다 놓습니다. 
 
3.3 용량과 휴지통 
• 드라이브 화면과 워크스페이스 아래쪽에서 현재 사용량을 확인할 수 있습니다. 용량이 부족하면 새 
파일을 업로드할 수 없습니다.

11 
• 삭제한 파일은 휴지통으로 이동합니다. 휴지통 항목도 용량을 차지하므로, 용량이 부족하면 휴지통을 
먼저 비웁니다. 
 
[주의] 휴지통을 비우면 되돌릴 수 없습니다. 
4. 스킬 
스킬은 AI 가 따르는 업무 절차입니다. 스킬 없이 요청하면 AI 가 전 과정을 자체 판단으로 처리하지만, 
스킬을 담아 두면 정해진 절차와 형식에 따라 작업합니다. 
왼쪽 메뉴의 스킬 아이콘으로 목록을 엽니다. 스킬은 분야별로 묶여 있고, 문서 스킬은 “document · 문서 
처리” 분야에 있습니다. 
4.1 제공되는 스킬 
스킬 하는 일 
양식 변환 v2(문서 → form2) 한글·워드 문서를 반복해서 사용할 수 있는 양식으로 변환합니다. 
양식 채우기 v2(문서·form2) 양식이나 문서의 빈칸과 표에 값을 채웁니다. 원본 서식은 그대로 
유지합니다. 
양식 내보내기 v2(문서·PDF) 값을 채운 양식을 외부에 전달할 수 있는 문서나 PDF 로 내보냅니다. 
Smart Excel 템플릿 학습 문서 폴더를 분석해 추출할 항목을 학습하고, 그 결과를 템플릿으로 
워크스페이스에 저장합니다. 
Smart Excel 생성 학습한 템플릿으로 여러 문서에서 값을 추출해 하나의 엑셀로 
정리합니다. 
공문서 생성(markdown → 
HWPX) 
양식이 없어도 작성한 글이나 대화 내용을 바탕으로 HWPX 
공문서를 생성합니다. 
 
4.2 워크스페이스에 담기 
담는 방법은 다음과 같습니다. 

PAGE 12

• 끌어다 놓기 — 스킬 화면에서 스킬 카드를 워크스페이스의 AI 컨텍스트로 끌어다 놓습니다. 분야 
카드를 끌어다 놓으면 해당 분야의 스킬이 한 번에 담깁니다. 
• 채팅에서 부르기 — 입력창에 / 를 입력하면 스킬 목록이 표시됩니다. 그룹은 # 로 부릅니다. 
• 바로 시작 — 스킬 카드의 [이 스킬 사용]을 선택하면 해당 스킬이 담긴 워크스페이스가 생성됩니다. 
※ 어떤 스킬이 필요할지 미리 판단하기 어렵다면 “document · 문서 처리” 분야를 통째로 담아 두고 시작할 수 
있습니다. 담아 둔 스킬 중 필요한 스킬을 AI 가 선택해 사용합니다. 
4.3 즐겨찾기 · 그룹 · 프리셋 
기능 설명 
즐겨찾기 카드 오른쪽 위의 별을 선택해 모아 둡니다. 계정에 저장되므로 다른 기기에서도 
동일하게 표시됩니다. 
그룹 자주 함께 사용하는 스킬을 묶어 이름을 지정합니다. 목록 위쪽 필터의 [새 
그룹]으로 생성하고, 채팅에서 # 로 부릅니다. 
프리셋 새 워크스페이스를 만들 때 자동으로 담길 스킬을 미리 지정합니다. 스킬 화면 
오른쪽 위의 [프리셋] 버튼을 선택해 스킬을 담고 [저장]합니다.

5. 실제 업무하기 
실제 업무는 워크스페이스에 스킬과 자료를 담고, 수행할 업무를 채팅으로 요청하는 순서로 진행합니다. 
수행할 업무에 따라 아래 절을 참고합니다. 
워크스페이스에 문서 스킬을 담아 두고 자연어로 요청하면, AI 가 필요한 시점에 관련 스킬을 찾아 
사용합니다. 사용자가 스킬을 직접 실행하거나 실행 순서를 지정할 필요는 없습니다. 아래 절은 스킬을

AI 가 생성한 결과물 — .asset 
스킬이 생성한 결과물은 일반 파일과 구분되도록 이름이 .asset 으로 끝납니다. 단일 파일이 아니라 결과 
문서와 근거·상태가 함께 포함된 묶음이며, 클릭하면 해당 결과물에 맞는 전용 화면으로 열립니다. 
이름 설명 
○○.form.asset 양식 — 채울 칸이 정의된 문서 양식입니다. 양식 변환 v2 로 생성합니다. 
○○-fill.form.asset 채운 결과 — 해당 양식에 값이 입력된 문서입니다. 채워진 칸과 비어 있는 
칸의 정보도 함께 기록됩니다. 
○○.template.asset 추출 항목 — Smart Excel 템플릿 학습이 만든 항목 정의입니다. 
○○.smart-excel.asset 정리 결과 — 항목별 값이 채워진 엑셀입니다. xlsx 파일로 내려받을 수 
있습니다. 
 
※ 이름은 자동으로 생성되며 우클릭 메뉴에서 변경할 수 있습니다.
