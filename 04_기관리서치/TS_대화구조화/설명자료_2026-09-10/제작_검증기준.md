# 설명자료 제작·검증 기준

## v1.2 추가 기준 — 2026-09-10

- 목적: CCK가 주관·총괄 수행사로 책임질 수 있는 사업 범위와 확인 조건을 설명한다.
- 수용기준: 직접·협력 책임, 외부 협조, 최소 납품물, 인력·납기·원가·검수·운영 근거를 명시하고 A/B/C를 주관 수행 검증 전으로 표시한다.
- 추적: U-CCK-02 → CCK 적용 기준 7절 → HTML 주관 수행 영역·Markdown → 연구 복사문·Q11 → 브라우저 검사 2개 추가.
- 검증 범위: 문서와 설명 UI. CCK 제품 구현·회사 수행 능력·실제 사용자 검증과 구분한다.
- 보존: 직전 버전과 검사 산출물은 `이력/v1.1_주관수행조건_반영전`에 있다.

## v1.1 적용 기준 — 2026-09-10

- 작업 유형·규모·위험: 설명자료와 기획 범위 수정 / M / Low.
- 방법론: 근거 추적을 포함한 Standard Loop. 구현 기능은 문서 설명에 한정하므로 제품 API·ERD·운영 배포 문서는 생략한다.
- 대상·성공기준: 내부 기획 검토자가 CCK 자산·로컬 LLM 역할과 비전 제외 범위를 구분하고 다음 연구에서도 같은 조건을 유지할 수 있다.
- 가정: CCK 자산은 파생 대장에 기재된 재사용 후보이며 제품·성능·로컬 실행 검증 전이다.
- 읽기 순서: 기획 중심 → CCK·로컬 LLM 범위 → 메가이슈별 적용 가설 → 조사안·상황 → 근거·연구·후속 확인.
- 추적: T01~T14 보존, 추가 요청 T15~T17, 현재 사용자 정정 U-CCK-01, 기술자료 K01~K03, 확인 대기 Q10.
- 수용기준: 첫 화면에 CCK·로컬 LLM·비전 제외 표시, 8개 메가이슈의 적용/제외 구분, 8개 복사문 전부 기술 범위 유지, NL2SQL 등 미확인 기능을 보유로 단정하지 않음, HTML/MD/다운로드 일치.
- 검증: 기존 탭·상황·키보드·모바일·인쇄·외부요청 검사와 범위 교정의 회귀 확인. 실제 CCK 엔진·로컬 LLM·예약 API·사용자 조사는 수행 대상이 아니다.
- 품질게이트: 범위 정의 → 출처/설계 확인 → 공통 데이터 수정 → 브라우저 검사 → 화면 자체 검토. 독립 평가위원·실제 사용자 검증으로 보고하지 않는다.
- 롤백: 설명자료 이전 버전과 검증 산출물은 이력/v1.0_CCK범위반영전에 보존했다. 현재 사용자 기술 범위 지침은 롤백 대상과 별도 관리한다.

## 최초 v1.0 제작 기준 (이력)

- 작업: 참조 대화 설명용 HTML·Markdown. 규모 M / Low. 근거 추적과 단계별 확인을 적용.
- 대상: TS 기획 담당자와 내부 검토자. 산출물은 내부 설명·토론용이며 사업 승인·공식 안내문이 아님.
- 가정: 2026-09-10 현재 반환된 대화 14개 턴을 기준으로 만든다. 연구 결과가 없는 요청을 완료로 해석하지 않는다.
- 읽기 순서: 기획의 중심 → 방향 전환 → 3개 조사안 → 예약 시나리오 → 근거 수준 → 연구 8단계 → 후속 확인.
- 형태: 외부 요청·폰트·이미지·라이브러리 없이 읽는 단일 HTML. 동일 내용 데이터에서 Markdown 동시 생성.
- 시각 구성: 남색·아이보리 기반, 편의는 청록, 안전은 주황. 장식 이미지 대신 정확한 HTML/CSS 도식을 사용.
- UI: 주제 선택 탭, 설명용 예약 상황 선택, 연구 단계 접기/펼치기, Markdown 저장, 인쇄.
- 권한·데이터: 실제 예약·법정 판단·연구 실행을 하지 않음. 서버·API·개인정보 입력 없음.
- 화면 상태: 주제·상황 선택, 조회 불명확 설명 예시, 클립보드 복사 실패 안내, JavaScript 미사용 시 전체 내용 열람, 인쇄 시 전체 펼침.
- 반응형: 320·390·768·1440px에서 본문 가로 넘침 없음. 표는 독립 스크롤 영역으로 표시.
- 접근성: 한국어 문서, 제목 계층, 건너뛰기 링크, 키보드 탭/화살표, 포커스 표시, 44px 조작 영역, 색 이외의 상태 라벨, 동작 감소 설정.
- 수용기준: T01~T14 추적, 주제 3+4개, 상황 4개, DR01~08, Q01~09, 요청/결과 구분, 현행 AX 범위 유지, HTML·MD 주요내용 일치.
- 검증: 정적 구조·외부 요청 없음·상호작용·다운로드 일치·키보드·모바일·인쇄·스크린샷 점검. 실제 스크린리더·외부 원문·현업 검증은 제외.
- 롤백: 날짜별 별도 폴더로 제작하며 과거 자료와 원장을 덮어쓰지 않음. 화면 링크만 이전 자료로 돌릴 수 있음.
- 평가: 내부 검토는 독립 평가위원 심사나 실제 사용자 검증을 대체하지 않음.
