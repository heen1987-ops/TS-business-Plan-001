## 실행 증거

[브라우저 검사 결과 JSON](검증결과.json)에서 **44개 검사 모두 통과**했다.

- 자료: 대화 14개 턴, AI 답변 본문 11개, 결과 본문이 반환되지 않은 시작 요청 3개를 구분했다.
- 내용: 3개 조사안·4개 비교 주제·4개 상황·DR01~08·Q01~09를 연결했다. 재구성한 요청 문장 3개에는 설명용 예시 표시를 붙였다.
- 일치: HTML 내장 Markdown과 별도 .md의 내용, 실제 저장한 Markdown, 생성 파일 해시가 일치했다.
- 동작: 조사안 탭, 상황 선택, 연구 단계 펼침, 복사 성공/대체 안내, 복사 차단 시 원문 선택을 확인했다.
- 키보드: 화살표·Home·End로 조사안 이동, Enter로 연구 단계 펼침을 확인했다.
- 화면: 1440·768·390·320px, 200% 확대에서 본문 가로 넘침이 없었다. 넓은 표는 별도 스크롤 영역으로 제공한다.
- 인쇄: 모든 조사안·상황·접힌 연구·출처를 펼치는 상태와 인쇄 뒤 상태 복구를 확인했다. 브라우저 PDF 생성도 시험했다.
- 독립 실행: 외부 HTTP 요청 0건, JavaScript 오류 0건. JavaScript가 꺼져 있어도 본문은 열람되며 작동하지 않는 선택·저장 조작은 숨긴다.
- 접근성 범위: 한국어·제목·랜드마크·고유 ID·앵커·키보드·포커스·CSS 텍스트 대비·작은 화면을 점검했다.

## 미검증·한계

- axe-core가 번들에 없어 해당 도구의 자동 접근성 검사는 실행하지 않았다. 기본 CSS 텍스트 대비와 키보드 검사는 별도로 실행했다.
- 실제 스크린리더, 실물 모바일 기기, 모든 브라우저, 인쇄물 전체 페이지의 정밀 조판은 검증하지 않았다. WCAG 전체 적합성 인증을 뜻하지 않는다.
- 법령·민원·기존 서비스의 공식 원문, 실제 예약 API·조회·확정, 현업·국민 수요, 심층리서치 보고서 본문은 이번에 검증하지 않았다.
- 설명용 UI의 내부 점검은 독립 평가위원 심사, 실제 사용자 조사, 사업 선정·운영 배포 승인을 대신하지 않는다.
