HTML은 더블클릭해 브라우저에서 연다. 외부 폰트·스크립트·이미지·서버에 의존하지 않아 파일 하나로 내용을 열람할 수 있다. 상단의 Markdown 저장은 같은 내용을 내보낸다. 인쇄 / PDF는 브라우저 인쇄창을 열며 전체 조사안·상황·접힌 연구 단계가 인쇄 대상에 포함된다.

## 갱신 방법

내용.json은 설명 내용의 기준이다. 수정 후 제작_설명자료.py를 실행하면 HTML·Markdown·생성_기록.json을 함께 갱신한다. 생성한 HTML·Markdown에서 수동 변경이 발견되면 스크립트가 중단하므로, 직접 편집한 문서를 임의로 덮어쓰지 않는다. Markdown만 따로 편집한 내용은 HTML에 자동 반영되지 않는다.

검증_설명자료.cjs는 번들 Node.js·Playwright와 설치된 Edge를 사용한다. 외부 예약·신청·연구를 실행하지 않고 로컬 문서의 동작을 검증한다.

## 근거와 해석

1~6차 연구 시작 요청을 DR01~06에 대응해 표시했지만, 해당 연구 결과 본문이 반환되지 않아 실제 완료 여부를 판정하지 않았다. 이 문서 제작을 연구 단계 완료로 기록하지 않았다.

현재 기획 범위는 AX 또는 디지털전환+AI+정보화다. 참조 대화의 독립 R&D 표현을 그대로 현재 범위로 옮기지 않았으며, 필요한 PoC만 전환사업 세부 과업으로 검토하도록 요약했다.

v1.1에서는 설명자료·기획 기준·후속 대기열 Q10을 갱신했다. 포트폴리오의 선정 상태·원천자료·자동화 설정은 변경하지 않았다. 이전 설명자료는 이력/v1.0_CCK범위반영전에 보존했다.
