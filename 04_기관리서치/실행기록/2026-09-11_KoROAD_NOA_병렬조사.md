# KoROAD NOA 확장 3개 분기 병렬조사

- 사용자 요청: “병렬로 분기하여 전부 조사”. 기존 NOA 공통 기반과 범용 업무·국민서비스 / 교통안전 특화 두 축을 대상으로 수행.
- 방법: 공통 기반(F), 범용 서비스(A), 교통안전(B) 조사자를 병렬 운용. 분기는 읽기 전용으로 공식 근거를 확인했고 통합 담당만 산출물 작성. 통합 담당은 기존 플랫폼 사업계획·기준 재배포·법정업무 근거를 추가 확인.
- 범위: 3분기·N01~N07 전체. 기존 36개 주요사업 메뉴 매핑을 계승했다. 모든 하위 첨부·운영 기능·계약·전 공공기관의 전수조사는 아니다.
- 신규 핵심: R01 2026 교통AI플랫폼 구축계획 PDF 1쪽 전체 확인. 생성형·자율형 업무자동화·분석·GPU 확충이 계획 범위에 포함된다. 계약·착수·확보 장비·사용 가능 자원은 미확인. 모든 후보에 기존 RFP/계약 대조를 선행조건으로 반영.
- A축: AI 국민비서·전자문서지갑·공공 마이데이터·은행 앱 교육예약 중복 확인. N01 준비·상담 인계, N02 전자 신청자료 보완 점검, N04 파일·시점·영향·반영 확인으로 구체화.
- B축: 기존 조치보고·합동점검·TEMS·교육·사후관리·TAAS 확인. N03 의미상 증빙 대조, N05 자유서술 이해 확인, N06 확인된 텍스트 원고 대조, N07 허용 API 질의·설명으로 한정.
- 제약: 로컬 LLM·기존 서버·신규 인프라 투자 0원. 비전·신규 OCR·STT/TTS·센서·제어·자동 안전판정 제외. TS 예산·기존 수행과업을 KoROAD 신규사업으로 이전하지 않음.
