# 2026-09-09 리서치 초기 기록

실행 종류: 사용자의 지침 적용 요청에 따른 대화 중 초기 조사. 예약 자동화가 실행된 기록이 아니다.

## 확인 범위

- 사용자 신규 사업기획 기준 7개와 월~금 오전 9시 정기 조사 주기 확인.
- 기존 프로젝트 SRC-005·SRC-010·SRC-011의 사업·업무·후속기획 경계 검토.
- 공식 출처 PUB-001~PUB-008의 기관 분류·설립목적·업무·심의 관련 자료 확인. 부분 열람·현행 적용 한계는 출처 목록에 기록.
- 기관 원장 ORG-0001, 업무 MAN-0001, 관계 REL-0001 등록. 현행 법적 적용성 검증은 미완료.

## 의미 있는 발견

1. 기존 업무 지침은 근거·규칙·사람 검토·감사 이력의 재사용 가능성을 보여 준다. 실제 자산·권한·계약 범위는 확인이 필요하다.
2. 기관 유형, 설립 목적, 법정 사업, 위탁·지정 관계는 서로 구별해야 한다.
3. 현행 공공기관운영법의 재정경제부 표기와 R&D 심사제도 개편 자료가 확인되어 과거 부처명·심의 체계의 일률 적용을 피해야 한다.

## 미완료와 다음 시작점

- PUB-002 지정고시 첨부 다운로드 오류: 공식 고시·ALIO에서 전체 목록과 TS 유형을 대조한다(Q01).
- TS 개별 위탁·지정 근거의 현행 조문·시행일과 수행조직을 확인한다(Q02).
- 투자·R&D·정보화 심의의 하위 규정·적용 조건을 확인한다(Q07).
- 이후 공식 명단의 미조사 기관을 순차 조사하며 TS와 유사한 안전·검사·평가·공시 업무에서 다른 부처로 범위를 넓힌다.

현재 모집단 총수 미확정. 등록 기관 1개·업무 1개·관계 1개, 현행 법적 적용성 확인 관계 0개. 사업기회는 아직 선정하지 않았다.

자동화 `ts-ai` 등록 상태 ACTIVE. 예약된 실행과 결과 저장은 후속 확인 대상이다.

- 산출물: [조사보고서](../공공PMS_병목관리/공공PMS_병목관리_조사보고서_2026-09-09.md), [출처목록](../공공PMS_병목관리/출처목록.md), [출처원장](../공공PMS_병목관리/출처원장.json), [후속조사](../공공PMS_병목관리/후속조사_대기열.md).
- 핵심 발견: 국세청 2024 규정에 PMS 기록·품질검증·SLA·만족도·개선 절차가 있다. 국내 제품도 승인·누락·변경관리 기능을 소개한다. 미국 FAR/CPARS에는 객관적 근거, 업체 소명, 상위 검토와 접근 제한 절차가 있다.
- 적용 판단: 기존 PMS 연계 AX를 비교 실증하는 방향을 제안했다. AI 추가 가치·TS 수요·비중복·국민 효과·평가정보의 공식 활용은 미검증이다. 기업평가 공동운영의 TS 포괄 권한을 확보한 것으로 해석하지 않았다.
- 출처 16개 기록(대화 1, 웹 14, 기존 ALIO 원천자료 1), 공개 HTML 13개 보존. 국세청은 웹 도구의 동적 본문 누락을 같은 공식 사이트 HTTP 본문 조회로 보완했다. 일부 자료는 게시문 또는 검색 발췌만 확인한 상태를 보존했다.
- 조사자 판정: 후속 문제·자료 검증 진행은 조건부 합격, 신규사업 선정·본구축·공식 평가 활용은 보류. 독립 법률·평가위원 검토, 실제 사용자 조사·AI 실증은 미실시.
- [검증 결과](../공공PMS_병목관리/검증결과.md)에 문서·참조 점검 범위와 미검증 사항을 기록한다. 기존 기관관계·포트폴리오 원장을 수정하지 않았으며 자동화·외부 연락·배포는 실행하지 않았다.
