# 기관·법령·법정업무 관계 조사

2026-09-09 기준 · 대상 독자: TS 신규 사업기획 담당자와 검토자

기관을 검색하면 주무기관, 설립 근거, 법령 간 인용, 업무별 위탁·대행 근거를 따라갈 수 있는 [관계도](기관법령_관계도.html)를 구성했다. 공식 명단, 기관 공시, 법령·조례 본문을 각각 보존하고 관계마다 출처와 확인 수준을 붙였다.

**관계도와 조사 기반 구축은 완료했다. 모든 기관의 모든 관계법령에 대한 전수 법률검토는 미완료다.** 공식 명단의 포괄성과 개별 조문의 적용 검증을 구별하며, 미확인 항목을 누락 없이 이어 조사할 수 있도록 기관별 대장을 만들었다.

## 1. 문제·가정·범위

문제는 기관의 이름이나 소속 부처만으로 사업기회를 판단하면 실제 법적 업무, 위탁 범위, 데이터 활용권한을 잘못 연결할 수 있다는 것이다. 조사 목적은 `국민 문제 → 실제 기관 업무 → 법적 근거 → 공공 AI 필요성 → 확장 조건`의 추적 가능한 기초를 마련하는 데 있다.

- 가정: TS는 한국교통안전공단이며, 범정부 확장을 위한 대한민국 기관 체계를 조사한다.
- 규모·위험: L / Medium. 외부 운영 시스템 변경 없이 공개자료 조사와 로컬 산출물을 작성했다. 개별 법률 적용 판단은 높은 정확성이 필요한 항목으로 취급했다.
- 방법론: Stage-Gate, 요구사항 추적, 근거 기반 조사. 범위 정의 → 공식 명단 확보 → 본문 확보 → 관계 유형화 → 검증 → 미확인 대기열로 진행했다.
- 성공기준: 기관·법령 검색, 관계 이동, 공식 근거 접근, 시행일·확인 수준 구별, 기관별 미확인 항목 유지, 기준명단과 공시의 차이 보존.
- 이번 범위: 정부 조직 기구도, 지정 공공기관·부설기관, 지방공기업, 지방 출자·출연기관, 지정자료의 미지정 참고목록, 이들 공시의 설립 근거와 관련 법체계, TS 핵심 관계.
- 별도 보완 범위: 각 중앙기관의 모든 소속·특별지방행정기관, 모든 지방자치단체·교육행정기관, 국공립학교 등 개별 시설, 각종 법정단체·협회 및 미지정기관 전체, 고시·정관·위수탁 협약. 이번 명단을 대한민국 모든 공적 조직의 확정 모집단으로 사용하지 않는다.
- 생략: 신규 솔루션 UI 설계서·배포 계획·사업성 확정. 현재 요청은 관계 조사이며 사업 주제와 예산은 정해지지 않았다.

## 3. 관계도 사용법과 판독 기준

1. [기관법령 관계도](기관법령_관계도.html)를 브라우저에서 연다. 외부 서비스나 계정 없이 파일 자체로 조회할 수 있다.
2. TS, 부처, 다른 기관 또는 법령명을 검색한다. 처음에는 TS와 주무부처·설립법·핵심 업무가 보인다.
3. 연결된 항목을 선택해 `기관 → 업무 → 근거 법령 → 다른 기관`을 따라 이동한다.
4. 관계 목록의 **근거 보기**에서 관계 종류, 조문 위치, 확인 수준, 원문 링크와 날짜를 확인한다. 화면에는 일부 연결을 우선 표시하며 아래 목록에서 나머지를 넘겨 볼 수 있다.
5. 기관명 출현 후보까지 탐색하려면 **자동 추출 관계 포함**을 켠다. 후보 연결은 개별 법적 역할을 확정한 결과가 아니다.

| 관계·상태 | 의미 | 판단에 사용할 때 주의할 점 |
|---|---|---|
| 공식자료 | 공식 목록의 분류·주무기관·부설 관계 | 주무기관 표기를 지휘·감독권이나 개별 위탁 근거로 바꾸지 않음 |
| 공시근거 | 기관이 공시에 적은 설립법·조례 인용 | 역사적 설립 근거, 구명칭, 현행 사업근거가 섞일 수 있음 |
| 분류근거 | 해당 공시 분류의 공통법 검토 출발점 | 적용 제외·특례·개별법 우선 적용을 별도 확인 |
| 법령본문 | 법령 본문·명시적 인용·법률과 하위법령의 대응 | 인용 자체가 권한 이전이나 데이터 제공 허용을 뜻하지 않음 |
| 조문검토 | 선택한 조문을 읽고 관계를 유형화 | 표시한 조문과 업무 범위에 한정. 독립 법률의견 또는 전수검토는 아님 |
| 자동추출 | 본문에서 기관명 또는 기관명이 들어간 법령명 출현 | 법정업무·수탁 사실·제재·협조 중 실제 의미를 재검토 |
| 미확인 | 제명·현재 효력·기관 대응 등을 추가 확인해야 함 | 자료가 없거나 권한이 없다는 결론으로 사용하지 않음 |

`공기업·준정부기관`은 지정 유형이다. `공사·공단·재단·회사`는 명칭 또는 법적 조직 형태이고, `위임·위탁·대행·지정`은 개별 업무 수행의 법적 관계다. 특히 **위탁집행형 준정부기관이라는 이유만으로 모든 업무가 위탁업무가 되지는 않는다.**

## 4. TS에서 확인한 법적 관계

기관은 한국교통안전공단, 주무기관은 국토교통부, 지정 유형은 위탁집행형 준정부기관이다. ALIO 최신 일반현황에 기재된 설립 근거·목적·기능을 현행 법령 본문과 구별해 보존했다. [TS ALIO 일반현황](https://www.alio.go.kr/upload/disclosure/2026/09/09/2026090903239015/doc.html)

핵심 15건의 법령명·조문·관계 종류·위탁 주체·예외·원문 링크는 [TS 조문 검토표](TS_조문검토표.md)에 정리했다. 다음 차이는 사업 범위와 발주 논리에 직접 영향을 준다.

- **법정 사업과 수탁업무:** 한국교통안전공단법 제6조의 자체 사업 근거와 개별 법령의 업무 위탁을 나눴다. 도로교통 교육·기술개발의 범위 제한, 지정·승인이 필요한 기타 사업을 일괄적인 권한으로 확대하지 않았다.
- **중앙과 지방의 권한 주체:** 자동차 튜닝 승인은 자동차관리법 시행령 제19조제5항의 시장·군수·구청장 위탁이다. 교통안전법 시행령 제48조의2제2항제1호·제4호 관련 업무에는 시·도지사등도 위탁 주체로 연결했다. 관계도에서 부처로 표시한 권한의 법문상 주체는 장관임을 근거 창에 적었다.
- **기관 간 업무 경계:** 철도안전법 시행령 제63조는 TS·한국철도기술연구원·국가철도공단의 위탁 범위를 나눈다. 항공안전법 시행령 제26조의 TS 업무와 별도 지정 전문기관 업무도 구별했다.
- **가능규정과 실제 위탁:** 위험물질 운송안전센터, 교통약자 조사·정보체계, 도심항공교통 지원의 일부 근거는 대행·위탁이 가능한 대상과 조건을 규정한다. 실제 지정 고시를 확인하기 전 확정 수탁업무로 표시하지 않았다.
- **정보시스템 근거:** 자동차 전산정보처리조직, 기계식주차장 정보망, 대중교통 통합정보시스템은 각각 별도 법적 근거로 연결했다. 정보시스템 구축 권한과 개인정보·기관 간 데이터 이용 권한은 따로 검토한다.

위 내용의 조문·시행일·공식 출처는 검토표의 각 행과 관계도 근거 창에 연결되어 있다. 수행조직·위임전결·협약·위탁기간까지 검증한 것은 아니다.

## 5. 공공 AI 기획에 반영할 변경

### 현행 공공 AI 행정법의 명칭과 적용 대상

기존 「데이터기반행정 활성화에 관한 법률」은 2026-08-28 시행 법률에서 「인공지능 및 데이터 기반 행정 활성화에 관한 법률」로 변경되었다. 제2조는 인공지능기반행정과 공공기관의 범위를 규정한다. 관계도에는 현행 명칭과 이전 명칭을 연결했다. [국가법령정보센터 현행 법률](https://www.law.go.kr/LSW/lsInfoP.do?ancYnChk=0&chrClsCd=010202&efYd=20260828&lsiSeq=283735&urlMode=lsInfoP)

적용 판단: 지정 공공기관·지방공사·공단 등 명시된 범위와 대통령령으로 정하는 추가 대상을 구별한다. 모든 출자·출연기관에 일률 적용하거나 이 법만으로 모든 개인정보 활용이 허용된다고 해석하지 않는다. 시행령·개별 업무 근거와 개인정보보호 규율을 추가 대조한다.

이는 조사 활용 기준이다. 신규 사업 선정, 메가이슈의 통계 검증, 타당성 또는 예산 심의 대상 확정 결과는 아니다. 모든 신규 사업에 동일한 재정 당국 사전 심의를 단정하지 않는다. 기존 [공식근거 및 심의경로](../공식근거_및_심의경로.md)와 함께 검토한다.

## 6. 미확인과 누락 방지

- **지방 기준명단 31개:** 명칭 변경·약칭·동명이기관 가능성. 예를 들어 강원·경남의 고성군상수도를 이름만으로 합치지 않았다. [기준명단 대조](기준명단_공시대조.json)
- **지방 공시 18개:** 일반현황 응답 미확보. 기관이 없어진 것으로 처리하지 않았다.
- **조례 제명 221개:** 제명 검색에서 본문 연결을 확보하지 못했다. 지자체 자치법규·설립기관 공시에서 구명칭·현행 제명·폐지·통합 여부를 대조해야 한다.
- **조례 현행 여부 1개:** 「경상북도 첨단산업 진흥을 위한 재단법인 설립 및 지원에 관한 조례」는 본문을 확보했으나 명확한 현행 시행일을 확정하지 않았다.
- **국가 법령 검색 응답 8개:** 약칭·구명칭·오탈자·조회 실패를 포함한다. 일부는 보완 제명으로 본문을 확보했으므로 8개를 모두 미확보 고유 법령 수로 세지 않는다. TS 법의 시행규칙 제명 조회 실패도 해당 시행규칙이 존재하지 않는다는 확정 결론이 아니다.
- **개별 법정업무:** 대부분의 기관은 설립근거 공시와 관련 본문을 연결한 단계다. 모든 법정 사업, 시행령·규칙·별표, 고시·지정·협약, 실제 수행조직과 유효기간을 검증하지 않았다.
- **소관법령의 역방향 대조:** 각 부처 소관법령 전체 목록에서 출발하는 대조와 별도 기관군 확대가 필요하다. 기관명 검색은 약칭·직제·별표·서식에 숨은 근거를 놓칠 수 있다.

상세 항목은 [기관별 미확인 대장](기관별_미확인대장.json), [취득 실패·제명 검토](취득실패_및_제명검토.json), [후속 조사 대기열](후속조사_대기열.md)에 보존했다. 기준일이 다른 명단을 임의로 합쳐 하나의 전체 완료율을 만들지 않는다.

## 7. 검증·평가와 운영

- 데이터 검증: 기관·법령·관계·출처 ID 참조, 부설기관 구별, 지방 기준명단 1,315개 보존, 기관별 미확인 대장 연결, 미래 시행 법령 혼입, 미검증의 완료 승격 여부를 확인했다. [검증 결과](검증결과.json)
- 원천 보존: 4,659개 파일과 관계도 출처 2,590개를 색인했다. 원천 파일 수에는 중간자료·실패 응답도 포함한다. SHA-256은 취득 때 계산된 값을 해당 파일에 연결했다. 전체 파일의 해시 재계산 검사는 파일 읽기가 오래 걸려 중단했으며, 해시가 없는 파일은 `null`로 표시했다. 따라서 전 파일 무결성 재검증 완료로 보고하지 않는다.
- 화면 검증: Microsoft Edge에서 기관 검색, 결과 없음, 법령 탐색, 이전 선택, 근거 열기, 자동 추출·확인 수준 필터, 키보드 선택, 데스크톱·모바일 가로 넘침과 JavaScript 오류 등 17개 검사를 통과했다. 최신 실행 결과는 [뷰어 검증 결과](뷰어_검증결과.json)에 기록했다.
- 사용자 관점: 처음 TS에서 시작해 기관·업무·법령을 따라가고 출처를 확인할 수 있다. 자료 없음·미확인 상태와 관계 유형을 표시했다. 모바일 표는 가로로 넘겨 근거 버튼을 볼 수 있다.
- 시각 증거: [데스크톱](QA_데스크톱.png), [모바일](QA_모바일.png), [다크 화면](QA_다크.png).
- 보안·배포: 조회 데이터가 포함된 로컬 파일이다. 외부 원문은 사용자가 링크를 열 때 접근한다. 외부 게시·배포·메시지 전송은 수행하지 않았다.
- 판정: 자체 QA에서 관계도 조회와 데이터 구조의 수용기준을 충족했다. **전수 법률검토 완료 판정은 보류**하며 독립 평가위원·법률전문가 검토는 미실시다. 스크린리더 실제 낭독과 색 대비 수치 검사는 미실시다.
- 변경·롤백: 2026-09-09 원천자료와 해시 목록을 보존했다. 미래 갱신 때 기준일별 변경 이력을 남기고 검증한 이전 산출물을 유지한다. 현재 수집 스크립트는 날짜와 캐시가 고정된 조사 재현 도구이므로 그대로 재실행한 결과를 신규 조사로 표시하지 않는다.
- 다음 반복주기: 기존 월~금 09:00 Asia/Seoul 리서치에서 후속 대기열을 사용한다. 이번 조사는 대화 중 실행이며 첫 예약 실행 성공을 의미하지 않는다.
- 축적한 교훈: 현행법 제명·기관명 변경, 부설기관 중복 집계, 가능규정의 수탁 사실 오인, 기관명 자동 추출의 과잉 해석을 분리해서 검증한다.
