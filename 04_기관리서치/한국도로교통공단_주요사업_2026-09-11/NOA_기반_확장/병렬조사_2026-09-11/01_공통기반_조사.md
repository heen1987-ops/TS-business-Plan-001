## 공통 기반: 로컬 실행과 기관의 통제
로컬 LLM은 두 서비스 축이 함께 쓰는 배포 조건이다. 데이터 주권의 납품 항목은 저장·접근·목적·실행·보존·감사·이관으로 정의한다. 아래 항목은 조사에서 도출한 설계·검수 제안이며 NOA 기본 탑재 사실을 뜻하지 않는다. | 통제 항목 | 기관이 결정할 내용 | 검수할 동작 |
| --- | --- | --- |
| 저장 | 원문·청크·임베딩·프롬프트·결과·캐시·로그·백업 위치 | 각 저장 위치와 외부 전송을 실제 배포 환경에서 대조 |
| 접근 | 업무 담당·검토자·운영자·국민 본인 사건 범위 | 검색·요약·출처·캐시에서도 권한 없는 원문이 노출되지 않는지 확인 |

| 감사 | 요청·근거·승인·실행 결과의 책임 | 불필요한 원문·비밀값을 남기지 않고 사건별 이력을 추적 |
| 이관 | 계약 종료 시 기관 데이터·설정·이력 반환 | 재사용 가능한 형식으로 내보내고 복원·누락 확인 |
실제 국민 접점은 기존 포털→본인확인·입력 검증→허용 API→내부 NOA 검토→담당자 확정→공개 가능한 결과 반환으로 설계한다. 기존 승인 망연계·인증 경로를 이용할 수 없으면 담당자 보조와 검토 후 서식 출력으로 줄인다. 국민이 내부 전체 RAG에 접근하는 구조를 전제하지 않는다. [F07](https://nis.go.kr/AF/1_7_7_1.do)

### CCK 자산과 추가 개발의 경계

| 자산 | 현재 근거 | 재사용 후보 | 추가 확인·개발 |
| --- | --- | --- | --- |
| NOA | 공식 제품 소개 | 문서·업무·승인·이력의 공통 환경 | 기관 납품 버전·모듈·권한·대국민 화면 |
| Argus | Grantee에 명시; 내부 대장 | 작업 분해·근거 대응·결과 보존 | NOA 실제 탑재, 행정·안전 플러그인·로컬 품질 |
| Keeper | 내부 파생 대장 | 실행 상태·비동기 처리 후보 | 승인 대기/재개·취소·재시도·중복 방지 계약 |
| Nexus | 클라우드 모델 호출 관리 설명 | 모델 호출 중앙 관리 후보 | 로컬 어댑터·도구호출·외부 fallback 제거 |
| Mothership | SaaS 인증·구독 허브 설명 | 조직·인증·권한 모듈 경험 | 기관 SSO·오프라인 라이선스·모든 계층 데이터 격리 |
| RAG | 공식/내부 근거 연결 설명 | 원문·조항 검색 | 권한 상속·삭제/변경 동기화·로컬 임베딩·재순위화 |
| Accio / Audin / Grantee | 회계·정산 도메인 제품 | 대조·규칙/증빙·근거 추적 패턴 | 교통 문서·서식·규칙·검수로 교체 |
| 문서 출력 | 제품 소개·내부 자산 | 검토 가능한 초안·결과 출력 | HWP/HWPX 호환·원문 누락; 외부 라이브러리 권리 |
| Foundry / NL2SQL | 상태 충돌 / 계획 단계 | 기존 완성 기능으로 비용 계상하지 않음 | 필요 시 신규 개발; N07 최소안에는 NL2SQL 불필요 |
NOA–Argus–Keeper–Nexus–Mothership의 실제 탑재 관계는 미확인이다. Keeper 승인 중단·재개, Mothership 권한 수준·암호 설명은 내부 자료 간 차이가 있어 납품 버전으로 대조해야 한다. Nexus의 클라우드 모델 설명과 Mothership의 SaaS 구독 구조를 폐쇄망으로 옮기는 작업을 무상·기완성 기능으로 계상하지 않는다. [F01](https://www.ccksolution.com/noa) [F04](https://www.ccksolution.com/grantee) [F05](file:///G:/%EB%82%B4%20%EB%93%9C%EB%9D%BC%EC%9D%B4%EB%B8%8C/1.%20%EC%97%85%EB%AC%B4%EC%98%81%EC%97%AD/6.%20CCK/%23.%20%ED%9A%8C%EC%82%AC%EC%A0%95%EB%B3%B4/01.%20%EC%95%84%EC%B9%B4%EC%9D%B4%EB%B8%8C/%28AX-CHATGPT%29/01_TECH_ASSETS/00_TECH_CATALOG.md)
폐쇄망 시험은 추론만 대상으로 하지 않는다. 임베딩·재순위화·최초 모델 로딩·패키지/컨테이너·인증·라이선스·로그·외부 도구·문서변환·업데이트·백업·원격지원까지 외부 의존 목록과 실제 동작을 확인한다. 모델 및 구성요소의 출처·무결성도 확인한다. [F10](https://nis.go.kr/AF/1_7_7_1.do)
