# 병렬조사 설명문서 검증

2026-09-11 · 최종 조사·설명 문서의 검증 기록

## 판정

**설명문서 검증 통과 / 조사·기획 문서로 합격 / 사업화·구축 승인은 아님.**

3개 조사 분기 결과를 통합한 뒤 범용 서비스 조사자가 MD와 근거원장을 별도로 검토했다. 7개 후보 누락, 근거·본문 ID, 사실의 과장, 로컬 LLM·인프라0·사람의 최종 판단 조건을 점검했고 중대 결함을 발견하지 못했다. 이 검토는 같은 도구 환경의 별도 에이전트가 수행한 문서 검토이며, 실제 현업·보안·법률 전문가의 심의나 원문 전체 재검증을 대신하지 않는다.

## 실행 검증

- 도구: 번들 Python 생성기, Playwright + Microsoft Edge headless.
- 결과: [검증결과.json](검증결과.json)의 **29개 항목 통과**, 브라우저 스크립트 오류 0, 로컬 문서·앵커 링크 오류 0.
- 자료 무결성: 후보 7개·축별 3/4개, 기존 메뉴 36개, 근거 기록 36개 고유 ID와 연결 확인. 메뉴 집계와 근거 집계는 서로 다른 모집단이다.
- 화면 기능: 축 필터·ID 검색·빈 결과·초기화·모두 펼침/접기·후보/근거 직접 링크·인쇄 시 전체 표시와 상태 복원 확인.
- 접근성 관련 확인: 한국어 문서 언어, H1 1개, 첫 키보드 포커스의 본문 건너뛰기, 입력 레이블·상태 안내·표의 스크롤 영역 제공. **전체 WCAG 2.2 AA·스크린리더 검수는 미실시.**
- 반응형: 1440px 데스크톱 및 390px·320px 모바일 문서 가로 넘침 없음. 넓은 비교표는 각 표 영역에서 좌우 스크롤하고 모바일에 안내를 표시한다.
- 원문 확인: R01 공식 PDF 1쪽 전체를 텍스트 추출하고 Poppler로 렌더링하여 페이지 이미지와 대조했다. Poppler는 일부 문자 매핑 파일 경로 경고를 출력했으나 생성 이미지의 한국어 본문·금액·기간·사업내용이 읽히는 것을 확인했다.
- 기록 반영: KoROAD 원장·후속 대기열·실행이력 갱신, 이전 확장안에 새 조사 링크 추가. TS 기관·법정업무 JSON 객체 보존을 비교 확인했다.

## 시각 확인과 수정

- 데스크톱 첫 화면, 공통 기반·두 축 도식, 모바일 첫 화면과 N04 상세를 직접 이미지로 확인했다. 제목·표·카드의 의미 전달, 여백, 한글 줄바꿈과 내용 잘림 여부를 점검했다.
- 첫 검증에서 모바일 N04 직접 링크 캡처가 smooth scroll 도중 첫 화면을 잡는 문제를 발견했다. 상세 링크 진입은 즉시 이동하도록 수정하고 실제 화면 위치 검증을 추가했다. 최종 모바일 캡처에서 N04 제목·검토 항목이 직접 나타나는 것을 확인했다.
- 모바일 제목의 단어 중간 줄바꿈을 줄이고 넓은 표의 좌우 탐색 안내를 추가했다.
- 원본·브랜드 이미지 생성이나 이미지 편집은 없었다. 구조도는 HTML/CSS로 표현했다.

## 사용자 관점과 남은 범위

사업 담당자는 공통 기반→7개 후보→수행·비용→검증 순서로 읽고, 기술 담당자는 특정 ID·기술·조건으로 후보를 찾아 원문 근거로 이동할 수 있다. 필터에 결과가 없을 때 초기화 경로가 있으며, 모바일에서 상세를 확인하는 동선을 재현했다. 실제 국민·직원 참가자의 사용성 시험은 하지 않았다.

NOA 설치·폐쇄망 동작·공식 API 인증 호출·실제 기관 업무·동시성·수요·사고 감소·확정 가격·2026 사업의 최종 계약 중복은 미검증이다. 이번 통과를 제품 또는 운영 서비스의 품질 보장으로 사용하지 않는다.
