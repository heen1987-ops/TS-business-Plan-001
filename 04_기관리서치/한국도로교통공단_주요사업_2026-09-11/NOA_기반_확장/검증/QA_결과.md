# NOA 기반 KoROAD 확장안 문서 QA

2026-09-11 · 설명 문서 검증 기록

판정: **설명 문서 QA 통과 / 사업화 조건부 검토 / 제품·수행 가능성 검증 전**.

## v1.1 재구성 검증

- 사용자 제안에 따라 공통 데이터 통제 기반과 A 범용 공공업무·국민서비스 / B 교통안전 특화 서비스로 재구성.
- 원장의 대표 축은 A 3개·B 4개로 확인. 기존 7개 ID와 36개 메뉴 연결을 보존하고 N04·N07 등 교차 재사용 설명을 추가.
- 갱신 후 기존 문서 점검 21개 통과. [두 축 데스크톱](두서비스축_데스크톱.png)과 [두 축 모바일](두서비스축_모바일.png)을 직접 시각 확인. 데스크톱 두 열·모바일 한 열에서 내용이 겹치거나 잘리지 않음.
- 초기 모바일 캡처에서 앵커 이동 애니메이션 중 빈 영역이 잡혀, 캡처 시 스크롤 애니메이션을 끄고 두 축 영역을 다시 촬영함. 문서 기능 결함으로 확인된 사항은 아님.
- 데이터 주권은 기획상 저장·접근·외부 전송·운영·이관 통제 요구로 정의. 로컬 LLM 설치만으로 보장되거나 NOA에 모두 검증 완료된 기능으로 표시하지 않음.
- 신규 제품 시험·외부 조사는 수행하지 않고 기존 근거의 분류·설명을 갱신함.

## 수행한 검증

- `검증_NOA.cjs` 실행: 21개 점검 통과. 결과는 [검증결과 JSON](검증결과.json)에 보존.
- 7개 서비스 ID의 고유성, 기존 공식 주요사업 36개 메뉴와의 누락 없는 연결, ORG-0002·인프라 예산 0 조건 대조.
- HTML 내부 앵커·로컬 파일 링크, 중복 ID, 브라우저 스크립트 오류 확인.
- 검색, 검토 경로 필터 3종, 빈 결과, 초기화, 전체 펼침·접기, N02 직접 링크 진입 확인.
- 키보드 첫 포커스의 본문 이동 링크, 1440px 데스크톱·390px 모바일 및 상세 화면의 페이지 가로 넘침 없음 확인. 넓은 표는 해당 영역에서 가로 스크롤한다.
- 인쇄 이벤트에서 전체 서비스가 나타나고 인쇄 후 원래 펼침 상태가 복원되는지 확인. 실제 인쇄물·PDF 레이아웃 검수는 수행하지 않음.
- [데스크톱](데스크톱.png), [모바일](모바일.png), [N02 상세](N02_서비스.png)를 이미지로 직접 확인. 제목·요약·항목 위계와 본문 읽기 흐름에 치명적 잘림·겹침 없음. 데스크톱 캡처에 보이는 본문 이동 링크는 키보드 포커스 시험 상태.

## 내용 QA

- NOA 공식 소개와 내부 엔진 대장을 구분. NOA의 승인 소개를 Keeper의 중단·재개 구현으로 승격하지 않았으며 실제 NOA 탑재 구성은 미확인으로 기록.
- Accio·Audin·Grantee의 회계·정산 기능을 교통 업무의 완성 제품으로 주장하지 않고, 재사용 후보와 교통 도메인 추가 개발을 구별.
- NL2SQL은 기보유 확정에서 제외. N07은 승인된 질의·API 어댑터 개발안으로 작성.
- 기존 조치보고·합동점검, TEMS, 인증 사후관리, 통합시험검사, 온라인교육, TAAS, AI·데이터 플랫폼의 중복 가능성을 보존.
- 공급사 무오류·무사고·성능·절감률·법규 자동 충족 홍보 문구를 성능 보증으로 채택하지 않음.
- 시나리오는 가상 사례로 표시. 실제 KoROAD 민원 발생·빈도·AI 효과를 입증한 것으로 기록하지 않음.
- TS와 KoROAD의 기관·서버·권리·예산 경계 및 신규 인프라 투자 0원 조건 유지.

## 검증 한계

실제 NOA 설치·성능·업무 완료·독립 평가위원 심의·현장 사용자 검증은 이번 문서 QA의 범위가 아니다.

스크린리더·전체 WCAG 2.2 AA 적합성, 모든 외부 링크의 현시점 접근성과 업무 수행 권한, 제품 소스·납품권·실제 공수는 검증하지 않았다. 검수 시나리오는 향후 개발 검수 기준 초안이며 실행된 제품 시험이 아니다. 이미지 생성물은 사용하지 않았고 HTML/CSS로 설명 구조를 구현했다.
