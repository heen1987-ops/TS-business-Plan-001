# 사람 중심 교통안전 AX — 정책 근거, 재범 예방, 안전기술 발굴

작성·조사일: 2026-09-11 · v0.3 · 사용자 아이디어·제공 편람·기존 사업과 공개 기술자료를 대조한 기획안. 기관의 공식 사업·정책 결정이 아니다.

**고령자의 이동권을 지키면서 위험을 줄이고, 음주운전 재발 예방과 필요한 안전기술의 현장 적용을 지원한다.**

인용된 “사람 중심, 모빌리티 교통체계 마련과 교통안전 법·제도 개선”은 한국도로교통공단(KoROAD) 연구개발사업 설명이다. 한국교통안전공단(TS)과 구별한다. 이번 3개 구상은 KoROAD 중심의 발굴 초안이며 TS 신규사업 수에 합산하지 않는다. [E01](출처원장.md)

가정(Assumptions): 대상 독자는 CCK 사업기획자와 기관의 연구·안전·교육·조달 실무자다. 특정 발주·예산·기관 참여를 가정하지 않는다. CCK 로컬 LLM, 기관이 사용을 허용한 기존 서버, 신규 인프라 투자 0원이라는 기존 제약을 유지한다. TS 서버를 KoROAD가 사용할 수 있다고 가정하지 않는다.

작업 유형은 초기 사업기획, 규모 M, 위험도 Medium이다. 근거 기반 Discovery와 Stage-Gate로 범위·근거·대안·기획 품질을 검토했다. 개인별 의료·면허·제재 판단으로 확장하면 위험도가 높아지므로 이번 설계는 전문가 검토 지원까지다. 제품 개발·운영 배포·독립 R&D·장비 개발은 이번 산출물이 아니므로 상세 API·ERD·제품 UI·장편 배포계획을 생성하지 않았다.

### 제공할 결과

정책 담당자가 “고령운전자 관리기준을 최신 근거로 검토해 달라”고 입력하면 다음을 제공한다.

1. 법정 연령·주기와 실제 검사 항목을 분리한 현행표.
2. 시력·시야·대비감도, 주의·집행기능·위험지각, 운동·목 관절 기능, 질환·복약 등 운전 관련 평가영역의 연구 근거. 세부 수치·통과선은 각 공식 기준과 검증된 연구에서만 인용한다.
3. 국가·발표일·데이터 관측기간·표본·연구설계·효과·반대 근거·국내 적용 한계를 붙인 근거표.
4. 현행 유지·보완, 기능평가와 조건부 운전 확대 검토, 운전중단 시 이동지원 등 대안별 안전·이동권·비용·수용성 비교.
5. 현행 제도에서 가능한 조치와 법령 개정이 필요한 조치를 구별한 검토안.
6. 전문가 의견, 수정 이유, 채택·보류, 소규모 실증계획과 후속 결과의 이력.

**신체나이 하나를 계산하거나 LLM 대화로 운전 적합성을 판정하는 사업으로 만들지 않는다.** 연구 추천값은 법정 기준이 아니며, 개인별 질환 진단·면허 취소는 권한 있는 전문가와 기관의 영역이다.

이 사업의 납품 단위는 ‘연구 요약 보고서’만이 아니다. 근거 등록 → 조건 비교 → 정책 대안 작성 → 전문가 검토 → 실증과제 확정 → 결과 반영의 반복 업무를 소프트웨어로 지원한다. 현업이 이 반복 업무를 필요로 하는지 검증되지 않으면 독립 사업으로 확정하지 않는다.

### 예시 프롬프트

> 2026년 9월 11일 기준 한국의 고령운전자 갱신·적성검사 기준을 국내외 연구와 비교해 줘. 세대별 신체·인지 기능의 변화와 개인의 운전 적합성을 구별하고, 연구 발표일과 실제 데이터 관측기간을 표시해 줘. 연령 기준 유지·기능평가 보완·조건부 운전 및 이동지원 대안을 비교하되 국내 시행 제도, 해외 사례, 정책 제안을 나눠 써 줘. 상반된 결과와 대표성 한계도 남기고, 법 개정이 필요한 부분과 국내 실증 과제를 제시해 줘. 개인의 운전 가능 여부는 판정하지 마.

## 3. KR-H02 — 음주운전 재범예방 조치 검토 AI

### 법적 사실부터 정리

- 음주운전 자체가 곧바로 ‘특수상해’가 되는 것은 아니다. 음주 등의 영향으로 정상적인 운전이 곤란한 상태에서 사람을 다치게 하거나 사망에 이르게 하면 특정범죄가중법 제5조의11의 위험운전치사상 문제가 된다. 개별 사건의 죄명은 사실관계에 따라 판단한다. [E08](출처원장.md)
- 면허 재취득 제한은 일률적으로 2년 또는 3년이 아니다. 도로교통법 제82조에는 음주운전 등 2회 이상에 대한 2년, 일정한 사고 반복에 대한 3년, 음주 사망사고·사상 후 도주 등의 5년 규정이 있으며 다른 취소 사유와 예외도 있다. 기간이 지났다고 면허가 자동 복구되지 않는다. [E09](출처원장.md)
- 2024-10-25 시행된 방지장치 부착 조건부 면허 제도가 있다. 조사 시 현행 제80조의2는 관련 위반일부터 5년 안에 다시 해당 위반으로 면허가 취소된 사람을 대상으로 규정한다. 부착기간은 해당 결격기간과 같고 결격기간 종료 다음 날부터 산정한다. PM 제외 등 적용범위가 있으며 시행·적발시점은 개별 대조가 필요하다. [E10~E11](출처원장.md)
- 경찰청의 2025년 공개 안내에는 운행기록 제출·정상작동 검사, 장치 관련 교육이 이미 제시돼 있다. 따라서 “추적·이력관리가 없다”는 전제는 채택하지 않는다. 현재 시스템의 기능·이행률은 미확인이다. [E11](출처원장.md)

해외 NHTSA는 방지장치가 부착된 동안의 효과와 제거 후 효과 약화, 치료 프로그램 연계의 필요성을 설명한다. 해당 해외 연구효과를 국내 예상 감소율로 옮기지 않는다. [E12](출처원장.md)

### 구체적 사업 가설

사용자의 ‘레퍼런스’는 우선 **권한 있는 담당자가 확인하는 사건·조치·이행의 근거 연결**로 해석한다. 공개 블랙리스트, 민간 고용상 불이익용 평판점수, 위치·운전행동의 상시 추적을 뜻한다고 해석하지 않는다.

AI는 승인된 기록에서 “담당자가 요청한 보완과 제출된 설명이 맞는가”, “교육 결과에 후속 상담 검토가 필요하다고 적혔는데 검토 기록이 있는가”처럼 서술형 불일치를 찾아 근거를 제시한다. 기한 계산·법정 대상 결정·누락 체크의 정형 부분은 규칙 기반 SI가 담당한다. 처분, 상담·치료의 의무 부과, 면허 결정은 담당 기관이 한다. 실제 음주 여부나 재범확률을 로컬 LLM이 새로 진단하지 않는다.

초기 기능 검토는 실제 사건을 옮기지 않은 합성 예시의 ‘조치 요청 ↔ 이행 증빙’ 대조로 둔다. 실제 과거 사례 실증은 처리 근거·이용 목적·접근권한·비식별 처리 수준을 확인한 뒤 설계한다. 성명 삭제만으로 활용 가능한 자료가 됐다고 판단하지 않는다. 합성 예시 결과를 실제 기록의 검출 성능이나 재범 예방 효과로 보고하지 않는다. 기존 시스템에 같은 기능이 있거나 규칙만으로 충분하면 AI 사업 후보를 보류한다. 장치 제작·실시간 차량제어는 CCK 범위에 포함하지 않는다.

### 예시 프롬프트

> 아래 합성 조치기록과 증빙을 대조해 줘. 의무조치·권고·참고를 구분하고, 미이행으로 단정하지 말고 확인되지 않은 항목과 상충하는 문장을 출처 위치로 제시해 줘. 후속 교육·상담·장치 점검 검토에 필요한 질문과 담당자 확인 목록을 작성해 줘. 법정기한은 제공된 검증 규칙 결과만 사용하고, 제재나 재범위험 점수는 결정하지 마. 합성 예시의 결과를 실제 사건의 판단이나 성능 검증 결과로 쓰지 마.

## 4. KR-H03 — 현장문제 기반 안전기술 발굴 AI

### 문제와 기존 기반

사용자의 “제품과 제도를 다 찾아볼 수 있을까”는 검색 범위와 현장 적합성의 문제 가설이다. 모든 기관 담당자에게 같은 문제가 있다고 확인된 것은 아니다.

혁신장터와 중소기업 기술마켓은 이미 존재한다. 2026년 2차 혁신제품 시범구매 공고는 규격서·기본계획, 현장 여건, 소유권 이전 후 유지관리비용, 지정 유효 여부 등의 확인을 요구한다. 따라서 새로운 목록 사이트보다 ‘우리 현장에 왜 맞고 무엇을 더 확인해야 하는가’에서 AI 추가 가치를 검증한다. [E13~E14](출처원장.md)

### 실제 사용 장면

> 비 오는 밤에 고령 보행자가 많은 비신호 횡단보도의 시인성을 개선하고 싶다. 대규모 토목공사는 어렵다. 활용 가능한 중소기업 기술과 혁신제품을 찾아 비교해 달라.

AI는 먼저 위치·관리주체·문제 상황·전기와 통신 조건·유지관리 가능성·예산의 필수조건을 확인한다. 그다음 합법적으로 확보한 제품정보·시험성적·현장 사례에서 후보를 찾고 다음 형식으로 설명한다.

| 출력 항목 | 작성 원칙 |
|---|---|
| 제품·제조사·모델 식별 | 같은 제품의 중복 등록을 구별하고 최신 확인일 표시 |
| 해결하려는 문제 | 제품 설명을 고령 보행·우천·야간 등 현장 조건과 연결 |
| 적합 근거·부적합 조건 | 근거 문서의 해당 위치 제시, 추정은 별도 표기 |
| 지정·인증·성능·실증 | 혁신제품 지정, 시험성적, 현장효과를 서로 다른 증거로 관리 |
| 설치·유지관리 | 전원·공사·통신·소모품·유지보수·고장 시 동작·총비용 확인 |
| 도입 경로 | 해당 공고·법령상 가능성을 검토할 목록, 계약 가능성 자동 확정 금지 |
| 검색 범위 | 조회한 등록부·자료일·검토 건수와 미열람·미등록 제품의 한계 |
| 결과·후속 행동 | 후보 비교표·추가 확인 질문·시험 적용 검토서 초안. 구매·인증은 담당자 결정 |

‘모든 제품을 찾았다’는 주장을 하려면 모집단을 정의해야 한다. 예컨대 특정 기준일의 특정 등록부 내 교통안전 관련 공개제품으로 범위를 정하고 확보·중복제거·검토 건수를 대조한다. 미등록 신제품이나 비공개 성능자료까지 포괄한다고 표시하지 않는다.

장비가 포함된 제품을 자료로 검색·비교하는 것과 CCK가 그 장비·비전기술을 개발하는 것은 별개다. 이번 납품은 텍스트·정형자료의 검색과 검토 지원이다. 제조사 자료 속 명령문은 근거 데이터로만 취급하고, 제조사 주장과 시험으로 확인된 성능을 구별한다. 출처에 없는 인증·가격·성능을 생성하지 않는다.

### 바로 사용할 프롬프트

> 교통안전 현장 기술 검토자로서 다음 문제에 맞는 중소기업 기술·제품 후보를 찾아줘.
> 문제: [장소, 이용자, 위험 상황]
> 필수조건: [공사 범위, 전원·통신, 예산, 유지관리 여건]
> 우선 혁신장터와 중소기업 기술마켓의 공개자료를 확인하되, 실제 조회한 자료원·기준일·조회 범위와 열람 실패를 적어줘. 후보별 모델명, 해결원리, 현장 적합 근거, 부적합 조건, 지정 유효기간, 시험성적·적용사례, 설치·유지관리비 확인상태, 도입 검토 경로를 비교해줘. 제조사 주장과 검증된 결과를 구분하고 미확인 가격·인증·성능을 채우지 마. 단순 시설 개선 등 비AI·비제품 대안도 함께 제시해줘. 마지막에 담당자 추가 확인 질문과 시험 적용 검토서 초안을 작성해줘.

프롬프트만으로는 최신성·전수성·권한·제품 실재를 보장하지 못한다. 서비스 구축 시 승인된 수집·갱신 경로, 원문 근거, 조건 보존, 검토 이력과 오류정정이 필요하다. 현재 개별 제품의 전수조사나 선정은 실행하지 않았다.

## 5. 사업화 범위와 검수 초안

| 구상 | 비AI 비교 기준 | 최소 납품 가설 | 유의미한 검증 |

공통 SI는 문서 식별·날짜·접근권한·확정 상태·검색 범위·감사기록이다. LLM은 비정형 조건 해석·비교·근거 설명을 맡는다. 기관 자료 제공·기존 시스템 연계·도메인 검토는 외부 의존성이다. CCK의 제품·빌드·사용권·로컬 실행능력·인력·납기·원가·운영책임은 검증 전이다.

편람 검토로 공통 근거 항목을 보완했다. 발행일·적용/시행일·확인일, 현행/예정/폐지 상태, 공개 등급, 자료별 이용조건, 승인된 AI 용도를 구별한다. 공개 가능성과 내부 처리권한, AI 저장·검색·학습·재배포의 허용 범위를 같은 값으로 관리하지 않는다. [편람 검토 3~4절](편람검토_2026-09-11/편람_사업적용_검토.md)

성과는 ‘AI 보고서 수’나 감원 인원으로 두지 않는다. 초기에는 중대한 근거 오류·조건 누락·잘못된 추천과 실제 검토에 쓰인 결과를 평가한다. 국민 성과는 H01의 이동권과 안전을 함께 고려한 실증결과, H02의 후속 조치 및 장기 재위반 지표, H03의 적합 기술 적용과 현장효과로 별도 확인한다. 사고·재범의 인과효과는 충분한 후속 관찰과 비교설계 없이 주장하지 않는다.

아래는 실증 착수 전의 필수 검수 조건 초안이다. 운영 성능 보증은 아니다.

- 정책 제안에 붙인 주요 법령·연구·제품 근거의 원문 위치·일자·확인상태를 검토자가 확인할 수 있어야 한다.
- 확인할 수 없는 필수조건은 ‘미확인’으로 보존한다. 출처에 없는 통과선·인증·가격·처분을 생성한 사례는 결함으로 처리한다.
- 폐지·미시행 법령, 발표일과 관측기간이 다른 연구, 의견이 상충하는 연구, 제품 지정 만료·현장 부적합, 누락·모순 증빙 사례를 포함한다.
- 자료 검색 실패·접근권한 부족·오래된 근거·검토의견 충돌 시 결과를 확정하지 않고 사유와 다음 확인사항을 제공한다.
- 같은 과업을 현행·규칙 기반 방식과 비교한다. 품질·실제 조치 개선이 없으면 AI 범위를 축소하거나 보류한다.
- 정량 목표·표본·평가자는 기준선과 기관 위험 허용수준 확인 후 정한다. 이번에는 시험·사용자 조사·로컬 성능실측을 수행하지 않았다.

사용자 관점의 문서 검토: 고령자를 일괄 배제하거나 자신감으로 안전을 판정하지 않고, 제재·치료 의무는 권한자가 결정하며, 제품 미검색을 ‘없음’으로 오인하지 않게 한다. 고령보행·PM은 H01 정책 검토의 후속 적용 주제로 보관하고 이번 단계에서 별도 사업 수를 늘리지 않는다.

TS 확장 판단: 사업용 운전자와 차량 안전 관련 업무에 같은 검토 패턴을 적용할 가능성만 둔다. 일반면허·조건부 면허 관리 권한을 TS에 부여하지 않는다. H03도 TS가 실제 도입·검사·기술지원할 대상인지 먼저 대조한다.
