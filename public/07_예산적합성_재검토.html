7억원·5억원 상한에서 다시 판단한 실행 범위

2026-09-22 추가 검토 · 원본 견적은 읽기 전용 · 내부 사전기획용 · 실제 발주금액·계약·제품검증 확정 아님

  • 현재의 공통+MR·SA 56 MM를 7억원에 구축 가능하다고 제시할 근거는 없음. 직접인건비는 4.70억원이지만 2027 후속 견적의 요율을 가정 적용하면 개발비 비교값만 약 15.13억원(VAT 포함)이다.
  • 제품 재사용·업무 범위·공수 증거를 바꾸지 않고 숫자만 낮추면 안 됨.

동일 산정방식으로 비교하면

  • 아래는 직접인건비×(1+120%)×(1+33%)×1.1의 민감도 비교다. 2027 원본 견적을 이번 과업의 견적으로 바꾼 것이 아니며, 공식 확정요율도 아님.
  • 제품 사용권·별도 직접경비·유지관리 등 미확정 비용은 포함하지 않았음.
  • 원본 견적의 1만원 절사와 달리 비교표는 총액을 원 단위 반올림했음.

  • 현재는 공급가격 가정에 따라 실행 가능 판단이 크게 달라질 정도로 산정 근거가 미완성이라는 뜻임. 2026 산출내역의 낮은 잔액형 가산율을 골라 예산에 맞추는 것도 근거가 부족함.

예산이 허용하는 비용 경계

  • 7억원과 추가 5억원은 이전 사용자의 기획 상한임.
  • 과거 문서는 VAT 포함으로 해석했으나 사용자 답변에서 VAT가 명시되지는 않았으므로, 이번 비교도 VAT 포함 가정을 명시함.
VAT 포함 상한 가정 공급가 한도 기타비용 0 경계에서 허용되는 직접인건비
700,000,000원 636,363,636원 217,485,863원

  • 산식: 허용 직접인건비 = (상한 / 1.1 − 제품·직접경비·별도 용역 등 공급가 비용) / 2.926.

  • 표의 기타비용 0원은 이론상 최대값을 보는 경계조건임.

  • 실제 비용을 0원으로 인정한 것이 아님.

  • 이 금액을 평균 임금으로 나누어 곧바로 인원수나 확정 MM로 쓰지 않음.

  • 2027 견적 496,804,000원과 7억원을 단순 비교하면 잔여 총액은 203,196,000원다.

  • 동일 가산 구조·기타비용 0 가정의 추가 직접인건비 상한은 약 63,131,796원다.

  • 견적의 17 MM가 이번 공통·처별 기능 전체를 이미 제공한다는 뜻이 아니므로, 이 잔액만으로 추가 Agent 엔진·2개 처·ERP를 완성할 수 있다고 말할 수 없음.

실행 대안과 권고

대안 무엇을 먼저 확정하는가 평가
A · 전체 기준 설계 유지 공통 25 MM와 처별 대표 8개를 현재 작업량 가정으로 모두 개발 설계 비교 기준으로 보존. 7억+5억 실행안으로 확정하지 않음
B · 제품 재사용형 1개 처 완결 업무 NOA/Agent 기능 시연 → 기납품/사용권 → 미보유 런타임 증분 → MR의 앱미터 변경 검증 1개 업무에 한정 조건부 권고. 목표·계획·실행·검증·재계획을 끝까지 유지하되 적용 업무·연계·데이터를 좁힘. 통과 전 MM·가격 확정 안 함
C · 2027 기존 견적의 과업 재구성 17 MM의 메일·회계·대국민·모델·RAG 범위를 산출물 단위로 다시 나누고 새 업무와 합의 B와 함께 검토. 4.97억원 유지 보장 아님. 불명확한 대국민 서비스 문구를 처별 과업으로 구체화
D · 단순 검색·요약만 구축 공통 실행과 검증을 빼서 비용만 축소 현재 목적 중심 AX 목표를 충족했다고 보기 어려움. 별도 보조도구로는 평가 가능
  • 권고는 B를 먼저 검증하고 C의 범위·가격을 함께 재작성하는 것임.
  • 이미 설계한 다른 처의 UI·흐름·요구는 유지하되 같은 회차에 구축된다고 약속하지 않음.
  • 공통을 인수한 뒤 2차 증분을 산정함. DRT는 정책지원처 후보 중 하나이며 전국 DRT 운행·보조금 예산까지 본 SW 가격에 포함하지 않음.

개발 가치평가: 무엇이 확인되면 투자 판단이 가능한가

확인 단계 필요한 증거 판정·설계 변경
1 · 제품 재사용 목표설정, 계획판본 승인, 도구 실행, 결과미확인, 재계획·재개를 현재 제품 버전에서 시연 동작·사용권 확인분은 신규 제작 제외. 남은 설정·업무 연계·시험만 공수 산정
2 · 업무 성과 대표 실제 사건의 재보완·중요 누락·처리기간 기준값과 개선 가설 앱미터 변경 검증에서 중요 누락을 늘리지 않고 순부담 감소가 있는지 비교
3 · 추가 작업량 문서/기준/예외/화면/실제 API/평가사례 수, 역할별 단위 작업시간 현재 설계 가정 MM를 실사 WBS로 교체. 동일 요구를 중복 산정하지 않음
4 · 가격과 운영 고정일자 견적, 라이선스 증분, 가격 포함·제외, 운영·지원·기간 개발비+운영비+별도 비용+VAT를 상한과 비교; 예산 초과면 범위/재원 재검토
5 · 수용·안전 현업 업무·권한 수용, 개인정보/보안·기존 서버·예외 복구 검증 통과해야 계약 범위와 인수기준을 고정; 확인 실패 시 조건부/보류
  • 금전 가치 산식은 실제 사건량 × 검증된 건당 순부담 감소 × 적절한 시간가치 − 추가 검수·운영·사용료다.
  • 이용자 대기시간과 직원 노동시간을 구별함.
  • 감원 인원으로 환산하지 않으며 사고감소·편익률·ROI/BCR은 실증치가 없으므로 만들지 않았음.
  • 현재 판정은 기획 구조 유지 / 예산 적합성 보류 / 제품 재사용형 범위 검증 우선임.

당장 사용할 내부 확인 목록

  • 제품 담당: 납품 가능한 버전·기능 시연·사용권 범위·기존 TS 설치 목록.

  • 업무 담당: MR 대표 사건·기준·시험 결과·반복 보완 현황, 실제 완료 기준.

  • 연계 담당: 시험계·API 문서·권한·오류/재조회·정정 경로.

  • 견적 담당: 2027 견적 D13을 납품물로 분해; TODAY 발행일 수정; 요율 적용근거·포함/제외·유지관리·추가 사용권 표기.

  • 사업 담당: 분석→설계→구현→시험→인수→운영 전체 과정을 유지한 일정·사람별 가용량 확인.

  • 외부 발송·계약 변경·결제·실제 시스템 등록은 수행하지 않았음.
