K010. 자료 결손·제공계획

10 / 92 · 원문 작업 W02.05 · 독립 컨셉 상세안

열 번째 컨셉의 결과물은 **「자료 확보·보완 제공계획」**임. TS 자료관리 책임자와 수행 데이터 담당자가 2027년 AX 적용을 준비하면서, 진단에서 확인한 자료 부족을 제공 주체·기한·대체수단과 연결하고, 확보하지 못할 때의 실증범위까지 정리하는 항목임.

  • 아래 기록항목·보완방법·사례는 원문 K010을 구체화한 설계 제안임.
  • 실제 TS 자료의 결손이나 제공 약속을 확인한 결과는 아니며, 다른 컨셉과의 묶음은 지정하지 않음.

1. 컨셉의 핵심: ‘부족한 자료 목록’을 ‘누가 보완할지 정해진 계획’으로 전환

앞선 자료 진단에서 무엇을 확보했고 무엇이 부족한지 확인했다면, K010에서는 부족한 부분을 해결할 경로를 정함.

  • ‘자료 확보 필요’라는 문구만으로는 실행하기 어렵습니다.
  • 어떤 자료를 누구에게 요청해야 하는지, 언제까지 필요한지, 제공이 어려우면 무엇으로 대체하거나 어디까지 범위를 줄여야 하는지가 빠져 있기 때문임.

따라서 K010의 핵심 질문은 다음과 같습니다.

“어떤 업무에 어떤 자료가 부족하며, 누가 언제 어떤 방식으로 보완할 것인가? 확보하지 못하면 어떤 작업과 검증을 수행할 수 없는가?”

예를 들어 다음 표현은 부족함.

“철도 심사자료 추가 확보 필요.”

다음처럼 바꾸어 기록하는 안임.

“가상 사건 A의 실행기록에서 대상기간과 사건 식별정보가 확인되지 않아 이행증빙 대조가 제한됨. 원자료 관리 주체에게 해당 정보가 포함된 기존 기록의 제공 가능 여부와 허용방식을 확인하고, 필요한 시점에 확보되지 않으면 해당 검증범위의 축소안 작성.”

  • 이 문장은 작성 예시임.
  • 실제 자료요청이나 진단 결과가 아닙니다.

자료 결손의 원인을 구분

  • 여기서 결손은 단순히 파일이 없는 경우만 의미하도록 좁히지 않음.
  • 필요한 자료가 있어도 사건을 연결할 수 없거나, 해당 사용행위가 허용되지 않았거나, 필요한 값을 읽지 못하면 예정된 작업에 제약이 생길 수 있음.

다만 다음 사실은 구분함.

원천에서 작성되지 않은 자료, 이미 작성됐지만 아직 제공받지 못한 자료, 제공받았으나 이용·연결·판독 조건이 부족한 자료는 보완방법이 다릅니다.

특히 수행팀이 받지 못했다는 사실을 원천기관의 미보유로 확대하지 않음. 실제 존재 여부와 제공 가능 여부를 확인할 대상으로 남깁니다.

계획·약속·수령·해소는 별도

구분 실제로 의미하는 것 의미하지 않는 것
제공계획 작성 필요한 자료·제공 주체·기한·대체경로를 정리 실제 요청 발송·제공일 합의
제공 협의 확인 특정 범위·방법·일정에 관한 확인 근거가 존재 자료의 실제 도착
자료 수령 특정 자료·버전·범위가 실제로 도착 권한·품질·기간·연결 문제의 해소
결손 해소 확인 최초에 기록한 부족사항이 해결됐음을 근거로 확인 전체 실증이나 최종 업무판단 완료

제공계획을 완성했다고 자료 확보까지 완료한 것으로 표시하지 않는 것이 기본임.

2. 어떤 진단 결과를 제공계획으로 연결하는가

원문의 입력자료는 목록·권리·변환·버전 진단이며, 수행내용은 보완 필요 자료를 소유자·기한·대체수단과 연결해 제공계획을 작성하는 것임.

입력 진단 가져올 확인정보 제공계획에서 정할 내용
목록 진단 필요한 자료와 실제 제공범위의 차이, 누락된 문서·쪽·항목·기간 무엇을 어느 범위까지 추가로 요청할지
권리 진단 열람·분석·저장·공유 등의 허용·제한·미확인 사항 자료 재제공이 필요한지, 이용조건 확인이나 제한된 열람방식이 필요한지
변환 진단 원문 판독 상태, 변환 누락·오인식·표 관계·위치 문제 원자료 재제공, 기존 원문의 재처리, 담당자 원문 확인 중 무엇이 필요한지
버전 진단 필요한 과거본·변경문서·적용기간 근거의 부족 어떤 버전·기간의 어떤 원문을 요청할지
  • K006~K009의 진단 결과를 필요한 범위에서 참조하되, 해당 컨셉들을 하나로 합치거나 K010에서 전부 다시 수행하는 것은 아닙니다.
  • 상세안이 작성됐다는 사실과 실제 진단이 완료됐다는 사실도 구분함.

‘필수자료’라고 부르는 근거부터 확인

자료요청 전에 어떤 확인 질문·업무·산출물에 필요한지 기록함.

  • 예를 들어 실행증거 대조를 위해 필요한 것은 해당 사건·기간의 실행기록일 수 있음.

  • 이를 기관 전체 교육·점검·보수자료 요청으로 확대하지 않음.

  • 필수 여부가 아직 현업과 합의되지 않았다면 **‘필수성 확인 필요’**로 기록함.

  • 자료가 많을수록 좋을 것이라는 이유만으로 요청범위를 늘리지 않는 방식임.

같은 부족이라도 보완경로가 다름

문서가 미수령이면 해당 범위를 제공할 주체와 일정을 확인함.

  • 원문은 있는데 변환에서 값이 빠졌다면 먼저 재처리·원문 확인 계획을 검토함.

  • 원천기관에 존재하는 자료 전체를 다시 요청하는 것이 항상 필요한 것은 아닙니다.

  • 과거 기준이 없으면 필요한 버전·기간과 변경근거를 특정함.

  • 현재 기준으로 빈칸을 채우지 않음.

원천 미작성·미보유가 확인됐다면 그 확인 근거를 남기고 대체자료 또는 실증범위 축소를 검토함. AI가 만든 기록으로 실제 증빙의 결손을 해소하지 않음.

3. 자료 확보·보완 제공계획에 무엇을 넣을 것인가

  • 원문의 확보·제한·미확보 구분을 유지함.

  • 다음은 그 상태를 구체적으로 기록하기 위한 적용안임.

  • 확보: 현재 요청 목적에 필요한 자료범위와 이용조건 등의 확인 결과가 있는 상태.

  • 확인한 범위·버전·목적을 함께 적습니다.

  • 제한: 자료의 일부 범위·행위·형식·기간 등에 제약이 있는 상태.

  • 무엇은 사용 가능하고 무엇이 미해결인지 구분함.

  • 미확보: 필요한 범위의 자료를 아직 확보하지 못한 상태.

  • 미수령, 보유 여부 미확인, 원천 미보유 확인 등의 사유를 나눕니다.

  • 상태를 판정할 근거가 부족하면 세 상태 중 하나를 임의로 선택하지 않고 판정 미확인과 필요한 확인자료를 보조정보로 남깁니다.

  • 이는 원문의 세 구분을 새로운 등급으로 대체하는 것이 아닙니다.

계획 한 행의 기록 단위

필수자료·범위 × 사용목적·시점 × 해결할 결손

  • 같은 파일이라도 특정 기간의 자료만 부족하거나, 열람은 되지만 분석이 미확인일 수 있음.
  • 이런 경우 전체 파일에 ‘확보’라고 표시하지 않고 필요한 범위를 나누어 기록함.
기록묶음 구체적으로 넣을 항목 확인하려는 질문
자료·목적 자료 ID·명칭·버전, 사건·기간, 필요한 업무·확인질문 무엇 때문에 필요한가?
결손·근거 부족한 쪽·필드·기간·관계와 진단기록 위치 정확히 무엇이 부족한가?
현재 상태 확보·제한·미확보, 수령 여부, 제한·미확인 사유 실제로 어디까지 준비됐는가?
책임·협의 소유자·제공 주체·요청 담당·이용조건 확인자·수령 후 확인자 누가 제공하고 누가 확인하는가?
요청범위·방법 필요한 형식·범위·식별정보, 허용된 전달·열람 환경 어떤 형태로 어디에서 받을 것인가?
기한 업무 필요일, 요청 희망일, 합의된 제공일, 실제 수령·확인일 언제 필요하며 언제 제공하기로 확인됐는가?
대체·축소 대체수단·한계, 미확보 시 수행 불가한 작업, 남길 범위 받지 못하면 무엇을 바꿔야 하는가?
해소 확인 필요한 완료증거, 실제 보완결과, 확인자·확인일, 잔여 결손 처음의 부족사항이 정말 해결됐는가?

날짜는 세 가지 이상을 구분

요청 희망일은 요청 측이 원하는 날짜임.

합의된 제공일은 제공 주체의 확인 근거가 있는 날짜임.

실제 수령일·보완 확인일은 실행 결과임.

  • “4월 9일까지 필요하다”고 요청한 사실을 “4월 9일 제공 예정”으로 바꾸지 않음.

  • 제공 측 확인이 없으면 합의일은 미확인으로 남깁니다.

  • 또한 업무 필요일은 자료를 받는 날과 같지 않을 수 있음.

  • 수령 후 사건·버전·품질·이용조건을 확인해야 한다면, 그 확인을 끝내야 하는 시점까지 계획에 반영함.

  • 필요한 확인기간은 실제 조건으로 정하고 임의의 고정 여유기간을 추가하지 않음.

4. 작성 예시: 철도 심사자료의 결손을 제공계획으로 전환

  • 다음은 보완경로를 설명하기 위한 가상 사례임.
  • 자료·진단내용·역할은 모두 가정이며, 실제 TS 자료나 제공 약속을 확인한 결과가 아닙니다.
결손 ID 필요한 자료와 현재 상태 가정 제공·보완경로안 필요한 시점 미확보 시 제한·축소안
DEMO-G01 심사자료 A v1의 표가 포함된 3~4쪽 미수령 원자료 관리 주체에게 동일 사건·버전의 누락 쪽 제공 가능 여부 확인 해당 표 대조 전 독립적으로 검토 가능한 다른 항목만 남기고 해당 표 관련 확인 제외
DEMO-G02 문서는 받았지만 사건번호·제출 이력 연결 불명확 제공 주체에게 제출목록 또는 원장 연결근거 요청 사건별 검증 표본 확정 전 사건 연결을 전제로 하는 검증에 사용하지 않음

DEMO-G04 현행 기준은 있지만 과거 사건의 변경근거 미확보 기준 소관 주체에게 필요한 버전·기간을 특정해 요청 과거 사건 평가자료·정답 확정 전 현행본으로 대체하지 않고 확인 가능한 기간·항목으로 축소 검토

  • 원문은 자료 부족 시 확보 범위로 실증대상을 축소하도록 제시함.
  • 이를 제공계획에 반영하되, 실제 범위 변경은 관련 확인·결정 절차와 분리함.

  • 자료의 사용 허용과 업무상 대체 인정은 별도임.

  • 확인되지 않았다면 후보로 유지함.

범위를 줄일 때 같이 바꿀 내용

남길 대상 → 제외할 대상과 사유 → 남은 범위의 필수 입력 → 산출물·검증방법 → 결과 해석의 한계

예를 들어 정상 제출사례만 확보했다면 정상 흐름의 확인은 검토할 수 있지만, 보완·기준변경·중요사항 누락에 대한 성능까지 입증한 것으로 표현하지 않음.

  • 확보된 일부 자료가 최소한의 검증 목적도 충족하지 못하면, 범위를 줄였다는 이유만으로 실증을 완료시키지 않음.
  • 수행 불가 범위와 추가 필요조건을 남겨 소관 결정자에게 인계함.

확보율 하나로 준비 완료를 판단하지 않음

  • 원문에는 자료 확보율 목표·가중치·최소 표본 수가 제시되어 있지 않음.

  • 이번 상세안에서 임의의 비율을 합격기준으로 추가하지 않음.

  • 같은 파일 수라도 빠진 자료가 필수적인 실행증빙인지 참고자료인지에 따라 수행 가능한 업무가 달라집니다.

  • 숫자를 집계하더라도 결손의 업무 영향과 남은 검증 한계를 함께 설명하도록 함.

6. 수행 순서와 K010의 독립 범위

수행은 진단 입력 대조 → 필수자료·결손 정의 → 제공경로 작성 → 대체·축소 검토 → 확인·인계 순서로 제안함.

순서 구체적인 수행내용 남길 결과
1. 진단 입력 대조 목록·권리·변환·버전 결과에서 실제 확인한 내용과 미확인 부분 구분 진단 근거 목록
2. 필수자료·결손 정의 필요한 업무·확인질문과 부족한 자료범위 연결 필수자료–결손 대응표
3. 제공경로 작성 소유자·제공 주체·요청 담당·방법·기한·이용조건 연결 제공계획·협의요청 초안
4. 대체·축소 검토 대체자료의 한계와 미확보 시 수행 가능한 범위 정리 대체 검토·범위조정안
5. 확인·인계 계획 확인 여부와 실제 요청·수령·보완 상태 구분 자료 확보·보완 제공계획과 잔여사항
  • 실제 요청이나 제공이 진행되면 계획에 실행 근거를 추가함.
  • 현재 제공한 문서는 그 계획과 기록 서식을 작성한 것이며, 요청 발송이나 자료 수령을 수행한 결과는 아닙니다.

이번 컨셉에서 끝낼 일

필수자료별 확보·제한·미확보, 결손과 업무 영향, 보완 담당·기한·대체경로, 미확보 시 실증범위 축소안, 해소 확인에 필요한 증거를 정리함.

별도로 남길 일

실제 권리 부여·접근권한 구현, 신규 자료수집 플랫폼 구축, 전체 변환 오류 수정, 기준 효력 확정, 모델 학습·성능검증, 계약·예산 변경, 전체 과제 착수 승인, 다른 컨셉과의 통합은 포함하지 않음.

  • AI를 활용한다면 허용된 진단기록에서 보완 목록과 요청 초안의 작성 보조를 검토할 수 있음.
  • 그러나 소유자·제공일·이용조건을 추정해 확정하거나, 자료를 받지 않고 결손을 해소 처리하지 않음.

AI 사용 자체는 K010의 필수 완료조건이 아닙니다.

8. 바로 사용할 보고서 문안

AX 적용 대상의 목록·권리·변환·버전 진단 결과를 바탕으로 필수자료별 확보·제한·미확보 상태와 부족 범위를 명시하고, 자료 소유자·제공 주체·보완 담당·기한·대체수단을 연결한 자료 확보·보완 제공계획 수립 필요. 요청 희망일과 제공 합의일, 실제 수령과 활용 가능 확인을 구분하여 예정 사항을 확보 완료로 기록하지 않도록 관리. 자료 부족 시 실제 확보·이용 가능한 범위로 실증대상을 축소하고 산출물·검증범위·결과 해석의 한계를 함께 조정. 대체자료는 사용 허용 및 확인 목적의 충족 여부를 검토하고, 부족한 실제 증빙을 합성·추정 자료로 대체하여 검증 완료로 처리하지 않도록 통제.

제공한 MD에는 대상·진단 입력 확인서, 필수자료·결손 개별 카드, 제공계획 목록, 요청·합의·수령 일정표, 대체수단·축소범위 검토서, 결손 해소 확인서, 자료 제공 협의요청 문안을 포함했음.

K010의 최종 결과는 ‘자료 요청 중’이라는 상태가 아니라, 어떤 자료를 누가 언제 어떻게 보완하며 확보하지 못할 때 무엇을 하지 않을지까지 연결한 제공계획임.
