# public/AGENTS.md — 공개 정적 자료 규칙

루트 `AGENTS.md` §1을 먼저 적용한다. **이 폴더의 모든 파일은 빌드 시 `dist/`로 복사되어 공개 URL로 제공된다.** 내부용·검토중·금액 자료를 두는 곳이 아니다.

## 폴더 역할

| 폴더 | 내용 | 규칙 |
|---|---|---|
| `assets/` | 컨셉도·흐름도·아키텍처 SVG/PNG | 처 코드 접두어(`MR_`, `DF_` …) 유지. `check.cjs`가 처별 컨셉도·흐름도 존재를 검사 |
| `downloads/` | 검토 문서 Markdown, 상세 아키텍처 명세 | 각 문서 머리에 작성일·상태·출처 표기 |
| `reference/`, `처별/`, `컨셉/` | 처별 사업정의·UI 시제품·아키텍처 흐름, 컨셉 K001~K092 | 현행 정본 |
| `legacy/` | 구버전 정적 화면 64개와 `snapshot.json`, JavaScript 미사용 진입점 | 자산·문서를 복사해 두지 않는다. 링크는 `../assets/…`처럼 `public/` 직속을 가리킨다 |
| 루트 `NN_*.html` | 통합 검토 문서 | 03·05·07(금액 포함)은 사용자 결정 대기. 금액 추가 금지 |

## 파일을 추가·수정할 때

- 같은 파일을 두 폴더에 두지 않는다. 필요하면 링크로 참조한다.
- 파일명은 `번호_주제.html`, 처별은 `처별/코드_처명/번호_주제.html` 형식을 지킨다.
- HTML 안 링크는 상대경로만 쓴다. `C:/`, `G:/`, `file:///`, OneDrive 경로가 들어가면 `check.cjs`가 실패한다.
- 금액·인원·비율을 적을 때 출처와 기준일, "설계 가정" 여부를 같은 문단에 적는다.
- 기 구축 시스템(TS AI 공통플랫폼 등)에 대한 비교·비판·대체 표현을 쓰지 않는다.
- 삭제·이동한 파일이 있으면 `site-routes.json`과 `legacy/` 링크를 함께 고치고 `npm test`로 깨진 링크 0건을 확인한다.
