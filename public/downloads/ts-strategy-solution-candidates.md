## ST-01 사고취약 수단·계층 정밀 안전망 구축

- 솔루션: **취약안전 우선순위·현장조치** · 관할·수단·취약계층별 위험 근거를 묶어 점검·개선 순서를 제안
- 담당 조직·직무: 교통안전처 / 운수회사 안전관리 · 실증사업처 / 교통시설·사각지대 점검 · 데이터융복합처 / 운행기록 분석 · 모빌리티연구처 / 교통약자 실태조사
- 관계 근거: L01, L02, L03, L04, L17 / 업무 상세는 기존 매핑표 참조
- 업무 흐름: 사고·점검·지역 자료 → 관할·대상·기간 일치 확인 → 현장점검 후보와 미조치 목록 → 담당 부서 확인·재점검
- CCK 재사용 후보: NOA의 점검 기준 검색·요약 / Audin·JET의 증빙 검토·항목 구조화
- CCK 기술 근거 수준: Audin·Foundry·JET·Torus(설계·개발 근거 확인) / 증빙·문서 검토 기술(기술·R&D 근거 확인)
- 추가 개발: 관할·대상 코드 사전 / 점검항목–증거–조치 연결표
- 결과물: 위험 근거 묶음·미조치 목록
- 우선 검증: 위험도는 조치 우선순위의 참고값. 현장 확인과 담당자 지정 전 자동 종결 금지
- 검수 연결: BM-ST-01-T01 / 공통 GAI-T02, GAI-T05, GAI-T07 / 기간·지역 불일치, 증빙 없는 완료 건 주입 → 원천 위치 표시·불일치 보류·미조치 유지
- 효과 측정안: 검토 완료시간 중앙값 / 미조치 탐지 건수 ÷ 실제 미조치 건수 · TS 실측 전
- 사례 근거: [AX01 서울 올빼미버스](https://english.seoul.go.kr/smg-taps-big-data-customized-policy/) · 서울 올빼미버스의 수요·지역자료 결합 방식 참고. TS 사고위험 판정 성과로 전용 금지
- 위험 사례: [AX08 Cruise 사고보고](https://www.nhtsa.gov/press-releases/consent-order-cruise-crash-reporting) · 동일 실패 조건의 TS 시험셋 구성
