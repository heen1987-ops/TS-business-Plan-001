# KA-02 부품 증빙·사후관리 검토 상세 아키텍처

공고 미매핑·논리 상세 설계 / 실제 배포 구조·제품기능 검증과 구분

- 목적: 대상 부품과 제출 증빙을 정확히 연결하여 조사·시험·사후관리의 누락 완화
- 기존 기반: 부품 자기인증 시스템과 기존 시험·조사·사후관리 기록. 외부 인증기관 자료의 사용권 확인.
- 식별단위: 부품·제도·시험회차·증빙
- 공통키: case_id + 대상키 + source_version + plan_version
- 공식 판단: 해당 업무의 현업 담당·전문가 및 원시스템의 공식 권한자. 내부 전결·대결·위탁범위 확인 후 확정.
- 제외·전문가 책임: 시험 수행·품질 판단·조사결과 확인. 별도 인증기관의 권한 및 공식 절차 유지.

## 데이터·완료조건

- 필드: 업무별 의뢰·시험·품질관리 자료 / 제품명·모델·버전·적용차량 등 식별자료 / 허용된 결함정보·시정·사후관리 기록
- 원장 관계: 공식 결과는 원시스템 ID·판본·조회시각으로 참조; 로컬 검토상태와 구분
- 완료: 부품–증빙 대응표 + 미충족·미확인 후보 + 전문검토·후속조치 목록 및 담당자 확인·후속 인계 기록
- 예외: 미확인·판독불가·비해당을 구분하고 적용조건을 담당자가 확인
- 허용 인계: 담당자 확인 후 보완요청·검토과업 인계

## 기존 요구 추적

기존 요구사항을 상세 모듈로 추적하는 설계 매핑. 기존 요구ID·문구·검수·산정값은 변경하지 않음.

KATRI DRAFT ID는 신규 기획용. 공식 RFP 요구ID·승인된 검수 명세 미확정.
