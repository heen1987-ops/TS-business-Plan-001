## 논리 인터페이스

AV2-I01~I12는 이번 제안의 논리 계약 ID. 현재 TS/CCK API 주소·프로토콜·연계완료를 의미하지 않음. 실제 API·파일·승인 경로 확정 후 OpenAPI/파일 스키마로 구체화.

공통 봉투 제안: schema_version, trace_id, case_id, actor_ref, purpose, source_or_input_version, request_id, requested_at

## 배치·운영

논리 프로세스 배치안. 실제 서버 수·망분리·포트·DB 제품·GPU 모델·이중화는 미확인. 기존 서버 내 프로세스/스키마 분리 또는 기존 기능 매핑을 먼저 검토. 16영역 동시운영·무상운영을 보장하지 않음.

공통 모듈은 도입 단위에서 1회 산정, 업무별 규칙·연계·검증은 증분 산정. 기존 계약 납품·제품 사용권·추가 개발 대조 전 금액·MM 추가 없음. 기존 원장의 산정값 유지.

| AV2-W02 | 문서·근거·판본 | C03·C04·DS1·DS2 | aRDa API/기존 색인 검증 + 출처·ACL·판본 연결 |
