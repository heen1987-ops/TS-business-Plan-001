# 세 대화 추가내용 · 통합 정리

작성일: 2026-09-23 · 사업제안용 설계 정리

## 결론

- 조직운영플랫폼 9~17단계의 범위·현장진단·지식·실행·환경·화면·사용자검토·변경·인수 연결.
- K009·K010 기존 상세안 재대조, K011~K021 상세안 추가 열람. 독립 컨셉 ID와 산출물 보존.
- AD27·RD27 기존 편성의 데이터·워크플로우·검증조건 연결. 기존 13개 처·104개 요구·92개 컨셉에 단순 가산하지 않는 원칙.
- 실제 제품 연계·현장 수요·사용자 시험·기관 인수는 미확인. 추가 인력·비용은 미산정.

## 가정과 적용 기준

- CCK 주관 · NOA 기반 · aRDa 조직지식 · 기존 ERP 연계
- 기존 로컬 서버 · 로컬 LLM · 신규 인프라 투자 0원 · 비전 제외
- Agentic OS는 기존 계약 미포함이라는 사용자 확인 유지
- 13개 처 · 104개 기존 요구 · 92개 컨셉 ID의 기준 원장 유지
- PB·K·기존 요구 간 대응은 이번 분석의 참조안. 계약 포함·구현·공수 중복 제거 완료의 증거 아님

## 세 가지 범위의 구분

| 범위 | 정리 방향 | 현재 판정 |
|---|---|---|
| RFP 연구개발 | 원 과제의 연구가설·일정·17개 KPI | 별도 트랙. 이번 TS AX+SI 계약·목표로 전용하지 않음 |
| NOA 제품 확장 | 조직지식·실행·협업·검증·책임관리의 공통 기능 | 실제 배포본·사용권·재사용 범위 대조 필요 |
| TS 기관 적용 | 처별 업무팩·규칙·자료·권한·연계·인수 | 기존 로컬 서버, 인프라 투자 0원, 비전 제외 |
