# KATRI 근거 기반 문서 1차 검토·보완 연계 AX

공개 업무 근거 기반 기획 초안 / 실제 적용·예산·효과 미확정

## 핵심 제안
자료를 읽고 쟁점을 찾는 준비과정을 지원하고, 담당자는 근거 확인·예외 판단·전문검사에 집중하는 업무구조.

조건별 제출자료와 다중 문서 대조가 필요한 업무의 존재는 확인. 실제 누락·재작업의 빈도와 개선 규모는 현업 자료로 검증할 대상.

## 적용 업무와 담당 조직

### KA-01. 기술검토·안전검사 준비
- 연결 조직: 자동차인증처
- 목적: 조건별 서류 누락과 재보완을 줄여 전문검사에 필요한 자료 준비
- 확인 근거: 공식 안내에서 기술검토는 서류 확인, 안전검사는 실차검사로 구분. 자동차인증처 담당업무에 기술검토·안전검사·제원통보·접수 확인.
- 입력 자료: 신청서·제원표·기술검토서 / 해당 조건의 수입·적재·특수장치·대리인 자료 / 원문 파일·접수 목록·적용기준 판본
- 1차 검토:
  - 차종·제작/수입·특수장치 등 조건에 따른 필수자료 구성
  - 신청·제원·시험자료의 대상 식별정보·수치·판본 불일치 후보
  - 보완 제출 이후 해소 여부와 남은 미확인 항목
  - 제원통보 등 다음 단계에 필요한 자료의 인계 상태
- 결과: 조건별 검토표 + 원문 위치가 붙은 쟁점 목록 + 보완요청 초안 + 담당자 인계 묶음
- 전문 판단: 적용기준·예외·기술적 적합성 검토, 실차 확인·시험, 공식 결과·발급
- 기존 기반: 기존 제작자 포털·안전검사 접수·안전기준검토 자동화 프로그램의 실제 기능 대조
- 추가 가치: 고정 파일 유무 확인을 넘어 사건 조건별 검토 범위 구성, 문서 간 대조와 보완 재검토의 연결
- 근거: [기술검토](https://katri.kotsa.or.kr/web/contents/katri1050101.do) · [안전검사](https://katri.kotsa.or.kr/web/contents/katri1050102.do) · [KATRI 조직·직원 업무](https://katri.kotsa.or.kr/web/contents/katri50602.do)

### KA-02. 부품 증빙·사후관리 검토
- 연결 조직: 부품연구처·결함정책처·홍성자동차부품인증지원센터 등 업무별 연결
- 목적: 대상 부품과 제출 증빙을 정확히 연결하여 조사·시험·사후관리의 누락 완화
- 확인 근거: 공개 업무에서 부품 시험·연구, 자기인증적합조사, 품질인증부품 사후관리 확인. 자기인증·대체부품·튜닝부품은 서로 다른 절차와 책임체계.
- 입력 자료: 업무별 의뢰·시험·품질관리 자료 / 제품명·모델·버전·적용차량 등 식별자료 / 허용된 결함정보·시정·사후관리 기록
- 1차 검토:
  - 어떤 제도·역할의 업무인지 먼저 분류
  - 서로 다른 모델·회차·기준의 증빙 혼합 여부
  - 시험 항목·자료 버전·사후조치 근거의 연결
  - 변경·보완 뒤 이전 검토의 재확인 필요 부분
- 결과: 부품–증빙 대응표 + 미충족·미확인 후보 + 전문검토·후속조치 목록
- 전문 판단: 시험 수행·품질 판단·조사결과 확인. 별도 인증기관의 권한 및 공식 절차 유지.
- 기존 기반: 부품 자기인증 시스템과 기존 시험·조사·사후관리 기록. 외부 인증기관 자료의 사용권 확인.
- 추가 가치: 제도별 체크리스트·대상 매칭·변경영향·후속증거 확인. 모든 부품 인증을 KATRI가 승인한다는 설계 제외.
- 근거: [자동차부품 자기인증](https://katri.kotsa.or.kr/web/contents/katri10602.do) · [대체부품 인증](https://katri.kotsa.or.kr/web/contents/katri10603.do) · [튜닝부품 인증](https://katri.kotsa.or.kr/web/contents/katri10604.do) · [KATRI 조직·직원 업무](https://katri.kotsa.or.kr/web/contents/katri50602.do)

### KA-03. 국제기준 변경·검토 대응
- 연결 조직: 안전기준국제화센터 + 분야별 전문 연구부서
- 목적: 검토해야 할 기준 변경과 영향 업무를 놓치지 않도록 대응자료·과업 구성
- 확인 근거: 국제조화 업무와 기존 자동차안전기준 DB 확인. 조직 안내에서 국내·국제 안전기준 및 정책 연구 담당 확인.
- 입력 자료: 승인된 수집범위의 국내·국제기준 원문 / 회의 의제·개정 제안·채택·시행 관련 문서 / 담당분야·기존 검토의견·시험기준 대응표
- 1차 검토:
  - 제안·논의·채택·시행 상태와 발행·수집 시점 분리
  - 신구 조문·부속서·번역어의 변화 후보와 원문 연결
  - 영향을 받을 검토표·시험항목·안내자료 식별
  - 담당자 검토·보완 및 반영 확인까지 추적
- 결과: 원문 대조표 + 변경 영향표 + 담당분야 검토 요청안 + 미반영 항목 목록
- 전문 판단: 기술·법적 해석, 국제협의 의견 확정, 국내기준 반영 판단. 번역·요약만으로 효력 확정 금지.
- 기존 기반: 기존 기준 DB·국제협력·전문부서 검토체계. 수집권한·언어·문서 사용조건 확인.
- 추가 가치: 검색·번역에 추가하여 변경의 업무 영향과 필요한 검토를 구성하고 담당자 확인 결과로 갱신
- 근거: [안전기준 국제조화 개요](https://katri.kotsa.or.kr/web/contents/katri10301.do) · [국제조화 논의 기구](https://katri.kotsa.or.kr/web/contents/katri10302.do) · [KATRI 조직·직원 업무](https://katri.kotsa.or.kr/web/contents/katri50602.do)

## 서비스 흐름
1. **수집·대상 고정**: 접수·공식 원문을 허용된 범위에서 확보. 사건ID·자료 목록·파일 해시·수집일 등록.
2. **검토 범위 구성**: 대상·조건·적용시점별 규칙을 선택. 미확인 조건은 질문으로 남기고 담당자가 검토 범위 확정.
3. **자료·기준 대조**: 정형 필수값·계산은 검증 규칙/도구, 표현·내용 관계는 로컬 LLM 지원. 원문 위치 보존.
4. **담당자 검토**: 쟁점 우선검토와 필수 전문검토 병행. 수용·기각·수정·추가확인 이유 기록.
5. **보완·재검토**: 담당자 확인 후 보완요청. 새 판본과 변경 항목을 연결해 해소·잔여·새 쟁점 재검토.
6. **공식 업무 인계**: 공식 검사·시험·판정 단계로 확인된 자료와 미해결 항목 인계. 문서 검토완료와 합격은 별개.

## 적용·산정 순서
- 우선 적용: 자동차인증처 기술검토·안전검사 준비 중 합의한 한 유형. 정규화된 텍스트·표 자료부터 시작.
- 시험자료: 현업 허용 범위의 정상·보완·변경·판독불가 과거 사건과 필수규칙. 원문 및 전문가 확인결과 확보.
- 재사용·증분: 기존 프로그램·포털·자료관리 기능 확인 후 공통 엔진 1회 + 업무별 규칙·연계·검증 증분 산정.
- 운영확장: 자료 품질·담당자 부담·누락/오탐·서버 여력 검증 후 부품·국제기준으로 단계 확장.

CCK 주관·기존 로컬 서버·신규 인프라 구매 0원·비전 제외. Agentic OS는 현 계약 밖의 추가 개발 검토 범위. 제품 연결·성능·운영비는 검증 전.

## 범위·판정 기준
- AI가 문제 없음으로 분류한 사건도 필수 전문검토와 위험도별 표본 재검토 대상. 후보 미탐지를 위험 0으로 간주하지 않음.
- 도면·사진·영상의 공학적 해석, 물리적 시험·실차 확인은 이번 로컬 LLM 범위 밖. 파일 존재 확인과 내용 검증 구분.
- 필수서류·숫자·단위·계산의 확정적 검사는 검증된 규칙·계산도구 사용. LLM 자체 계산에 의존하지 않음.
- 미확인·비해당·미제출·판독불가·자료접근불가 상태 분리. 자료가 보이지 않는다는 이유로 신청자 누락 확정 금지.
- 공식 결과·법적 지위의 변경, 보완요청 발송·대외 제출은 권한과 확인 절차를 거친 기존 시스템에서 수행.
- 공식 업무안내의 과거 품목 수·기간·수수료를 현재 전체 법정 기준으로 사용하지 않음. 현행 조문·별표·시행일은 구축 전 추가 대조.

## P01–P07 검토
- P01: 국민 안전과 신청기업의 반복 보완·재방문 부담 완화 가설.
- P02: 전문검토·예외판단 집중 지원. 감축 인원 환산 제외.
- P03: 기존 자동화·전자체크리스트와 AI 증분 비교.
- P04: 기준·제품 변화에 따른 확인 부담 가설. 실제 피해규모·발생률 미확보.
- P05: 공통 문서·쟁점·보완 모델 재사용, 기관별 규칙·권한 분리.
- P06: 자동차인증처·국제화센터 등 공개 업무 대조. 개별 법적 권한·현행 조항·전결 추가 확인.
- P07: 실제 업무 필요성의 근거와 실증 평가 연결. 예산·정량 개선율 확정 전.
