# TS 대국민 ARS 접점·처별 기획 연결

- 조사일: 2026-09-23
- 상태: 현행 공개 안내 대조 / 통화·문자·챗봇 실사용 미검증 / 공고 미매핑 기획 초안
- 사용자 제공 표의 업무·경로를 정규화하고 공식 게시내용과 대조. 통화·문자 전송 미수행.
- 가정: 제공 자료를 기존 부서별 AX 기획의 대국민 이용경로 근거로 추가. 기존 13개 대표 과업·예산은 유지.

## 1. 기존 운영과 기획 판단

- 운영지원처: 대표콜센터 운영계통으로 공개.
- 기후탄소물류처: 화물콜센터 운영계통으로 공개.
- 기존 채널: 챗봇·SMS·예약 사이트·상담원 연결의 존재 확인.
- 이용 집중: 월요일·휴일 다음날 상담 연결 지연 가능성 안내.

## 2. 정규화 기준
메뉴 안내의 최종 선택 경로 31개. 상담원·이전메뉴·다시듣기 공통 제어 제외. 지역별 소속 분기는 한 경로로 집계. 신규사업·업무·조직 수와 구분.

## 4. 공통 서비스 모델 — 목적에서 공식 처리까지
- AI 역할: 상황에 맞는 과업 경로 구성·진행 중 미확인 사항 보완·상담 맥락 연결.
- 기존 DX 기반: 메뉴·문자·예약·상담 시스템 재사용.
- 비AI 비교안: 메뉴 단순화, 링크 목적지 개선, 기존 상담원 인계서식 정비.
- 이용 목적 확인: 국민의 표현을 서비스 목적·진행 단계로 구성. 고정 메뉴 탐색 대안 검토.
- 필요 조건 확인: 공식 근거와 업무별 필수정보 대조. 불필요한 개인정보 수집 최소화.
- 공식 경로 연결: 기존 예약·신청·신고·문자·상담 채널 재사용. 연계되지 않으면 현재 경로 안내.
- 상담 맥락 인계: 이용자가 확인한 목적·질문·조치 내역을 허용된 범위에서 상담원에게 전달.
- 완료 여부 확인: 링크 발송·신청 접수·예약 확정·실제 업무 완료를 별개 상태로 기록. 조회권한이 없으면 완료 미확인.

## 5. 구현 경계
- NOA·로컬 LLM: 목적·상황 이해, 추가 확인 질문, 업무 경로 구성, 상담 인계 요약의 적용 후보. 제품·성능 검증 전.
- aRDa·승인 지식: 업무별 공식 안내·버전·근거·담당자 자료 관리의 적용 후보. 기존 자산·사용권 확인.
- 기존 업무 시스템: 예약·자격·신고·발급·정확한 상태의 기준. 승인과 인증이 필요한 변경은 기존 공식 절차 준수.
- 음성·통신 연계: STT/TTS·CTI·SMS·콜센터 API는 별도 확인. 로컬 LLM 보유만으로 전화봇 구현 완료를 가정하지 않음.
- 망·데이터 경계: 공개 연혁의 민간클라우드 콜센터와 신규 로컬 AI 사이 연계 방식·수탁관계·가용자원 확인. 무조건 전면 온프레미스라고 표기하지 않음.

| 중대 오안내율 | 사전 정의한 중대 오안내 건 / 전문가 검토 대상 안내 건 | 자격·검사·신고별 오류 유형과 표본·판단 근거 기록. AI 자동 판정값으로 대체하지 않음. |

목표값·기준선 미확정. 현행 ARS, 메뉴·SMS 개선, AX 적용을 같은 업무·조건에서 비교하고 연령·디지털 이용 여건별 결과 확인.

## 7. 기존 기획 반영·산정 경계
공통 상담·과업 연결 기능 1회 + 업무별 지식·규칙·연계·시험 증분. 현재 민원 AI와 동일 납품분은 계약 대조. 새 수량·예산·고용감축을 확정하지 않음.
- 기존 13개 처의 대표서비스만으로 모든 ARS 업무를 포괄하지 않음. 다음 영역의 세부 기획 추가 검토:
- 운영지원처의 대국민 상담 운영
- 튜닝 승인·절차 지원
- 드론·항공·철도 자격 지원
- 피해자 가족지원의 외부기관 안내 연계
