## MR-02 · 기존 DRT 연계 전화조건 이해·예외 재계획·운영계획 환류 AX

조사·기획 가설 · 현업 정합성/타당성 미확인

- 목적: 전화 접수와 수동 기사 배정의 부담을 줄이고 수요·공급에 맞는 운영계획 개선

- 조사된 병목: 원 RFP가 현행 수동 배차를 명시. 2026 발주의 자동배차·관제 등을 재개발하기보다 전화 요청의 조건 해석과 운영 예외·계획 개선의 실제 미지원 범위를 확인.

- 해결 방법: 전화 요청 텍스트의 출발지·목적지·시간·지원조건 정리 → 확인질문·운영 제약 검증 → 기존 배차/최적화 도구의 후보 조회 → 운영자 확정과 원 시스템 결과 대사 → 예외 원인·수요/공급 기록으로 운영계획 비교

- 자료·조건: 한 조합·생활권의 접수/배정/거절/취소/재배정/운행 기록, 차량·기사 가용, 운영 제약, 실제 배차 API. 최초 입력은 상담 기록 또는 허용된 기존 전사문.

- 공식 판단·중복/제외 경계: 초기는 조회·제안만 허용. API·권한·중복 방지·결과 조회 미확보 시 배차 실행 차단. STT/전화망/발신·전국 배분은 별도 증거 확보 대상. 정산감사·부정수급 판단·환수·전국 예산배분은 현재 납품·대가·핵심 성과에서 제외. 기존 검토 내용은 미선정 후속안으로 보존.

## 실제 회신 처리

공개되는 파일은 질문·준비계획·빈 회신양식만 포함. 실제 회신·식별정보·건강정보·음성녹음·원문 사건자료는 별도 접근제한 공간에서 관리하고 자동 공개/커밋하지 않음. 첫 확인은 자료목록·빈 서식·필드 정의·허용된 비식별 예시부터. 녹음·전사·실자료 이용은 별도 목적/권한/보유조건 확인.

의견·실제 경험·기록·추정을 구분하여 대조. 미응답/담당 아님/자료 부족/미관찰/해결됨을 분리. 동의 비율이나 척도 합계만으로 병목 규모·효과·기관 수요·발주를 확정하지 않음. 상충·반대·소수 의견을 유지하고 원문/사례 확인 뒤 유지·수정·통합·정형 개선·보류·제외 판단.

검토 결과 → 병목 문장·근거·원인 수정 → 기존 대응과 차분 → 필요한 결과·기능/자료/권한/연계 → 검증·인수기준 → 공통/처별 증분 WBS → 적합 대가산정. 설문 회신만으로 FP·MM·가격·개선율 확정 불가.
