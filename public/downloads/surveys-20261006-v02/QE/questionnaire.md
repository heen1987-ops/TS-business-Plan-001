- 목적: 운전적성정밀검사의 소견을 이해하고 필요한 교정교육 활동을 완료하도록 지원

- 해결 방법: 정밀검사 소견·개인 질문의 의미 연결 → 근거 있는 교정활동 안내 → 이해 확인 → 허용된 교육·후속 활동 검토.

- 자료·조건: 검사 회차·항목별 공식 소견 / 허용된 교정교육 기준 / 이해·접근 지원 필요사항 / 교육 계획·실시일지 / 확인자·동의 또는 처리근거 / 후속 검사·관측 결과

- 공식 판단·중복/제외 경계: 정밀검사 판정·안전역량 향상 보장 제외. 정형 안내로 해결되면 AI 범위 축소 신청 대비 입교 차이는 미입교 사유·중복 신청 등을 확인하기 전 수용능력만의 문제로 확정 불가. 연령으로 부적격·위험등급을 자동 부여하지 않음.

## QE-H01 · 고령 운수종사자 기능평가·의료근거 연계 및 검사 변별력 검증

조사·기획 가설 · 현업 정합성/타당성 미확인

- 목적: 실제 기능 저하를 놓치는 경우와 불필요하게 추가검사·자격제한을 받는 경우를 함께 줄일 수 있는지 검증하고, 확인된 기능별 보완을 교육·전문검토·재검에 연결하는 목적.

- 조사된 병목: 현행 강화 검사와 허용 의료 기능 결과로도 중요한 확인 누락·과잉의뢰가 남는지, 추가 정보가 실제 변별력을 개선하는지 미확인. 연령·질병만으로 위험이나 부적격을 확정하는 가설은 제외.

- 해결 방법: 허용된 기존 기능검사·의료 결과의 대상/시점/근거 연결 → 전문가가 정한 추가 확인질문 → NOA 검토안·원문 대조 → 전문 판단과 오류/집단별 부담 비교.

- 자료·조건: 현행 기능검사 결과와 판본 / 허용된 의료 기능 결과·필요 최소 필드 / 전문 참조평가·검수 기록

- 공식 판단·중복/제외 경계: NHIS 질병 원자료 연계는 초기 전제 아님. 별도 제공근거·추가가치 확보 전 제외. AI의 의료/자격 합불 결정 제외.

## 실제 회신 처리

공개되는 파일은 질문·준비계획·빈 회신양식만 포함. 실제 회신·식별정보·건강정보·음성녹음·원문 사건자료는 별도 접근제한 공간에서 관리하고 자동 공개/커밋하지 않음. 첫 확인은 자료목록·빈 서식·필드 정의·허용된 비식별 예시부터. 녹음·전사·실자료 이용은 별도 목적/권한/보유조건 확인.

의견·실제 경험·기록·추정을 구분하여 대조. 미응답/담당 아님/자료 부족/미관찰/해결됨을 분리. 동의 비율이나 척도 합계만으로 병목 규모·효과·기관 수요·발주를 확정하지 않음. 상충·반대·소수 의견을 유지하고 원문/사례 확인 뒤 유지·수정·통합·정형 개선·보류·제외 판단.

검토 결과 → 병목 문장·근거·원인 수정 → 기존 대응과 차분 → 필요한 결과·기능/자료/권한/연계 → 검증·인수기준 → 공통/처별 증분 WBS → 적합 대가산정. 설문 회신만으로 FP·MM·가격·개선율 확정 불가.
