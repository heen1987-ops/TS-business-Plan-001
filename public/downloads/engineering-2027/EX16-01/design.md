## 1. 목적·현행 한계·개발범위

- **목적**: 튜닝·부품 기업이 필요한 시험에 정확히 준비하여 불필요한 비용과 재방문 부담 완화
- **확인할 한계**: 시험목적과 시편·제품판본·조건 불일치 때문에 준비가 반복되는지 검증
- **초기 범위**: 한 부품·시험군의 시편·제품판본·준비 보완 사례. 장비·일정 부족과 문서 준비 문제 분리.
- **입력 자료**: 제품 사양·시험목적 / 공식 시험조건·준비요건 / 시편·신청·보완 이력 / 시편 교체·시험범위 변경·보완 원인·전문가가 철회한 과다 요구
- **연결키**: 부품×판본×시편×시험군
- **담당자·완료**: 시험기관 전문가 / 시험목적에 맞는 시험조건·시편·판본·자료를 전문가가 확정하고 준비완료를 확인해 시험에 인계하는 상태
- **제공할 결과**: 시험목적–시험조건–시편·제품판본–준비자료 대응표와 보완 항목
- **추가 개발**: 시험목적–조건–시편 관계, 준비자료·보완 스킬과 전문 평가사례
- **개인정보·기업자료**: 기업 기술자료 보호
- **범위 경계**: 시험수행·결과판정·성적서 발행은 시험기관. 시험 장비 추가구축 제외 / 장비·일정 부족과 서류 이해 문제 분리

| 적용 위치 | 구현방법 |
| --- | --- |
| NOA | 제품 설명에서 필요한 검증질문·시험준비과업 구성, 보완 후 조건 재대조 |
| 원문·판본 기반 | 기관이 허용한 원문·판본·원문 위치·접근권한을 보존하는 지식 기반. aRDa 적용·재사용은 실제 설치본과 사용권 확인 후 결정. |
| Grantee 후보 | 부품×판본×시편×시험군의 조건·증빙·처리기록 대사 규칙 구성 |

### S2 · 샘플 검증·설계 확정

- **산출물**: 전문가 정답·반례 / 판본·규칙·스킬 초안 / 기존 서버 부하·제품 결합 시험 / 요구사항·산정 단위

- **책임**: 현업 전문가·CCK·QA

- **수행**: 시험목적–조건–시편 관계, 준비자료·보완 스킬과 전문 평가사례

## 7. 공통 보안·AI 윤리·운영

사업유형·재원·규모·시점에 따라 ISP/ISMP·기관 심의·영향평가·보안성 검토·감리·개인정보·AI 윤리 적용 판단. 특정 선행 RFP의 의무·기한을 모든 TS 과제에 적용하지 않는 기준.
