이번 과업 제외: 정비 원인진단, 검사 판정·면제·기한 연장, 위험한 자가정비·운행 허용
선행 확인: 검사유형 1개·부적합 유형 1~2개·참여 차량군

공식 업무 존재와 문제 발생규모·구매수요는 별도. 제품 역할은 적용안이며 TS 설치·성능 검증 완료를 의미하지 않음.

기술 근거: 제품별 근거·재사용 판단 · 기획 출처·확인 한계

대화에서 제안한 2027년 편성안을 이번 설계로 구체화한 자료. TS 확정 업무계획·발주서·계약·실행시험 결과가 아님.

확인된 안전미흡을 적정 조치·정정과 공식 재확인까지 연결하고 예방 가능한 재방문을 줄임.

컨셉

  • 부적합 이후 실제 조치와 재검사 완료 지원.
  • 검사 담당자·검사소·참여 차량 소유자가 차량–검사건–부적합 항목를 기준으로 원문과 공식 결과를 연결하고, NOA가 확인계획·허용된 수행·결과검증·재계획을 담당하도록 구성함.

기존 업무와 추가 가치

자동차검사 소개에서 안내 담당부서 검사기획처를 2026-09-22 확인했음. 전체 분장·신규 서비스 권한·계약범위는 미확인.

검사기획처는 기준 적용·후속 지원의 업무 설계, AI검사인프라처는 실제 검사 원천·예약·전자안내 연계의 역할을 확인함.

  • 일반 검색·요약·안내 기능만으로 도입효과를 주장하지 않음.
  • 추가 가치는 새 사실에 맞추어 필요한 검증과업이 달라지고, 수행결과가 실제 완료·보완 판단에 반영되는지로 확인함.

서비스 범위와 효과 검증

  • 공식 해소/정정 확인율·반복 방문·미추적 비율.

  • 평가 분모는 동일 접수집단의 원 부적합 항목과 참여 차량.

  • 미추적은 실패·성공으로 임의 배정하지 않음.

  • 초기 적용은 자료 접근·참여자·공식 결과 확인·현업 검증이 가능한 범위에서 결정함.

  • 목표값은 기준선 조사 후 합의하며 현재 실제 개선률은 미측정임.

  • 정비 원인진단, 검사 판정·면제·기한 연장, 위험한 자가정비·운행 허용은 제외함.
