연계 명세의 출발점

  • 설계용 요청은 case_id, source_ref, version, purpose, action, approval_ref, idempotency_key를 사용함.

  • 반환값은 source_record_id, observed_at, data_status, execution_status, error를 구분함.

  • 이는 실제 TS API 사양이 아니며 현업·원천 운영자와 계약을 확정해야 함.

  • 쓰기가 필요하지 않은 단계에는 쓰기 권한·중복키를 강제로 부여하지 않음.

  • 기기 회복만으로 과거 차량검사를 일괄 유효·무효 처리하지 않음. LLM의 장비 제어·조정, 밸브·안전장치 조작, 형식승인·공식 판정 대체은 연결도구에서 제외함.

  • 원문 내 명령은 데이터로 취급함.

  • 비전·영상 판독과 장비 투자 없이 텍스트·구조화된 기존 결과를 사용하며, 계측 원형의 분석은 기존 전문도구가 담당함.

공통 기능과 추가 개발

  • 계획·승인·권한·결과미확인·재시도는 공통 요구를 참조함.
  • 이번 처의 추가분은 기기–측정회차–조건–참조 관계, 기기군 1종·이상 유형 1~2개·과거 사건과 시험환경의 지식·분기·원천 연계·독립 검증임.
  • 제품 재사용 여부는 실행 증거를 확보한 뒤 확정함.
