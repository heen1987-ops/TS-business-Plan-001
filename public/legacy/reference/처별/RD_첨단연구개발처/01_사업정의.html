기술 근거: 제품별 근거·재사용 판단 · 기획 출처·확인 한계

대화에서 제안한 2027년 편성안을 이번 설계로 구체화한 자료. TS 확정 업무계획·발주서·계약·실행시험 결과가 아님.

기존 검사방법의 미확인 조건을 찾아 필요한 실험과 독립검증을 조직하고 현장 이관에 충분한 근거를 확보함.

컨셉

  • KADAS 검증공백을 줄이는 연구과업 수행 지원.
  • 검사기술 연구자·시험 전문가·독립평가자가 가설–차량/시료–실험–분석판본를 기준으로 원문과 공식 결과를 연결하고, NOA가 확인계획·허용된 수행·결과검증·재계획을 담당하도록 구성함.

기존 업무와 추가 가치

첨단자동차안전연구에서 안내 담당부서 첨단연구개발처를 2026-09-22 확인했음. KADAS 실제 운영·자료사용권·2027년 연구계획은 별도 확인.

  • 현재 TS 연구업무를 돕는 AX+SI 모듈로 한정함.

  • 새 공학연구·장비투자는 이 구축 견적에 포함하지 않음. KADAS와 KADIS는 다른 체계임.

  • 일반 검색·요약·안내 기능만으로 도입효과를 주장하지 않음.

  • 추가 가치는 새 사실에 맞추어 필요한 검증과업이 달라지고, 수행결과가 실제 완료·보완 판단에 반영되는지로 확인함.

서비스 범위와 효과 검증

  • 중요 검증공백 해소·재현 성공·평가자료 혼입·인수 보완.

  • 평가 분모는 차량/시료 단위 분리, 같은 기록의 반복 집계 방지.

  • 근거 없는 정확도 목표 미설정.

  • 초기 적용은 자료 접근·참여자·공식 결과 확인·현업 검증이 가능한 범위에서 결정함.

  • 목표값은 기준선 조사 후 합의하며 현재 실제 개선률은 미측정임.

  • 새 장비·비전모델 개발, 물리 실험 자동제어, 검사방법의 과학적 검증 대체, 독립 R&D 사업 편성은 제외함.
