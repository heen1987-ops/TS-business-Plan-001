첨단검사전략처 · 인력·대가 산정 준비

미산정·기존 153.5 MM에 미포함 · 과업·인도물 기준 사전 개발 가치평가

  • 현재 금액을 기입할 근거는 부족함. 다음 작업별 물량·처리난이도·재사용 실행증거를 확보하여 산정함.
  • 미산정은 0원이 아님.

같은 사람이 여러 역할을 맡을 수 있어 역할 수를 투입 인원 수로 합산하지 않음. 역할별 월별 FTE 합계 → 월 피크 인원 → 역할별 MM을 구분하며, 일정 중 겹치는 현업 검토·독립시험·운영지원까지 계산함.

산정식·원가 경계

역할별 MM = [Σ(작업물량 × 단위 소요시간) + 별도 작업으로 분리한 문서화·독립검증·이관 시간] ÷ 합의한 역할별 월 가용시간

  • 모든 분자 항목의 단위는 인·시간임.
  • 단위 소요시간에 이미 포함된 문서화·시험·이관 시간은 다시 더하지 않음.
  • 미실측 물량·단위시간은 산정 가정과 실제값을 구분함.

직접인건비 = Σ(역할별 MM × 적용연도 역할별 단가)

  • 작업 방식에 맞는 FP 또는 투입공수 산정방법을 정하고 같은 인도물에 두 방식의 대가를 중복 가산하지 않음.

  • 현재는 내부 작업계획을 위한 WBS이며 확정 FP·단위시간·2027 단가·발주 총액은 미확인임. 기존 대가 검토를 참고함.

  • 공통 엔진·보안·운영의 동일 납품은 한 번 계상함.

  • 도메인 설정·지식·연계·시험은 추가 작업 근거를 연결함.

  • 기존 제품의 실제 재사용 기능이 입증될 때 해당 작업량만 조정함.

  • 원 계약에 없던 Agentic OS 전체를 무료 재사용으로 처리하지 않음.

개발 가치평가

  • 비교 대상은 현행 방식, 비AI 관계·규칙·절차 개선, 개별 AI 보조, NOA 과업 수행형 AX다.
  • 진단불능 해결률·잘못된 정상/고장 안내·현장 재현 실패을 동일 차량군·판본·오류유형.
  • 통신 성공률과 진단 유효성을 별도 측정 기준으로 비교함.
  • 검토·수정·오류복구·정기 갱신 부담을 포함한 순효과를 산출하고, 사람 작업시간과 외부 대기시간을 따로 집계함.
  • 업무시간 감소를 감축 인원으로 환산하지 않음.

비용 확정에 필요한 회신

  • 실제 사례 견본과 유형별 건수, 읽기/쓰기 인터페이스 수, 역할·자료등급, 기존 제품 시연, 독립 시험물량, 협력기관 참여기간, 운영·갱신 범위가 필요함.
  • 역할별 공수와 월별 배치는 이 입력을 받은 뒤 산정함.
  • 금액 크기로 필수 요구분석·설계·검증·인수 과정을 생략하지 않음.
